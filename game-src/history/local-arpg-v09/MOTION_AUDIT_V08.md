# 0.8 동작 재검토

## 핵심 원인

기본 대기0은 사용자가 승인한 체형이다. 그러나 새 시트는 같은 참고 그림을 보고 별도로 생성된 그림이며, 그 결과가 같은 신체 치수를 가진다는 보장이 없다. 전체 키를 맞추는 처리는 머리/몸통/팔다리 비율을 일치시키지 못한다. 이미지 생성 지시에 같은 크기를 요구한 것과 실제 결과가 같은 크기인 것은 다르다.

0.8의 통과 검사는 입력, 판정 시점, 전체 그림을 그대로 표시하는지 확인했다. 몸의 비율, 좌우 지지발의 교대, 동작의 자연스러움은 검증하지 않았다. 이를 작화 개선의 증거로 취급해서는 안 된다.

## 확인한 결함

| 부위/동작 | 현재 결함 | 원인과 필요한 수정 |
|---|---|---|
| 머리/체형 | 전투·걷기·달리기·앉기에서 머리 실루엣 크기가 변함 | 별도로 생성한 원화의 머리/몸 비율이 다름. 공통 키로 일괄 축소해도 해결되지 않음. 기준 대기에서 머리·목·어깨·골반·사지 치수를 먼저 고정하고 작화 자체를 교정해야 함. |
| 정렬 | 자세마다 몸이 좌우로 씰룩일 수 있음 | `append_v08_assets.py`는 그림 높이의46~57% 띠에서 가장 오른쪽 덩어리를 골반이라고 가정함. 자세별로 팔·몸통·허벅지를 고를 수 있음. 실제 해부학적 기준점을 프레임별로 지정해야 함. |
| 걷기 | 팔꿈치를 거의 편 채 왕복하고 일부 실루엣이 튐 | 실제 팔꿈치 굽힘과 어깨/흉곽 반대 회전이 연속된 보행 작화로 확보되지 않음. 생성 결과를 접지·하강·통과·상승의 순서와 양쪽 지지발로 검사해야 함. |
| 달리기 | 앞4장과 뒤4장이 크게 달라져 반복 시 튐 | 원화에서 신체 높이와 자세가 불연속이고, 별도의 행마다 바닥을 정렬함. 99→100에서 그림 상단이13픽셀, 103→96에서14픽셀 바뀜. 단순 재생속도 문제가 아니며, 재정렬만으로 연속 동작이 만들어지지 않음. |
| 쪼그려 걷기 | 지지발 교대와 다리 이동이 불명확함 | 생성 도구가 참고도의 관절 위치/앞뒤 다리 지정에 일관되게 따르지 않음. 전신 원화여도 실제 보행 주기가 확보되지 않았음. 양발의 지지·들기·전진·접지를 먼저 명확히 그려야 함. |
| 2타 | 상체 전진과 뒤꿈치·골반·어깨의 추진이 부족함 | 팔을 뻗은 정지 자세 위주로 선택함. 뒷발 회전, 체중 이동, 상체 전진을 이어 주는 준비/추진/접촉/회수 자세가 필요함. |
| 3타 | 팔꿈치만 굽힌 작은 공격처럼 보이고 실루엣 변화가 작음 | 강한 공격 자세가 확보되기 전에 위력/정지시간/효과를 추가함. 깊은 하중 싣기, 디딤/회전, 큰 어깨 전진과 전신 후속 동작이 우선이며, 타격 방향을 훅/어퍼컷 사이에서 모호하게 두면 안 됨. |

## 수정 순서

1. 기준 대기0의 머리, 목, 어깨, 허리, 골반, 팔다리 길이/두께를 픽셀 좌표로 기록한다. 시트의 첫 그림 높이를 기준으로 삼지 않는다.
2. 전투 가드, 앞발 접지, 뒷발 접지, 깊은 쪼그림을 기준 체형과 같은 배율로 비교해 고정한다. 이것이 맞기 전에는 동작 프레임을 늘리지 않는다.
3. 실제 골반/발 접지/머리 기준점을 프레임별로 지정한다. 현재의 자동 골반 추정은 폐기해야 한다.
4. 달리기와 쪼그린 보행의 좌우 지지발 순서를 검토한 전신 핵심 자세를 먼저 확보한다. 연결 그림과 속도 조절은 그 다음이다.
5. 2타와 3타는 발·골반·어깨가 추진되는 전신 핵심 자세를 확보한 다음 연결한다. 효과를 끈 상태에서도 강약이 보여야 한다.

이번 재검토에서는 실행본과 원화를 다시 교체하지 않았다. 진단 자료는 output/v08-head-audit.png, output/v08-run-registration-audit.png, output/v08-crouch-registration-audit.png와 output/v08-diagnostic-report.json이다.
