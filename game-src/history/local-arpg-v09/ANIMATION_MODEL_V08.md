# 쟈알디 전신 작화 기준

사용자가 선택한 기준은 기존 프레임 0의 기본 대기다. 추출 원본은 output/Jyaldi_canonical_reference.png다. 새 전투 원화나 분리된 신체 부품을 체형 기준으로 삼지 않는다.

## 체형과 크기

- 기존 기본 대기: 머리부터 신발 바닥까지 160 게임 픽셀.
- 머리 크기, 어깨와 골반 너비, 소매와 바지의 두께, 팔·다리 길이를 모두 같은 인물의 기준으로 유지한다.
- 굽히거나 회전하면 보이는 높이와 폭은 달라지지만, 신체 부위의 길이·두께 자체를 바꾸지 않는다.
- 원화의 중립 자세에 공통 배율을 한 번 정한다. 쪼그림이나 주먹을 뻗은 자세를 바운딩 박스 높이로 각각 확대·축소하지 않는다.
- 보행과 전투 전환에서 머리와 몸통을 나란히 비교한다. 머리 크기만 일치하거나 전체 키만 일치하는 것은 합격 기준이 아니다.

## 전체 동작

- 잽: 앞발·무릎의 작은 추진 → 앞 어깨 전진 → 앞팔 직선 뻗기 → 어깨와 팔이 같이 회수.
- 스트레이트: 뒷발 뒤꿈치 회전 → 뒤 골반과 허리 회전 → 갈비뼈·어깨 전진 → 뒷팔 직선 뻗기 → 체중과 자세 회복.
- 마지막 훅: 앞 무릎에 체중 싣기 → 앞발 회전과 골반·몸통 회전 → 팔꿈치를 굽힌 훅 → 전신 후속 회전 → 가드 회복.
- 걷기: 발 접지·하강·통과·상승 주기. 골반과 어깨의 반대 회전, 체중의 좌우 이동, 팔과 반대 다리의 협응.
- 달리기: 접지·압축·추진·공중 주기. 몸 전체의 전진 기울기와 체중 반동, 어깨와 골반의 반대 회전.
- 쪼그려 걷기: 한 발이 몸무게를 받는 동안 다른 발을 들고 전진. 골반 이동과 무릎 접힘을 한 전신 그림에 그린다. 다리를 늘이거나 줄이지 않는다.

## 렌더링과 검토

- 캐릭터의 팔·다리를 분리해 회전시키거나 몸통을 줄 단위로 뒤트는 합성은 사용하지 않는다.
- 각 프레임은 머리·몸통·팔다리·복장까지 완성한 전신 원화다.
- 새 작화가 모두 같은 체격인지 비교표에서 확인한 뒤 런타임에 연결한다.
- 기능 검사는 입력·공격 판정·자원 사용·프레임 연결 오류만 확인한다. 작화의 자연스러움을 증명하지 않는다.
- 구버전의 0.7 관절 수치 검사는 폐기 대상으로 보관한다. 새 전신 작화에 그대로 적용하지 않는다.
