# 필드 대사 작성 규칙 (2026-10-25)

설계 근거: `docs/필드_대사_설계_결정.md`. 이 폴더는 **대사 데이터만** 둔다. 게임 코드 연결은 아직 없다(필드 브랜치 작업과 합칠 때 따로).

- 이름 있는 인물: `characters/<이름>.json` (위키 `card/wiki-base.json`의 person 문서 52명)
- 일반 NPC(복제해서 쓰는 종류): `npc/<종류>.json`
- 검사: `python3 tools/check_dialogue.py` (형식·개수·길이)

## 공통
- 한국어. 위키에 있는 말투·어록·관계를 근거로 쓴다. 위키에 없는 사실(과거사·관계·능력)은 지어내지 않는다.
- **bark** = 플레이어가 지나갈 때 머리 위 말풍선. 혼잣말이나 짧은 한마디. **25자 이하**.
- **talk** = 플레이어가 E로 말을 걸었을 때 상호작용창 첫마디. 1~2문장, **70자 이하**.
- 같은 인물 안에서 같은 문장을 되풀이하지 않는다. 다른 인물과도 겹치지 않게 그 사람 말버릇을 살린다.
- 성적인 대사 금지. 미성년자(학생 NPC 등)가 나오는 대사는 특히 조심한다.
- 빈칸: `{호칭}` = 상대(플레이어)를 부르는 말. 코드가 `address` 규칙으로 채운다. **바로 뒤 조사(이/가, 은/는, 을/를, 과/와, 이라도/라도, 이랑/랑, 으로/로)는 코드가 채운 말의 받침에 맞춰 고친다**(`src/core/josa.ts`). 그래서 대사에는 어느 쪽으로 써도 된다. 플레이어 이름을 직접 쓰지 않는다. 다른 인물 이름은 그대로 써도 된다.
- **ally** = 지금 플레이어와 같은 편(협력·동행·전향 뒤). **enemy** = 지금 필드에서 적으로 마주침. 설정상 적대 관계라도 ally 대사는 「지금은 같은 편」 투로 쓴다.

## 인물 파일 형식 `characters/<이름>.json`
```json
{
  "name": "잼트리",
  "faction": "A00",              // A00 관리국 / B00 가짜 관리국 / C00 백일몽 / "협회" / "지하상가" / "교황청" / "십자군" / "독립"
  "rank": "선임 요원",
  "level": 2,                    // 직급 사다리 숫자. 사다리 밖이면 null
  "voice": "말투 한 줄 요약",
  "address": {
    "self": "언니",              // 자칭 (없으면 "")
    "up": "선배님",               // 같은 조직 윗사람 플레이어를 부르는 말
    "peer": "동기",
    "down": "후배",
    "outsider": "손님"            // 다른 소속 플레이어
  },
  "relations": { "스팡달": "close" },   // 위키에 드러난 특별한 사이만. close / hostile / boss / junior / peer / outsider
  "persona": {                   // 플레이어가 페르소나일 때
    "same":  { "up": CELL, "peer": CELL, "down": CELL },   // 플레이어가 같은 조직일 때 (조직 없는 인물은 이 칸 없음)
    "A00": CELL, "B00": CELL, "C00": CELL, "D00": CELL, "E00": CELL,   // 플레이어 소속별. 자기 조직 코드 칸은 빼고 same을 쓴다
    "etc": CELL                  // 그 밖의 소속(사용자 추가 세력)
  },
  "chars": {                     // 플레이어가 다른 인물(캐릭터로 플레이)일 때, 관계 칸별
    "boss": CELL, "close": CELL, "peer": CELL, "junior": CELL, "hostile": CELL, "outsider": CELL
  },
  "special": { "스팡달": CELL },  // 특별한 사이 인물(위키 근거, 보통 2~6명) 전용
  "time": { "morning": [3], "day": [3], "evening": [3], "night": [3] },      // bark, 상대 무관 혼잣말
  "situation": { "deployed": [2], "returned": [2], "hurt": [2], "companion": [2], "alert": [2] }   // bark
}
```
- `CELL` = `{ "ally": { "bark": [3줄], "talk": [2줄] }, "enemy": { "bark": [3줄], "talk": [2줄] } }`
- `special`의 CELL은 bark 2줄, talk 1줄씩이어도 된다(최소). 
- situation: deployed 투입 직전·작전 중 / returned 작전에서 돌아옴 / hurt 다쳤을 때 / companion 플레이어와 동행 중 / alert 괴이 경보·이상 징후.
- persona 칸 설명
  - 관리국(A00) 인물 기준: same=관리국 플레이어(직급 비교), B00=가짜 관리국 사람, C00=백일몽 사람, D00=괴이를 모르는 민간인, E00=협회 프리랜서.
  - 직급 사다리: 관리국 0 신입 < 1 요원·연구원 < 2 선임 요원·연구 책임자 < 3 부장. 가짜 관리국·백일몽 0 신입 < 1 사원 < 2 주임 < 3 대리 < 4 과장 < 5 차장 < 6 부장 < 7 국장·이사 < 8 전무 < 9 사장. 특이 직책(경비반장 등)·협회·지하상가·독립 인물은 null.
  - 직급이 가장 높은 사람(쟈알디·사장·청달래 등)도 same.up 칸을 쓴다(그럴 일이 드물어도 어색하지 않게).

## NPC 파일 형식 `npc/<종류>.json`
같은 종류는 복제해서 쓰므로 말투를 공유한다. 개인 대사 없음.
```json
{
  "type": "가짜 관리국 검사",
  "faction": "B00",            // 조직 NPC만. 일반인은 null
  "voice": "말투 한 줄",
  "persona": { "same": CELL, "A00": CELL, ... , "etc": CELL },   // 자기 조직 칸은 same. 일반인 NPC는 same 없음
  "time": { "morning": [3], "day": [3], "evening": [3], "night": [3] },
  "situation": { "alert": [3], "hurt": [2] }
}
```
- 프리랜서 NPC는 same 대신 E00 칸이 「같은 프리랜서」다(검사기가 A00·B00·C00만 조직으로 본다).
- NPC의 CELL도 ally/enemy 두 벌. 일반인(경찰·상인·학생·시민 등)은 enemy를 「적대적인 상황·겁먹거나 쫓아내는 투」로 쓴다.
- NPC 종류(동작표 71명 기준): 관리국 직원, 가짜 관리국 검사, 가짜 관리국 진압, 백일몽 직원, 협회 직원, 프리랜서, 경찰, 불량배, 상인, 의사, 간호사, 청소부, 학생, 시민.

## 생태계 대사 (2026-10-26 추가, `eco/`)

필드 세계(docs/필드_세계_NPC_설계.md)에서 인물·몹이 **스스로 하는 일**에 붙는 말풍선. 기존 persona/time/situation 대사와 따로 둔다. 전부 **bark(머리 위 말풍선) 25자 이하**, 한국어, 그 인물·종류의 말투(`voice`·위키 어록)로.

- 이름 있는 인물: `eco/characters/<이름>.json` → `{ "name": "잼트리", "eco": { "<태그>": ["줄", "줄", "줄"] } }` (태그마다 3줄)
- 일반 NPC 종류: `eco/npc/<종류>.json` → `{ "type": "시민", "eco": { "<태그>": [3줄] } }`
- 빈칸: `{상대}` = 함께 있는 인물 이름(수다), `{호칭}` = 플레이어 호칭(기존 규칙). 다른 빈칸 금지.
- 위키에 없는 사실(과거사·관계·능력)은 지어내지 않는다. 성적인 대사 금지. 플레이어 이름 직접 쓰지 않음.

### 이름 있는 인물 태그
| 태그 | 언제 |
| --- | --- |
| `work` | 일하는 중 혼잣말 (그 인물의 일: 결재·장비 점검·감정·서류 등) |
| `eat` | 먹거나 마실 때 (커피·간식·식사) |
| `rest` | 휴게실에서 쉴 때·피곤할 때 |
| `restroom` | 화장실 가며 (점잖게, 직접 묘사 없이 「잠깐 다녀올게」 투) |
| `hobby` | 취미 할 때 (위키 근거 있으면 그 취미, 없으면 일반적인 쉬는 말) |
| `chat` | 다른 인물과 수다 첫마디 (`{상대}` 쓸 수 있음) |
| `hit` | 플레이어에게 맞았을 때 |
| `crowd` | 근처에서 소란이 났을 때 |
| `off` | 퇴근·자리 뜰 때 |

### 일반 NPC 태그
| 태그 | 언제 | 비고 |
| --- | --- | --- |
| `pass` | 지나가며 혼잣말 | 모두 |
| `work` | 근무 중 (청소·경비·안내·판매 등 그 종류의 일) | 일하는 종류만, 없으면 빈 배열 |
| `victim` | 소매치기 당했을 때 | 모두 |
| `thief` | 훔치고 달아날 때 | 불량배만, 나머지 빈 배열 |
| `witness` | 소매치기·시비를 봤을 때 | 모두 |
| `crowd` | 소란 구경 | 모두 |
| `flee` | 도망칠 때 | 모두 |
| `harass` | 시비 걸 때 (취해서) | 불량배·시민·프리랜서만, 나머지 빈 배열 |
| `harassed` | 시비 당할 때 맞받아치거나 피하며 | 모두 |
| `warn` | 범죄를 저지른 플레이어에게 경고 | 경찰·관리국 직원·가짜 관리국·백일몽 직원·협회 직원만, 나머지 빈 배열 |
| `hit` | 플레이어에게 맞았을 때 | 모두 |
| `drunk` | 취해서 혼잣말 (밤) | 시민·불량배·프리랜서만, 나머지 빈 배열 |
