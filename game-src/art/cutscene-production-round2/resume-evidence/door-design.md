## 첫 요청: 북쪽 유리문 닫힘 1종

파일: `game-src/art/hq-door-round2/glass-n-closed.request.json`.

이 파일은 **MCP `create_image_pixen`의 인자 JSON**이다. REST body가 아니다. 96×144 캔버스 안에 80×125 개구부를 목표로 하며, 문턱 앵커를 `(48,136)`으로 제안한다. 2배 표시 시 캔버스 좌상단은 `(door.x-96, 168)`, 개구부는 `(door.x-80,190)`부터 `(door.x+80,440)`까지다. 생성 모델이 이 좌표를 정확히 지킨다고 보장하지 않으며 검수에서 실제 불투명 영역을 측정한다.

프롬프트는 JSON의 `description`을 그대로 사용한다. 요지는 정면의 닫힌 유리 미닫이문 한 개, 숯색 프레임·청회색 유리·젖빛 띠·중앙 이음새, 외부 투명, 인물·문자·배경 없음이다. 이미지 참조 입력은 없다. 문짝 분리와 열림 상태는 이 샘플이 승인된 다음에만 설계한다. 남쪽 출구 표식도 이번 첫 호출에는 포함하지 않는다.

## 공식 도구·과금·투명 지원 확인

2026-10-22 확인: [MCP 도구 문서](https://api.pixellab.ai/mcp/docs), [API OpenAPI](https://api.pixellab.ai/v2/openapi.json), [도구 문서](https://www.pixellab.ai/docs).

| 도구/작업 | 차감 기준 | 이번 계획 / 실제 |
| --- | --- | --- |
| `search_help` | 저장소 사용법 문서에 무료로 기록됨 | 연결 후 먼저 확인 / 호출 0 |
| `create_image_pixen` | 공식 MCP 문서: 1회 | 첫 샘플 1호출, 예정 1회 / 실제 0 |

| 편집·애니메이션·다른 생성 도구 | 이번에 사용하지 않음 | 계획 0 / 실제 0 |

Pixen은 변 길이 4의 배수, 최소 변 16, 면적 상한 512², 한 변이 32 미만이면 정사각형 조건이 있다. 투명 배경은 `no_background=true`, 면적 65,536px 이하. 제안 96×144=13,824px는 조건을 충족한다. API의 `enhance_prompt=true`는 추가 0.05회이므로 사용하지 않는다. MCP와 REST의 인자 구조를 섞지 않는다. 이 표는 문서상 차감 단위이며 계정 청구 결과는 아니다.

## 연결된 세션에서 실행할 요청과 준비물

1. PixelLab 계정과 해당 클라이언트의 PixelLab MCP 연결을 준비한다. 공식 연결 주소는 `https://api.pixellab.ai/mcp`. 토큰은 비밀 설정으로 등록하며 Git·프롬프트·spend.log에 쓰지 않는다. 실제 도구 노출과 계정 접근을 확인한다.
2. 무료 `search_help`에 다음 질문을 먼저 보낸다: “본부 북쪽 벽의 정면 유리 미닫이문 닫힘 1장만 생성한다. create_image_pixen의 width=96, height=144, no_background=true, view=side, direction=south가 유효한가? 차감은 정확히 1 generation인가? get_image/search_help/balance 조회 및 실패·타임아웃 시 차감 정책도 확인해 달라. 캐릭터와 이미지 참조는 사용하지 않는다.”
3. 현행 도구 스키마와 도움말이 이 요청·차감표와 맞는지 확인하고 사용자에게 실제 사용할 도구별 차감을 다시 안내한다. 상충하면 생성하지 말고 기록을 수정한다.
4. 전용 `spend.log`에 `submitted` 이벤트(시각, 도구, 요청 파일, 예정 차감)를 먼저 기록하고 `create_image_pixen`에 JSON을 **한 번** 전달한다. 즉시 job ID/응답을 이어 기록한다. 연결 복구 전 REST 우회 생성은 하지 않는다.
5. 결과는 같은 job ID로 조회한다. 호출 타임아웃으로 결과를 모를 때도 새 생성 요청을 보내지 않는다. 성공·실패·청구 불명 상태와 확인된 실제 차감을 로그에 추가한다. 한 번 실패하면 원인 조사·보고 후 방식을 바꾸며 프롬프트만 고쳐 재호출하지 않는다.
6. 성공 원본을 이 폴더의 `glass-n-closed.candidate.png`로 보존하고 크기·RGBA·외곽 alpha=0·문턱/프레임 위치를 측정한다. 검수 전 이름에 approved를 붙이지 않는다.
