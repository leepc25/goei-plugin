# 메인 통합 담당용 환경 구간

이 묶음은 첫 출근 c3 전체6초 중 앞2.4초만 포함한다. 자동 배포 또는 원본 덮어쓰기 스크립트는 없다.

- environment-runtime.zip: 환경17장과 timing.json, contract.json. 원본 PNG 픽셀·시간은 변경하지 않고 파일명만1부터 맞췄다.
- environment/c1/: 단독 재생 검증용. 기존 VideoPlayer의 base를 이 environment/로 하고 cuts=[2.4]로 시험했다.
- runtime-validation.json: 실제 기존 재생기에서0001..0017 전체 표시, 완주, 오류0 확인. 타입 제거 외 재생기 로직 변경 없음.
- contract.json: 원본0기반→런타임1기반 매핑, 파일별SHA256, 환경/캐릭터 시간 계약.

통합 순서:
1. 별도 통합판 first_day/c3를 준비하고 환경0001..0017을 앞부분으로 넣는다.
2. 다른 담당의 신규 인사 캐릭터 구간을0018부터 잇는다. 이전 반려 캐릭터 프레임으로 채우지 않는다.
3. 환경 ms 배열2400ms와 캐릭터 ms 배열3600ms를 이어 timing.json을 만들고 합계6000ms를 확인한다.
4. first_day의 기존 cuts=[4,4,6,4]를 유지한다면 환경은전체8.0~10.4초, 캐릭터는10.4~14.0초다.
5. 기존 t=8초 인사 자막은 빈 복도에 먼저 나타난다. t=10.5초 다음 대사와 함께 메인 담당이 음성/자막 연출을 정합시킨다.

이 환경 묶음만c3 전체로 사용하면 재생기가 마지막 열린 문을 나머지3.6초 동안 유지하므로 인사 장면이 빠진다.
사용자 시각 승인, 실기기 확인, 캐릭터 연결 및 최종 게임 반영은 이 묶음의 완료 주장에 포함하지 않는다.
