# 컷신 정순 제작 · 2026-10-22

요청서 `docs/GPT요청_컷신영상.md`를 오프닝부터 회식까지 순서대로 확인했다. 각 컷 시작 전에 main을 새로 받아 `timing.json`, PNG 수, 연속 번호와 크기를 검사했다.

- 오프닝 c1~c8을 새로 제작하고 컷별로 커밋·푸시했다. c8은 최종 검수에서 보라색·연두색 머리를 보존하도록 공통 팔레트를 보정했다.
- 오프닝 c9와 나머지 37컷은 최신 main에서 완료 조건을 충족해 기존 파일을 유지했다.
- 10편 모두 `frames/index.json`에 등록되어 있다. 최종 납품은 46컷, 396프레임이다.
- 새 그림은 내장 image_gen으로 생성했다. PixelLab은 사용하지 않았다. 프롬프트와 생성 원본은 `forward-records/`와 `forward-sheets/`에 보존했다.
- PNG는 불투명 640×360이다. 새 컷은 컷별 공통 64색 팔레트와 최근접 샘플링을 사용하며 디더링·보간 필터를 사용하지 않는다. c8은 배경 48색에 생성 원본에서 추출한 붉은색·녹색·파란색·보라색 계열 각 4색을 함께 배정했다.
- c2는 생성된 긴 건물 원화에서 24프레임으로 카메라를 내린다. c6의 마지막 125ms는 균일한 흰 화면 전환이다. c8은 8장 입장과 16장 개인 동작으로 구성한 6초 장면이다.
