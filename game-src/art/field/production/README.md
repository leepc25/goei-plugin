# 전체 캐릭터 제작 · 현재 실행 인계

최신 사용자 지시: 실제 정면 기준 그림을south에 넣어8방향 등록한다. 이동·전투 동작은east, 제자리 비전투 상호작용은south-east다. 견본20종 중south-east는breathing-idle와drinking뿐이다. 전투대기는east다. 약7등신, 정상 머리·목·가랑이 비율을 지킨다.

원작55명(관리국12, 가짜관리국14, 백일몽16, 기타13)을 `manifest.json`에 원작 파일·SHA-256·위키 외모·실제 검토한 원화의 외형과 함께 기록했다. 원작은사전시각검토이며, Pro Flash 요청에 직접 전달되는 이미지 입력은 기존 성공 남성 도트의 **스타일 참조**다. 원작 이미지를 외모 참조 입력으로 전송했다고 주장하지 않는다. 정면·128×256·48색·투명·seed10222027로 생성한다.

지침을 먼저수정한 뒤 쟈알디부터 전면재생성을 시작했다. 첫등록·방향착오·일반template실패·취소결과는 `history/`에 보존한다. 새쟈알디는구형남동이미지를direction_images로 혼합하지 않는다. 스팡달은 새정면생성과 8방향등록을 이미접수했으며, 응답중단후 같은job을 조회해복구했다(중복등록안함).

실행기: `tools/field_character_production.py`. 진행저장: `state.json`, 실행제어: `control.json`. 환경변수 `PIXELLAB_API_KEY`만사용하며 비밀값은 파일에기록하지않는다. 최대20개진행, 캐릭터그림/등록은6개진행으로두고 남는자리에동작을넣는다. 등록 background job 완료·8방향·저장된18관절3D골격을 모두확인한후 견본을 `skeleton-v3`로만요청한다. 일반template으로우회하지않는다.

현재쟈알디만동작재개가허용되어있다. 쟈알디새동작의 실제프레임·방향·몸비율·외형을검수한뒤 관리국→가짜관리국→백일몽→기타순으로 `motion_allowed_slugs`를확장한다. 사용자지시는전체제작을계속하라는것이며, 이검수단계가작업전체정지를뜻하지않는다. 다른캐릭터그림/등록은계속진행한다.

실패복구: 사용자는결함확인·설명/설정수정·리롤·재검수를허용했고, 실패를그대로건너뛰거나전체중지하지말라고지시했다. 자동실행기는중복과무근거과금을막기위해실패/응답불명POST를무조건반복하지않는다. 담당에이전트가오류와결과를조사해해당요청을고치고재접수한다. 독립작업은계속진행한다. 401/429는미접수응답이므로지연후다시연결한다. 응답불명은job조회로복구하고같은POST를복제하지않는다.

그림과등록만완료된것을20동작완료나게임적용으로보고하지않는다. 각원본/프레임/영수증/사용량을보존하고검토용단일HTML을함께만든다. `state.json`의API실사용량과예상견적을구분한다. 전후잔여량은동시작업중개별호출비용으로배분하지않는다. 생성기준·비용·실패복구는지침과spend.log에도갱신한다.

현재브랜치: `codex/field-art-input-pipeline`, 공유PR: https://github.com/leepc25/goei-plugin/pull/26. 사용자별도지시없이main병합/배포하지않는다. 실행기는5분간격으로자신의제작폴더만커밋/푸시한다. 다른파일의변경은덮어쓰지않는다.

재개: 살아있는실행기를먼저확인한다. 동일폴더에프로세스잠금이있으므로중복실행하지않는다. 백그라운드nohup은호스트에서종료된사례가있어지속실행을보장하지않는다. 도구의실행세션에서foreground로유지하고 실제접수/상태변경을확인한다. API서버가수행중인job은로컬세션종료와별개로계속될수있다.

최근 사용자 확인: 키·체격·복장은 인물별 원작/위키를 따른다. 공통230~240px 몸 높이 지시를 제거했다. 명부의stature_rendering은 제작상의 상대 높이 목표이며 설정상cm가 아니다. 7명 동일 바닥선 비교에서 에일린·데드폴의 작은 체구가 약해지고 큐라스가2m 고르고디오와 같은 높이인 결함을 확인했다. repair-queue.json의3건을 실행기가 기존 접수 작업 종료 후 이력 보존하고 새 정면부터 다시 만든다. 동일 실패 요청 반복이 아니라 인물별 높이 목표·스타일 참조 범위를 고친 요청이다. 추가 예상 비용은 인당 그림9+등록4이며 실제 사용량은 영수증으로 기록한다.

`python tools/field_production_review.py`는 비용 없는 로컬 검수HTML과 실제API사용량spend.log를 갱신한다. `review.html`은 현재 원본의 동일확대·동일바닥선 비교와 완료동작 재생을 제공한다. 생성 완료 후 갱신하고 실제 이미지를 직접 검수한다. 수정 전 결과는history/stature-v2-*/에 보존된다. 미완성·미승인을 완료로 보고하지 않는다.
