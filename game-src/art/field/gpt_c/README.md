# GPT 배경 C안 → 관리국 (2026-10-25)

사용자가 준 GPT 4안(A–D) 중 C안을 관리국용으로 골랐다. 원본은 `../raw/gpt_c/`.

고른 이유: 밝고 정돈된 현대 정부 기관 톤, 층 사이 화풍·재질 일관, 지하(B2)가 회색 시설 톤으로 지상과 구분됨, 2F·B2에 층 숫자 글자 없음, 도트풍 윤곽이 또렷함.

편집(`tools/fit_bg700.py`): 문 높이를 300px(1m = 142px, 맨 뒤 사람 235px)로 맞춰 배율을 정하고, 벽·바닥 선을 y420에, 세로 700으로 자름(위는 천장 일부, 아래는 화면 밖 바닥).

- 바닥(y420–700)은 화면 아래 40%, 걷는 범위 y420–669.
- 천장은 위 40px 정도만 남음(지침 2절). 천장 다운라이트 몸체는 대부분 잘리고 벽의 빛 원뿔만 남음.
- 리샘플은 LANCZOS(배율 0.98–1.09라 화풍 변화 작음).
- CB3(지하 주차장)은 원근 구조가 달라(벽선 약 72% 높이) 같은 방식으로 맞추면 차량·천장이 크게 잘려 보류.
- 원본에 남은 것: 바닥 광택 반사, 나무 세로 패널(지침 0절과 다름), 3F·B1에 화장실·계단 픽토그램.
