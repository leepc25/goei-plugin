# 장 단위 검수 기록 (Claude, 생성 직후)
판정: 통과 / 장 뺌(n) / 다시(뼈대 바꿔 재생성) — 결과는 tools/build_blaret_saladin_demo.py FIX와 결함 목록에 옮김.
모든 장은 fxclean(총구 불꽃·연기·떨어진 조각 자동 삭제)을 거친 뒤 봄.

## 블라렛
- idle 통과
- walk 통과
- run 통과 (상체 숙인 질주)
- blink 장 뺌(4): 마지막 장이 깨짐(살색 조각)
- draw 통과
- guns_idle 다시: 손이 가슴 앞에 모이며 총이 사라짐 → 허리 높이 준비 자세로 뼈대 바꿈
- fire 통과 (모델이 그린 불꽃·연기 지움)
- fire_split 통과
- cut1 장 뺌(0): 첫 장에 검이 없음

## 성전 병사
- march 통과 (발 움직임이 작음, 행진 속도는 코드가 밀어 줌)
- slash 통과, 사소: 1장에서 칼이 방패 뒤로 가려 안 보임
- rise 통과 (웅크렸다 일어남, 땅에서 솟는 연출은 코드)

## 고위 맘루크
- run 통과 (폭약을 끌어안고 숙인 채 돌격)

## 블라렛 (이어서)
- jump 통과
- air_fire 장 뺌(2,4) + 총구 앞 칸 지움: 모델이 옅은 불꽃·연기를 그려 자동 삭제로 다 안 지워짐
- reload 통과
- stake_throw 통과 (날아가는 말뚝은 코드)
- stake_finish 다시: 모델이 밑에 쓰러진 사람을 그려 넣음(인물만 규칙 위반) → 동작 글에서 「쓰러진 적」을 빼고 「빈 바닥에 내리꽂기」로 바꿈
- extract 장 뺌(5): 칼이 두 자루로 겹침
- sword_idle 장 뺌(0): 첫 장만 칼을 세우고 나머지는 어깨 뒤로 눕혀 반복 때 튐 → 어깨에 걸친 3장 반복
- cut2 장 뺌(3): 칼날에 모델이 그린 잔상 덩어리. 사소: 0·1장 칼끝이 살짝 번짐
- cut3 통과 (크게 휘둘러 무릎 꿇으며 내려벰)
- lunge 통과 (사소: 0장 칼이 흐림)
- rise 장 뺌(4): 칼이 사라진 장
- plunge 4~6장 빛기둥 지움(모델이 그린 효과). 사소: 칼이 바닥에 꽂히지 않고 눕혀져 「내리꽂기」보다 「내리찍기」로 보임, 3장 칼 흐림, 7장 칼 끝에 짧은 가로줄
- sword_break 통과
- palm 통과
- wave 통과
- click 통과 (귀 옆 손짓)
- guard 통과
- high_kick 통과
- sidestep 통과 (사소: 2장 머리카락 끝 번짐)
- backflip 통과 (사소: 3장 뒤집힌 몸이 뭉개짐, 빠르게 지나가는 장)
- cathedral 통과 (무릎 꿇고 기도 → 두 팔 들어 올림)
- command 통과 (칼끝으로 앞을 가리킴)
- super_ready 다시: 두 팔이 머리 위에서 겹쳐 얼굴이 가려지고 뒤돈 것처럼 보임 → 팔을 앞 위로 벌리게 뼈대 바꿈
- super_cut 장 뺌(0,1): 칼을 머리 위로 든 첫 두 장에서 얼굴이 팔에 가려 뒤돈 것처럼 보임
