## 기존 자료 대조

시스템 59a2a883과 Claude 067f62a148788799373d304704bcf13ee8208484의 전용 원본·spend.log·manifest·빌더는 Git blob이 같다. baseline-comparison.json에 파일별 blob을 보존했다. 전체 브랜치 병합 없음. 준비 브랜치의 검수판, 뼈대, 회수 도구는 담당들에게 경로를 인계했으며 큐라스 두 유료 작업은 중복 회수하지 않았다.

기존 인계의 171회는 과거 집계이며 현재 잔액이나 작업별 실비 증거가 아니다. 신규 비용은 각 receipt.json의 서버 cost만 집계한다. 과거 spend.log가 응답을 160자로 잘라 job별 cost를 누락했으므로 미확인을 0으로 채우지 않는다. 기존 상한은 460회, 이번 우선 묶음은 6건/18회 견적이다.

## 실패 원인과 바꾼 방법

기존 base.json은 두 캐릭터에 다른 그림의 기본 관절을 적용해 실제 기준 그림의 팔꿈치·손과 어긋났다. 본인 기준 PNG를 직접 열어 관절을 측정했다. 새 요청은 view=side, no_background=true를 명시한다. 블라렛 총 대기는 두 손이 겹치지 않게 위치를 벌리고, 처형은 공중 예비동작을 제거해 접지한 무릎 동작으로 바꾸고, 필살 준비는 팔꿈치/손을 얼굴 앞에서 바깥으로 이동한다. 살라딘은 본인의 draw/07.png를 참조해 이미 보이는 무장을 유지한다. 다른 캐릭터의 PNG는 입력하지 않는다.

이동은 지지발을 프레임 공간에서 고정하고 몸을 전진시킨다. 반복 경계에서만 root_motion.cycle_dx를 적용한다. 아직 실제 출력 픽셀의 접지가 검증된 것은 아니다.

각 request.json은 입력 SHA-256과 요청 SHA-256을 포함한다. receipt.json이 있으면 준비 도구도 같은 작업을 다시 준비하지 않는다. 기존 gen.py의 삭제·자동 재시도·8건 동시 제출 경로는 사용하지 않는다. 원래 clips/와 기준 그림은 덮어쓰지 않는다.

## 규칙 충돌 인계

캐릭터 전용 최신 설계서 3장/인계는 쌍권총·성검·언월도·소총을 인물에 포함하지만 공용 인수인계는 무기 분리를 요구한다. 이번 사용자의 총 소실 수정 요청과 캐릭터 전용 설계에 따라 전용 검수판에서는 무장 그림을 검수한다. 엔진 연결은 하지 않으며, 통합 시 무기를 이중 렌더링하지 않도록 별도 판단이 필요하다.

생성 완료, 내부 검수, 사용자 시각 승인은 별도 상태다. 새 결과의 검수는 review.json에 기록한다. 아직 사용자 승인 없음.

## 인계에서 미검수였던 블라렛 여섯 클립

- hit 0–3: 얼굴·복식 유지, 몸 뒤로 젖힘과 베일 반응 확인. 발은 땅에 있다.
- stagger 0–5: 3장에서 팔이 얼굴을 일부 가림. 비틀거림 중 동작성 가림이며, 오래 유지하는 전투 준비 자세와 구분. 뒤로 물러나는 동작이 읽힘.
- down 0–6: 1–2 공중, 3–6 등과 다리로 착지. 다른 인물 없음. 누운 얼굴·복식 유지.
- getup 0–5: 1장의 몸 접기에서 얼굴 가림, 2–3 공중, 4–5 착지/정자세. 동작 순서는 읽히나 1장의 다리 겹침은 확대 검토가 필요.
- halfblood 0–5: 미세 고개 숙임. 얼굴·복식·손·접지 안정. 큰 전투 동작으로 과장해 해석하지 않음.
- wrath 0–5: 고개 들고 한 걸음 전진. 얼굴/복식 유지. 발 위치 이동이 있어 엔진에서 추가 전진을 이중 적용하면 안 됨.

이 여섯 클립은 기존 그림의 신규 검수이며 새 생성/사용자 승인으로 집계하지 않는다. 원본과 기존 시연판을 바꾸지 않았다.
