## 코드와 그림을 분리한 판단

최신 시스템 기준의 `src/game/action/engine/player.ts:233`은 실제 이동량을 `finishLocomotion()`에서 재어 `gaitFrame`을 진행한다. 벽에 막힘·정지·방향 전환은 `resetLocomotion()`로 처리된다. 따라서 이전 시간 기반 재생 문제를 현재 미수정이라고 보고하면 안 된다. 이 검수는 엔진을 수정하지 않았다.

다만 최신 코드의 이동량 기반 동기화가 **각 프레임 지지발의 월드 좌표를 고정한다는 뜻은 아니다.** 현 원본 walk/run은 몸통 x가 대체로 고정된 제자리 사이클이며 `manifest.adv=0`이다. 요구된 「그림 안에서 전진하고 코드가 끝 장에서만 이동」 규격과도 다르다. 그림 제작에는 지지발 고정/루트 이동 메타데이터가 필요하며 엔진 담당에게 연결 패치로 전달해야 한다. 코드 속도만 고쳐 그림의 팔·무릎 결함이 해결됐다고 보고하지 않는다.
