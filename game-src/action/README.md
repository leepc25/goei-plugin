# 쟈알디 도트 제작 자료 — 체형 개선 시연판

> 신규 목표는 `jyaldi-production-v3.json` 및 [일반 체형 v0.3 명세](../../docs/쟈알디_일반체형_도트규격_및_동작프레임_v3.md)다. 128px 원본·2배 표시, 약 6등신과 상하체 매스 균형·조금 큰 손을 사용한다. 아래 배포판/160px 자료는 이전 구현 기록이며 새 규격을 적용한 결과물이 아니다.

인상·머리·눈·복장의 참고 자료는 사용자가 첨부한 **Jyaldi_default.png**다. 사용자의 정정에 따라 해당 그림의 체형을 그대로 확장하거나 복사하는 규칙은 적용하지 않는다. 전신 체형은 자연스럽고 미형인 성인 여성으로 별도 설계한다. 저장소 설정의 일반 설명이나 생성된 다른 그림이 이 원본을 대체하지 않는다. 첨부 원본의 Windows 경로는 클라우드 작업 환경의 파일 경로가 아니므로 직접 읽었다고 간주하지 않는다. 이미지 생성에는 대화에 첨부된 실제 이미지를 참조한다.

지켜야 할 정체성:

- 길고 날카로운 성인 여성 얼굴, 반쯤 내려앉은 붉은 눈과 차분하고 서늘한 표정.
- 긴 검은 생머리, 검은 넥타이, 흰 셔츠, 몸에 맞는 검은 정장, 검은 장갑.
- 일반적인 밝고 둥근 애니메이션 얼굴이나 남성적인 넓은 재킷으로 교체하지 않는다.
- 전체 키를 유지하며 몸통·복부·골반을 충분히 확보한다. 사타구니를 지나치게 높이지 않고 긴 종아리를 줄여 자연스럽게 맞춘다.
- 첨부 원본에 보이지 않는 하체의 세부는 게임용 보완안이며 원본 그대로라고 주장하지 않는다.

현재 적용 상태 (2026-10-19):

- `jyaldi-master.png`는 고정한 전신 체형 기준이다. 사용자에게 최종 승인을 받았다고 주장하지 않는다.
- `motions/`는 이 기준을 참조해 새로 제작하고 실제 160px에서 검토한 동작 원본이다. 과거 SD 동작 초안은 배포하지 않는다.
- `layout.json`에 원본 SHA-256, 연결 요소 수, 시트 전체에 적용하는 단일 배율과 실제 클립 매핑을 기록한다. 프레임별 가로/세로 비율 보정은 없다.
- 실제 런타임은 기준 포즈 포함 44프레임이다. 걷기 6, 달리기 8, 장타/팔꿈치/앞차기/사격 각 4, 대기 2, 방어·점프·착지·피격·다운·기상을 포함한다. 회피는 달리기 2프레임을 공유한다.
- 앉기·다운을 서 있는 160px로 확대하지 않는다. 배경은 `bureau-corridor.png`를 640×360, 96색으로 패킹한다.

재현 (Python 패키지 Pillow, numpy, scipy 및 `npm ci` 필요):

```sh
python3 tools/action_master.py
python3 tools/action_assets.py
npm run build
```

게임: `dist/goei-action-demo.html`. 동작별 정지·프레임 이동·2배 확대 확인: `dist/goei-jyaldi-motions.html`. 배포본은 `release/demo/`에 둔다. 원본 PNG는 HTML이나 게임 팩에 넣지 않는다.

## 체형 시안과 실제 크기 비교

`jyaldi-master.png`는 전신 실루엣을 다시 다듬은 **검토용 시안**이다. 최종 승인 또는 전체 동작 제작 완료를 뜻하지 않는다. 고해상도 제작 원본을 게임에 그대로 넣지 않는다.

```sh
python3 tools/action_master.py
```

결과는 `dist/goei-jyaldi-proportions.html`이다. 원본 비율 표시, 실제 160px, 160px의 2배 표시, 640×360 배경 위 접지를 한 페이지에서 비교한다. `game-pack/action/master.json`에 원본 영역과 단일 배율을 기록한다. 이 비교 자료는 기존 게임의 캐릭터 그림을 자동 교체하지 않는다.

근접 3연계와 이동 거리 기반 보행 위상을 시연판에 적용했다. 비교 페이지 자체는 정자세 비교용이며 실제 동작은 위 게임과 동작 확인 파일에서 확인한다.

최신 체형 수정 지시: 전신을 다시 설계하거나 다리를 크게 줄이지 않는다. 직전 미형 시안을 기준으로 다리 길이만 약 3~5% 미세 조정하고, 얼굴·어깨·몸통·골반은 유지한다. 이 수치는 해당 시안의 수정량이며 모든 캐릭터의 공통 신체 규격이 아니다.

## 고정 기준과 제작 중단선

이후 작업은 [쟈알디 제작 고정 기준](../../docs/쟈알디_제작_고정기준.md)과 `jyaldi-standard.json`을 따른다. 불일치하는 다중 동작 생성 결과는 채택하지 않는다. 걷기를 실제 화면에서 먼저 검토한 뒤 전용 동작을 연결했다. 이전의 불일치 시트는 새 동작으로 대체했다. 이 검토 기록은 사용자의 최종 승인을 대신하지 않는다.

## 일반 체형 샘플 v0.3

`normal-v3/sample-source.png`의 인체·손 크기 수정은 이미지 제작에서 수행했다. `python3 tools/action_sample.py`는 이 원본을 전체 동일 배율로 패킹해 `release/demo/samples/`의 128px 원본·256px 표시·비교 HTML을 만든다. 신규 계획은 75동작/601장 예산, 필수 45동작/326장이다. 단일 샘플은 기존 플레이판의 체형·애니메이션을 교체하지 않는다.
