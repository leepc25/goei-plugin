# 블라렛·살라딘 기존 원본 검수

판정은 총괄의 원본 시각 검수이며 사용자 시각 승인이 아니다. 0부터 시작하는 파일 번호를 사용한다. 증거는 `evidence/*.png`, 입력 해시는 `review-inputs.json`. 원본 39장 전체를 연락표로 확대 열람했다. 재생/PC·모바일 조작 검사는 이번에 하지 않았다. 접지 판정은 정지 프레임 기준이다.

|---|---|---|
| 블라렛 guns_idle | 00~03 얼굴·베일·옆트임·발 위치가 대체로 유지되지만 두 손이 가슴 앞에 모인다. 쌍권총 준비 동작의 분리된 두 손 파지가 보이지 않음. 03→00에서 큰 몸 위치 변화는 안 보임 | 불합격 유지. 단순히 총을 다시 그려 넣지 말고 최신 빈손/소품 분리 규칙에 맞춰 양손 파지 뼈대와 hands를 함께 검수 |

살라딘 손가락 단위 파지와 hands 좌표의 실제 접촉 일치는 미검증이다. 정지 연락표에서 자연스러워 보인다는 이유로 전투·이동 양산 승인으로 바꾸지 않는다.

생성기 `scripts/gen.py`는 `run(..., maxpend=8)`, 예외 시 최대 60회 제출 재시도, 회수 시 기존 디렉터리 파일 삭제를 포함한다. 전용 담당이 수정해야 한다. 이번 총괄은 공유 폴더/빌더를 수정하지 않았다. 전송 결과 불명확 상태는 작업 목록 대조로 해결하고 새 호출을 자동 반복하지 않는다.
