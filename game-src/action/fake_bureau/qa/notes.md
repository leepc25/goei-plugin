# 검수 메모 (진행 중)
## 이도형
- cut4: 마지막 장 검은 실루엣 → 뺌(9장).
- dashcut: 피 그려짐 → 빨강 지우기 추가로 해결.
- jump: 첫·끝 장은 칼집에 꽂힌 상태, 공중 장은 칼을 뽑아 든 상태(순간 발도·납도로 읽힘).
- bulletcut 2, aircut 2: 칼날이 흐릿한 잔상처럼 그려짐(작음).
- hamster: 재킷 안감의 꾸러미가 잘 안 보임.
- smoke 6–7: 머리 옆 연기 몇 점.
- grab, grabslam: 생성기가 잡힌 상대·사람 몸을 그려 넣음(프롬프트에 '멱살·적'을 적은 탓). 코드로 지우면 칼집까지 잘려서 → 몸 동작만 적은 문장으로 다시 생성(6회, @v2).
- super_ready: 마지막 장 검은 실루엣 → 뺌.
- down 4–6: 누운 몸 위로 칼집·칼이 X자로 솟음(작음).
- 남은 큐 27개 문장에서 사물·장면 낱말(벽·바닥·무전기·총알·불 등) 빼고 몸 동작만으로 고침(생성 전).
