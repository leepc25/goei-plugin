# 로제몬 장 단위 검수 기록
- downbeat 00: 머리 위로 든 두 주먹이 갈색 덩어리로 뭉개짐 (손 모양 흐림)
- thread 05: 앞손 끝에 회색 점 몇 개
- aircue: 전 장 발 아래끝 131 (공중 장이라 정상)
- drink 01~05: 생성기가 갈색 병을 손에 같이 그림(물건 분리 규칙 위반). 시연판은 엔진 컵을 겹치지 않게 뺌
- down 07: 끝 장이 선 자세로 되돌아감 + 회색 얼룩 → 뺌(코드)
- down 03~06: 뒤로 넘어진 머리카락 끝이 그림 왼쪽 끝(x=0)에서 잘림
- getup 00·01: 머리에 회색 노이즈 → down 06(누운 장)으로 바꿈(코드)
- wfire 01~04: 총구 앞에 떨어진 회색 연기 덩이 → 지움(코드). 설계는 「고개 돌린 채 쏨」인데 그림은 과녁을 똑바로 봄
- wswing: 쇠파이프 대신 손에 작은 검은 고리 모양이 그려짐(파이프는 엔진이 손 좌표에 그림)
- turn: 3장 모두 거의 같은 옆모습(돌아서는 중간 자세가 없음). 엔진은 좌우 뒤집기로 대신함
- kid_ankle 04: 머리 술 주변 흩어진 점 → 지움(코드)
- man_limp·man_rise 00~01·man_break 04~05: 누운 몸이 바닥선 아래(캔버스 끝 144)까지 내려감 → 바닥선으로 올림(코드). 바닥에 닿는 쪽 몇 px는 캔버스 밖이라 잘려 있음
- man_sweep 02: 발끝 앞에 떨어진 점 → 지움(코드)
- man_throw 03~04: 뒤로 젖힌 머리가 그림 왼쪽 끝에서 잘림
