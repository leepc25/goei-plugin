## 매칭 (`match_icon.mjs`, 표시 전용 — 모델에 목록을 넘기지 않음)
1. 고유 키워드(몸통 말이 아닌 것)가 이름에 들어 있으면 가장 긴 것 — 「착한 친구」 → 착한 친구 키링
2. 몸통 말이 맞고 특징 말이 하나 이상 맞으면 점수 높은 것(같으면 모델이 준 종류가 같은 쪽, 그다음 대표) — 「피 묻은 곰인형」 → 피 묻은 인형
3. 몸통 말만 맞으면 그 몸통의 대표 — 「속삭이는 거울」 → 거울
4. 아무것도 안 맞으면 종류 기본 그림

알려진 한계: 조사가 끼어 특징 말이 끊기면(「목이 없는 인형」) ②를 못 잡고 ③으로 감.
고유 키워드가 두 그림에 걸린 것은 0건(11-07 점검).
