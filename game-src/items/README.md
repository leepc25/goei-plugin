| 칸 | 뜻 |
|---|---|

| kind | 큰 종류 16개: food·tool·misc·anomaly·wear·device·weapon·medical·paper·consumable·charm·adult·body·seal·key·valuable |
| file | 쓸 그림. merged_into 줄은 묶인 대표 그림 |

| merged_into / own_file | 같은 물건으로 묶음 / 원래 뽑은 그림(지우지 않음) |

## 매칭 (`match_icon.mjs` = 플러그인 `src/core/datapack.ts` matchItemIcon, 표시 전용 — 모델에 목록을 넘기지 않음)
11-07 고침. 옛 「키워드 포함 → 특징 → 몸통 대표」는 짧은 낱말이 긴 이름 안에 끼어 먼저 잡혀서(확성기 → 「성기」, 봉지라면 → 「지라」, 손목시계 → 손목) 버림.
1. **그림 찾기 낱말**: 물건을 만드는 모델(상점·갱신기·시작 소지품)이 쓴 영어 낱말(`icon`)이 있으면 그것으로 먼저 고른다. 이름은 비슷한 점수를 가르는 데만.
2. **이름 글자 조각 점수**: 낱말이 없거나 안 맞으면 이름으로. 한글은 띄어쓰기를 지운 뒤 한 글자·두 글자 조각, 영어는 낱말. 조각마다 표에 드문 것일수록 무게가 큼. 점수는 줄의 키워드·몸통 말 중 가장 잘 맞는 것. 한국어는 몸통이 끝에 오므로 끝 말이 같으면 덤, 마지막 글자가 줄에 없으면 깎음. 앞 꾸밈말(받침 ㄴ으로 끝나는 말: 속삭이는, 피 묻은, 녹슨)은 무게 반.
3. 이름·낱말이 몸통 말 그 자체면 `head_rep` 대표(방패 → 진압 방패, 거울 → 거울).
   - 11-08: 꾸밈말이 하나도 안 맞으면 공통 그림 대신 그 몸통 말의 `head_rep` 대표(생체 신호 은폐 패치 → 파스, 방수 전술 랜턴 → 전기 랜턴).
   - 11-08: 키트·세트·장치·도구·기계·상자·용품처럼 물건이 무엇인지 말하지 않는 몸통 말은 대표를 쓰지 않는다. 표의 말과 똑같을 때(구급 상자)만 그대로, 아니면 떼고 앞말로(향초 세트 → 향초). 장치·기계·도구는 「~기」로도(경보 장치 → 경보기). 그래도 없으면 공통 그림(침술 키트·낚시 도구 세트).
4. **공통 그림**: 가장 높은 점수가 낮으면(흔한 조각 「키트·상자」만 맞음, 아무것도 안 맞음) 공통 그림(misc 기본 그림 = 비닐봉지).

동의어(가스마스크 = 방독면, 간호복 = 간호사복 등)는 조각으로는 못 잡으니 표의 `keywords`에 다른 이름으로 넣는다. 2026-11-09 재설계: 모델이 그림 칸에 「종류/물건말」(옷/코트)을 쓰면 그 종류(kind) 안에서 먼저 찾고 → 종류 안에서 글자가 가장 가까운 그림 → 종류 대표(base) 그림. 상자는 종류를 모를 때만. 설정 「그림 대체 말」(외투 → 코트)로 몸통 말을 바꿔 찾고, 못 찾은 말은 설정에 기록된다.
시험: `tests/itemicons.test.mjs` (두 구현이 같은 답인지도 맞대 봄).
