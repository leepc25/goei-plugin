## 4. 돌리는 법

준비: 점검할 판을 받아 `npm run build`, 시험 카드 `npm run test:browser -- --only install --no-build`(`.scratch/fixture/`).

- **판이 바뀌면 바뀐 곳·연계된 곳만** (사용자 11-09 크게 화냄: 「쪼금 수정했는데 매번 여섯 시간씩 돌릴래?」). 지난 기록이 있으면
  `node scripts/click-audit.mjs --resume <지난 기록 폴더들,쉼표> --plan` 으로 다시 누를 수를 보고, `--plan` 빼고 돌린다. **전체 다시 돌리기는 하지 않는다.** 지난 기록이 없으면(새 컨테이너) 바뀐 화면만 아래 「한 화면만」으로 잰다.
- **빨리**: 시작 상태별로 넷을 nohup으로 동시에(`--vp pc --start board` / `--vp pc --start picker,items,shop,gnet` / 폰 둘, 각 `--workers 2`, `--out` 다르게). 하네스 백그라운드는 2시간에 끊긴다.
- **한 화면만 높이·모양 재기**: `--vp pc --start board --from '<길>' --max-clicks 1 --workers 1 --out .scratch/x` → `report.json` 의 `states[0].audit.styles`(단추마다 높이·색·테두리), `audit.off`(넘침), `audit.cut`(잘린 글).
  - 17번 다시 잴 길: PC `nav-tab|net>br-go|gn>gn-write|`, 폰 `cdr|>br-site|gn>gn-write|`, 폰 `tab|records>rec-sub|factions>rec-faction|A00`. `button.ph-tool` 높이가 36이면 고쳐진 것.
- **정해진 순서로 재기**: `--from <화면> --probe scripts/click-audit-probes/<파일>.mjs` → `<out>/probe-<vp>.json`. 예) 지도 `--from 'nav-tab|map'`(폰 `tab|map`) + map-declutter.
- `--from` 의 길은 `동작|값` 을 `>` 로 잇는다. 길은 지난 report.json 의 `results[].path` 에서 따온다.

도구 쪽이라 앱 문제 아닌 것(보고 안 함): 사건·괴담톡 방 번호가 든 「재현 실패·못 찾음」(판마다 번호가 바뀜), `ed-rule-*` 못 찾음, 폰 설정 서랍 열린 채 뒤 단추 「가려짐」, 빈 칸일 때 꺼진 단추, 출발·탭 이동으로 창이 닫히는 것.
