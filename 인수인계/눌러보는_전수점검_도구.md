# 인수인계: 눌러 보는 전수점검 도구 (2026-11-09 KST)

스레드 「눌러 보는 전수점검 도구 만들기」. 저장소 `leepc25/goei-plugin`, 브랜치 **`claude/project-thread-5aw6ui`** (마지막 커밋 974aedca52). 사용 설명서는 저장소 [docs/눌러보기_전수점검.md](docs/눌러보기_전수점검.md).

## 1. 이 도구가 하는 일

- 「전수점검」을 받으면 코드를 읽지 않고, 브라우저로 **PC·폰 화면의 단추를 하나도 빼지 않고 실제로 누른다**(11-08 사용자 지시: 코드 읽기 점검은 「효과 코드 있음 → 됐다」로 넘어가 못 잡음).
- 누를 때마다 앞·직후·뒤·끝 캡처 4장과 반응(창 닫힘, 효과 틈 없이 사라짐, 가려짐, 넘침, 같은 종류인데 모양이 다름 등)을 적는다.
- 판단은 도구가 아니라 **점검하는 Claude가 캡처를 직접 열어** 사용자 결정(메모리·CLAUDE.md)과 맞춰 본다. 결정과 어긋난 것, 통일성 없는 것부터 이상한 것 전부 보고.
- 도구는 사용자가 아니라 Claude가 쓴다.

## 2. 파일

| 파일 | 내용 |
|---|---|
| `scripts/click-audit.mjs` | 본체. 가짜 Risu(`tests/qc-settings-harness.mjs`) 위에서 Playwright로 누름 |
| `scripts/click-audit-probes/*.mjs` | `--probe`용 정해진 순서 재기: `map-declutter`(지도 이름표 겹침·숨은 점 누르기), `flow-recount`(호출 흐름 토큰 다시 세기), `sel-cards`(고른 카드 테두리) |
| `docs/눌러보기_전수점검.md` | 돌리는 순서·보고서 읽는 법·이어 돌리기 |
| `package.json` | `npm run audit:click` |

## 3. 돌리는 법

준비: 점검할 판을 받아 `npm run build`. 시험 카드는 `.scratch/fixture/fixture.json`(없으면 `npm run test:browser -- --only install`).

- **처음 판 전체**: `npm run audit:click` (기본 PC·폰, 시작 상태 board·picker·items·shop·gnet). 길다(2시간+). **사용자가 「매번 여섯 시간 돌릴래?」로 크게 화냄 → 전체 다시 돌리기는 하지 않는다.**
- **판이 바뀌면 바뀐 곳·연계된 곳만** (11-09 사용자 지시):
  `node scripts/click-audit.mjs --resume <지난 기록 폴더들(쉼표)> --plan` 로 다시 누를 동작·모양 수를 먼저 보고, `--plan` 빼고 돌린다. 지난 판 → 지금 판 git diff에서 바뀐 단추(data-action·case)·CSS class·바뀐 함수를 쓰는 곳의 단추만 다시 누른다.
- **같은 판에서 이어서**: `--resume <폴더>` (지난번 누른 건 건너뜀).
- **빠르게: 시작 상태별로 따로 띄워 동시에** 돌린다. 예) `--vp pc --start board`, `--vp pc --start picker,items,shop,gnet`, `--vp phone --start board`, `--vp phone --start picker,items,shop,gnet` 넷을 nohup으로 동시에, 각 `--workers 2`, `--out` 다르게. (4코어)
- **한 화면만**: `--from 'a|v>b|v' --only-scope '<css>'`. 그 화면 높이·모양만 볼 땐 `--max-clicks 1 --workers 1` (화면0 기록에 모든 단추의 높이·색이 들어감).
- **정해진 순서로 재기**: `--from <화면> --probe scripts/click-audit-probes/<파일>.mjs` → `<out>/probe-<vp>.json`.
- 보고서만 다시: `--report-only --out <폴더>`.
- 긴 일은 백그라운드로. 하네스 백그라운드는 2시간에 끊기므로 nohup으로 띄우고 기다리는 줄만 백그라운드로.

## 4. 보고서 읽기

`<out>/report.md`: 1절 이상 반응(캡처 확인할 곳), 2절 선택 표시 모양, 3절 통일성(같은 종류 다른 모양), 못 누른 data-action 목록. `report.json`에 누른 것(results)·화면(states, audit.styles 에 단추별 높이·색·테두리, audit.off 넘침, audit.cut 잘린 글).

**도구 쪽이라 앱 문제 아닌 것** (보고하지 않음):
- 「재현 실패·못 찾음」 중 사건·괴담톡 방 번호가 든 것(판마다 번호가 바뀜), ed-rule-*(규칙 id 무작위).
- 폰 설정 서랍 열린 채 뒤 화면 단추 「가려짐」.
- 꺼진 단추(빈 칸일 때 로그인 저장, 저장된 기본값 없을 때 불러오기·초기화 등).
- 출발·창 닫기·탭 이동으로 창이 닫히는 것(의도).
