# Wiki images

공유 폴더에서 제공된 위키 이미지의 AVIF 사본입니다. 원본 파일은 변경하지 않았습니다.

- `Anomalies/`: 괴이 70장
- `Mystic Sites/`: 미스틱 사이트 10장
- `Factions/`: 세력 15장
- 전체 95장, 832 × 832 픽셀. AVIF quality 90, 4:4:4 (손실 압축).

괴이와 미스틱 사이트의 파일명은 배포 카드의 `Directory.english` 값을 그대로 사용합니다. 세력 폴더명은 배포 카드의 명시적 영문명이 있으면 우선하고, 없으면 `src/core/world/directory.ts`의 `ORG_ENGLISH` 기본값을 따릅니다. 원본 카드와 최신 코드에서 철자가 다른 경우도 이 규칙을 따릅니다.

세력 내부 장면의 영문 제목은 공식 표기가 없어 설명식으로 번역했습니다. `manifest.json`에서 공식 개체명과 번역한 장면명을 구분하고 한글 원본 파일명과 연결합니다. 원래 숫자·알파벳 순번과 `_832`는 제거했습니다. 여러 세력 장면 중 대표 이미지는 임의로 지정하지 않았습니다. 원래 세력명만 있는 파일은 `_default`를 사용합니다.

원본 안내문은 요청 범위에 137장(70 + 10 + 57)이 있다고 적고 있으나, 실제 제공된 범위에는 95장(70 + 10 + 15)만 있습니다. 일부 현재 파일은 안내문과 이름도 다릅니다. 원본 안내문에는 있지만 공유 폴더에는 없는 정확한 파일명은 `manifest.json`의 `missingFromSourceReadme`에 기록했습니다. 요청하지 않은 `04_이전시안`은 가져오지 않았습니다.

이 변경은 저장소에 이미지 파일만 추가합니다. 실행 중인 봇 카드에 이미지가 자동으로 삽입되지는 않습니다. 카드 이미지 에셋으로 등록할 때에는 manifest의 영문 이름과 기존 플러그인의 에셋 검색 규칙을 참고하세요.
