## 만든 방법

공통: `stitch_bg.py`가 이음매 양쪽 색을 행별로 맞추고(±8% 한도) 겹친 구간을 섞는다. `remap_rows.py`는 벽선·바닥선 높이를 맞춘다.

```
# 앞골목: 2를 0~1968, 3을 82~2000으로 잘라 기둥이 겹치지 않게
python3 tools/stitch/stitch_bg.py 앞골목.png 40,6 원본/앞골목1.webp p2.png p3.png

# 뒷골목: 1은 크게 그려져 0.89배 + 벽선 530→483, 3은 벽선 497→483
python3 tools/stitch/remap_rows.py 원본/뒷골목1.webp p1.png 0.8915 97:97 530:483
python3 tools/stitch/remap_rows.py 원본/뒷골목3.webp p3.png 1 97:97 497:483
python3 tools/stitch/stitch_bg.py 뒷골목.png 60 p1.png 원본/뒷골목2.webp p3.png

# 지하2층: 1을 0~1935, 2를 0~1925로 잘라 배관이 겹치지 않게, 2의 벽선 490→512
python3 tools/stitch/remap_rows.py 2잘림.png p2.png 1 90:90 490:512
python3 tools/stitch/stitch_bg.py 지하2층.png 30 1잘림.png p2.png 원본/지하2층3.webp

# 지상거리: 정류장이 왼쪽 끝, 지하상가 입구가 오른쪽 끝. 건물 사이 골목에서 잇는다.
# 3은 높이선(건물 밑 430, 노란 선 515, 연석 550, 차선 590)을 1·2에 맞춤. 뒤 그림 왼쪽 150px는 잘라 골목 폭을 줄임
python3 tools/stitch/remap_rows.py 3(668줄로 자름).png p3.png 1 160:160 430:437 515:530 550:563 590:600
python3 tools/stitch/street_merge.py ab.png 원본/지상거리1.webp 원본/지상거리2.webp 140 150 25 110 150,0,265,445
python3 tools/stitch/street_merge.py 지상거리.png ab.png p3.png 140 150 25 110 150,0,265,445

# 지상거리_낡음: 높이선이 세 장 모두 같아 자르기만 함. 건물 사이 어두운 틈에서 잇고, 화분이 두 번 나오지 않게 2·3은 95부터 자름
python3 tools/stitch/stitch_bg.py 지상거리_낡음.png 15 1.png 2(95~).png 3(95~).png
```

뒷골목·지하2층은 색 보정 한도(±8%)를 넣기 전에 만들었다.
