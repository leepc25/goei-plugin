# 중림 지하상가 배경 (2026-10-26)

> **⚠ Claude 반성 · 2026-10-31 (사용자 지시로 문서마다 남김)**
> 2026-10-31 Claude는 다음 잘못을 저질렀다. 이 문서를 읽는 모든 Claude는 같은 짓을 하지 않는다.
> 1. **사용자 결정을 무시했다.** 콘쥬스는 사용자가 10-26에 20세로 정했고 인계서에도 적혀 있었는데, 옛 Claude 문장(teenage high school girl)을 근거로 화장실·샤워 그림을 거부하고, 사용자가 직접 뽑은 화장실 줄까지 팩에서 뺐다. 옷도 제복인데 교복이라고 단정했다.
> 2. **사용자 말에 토를 달고 같은 주장을 되풀이했다.** 사용자가 여러 번 지적했는데도 근거를 다시 확인하지 않아 몇 시간을 허비하게 했다.
> 3. **허락 없이 문서를 지웠다.** 「지침을 지우라」는 말만 듣고 목록을 보여 주지도 않고 96개를 지웠다가 되살렸다(결과물 삭제 금지 규칙 위반).
> 4. **문장을 덧대기만 하며 PixelLab을 낭비했다.** 이성해 점프 공격 5번 연속 실패, 이어폰 음악 120줄을 못 쓰게 만듦.
> 5. **답을 미루고 일을 멈춰 두었다.** 백그라운드로 돌릴 일을 돌리지 않고 대화만 했다.
>
> 지킬 것: 사용자 결정·위키가 근거다. 옛 Claude 자료는 근거가 아니다. 사용자 말에 토 달지 않는다. 무엇이든 지우기 전에 목록을 보여 주고 허락받는다. 실패하면 덧대지 말고 다시 쓰거나 바꾼다.

## 만든 방법

주의: 채팅에 올린 그림은 가로 2000으로 줄어서 들어온다. 원본 크기가 필요하면 GitHub로 올린다.

공통: `stitch_bg.py`가 이음매 양쪽 색을 행별로 맞추고(±8% 한도) 겹친 구간을 섞는다. `remap_rows.py`는 벽선·바닥선 높이를 맞춘다.

```
# 앞골목: 2를 0~1968, 3을 82~2000으로 잘라 기둥이 겹치지 않게
python3 tools/stitch/stitch_bg.py 앞골목.png 40,6 원본/앞골목1.webp p2.png p3.png

# 뒷골목: 1은 크게 그려져 0.89배 + 벽선 530→483, 3은 벽선 497→483
python3 tools/stitch/remap_rows.py 원본/뒷골목1.webp p1.png 0.8915 97:97 530:483
python3 tools/stitch/remap_rows.py 원본/뒷골목3.webp p3.png 1 97:97 497:483
python3 tools/stitch/stitch_bg.py 뒷골목.png 60 p1.png 원본/뒷골목2.webp p3.png

# 지하2층: 1을 0~1935, 2를 0~1925로 잘라 배관이 겹치지 않게, 2의 벽선 490→512
python3 tools/stitch/remap_rows.py 2잘림.png p2.png 1 90:90 490:512
python3 tools/stitch/stitch_bg.py 지하2층.png 30 1잘림.png p2.png 원본/지하2층3.webp

# 지상거리_낡음: 원본 PNG(약 2172×724, GitHub로 받음). 높이선이 세 장 모두 같아 자르기만 함(세로 724).
# 건물 사이 어두운 틈에서 잇고, 화분이 두 번 나오지 않게 2·3은 103부터 자름
# 1은 건물이 2·3보다 위에 그려져 있어(간판 위 20→25, 건물 밑 462→485) 맞추고, 연석(600) 아래는 그대로
python3 tools/stitch/remap_rows.py 원본/지상거리낡음1.png p1.png 1 20:25 462:485 600:600
python3 tools/stitch/stitch_bg.py 지상거리_낡음.png 16 p1.png 2(103~).png 3(103~).png
```

뒷골목·지하2층은 색 보정 한도(±8%)를 넣기 전에 만들었다.
