# 인수인계서 · 괴이: 이면세계 (Claude → GPT, 2026-10-22)

이 문서 한 장으로 이 저장소의 모든 작업을 넘겨받을 수 있게 썼습니다. 읽는 사람은 GPT(Codex)입니다. 사용자(YoungZ)는 한국어만 읽습니다. 사용자에게 하는 보고와 화면 글씨는 모두 한국어로 씁니다.

- 저장소: `leepc25/goei-plugin` (공개). 기본 브랜치는 `main`입니다.
- 이 문서를 쓴 시점의 main은 문서 맨 끝 「기록」에 적었습니다.
- 사용자가 저장소를 나중에 닫을 수 있습니다. 그래서 어떤 기능도 이 저장소에서 내용을 받아 오는 데 영구히 의존하면 안 됩니다.

## 1. 이 프로젝트는 무엇인가

두 가지가 한 저장소에 있습니다.

1. **RisuAI 플러그인 「괴이: 이면세계」**
   - 원래 괴이봇(Anomaly Sim 2.4)은 Lua가 무거워 렉이 났습니다. 그 Lua 기능을 진짜 플러그인(TS + esbuild)으로 옮긴 것입니다.
   - 원본 카드: `card/원본_봇카드.jpeg`. 이 파일은 그림 뒤에 charx가 붙은 형태입니다.
   - Lite 카드는 `tools/build_lite_card.py`가 만듭니다.
   - 플러그인은 작은 시작기 `goei-plugin.js`(src/main.ts)와 본체 `goei-body.js`(src/body.ts)로 나뉩니다.
   - 플러그인은 `//@update-url`로 자기 갱신합니다. 카드는 창 설정 → 업데이트로 갱신합니다.
   - 마지막 릴리스는 v0.16.38(2026-10-21)이고, 게임 단추는 숨긴 상태입니다.
2. **괴이 액션 게임** (플러그인 창 안에서 도는 1인 벨트스크롤 로그라이트)
   - 통합판은 `release/demo/goei-action-game.html` 하나뿐입니다.
   - 사용자가 완성이라고 말하기 전에는 게임을 릴리스하지 않습니다. 플러그인 릴리스에서도 게임 단추는 개발용 깃발로 숨겨 둡니다.

지금 사용자의 관심은 거의 전부 게임에 있습니다.

## 2. 사용자가 확정한 결정 (어기면 안 되는 것)

### 일하는 방식
- **보고는 한국어로, 짧게, 결과부터** 씁니다. 사용자는 한국어만 읽습니다.
- **시연판을 먼저 내놓습니다.** 새 빌드가 나오면 바로 폰에서 열 수 있는 링크를 「검수 전」이라고 표시해 줍니다.
  - 형식: `https://rawcdn.githack.com/leepc25/goei-plugin/<40자 커밋 해시>/release/demo/<파일>.html`
  - 검수는 그 뒤에 따로 돌립니다.
- **결함은 직접 찾습니다.** 사용자가 결함을 하나씩 찾게 두지 않습니다. 보여 주기 전에 화면마다(PC와 폰 가로 844×390) 직접 검수합니다.
- **범위를 늘릴 때는 비용부터 말합니다.** 몇 장, 몇 회인지 밝히고 승인을 받은 뒤 만듭니다. 기준이 정해진 뒤의 양산은 중간 확인 없이 한 번에 끝냅니다.
- **추측한 수치를 사실처럼 말하지 않습니다.** 먼저 잽니다.
- **원작 설정(카드 로어)부터 읽습니다.** 특히 `card/wiki-base.json`의 「차원 승강기」입니다. 기획서를 글자 그대로만 읽어 설계하다 크게 틀린 적이 있습니다.

### 게임 설계
- **최우선은 액션성(손맛)입니다.** 타격 반응, 예비 동작과 마무리의 과장, 연타 리듬, 조작 반응을 가장 먼저 봅니다. 미스타라·던파처럼 동작을 크고 확실하게 만듭니다.
- **장르 관례를 기본값으로 둡니다.** 근접은 주먹, 공중 공격은 점프 킥입니다.
- 모든 자세는 실제 무술 근거를 따릅니다. 근거 문서: `docs/캐릭터제작서/동작근거_쟈알디_무술.md`.
- **차원 승강기 = 주머니 차원입니다.**
  - 층마다 다른 세상이고 규칙도 다릅니다. 건물의 한 층이 아닙니다.
  - 모든 승강기는 하나의 의식입니다.
  - 정비 구역은 세상과 세상 사이의 틈입니다.
- **구조는 메트로배니아에 로그라이크를 더한 것입니다** (사용자 2026-10-22 04:32 확정).
  - 층은 방들이 위·아래·좌·우로 이어진 미로입니다. 갈림길, 막다른 길, 고리가 있습니다.
  - 출동마다 시드로 새로 생성합니다.
  - 깊이가 곧 난이도입니다. 층마다 환경 괴이를 깊이별 풀에서 뽑습니다.
  - 다음 층은 그 층을 다 정리해야 열립니다(수호자와 모든 싸움 방).
  - 방 안 싸움은 벨트스크롤입니다.
  - 방 그림은 방마다 한 장이 아니라 타일로 그립니다(`docs/GPT요청_방타일.md`).
- **조작** (기본기획서 부록 A, 쟈알디 단독 시연판 기준):

  | 키 | 동작 |
  | --- | --- |
  | 방향키 | 이동 |
  | Shift 길게 | 달리기 |
  | Shift 짧게 | 회피 |
  | Space | 점프 |
  | A | 연타(최대 3타), 달리며 A 돌진, 공중 A 점프 킥 |
  | S | 권총: 첫 S는 뽑기, 다음 S부터 사격. 움직이면 집어넣음 |
  | R | 장전 |
  | D | 짧게 폭파, 길게 누르면 충전 뒤 큰 폭파. 앉아서 D는 지면 폭파 |
  | Q (누르고 있기) | 가드 |
  | W | 필살 |
  | E | 조사·줍기, 앞의 적 잡기 |
  | ↓↓ | 앉기(유지). ↑로 일어섬 |
  | F | 숙련 3 연쇄 폭파 |
  | G | 숙련 6 벽 통째로 |
  | C | 지원 호출 |
  | 1~4 | 아이템 |
  | Z / Tab / M | 지도 |
  | X | 자동 전환 |
  | Esc | 메뉴 |

  - 잡기는 비틀거리는 적에게 걸어 붙어도 됩니다.
  - 잡은 채로 A는 무릎, 방향+A는 잡기 폭파, Space는 놓기입니다.
- **화면 규칙**
  - UI는 한국어만 씁니다.
  - 벽 위 메타 글씨와 떠 있는 라벨은 금지합니다. 방 이름은 들어갈 때 잠깐 뜨는 제목만 허용합니다.
  - 왼쪽 테두리 줄무늬는 금지합니다.
  - 확대는 Ctrl+휠로만 합니다.
  - 모바일 조작부는 아래쪽에 둡니다.
  - 테마는 적당히 어둡게 합니다.
  - 플러그인은 다른 봇에서는 조용해야 합니다.
- **검수에서 떨어지는 것**
  - 색만 바꾼 복제 적·NPC
  - 회색 상자, 코드로 그린 납작한 그림
  - 시스템 글꼴이나 웹 UI 느낌
  - 떠 있는 메타 글씨
  - 한 글자만 다음 줄로 넘어가는 줄바꿈
  - 같은 모양의 층
  - 문·승강기를 가리는 말풍선·숫자·판
  - 칸막이 사무실처럼 보이는 방, 빈 화면
- **본부(HQ)**
  - 옆에서 보는 벨트스크롤 건물입니다(진짜 기관 건물).
  - 모든 동작이 옆모습이므로 집기도 옆면을 씁니다. 북쪽 벽에 일렬로 붙이지 않고 깊이를 씁니다.
  - 3판 설계 요청서: `docs/GPT요청_본부3판.md`. 평면도: `docs/본부_평면도.md`.

### 그림
- **캐릭터 그림에는 캐릭터만 그립니다.**
  - 가구·벽·문·사다리·든 물건·무기·불꽃·연기는 그리지 않습니다. 손은 빈 채로 쥔 모양만 그립니다.
  - 대신 장마다 손 좌표를 남깁니다. 형식은 `final/hands.json`의 `{클립: [[x, y, 각도]]}`입니다.
  - 물건은 엔진이 따로 그립니다.
- **쟈알디 그림체가 기준입니다.** 몸을 베끼지는 않습니다.
- **미성년자(콘쥬스)의 씻기·탈의 장면은 절대 만들지 않습니다.** 수건을 두른 그림도 안 됩니다.
- 게임 배경은 GPT가 평면 채색으로 그리고 코드로 도트화합니다(`tools/bg_pixelize.py`).
- 컷신은 GPT가 그린 도트 프레임 애니메이션입니다. 640×360 PNG 프레임과 `timing.json`이고, mp4는 금지입니다.
- 이름은 공식 「괴이 ː 이면세계」입니다. 사용자는 이 이름을 좋아하지 않습니다. 대안으로 리미널 오피스·위어드 시프트·미드나잇 뷰로를 제시했고, 급하지 않습니다.

## 4. 빌드와 시험

```bash
npm ci
npm run build                 # dist/ + release/demo/*.html (goei-action-game.html 포함). 이 html은 손으로 고치지 않는다
npm test                      # 단위 시험 (지금 288개 통과)
node tests/game-loop.mjs      # 본부 → 출동 → 층 여러 개 → 철수 → 정산 한 바퀴
node tests/engine-browser.mjs # 조작 실입력 (S 뽑기 → S 사격, 총알 높이 검사 포함)
node tests/hq-browser.mjs
node tests/ui-browser.mjs
node tests/npc-browser.mjs
FAST=1 SEEDS=8 FLOORS=6 node tests/game-overlap.mjs   # 소품 겹침 0이어야 함
COMPACT=1 node tests/final-shots.mjs <폴더> 3          # 검수용 PC·폰 스크린샷 약 60장
python3 tools/build_engine_art.py                      # 쟈알디 그림 묶음 다시 만들기
python3 tools/bg_pixelize.py <장소>                    # GPT 배경 원본 → 도트
```

- **지금 깨진 시험(2026-10-22 05:40):** `tests/game-loop.mjs`(31줄)와 `tests/engine-browser.mjs`(94줄)는 본부 3판 이후 실패합니다.
  - 두 시험은 본부 시작 화면에서 `world.props`에 `spot:jaemtri`가 있다고 가정합니다.
  - 그런데 본부 3판(`dadfd6b`)은 가장 가까운 자리 하나만 props에 올리고, 시작 장면도 바뀌었습니다.
  - 고칠 방법: 시험이 잼트리 자리로 플레이어를 옮기게 합니다(`hq/rooms.ts` office `use` 좌표 x·y). 또는 본부 모듈에 시험용 `goto('jaemtri')`를 엽니다.
  - `npm test`, `hq-browser`, `ui-browser`, `npc-browser`, `game-overlap`은 통과합니다.
- 브라우저 시험은 Chromium을 씁니다. 이 환경에서는 `/opt/pw-browsers/chromium`이고 Playwright는 전역 설치입니다.
- **main에 올리기 전에 반드시 할 것**
  1. origin/main을 합칩니다.
  2. `npm run build`를 다시 돌립니다.
  3. 위 시험을 통과시킵니다.
  4. push합니다.
- 다른 작업이 main에 자주 올라오므로, push가 거절되면 fetch·merge 뒤 다시 push합니다.
- `release/demo/*.html` 충돌은 손으로 풀지 않습니다. 다시 빌드한 것을 씁니다.

### 플러그인 릴리스 순서 (사용자가 「릴리스」라고 할 때만)
1. `package.json` version을 올립니다.
2. `npm run build`를 돌립니다.
3. `python3 tools/build_lite_card.py card/원본_봇카드.jpeg release/괴이_이면세계.charx`로 카드를 만듭니다.
4. `dist/goei-plugin.js`, `dist/goei-body.json`, `dist/goei-body.*.txt`를 `release/`로 복사합니다.
5. `npm test`와 `tests/browser.mjs`를 통과시킵니다.
6. main에 push합니다.
   - `release/version.json`이 바뀌면 GitHub Actions가 zip·charx·플러그인을 붙인 릴리스를 만듭니다.
   - `release/pic/`도 같이 커밋합니다.
- 변경 사항은 묶어 두었다가, 사용자가 말할 때 한 번에 릴리스합니다.

### 인수인계 · 차원 승강기 메트로배니아·로그라이크 (2026-10-22)

#### 사용자가 확정한 구조
- 차원 승강기는 건물 엘리베이터가 아니라 주머니 차원이다. 층마다 다른 세상이고, 원전은 card/wiki-base.json 「차원 승강기」(수직형 미궁)이다.
- **층수 = 난이도.** 깊이에 끝이 없고, 내려갈수록 위협 예산·방 수·잠금 수가 늘어난다.
- **층의 괴이(환경) = 깊이별 풀에서 무작위로 뽑는다.** 로비는 L1~L3이고, 그 아래는 직전 3층과 겹치지 않게 뽑는다(pickType).
- **개미굴(방 격자)도 무작위다.** 방은 위·아래·좌·우로 이어지고 갈래, 막다른 방, 고리, 잠금과 열쇠, 숨은 방이 있다. 방 내부(조각·문·계단·적)도 생성한다.
- **층을 다 클리어해야 다음 층으로 내려간다.** 클리어 기준은 숨은 방을 뺀 모든 방에 들어가 그 방 싸움을 다 이기는 것이다. 클리어 전에는 승강기 패널과 정비 구역의 아래 점검문·틈새가 꺼져 있다.
- **로그라이크 판 구조:**
  - 출동 한 번이 한 판이고, 출동마다 시드가 새로 정해진다.
  - 죽으면 그 판에서 얻은 것을 모두 잃는다.
  - 판 안의 성장: 보상 배낭에서 강화를 3개 중 1개 고르고, 같은 계열 3개면 세트 보너스가 붙는다.
  - 출동마다 규칙 1~2줄이 뒤집힌다.
  - 위험과 보상: 다락방 로프로 귀환할지, 더 내려갈지 고른다.
  - 판이 끝나도 남는 것: 규칙서, 총애, 최고 깊이. 본부 강화와 시작 장비 해금은 **아직 없다**.
