# 능력치 방식 · 기술 피해 계산 안 (2026-10-30, 결정 전)

`설계_능력치_안.md`(1판)를 자세히 푼 것이다. 숫자는 모두 안이다. 기술마다 매긴 판정 형태·속성 표는 `docs/퍽/기술_속성표.md`(55명)에 따로 둔다.

## 1. 결론부터

| 질문 | 안 |
| --- | --- |
| 능력치는? | **힘·민·체·지·정 다섯 개(1~10)를 요원마다 고정**하고, 전투 수치는 공식으로 산출한다. 레벨업은 없다 |
| 조작 상태(유저가 그 요원으로 괴이에 들어감)는? | **다섯 칸 합계 25 고정.** 나누는 모양만 다르다 |
| NPC 상태(필드·적·동료)는? | 같은 다섯 칸 위에 **등급 배수**(체력·피해·방어막)를 얹는다 |
| 기술 피해를 키우는 능력치는? | 기술의 **판정 형태**로 정한다. 몸으로 때리면 힘, 총·투척은 민, 이능(초능력·괴이 힘)은 지 |
| 속성은? | **공격 단위로 붙인다.** 평타는 전원 물리이고, 기술은 하나하나 매긴다 |
| 퍽은? | 대부분 전투 수치를 바로 바꾼다. 드물게 기본 능력치 +1. 「힘 7 이상」 같은 출현 조건을 걸 수 있다 |

왜 산출 방식인가:
- 인물 개성이 숫자 다섯 개로 한눈에 보인다. 통합창 왼쪽 칸에 그대로 나온다.
- 퍽 출현 조건을 걸 수 있다(폴아웃 방식). 같은 공용 퍽 목록이어도 인물마다 나오는 퍽이 달라진다.
- 직접 항목 방식이면 인물끼리 비교하기 어렵고, 조건을 걸 곳이 없다.

## 3. 전투 수치 (통합창 왼쪽 칸에 전부 나옴)

| 전투 수치 | 공식 | 1일 때 | 5일 때 | 10일 때 | 퍽으로 바뀜 | 코드 자리 |
| --- | --- | --- | --- | --- | --- | --- |
| 최대 체력 | 500 + 체 × 100 | 600 | 1,000 | 1,500 | ○ | `progression` hp |
| 근접 공격 | 100 + (힘 − 5) × 8 | 68 | 100 | 140 | ○ | `power` |
| 사격 공격 | 100 + (민 − 5) × 8 | 68 | 100 | 140 | ○ | `aim` |
| 이능 공격 | 100 + (지 − 5) × 8 | 68 | 100 | 140 | ○ | 새 칸 |
| 치명 확률 | 0% (능력치와 무관) | | | | 퍽만 | 새로 |
| 치명 피해 | 200% (능력치와 무관) | | | | 퍽만 | 새로 |
| 받는 피해 | 100% − (체 − 5) × 2% − (정 − 5) × 2% | 116% | 100% | 80% | ○ | `defense` |
| 경직 저항 | 0 (능력치와 무관) | | | | 퍽만(3 = 넘어지지 않음) | `poise` |
| 이동 속도 | 100 + (민 − 5) × 3 | 88 | 100 | 115 | ○ | `speed` |
| 회피 | 2회 · 0.8초 (능력치와 무관) | | | | 퍽만 | `dodgeMax`·`dodgeCd` |
| 기술 쿨 | 100% − (지 − 5) × 4% | 116% | 100% | 80% | ○ | `setCd` |
| 필살 충전 | 100% + (정 − 5) × 6% | 76% | 100% | 130% | ○ | `charge`(`spMul`) |
| 상태 이상 지속 | 100% − (정 − 5) × 8% | 132% | 100% | 60% | ○ | `combat/status.ts` |
| 괴이 정신 피해 | 100% − (정 − 5) × 6% | 124% | 100% | 70% | ○ | 새로 |

- **10-30 사용자 결정: 폭을 키웠다**(처음 안은 3%·50씩이라 세 명이 거의 차이 없었음). 합계 25 고정이라 전체 세기는 같고 성격만 확실히 갈린다.
- 치명·경직·회피를 능력치에서 빼는 이유:
  - 치명은 확률이라 능력치에 붙이면 인물 간 차이가 너무 커진다.
  - 경직 저항 1·2는 엔진에서 차이가 거의 없다.
  - 회피는 막 정한 2회 충전 규칙을 흔들지 않기 위해서다.
- 1판과 바뀐 점: 지가 맡던 필살 충전을 정으로 옮겼다. 지가 이능 피해까지 맡으면 너무 많이 쥐기 때문이다.

## 4. 기술 피해 계산

### 4-1. 순서

```
최종 피해 = 기본 피해
          × 판정 형태 배율 (근접 공격 / 사격 공격 / 이능 공격 ÷ 100)
          × (1 + 퍽 보너스 합: 출처 + 속성 + 조건)          ← 더함
          × 치명 (치명이면 치명 피해 ÷ 100)
          × 상대 받는 피해
          × (1 − 상대 속성 저항)
```

- **기본 피해**: 테스트룸에서 실측해 맞춘 값을 그대로 쓴다.
  - 평타: 인물 팩 `bal.atk`(줄마다, 한 대 14~27)
  - 사격: `shotDmg`
  - 충전·고유기·필살: 기술 자료 안의 `hit.dmg`(충전 75/150/240, 고유기 270, 필살 380/480 언저리)
- **판정 형태**: 기술마다 하나를 정한다(`기술_속성표.md`).

  | 형태 | 무엇 | 배율 |
  | --- | --- | --- |
  | 몸 | 맨손·근접 무기로 직접 때림. 평타·강공·슬라이딩·점프 공격, 몸으로 하는 기술 | 근접 공격(힘) |
  | 총·투척 | 탄환·던진 물건 | 사격 공격(민) |
  | 이능 | 초능력·괴이 힘·이펙트로 나가는 공격(폭발·염동·정신 등) | 이능 공격(지) |

- **퍽 보너스**: 모두 한 합에 **더한다**. 예를 들어 「충전 피해 +12%」, 「폭발 피해 +10%」, 「등 뒤 +15%」가 있으면 +37%다. 곱하면 폭주한다(하데스가 초기에 겪고 고친 문제).
- **곱하는 것**: 치명, 상대 받는 피해, 속성 저항 셋뿐이다.

### 4-2. 속성

| 속성 | 예 | 쓰는 곳 |
| --- | --- | --- |
| 물리 | 모든 평타, 총탄, 칼 | 기본 |
| 폭발 | 쟈알디 근접 폭파, 수류탄 | 괴이·적 속성 저항/약점, 속성 퍽 |
| 화염 | 화염 기술 | 상태 이상 연결(화상) |
| 전기 | 감전 기술 | 〃 |
| 냉기 | 얼음 기술 | 둔화 연결 |
| 염동 | 좌표 압살·끌어당김 | |
| 정신 | 공포·환각·속삭임 | 괴이 정신 피해와 짝 |
| 오염 | 괴이 오염 | 오염 상태와 짝 |
| 시간 | 데드폴 되감기·정지 | |
| 빛 | 신성·섬광 | 괴이 특효 후보 |

- 평타는 전원 물리다. 인물이 폭발 계열이어도 평타는 물리다(10-29 사용자 결정).
- 속성은 지금 엔진에 없다. 타격마다 `src` 대신 {출처, 형태, 속성} 꼬리표를 붙여 넘긴다(4-4).

### 4-3. 계산 예

| 상황 | 계산 | 결과 |
| --- | --- | --- |
| 에일린 사격 한 발, 퍽 없음 | 7 × 1.24 | 8.7 → 9 |
| 에일린 사격, 「정조준」 2랭크(+16%) | 7 × 1.24 × 1.16 | 10.1 → 10 |
| 쟈알디 고유기 「근접 폭파」(이능·폭발) 270, 퍽 없음 | 270 × 0.92 | 248 |
| 위에 「고유기 강화」 1(+12%)·「폭발 피해」(+10%)·치명 | 270 × 0.92 × 1.22 × 2.0 | 606 |
| 같은 기술을 폭발 저항 30% 괴이에게 | 248 × 0.7 | 174 |

- 기본 피해 숫자(7, 270)는 아직 테스트룸 샌드백(체력 400) 기준이라 다시 맞춰야 한다(7장).

### 4-4. 코드에 넣는 자리

| 할 일 | 지금 | 바꿀 곳 |
| --- | --- | --- |
| 능력치 → 전투 수치 | `AgentStats` 7칸(hp·power·aim·defense·speed·poise·charge), 주인공 220·AI 160 고정 | `engine/progression.ts`에 힘민체지정과 산출 함수. 인물 팩에 다섯 칸(55명 표) |
| 판정 형태 배율 | `hurtTarget`이 `src`(ranged·blast) 두 가지로만 힘/사격을 고름(`fighter/player.ts:144`). 나머지는 전부 근접으로 계산됨 | 타격마다 형태 꼬리표. 코어가 피해를 내는 곳 세 군데(평타·기술 타격·탄환)에서 넘김 |
| 속성 | 없음 | 기술 자료 `hit`에 `el` 한 칸. 값은 `기술_속성표.md`에서 |
| 퍽 보너스 합 | 없음(`dmgMul` 곱 하나) | 합산기 하나. 출처·속성·조건 보너스를 더함 |
| 치명 | 에일린 유물 한 곳 | 합산기 다음에 굴림 |
| 기술 쿨 | `setCd`가 표 값 그대로 | × 기술 쿨 |
| 필살 충전 | `spMul` | × 필살 충전 |
| 상태 이상 지속 | `StatusSet` | × 상태 이상 지속 |

- 동작·이펙트·그림은 그대로 쓴다. 바뀌는 것은 숫자 계산뿐이다.

## 5. NPC 상태

- 같은 다섯 칸을 쓰고, 그 위에 **등급 배수**를 얹는다(`설계_인물_초기값.md`):
  - 시민 0.15
  - 거리 0.3
  - 훈련 0.6
  - 숙련 1.0
  - 적당히 1.3(방어막 20%)
  - 상당히 2.0(방어막 40%)
  - 재난급 3.0
- 이름 없는 몹(시민·경찰·불량배 등 71명)은 원형마다 다섯 칸 한 벌을 쓴다.

## 7. 기본 피해 다시 맞추기 (해야 함)

- 지금 기본 피해는 테스트룸 샌드백 체력 400 기준이다(약공 연타로 약 10초). 체력 1,000 단위에 그대로 쓰면 싸움이 2.5배 넘게 길어진다.
- 인물 AI 적이 같은 기술을 쓰므로, 고유기(약공 3타의 약 6배)·필살(약 10배)을 일괄로 올리면 적 한 방이 너무 세다 → 적이 쓸 때 기술 배율을 따로 둔다.
- 순서 안: 목표 시간(몇 대에 쓰러지나)을 정함 → 평타·사격 공통 배율(약 ×3) → 고유기·충전·필살은 플레이어용과 NPC용 배율을 나눔 → 튀는 값 정리(노기균 고유기 마지막 타 1,882) → 시험장 실측.

## 6. 정할 것

1. 산출 방식(이 문서) / 직접 항목 방식
2. 한 칸당 폭(3장 표)
3. 합계 25, 9 이상 한 칸만
4. 치명 피해 기본 200%(하데스는 300%)
5. 역할별 기본 분배(2장 표)
6. 판정 형태 3가지(몸·총투척·이능)와 속성 10가지
