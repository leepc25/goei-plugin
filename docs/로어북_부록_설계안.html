로어북 부록 설계안

길어진 로어북 항목을 본 항목과 부록으로 나누는 방법. 기능, 넣는 법, 코드 변경, 장단점, 정할 것.

목차
  • 1. 무엇인가
  • 2. 넣는 법
  • 3. 켜지는 조건 (명부 「부록」 탭, 부록마다)
  • 4. 해금
  • 5. 카드 업데이트
  • 6. 카드에 들어간 것 (원작 3부)

1. 무엇인가

  • 길어진 로어북 하나를 본 항목 + 부록으로 나눈다. 정보는 버리지 않고, 세부는 필요할 때만 들어간다.
  • 부록은 카드의 📎부록 폴더에 넣는다. 이름을 본 항목 이름 · 설명으로 지으면 본 항목에 저절로 붙는다.
  • 세력·괴이·파밍·요원 어느 항목에나 쓸 수 있다.

2. 넣는 법

항목 규칙
폴더 📎부록 (이모지는 상관없고 이름에 「부록」)
이름 본 항목 이름 · 설명. 가운뎃점 앞이 다른 로어북 이름과 똑같으면 그게 본 항목 (· ・ ㆍ • 모두 됨)
키 그 장면에서만 나오는 고유 명칭. 키 없이 다른 조건만 써도 됨
순서 본 항목 순서를 따르고 본 항목 바로 뒤에 붙음 (부록 자체 순서값은 안 씀)
자리 본 항목 폴더의 자리 (세력 200, 특수 400, 괴이 500, 요원 600). 본 항목을 못 찾으면 세력 자리
명부 괴이·특수·요원 목록에 들어가지 않음 → 무작위 발생 후보가 되지 않음

3. 켜지는 조건 (명부 「부록」 탭, 부록마다)

조건 내용 기본
키가 걸리면 지금 방식 그대로 켬
본 항목과 같이 본 항목이 켜지면 같이 끔
상태창 목표가 본 항목이면 그 괴이·특수 안에 있을 때 켬
위치 상태창 위치 칸에 이 말이 들어 있으면. 거점 이름을 눌러 넣을 수 있음 없음
동행·투입 요원 이 요원이 동행 칸에 있거나 투입·외근 중이면 (요원 이름·영문명·별칭) 없음
본 항목이 꺼져 있으면 끄기 다른 조건이 맞아도 본 항목이 없으면 끔 끔
해금 조건 적으면 해금 전에는 어떤 조건으로도 켜지지 않음 없음
  • 예산이 모자라면 본 항목을 먼저 넣고 부록은 남는 몫에 넣는다.
  • 설정 「로어북 확인」에 부록은 「○○ 부록」으로, 켠 까닭(위치·동행·투입·본 항목)과 함께 보인다. 해금 전 부록도 따로 보인다.

4. 해금

  • 해금 조건이 있는 부록은, 본 항목이 켜졌을 때 해금 조건만 모델에게 알린다 (내용은 안 보냄).
  • 조건이 맞으면 모델이 응답 끝에 [🔓|부록 이름]을 남긴다. 플러그인이 이 채팅에 해금을 적고($goei_unlocked), 본문에서 표시를 지운다. 다음 요청부터 내용이 들어간다.
  • 명부 부록 탭에서 이 채팅의 해금을 직접 켜고 끌 수 있다.
  • 해금 조건 글은 모델에게 가므로 비밀을 직접 쓰지 말고 "무엇을 보거나 알게 되면"처럼 적는다.
  • Risu가 직접 켜는 방식에서는 해금이 걸린 부록을 늘 막아 둔다 (해금 상태는 플러그인만 안다).

5. 카드 업데이트

  • 명부는 사용자 것을 지키므로, 새 카드 명부에만 있는 부록 조건은 사용자 명부에 더한다. 사용자가 고친 부록 조건은 그대로 둔다.

6. 카드에 들어간 것 (원작 3부)

로어북 폴더 부록
남해지사 🌆세력 남해지사 · 시설 (키 + 위치 「남해지사」), 남해지사 · 숨은 진실 (본 항목과 같이 + 해금)
망상홈쇼핑 🎁파밍 망상홈쇼핑 · 상품 (키 + 목표 + 위치 「망상홈쇼핑·오후역」)
빛이 없으라 🚧괴이 빛이 없으라 · 수도원 (키 + 목표 + 해금)
  • 원문: card/extra-lore/*.txt (머리 줄 folder·name·key·order·appendix, --- 아래 본문). 카드 빌드(tools/build_lite_card.py add_extra_lore·add_appendix_data)가 넣는다.
  • 오후역 키에서 망상홈쇼핑 3개를 뺐다. 화요퀴즈쇼에 「Outside Summoning: Purgatory Choir Parade」 절을 더했다.
