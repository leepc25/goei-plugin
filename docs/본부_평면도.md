# 관리국 본부 평면도 (2026-10-21 초안)

종로 뒷골목의 5층짜리 낡은 사무 건물 하나. 관리국은 이 건물 3층(종합대응팀)과 지하 2개 층을 쓰고, 나머지 층은 일반 회사가 입주한 것처럼 보이게 둔다(인식의 장막). **장면 하나 = 방 하나 또는 복도 하나**다. 문을 E로 열면 화면이 잠깐 어두워졌다가 그 방 장면으로 바뀐다. 층 사이는 엘리베이터(층 고르기)와 계단(바로 위·아래 층)으로 다닌다.

## 층별 구성

```
 5F  (일반 입주사, 안 감)
 4F  (일반 입주사, 안 감)
 3F  ┌ 엘리베이터 홀·계단 ─ 유리문 ─┬──────── 종합대응팀 사무실(큰 방) ────────┐
     │                              │ 잼트리 자리 · 팀 책상 2줄 · 창가 소파     │
     │                              │ 안쪽 벽: [부장실 문]  [탕비실 문]         │
     └──────────────────────────────┴──────────────────────────────────────────┘
 2F  ┌ 엘리베이터 홀·계단 ─ 짧은 복도 ─ [의무실 문] ─ [면담실 문] ┐
 1F  ┌ 정문 ─ 로비(경비 데스크·우편함) ─ 엘리베이터·계단 ┐
 바깥 종로 거리: 건물 정문 · 길 건너 파스타집
 B1  ┌ 엘리베이터·계단 ─ 정비·보급실(창고형 큰 방) ─ [훈련장·사격장 문] ┐
 B2  ┌ 엘리베이터(카드키)·계단 ─ 보안문 ─ 격리 구역 복도(전시 진열장)
     │   복도 양쪽: [감정실 문] [격리 연구실 문] · 복도 끝 철문: [이빨 요정 격리실]
```

## 지금 통합본에서 바꾸는 것

1. **같은 폭 칸을 한 줄로 늘어놓던 것을 없앤다.** 위 장면들로 쪼갠다. 시설은 방 문이 아니라 **방 안의 물건**(책상, 사물함, 커피 머신)에 붙는다. 지상과 지하는 엘리베이터와 계단으로만 이어진다.
2. **벽에 떠 있던 글씨를 전부 뺀다.** 방 이름, 「지상/지하」, 「잠김 · 첫 구조 후」 같은 글은 화면에 쓰지 않는다. 방 이름은 문을 열 때 화면 위에 1초 뜨는 작은 제목만 쓴다. 아직 못 여는 문은 닫힌 채로 두고, E를 누르면 문이 덜컹하는 소리만 난다(이유는 잼트리 게시판·대사로 알려 준다).
3. **NPC 색 바꾼 쟈알디 복제를 뺀다.** 진짜 도트가 나오기 전까지는 **빈 자리 + 목소리** 방식으로 한다. 잼트리 자리에는 켜진 모니터·연유 커피 컵·걸쳐 둔 카디건만 놓고, E를 누르면 대화창(초상화 없이 이름 + 대사)이 뜬다. 고그니쟈·데쥬레·콘쥬스도 각자 자리 물건(믹스커피 통, 감정 장갑, 화물 카트)으로 "있는 자리"만 보여 준다. 쉬는 요원도 같은 방식(의자에 걸친 외투). 도트가 생기면 그 자리에 세운다.
4. **칸 사이 검은 기둥을 뺀다.** 방 하나가 이어진 벽 한 장이고, 기둥은 그 건물 구조(창 사이 기둥 등)로만 그린다.
