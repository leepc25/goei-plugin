## 나6 · 폰 뷰포트 시험에 viewport 메타

`isMobile` 로 폰을 흉내 내는 문서에 메타가 없으면 Chromium 이 980px 배치로 돌아 폰 화면을 못 잰다. `setContent`/직접 만든 HTML 중 없는 곳에 `<meta name="viewport" content="width=device-width, initial-scale=1">` 을 넣었다.

| 파일 | 넣은 곳 | 비고 |
|---|---|---|
| `tests/qc-host.mjs` | boot 문서 | qc-mobile 이 부팅 뒤 `document.head.append(meta)` 로 끼우던 줄은 뺌(이제 처음부터 있음) |
| `tests/qc-game-host.mjs` | boot 문서 | touch 옵션으로 폰 흉내 |
| `tests/browser.mjs` | boot 문서 | 390×844 touch 절·setViewportSize 390 절 |
| `tests/wallet-browser.mjs` · `tests/wiki-side-browser.mjs` | boot 문서 | 390×844 (isMobile 은 안 씀 → 메타가 배치를 바꾸지는 않음, 일관성) |
| `tests/hq-growth-browser.mjs` | `<html><body>` 에 head 추가 | 390×844 isMobile |
| `tests/navigation-feedback-round2-browser.mjs` | fixtureHtml | 844×390·667×375 isMobile |
| 이미 있었음 | `qc-settings-harness.mjs` · `field-harness.mjs` · `qc-modules-browser.mjs` · 시연판 HTML(`scripts/build.mjs`·`build-enemy`·`build-story`·`hq/build-demo`) | 안 건드림 |
| PC 전용이라 안 넣음 | install · editor · qc-static-xss · qc-static-risu · qc-static-harness · browser.mjs 2289행(iframe 시작기) · PC 1280×720 자체 http 시험들 | — |
