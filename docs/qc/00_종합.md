## 스스로 내린 결정 (사용자 부재 중, 근거는 각 보고서 ④)

- 유저 이름을 모를 때 `{{user}}` 를 빈 글 대신 그대로 둬요. 빈 글이면 문장이 깨져서예요.
- 「Risu 방식」 로어 고르기에서 새 카드의 세계 로어는 플러그인이 끼워요. 안 그러면 세계 로어가 통째로 빠져서예요. 직접 넣은 항목은 전처럼 Risu가 켜요.
- 로어 덩어리는 첫 장면 앞에 둬요. Risu가 로어북을 넣는 자리와 같게 했어요.
- 시드와 겹치는 로어는 한 번만 보내요. 기능은 그대로이고 토큰만 아껴요.
- 카드 업데이트 때 새 카드에 없는 옛 자리 항목(📚Lore slot 4개)은 지워요.
- 설정 창 기능 페이지(괴담넷·괴담톡 등)의 고급 칸은 늘 이 채팅에 적혀요. 「새 채팅 기본값」 범위는 고급 페이지에서만 따라요. 기능 페이지에 범위 칩이 없어 화면과 저장이 어긋나서예요.
- 사용자가 정한 수치·방식(인물 기록 상한, 세력 구간, 시간 규칙 등)은 하나도 바꾸지 않았어요.
