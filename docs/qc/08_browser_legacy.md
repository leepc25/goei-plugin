- 결정: 「다른 폴더에서 온 후보」는 의도적으로 뺀 흔적(주석·문서)이 없고, 사용자가 남기라고 한 기능(옛 프로젝트 메모 `goei-directory-photos.md`)이라 **버그로 보고 되살렸다**(B5). 명부 처리기(`dir-ext-*`)와 편집 창 입력 처리(`dir-ext-q`)는 이미 남아 있어 단추·칸만 그렸다.
- 결정: 게임 캔버스 크기 단언은 2026-10-23 사용자 결정(게임은 창 틀 안에서만)에 맞춰 「필드 칸을 한쪽이라도 꽉 채움」으로 바꿨다. 틀 안에서 세로 폰 화면이 16:9 캔버스로 위아래가 비는 것(390×844 → 390×219)은 그 결정의 결과라 고치지 않았다.
- 결정: 게임 힙 기준을 「처음 닫은 뒤」로 옮겼다. 시험의 가짜 저장소가 받은 파일을 페이지 힙의 문자열로 들고 있어(실제 Risu 는 플러그인 저장소 밖) 받기 전 기준은 누수와 무관한 수 MB 를 센다.
- 결정: 폰 세계 기록 페이지는 목록 대신 맨 위 드롭다운이 본문과 같이 내려간다(사용자 규격 「760px 이하 한 열」). 드롭다운을 고정하지 않고 시험도 머리 고정만 본다.

## ⑤ 고치지 못했거나 확인이 필요한 것

- 17c·17d 절은 묶음 위키(`GOEIWIKI1:`)가 든 카드에서만 돈다. v0.17 경량 카드 fixture 로는 건너뛰고, 옛 명부 경로(`prefs-open` → `set-scope card` → `.dir-kinds`)가 남아 있다. 묶음 위키 카드 fixture 가 생기면 17절처럼 세계 탭으로 옮겨야 한다.
- 시작 뒤 설정 창에서 「지금 채팅 설정을 새 채팅 기본값으로 한 번에 덮어쓰기」(옛 `set-bar save`)는 이제 없다. 기본값 범위 칩에서 값마다 고칠 수 있지만 한 번에 옮기는 단추가 필요한지는 사용자 판단(처리기 `set-bar-yes` 는 settings.ts 에 남아 있음).
- 폰 세로에서 필드 게임 캔버스는 칸의 30% 남짓(위아래 빈칸). 2026-10-23 결정(틀 안에서만, 돌려 보기 없음)의 결과로 보이나 사용자 확인 권함.
