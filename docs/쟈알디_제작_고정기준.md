# 쟈알디 제작 고정 기준

2026-10-19. 반복된 체형 불일치를 막기 위한 실제 파일 기준. 이 문서와 JSON이 이후 생성 프롬프트의 일반 표현보다 우선한다.

## 기준 파일 하나

- 원본: `game-src/action/jyaldi-master.png` — 사용자가 ‘조금만 줄여봐’라고 지정한 다리 소폭 조정 시안.
- 실제 표시: `game-pack/action/jyaldi-master.png` — **55×160px**. 원본과 가로·세로 같은 배율로만 축소한다.
- 고정 수치와 파일 지문: `game-src/action/jyaldi-standard.json`.
- 이는 현재 작업 기준이며 사용자가 모든 동작·최종 외형을 승인했다는 뜻이 아니다. 새 피드백이 있으면 기준 파일과 버전을 함께 갱신한다.

## 정자세에서 확인할 수치

| 항목 | 현재 기준 도트 가이드 |
| --- | ---: |
| 머리 꼭대기 → 발바닥 | 160px |
| 머리 높이 | 약 22px |
| 어깨 폭 | 약 32px |
| 어깨 → 사타구니 | 약 50px |
| 사타구니 → 무릎 | 약 37px |
| 무릎 → 발목 | 약 35px |

수동 가이드는 머리 꼭대기 y=0, 턱 22, 어깨 29, 허리 52, 골반 73, 사타구니 79, 무릎 116, 발목 151, 발바닥 160이다. 단순한 원화 해석치이며 숨겨진 관절의 정확한 실측값으로 주장하지 않는다. 필요하면 기준 포즈를 보며 주석만 교정한다. 주석에 맞추려고 원본의 신체를 변형하지 않는다.

움직일 때 관절의 화면 y좌표는 바뀐다. 위 수치를 웅크린 포즈의 높이로 강제 적용하지 않는다. 머리 크기·골격의 길이·정체성이 유지되는지 자세와 투영을 고려해 사람이 확인한다. 자동 검사로 인체 움직임의 질을 보장한다고 주장하지 않는다.

## 금지

1. ‘성인 여성’, ‘늘씬함’, ‘7등신’ 같은 말만 적고 다른 체형의 결과를 받아들이기.
2. 여러 동작을 한 번에 생성한 뒤 작고 큰 프레임을 개별적으로 키에 맞춰 보정하기.
3. 머리만 큰 SD 결과를 도트 스타일이라는 이유로 사용하기.
4. 얼굴·넥타이·신체 실루엣이 달라졌는데 프레임 수가 많다는 이유로 통과시키기.
5. 그림을 늘이거나 줄여 포즈·관절·접지 오류를 감추기.
6. 기능 시험 통과를 시각 품질 합격으로 취급하기.

## 다음 제작은 걷기 하나만

기준 도트를 실제 160px와 2배 확대에서 나란히 놓고 시작한다. 걷기의 접지·하강·통과·상승, 반대발 접지·하강·통과·상승을 제작한다. 프레임마다 기준 머리 크기와 몸통·팔다리의 길이를 확인하고, 정지 카메라에서 발의 접지와 실제 이동량을 맞춘다. 루프 마지막→처음, 시작·정지 연결을 확인한다.

**걷기의 체형·접지·루프가 통과하기 전에는 달리기·공격·방어 시트의 대량 제작과 런타임 승격을 하지 않는다.** 지금 생성된 불일치 시트는 미승인 자료이며 사용하지 않는다. 생성 도구가 기준을 유지하지 못하면 같은 요청을 무한 반복하는 대신 프레임 단위 제작·수정 방식으로 전환한다. 자동 생성만으로 이 일관성을 보장할 수 있다고 약속하지 않는다.

## 비교와 검증

```sh
python3 tools/action_master.py
```

결과: `dist/goei-jyaldi-proportions.html`. 기준 원본, 실제 160px, 동일 도트 2배 확대, 정자세 가이드를 비교한다. 원본·실제 도트의 SHA-256이 JSON과 다르면 생성이 중단되므로 기준 파일을 조용히 바꿀 수 없다.

## 체형 개선 시연판 적용 기록

2026-10-19: 기준 원본은 바꾸지 않고 걷기를 먼저 실제 게임 크기에서 검토한 뒤 새 동작을 연결했다. 기준 포즈 포함 44프레임이며 기존 불일치 SD 시트는 포함하지 않는다. `release/demo/goei-jyaldi-slender.html`이 플레이 시연판이고 `goei-jyaldi-motions.html`에서 같은 자산을 동작별로 정지·확대해 확인할 수 있다. 자동 단위 시험과 별도로 원본 시트, 실제 160px 모음, 배경 위 표시를 검토했다. 이는 사용자의 최종 승인을 기록한 것이 아니다.
