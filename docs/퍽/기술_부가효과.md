# 기술 부가효과 표

2026-10-30 사용자 지시: 상태 이상을 거는 별도 시스템을 만들지 않고, 완성된 인물 기술에 「부가효과」를 붙인다. 목적은 「출혈 걸린 적이 폭발에 맞으면…」 같은 조합 퍽이 뜻을 갖게 하는 것. 데이터: `기술_부가효과.json`.

## 규칙

- 평타(약공·강공·점프·슬라이딩)·기본 사격에는 붙이지 않는다. 고유기·고유기2·충전 단계·필살에만.
- 인물마다 1~2개 기술에만. 이미 표식(mark)·묶기(bind)가 있는 기술은 그대로 두고 `existing: true`로 표시만.
- 쓰는 효과는 엔진에 이미 있는 것만: 상태 이상 7종(`src/game/combat/status.ts`) + 코어 반응 표식·묶기(`src/game/action/fighter/core.ts`).
- 지속(sec)은 짧게 2~5초, 필살은 4~5초까지. 엔진 기본값(출혈 8·두통 10·혼란 4·공포 5·둔화 5·침묵 6)보다 짧게 넘긴다(`apply(kind, sec)`).
- 오염은 엔진상 지속이 무한(정화제로 한 단계씩)이라 `sec: 0`, `stage: 1` = 맞을 때 한 단계 +1. 최대 체력 −20%가 영구라 **필살에는 붙이지 않고** 충전·고유기에만.
- 기술 한 번에 대상마다 한 번만 건다(다단 히트로 출혈·오염이 3단계까지 한꺼번에 쌓이지 않게).
- 혼란은 맞으면 풀리므로(`onHit`) 다단 기술은 **마지막 타**에 건다.
- NPC가 주인공에게 쓸 때도 똑같이 걸린다: 필살 + 침묵, 필살 + 오염 조합은 두지 않았다. 침묵은 모두 2~2.5초, 고유기·충전에만.
- 폭발 계열(쟈알디·큐라스·윤병수 수류탄·곽성주 판처파우스트·송진섭 박격포)은 넘어뜨림 반응이 이미 있어 폭발 기술에는 원칙적으로 붙이지 않았다(기술이 전부 폭발인 쟈알디·큐라스만 예외, 아래 참고).

- 1.1 쟈알디: 기술 전부 폭발. 1~2개 규칙 때문에 충전2(둘레 폭발)에 가장 가벼운 두통 3초만. 빼도 된다.
