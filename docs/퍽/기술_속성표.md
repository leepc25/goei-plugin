# 기술 속성표 (2판 · 2026-10-30)

이름 있는 55명의 기술 332개. 평타(약공 3타·강공·점프 공격·슬라이딩)는 표에 없고 **전원 물리·몸**이다. 기계용 사본: [기술_속성표.json](기술_속성표.json). 기본 피해 규칙은 `설계_기본피해_표준.md`.

**2판 정리(10-30 사용자 승인 규칙)**
- 속성 목록 9개로 확정: 물리·폭발·화염·전기·염동·정신·오염·빛·음파 + 「이상」(시간·공간·석화를 묶음). 냉기는 쓰는 기술이 없어 뺐다(괴이용으로 필요하면 다시 넣음).
- 1판 「기타」 정리: 음파 → 음파, 공간·시간·석화 → 이상, 주술 → 정신, 착취 → 오염, 피해 없는 기술 → 없음.
- 애매했던 행은 두 규칙으로 정리: ① 몸 기술에서 뻗어 나가는 충격파·칼바람·장풍은 몸·물리 ② 그림과 설정이 다르면 설정을 따른다. 1판 판단이 이미 이 규칙대로라 결과는 그대로 두고, 「애매」 칸에 이유만 남겼다.
- 속성이 하는 일은 둘뿐: 괴이·적의 속성 저항/약점, 속성 퍽. 속성만으로 상태 이상을 걸지는 않는다(퍽으로만).
- 「새 기본 피해」는 기술 종류별 표준값이다. 인물마다 다르던 값(역할별 차이)은 없앴고, 인물 차이는 힘민체지정·고유 퍽·등급 배수에서만 낸다.
