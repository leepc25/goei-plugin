# 능력치 55명 (안 · 2026-10-30)

> **⚠ Claude 반성 · 2026-10-31 (사용자 지시로 문서마다 남김)**
> 2026-10-31 Claude는 다음 잘못을 저질렀다. 이 문서를 읽는 모든 Claude는 같은 짓을 하지 않는다.
> 1. **사용자 결정을 무시했다.** 콘쥬스는 사용자가 10-26에 20세로 정했고 인계서에도 적혀 있었는데, 옛 Claude 문장(teenage high school girl)을 근거로 화장실·샤워 그림을 거부하고, 사용자가 직접 뽑은 화장실 줄까지 팩에서 뺐다. 옷도 제복인데 교복이라고 단정했다.
> 2. **사용자 말에 토를 달고 같은 주장을 되풀이했다.** 사용자가 여러 번 지적했는데도 근거를 다시 확인하지 않아 몇 시간을 허비하게 했다.
> 3. **허락 없이 문서를 지웠다.** 「지침을 지우라」는 말만 듣고 목록을 보여 주지도 않고 96개를 지웠다가 되살렸다(결과물 삭제 금지 규칙 위반).
> 4. **문장을 덧대기만 하며 PixelLab을 낭비했다.** 이성해 점프 공격 5번 연속 실패, 이어폰 음악 120줄을 못 쓰게 만듦.
> 5. **답을 미루고 일을 멈춰 두었다.** 백그라운드로 돌릴 일을 돌리지 않고 대화만 했다.
>
> 지킬 것: 사용자 결정·위키가 근거다. 옛 Claude 자료는 근거가 아니다. 사용자 말에 토 달지 않는다. 무엇이든 지우기 전에 목록을 보여 주고 허락받는다. 실패하면 덧대지 말고 다시 쓰거나 바꾼다.

## 규칙 요약

- 다섯 칸 **합계 25 고정**, 각 1~10, **9 이상은 한 칸만**. 등급(간부·재난급 등)은 여기 넣지 않는다(NPC로 나올 때 등급 배수로 따로 얹음).
- 출발점(힘/민/체/지/정): 방패 tank 6/3/8/3/5 · 돌격 bruiser 8/4/6/3/4 · 타격 striker 6/8/4/3/4 · 사격 ranged 3/8/4/5/5 · 제어 control 3/4/4/8/6 · 지원 support 3/4/5/6/7.
- 기획서 5.1 표의 8명(쟈알디·스팡달·에일린·고르고디오·큐라스·데드폴·게슈간·로제몬)은 4축을 옮겼다: 생존→체, 화력→힘/민(이능 기술이면 지), 기동→민, 제어→지.
- 나머지는 설정·기술에서 근거를 찾아 역할 기본값에서 칸마다 1~3씩 옮겼다(전원 칸당 3 이내). 기술의 **판정 형태**(`기술_속성표.md`)를 가장 크게 봤다: 몸=힘, 총·투척=민, 이능=지.
- 정 = 정신력. 괴이·정신 계열에 강하거나 겁이 없는 인물은 높게, 겁 많고 패닉하는 인물은 낮게.
- 산출 수치(키운 안): 체력 500+체×100 · 근접/사격/이능 100+(힘/민/지−5)×8 · 받는 피해 100−(체−5)×2−(정−5)×2 % · 속도 100+(민−5)×3 · 기술 쿨 100−(지−5)×4 % · 필살 충전 100+(정−5)×6 % · 상태 이상 지속 100−(정−5)×8 % · 괴이 정신 피해 100−(정−5)×6 %.
- 치명(5%·200%)·경직 저항·회피는 능력치와 무관해 표에 없다.
