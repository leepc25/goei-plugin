# 능력 뱃지 생성 계획 (2026-11-01)

## 정한 것
- 뱃지 1개 = 능력 1개. 기호를 나눠 쓰던 능력(예: 회피 4개)도 각자 다른 그림. 모두 157개.
- 그림: 남색 동그란 판 + 검은 정장·흰 셔츠·선글라스 요원(모든 뱃지 같은 요원, 얇은 흰 윤곽선)이 그 능력을 몸으로 보여 줌. 효과 하나만 색(출혈 빨강·폭발 주황·방어막 하늘·오염 보라·둔화 파랑).
- 특성은 판 바탕 어두운 빨강. 테두리는 그리지 않음 — 등급 고리(은·파랑·금) 3개를 따로 1장 뽑아 게임이 씌움.
- 빠진 것: 아이템 능력 6개(주머니), 특성 「맨몸」 — 사용자 보류.
- 그림 칸 「소품」은 능력 목록 3판에 이미 적힌 기호 그림(iconArt). 요원이 이 소품을 쓰거나 이 모습으로 동작.

## 판 나누기 (512×256 한 장 = 64px 32칸, 1장 25회)
- 판 5장 = 125회 + 등급 고리 1장 25회 = **150회** (잔액 1,384)
