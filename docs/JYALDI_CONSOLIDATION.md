## 이 로컬 채팅에서 추가된 미해결 요구

1. 연속공격의 실제 타격 팔이 좌→우→좌 또는 우→좌→우여야 한다. 상태명 3개나 키 입력 시험 통과로 그림의 팔 교대를 증명하지 않는다. 마지막 강타는 발끝 추진·골반·허리·어깨 회전과 전진, 접촉 유지·후속 동작까지 명확해야 한다.
2. 서기→걷기/달리기/앉기/앉아 공격에서 머리·허벅지·종아리의 실제 길이와 두께가 바뀌지 않아야 한다. 머리 크기만 맞추기 위해 전체 프레임을 축소한 로컬 0.9 보정은 실패했다.
3. 걷기에서 내딛는 다리를 과하게 굽히지 않는다. 팔꿈치를 자연스럽게 굽히며 반대쪽 다리와 교차한다. 골반·몸통·어깨의 반동도 함께 그린다.
4. 달리기에서 하체가 짧아지지 않으며 양팔 전체가 어깨에서 왕복한다. 한쪽 전완만 진자처럼 움직이는 방식은 반려됐다.
5. 쪼그려 걷기는 체중 지지발을 교대한다. 뒷다리 고정·앞다리 늘였다 줄이기·가는 다리·둥근 로봇 관절 금지. 하단차기 전환 때 체격이 바뀌지 않는다.
6. 기본 대기는 자연스러운 호흡, 전투 대기는 전신의 작은 체중 이동. 기본 대기에서 전투 대기로 바뀔 때 머리와 몸이 커지거나 두꺼워지지 않는다.
7. 음료/음식 섭취 시 신체 찌그러짐을 검수한다. 강한 피격/패배는 힘 방향으로 날아가 착지 후 쓰러짐이 이어져야 한다.
8. 조작 간소화/키 재지정은 후순위. 사용자가 지적하면 실제 수정·실행본 반영까지 이어가고 진단이나 완료 표현만 남기지 않는다.

로컬 기본 정자세에 대한 과거 평가는 역사 기록이다. 최신 사용자 결정은 클라우드판의 픽셀 가독성·캐릭터 픽셀 크기를 기준으로 하는 것이다. 자연스러운 장신 비율을 되살리기 위해 로컬 160px 규격으로 돌아가지 않는다. 기존 생성 그림 재사용 금지는 유지한다.

## 신체 크기 일관성 필수 검수 · 사용자 추가 지시

- 모든 동작에서 동일한 두개골 크기, 목·흉곽·골반 매스, 위팔·전완·허벅지·종아리 길이와 두께, 손·발 크기를 유지한다. 자세 변경에 따른 전체 높이 감소와 신체 자체 축소를 구분한다. 옷 주름과 머리카락의 변화로 실제 몸통 두께를 대신 판단하지 않는다.
- 신규 기준표에 중립 자세의 부위별 길이·폭과 관절 위치를 기록한다. 기존 숫자는 잠정 규격이며 대표 자세 검수 전 확정 치수로 취급하지 않는다. 관절 가이드는 제작·검수용이고 런타임 팔다리 회전 합성으로 대체하지 않는다.
- 동일 바닥 위치·카메라·표시 배율에서 기본 대기↔전투 대기, 서기↔걷기↔달리기, 서기↔앉기↔앉아 이동↔하단차기, 근접 1→2→3타, 점프·착지, 사격·섭취·피격의 전환을 나란히 재생·느린 재생·겹침 비교한다. 시작·끝뿐 아니라 중간 그림도 검사한다.
- 게임 캐릭터 표시 배율은 신규 버전 내 하나로 고정한다. 현행 `render.ts`의 `depthScale(b.y)`도 새 그림 검증 때 고정 배율로 바꿔야 한다. 바닥 위아래 이동이나 행동 ID에 따라 캐릭터가 작아지거나 커지지 않게 한다. 연출용 화면 확대는 캐릭터 단독 확대와 구분한다.
- 쪼그림·기울기·원근 단축 때문에 화면상 키나 관절 간 투영 길이가 줄어드는 것은 허용한다. 근거 없는 머리 확대·팔다리 단축·체격 변화는 반려한다. 모든 프레임의 전체 높이를 강제로 같게 만들거나 머리 크기에 맞춰 몸 전체를 개별 리사이즈하지 않는다.
- 합격 근거는 고정된 인체 기준과 실제 전환 영상/플레이 화면이다. 바운딩박스 높이·머리 크기 하나·자동 테스트 통과만으로 합격 처리하지 않는다. 허용 오차는 신규 픽셀 기준표에서 부위·시점별로 명시하고, 눈에 보이는 체격 튐을 평균값이나 수치 오차로 면제하지 않는다.

## 작화 기준의 출처

- 인물 정체성은 사용자 원작 `Jyaldi_default`와 저장소 설정이 기준이다. 저장소의 `assets/agents/Jyaldi_default.avif`는 사용자 제공 기본 그림 기록이므로 신규 기준표 제작 전에 실제 열어 원작과 대응을 확인한다.
- 긴 흑발·붉은 눈·검은 바지 정장·흰 셔츠·검은 넥타이·장갑과 얼굴 인상을 유지하고, 같은 신규 기준표에서 전신·각 시점·모든 동작·컷인을 제작한다. 상반신 원화에 없는 다리 길이를 원작 확정 수치로 주장하지 않는다.
- 로컬 0.9 또는 클라우드 v4의 생성 도트는 신규 작화 원본으로 채택하지 않는다. 로컬 기본 대기의 비율이 상대적으로 좋았다는 사용자 평가는 디자인 검토 시 반영하되 그 그림 재사용이나 무조건 160px 채택으로 해석하지 않는다.
- **2026-10-20 사용자 확정: 캐릭터 픽셀 크기는 클라우드판 기준으로 한다. 정자세 원본 키 128px, 게임 표시 정수 2배로 정자세 256px를 공용 규격으로 고정한다. 로컬 160px를 채택하거나 동작마다 배율을 달리하지 않는다.** 128px는 중립 정자세의 신체 기준이며 앉기·점프·기울인 자세의 외곽 높이를 128px로 강제하는 뜻이 아니다. 뻗은 동작은 셀 여백만 확장한다.
- 사용자는 한정된 픽셀에서 길쭉한 실제 인체 비율의 표현이 어렵다는 이유로 자연스러운 신체 비율 우선을 포기했다. **클라우드판처럼 잘 읽히는 게임용 체형과 실루엣이 우선**이다. 약 6등신을 설계 출발점으로 머리·얼굴·손·몸통에 충분한 픽셀을 배분하며, 로컬판의 길고 가는 팔다리나 작은 머리를 목표로 복구하지 않는다. 자연스러운 체중 이동·관절 움직임은 계속 요구한다.
- 게임용으로 정한 동일 체형의 머리·몸통·팔다리 크기는 모든 동작에서 유지한다. 과장된 디자인 선택과 동작 중 체격 변화는 구분한다. 클라우드의 가독성·픽셀 규격 채택은 현재 반려된 그림 전체의 승인이나 재사용 허가를 뜻하지 않는다.

## 기능 이식 순서

우선 기존 `docs/다음방_작업인계_캐릭터전면재제작.md`의 원작 확인→신규 기준표→핵심 자세 동일 인물 검수를 따른다. 그다음 동일한 신규 기준으로 동작을 제작한다. 로컬 기능은 `src/engine.js`의 `ability`, `slide`, `hitPlayer`, `interact`, `perform`을 참고해 공용 엔진의 상태·자원·저장 형식에 맞춰 옮긴다. 로컬의 복잡한 전체 키 배치를 그대로 복제하지 않는다.

진행 상태: 원본 보존 완료 / 코드 비교 완료 / 공용 개발 위치 지정 완료 / 특수기·생활 기능 이식 미완료 / 신규 그림 제작 미완료. 구별 없이 '통합 게임 완성'이라고 부르지 않는다.

매 작업 시작 시 원격 최신 커밋과 진행 브랜치를 확인한다. 종료 시 변경·검증·남은 문제를 이 문서에 갱신하고 커밋/푸시한다. 다른 PC에서는 같은 원격 변경을 받은 뒤 이어간다. 채팅 기록만으로 파일이 공유됐다고 가정하지 않는다.
