# 쟈알디 공용 작업 기준 · 로컬/클라우드 통합

2026-10-20. 사용자가 두 PC에서 별도로 진행된 쟈알디 작업을 비교·보완하고 하나로 이어가도록 요청했다. 새 방에서 처음부터 재개하지 말고 이 문서와 기존 전면 재제작 인계를 함께 읽는다.

## 한 곳에서 이어갈 위치

- 공용 저장소: `leepc25/goei-plugin`.
- 공용 실행 코드: `src/game/action/`. 별도 로컬 엔진을 두 번째 현행 제품으로 개발하지 않는다.
- 메인 봇과의 연결: `src/ui/game.ts`, `src/host/actionpack.ts`. 기존 Claude 작업과 자동 업데이트 배포물을 임의로 교체하지 않는다.
- 로컬 최종 0.9 원본: `game-src/history/local-arpg-v09/source.zip`. 코드와 테스트는 같은 폴더에서 바로 비교할 수 있다. `manifest.json`에 파일 해시와 이관 기준 커밋을 기록했다.
- 클라우드 기존 구현과 제작 자료는 원래 위치와 Git 이력에 보존한다. 로컬 그림을 클라우드 그림에 덮어쓰지 않았다.

이 커밋은 원본·요구사항·개발 위치의 통합이다. 미이식 기능을 합쳤거나 그림을 고쳤다고 보고하지 않는다. 공용 게임의 동작은 이관 전과 같다. 과거 실행본은 비교 자료이며 새 수정본이 아니다.

## 이 로컬 채팅에서 추가된 미해결 요구

1. 연속공격의 실제 타격 팔이 좌→우→좌 또는 우→좌→우여야 한다. 상태명 3개나 키 입력 시험 통과로 그림의 팔 교대를 증명하지 않는다. 마지막 강타는 발끝 추진·골반·허리·어깨 회전과 전진, 접촉 유지·후속 동작까지 명확해야 한다.
2. 서기→걷기/달리기/앉기/앉아 공격에서 머리·허벅지·종아리의 실제 길이와 두께가 바뀌지 않아야 한다. 머리 크기만 맞추기 위해 전체 프레임을 축소한 로컬 0.9 보정은 실패했다.
3. 걷기에서 내딛는 다리를 과하게 굽히지 않는다. 팔꿈치를 자연스럽게 굽히며 반대쪽 다리와 교차한다. 골반·몸통·어깨의 반동도 함께 그린다.
4. 달리기에서 하체가 짧아지지 않으며 양팔 전체가 어깨에서 왕복한다. 한쪽 전완만 진자처럼 움직이는 방식은 반려됐다.
5. 쪼그려 걷기는 체중 지지발을 교대한다. 뒷다리 고정·앞다리 늘였다 줄이기·가는 다리·둥근 로봇 관절 금지. 하단차기 전환 때 체격이 바뀌지 않는다.
6. 기본 대기는 자연스러운 호흡, 전투 대기는 전신의 작은 체중 이동. 기본 대기에서 전투 대기로 바뀔 때 머리와 몸이 커지거나 두꺼워지지 않는다.
7. 음료/음식 섭취 시 신체 찌그러짐을 검수한다. 강한 피격/패배는 힘 방향으로 날아가 착지 후 쓰러짐이 이어져야 한다.
8. 조작 간소화/키 재지정은 후순위. 사용자가 지적하면 실제 수정·실행본 반영까지 이어가고 진단이나 완료 표현만 남기지 않는다.

로컬에서 기본 정자세의 비율이 상대적으로 좋다는 피드백은 보존하되, 최신 클라우드 인계의 기존 생성 그림 재사용 금지를 무효화하거나 새 디자인 승인으로 해석하지 않는다.

## 기능 이식과 다음 진행

우선 기존 `docs/다음방_작업인계_캐릭터전면재제작.md`의 원작 확인→신규 기준표→핵심 자세 동일 인물 검수를 따른다. 그다음 동일한 신규 기준으로 동작을 제작한다. 로컬 기능은 `src/engine.js`의 `ability`, `slide`, `hitPlayer`, `interact`, `perform`을 참고해 공용 엔진의 상태·자원·저장 형식에 맞춰 옮긴다. 로컬의 복잡한 전체 키 배치를 그대로 복제하지 않는다.

진행 상태: 원본 보존 완료 / 코드 비교 완료 / 공용 개발 위치 지정 완료 / 특수기·생활 기능 이식 미완료 / 신규 그림 제작 미완료. 구별 없이 '통합 게임 완성'이라고 부르지 않는다.

매 작업 시작 시 원격 최신 커밋과 진행 브랜치를 확인한다. 종료 시 변경·검증·남은 문제를 이 문서에 갱신하고 커밋/푸시한다. 다른 PC에서는 같은 원격 변경을 받은 뒤 이어간다. 채팅 기록만으로 파일이 공유됐다고 가정하지 않는다.
