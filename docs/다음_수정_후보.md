## 결정이 필요한 것

1. **설정 창 머리 단추가 탭마다 다름** (사용자: 「개판」)
   - 지금: 기능 = 기본값 저장·불러오기 / 세계 = 저장·되돌리기 / 지침 = 페이지 단추 / 점검 = 없음.
   - 안 A: 머리에는 언제나 같은 자리에 「저장」「되돌리기」 두 칸만 두고, 탭에 맞지 않으면 흐리게(눌리지 않게). 기본값 저장·불러오기는 기능 탭 본문 맨 아래 묶음으로 내린다.
   - 안 B: 머리 단추를 모두 빼고, 각 탭 본문 맨 아래에 같은 모양의 「바닥 줄」(왼쪽 설명, 오른쪽 단추)을 둔다.
   - 시안을 보고 고르는 것을 권함.

2. **필드 다녀온 기록을 어디에 보일지**
   - 출동 종료 → 보고서·일지에는 이미 쌓인다(기록 메뉴).
   - 안: 필드 첫 화면에 「지난 출동」 한 줄(장소·시간·결과 → 누르면 그 보고서). 넣을지 말지.
