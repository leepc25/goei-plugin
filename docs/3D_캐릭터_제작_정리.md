# 3D 캐릭터 제작 정리 (2026-10-28, 중복 지출 방지)

에일린 시험에서 Tripo 300크레딧을 썼고, 그중 135는 설정을 잘못 골라 버렸다. 다음부터는 이 문서대로만 쓴다.

## 캐릭터 1명에 드는 것 (Tripo API V3, `openapi.tripo3d.ai`)

| 단계 | 설정 | 크레딧 |
| --- | --- | --- |
| 모델 | `POST /v3/generation/image-to-model`, 정면 전신 그림 **한 장**, `model=v3.1-20260211`, `geometry_quality=detailed`, `texture_quality=detailed`, `pbr=true`, 면 제한 없음 | 60 |
| 줄이기 | Blender `tools/3d/lowpoly.py` (4만 면) | 0 |
| 뼈대 | `POST /v3/animations/rig`, 줄인 GLB 업로드, `model=v3.0-20260909`, `spec=mixamo` | 25 |
| 동작 | **Tripo에서 사지 않는다.** 아래 무료 동작 묶음을 Blender에서 옮긴다 | 0 |
| 압축 | `npx -y gltfpack@0.22.0 -cc -kn -km` (영구 허용) | 0 |
| **합계** | | **85** |

## 하지 말 것 (이미 돈을 버린 것)

- 정면·옆·뒤 여러 장 입력(multiview): 옆모습을 넣으면 앞머리가 얼굴을 덮었다. 정면 한 장이 낫다.
- `face_limit` 낮게 두고 뽑기, `texture_quality=standard`, `pbr=false`: 얼굴·머리가 뭉개진다. 고품질로 뽑고 Blender에서 줄인다.
- 텍스처만 다시 입히기(`/v3/models/texture`, v3.5 detailed): 얼굴이 회색으로 얼룩졌다.
- Tripo 기본 동작(retarget): v3.0 뼈대는 11개뿐이고 `shoot`은 공 차기, `slash`는 맨손 휘두르기라 쓸 데가 없다. 1개 10크레딧.

## 옮길 때 꼭 볼 것

- **앞 방향**: UAL 원본은 -Y를, Tripo 모델은 +X를 본다. 맞추지 않고 옮기면 다리·팔이 몸 옆으로 휘둘려 안짱다리·팔 벌린 점프·제자리 걷기가 된다(10-28 첫 판이 이랬다). `retarget_ual.py`가 양쪽 허벅지 축으로 재서 원본을 돌려 맞춘다. 결과는 반드시 **옆에서 본 걷기 장면**으로 다리가 앞뒤로 벌어지는지 확인한다.
- 뼈 방향이 원본과 같다는 숫자 검사만으로는 이 오류가 안 잡힌다(원본 기준으로는 맞으니까). 그림으로 본다.

## 무료 동작 묶음 (CC0)

Quaternius Universal Animation Library 1·2 Standard (CC0, 상업 이용 가능). OpenGameArt에서 받는다.
- https://opengameart.org/content/universal-animation-library
- https://opengameart.org/content/universal-animation-library-2

뼈대는 Rigify `DEF-*` 이름(53뼈). Mixamo 이름으로 옮겨 붙인다.

쓸 만한 동작: Idle_Loop, Walk_Loop, Walk_Formal_Loop, Jog_Fwd_Loop, Sprint_Loop, Jump_Start/Loop/Land, Roll, Crouch_Idle/Fwd, Punch_Jab, Punch_Cross, Melee_Hook, Pistol_Idle_Loop, Pistol_Aim_Neutral/Up/Down, Pistol_Shoot, Pistol_Reload, Hit_Chest, Hit_Head, Hit_Knockback, Death01, LayToIdle(일어나기), Sitting_Enter/Idle_Loop/Talking_Loop/Exit, Idle_Talking_Loop, Idle_FoldArms_Loop, Idle_TalkingPhone_Loop, Consume(먹기·마시기), Interact, PickUp_Table, Yes(끄덕), Slide_Start/Loop/Exit, Sword 콤보 등.

## 게임 연결 (시험판)

- `src/game/action/eileen/three3d.ts`: 몸 그림만 3D, 판정·키는 테스트룸 코어.
- 됨: 무료 동작 38개 옮김(`tools/3d/retarget_ual.py`, `tools/3d/ual_clips.txt`), 원래 속도 재생+섞기, 이동 방향 360° 돌기, 한 번 동작(공격·피격)은 2D 판정 장 진행에 맞춰 재생, 왼쪽을 볼 땐 거울로 그림, 점프 때 동작의 엉덩이 상승 빼기(높이는 게임 z).
- 남은 것: 총 모델, 앞머리·고개 보정, 이펙트 위치를 3D 몸 기준으로, 의자·침대 앉기/눕기 맞춤, 폰 성능.
