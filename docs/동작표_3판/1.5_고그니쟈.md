- **정한 것**:
  - 싸우는 방식: 무술이 없는 미친 과학자. 주먹을 쥐지 않고 **두 팔을 활짝 벌린 「환영」 자세**에서 손바닥·손등·이마·몸통으로 크게 들이댄다. 모든 공격 끝에 두 팔을 다시 벌린다.
  - 콤보: 약1 = 앞팔꿈치 찌르기(가슴 높이, 내디딘 채 끝) → 약2 = 앞어깨 들이받기(한 보폭, 내민 채 끝) → 약3 = 두 손바닥 밀치기(한 보폭) 뒤 두 팔 벌림.
  - 강: 박치기(상체를 크게 뒤로 휘었다가 고글 이마로 내리박기).
  - 돌진: 달리다 두 팔 벌려 와락 끌어안기(덮치기).
  - 점프 공격: 두 무릎 모아 내리찍기.
  - 원거리: 리모컨을 팔 다 펴 겨누고 엄지로 연타(발사는 천장·벽 설비 = 코드).
  - 회피: 뒤 = 무릎 높이 든 만화식 뒷깡총(팔 허우적), 앞 = 상체 수평으로 숙이고 팔을 날개처럼 젖혀 낮게 날아들기.
  - 막기: 실험복 옷깃을 움켜 몸 앞에 여미며 팔뚝 엇갈리기.
  - 고유기술 「비상 장치 가동」: 고글 밀어 올림 → 리모컨 머리 높이로 쳐들고 엄지 꾹 → 허리 젖혀 웃음.
  - 충전 「꽤 깊지!」: 두 팔 들고 오케스트라 지휘 → 방출 = 팔 번쩍 → 바닥에 손가락 내리꽂기 → 젖혀 웃음.
  - 필살기: 손가락 튕김(머리 위) → 한 걸음 비키며 허리 숙여 길 내주기 → 두 손 비비며 웃음 → 두 팔 벌림.
