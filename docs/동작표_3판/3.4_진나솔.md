- **정한 것** (작업자 결정 2026-10-25):
  - 전투 자세: 옆으로 서서 두 발을 어깨너비 두 배, 무릎 굽혀 무게는 뒷다리, 상체는 곧고 지루한 얼굴. **앞손은 어깨 높이로 앞으로 내밀어 다섯 손가락을 갈퀴처럼 편 채, 뒷손 두 손가락은 관자놀이에.**

  - 강: **구두 굽 내려찍기**(앞다리를 곧게 머리 높이까지 들어 올렸다가 굽을 바닥 앞까지 내림, 깊이 앉으며).
  - 돌진: **밀어 차기**(달리던 몸을 세워 앞발 바닥으로 배 높이를 곧게 밀어 차고 뒷발로 미끄러져 섬, 「부하를 차서 밀어내기」).
  - 점프 공격: **두 손 갈퀴 내려 긋기**(공중에서 두 손을 머리 위 앞에서 허리 앞까지 끌어내림).
  - 원거리: **손톱 쏘기**(앞손을 반대 어깨로 감았다 어깨 높이로 곧게 뻗으며 손가락을 활짝, 손목만 탁. 두 번. 실·손톱은 코드).
  - 회피: 뒤 = **두 무릎을 당겨 낮고 길게 뒤로 뜀, 한 손으로 바닥을 짚고 쪼그려 미끄러지며 착지**. 앞 = **앞어깨로 낮게 앞구르기, 한 무릎으로 일어남**. 막기 = **두 팔뚝을 얼굴 앞에서 X로 엇걸고 손가락을 편 가드**, 무릎 깊이.
  - 고유기술 「당기기」 = 앞손을 곧게 뻗어 손가락을 활짝(손톱 쏘기) → 편 손을 든 채 → 주먹을 쥐며 허리로 확 당기고 뒷발로 반걸음 물러남 → 손을 들어 손톱 끝을 들여다봄. 충전 「외알 안경」 = 무릎을 낮추고 뒷손으로 관자놀이를 누르며 앞손 두 손가락을 눈가에 대는 손짓. 방출 = 눈가의 손을 앞으로 곧게 뻗어 검지로 가리킴 → 전투 자세. 필살기 「퇴근」 = 두 손을 앞으로 뻗어 열 손가락을 활짝 → 한 팔을 머리 위로 뻗어 매달린 채 무릎을 당기고 앞으로 그네 → 웅크려 착지, 검지 하나를 까딱 당김 → 왼손목을 들어 시계를 봄.
