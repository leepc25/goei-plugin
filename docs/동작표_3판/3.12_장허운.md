- **정한 것** (작업자 결정 2026-10-25):

  - 고유기술 「막아 서기」 = 웅크렸다 한 보폭 뛰어들어 넓게 착지하며 **등을 처음으로 곧게 펴고** 가슴을 내밂, 앞팔뚝은 얼굴 앞 세로, 뒷팔은 손 펴서 멀리 뒤로. 충전 「매뉴얼대로」 = 뒷무릎을 꿇고 등을 숙여 두 팔을 엉덩이 뒤로(업을 준비), 입만 중얼. 방출 = 두 팔을 등 뒤로 건 채 등을 곧게 펴고 일어섬 → 짧은 끄덕 → 전투 자세. 필살기 「사람으로 대할 것」 = 끄덕 → 앞손이 저절로 떨며 올라옴 → 주먹으로 자기 가슴 → 두 팔뚝을 앞에 대고 세 걸음 밀고 나감 → 전투 자세.
