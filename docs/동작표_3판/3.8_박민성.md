  - 강: **씨름꾼 디딤 손바닥**(앞발을 들었다 쿵 디디며 뒷손바닥을 가슴 높이로 다 내밂).
  - 돌진: **팔뚝 방패 들이받기**(두 팔뚝을 얼굴 앞에 붙여 세우고 머리를 숙여 들이받은 뒤 미끄러져 멈춤).
