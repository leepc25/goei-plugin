- **정한 것** (작업자 결정 2026-10-25):
  - 전투 자세: 옆으로 서서 뒷발에 무게를 두고 무릎을 낮춘 채 상체를 웅크리고 어깨를 올림, 뒷손은 재킷 안 가슴에 숨기고 앞손은 엉덩이 앞 낮게 손가락을 벌림, 비웃는 얼굴(언제든 도망칠 자세).

  - 강: **발목 낚아채기**(몸을 바닥 가까이 숙여 두 손을 앞 발목 높이로 뻗어 움켜쥐고, 뒤로 주저앉듯 허리까지 홱 당김 → 전투 자세).
  - 돌진: **무릎 높이 어깨 태클**(달려들며 몸을 무릎 높이까지 숙여 앞어깨로 들이받고 튕겨 웅크려 멈춤).
  - 점프 공격: **두 발 짓밟기**(공중에서 두 무릎을 가슴으로 당겼다 두 발바닥을 아래 앞으로 곧게 내리뻗음, 덕트에서 떨어지듯).
  - 원거리: **숨긴 물건 내던지기**(재킷 안 가슴에서 뒷손을 빼며 옆팔로 가슴 높이 앞으로 던짐, 런지). 무기 없음.
  - 회피: 뒤 = **두 발 모아 뒤로 깡충**(염소처럼 두 무릎 들고, 두 손은 얼굴 앞). 앞 = **바닥에 붙어 파고들기**(가슴을 무릎 높이로 낮춰 한 손으로 바닥을 쓸며 앞으로 미끄러지듯 뛰어듦). 막기 = **머리 감싸고 웅크리기**(두 팔뚝으로 머리를 감싸고 뒷어깨를 올려 웅크림, 이 악문 얼굴).
  - 고유기술 「미끼」 = 재킷 안에서 작은 물건을 꺼내 앞 아래로 툭 던짐 → 한 발 물러나 몸을 낮추며 히죽. 충전 「역안」 = 몸을 웅크리고 앞손 손가락으로 안대 끝을 들어 올림(유지) → 방출 = 안대를 내리며 상체를 펴고 고개 젖혀 비웃음. 필살기 「추가 지급」 = 손가락 동그라미 + 재킷 앞섶 열기 → 물건 두 번 던져 줌 → 위로 뛰어 매달림 → 두 발로 내리찍기.
