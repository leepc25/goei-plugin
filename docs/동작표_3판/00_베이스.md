# 동작표 3판 · 베이스

2026-10-25 · 에일린(`docs/동작표/1.4_에일린.md`)을 끝까지 뽑고 사용자 판정을 받은 결과로 만든 베이스다. 옛 동작표(`docs/동작표/`의 다른 인물 파일, 보기 화면 HTML)는 에일린 전 형식이라 쓰지 않는다. 요원 파일은 빈 틀만 있고, **한 명씩 만들 때마다 채운다.**

## 0. 에일린에서 배운 것

### 0-1. 첫 기준: 액션성과 역동성

모든 줄이 **액션 게임(격투·벨트스크롤) 스프라이트**처럼 보여야 한다. 사실적인 사람 동작, 꼿꼿이 서서 팔만 까딱이는 「건강체조」는 실패다.

- **공격 4박자**: 크게 준비(무게를 뒤로, 몸을 감기) → 온몸으로 뻗기 → 다 뻗은 정점을 분명한 한 장으로 → 반동과 뒤따름을 크게.
- **온몸을 쓴다**: 두 발 넓게(어깨너비 두 배쯤), 엉덩이 낮추기, 앞무릎 깊이, 뒷다리 펴기, 뒤꿈치 들기, 허리 비틀기, 어깨 깊이 넣기, 상체 싣기. 「한 보폭」, 「팔 다 펴기」, 「허리 끝까지」처럼 끝까지 가게 쓴다.
- **과장한다**: 장마다 실루엣(폭·높이)이 확 달라야 한다. 폭이 그대로면 실패.
- **모든 줄이 그렇다**:
  - 뛰기는 두 발이 다 뜬다. 점프는 깊이 웅크렸다 튀고, 착지는 받아 낸다.
  - 회피는 두 발이 뜨게 뛰어 물러나거나 파고든다. 막기는 깊이 낮추고 앞으로 기울인다.
  - 맞기는 휘청이고, 쓰러지기는 날아가고, 일어나기는 튀어 오른다.
  - 스턴·슬라이딩은 격투 게임 방식으로 한다.
  - 전투 대기도 들썩인다.
- **따라오는 움직임**: 머리카락·옷자락이 몸을 따라 날린다.
- **감정·생활 동작**: 크기 대신 읽히는 자세로 쓴다. 표정 + 맞는 부위 하나를 분명하게 하고, 필요하면 정점에서 잠깐 멈춘다.
- **타격감 = 그림 + 코드**: 그림은 정점을 분명히, 코드는 맞았을 때만 멈춤·경직·흔들림으로 「묵직하게 퉁」. 딜레이를 너무 줄이지 않는다.

### 0-2. 인물마다 먼저 정할 것

- **몸동작 근거**: 위키·기술안·옛 설계에서 문장을 인용해 그 인물만의 싸우는 방식을 정한다(에일린: 「군더더기 없음」 → 주먹 없음, 떼어내기, 뒤로 피하기). PixelLab 예문은 형식 참고일 뿐 인물 차이를 만들어 주지 않는다.
- **콤보 흐름·강공격·회피 방식·기술·필살기**: 사용자와 정하고 표에 옮긴 뒤에 쓴다. 대화로 정한 것을 표에 안 옮기고 뽑으면 틀린다.
- **무기**: 긴 무기는 256px 캔버스 밖으로 잘린다 → 짧은 무기로(에일린 소총 → 기관단총). 바꿀 수 없으면 사용자에게 묻는다.
- **방향**: 옆(E 또는 W)과 비스듬(SE 또는 SW)을 등록 그림을 보고 고른다. 비스듬 줄의 장은 옆 줄의 시작 장으로 못 쓴다.

### 0-3. 기준 장 사슬

- **전투 자세 잡기(3-0)·무기 꺼내기(W)**: 끝 장 없이 뽑고, 사용자가 고른 장이 「전투 자세 장」·「무기 자세 장」이 된다. 거의 모든 줄의 시작 장이라 **사용자 확인 전에는 여기서 시작하는 줄을 뽑지 않는다.**
- **무기는 맨손에서 생기게 하지 않는다**: 무기를 쓰는 줄은 무기 자세 장에서 시작하고 끝난다.
- **콤보**: 약1·약2는 뻗은 자세로 끝나고 그 장이 다음 약의 시작 장. 글은 「앞 손을 거두며 다음 손·발이 나감」부터 쓴다. 약3·강은 전투 자세 장으로 끝난다.
- **중간 장에서 이어 뽑기**: 점프 공격은 방향 점프의 꼭대기 장에서 시작하고 끝 장 없음(떨어뜨리기는 코드). 달리다 점프·돌진 공격은 뛰기 한 장에서 시작.
- **되돌아가는 동작은 거꾸로 틀기**: 일어서기 등은 새로 뽑지 않는다. 끝 장을 다음 줄의 시작 장으로 맞춘다(주저앉기 → 뒤로 기어나가기, 웅크려 떨기 → 네발로 기기).
- **반복 줄 나누기**: 반복되게 그려지지 않는 동작은 시작 줄 + 반복 줄. 반복 줄은 「첫 장 유지」를 켜고 같은 장으로 닫고, 「자세는 고정, 팔다리만 움직임」으로 쓴다.

### 0-4. 칸과 옵션 (PixMiniMax 커스텀)

| 칸 | 쓰는 것 |
| --- | --- |
| Subject | 외모 명사구 하나 |
| Starting pose | 2장 자세 이름 그대로. 발 위치(앞발·뒷발, 벌린 폭), 몸 방향, 무릎, 두 손 높이 필수. compact 같은 크기 말 금지 |
| 시작 장 | 표의 「시작 장」 그림 |
| 끝 장 | 표에 있으면 **반드시** 넣는다(빠지면 직립으로 끝남). 없으면 비움 |
| 움직임 | 움직임만. 외모·자세·방향·장소 금지 |
| Enhance prompt | 끔 |
| No background | 켬 |
| Keep first frame | 끔. 반복 줄만 켬 |

### 0-5. 움직임 문장

1. **한 줄에 큰 동작 1~2개.** 4장 = 1~2단계, 8장 = 3단계, 12장 = 4단계까지. 생성기는 가장 눈에 띄는 단계만 그린다.
2. **명령형 동사를 재생 순서대로**, 두세 문장.
3. **어느 부위가 · 어디로 · 얼마나**: 앞손·뒷손·앞발, 턱·가슴·허리 높이, 한 걸음·손바닥 하나. 「낮게·높게·크게」에도 기준을 붙인다(무릎 높이, 머리 위).
4. **끝은 끝 장 자세 이름으로** 쓴다. 「돌아온다」 금지.
5. **시작 상태를 밝힌다**: 「선 데서 시작」(안 쓰면 처음부터 웅크림).
6. **전문 용어 대신 몸 위치**: butt strike → 「총 뒤끝으로 앞을 친다」.
7. **대기도 반복 움직임 하나**를 시킨다(「가만히」는 네 장이 같음). 걷기·뛰기도 「제자리에서」 글로 쓴다. 실제 이동은 코드.

### 0-6. 빼야 하는 말

- **장면·물건 이름**: 그것까지 그린다(샤워 부스, 욕조).
- **이펙트**: 불꽃·빛·총알·연기·궤적. `hit`은 피격 이펙트를, `wide arc`는 궤적선을 부른다. 그림 안 이펙트는 256px에서 잘린다.
- **꾸밈말·상태 단어·부정문**: sharp, fluid, calm, dazed, without, no ….
- **128px에서 안 보이는 것**: 눈, 입꼬리, 한숨, 깍지, 장전 손잡이, 눈만 훑기. 안 보이면 몸을 엉뚱하게 돌린다. 예외: 맞기·쓰러지기·스턴은 아픈 표정을 쓴다.
- **몸 전체 회전 말**: 팽이처럼 돈다. 비스듬 줄에서 몸을 앞으로 돌리는 말도 뺀다. 스턴은 「발 고정」을 써야 셔플댄스가 안 된다.

### 0-7. 장 수 · 크기

- 공격·회피·피격 **8장**. 점프 공격 4장. 천천히 변하는 동작(주저앉기·기기·쓰러져 누워 숨)은 12장 + 「천천히, 점점」. 필살기 12장.
- 감정·대화는 4~8장, 표정 + 몸 한 군데만(크게 쓰면 끄덕임이 목례, 고개 젓기가 몸통 도리도리).
- 비슷한 줄은 달라 보이게(원거리 = 어깨 조준, 제압사격 = 허리춤 난사).
- 눕거나 기는 줄은 방향이 틀어지기 쉽다 → 방향 시험, 「머리와 발이 같은 높이, 땅과 일직선」.
- 비용: 8장까지 1회, 넘으면 2회. 다시 뽑기는 따로.

### 0-8. 그림이 아니라 코드가 하는 것

이동 거리, 떨어뜨리기, 거꾸로 틀기, 반복 구간, 히트스톱·경직·흔들림, 총알·불꽃 아닌 이펙트(PixelLab VFX), 총구·발 위치 계산. 총 불꽃은 그림에 그려진 것만 쓰고 덧붙이지 않는다. 몸 둘레 오라 금지.

### 0-9. 작업 순서

1. 사용자와 정한 것을 표에 옮긴다(몸동작 근거, 콤보·회피·기술, 시작 장 → 끝 장).
2. 줄마다 PixelLab 예문을 받는다(`/enhance-animation-v3-prompt`, 0.05회).
3. 0-1~0-7 기준으로 다듬는다.
4. **묻지 않고** 비교표(결정 / 적은 것 / 맞음)와 예문을 보이고 비용을 말한다.
5. 사용자가 시키면 뽑는다. 3-0·W를 먼저 뽑아 기준 장을 확인받는다.
6. 사용자가 판정한다. 지적한 줄만 다시 쓰고, 다시 뽑으면 이전 판은 지운다.
7. 테스트룸에서 움직여 보고 판정. 위치·각도는 확대 스크린샷에 점·선을 찍어 확인한 뒤 보고.
8. 결과물은 생길 때마다 작업 브랜치에 커밋·push. 동작은 번호가 아니라 이름으로 부른다.

## 1. 인물 파일 형식

머리(위에서 아래로):

- 번호·이름, 상태(빈 틀 / 쓰는 중 / 확인 / 뽑음 / 완료), 생성 회수
- 소속 · 요원 색 · 무기(있음·없음, 무엇)
- PixelLab id
- 방향: 옆 / 비스듬
- Subject
- 몸동작 근거(인용)
- 정한 것: 콤보 흐름, 강공격, 회피 방식, 기술, 필살기

이어서 2장 자세 이름, 3장 줄 목록 순서의 표:

| # | 동작 | 방향 | 장 | 시작 장 → 끝 장 | Starting pose | 프롬프트 (영어 입력 · 아래 한글 번역) | 회수 | 메모 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |

메모 칸에는 사용자 판정과 고친 까닭을 회차마다 적는다.

## 2. 자세 이름 (인물마다 채움)

- **등록 옆**: `standing upright facing <옆>, feet together, arms relaxed at the sides`
- **등록 비스듬**: `standing upright facing <비스듬>, feet together, arms relaxed at the sides`
- **전투 자세 장** (3-0 결과에서 사용자가 고른 장): 발·몸 방향·무릎·두 손 높이로
- **무기 자세 장** (W 결과에서 사용자가 고른 장): 위 + 무기를 어떻게 들었는지, 총구 방향
