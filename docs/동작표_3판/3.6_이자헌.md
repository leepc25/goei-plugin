  - 위키 「회식에서 소고기를 굽는 속도가 일정해서 "조장님 타이머"」, 「날짜와 시간을 정확히」 → 개인 대기는 손목시계 보기 + 넥타이 바로잡기, 섭취는 일정한 박자로 세 번 씹기.

- **정한 것** (작업자 결정 2026-10-25):
  - 전투 자세: 옆으로 서서 앞발 길게·발 폭 어깨너비 두 배, 무릎 깊이 굽힘, **등은 수직으로 곧게, 턱 수평, 무표정**, 앞손은 편 손(손바닥 아래)으로 가슴 높이 앞, 뒷주먹은 허리에 당김(잡는 손 + 장전한 주먹).
  - 콤보: 약1 **앞손 움켜잡기**(앞손을 편 채 머리 높이로 깊은 런지와 함께 다 뻗어 쥐고 끝) → 약2 **끌어당기며 뒷주먹**(쥔 앞손을 허리로 끌어당기며 뒷주먹을 가슴 높이로 다 뻗음, 뒷발 돌리기·허리 비틀기) → 약3 **아래서 위로 뒷주먹 올려치기**(무릎 높이에서 머리 위까지 온몸을 펴며 발끝으로 섬 → 전투 자세).
  - 강: **문짝 뜯기**(두 손을 가슴 높이로 뻗어 잡고 상체를 뒤로 젖히며 두 손을 뒷어깨 위까지 확 끌어당김).
  - 돌진: **팔뚝 빗장**(달리던 몸으로 앞팔을 목 높이로 곧게 앞으로 내밀어 막대처럼 걸고 지나가며 미끄러져 멈춤).
  - 점프 공격: **두 주먹 맞잡아 내리기**(공중에서 맞잡은 두 주먹을 머리 위에서 허리 앞 아래까지).
  - 원거리: 앞손에 버터나이프를 든 채 **뒷손으로 크게 던지기**(뒷손을 머리 뒤로 젖혔다 긴 디딤과 함께 앞으로 다 뻗음. 던지는 고정물 조각은 코드).
  - 회피: 뒤 = **꼿꼿한 상체 그대로 두 발 떠서 뒤로 한 번 길게 뛰고 무릎 굽혀 미끄러지며 착지**, 앞손은 앞에 그대로. 앞 = **무릎을 깊이 굽혀 머리를 어깨 아래로 낮추고 앞팔뚝을 머리 위로 든 채 앞으로 낮게 뛰어 파고듦**. 막기 = **앞팔뚝 하나를 얼굴 앞에 세우고 뒷주먹은 허리에 그대로**, 무릎 깊이·앞으로 기움(한 팔로 받는 겁 없는 막기).
  - 고유기술 「버터나이프 틈」 = 버터나이프를 머리 위에서 허리까지 세로로 내림 → 빈손 손가락을 그 앞 허공에 넣어 옆으로 벌림 → 붙잡아 허리 뒤까지 끌어냄. 충전 「손잡이 한 방」 = 꼿꼿이 선 채 뒷주먹만 천천히 등 뒤로 당김 → 방출 = 긴 런지로 뒷주먹을 가슴 높이로 다 뻗음. 필살기 「물리 퇴마」 = 정확한 두 걸음 → 앞손으로 머리 높이를 잡아 들어 올림 → 뒷주먹을 두 번 내지름 → 놓고 소매 끝을 바로잡음.
