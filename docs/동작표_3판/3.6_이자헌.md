- **정한 것** (작업자 결정 2026-10-25):
  - 전투 자세: 옆으로 서서 앞발 길게·발 폭 어깨너비 두 배, 무릎 깊이 굽힘, **등은 수직으로 곧게, 턱 수평, 무표정**, 앞손은 편 손(손바닥 아래)으로 가슴 높이 앞, 뒷주먹은 허리에 당김(잡는 손 + 장전한 주먹).

  - 강: **문짝 뜯기**(두 손을 머리 높이로 들어 움켜쥐고 아주 깊은 스쿼트로 두 주먹을 앞무릎까지 끌어내림. 처음의 「뒤로 젖혀 뒷어깨 위로 뜯기」는 2회 실패로 바꿈).
  - 돌진: **팔뚝 빗장**(달리던 몸으로 앞팔을 목 높이로 곧게 앞으로 내밀어 막대처럼 걸고 지나가며 미끄러져 멈춤).
  - 점프 공격: **공중 팔꿈치 내리꽂기**(상체를 앞아래로 숙이며 앞팔꿈치를 아래로. 처음의 「두 주먹 맞잡아 내리기」는 2회 실패로 바꿈).
  - 원거리: 앞손에 버터나이프를 든 채 **뒷손으로 크게 던지기**(뒷손을 머리 뒤로 젖혔다 긴 디딤과 함께 앞으로 다 뻗음. 던지는 고정물 조각은 코드).
  - 회피: 뒤 = **꼿꼿한 상체 그대로 두 발 떠서 뒤로 한 번 길게 뛰고 무릎 굽혀 미끄러지며 착지**, 앞손은 앞에 그대로. 앞 = **무릎을 깊이 굽혀 머리를 어깨 아래로 낮추고 앞팔뚝을 머리 위로 든 채 앞으로 낮게 뛰어 파고듦**. 막기 = **앞팔뚝 하나를 얼굴 앞에 세우고 뒷주먹은 허리에 그대로**, 무릎 깊이·앞으로 기움(한 팔로 받는 겁 없는 막기).
  - 고유기술 「버터나이프 틈」 = 버터나이프를 머리 위에서 허리까지 세로로 내림 → 빈손 손가락을 그 앞 허공에 넣어 옆으로 벌림 → 붙잡아 허리 뒤까지 끌어냄. 충전 「손잡이 한 방」 = 꼿꼿이 선 채 뒷주먹만 천천히 등 뒤로 당김 → 방출 = 긴 런지로 뒷주먹을 가슴 높이로 다 뻗음. 필살기 「물리 퇴마」 = 정확한 두 걸음 → 앞손으로 머리 높이를 잡아 들어 올림 → 뒷주먹을 두 번 내지름 → 놓고 소매 끝을 바로잡음.

## 테스트룸

- 반복 구간: 평상 대기 1·2·4장(3·5장이 동쪽으로 조금 돎) · 전투 대기 1~4장 · 무기 대기 1~4장 · 걷기 1~7장 · 뛰기 1~8장(뛰기 한 장 = 3장) · 도망 2~8장 · 뒷걸음질 반복 1~8장 · 엎드려 기기 반복 1~8장 · 네발로 기기 반복 1~8장 · 주저앉아 뒤로 기어나가기 1~8장 · 쓰러지기 끝 9~12장 · 스턴 3~8장 · 웅크려 떨기 3~8장 · 주저앉기 8~12장.
- 타격 장: 약1 6장(편 손 다 뻗어 움켜쥠) · 약2 3장(뒷주먹 다 뻗음, 첫 장이 약1 끝과 어긋남 → 2장부터) · 약3 5장(머리 위 올려치기) · 강 3장(두 주먹을 무릎까지 끌어내린 첫 장) · 돌진 3장(앞팔 막대) · 점프 공격 1~4장 전부(떨어뜨리며 착지 때 판정) · 원거리 4장(뒷팔 다 뻗음, 이때 던진 조각 생성) · 충전 방출 1장 · 필살기 3~5장 잡아 들기 + 8장 내지르기(두 번째 타는 8장 다시) · 고유기술 3~5장(틈 생성).
- 손 위치가 필요한 줄: 원거리(뒷손 끝에서 조각 출발), 고유기술(칼 끝 = 틈 위치, 빈손 = 끌림 위치), 필살기(앞손 = 잡은 적 머리).
- 고유기술 「버터나이프 틈」: 1~2장 칼을 머리 위로 → 3장부터 몸 앞에 GPT `fx_이자헌_공간틈`(세로 틈, 안쪽 검보라) 6장을 칼 끝 높이로 열고, 5장에서 숨은 적을 앞으로 끌어내 다운.
- 충전 「손잡이 한 방」: 충전 모으기 8장 유지 동안 슈퍼아머, 기운은 그리지 않음. 1단 방출 = 충전 방출 줄 + 공용 `fx_공용_타격_강`, 적 크게 날림. 2단 = 강(철문 뜯기) 1~3장을 「뜯기」로 쓰고 원거리 줄로 던짐: 뜯긴 고정물은 방 배경 조각 또는 `fx_이자헌_문짝` 회전 4장.
- 필살기 「물리 퇴마」: 1~2장 걸음 동안 코드로 대상까지 이동(무적, 길의 작은 적은 밀어냄) → 3~5장 잡아 들어 올림(대상도 들어 올림) → 7~10장 내지르기 × 2 + 강 3장 재사용으로 6타 → 11장에서 놓음(12장은 번진 겹침이라 버림). `fx_공용_타격_강` 연속, 영체 적은 흰 연기 도트가 찢겨 흩어짐. 컷인 이스터에그는 기술안 그대로.
- 일어나기는 2회차 판 사용. 쓰러지기 끝 장의 머리는 서쪽.
