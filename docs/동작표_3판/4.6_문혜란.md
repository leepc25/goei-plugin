- 몸동작 근거:
  - 위키 「키가 크고 팔다리가 길쭉하다. 느슨하게 어깨를 흔들며 걷는 여유로운 걸음걸이 … 이 여유가 계산된 것」 → 긴 팔다리를 끝까지 쓰는 공격(긴 다리 밀어차기·다리 걸기), 걷기는 어깨를 흔드는 느긋한 긴 보폭.
  - 위키 「목소리가 크고, 연극적으로 친근하다. 반문을 섞어 말하고 등을 팡팡 친다. 거절할 때도 웃는다」 → 약1 = 손바닥으로 어깨 팡(「친구!」), 전투 자세 앞손은 손바닥을 위로 편 「앉아, 앉아」 손. 감정 줄은 크게 웃는 얼굴.
  - 위키 「시계를 딱 한 번 톡 두드리는 버릇 … 시간이 흐르고 있다는 걸 들려주고 싶을 때만」 → 개인 대기(시계 흘끗)와 충전(시계 보여 주기) → 방출(톡 + 「앉아」).
  - 위키 「허리 뒤에는 짧은 접이식 진압봉」, 기술안 「소파에서 행패를 부리던 손님이 몇 초 만에 바닥에 엎드려 … "어이, 친구, 바닥 차갑지? 일어나서 사인부터 하자."」 → 약3 = 다리 걸어 쓸기, 고유기술 = 진압봉 2연타 + 다리 걸기 + 내려다보며 웃음.
  - 위키 「5년 동안 직접 현장을 뛰었다」 → 막싸움에 익숙한 실전형: 턱 옆 뒷주먹, 래리어트 돌진, 구둣굽 내리찍기.
  - 기술안 4.6 필살기 「재킷 안쪽에서 표시된 카드 한 벌을 꺼내 부채처럼 폄 → 카드 세 장을 날림 → 크게 휘두름」.
- **정한 것** (작업자 결정 2026-10-25):
  - 전투 자세: 옆으로, 긴 다리를 앞뒤로 어깨너비 두 배 벌리고 두 무릎 굽혀 낮춤, 무게는 뒷다리(느긋한 짝다리 기운). 뒷손은 주먹 쥐어 턱 옆, 앞손은 손바닥을 위로 펴 허리 높이로 내밂(「앉아, 앉아」), 웃는 얼굴.
  - 콤보: 약1 **손바닥 어깨 팡**(앞손을 귀 높이로 들었다 상대 어깨 높이로 손바닥을 내림, 깊은 런지) → 약2 **뒷손 손바닥 턱 올려치기**(앞손 거두며 뒷손 손바닥 뿌리를 허리에서 턱 높이로 밀어 올림, 뒷발 돌리기) → 약3 **다리 걸어 쓸기**(앞다리를 낮게 발목 높이로 쓸어 당기고 전투 자세).
  - 강: **긴 다리 밀어차기 「문 밖으로」**(앞무릎을 가슴까지 접어 올렸다 구두 밑창을 가슴 높이로 다리 끝까지 밀어 뻗음, 상체 뒤로).
  - 돌진: **래리어트**(달려와 앞팔을 곧게 뻗어 팔뚝을 목 높이로 걸며 한 보폭 깊은 런지).
  - 점프 공격: **구둣굽 내리찍기**(공중에서 앞다리를 아래 앞으로 곧게 뻗어 굽을 내밀고 두 팔을 뒤로, 끝까지 공중).
  - 원거리: **카드 던지기**(진압봉은 앞손에 든 채, 뒷손을 재킷 안 가슴에서 어깨 높이 앞으로 쭉 뻗어 던짐. 카드는 코드).
  - 회피: 뒤 = **두 손바닥을 앞으로 펴 「진정해」 하며 두 발로 뒤로 깡충**(웃는 얼굴). 앞 = **상체를 뒤로 크게 젖히고 무릎 굽혀 앞으로 미끄러져 들어감**(림보처럼, 긴 다리). 막기 = **두 팔뚝을 가슴 앞에서 엇갈려 겹치고 깊이 낮춰 어깨를 앞으로**.
  - 맞기: 턱 맞고 고개가 뒤로 젖혀지며 반걸음 휘청, 한 손으로 턱을 짚음. 쓰러지기: 뒤로 날아가 등으로 떨어져 미끄러짐.
  - 고유기술 「진압봉」 = 진압봉을 위에서 아래 → 아래에서 위 두 번, 앞다리로 발목 걸기, 내려다보며 웃음. 충전 「시계 한 번 톡」 = 짝다리로 기대듯 서서 왼손목 시계를 가슴 높이로 앞으로 내보이며 웃음(유지). 방출 = 검지로 시계를 한 번 톡 → 손바닥을 아래로 펴 허리 높이로 내리누름(「앉아」). 필살기 「대박알선 뒷방」 = 뒷손으로 재킷 안에서 카드를 꺼내 가슴 앞에 펼침 → 어깨 높이로 앞으로 뻗어 던짐 → 진압봉을 머리 뒤에서 앞 무릎 높이까지 크게 내림.
