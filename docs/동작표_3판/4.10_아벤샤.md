- 몸동작 근거:
  - 위키 「손짓 한 번에 모래로 바꿔 버리는 일급 전투 마녀」 → **주먹·발차기 없음.** 근접도 몸이 닿지 않는 손짓(손등 털기·손바닥 밀기·손바닥 뒤집어 올리기)을 온몸 디딤으로 크게.
  - 위키 「동화책 속 마녀가 정장을 입고 걸어 나온 것 같았다」, 「낡고 수수한 짙은 보랏빛 후드 망토 … 에메랄드 브로치 하나로 여민다」, 「망토를 벗는 걸 본 사람은 없다」 → **망토가 무기이자 방패.** 강공격 = 망토 자락 내던지기, 막기·회피·충전 방출 = 망토로 감싸기. 뒷손은 늘 브로치(맞기도 브로치부터 감쌈).

  - 위키 「위로는 비굴할 만큼 아부하고」, 「땅을 기는 미천한 애벌레」, 「감격하면 … 비명 같은 환호」 → 응대 = 망토 자락 들고 한 발 빼 깊이 숙이는 마녀식 인사, 기뻐하기 = 손을 뺨에 대고 발돋움.
  - 위키 「살아 있는 성기사는 진심으로 무서워한다」, 「도망칠 일을 미리 대비하는 성격」 → 겁 동작(뒷걸음질·웅크려 떨기·도망)은 망토를 몸에 여미고 숨는 몸.
  - 기술안 4.10 몸동작 그대로(크게): 모래 탄환 = 망토 자락을 젖히며 손을 앞으로, 손가락 세 번 튕김 / 흐르는 모래 = 손바닥 아래로 펴고 망토가 위로 → 망토로 감싸 웅크림 → 펼치며 일어섬 / 모래 해일 = 브로치 쥐고 망토 휘두름 → 두 팔 올림 → 앞으로 내리꽂음 → 손 뻗은 자세.
- **정한 것** (작업자 결정 2026-10-25):
  - 전투 자세: 옆으로 서서 발을 넓게 벌리고 앞무릎을 굽혀 상체를 조금 앞으로. **뒷손은 허리에 얹고**(3-0 결과대로), 앞팔은 가슴 높이로 앞에 내밀어 손바닥을 아래로, 손가락을 느슨하게 늘어뜨린 마녀 손. 망토는 뒤로 펼쳐짐.
  - 콤보: 약1 **손등 털기**(앞손을 반대 어깨까지 감았다가 깊은 디딤과 함께 손등으로 가슴 높이 바깥 앞으로 쓸어 다 뻗음) → 약2 **손바닥 밀기**(앞손을 거두며 허리의 뒷손을 떼어 허리를 비틀고 뒷발 뒤꿈치를 돌려 뒷손바닥을 가슴 높이 정면에 다 뻗음) → 약3 **손바닥 뒤집어 올리기**(두 손을 무릎 높이로 낮췄다가 손바닥을 위로 뒤집어 턱 높이까지 퍼 올리며 앞발 뒤꿈치까지 듦 = 모래 기둥 → 전투 자세).
  - 강: **망토 내던지기**(앞손으로 망토 자락을 쥐고 뒤로 감았다가 깊은 런지로 몸 앞으로 넓게 내던져 펼침 → 거둬 전투 자세).
  - 돌진: **낮게 미끄러지는 손 쓸기**(달리던 몸을 깊은 런지로 낮춰 미끄러지며 앞손을 정강이 높이에서 앞으로 쓸어 냄, 망토가 뒤로 흐름).
  - 점프 공격: **공중 손바닥 내리꽂기**(다리 모아 발끝을 펴고 앞손바닥을 앞 아래로 다 뻗은 채 끝까지 공중).
  - 원거리: **손바닥 불기**(앞손바닥을 위로 해 턱 앞에 모았다가 앞으로 어깨 높이까지 쭉 내밀며 손가락을 편다, 두 번). W-1은 앞손바닥을 위로 해 가슴 높이에 내민 겨눔 대기.
  - 회피: 뒤 = **망토 두르고 뒤로 뜀**(앞팔로 망토를 몸 앞에 감싸며 두 발로 뒤로 낮게 뜀 → 망토를 걷으며 전투 자세). 앞 = **낮게 미끄러지는 앞 도약**(상체를 숙이고 두 다리를 모아 두 발이 뜬 채 앞으로 길게, 망토가 뒤로 흐름). 막기 = **망토 방패**(앞팔로 망토 자락을 몸 앞에 끌어와 얼굴 높이까지 가리고 무릎을 깊이 굽혀 앞으로 기울임).
  - 고유기술 「모래 탄환」 = 앞팔로 망토 자락을 뒤로 젖히고 깊은 디딤과 함께 앞손을 어깨 높이로 뻗어 손가락을 세 번 튕기듯 폄. 충전 「흐르는 모래」 = 무릎을 굽히고 두 손바닥을 아래로 허리 높이 앞뒤로 펴서 망토가 아랫단부터 들림. 방출 = 망토를 몸에 휘감고 낮게 웅크림 → 망토를 펼치며 일어섬. 필살기 「모래 해일」 = 브로치를 쥐고 망토를 휘두름 → 두 손을 어깨 높이로 퍼 올리며 발돋움 → 앞으로 깊이 내리꽂음 → 두 손을 앞으로 뻗은 자세 유지.
