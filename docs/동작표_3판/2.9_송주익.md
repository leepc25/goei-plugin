  - 강: **뛰어오르는 올려베기** — 뒷무릎을 바닥 가까이 낮췄다 앞 위로 튀며 두 손으로 뒤 아래에서 머리 위까지.
  - 돌진: **턱부터 날리는 몸통 다이빙**(맨손, 뛰기 한 장 → 전투 자세 장).

  - 원거리: 제자리 **두 손 수직 내려베기 두 번**(칼날을 허리 높이에서 멈춤, 청록 칼바람은 코드).
  - 회피: 뒤 = 칼을 가슴에 세워 안고 뒤로 멀리 뛰어 **한 무릎·빈손 짚고 미끄러지는 착지**, 앞 = 칼을 붙이고 **앞구르기**. 막기 = 깊이 낮추고 **칼을 머리 위에 가로로** 받침.
  - 고유기술 「시범 베기」 = 내려베기 → 올려베기 → 반 걸음 찌르기, 칼끝 정지에 턱 듦. 충전 「선착 보고」 = 낮게 웅크려 칼을 뒤로 끌고 빈손을 입 옆에 대어 외침 → 방출 = 튕기는 두 걸음 → 멈춰 서서 손을 입 옆에 대고 외침. 필살기 「예카테리나」 = 칼을 얼굴 앞에 세워 속삭임 → 쓰다듬기 → 크게 감았다 수평 휘두름 → 다시 얼굴 앞에 세움(「한 바퀴 돌며」는 팽이가 되므로 뺌).
