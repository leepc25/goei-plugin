- 기준 장: 전투 자세 장 = 3-0 4장, 무기 자세 장 = W 4장(두 손으로 서류철을 가슴 앞에 세워 듦), 뛰기 한 장 = 5번 3장, 방향 점프 꼭대기 장 = 7번 4장, 네발로 기기 한 장 = 42번 10장.

- 손·무기 위치가 필요한 줄: 원거리(15) 서류철 앞끝 = 종이 날림 시작점, 충전(23) 펼친 서류철 면 = `fx_김조학_노트북화면` 얹을 자리(8장 유지), 필살기(25) 펼친 서류철 4~8장 = 파일 창 VFX 기준, 11장 검지 = 경비 호출 방향(뒤쪽).
