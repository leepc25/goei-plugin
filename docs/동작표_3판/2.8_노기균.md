- 정한 것 (작업자 결정 2026-10-25):
  - 싸우는 방식: 맨손일 때는 **앞손을 쭉 내민 「내 손을 잡아라」 자세**(넓고 낮은 자세, 상체 앞으로, 뒷주먹은 허리, 활짝 웃음). 칼을 들면 **칼등을 뒷어깨에 걸치고 앞손을 가슴 앞에 편** 여유 있는 자세에서 군더더기 없이 곧장 들어간다. 모든 칼질은 어깨에서 출발해 어깨로 돌아온다.
  - 콤보: 약1 = 어깨에서 들어 머리 위 → 깊은 런지로 비스듬히 무릎까지 내리베기(낮게 뻗은 채 끝) → 약2 = 칼을 허리로 끌어올리며 뒷발 넘겨 딛고 허리 높이 가로베기(팔 뻗은 채 끝) → 약3 = 엉덩이 옆에 칼을 당겼다 한 보폭 런지로 가슴 높이 곧은 찌르기(「칼끝이 정확하게」) → 어깨
  - 강: 두 손으로 머리 위에 들고 반걸음 뛰어 바닥까지 내리쳐 깊이 웅크림
  - 돌진: 칼을 엉덩이 뒤로 끌고 낮게 달려 들어와 아주 넓은 자세로 허리 높이 가로베기(무기 자세 장에서 시작 — 맨손 뛰기 장에서 칼이 생기지 않게)
  - 점프 공격: 공중에서 두 손으로 머리 위 → 발 아래까지 내리베기
  - 원거리: 두 손으로 칼을 뒷엉덩이 뒤로 크게 감았다 내디디며 어깨 높이 가로로 휘두름(검기 날리기는 코드·VFX)
  - 회피: 뒤 = 공 튀듯 두 발로 뒤로 통통 튀기(튕기는 이동법), 앞 = 상체를 거의 수평으로 숙여 낮고 길게 튀어 들어가기
  - 막기: 깊이 웅크려 칼을 얼굴 앞에 세우고 다른 손바닥으로 칼등을 받침(소총탄 쳐내기)
  - 고유기술 「튕겨 들어가기」 = 낮게 세 번 튕기는 걸음 → 무릎 아래에서 머리 위로 올려벰. 충전 「검증 대련」 = 칼을 앞 위로 겨누고 다른 손가락 까딱 + 활짝 웃음 → 방출 = 고함치며 짧은 베기 4번. 필살기 「수고하십시오!」 = 고함 → 튕기는 큰 걸음 두 번 → 칼 털기 → 경례 → 어깨
