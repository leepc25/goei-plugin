# 스테이지 설계서 · 차원 승강기 (주무대)

문서 버전: 1.0 / 2026-10-20 / Claude / 상태: 사용자 검토 전

사용자 결정(2026-10-20): 게임은 **끝없이 이어지는 메트로배니아**다. 명일 아파트는 "5층에 떨어져 1층으로 나온다"는 끝이 있는 코스라 주무대로 맞지 않고, 차원 승강기는 원문부터 끝없는 수직 공간이라 주무대로 바꾼다. 명일 아파트 설계는 버리지 않고 이 문서 6장의 **재현의 층 「아파트 단지」**로 흡수한다(`스테이지설계서_명일아파트.md`는 그 자료집).

근거: 위키 「차원 승강기」(주머니 차원형 괴담, 끝없는 수직 복합 공간, 층수 세다가 포기, 최저 기록 B-12, 생환자 확인됨). 원문에 없는 수치·적 패턴·귀환 수단은 "게임 설계"라고 적는다. 상위 문서는 `게임_기본기획서.md`(9장이 이 문서를 가리킨다).

## 1. 한 줄과 왜 맞는가

**낡은 건물의 엘리베이터를 탔더니 "띵. 1층입니다." 그런데 로비가 아니다. 패널에는 없던 숫자가 빼곡하다. 내려갈수록 세상이 바뀌고, 층마다 규칙이 다르고, 아무도 미리 알려 주지 않는다.**

원문이 이미 게임의 뼈대를 다 가지고 있다.

| 게임이 필요로 하는 것 | 원문에 있는 것 |
| --- | --- |
| 끝없는 진행 | "끝없는 수직 공간", "층수: 세다가 포기함", 최저 기록 B-12 |
| 층마다 다른 방·규칙 | "층마다 다른 세상, 층마다 다른 규칙", 규칙 하나짜리 층부터 수십 개가 얽힌 층까지 |
| 난이도가 고르지 않은 뽑기 | "쉬운 층 다음에 쉬운 층이 온다는 보장이 전혀 없다" |
| 휴식·파밍·절차 생성의 핑계 | **정비 구역**: 선배들의 메모·지도·보급품·장비, "통로가 몇 분 만에 무너지고 다시 짜인다" |
| 구역 보스 | **층 수호자**: 층마다 그 층에 맞춰 만들어진 것, 자기 층 규칙을 절대적으로 따름 |
| NPC 협력·배신 | **떠도는 승객**: 정보·보급을 주는 사람과 유인·거짓 정보를 파는 사람, "둘 다 친절해 보인다" |
| 해설자·거래 상대 | **승강기**: 하나의 의식, 방송으로 이름과 사적인 사실을 부름, 거래 가능, 인사하면 대우가 달라짐 |
| 장기 목표 | **출구 떡밥**: 위로 올라가면 EXIT·1F·LOBBY 버튼이 뜬다는 증언, 눌러서 나온 사람은 없음 |
| 다른 괴이를 담는 그릇 | **재현의 층**: 병원·학교·지하철역·아파트 단지가 완벽 재현됨 → 명일 아파트, 심연교통공사 등이 층으로 들어옴 |
| 희망 | "탈출한 사람이 확실히 있다" → 관리국이 출동할 명분 |

## 2. 수직 구조

```
          ▲ 위: 출구 떡밥 (EXIT · 1F · LOBBY 버튼) ── 공략 완료 목표
[입구 엘리베이터] ─"띵. 1층입니다"─▶ [로비 층 L1~L3] 평범해 보임, 미묘하게 어긋남, 튜토리얼
                                        │ 승강기가 보여 주는 버튼 중 하나를 고름 (2~3개)
                                        ▼
                                   [지하 B-1] 층 유형 1 ──┐
                                        ▼                 ├─ 정비 구역 (층 사이 수직 미로, 다락방·귀환 로프)
                                   [지하 B-2] 층 유형 2 ──┘
                                        ▼
                                        …
                                   [B-12] 기록된 최저 (완전한 어둠, 만져서 말하는 것들)
                                        ▼
                                   [B-13…] 기록 갱신 (게임 설계: 관리국 기록)
```

- **한 출동 = 입구 엘리베이터 → 로비 → 아래로 n층 → 귀환 로프**(4.3). 위로 되돌아 타는 것은 원문대로 안 된다("원래 건물 층수를 눌러도 엉뚱한 층이 열린다").
- **층 = 벨트스크롤 가로 구간** 하나. 조각(5장) 6~12개를 이어 붙인다. 층 안은 좌우 이동·앞뒤 깊이 3줄.
- **정비 구역 = 층과 층 사이의 세로 구간.** 점검문·천장 해치·승강로 틈새로 들어간다. 덕트·지지대 사이를 기어 오르내리는 작은 미로이고, 여기서 **되돌아가기·지름길·숨은 길**이 생긴다. 메트로배니아의 "뼈대"가 이 수직 구간이고, 층은 거기 붙은 "가지"다.
- **승강기 탑승 = 경로 선택.** 엘리베이터 홀에서 패널에 뜬 버튼 2~3개 중 하나를 고른다. 어느 유형인지는 문이 열리기 전엔 모른다(원문). 단 승객 정보·정비 구역 지도·승강기 총애가 있으면 미리 안다(8장).
- **깊이 = 난이도.** 기본 기획서 8.4의 예산 수식에서 `층 기본값`을 깊이 n이 정한다. 원문 "지하로 한 층 내려갈 때마다 생존 확률이 뚝뚝 떨어진다"가 그대로 수식이다.
- **끝없음.** B-12는 원문의 최저 기록일 뿐 바닥이 아니다. 그 아래는 "관리국 기록 갱신"(게임 설계)이고 유형·수호자·규칙이 겹쳐 쌓인다. 기록은 "최저 도달 층"과 "한 출동 최다 층"으로 남긴다.
- **위로 가는 길 = 공략 완료.** 규칙서를 채우고 승강기의 총애를 얻으면 패널에 EXIT가 뜬다(조건은 7장). 누르면 "진짜 로비"로 나오는 엔딩 연출. 공략 완료 뒤에도 승강기는 남고(원문: 아무도 나온 사람이 없는 떡밥은 "관리국이 처음으로 나왔다"로 게임이 답함) 위험 단계가 열린다. **영원한 공략은 없다**(사용자 2026-10-20): EXIT를 누르면 승강기가 **재편**된다. 규칙서는 공통 10줄 중 일부가 새 줄로 바뀌고(기록한 줄에 취소선), 총애는 0으로, 수호자·층 유형 배치와 떠도는 승객의 진실/거짓이 다시 섞인다. 다음 EXIT 조건은 그 새 규칙서로 다시 채워야 한다. 출동마다도 규칙서의 1~2줄은 '이번 출동에는 다름' 변형이 붙는다.

### 2.1 층 수와 길이 목표

| 항목 | 목표 |
| --- | --- |
| 로비 층 | 3층 (L1 튜토리얼, L2 첫 규칙, L3 첫 수호자). 조각 4~6개, 각 2~3분 |
| 지하 한 층 | 조각 6~12개, 3~5분. 수호자 있는 층은 +1~2분 |
| 정비 구역 한 구간 | 1~2분. 다락방(휴식방) 1개 포함 |
| 한 출동 | 수동 10~20분 = 로비 + 지하 2~4층. 깊이는 플레이어가 정한다(더 내려갈지 로프를 탈지) |
| 유형별 조각 세트 | 12~16개 (유형 6종 → 약 80개), 공용 조각 10개, 고정 방 5개 |

## 3. 층 유형 (원문 5종 + 시험 층)

유형 하나 = 조각 세트 + 규칙 세트 + 수호자 후보 + 사건 목록 + 팔레트·소리. 같은 유형이라도 층마다 세부가 다르다(원문).

| 유형 | 원문 | 게임 플레이 | 규칙 예 (규칙서) | 수호자 후보 | 첫 판 |
| --- | --- | --- | --- | --- | --- |
| **침묵의 층** | 아무 소리도 안 들림, 재채기 한 번에 증언이 끝남 | 소리 게이지. 달리기·총·타격 큰 기술이 소리를 냄. 소리가 차면 수호자 소환. 근접 요원 유리, 총 요원은 소음기(부록 F) 필요 | "소리를 내지 마라" / "속삭임(E 길게)으로만 승객과 말해라" | 소리와 냄새(몸 없는 발소리) | 2판 |
| **어둠의 층** | 빛이 몇 초 만에 사그라듦, 어둠 속에서 체온을 잼 | 시야 원이 줄어듦. 손전등 아이템은 3초만. 적은 보이지 않고 발소리·냄새 파문으로만 표시. 움직임을 멈추면 적이 다가옴(체온) | "멈추지 마라" / "빛을 아껴라" | 그림자 (얼룩 → 진해짐) | 2판 |
| **추격의 층** | 문이 열리는 순간 사냥이 시작 | 자동 스크롤 + 뒤에서 오는 것. 멈추면 죽음. 장애물 점프·앉기·문 닫기(E). 전투보다 이동 기술 시험 | "뒤돌아보지 마라" / "문은 닫고 가라" | 벽과 천장을 기는 다리 많은 것 | **1판** |
| **퍼즐과 선택의 층** | 과제를 풀어야 문이 열림, 시간 넘기면 악화, 구별 못 하는 두 갈래 | 과제 방(스위치·순서·운반) + 시간 압박(벽 조여 옴) + 두 갈래 문(단서 없으면 운, 승객 정보·규칙서·승강기 총애로 단서) | "표지를 읽어라" / "두 번째 문은 열지 마라" | 불가능한 입체 도형 (보면 멀미 = 조작 반전) | 2판 |
| **재현의 층** | 병원·학교·지하철역·아파트 단지가 완벽 재현, 평범해 보이는 것들이 특정 행동에 적대적으로 변함 | **다른 괴이를 담는 층.** 장소마다 하위 세트. 첫 세트는 「아파트 단지」 = 명일 아파트 설계(6장). 규칙을 지키면 전투 없이 지나가고, 어기면 그 장소의 '주민'이 적 | 아파트: 신발·인사·목소리·밥상 / 병원: 길을 묻지 마라 / 지하철: 안내 방송을 따르지 마라 | 그 장소의 주인(아파트: 405호 노부부·208호 가족, 병원: 목이 도는 간호사, 지하철: 낡은 제복 차장) | **1판 (아파트)** |
| **시험 층** | 목표가 적혀 있거나 빨리 알아내야 함, 수호자가 가장 많이 목격됨 | 들어가면 벽에 목표가 적혀 있다("30초 안에 셋을 찾아라"). 달성하면 보상 큼, 실패하면 수호자 | "목표를 읽어라" | 낡은 제복의 사람 모양(순찰 경로 고정) | **1판** |

로비 층(L1~L3)은 유형이 아니라 "평범해 보이는 층"이다. 조각은 사무실 건물 로비·복도·휴게실. 어긋난 구석(시계가 거꾸로, 안내판 글자가 섞임)이 규칙 단서이고, "해롭지 않아 보이는 존재"(원문) 한 종이 방심한 플레이어를 노린다.

## 4. 정비 구역 (휴식·파밍·되돌아가기)

### 4.1 구성

- **입구**: 층의 점검문·천장 해치·승강로 틈새. 조각마다 0~1개. 쟈알디 같은 벽 부수기 요원은 금 간 벽에서 입구를 하나 더 연다(숨은 길).
- **통로**: 덕트(앉아 이동 구간), 지지대(점프 구간), 기울어진 바닥(미끄러짐), 승강로 틈새(아래가 끝없이 보임). 세로 미로이고 조각 3~6개.
- **다락방 = 휴식방**: 원문 "선배들의 다락방". 벽에 긁어 쓴 메모(규칙 단서), 대충 그린 지도(다음 층 유형 미리보기), 버려진 보급품(아이템), 용도 모를 장비(임시 무기·유물 후보). 저장·회복·송신·철수 지점. 중림 상인이 가끔 있다(기본 기획서 17장).
- **포식자**: 정비 구역 전용 적. "틈새로 떨어진 것들을 먹고 사는" 느리고 큰 것. 다락방에 오래 머물면 온다(원문 메모 "여기 오래 있지 마" = 체류 시간 제한 90초, 넘기면 포식자 등장).
- **다시 짜임**: 원문 "통로가 몇 분 만에 무너지고 다시 짜인다" = 같은 출동 안에서도 정비 구역은 한 번 나갔다 들어오면 조각이 바뀐다. 절차 생성의 설정상 근거. 단 다락방과 귀환 로프 위치는 바뀌지 않는다.

### 4.2 메트로배니아 요소

| 요소 | 어디에 | 출동 안 | 출동 사이(영구) |
| --- | --- | --- | --- |
| 되돌아가기 | 정비 구역으로 윗층에 다시 올라감 | 가능(승강기는 안 됨, 정비 구역만) | — |
| 잠긴 문·열쇠 | 층 안 두 갈래 문, 정비 구역 점검문 | 열쇠·승객 정보·규칙 | — |
| 지름길 | 정비 구역 해치 ↔ 층 | 한 번 열면 열려 있음 | **승강기 버튼 기억**: 한 번 간 깊이는 다음 출동에서 바로 그 버튼이 뜬다 |
| 숨은 길 | 금 간 벽·막힌 덕트 | 벽 부수기·앉아 이동 | — |
| 지도 | 가 본 층·정비 구역·다락방·로프 | 자동 | 다락방 지도를 송신하면 다음 출동 브리핑에 유형 힌트 |

### 4.3 귀환 로프 (게임 설계)

원문은 "타고 온 엘리베이터로 되돌아갈 수 없다"고 하므로 귀환은 승강기가 아니라 정비 구역이다. 관리국 선발대가 정비 구역 승강로에 **귀환 로프**를 걸어 두었다(게임 설계). 다락방마다 로프가 있고, 로프를 타면 입구 엘리베이터 앞으로 돌아온다(연출: 승강로를 한참 올라가 점검문을 열면 진짜 로비). 자발 철수·귀환은 이 로프다. 후송은 "로프로 끌어올려졌다"로 처리한다.

## 5. 조각 기반 생성 (방을 하나하나 만들지 않는다)

사용자 지적(2026-10-20)대로 42개 방을 손으로 만드는 것은 절차 생성이 아니다. 단위를 **조각**으로 내린다.

- **조각** = 반 화면 폭(640px 원본) 가로 1칸. 왼쪽 끝과 오른쪽 끝이 어느 조각과도 이어지도록 바닥선·깊이 3줄·벽 높이를 통일한다. 조각은 "지형 모양"만 가진다(바닥 단차 없음/단차/구멍/문 1~2/점검문/천장 해치/베란다).
- **층** = 조각 6~12개 이어 붙이기 + 양 끝에 고정 방(엘리베이터 홀). 조각마다 소품·적·사건·규칙 장치는 생성 시 얹는다(조각에 박혀 있지 않다).
- **고정 방 5개**만 손으로 만든다: 엘리베이터 홀(패널), 다락방, 수호자 방, 시험 층 목표 방, 출구 홀(EXIT).
- **조각 세트**: 공용 10개(복도 평지, 단차, 구멍, 두 문, 점검문, 해치, 막다른 벽, 꺾임, 넓은 홀, 좁은 통로) + 유형별 12~16개(그 유형 팔레트·소품·장치). 재현의 층은 장소 세트마다 12~16개(아파트 세트는 명일 아파트 설계서 5장의 틀을 조각으로 쪼갠 것: 복도·거실·안방·부엌·베란다·계단실·창고).
- **생성 순서**: 깊이 n → 유형 뽑기(직전 3층과 다른 유형) → 조각 수 → 경로 조각 나열(막다른 벽은 끝에만) → 고정 방 삽입(수호자 방은 층 끝, 다락방은 정비 구역) → 예산(8.4)으로 적 배치 → 규칙 장치·사건·승객 배치 → 정비 구역 생성(조각 3~6) → 검증(끝까지 길이 있는가, 다락방 1개, 열쇠가 문보다 앞, 수호자 방 도달) → 실패 시 같은 씨앗 재생성 3회 → 고정 배치 A/B.
- **변주**: 조각 좌우 뒤집기, 팔레트, 소품 밀도, 깊이 n에 따른 손상(벽 금, 핏자국, 메모). 같은 조각이라도 예산·규칙·승객이 다르면 다른 층이다.
- **첫 판 제작량**: 공용 10 + 추격 12 + 재현(아파트) 14 + 시험 12 + 로비 6 + 정비 구역 8 = 약 62 조각 + 고정 방 5. 조각은 타일셋(PixelLab tileset) 위에 코드로 조립하므로 그림 비용은 유형당 타일셋 1장과 소품이다.

## 6. 재현의 층 「아파트 단지」 = 명일 아파트 흡수

- 원문: 재현의 층은 "아파트 단지 같은 실제 장소가 완벽하게 재현되어 있고, 평범한 사람처럼 보이는 것들이 특정한 행동에 반응해 갑자기 적대적으로 변한다". 명일 아파트의 4층(예절)·5층(남의 물건)·2층(붉은 벽)이 정확히 이것이다.
- **하위 변형 3개**(층마다 하나): 빈집(명일 5층: 남의 물건 규칙, 「일어난 집」) / 사는 척(명일 4층: 신발·인사·목소리·밥상 규칙, 402호·403호 사건, 수호자 405호 노부부) / 붉은 벽(명일 2층: 색 규칙, 벽 얼굴·손 바닥·문틀 등, 수호자 208호 가족). 3층 "끝나지 않는 복도"는 퍼즐과 선택의 층 하위 변형으로 옮긴다.
- 규칙·적·수호자 패턴·사건·대사·자산은 `스테이지설계서_명일아파트.md` 3·4·6·8·9·10장을 그대로 쓴다. 폐기하는 것은 그 문서의 2장(5→1층 구조), 5장(42틀), 7장(임무), 11장(파라미터), 12장(7층 결정)이다.

- 뒤에 넣을 재현 세트: 지하철역(심연교통공사, 원문이 직접 연결), 병원(목이 도는 간호사, 원문), 학교. 세트 하나가 곧 "새 괴이 하나"의 제작 단위다.

## 8. 승강기 (의식) — 해설자이자 거래 상대

- **방송**: 층 안내(「띵. B-3입니다. 문이 열립니다.」), 수수께끼 경고(「이번 층에서는 뛰지 마세요.」= 규칙 힌트), 혼잣말, 그리고 **호명**: 요원의 이름과 원작의 사적인 사실을 부른다(「안녕, 에일린 씨. 그 와이셔츠, 아직 못 버렸죠.」). 요원마다 호명 대사 3줄을 제작서 9장 대사표에 추가한다. 대사는 미리 쓴 대본이다(기본 기획서 18장).
- **총애(-3 ~ +3)**: 인사(E, 탑승마다 +0 또는 +1 무작위), 닫힘 연타(-1), 승객을 구함(+1), 수호자를 규칙으로 통과(+1), 승강기 안에서 공격(-2). 총애가 높으면 버튼 선택지가 3개로 늘고 유형이 미리 표시되며 보급품 위치를 알려 준다. 낮으면 선택지 1개, 문이 안 닫혀 갇힘(원문 각주, 10초 정지 + 적).
- **거래**(원문): 다락방 인터폰에서 1회. 현금이 아니라 **회수물 1개 또는 미송신 단서 1개**를 준다 → 다음 층 유형 공개 / 갈 수 없는 층 열림(깊이 +2 점프) / 보급품 위치. 결과는 총애에 따라 참·거짓이 섞인다(원문 "틀린 정보를 받아 동료를 잃었다").
- **정체**: 게임은 답하지 않는다. 다만 총애 +3에서 한 번 "그건 외로워 보였다"(원문)에 해당하는 방송 한 줄을 들려준다.

- 그림: 2000년 이전 지은 낡은 사무실 건물 엘리베이터 안. 정기 점검표, 서명란이 비어 있다.

- 암전. 「띵. 1층입니다. 문이 열립니다.」 문이 열리면 로비 같은데 로비가 아니다. 뒤를 돌아보면 패널에 없던 숫자가 빼곡하다(도트: 패널 클로즈업 1장).

**첫 호명 (도트)**
- 인터폰: 「안녕, ○○ 씨. (요원별 사적 사실 한 줄). 이번 층에서는 꼭 살아남아요.」
- 요원 반응 대사(요원별).

**다락방 (한 장 그림)**
- 그림: 덕트 사이 비좁은 공간, 벽의 긁어 쓴 지도, 버려진 배낭, 끝에 「여기 오래 있지 마」.
- 잼트리: 「선배들의 다락방이래요. 관리국 선배가 로프를 걸어 뒀고요. …오래 있지는 마세요.」

**삼 년째 승객 (도트)**
- 「나 여기 삼 년째야. 그러니까 내 말 들어. 저쪽 문 말고 이쪽.」

**귀환 (도트)**

**출구 (공략 완료, 한 장 그림 + 도트)**
- 패널에 EXIT가 뜬다. 누른다. 「…1층입니다. 문이 열립니다.」 문이 열리면 관리국 차량. 인터폰 마지막 한 줄: 「또 와요.」

## 15. 절차적 생성 파라미터 (이 괴이)

```
anomaly: elevator
lobby: floors 3 (L1 tutorial, L2 rule, L3 guardian "guard"), chunks 4-6
depth: unbounded; B-n budget = base(n) + chunk_index*step + danger*bonus + variant + growth
types: [chase, replica, trial, dark(2nd), silent(2nd), puzzle(2nd)]
type pick: != last 3 floors; replica sub = [vacant, pretending, red] (myeongil sets); trial every 3rd floor at least once
floor: chunks 6-12 (common 10 + type 12-16), fixed rooms: elevator_hall both ends, guardian_room at end (p by depth), trial_goal if trial
service: between floors, chunks 3-6 vertical, attic 1 (save/send/rope/shop p=0.3), predator after 90s stay, re-roll on re-entry (attic+rope fixed)
elevator: buttons 1-3 by favor(-3..3), type shown if favor>=2 or passenger info or attic map; greet E; deal once per attic
passengers: p=0.5 per floor, honest/deceptive 50/50 (rule 8 tell), rescue target by mission
intrusions: fake_bureau p=0.25 (any B), daydream p=0.30 (B>=2), anomaly_burst per combat 0.12
exit: EXIT button appears in lobby when rules>=10 && favor>=3 && reached B-12
validate: path to floor end, attic per service, key before lock, guardian reachable; retry 3; fallback A/B
seed: one per run
```

## 16. 사용자 결정이 필요한 것 (결정 목록 D에 반영)

1. 귀환 로프(관리국 선발대가 걸어 둔 것)라는 게임 설계를 허용할지. 대안: 승강기와의 거래로만 귀환(더 가혹).
2. 공략 완료 = EXIT 버튼(관리국이 처음으로 나온 사람이 된다)을 허용할지. 원문 떡밥에 게임이 답을 다는 셈이다. 대안: EXIT는 끝내 안 뜨고 깊이 기록만.
3. 승강기 호명에 요원의 원작 사적 사실을 쓰는 것(요원마다 3줄, 제작서에 추가).
4. 첫 판 유형 3종(추격·재현 아파트·시험)으로 갈지.
5. 재현의 층에 명일 아파트를 넣어 405호·208호가 "재현된 것"이 되는 설명.
