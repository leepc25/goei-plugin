# 쟈알디 대사 시험판 (10-31, 4판)

- **읽는 법: 칸마다 후보 6줄(번호 1~6). 그 상황이 오면 이 중 한 줄만 말풍선 하나로 뜬다.** 한 줄 = 한 문장.
- 근거(사용자 자료만): 위키 `card/wiki-base.json` 「쟈알디」, 카드 첫 인사(`src/data/install/greetings.json` 본편 글). 옛 Claude 대사·호칭 표·직급 칸은 쓰지 않음.
- 말투: 다나까체, 단답이 아니라 내용 있는 한 문장(카드 첫 인사처럼: 「보고서는 읽었다.」「차차 알게 될 거다.」「거긴 신입을 보낼만한 곳이 아니다.」).
- 주인공 호칭·직급을 짐작하는 말은 넣지 않음(사용자가 정함).
- 원본 `game-src/dialogue2/characters/쟈알디.json` (후보 816줄)
