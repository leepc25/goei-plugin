# 쟈알디 대사 시험판 2판 (10-31)

- 근거(사용자 자료만): 위키 `card/wiki-base.json` 「쟈알디」, 카드 첫 인사(`src/data/install/greetings.json` 본편 글). 옛 Claude 대사·호칭 표·직급 칸은 쓰지 않음.
- 말투: **다나까체** — 「들어와라. 일단 앉지.」「보고서는 읽었다.」「잘 어울리는군.」「결격 사유는 없군.」「따라와라.」「관리국식이라고 생각해라.」「본때를 보여줘야겠군.」「좋은 아침이다.」「하아… 잼트리. 어떻게 좀 해봐라.」「충분히 쉬었나? 이동한다.」
- **말풍선 하나 = 한 문장.** 여러 문장은 쪼개서 차례로 띄운다(표에서 「→」).
- 주인공 호칭·직급을 짐작하는 말은 넣지 않음(사용자가 정함).
- 구조: 주인공 소속 6칸 × 평판 4단계 × 상황 4개(주인공을 향한 말) + 상대와 무관한 칸(한 벌). 원본 `game-src/dialogue2/characters/쟈알디.json`
