# 동작 줄 활용표 (10-30)

지금 코드에서 각 동작 줄이 어디서 틀리는지 **코드 사실만** 적은 표다. 계획·추측은 넣지 않았다. 줄 목록 = 166줄(요원 55명·NPC 71명 보유 수).

근거 파일: 전투 엔진 `src/game/action/fighter/core.ts`·`player.ts`(PRESS)·`ai.ts`(BTN)·`seats.ts`, `src/game/combat/brain.ts`, 키 배치 `src/game/action/engine/input.ts`(useEileenKeys, main.ts:65에서 켬), 인물 기술 `game-src/action/testroom3/chars/*.json`(skills.anim·hold·release), 필드 `src/game/action/art/charPacks.ts`(FIELD_CLIP 클립 이름→줄), `src/game/world/actors.ts`(setClip·SEAT_KIND), `src/game/world/needs.ts`(ACTIVITIES), `src/game/action/engine/hub.ts`, 시험장 `src/game/action/fighter/testroom.ts`.

구분:

- 「게임(전투)」 = 액션 엔진에서 주인공 입력(키)·전투 AI(brain.ts 버튼: 이동·light·heavy·block·dodge·jump·shoot·charge·skill·super·run)·피격 처리·자동 대기가 트는 줄.
- 「게임(필드·본부: 클립)」 = 필드·본부 행위자(actors.ts)가 실제로 setClip 하는 클립 이름이 고르는 줄. 후보가 여럿이면 앞 줄이 없을 때만 뒤 줄. 주인공 본부 의자(hub.ts:397)도 여기.
- 「게임(아이템)」 = 주인공 아이템 사용(player.ts:213 drink·eat·bandage → 26).
- 「시험장만」 = 시험장 장면 버튼(core.SCENES)·생활 줄 버튼(lifeIds/playLife, 50번 이상)·게임 입력/AI가 보내지 않는 onPress 이름으로만 틀림.
- 「안 씀」 = 코드 어디서도 부르지 않음. 시험장 맨 아래 「동작 하나씩」(testroom.ts:253, 모든 줄 act(id))으로만 볼 수 있음. 이 단추는 모든 줄에 있으므로 따로 적지 않았다.
