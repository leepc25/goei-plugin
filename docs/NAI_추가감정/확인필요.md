# 생성 전 확인할 것 (2026-10-27)

설정 반영본은 `결과/` 4개 파일. 아직 NAI로 한 장도 생성해 보지 않았다. 아래는 먼저 몇 장 뽑아 볼 곳.

## 그림으로 확인

- **사장**: `no eyes, shaded face`로 검은 얼굴에 입만 나오는지.
- **브라우니**: `tv head` 화면에 눈썹·입 표정이 실제로 그려지는지. indifferent는 `faceless`(꺼진 화면).
- **제이**: 모자·마스크 고정이라 입 태그 없음. angry smile·crazy smile·forced smiling이 눈만으로 웃음으로 읽히는지.
- **고그니쟈**: 위키·동작표는 고글, 그림은 둥근 선글라스 → `round eyewear, sunglasses`로 정함.
- **세크리엠**: 입 다문 장에도 `fangs` → 송곳니가 삐져나올 수 있음.

## 해석이 들어간 감정

- 쟈알디 tormented = 이도형 이름(사적인 분노)
- 곽제강 tormented = 남의 불행 앞에서 웃음 참기
- 장허운 jealous·pouting·angry smile·crazy smile = 쓸쓸함·고집·웃는 척 참기·절박한 희망
- 게슈간·고그니쟈·고르고디오 jealous = 위키 일화 기반 곁눈
- 백사헌 crazy smile에 `blood on face`(입사 첫날 일화) — 수위 걱정되면 뺌

- 콘쥬스: 위키는 20세 대학생·과잠, 그림·동작표는 고교 교복.
- 이기석: GPT의 `prosthetic arm` 뺌(위키상 소매 안 실제 팔처럼 보임).
- 윤병수: 그림엔 담배 없음, 위키 따라 담배 3장.
