# 통합 캐릭터 창과 퍽 체계 (초안 · 2026-10-30)

사용자 요구(10-30):
- 캐릭터 창·인벤토리·스킬·퍽을 **창 하나로 통합**한다.
- **도트 스타일**로 만든다. 코드로 그린 PPT 표처럼 보이면 안 된다.
- 퍽은 폴아웃처럼 **카드나 뱃지로 하나하나 디자인**한다.
- 퍽은 **장점만 있는 퍽과 장점·대가가 같이 있는 특성을 섞는다.**
- 초안을 먼저 잡고, 필요하면 PixelLab으로 뽑는다.

이 문서는 설계 초안이다. 코드와 그림은 아직 만들지 않았다. 출동 루프는 `설계_출동루프_3판.md`를 따른다.

## 2. 통합창

### 2-1. 원칙
- **창은 하나다.** 탭을 오가지 않고 한 화면에 다 보이게 한다. 칸이 모자라면 칸 안에서만 넘긴다.
- 필드에서도, 괴이 안에서도 **같은 창**을 쓴다. 괴이 안에서만 의미 있는 칸(임시 퍽)은 필드에서는 비어 있다.
- 열면 게임이 멈춘다(지금 메뉴와 같다).
- 그리기는 **캔버스에 도트로** 한다. 틀은 PixelLab으로 뽑은 그림이고, 글자는 도트 글꼴이고, 아이콘은 도트 그림이다. 표 테두리 선이나 둥근 상자는 쓰지 않는다.
- 여는 키(안): 키보드 `Tab`(또는 `I`), 패드 `Start`를 누르면 일시정지 메뉴 첫 줄, 터치는 HUD 초상화를 누른다.

### 2-2. 배치 (게임 화면 1280×720, 도트 2배 기준 640×360 안에서)

```
┌──────────────────────────────────────────────────────────────┐
│ [초상]  에일린 · 관리국 1팀        상태: 출동 중 / 체력 ███░ │
│ [ 64 ]  사격 · 고유 퍽 뱃지 1                                │
├───────────────┬───────────────────────┬──────────────────────┤
│ 능력치         │ 기술                   │ 퍽                    │
│ 체력   920    │ [약공] [강공] [사격]   │ (고유) ◆               │
│ 피해   1.00   │ [충전] [고유] [필살]   │ (임시) ◇◇◇◇◇◇          │
│ 속도   1.00   │ 고른 기술 설명 2줄     │ (임시) ◇◇◇◇◇◇          │
│ 쿨     1.05   │ 피해 · 쿨 · 판정       │ 고른 퍽 카드 크게 보기 → │
│ 받는피해 1.00 │                        │                      │
│ 경직   0      │                        │                      │
├───────────────┴───────────────────────┴──────────────────────┤
│ 소지품  [1][2][3][4] 퀵칸   [ ][ ][ ][ ][ ][ ][ ][ ] 가방    │
│ 장비    [ 비어 있음 · 나중 ]           현금 ₩ / 판 재화      │
└──────────────────────────────────────────────────────────────┘
```

| 칸 | 보여 주는 것 | 자료 출처 |
| --- | --- | --- |
| 머리 | 초상(HUD 초상 그림), 이름·소속, 상태 태그, 체력, 고유 퍽 뱃지 | 인물 팩, `$goei_world` 태그 |
| 능력치 | 숨은 수치 6개를 **보기만** 한다(찍는 칸이 아니다). 임시 퍽으로 바뀐 값은 색으로 표시한다(원래 값 → 지금 값) | 몸의 능력치 |
| 기술 | 기술 6칸 아이콘. 고르면 설명·피해·쿨이 나온다 | 인물 팩 `cfg.bal`, `기술_재설계/<인물>.md` 요약 |
| 퍽 | 고유 퍽 1개 + 임시 퍽 뱃지 격자. 고르면 카드가 크게 뜬다 | 퍽 데이터(3장) |
| 소지품 | 퀵칸 4칸 + 가방 칸. 고르면 설명, 쓰기·버리기 | 필드 가방 `fieldShop` / 출동 `ItemRun` |
| 장비 | 자리만 둔다(장비는 아직 계획에 없다) | — |

- 「보이는 스탯 칸은 없다」(10-29)는 **찍어서 올리는 칸이 없다**는 뜻이다. 통합창에서 수치를 보여 주는 것은 10-30 요구다.
- 모바일 세로 화면에서는 머리 + 능력치 + 기술을 위에, 퍽과 소지품을 아래에 놓는다. 그래도 창은 하나다.

## 3. 퍽 체계

### 3-1. 종류

| 종류 | 언제 붙나 | 언제 사라지나 | 장단 |
| --- | --- | --- | --- |
| **고유 퍽** | 처음부터 붙는다(이름 있는 인물 55명마다 1개) | 사라지지 않는다 | 퍽 또는 특성 |
| **임시 퍽(공용)** | 괴이 안에서 방 보상으로 3택1 | 괴이를 나오면 사라진다 | 대부분 퍽 |
| **임시 특성(공용)** | 드물게 후보에 섞여 나온다 | 괴이를 나오면 사라진다 | 장점 + 대가 |
| **괴이 전용 퍽** | 그 괴이 안에서만 후보에 나온다 | 괴이를 나오면 사라진다 | 괴이 성격상 대가가 붙는 것이 많다 |
| **NPC 전용 퍽** | 몹·정예·시민 원형에 붙는다(유저는 못 얻는다) | — | 정예 특전, 도망 잘함 등 |

- **퍽** = 장점만 있다(폴아웃 Perk).
- **특성** = 장점과 대가가 같이 있다(폴아웃 1·2·뉴베가스 Trait). 예: 「피해 +20%, 받는 피해 +15%」.

### 3-2. 개수 추정

| 종류 | 계산 | 개수 |
| --- | --- | --- |
| 고유 퍽 · 이름 있는 인물 | 인물 팩 1~5번대 55명 × 1 (6번대 71명은 모두 원형 몹 그림이라 NPC 전용 퍽을 쓴다) | 55 |
| 임시 퍽 · 공용 | 분류 7개 × 15~18 | 약 110~125 |
| 임시 특성 · 공용 | | 약 20 |
| 괴이 전용 | 괴이당 6~10 × 괴이 수(미정) | 괴이 10개면 약 80 |
| NPC 전용 | 정예 특전·원형 성향 | 약 20~30 |
| **합계** | | **약 285~310** (괴이 10개 기준) |

임시 퍽·공용 분류 7개(안):

| 분류 | 예 |
| --- | --- |
| 근접 | 약공 피해 +, 강공 범위 +, 연타 마지막 타 밀침 |
| 사격·투사체 | 탄 +1, 관통, 탄속 +, 과열 한계 + |
| 이동 | 3단 점프, 이동 속도 +, 회피 +1, 공중 회피 |
| 생존 | 최대 체력 +, 받는 피해 −, 방 넘길 때 회복, 한 번 버티기 |
| 기술 | 고유기 쿨 −, 충전 시간 −, 필살 게이지 + |
| 상태 이상 | 맞히면 출혈·둔화·공포를 건다(지금 있는 7종 사용) |
| 조건 | 등 뒤 +, 체력 높을 때 +, 안 다친 적 + |

- 공용 퍽 중 일부는 랭크(1~3)를 둔다. 랭크는 퍽 개수로 세지 않는다.
- 사격이 없는 요원(60명)에게는 사격 분류가 후보에 나오지 않는다.

### 3-3. 퍽 하나의 자료 형식(안)

```
id, 이름, 종류(고유/임시/특성/괴이/NPC), 분류, 설명 한 줄(설정 말투), 효과(숫자),
대가(특성만), 랭크 최대, 나오는 조건(사격 있음 등), 그림 id, 테 등급
```

효과는 숨은 수치 6개와 「조건 + 효과」 틀만 쓴다. 그래서 퍽이 수백 개라도 코드는 늘지 않고 자료만 는다.

## 4. 퍽 그림 (뱃지 + 카드)

### 4-1. 두 크기

| 크기 | 어디에 | 내용 |
| --- | --- | --- |
| **뱃지** 32×32 | 통합창 퍽 격자, HUD, 3택1 후보 | 테(종류별 색) + 그림 |
| **카드** 96×128 | 퍽을 고르면 크게, 3택1 창 | 위에 큰 그림, 아래 이름·설명·효과(도트 글꼴) |

### 4-2. 그림체 방향 (고를 것)

| 안 | 모양 | 장점 | 단점 |
| --- | --- | --- | --- |
| **A. 안전 수칙 픽토그램** | 괴이 규칙서·안전 표지처럼 단순한 사람 모양 픽토그램이 퍽 내용을 몸으로 보여 준다(폴아웃 볼트보이 자리) | 세계관(규칙서·관리국)과 맞는다. 수백 개를 같은 결로 뽑기 쉽다 | 인물 개성은 약하다 |
| B. 관리국 배지·도장 | 사원증 배지나 결재 도장 모양에 상징 하나 | 관리국 회사 분위기와 맞는다 | 퍽끼리 구별이 어렵다 |
| C. 인물 얼굴 | 고유 퍽만 그 인물 얼굴 도트 | 고유 퍽이 눈에 띈다 | 공용 퍽에는 못 쓴다 |

- 추천: **공용·괴이 퍽은 A, 고유 퍽은 A에 인물 상징색을 섞거나 C**.
- 테 색(안):
  - 고유 = 금
  - 공용 퍽 = 은
  - 특성 = 반은 은, 반은 붉은색(대가 표시)
  - 괴이 전용 = 검붉은 일그러진 테
  - NPC = 회색

### 4-3. 만드는 순서
1. **틀**: 통합창 틀, 뱃지 테 5종, 카드 틀 5종을 PixelLab `generate-ui-v2`로 뽑는다. HUD를 만든 방식과 같다.
2. **견본**: 그림체 A 기준으로 퍽 6~8개를 뽑아 사용자가 고른다. 결이 정해지면 스타일 기준 그림으로 고정한다.
3. **양산**: 3-3 자료 형식으로 목록을 만들고, 그림 id별로 PixelLab에서 32×32 그림을 뽑는다. 카드 그림은 같은 그림을 키우거나(도트 2~3배) 따로 뽑는다.
4. 그림이 나오기 전에는 뱃지 자리에 **분류 색 + 분류 글자 한 개**로 된 도트 임시 그림을 쓴다. 표가 아니라 뱃지 모양 그대로 둔다.
