> 2026-10-31 Claude는 다음 잘못을 저질렀다. 이 문서를 읽는 모든 Claude는 같은 짓을 하지 않는다.
> 1. **사용자 결정을 무시했다.** 콘쥬스는 사용자가 10-26에 20세로 정했고 인계서에도 적혀 있었는데, 옛 Claude 문장(teenage high school girl)을 근거로 화장실·샤워 그림을 거부하고, 사용자가 직접 뽑은 화장실 줄까지 팩에서 뺐다. 옷도 제복인데 교복이라고 단정했다.
> 2. **사용자 말에 토를 달고 같은 주장을 되풀이했다.** 사용자가 여러 번 지적했는데도 근거를 다시 확인하지 않아 몇 시간을 허비하게 했다.
> 3. **허락 없이 문서를 지웠다.** 「지침을 지우라」는 말만 듣고 목록을 보여 주지도 않고 96개를 지웠다가 되살렸다(결과물 삭제 금지 규칙 위반).
> 4. **문장을 덧대기만 하며 PixelLab을 낭비했다.** 이성해 점프 공격 5번 연속 실패, 이어폰 음악 120줄을 못 쓰게 만듦.
> 5. **답을 미루고 일을 멈춰 두었다.** 백그라운드로 돌릴 일을 돌리지 않고 대화만 했다.
>

## 4. 결함 정리 (심각한 것부터)

1. **Router·Director 시간 초과 3회 → 세션 끝까지 꺼짐.** 원본에는 없는 동작. 기본 시간 제한도 15초·20초로 원본(300초)보다 훨씬 짧아, 느린 보조 모델이면 몇 턴 안에 둘 다 조용히 꺼진다. 사용자가 「켜져 있는데 안 돈다」고 느끼는 직접 원인 후보.
2. **모델 Router 결과가 코드 Router 결과를 대체.** 원본은 이름이 나온 인물을 코드가 무조건 합친다. 이식판은 모델이 빠뜨리면 그 인물이 그 턴 본편 기록에서 사라진다.
3. **사실형 Director 가 호출 없음.** 원본 사실형은 본편 앞에 Director 를 부른다. 이식판은 전 턴 갱신기 메모를 재사용하므로 이번 입력을 반영하지 못한다(설계 결정이면 설정 화면 설명에 명시 필요).
4. **Director 지침·자료·출력이 모두 축약.** 지침 7,855 → 1,500자, 기능별 전문 → 1문단, 기록 전문 → 꼬리 6개, 메모 12,000 → 120자/인물. 원본 Director 의 「판단」이 이식판에서는 「한 줄 요약」이 됐다.
5. **지식 경계 규칙 누락.** 원본은 Director 성패와 무관하게 「보지 못한 비밀을 말하거나 행동에 쓰지 말라」 규칙을 본편에 항상 넣는다. 이식판은 Director 실패 시 아무것도 넣지 않고, 성공 시에도 이 문장이 없다.
6. **Director 출력 검증 실패 시 고침 재호출 없음.**
7. Router 명단에 정체 발췌·관계가 없음(「그 사람」 식 지칭 해결 근거 부족).
8. 최근 글 범위(Router·Director) 설정 칸 없음, 캐시 1개.
