# 필드 재제작 — 최신 사용자 지시

이 문서는 이전 작업 중단 지시 이후 사용자가 직접 내린 재개 지시를 기록한다.

- 가짜 관리국 14명 전원 실패, 기존 등록본 삭제 후 신규 제작. 원본·실패본·영수증은 이력에 보존한다.
- AVIF 원작을 한 명씩 크게 열어 머리·얼굴·눈·체격·복장·특징을 먼저 확인한다. 로어북은 보충용이다. 카우보이 컷에서 알 수 없는 키는 사용자 지정값과 로어북의 상대적 키·덩치 정보를 사용한다. 임의 추정 수치를 공식 설정으로 보고하지 않는다.
- 가짜 관리국 → 백일몽 → 나머지 명부. 실제 기존 명부는 55명(관리국 12, 가짜 관리국 14, 백일몽 16, 기타 13). 사용자 발언의 53명은 질문형 추정이며 임의로 두 명을 빼지 않는다.
- 전원 캐릭터·8방향 등록 완료 전 새 동작 생성 금지. 등록 API 자체가 8방향을 생성하므로 중복 요청 금지.
- 전원 등록 후 관리국부터 한 명씩 동작 제작. 이동·전투는 east, 제자리 비전투 breathing-idle/drinking은 south-east. 쟈알디·스팡달은 west/south-west. 실제 얼굴 가림을 비교해 개별 예외를 기록한다.
- 계정 동시 큐 최대 20개. 원작과 결과 검수 없이 큐를 채우지 않는다. 불명 접수는 조회해 복구하며 중복 결제하지 않는다.
- 동작 외곽/테두리의 회색 덧칠은 실패이며 리롤 대상. 쟈알디 점프 실패본과 비교하고 매 프레임의 불투명 외곽 픽셀도 확인한다. 알파 검사는 시각 검수를 대체하지 않는다.
- 한 명 출력 완료마다 이 지침을 재확인한다. 실패를 완료로 집계하지 않고 재작업한다. 독립적으로 진행 가능한 작업을 계속한다.

가짜 관리국 원작 14명을 개별 열람하고 외형을 새로 기록했다. `manifest.json`의 `source_review_details`가 근거다. 첫 재제작 예상은 정면 9 + 8방향 등록 4 = 인당 13 generations, 14명 182 generations. 실제 청구는 완료 영수증으로 기록한다.


## 재개 작업 기록

- 가짜 관리국 실등록 9건을 백업 후 삭제하고 각각 GET404 확인했다. 아직 등록되지 않은 5명도 실패 파일을 이력으로 격리했다.
- 큐라스·데드폴의 이전 실패 등록 각1건을 백업 후 실제 삭제했다. 현재 등록과 사용자 테스트 캐릭터는 보존했다.
- 55명 원작을 모두 개별 열람했고, 로어의 외모/외형을 보충 자료로 읽었다. 이미지와 로어가 충돌하면 원작 기본 복장을 우선했다.
- 데쥬레의 불명 응답은 서버에 이미 완성된 등록을 찾아 복구했다. 중복 유료 등록하지 않았다.
- 첫 정면 결과는 파일 형식 통과와 별개로 검수했다. 이길환은 체형·키·정면 통과 후 등록했다. 다른 결과의 과대한 키, 측면으로 돌아간 얼굴, 빠진 흉터/턱 특징은 실패 사유를 남겨 리롤한다.
- 남성 스타일 참조 구도가 캐릭터 키와 방향에 영향을 주는 것으로 의심돼 재시도에서 제거했다. 키에 맞는 작은 네이티브 캔버스에 신규 생성하고 위에 투명 여백만 추가한다. 생성 픽셀은 리사이즈·보간·덧칠하지 않는다. 원본은 native-generation.png, 검수용 표준128×256은 reference.png로 보존한다.
- 정면 리롤마다 지침 재확인 목록과 사유를 visual-review.json에 기록한다. 실패본과 영수증은 history/rebuild-20261024/rerolls에 보존한다.
- 기존 관리국11명 8방향을 눈으로 확인하고 방향을 기록했다. 기존 관리국 결과 유지 범위의 확인이며, 새 키 목표에 대한 신규 승인이라고 주장하지 않는다.
- 강이학 첫 작업은 서버 과부하5000으로 실패했고 청구0 응답을 기록했다. 재시도 대기열로 복귀한다.
- 모의 스케줄러 검사: 전체 명부8방향 검수 전 동작0, 동시20 제한, 한 캐릭터 동작 검수 전 다음 캐릭터 금지 모두 통과. 검사는 네트워크·유료 호출 없이 실행했다.

## 정면 검수 진행 및 방식 보정

- 가짜 관리국14명 전원의 신규 정면을 원작과 대조해 시각 검수했다. 사용자 최종 승인을 새로 받았다고 주장하는 기록이 아니며, 다음8방향 결과에서도 특징 유지를 확인한다.
- 작은 네이티브 캔버스에서 일부 결과가 지나치게 작아졌다. 후속 작업은 원작 외형 설명을 유지하면서 시각 검수에 통과한 이길환·도필헌·김성진·은하제·박민성 등의 정면 도트를 **픽셀 스타일·크기 참조만**으로 사용한다. 참조 인물의 얼굴·복식·체형을 복사하지 않도록 지시하고 매 결과에서 다시 확인한다. 색상 복사 옵션을 끄고 각 원작 색을 우선한다.
- 일부 부분 교정은 Pro Flash edit를 사용했다. 팔레트 보정 후 이성해의 초록 눈과 이자헌의 붉은 눈이 사라지고 색 수가 급감한 결과는 실패로 격리했다. 이자헌은 색상 복사를 끈 장신 참조로 재생성한다. 이성해는 초록 눈·키가 맞았던 이번 제작본을 입력으로 머리 영역만 inpaint한다. API의 unmasked RGBA 보존 계약을 읽었고, 검수 코드에서도 마스크 밖 모든 RGBA가 같은지 검사한다. 공식128×256 inpaint 견적은9회다.
- 검수 화면은 캐릭터별 축척 보정을 제거했다. 같은 정수 배율·같은 바닥선으로 표시하며 원작 AVIF 링크와 정면 검수 상태를 표시한다. Chromium에서 자바스크립트 오류 없이 렌더링되는 것을 확인했다.
- 투명 여백만 붙인 결과6건은 원본 RGBA 바이트와 표준 캔버스의 해당 영역이 정확히 같은지 검사했다. 수작업 리사이즈로 키를 맞추지 않았다.
- 집계는 파일형식 통과/신규 정면 시각 검수/8방향 시각 검수/캐릭터별 동작 검수를 구분한다. 전체 완료 조건은 전원8방향과20개 동작의 완료·시각 검수다. 대기 중 요청이 없어졌다는 이유만으로 완료 처리하지 않는다.
- 동일 이름을 일괄 삭제하는 초기 정리 도구는 감사 기록이 이미 있으면 재실행을 거부한다. 새로 통과한 등록을 실수로 삭제하지 않도록 했다.
- 동작 방향 추가 예외: 콘쥬스는 분홍 줄이 보이는 west/south-west, 은하제는 비대칭 이마 틈과 얼굴이 더 잘 보이는 west/south-west. 실제8방향 시트에 근거하며 새 동작은 아직 제출하지 않았다.

- 8방향 검수28명까지 진행. 진나솔은 측후면에서 높은 긴 포니테일 확인. 장허운은 뒤늦은 원작 재대조에서 열린 셔츠가 잠긴 형태로 바뀐 것을 확인해 기존 통과를 철회했다. 등록 bf2fe438-73ff-4721-966a-492e4e30facb를 백업·삭제·GET404 검증하고, 이번 제작의 마른 체형 참조를 사용해 다시 생성한다.
- 이성해의 머리 마스크 교정은 마스크 밖 RGBA 전체 보존 검사를 통과했다. 결과59색은 임시48색 형식 한도를 초과했으나48은 사용자 필수 규격이 아닌 생성 목표다. 초록 눈을 파괴하는 재양자화 대신 해당 마스크 교정만64색 한도로 명시했다. 실제 모발·초록 눈·키·외곽을 별도 검수한 뒤 등록했다.

- 공식 MCP HTTP 전송으로 읽기 전용 list_jobs/wait_for_jobs를 확인했다. 등록 작업은 내부 animation 자식 작업도 표시하므로 이것을 새 동작 발주로 오인하지 않는다. 직접 접수한 최상위 작업의 동시 한도는20이다.
- 공식 search_help에서 skeleton-v3 프리셋의 action_description이 관절 자세를 바꾼다는 근거는 없다고 확인했다. 사용자 gray 외곽 반려는 재시도 대상으로 유지하며, 텍스트만으로 포즈 수정이 보장된다고 주장하지 않는다. 별도 animate_with_skeleton_v3는18개 관절을 직접 지정할 수 있고, 원본 자세와 first_frame_keypoints 불일치는 투명도·색상 정확도를 해칠 수 있다는 공식 설명을 확보했다.
- 기존 쟈알디 서쪽 걷기8프레임 검수 통과. 서쪽 달리기는4·5프레임의 뒤팔이 머리 뒤로 과도하게 올라가 반려 기록. 새 동작 재작업은 전원8방향 검수 이후에만 시작한다.

- 가짜 관리국14명 전원 새 정면과8방향 시각 검수 완료. 노기균은 양 입꼬리에서 볼로 이어지는 흉터를 정면·사선에서 확인.
- 고영은·곽제강은 등록job completed와8장 회전URL은 있으나 skeletons:null이었다. 공식 도움말에도 관절만 복구하는 공개 경로는 확인되지 않았다. 각 실패 등록을 백업·삭제·404 확인하고 검수된 정면을 유지한 채 재등록했다(예상4회씩, 합8).
- 장허운의 열린 깃 교정 후 머리가 짧아진 문제, 고연지의 파란 짧은 단발, 마덕희의 갈라진 앞머리를 발견해 머리 영역만 마스크 교정한다(예상9회씩, 합27). 마스크 밖 얼굴·눈·복장·키 RGBA 보존을 검증한다.

- 8방향 검수35/55 진행. 호유원은 실제 동쪽에서 앞머리가 눈을 가려 west/south-west 예외 추가. 이성해·이병진도 종료된 등록의 skeletons:null을 확인해 정면 보존 재등록(각4회 예상). 제이는 회전에 원작에 없는 방패형 소매 패치가 추가돼 등록만 반려·삭제 후 무늬 없는 소매로 재등록(4회 예상).
- 아벤샤는 과도한 파랑·보라 채도를 원작의 청회색 머리·어두운 자주색 망토로 마스크 교정(9회 예상). 에스테티시즘은 작은 입과 목의 봉합선만 교정하고 마네킹 체형은 보존(9회 예상).
- 개별 단일HTML 검수 화면에 방향·동작 선택, 프레임 전후 이동, FPS, 정수 확대, 배경색 전환을 추가했다. Chromium에서 쟈알디 달리기 반려 표시·프레임 이동·흰 배경 전환을 오류 없이 확인했다. 이 화면은 게임 통합 결과가 아니다.
