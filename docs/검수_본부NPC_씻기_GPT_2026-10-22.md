각 PNG는 `game-src/action/npc/clips/<id>/<clip>/NN.png`에 개별 커밋으로 main에 반영했다. 시작 시 해당 경로에 있던 파일은 0장이다. 생성은 내장 ImageGen, PixelLab 사용은 0회다. 반려한 크기 오류 초안은 납품하지 않았다.

## 미완료 17장

- `jaemtri/undress/05.png`: 크기가 잘못된 초안을 제외한 뒤 수정 생성이 출력 안전 검사에서 차단됐다. 요청 ID `03126b5d-bb4b-48ed-884c-f7b02a0abc8e`.
- `dejure/undress/04.png` 생성이 입력 안전 검사에서 차단됐다. 요청 ID `6f986521-cd65-4a0a-92c2-d2a27930499a`. 이어지는 동일 수건 차림 16장은 생성하지 않았다: undress 04~06, showerturn 00~02, shower 00~05, bath 00~03.
- 누락 장에 다른 장이나 다른 옷차림을 넣어 완료 처리하지 않았다. 요청 목록은 부분 납품으로 표시한다.

## 통과한 기술 검사

- 납품 PNG 43장 전부 192×144 RGBA, 투명도는 0/255 두 값만 사용.
- 모든 장의 가장 아래 불투명 픽셀은 y=135. 옆모습/뒷모습은 발 기준으로 캔버스 전체를 평행 이동해 정렬했다.
- 불투명 색 수는 장마다 63~78색. 외곽의 안쪽 1px을 거의 검정 `#0D1213`으로 통일했다.
- 전체 캔버스 최근접 축소·감색·투명도 정리·전체 평행 이동·외곽선 색 정리만 수행했다. 부위 조립이나 자세 보간으로 신규 장을 대신하지 않았다.
- 잼트리/고그니쟈 showerturn 00은 각각 이번에 새로 생성한 undress 06과 같은 경계 자세를 사용한다.
- 내장 PNG 43장의 디코딩과 JavaScript 문법, 프레임 선택/앞뒤 이동/인물 선택/순서 재생, 누락 장 표시를 Node 실행 및 네이티브 Canvas 렌더링으로 확인했다.

## 시각 검수에 남기는 사항

기술 검사 통과를 동일 인물·체형·팔꿈치 방향 승인으로 취급하지 않는다.

- 데쥬레 요청 표는 약 80px지만 지정 기준 PNG의 불투명 영역 키는 87px이다. 기준 그림의 비율을 유지했으며 납품 정자세는 86~87px이다.
- 잼트리 정자세 불투명 영역 키는 90~92px, 고그니쟈는 97~98px이다. 고그니쟈의 돌아서기 뒷모습은 100px로 정자세와 차이가 있어 회전 전환 때 키·머리 크기 대조가 필요하다.
- 앉기에서 머리끝은 잼트리 69/68/70/68, 고그니쟈 70/68/70/69행이다. 요청의 1px 호흡보다 2px 차이가 있는 구간과 엉덩이 y≈128·팔꿈치 방향은 장별 시각 검수 대상이다.
- 실제 브라우저 자동 검증은 실행 파일이 없고 브라우저 다운로드가 실패해 완료하지 못했다. 모바일 배치의 실제 브라우저 검증도 남아 있다.
