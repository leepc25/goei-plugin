# 필드 그림 통합 지침 (배경·요원) — 2026-10-23

원본은 Claude Doc 「필드 그림 통합 지침」이고, 이 파일은 같은 내용을 저장소에 옮긴 것이다. 숫자가 다르면 이 파일을 고친다.

## 기준 숫자

기준은 하나다. **바닥 맨 뒤 줄에서 요원 그림 1px = 배경 그림 1px.** 배경은 세로 480px로 뽑고, 요원은 180 캔버스로 뽑으면 이 기준이 저절로 맞는다.

| 항목 | 값 | 비고 |
| --- | --- | --- |
| 기본 확대 | 약 2.2배 (바닥 맨 앞) | 180 캔버스 요원 기준 |
| 원근 | 맨 뒤 0.85배 ~ 맨 앞 1배 | 바닥 깊이에 따라 고르게 |
| 배경 그림 세로 | 480px | 게임이 창 높이에 맞춰 늘림 (PC 약 890px → 약 1.85배) |
| 요원 캔버스 | 180×180, 몸 약 117px | PixelLab |
| 화면에서 요원 키 (PC 890px 기준) | 맨 앞 약 255px, 맨 뒤 약 217px | |
| 배경 그림 안 요원 키 | 맨 뒤 줄 117px, 맨 앞 줄 137px | 배경을 그릴 때 쓰는 기준 |

화면 배율은 정수가 아니어도 된다. 2026-10-23 시험에서 일그러짐이 보이지 않았다.

## 배경 지침 (GPT)

현재 부장실 그림(`game-pack/start-room`)은 참고하지 않는다(분위기가 설정과 맞지 않음). 분위기 참고는 예전에 그린 본부 벽 그림(`game-src/art/bg/raw/hq_containment`, `hq3_office`).

**1. 파일**
- PNG, 세로 정확히 480px. 가로는 방 길이대로, 최소 1100px.
- 완성된 도트 그림으로 뽑는다. 도트 1칸 = 1px.
- 안티에일리어싱·흐림·부드러운 그라데이션은 쓰지 않는다. 디더링은 괜찮다.
- 한 장에 색 128개 이하. 물건 테두리는 1px 어두운 선.

**2. 화면 나누기 (위에서부터 y좌표)**
- y 0–40: 천장 끝 (천장 들보, 매달린 조명 자리).
- y 40–288: 뒷벽.
- y 288: 벽과 바닥이 만나는 선. 그림 전체에서 정확히 이 높이, 수평 일자.
- y 288–480: 바닥. 사람은 y 288(맨 뒤)부터 y 459(맨 앞) 사이를 걷는다.

**3. 크기 기준 (사람 키 1.65m)**
- 맨 뒤 줄(y 288)에 선 사람 = 117px. 그래서 이 줄에서 1m = 71px.
- 맨 앞 줄(y 459)에 선 사람 = 137px. 앞으로 올수록 고르게 커진다.
- 벽에 붙은 물건은 모두 맨 뒤 줄 기준으로 그린다:
    - 문: 높이 150px, 폭 65px (문틀 포함). 문 아래끝은 y 288.
    - 책상 높이 53px, 의자 좌석 32px, 소파 등받이 60px, 키 큰 책장 141px.
- 바닥 가운데 놓인 물건은, 그 물건 앞발이 닿는 y에 따라 위 크기를 키운다. y 288이면 1배, y 374면 1.09배, y 459면 1.18배.

**4. 바닥과 시점**
- 시점은 정면에서 살짝 내려다본다. 가구 윗면이 보이고, 윗면 두께 = 가구 깊이(m) × 41px.
- 바닥 무늬는 가로줄만 쓴다 (좌우로 긴 마루판). 앞뒤로 길게 뻗는 선·한 점으로 모이는 선은 그리지 않는다.
- 마루판 줄 간격은 앞쪽이 뒷쪽의 1.18배. 뒤로 갈수록 고르게 좁아진다.
- 판자 이음선(세로)은 짧게, 어긋나게, 수직으로만 그린다.

**5. 배치**
- 가구는 벽에 붙이거나 y 288–384 안에만 둔다. y 384–480은 빈 바닥(사람이 지나다니는 길).
- 가구끼리 겹치지 않게 3px 이상 띄운다. 게임이 가구를 하나씩 오려내서 앞뒤 가림과 충돌에 쓴다.
- 문 앞 바닥은 앞으로 40px까지 비워 둔다.

**6. 넣지 말 것**
- 사람, 사람 그림자.
- 글자·숫자·읽을 수 있는 로고. 표지판·명패는 빈 판으로 두면 게임이 글자를 얹는다.

**7. 분위기 (관리국 배경만)**
- 관리국(본부) 배경을 뽑을 때만 쓰는 기준이다. 현대 한국의 사무실 분위기가 기본. 사무실은 파티션·모니터·사무용 의자·천장 형광등/LED가 있는 현대식 사무실. 격리층·훈련장 같은 시설 쪽만 회색 콘크리트·보안 문·카드 리더기·경고 줄무늬를 더한다. 고풍·앤티크·빅토리아·탐정 사무실 분위기는 금지. 괴이 현장 같은 다른 장소의 분위기는 장소마다 따로 정한다.

## 요원 지침 (PixelLab)

요원은 180×180 캔버스, 옆모습으로 뽑는다.

**1. 캔버스와 크기**
- 180×180. 몸 키는 약 117px (캔버스의 약 65%, PixelLab 기본값).
- 한 요원의 모든 동작은 같은 캔버스·같은 몸 크기로. 발끝 높이는 모든 장에서 같은 줄.
- 배경은 투명. 그림자는 넣지 않는다 (게임이 그린다).

**2. 방향**
- 오른쪽을 보는 옆모습 하나만. 왼쪽은 게임이 좌우 뒤집어 쓴다.
- 3/4 정면으로 돌아 있으면 불합격.

**3. 만드는 순서**
1. GPT가 요원 기준 그림을 뽑는다. 외모는 위키 요원 문서(`card/wiki-base.json`)의 외모 설명대로.
    - 정면(화면을 보는) 전신 1장이 필수. 오른쪽을 보는 옆모습 전신은 선택(게임에서 보이는 옆모습을 확실히 고정하고 싶을 때, 같은 옷·같은 크기로).
    - 180×180 투명 배경, 몸 키 약 117px, 발끝은 가로 가운데. 도트 1칸 = 1px, 안티에일리어싱 없음, 1px 어두운 테두리.
    - 차렷 자세, 팔은 몸에서 살짝 떼고 빈 손. 그림자·물건·무기 없음.
2. 사용자가 그림을 컨펌한다. 안 되면 GPT가 다시 그린다.
3. 컨펌된 그림으로 PixelLab에 캐릭터를 등록한다 (create-character-v3: 정면 = reference_image, 옆모습이 있으면 direction_images의 east). 나머지 방향만 PixelLab이 만든다.
4. 대기·걷기 같은 기본 동작은 등록 캐릭터의 견본(animate-character)으로.
5. 견본에 없는 동작은 글로 동작 만들기(text v3). 뼈대 방식은 이 두 가지로 안 될 때만.

**3-1. 단계별로 같이 쓰는 기능**

| 단계 | 기능 | 쓰는 때 |
| --- | --- | --- |
| 등록 전 | unzoom | GPT 그림이 확대된 도트(2×2 등)로 오면 진짜 1도트 = 1px로 되돌린다 |
| 등록 전 | correct-pixelart, reduce-colors | 번진 픽셀 정리, 색 수 줄이기 |
| 변형 | create-character-state | 같은 요원의 다른 상태(재킷 벗음·부상·잠옷 등). 모든 방향에 똑같이 적용 |
| 변형 | transfer-outfit-v2 | 이미 만든 동작에 다른 옷을 입힌다. 옷마다 동작을 다시 뽑지 않는다 |
| 동작 고치기 | edit-animation-v2 | 망가진 동작을 글 지시로 고친다 |
| 동작 고치기 | inpaint-v3, edit-images-v2 | 한 장의 일부(손·얼굴 등)만 고친다 |
| 동작 만들기 | estimate-skeleton | 뼈대 방식을 쓸 때 기준 그림의 관절을 잡는다 |
| 효과 | vfx | 총구 불꽃·연기 같은 효과를 그림과 따로 만든다 |
| 대화 초상 | vocal-animation → talking-gif | 표정마다 입 모양을 한 번 만들면(유료) 대사마다 말하는 움직임은 무료 |

못 쓰는 것: interpolation-v2(장 사이 채우기)는 최대 128이라 180 요원에는 안 된다.

**4. 그림에 넣지 말 것**
- 가구·벽·문·손에 든 물건·빛·연기 같은 효과.
- 예외: 요원 자기 무기. 공격 동작은 요원마다 **기본공격 1개 + 원거리공격 1개**뿐이고, 그 동작은 자기 무기를 든 채로 그린다(create-character-state로 무기 든 상태를 만들어 거기서 뽑는다). **각각 무엇으로 할지(무기·동작)는 제작 전에 반드시 사용자와 상의해 정한다.**
- 주워 드는 무기는 당분간 만들지 않는다(2026-10-23 보류). 손 위치에 무기를 붙이는 방식은 쓰지 않는다.
- 동작 문구에 물건·장소 이름을 쓰지 않는다. 몸 자세와 움직임만 설명한다.

**5. 비용과 승인**
- 참고 그림으로 180 캔버스 캐릭터를 등록하면 1회 4. 방향 1개 기준으로 대기 2, 걷기 3, 글 동작 8장 약 4~6. 요원 1명 기본 세트(등록·대기·걷기·기본공격·원거리공격·맞기·쓰러지기) 약 21~27회.
- 동작 목록과 비용을 먼저 정리해 사용자 승인을 받은 뒤에만 뽑는다.

**6. 검수**
- 동작마다 한 장씩 보고 올린다: 옆모습 유지, 발끝 높이, 팔꿈치·무릎 방향, 물건이 안 그려졌는지.

## 게임 쪽에서 맞출 것 (아직 안 함)

- 배경 세로 480px을 게임 세로 720에 맞춰 그린다 (×1.5). 방 길이도 같은 비율로 정한다.
- 걷는 범위를 배경 y 288–459에 맞춘다 (게임 좌표로 432–689).
- 180 캔버스 요원이 오면 필드 PIXEL을 약 2.18(맨 앞 약 255px)로 바꾼다 (지금은 옛 요원 그림을 2.625로 늘려 쓰는 중).
- 가구 오려 내기 범위와 충돌 상자를 배경 그림 좌표로 방마다 적는다.
