# 관리국 배경 탑재 인계 (2026-10-25)

## 2. 매칭안 초안 (서→동, 미확정)

현재 본부 장소 목록 `src/game/action/hq/data.ts` 기준.

| 층 | 문·시설 → 장소 |
| --- | --- |
| 1F 로비 | 왼쪽 유리 현관 → `street`(→ `pasta`) · 안내 데스크(장식) · 엘리베이터 · 오른쪽 문 → 계단 |
| 2F | 왼쪽 화장실(잠김) · 유리 이중문 → `office`(안에 `jaemtri`) · 엘리베이터 · 반투명 문1 → `chief` · 반투명 문2 → `pantry` · 오른쪽 문 → 계단 |
| 3F | 왼쪽 화장실(잠김) · 반투명 문1 → `interview` · 반투명 문2 → 잠김 · 엘리베이터 · 유리 창구 → `supply` · 오른쪽 문 → 계단 |
| B1 | 왼쪽 문 → `clinic` · 큰 이중 철문 → `training` · 엘리베이터 · 반투명 문1 → `appraisal` · 반투명 문2 → 잠김(목욕탕 보류) · 오른쪽 문 → 계단 |
| B2 | 왼쪽 철문 → `tooth` · 셔터 → `gallery` · 엘리베이터 · 흰 유리 이중문 → `lab` · 오른쪽 철문 → 계단 |
| B3 주차장 | 승합차 → 출동(임무 선택 후) · 경비실 문(잠김) · 엘리베이터 (계단 문 없음) |

- 엘리베이터: 층 선택 창(1F·2F·3F·B1·B2·B3). 계단: 오른쪽 끝 문, 한 층씩.
- 열림 조건은 `data.ts`의 `opens` 그대로. 잠긴 문은 「잠겨 있다」.

## 3. 논의할 것

1. 이전 결정(`docs/배경_범위_검토_2026-10-24.md` 5절: 2F 진압팀·1F 면담실·지하 한 층)과 다름. 배경이 6개 층이라 현재 장소 목록 기준으로 다시 짬. 진압팀은 게임에 장소가 없음.
2. 출동을 B3 주차장 승합차로 옮길지(현재는 잼트리 자리에서 임무 → 출동).
3. 각 배경의 문·엘리베이터 x 좌표 측정과 상호작용 범위.
4. 본부 장면이 지금 한 줄 벨트(장소 x 나열)라, 층별 장면 + 층 이동 구조로 바꾸는 범위.

## 4. 작업 규칙

`docs/게임_통합_현황.md` 따름. 엔진(`engine/`)·`main.ts`는 「전투와 조작」 담당. 올리기 전 `npm run build` · `npm test` · `node tests/engine-browser.mjs` · `node tests/game-loop.mjs`. `release/demo/goei-action-game.html`은 빌드가 만든다. main push·릴리스는 사용자가 「릴리스해」라고 할 때만.
