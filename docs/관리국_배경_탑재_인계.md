## 3. 논의할 것

1. 이전 결정(`docs/배경_범위_검토_2026-10-24.md` 5절: 2F 진압팀·1F 면담실·지하 한 층)과 다름. 배경이 6개 층이라 현재 장소 목록 기준으로 다시 짬. 진압팀은 게임에 장소가 없음.
2. 출동을 B3 주차장 승합차로 옮길지(현재는 잼트리 자리에서 임무 → 출동).
3. 각 배경의 문·엘리베이터 x 좌표 측정과 상호작용 범위.
4. 본부 장면이 지금 한 줄 벨트(장소 x 나열)라, 층별 장면 + 층 이동 구조로 바꾸는 범위.

## 4. 작업 규칙

`docs/게임_통합_현황.md` 따름. 엔진(`engine/`)·`main.ts`는 「전투와 조작」 담당. 올리기 전 `npm run build` · `npm test` · `node tests/engine-browser.mjs` · `node tests/game-loop.mjs`. `release/demo/goei-action-game.html`은 빌드가 만든다. main push·릴리스는 사용자가 「릴리스해」라고 할 때만.

## 5. 확정 배치와 구현 (2026-10-25, 이 스레드)

**사용자 확정 배치 (서→동)**

| 층 | 문 → 장소 |
| --- | --- |
| 1F | 현관 → 거리 · 안내 데스크(NPC 자리, 별도 스레드에서 구현 중) · 엘리베이터 · 계단(위·아래) |
| 2F | 화장실(열림) · 유리문 → 진압팀 · 엘리베이터 · 회의실(잠김) · 면담실 · 계단(위·아래) |
| 3F | 화장실(열림) · 탕비실(메뉴) · 휴게실 · 엘리베이터 · 자동 유리문 → 종합대응팀(시작 사무실) · 계단(아래) |
| B1 | 교육장(열림, 새 방) · 훈련장 · 엘리베이터 · 샤워실 남·여(잠김) · 계단(위) |
| B2 | 심문실(잠김) · 격리실 셔터 → 지금은 이빨 요정 격리실(셔터 뒤 큰 격리실들은 나중) · 엘리베이터 · 의무실·연구실(의무실+격리 연구실 한 방, 감정·연구도 여기) · 창고·서고(잠김) |
| B3 | 승합차 → 출동 · 보급실(메뉴) · 엘리베이터 |

- 아무것도 없는 방은 잠김(덜컹 + 「잠겨 있다」). 출동: 3층 잼트리 자리에서 「출동 준비」 → B3 승합차 앞 E로 출발.
- 표찰: 2·3층만, 문 윗부분에 도트 글씨(그림에 표지가 있는 화장실·계단은 생략). 엘리베이터 앞에 서면 양쪽 방향 안내(← 이쪽 방들 · 이쪽 방들 →, 모든 층).

**구현 위치**
- 좌표: `src/game/action/hq/painted.ts` · 그리기: `src/game/action/art/hqField.ts` · 배치: `src/game/action/hq/map.ts` · 엔진 연결: `engine/hub.ts`(문 상태·계단 고르기·메뉴 문·잠긴 문·출동 차량).
- 문 열림: 배경에서 문짝 자리를 떠서 움직임(엘리베이터·자동문 = 양쪽 미닫이, 여닫이 = 경첩 쪽으로 접힘, 셔터 = 위로 말림). 들어온 문은 뒤에서 닫힘.
- 오브젝트: 로비 데스크(`game-src/art/field/objects/lobby/desk.*`), 엘리베이터 문짝 6층(`objects/<층>/elevator_*.png`, `tools/cut_hq_elevators.py`).
- 시간대 조명: 필드 시각(본편 시계)으로 새벽·낮·저녁·밤. 지상은 창밖 색·도시 불빛, 지하는 밤 절전만. 시험용 **T 키**(자동→새벽→낮→저녁→밤), 주소 `?hour=21`.
- B2 붉은 등: 셔터 위 경광등 맥박, 문 옆 표시등 번갈아 깜빡.
- 시연판 주인공: 에일린 테스트룸 완성본(agent-motion-set `motion_v3/에일린_테스트룸.html`)의 정리된 시트·기준점 25개 동작을 `tools/build_field_eileen.py`로 뽑아 씀(`game-pack/test-people/eileen_*.png`·`eileen.json`). 재생은 테스트룸 규칙(평상 대기 앞 두 장 0.6초, 걷기 11·뛰기 15장/초, 발밑 h-4). 엔진 동작(약·강·회피·점프·맞기 등)은 테스트룸 번호로 바꿔 그림.
- 설정 「캐릭터 크기」(60~160%, 기본 115% = 맨 뒤 1.65m가 235px). 그림만 바뀌고 판정은 그대로. 필드 주인공·방문 요원·시험 남자에 적용.
- 유리문: 투명 유리는 살짝만 열리고(미닫이 20%, 여닫이 30°) 틈은 밝은 실내 빛, 젖빛 유리(B2 의무실)는 다 열림. 여닫이는 경첩 축으로 돌며 먼 끝이 원근으로 짧아짐.

**알려진 결함 (검수 전)**
- 그림에 그려진 낮 햇빛 줄무늬·바닥 반사가 밤에도 남음(곱하기로 어둡게만 함).
- 옆벽 문(화장실·계단 등)의 원근 좌표는 눈으로 잰 값이라 열릴 때 1~3px 어긋날 수 있음.
- 진압팀·교육장·화장실·휴게실 안은 아직 색 상자 임시 방.
- `tests/game-loop.mjs`: 출동 뒤 층 진행 중 일시정지 메뉴에 「본부로 귀환」이 없어 멈춤(이번 변경 전부터, main에서도 앞 단계에서 실패). 본부 → B3 출발까지는 통과.
