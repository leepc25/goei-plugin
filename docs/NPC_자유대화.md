# NPC 자유 대화

게임 안에서 말을 걸 수 있는 사람과는 직접 글을 써서 대화한다. 보낼 때마다 본편과 같은 모델을 한 번 부르고, 답이 없거나 실패하면 미리 써 둔 대사로 대신한다. 게임은 기다리지 않는다(25초 넘으면 미리 쓴 대사).

## 어디에 있나

| 파일 | 하는 일 |
|---|---|
| `src/game/action/npc/roster.ts` | 명단: 이름, 인물 시트 이름, 게임 속 역할, 말투, 할 수 있는 행동, 미리 쓴 대사 |
| `src/game/action/npc/sheets.json` | 본편 로어북 인물 시트 (외모 칸 뺀 것). `python3 tools/npc_sheets.py`로 다시 뽑는다 |
| `src/game/action/npc/brain.ts` | 프롬프트 만들기, 답 읽기(태그 뽑기), 판정, 호감 저장 |
| `src/game/action/npc/index.ts` · `style.css` | 대화창 (본부 대화창과 같은 도트 틀) |
| `src/game/action/engine/npcLink.ts` | 엔진에 잇기: E 가로채기, 승객 훅, 백일몽 대치·동행 |
| `src/host/game/talk.ts` | 플러그인 쪽: 모델 호출(`runModel`, allowPlugins), 로어북 시트 읽기, 본편 최근 채팅 |

## 누구와

- 본부: 잼트리·고그니쟈·데쥬레·콘쥬스, 사무실의 다른 요원(버튼으로 바꿈), 면담실의 구조된 생존자
- 층: 중림 상인(마덕희, 고연지·윤지아, 신유리), 떠도는 승객, 사는 척하는 주민, 승강기
- 난입한 백일몽 탐사원: 처음엔 거리를 두고 지켜본다. 먼저 때리면 싸움, 말로 틀어지면 싸움, 말이 통하면 그 방 동안 같이 싸운다
- 아직 게임에 자리가 없는 사람(블라렛·살라딘·아벤샤·브라우니·탐미주의·가짜 관리국 이도형·곽성주, 상인 문혜란 등)은 명단에 있고, 그 사람이 들어오는 모듈이 `npc.talkTo(id, {...})`로 창을 연다

## 행동은 게임 코드가 정한다

모델은 대사 뒤에 태그를 붙여 "계기"만 준다. 태그를 받아들일지는 `decide()`가 정한다.

| 태그 | 조건 | 게임에서 |
|---|---|---|
| `[[호감 +1]]` / `[[호감 -1]]` | 한 번에 ±1, -3~+3 | 이름표 옆 칸, 저장됨 |
| `[[거래]]` | 거래 버튼이 있는 사람 | 상점 창 |
| `[[동행]]` | 호감 +1 이상 (승객·민간인 0 이상), 동행 가능한 자리 | 백일몽: 같은 편으로 싸움 · 승객: 돕기/따라가기 |
| `[[적대]]` | 호감 -2 이하 | 싸움 시작 (주민: 규칙 위반으로 돌변) |
| `[[떠남]]` | | 상인은 짐 싸서 떠남, 백일몽은 물러남, 승객은 지나침 |
| `[[힌트 N]]` | 게임이 준 단서 목록의 N번, 만남마다 한 번 | 단서 줄 |
| `[[선물 물건]]` | 정해진 물건만, 하루 한 번 | 소모품 칸에 들어감 |
| `[[진정]]` | 호감 0 이상 | 경계가 풀림 |

호감은 대화 말고도 게임 행동으로 움직인다(구조, 근처에서 때리거나 부수기). 적대와 동행·거래·선물은 함께 일어나지 않는다.

## 조작

- E: 말 걸기. 창이 열린 뒤 E·Space는 첫 버튼(원래 E가 하던 일), 1~9는 버튼, Enter·T는 입력칸, Esc는 닫기
- 터치: 창이 열리면 터치 버튼을 숨기고 창의 버튼·입력칸을 쓴다

## 본편과의 연결

- 읽기만: 상황판 사건, 그 요원의 본편 상태, 진영(시트 CBS). 설정 → 대화 → 「본편 최근 채팅 같이 보내기」를 켜면 본편 마지막 두 줄도 참고로 보낸다(기본 끔)
- 본편에 쓰는 것은 정산의 보고 버튼뿐. 대화는 본편 채팅·로어북에 남지 않는다
- 모델: 설정 → 대화 → 「NPC 대화 모델」 주 모델(기본)·보조 모델

## 지키는 것

- 콘쥬스(미성년자): 성적인 이야기, 노출, 씻기·옷 갈아입기 이야기를 하지 않는다는 줄이 프롬프트에 늘 붙는다
- 대사는 한국어 1~3문장, 이름표·지문·별표는 읽을 때 지운다
