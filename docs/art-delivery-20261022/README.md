- 컷신: `game-src/art/cutscene/raw/`의 1024×1024 PNG 14장.
- 동작: `game-src/action/jyaldi-v5/full/clips/` 아래 `shower` 6장, `bath` 4장, `toilet` 4장, `undress` 8장. 모두 192×144 RGBA. 목욕 수건으로 가리고 샤워는 뒷모습, 목욕·용변은 오른쪽 옆모습이다.
- 샤워 머리에 샴푸 거품이 있다. 탈의는 동작만 있으며 벗어 놓은 옷더미를 만들지 않는다. 물·욕조·부스·변기·목욕탕은 캐릭터 PNG에 없다. 해당 배경과 소품은 엔진에서 합성한다.
- 새 PNG를 직접 사용한다. 기존 `split/` 레이어 및 `jyaldi_fixes.py`의 과거 샤워 보정을 새 프레임에 적용하지 않는다. 기존 전체 데모를 다시 빌드하면 이 클립들이 제외될 수 있다.
- 위치와 속도는 `game-src/action/jyaldi-v5/full/gpt-bathing-20261022.json` 참고. 발 기준점은 배치용이며 실제 변기 좌석 접점은 소품에 맞춰 별도 조정한다.
- 독립 미리보기: `release/demo/jyaldi-bathing-gpt.html`. 파일 하나에 프레임이 포함되어 오프라인으로 열 수 있다. 동작 선택·재생/정지·한 장씩·처음부터·속도를 제공한다. 엔진 연결 완료를 뜻하지 않는다.
