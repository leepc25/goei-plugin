# GPT 요청서 · 잡몹 ① 차원 승강기 고유 10종 (2026-10-22)

**먼저 [GPT요청_잡몹_공통.md](GPT요청_잡몹_공통.md)를 끝까지 읽는다.** 저장 경로·캔버스·금지 사항·기본 장면 20장은 거기 있다.
순서대로 만든다: lurker → hollow → shooter → charger → thief → crawler → predator → edge → shade → hum. 이미 있는 몹·장은 건너뛴다.

무대: 끝없이 내려가는 낡은 사무실 건물. 몹들은 **먼저 갇힌 사람이 변한 것**이라 대부분 평범한 옷을 입고 있고, 한 군데만 사람이 아니다. 피·내장 묘사는 하지 않는다. 무서움은 자세와 비율로 낸다.

## 1. `lurker` 해롭지 않아 보이는 것 · 사람 192×144 · 키 102px

- 생김: 야근하는 회사원. 회색 와이셔츠, 느슨한 남색 넥타이, 짙은 회색 바지, 사원증 줄. **어깨가 처지고 목이 보통보다 손가락 두 마디 길다.** 얼굴은 무표정, 눈만 검은 점.
- 노는 법: 로비 구석에 가만히 서 있다가, 가까이 오거나 등을 보이면 **고개가 몸보다 먼저 180° 돌고** 물어뜯는다.

| --- | --- | --- |
| 기본 장면 | 20 | `idle`은 **가만히 서 있는 척**: 고개 숙인 채 거의 안 움직임 |
| `turn` | 3 | 몸은 왼쪽(뒤)을 보는 채 고개만 돎: 뒷머리 → 옆 얼굴 → 얼굴이 등 쪽에 붙어 이쪽을 봄 (이 클립만 몸이 왼쪽을 봄) |
| `snap_tele` `snap_hit` `snap_rec` | 2·2·1 | 물어뜯기: 목을 뒤로 빼고 → 목이 쭉 늘어나 앞으로 문다 |
