## 무엇을 만드나
아카라이브(arca.live) 게시글로 올릴 **봇 소개 페이지**. RisuAI용 괴담 시뮬레이션 봇 「괴이 ː ANOMALY」(제목의 가운데 글자는 U+02D0 `ː`)를 처음 보는 사람에게 보여 주는 페이지다.
플러그인 소개가 아니다. **봇**이 주인공이고, 플러그인 화면은 「이 봇 안에서 겪는 일」로 보여 준다.

## 주인(사용자)이 앞선 시안을 전부 버린 이유 — 그대로 옮김. 같은 짓을 하면 실패다
- 「내용이 이게 다야?」 메뉴 이름을 한 줄씩 늘어놓아 내용이 빈약했다.
- 「이미지 첨부는 안해? 글로만 찌끄리면 다야?」 그림 없이 글만 있었다.
- 「너같으면 이거 보고 흥미를 느끼겠냐?」
- 「저거 인물 저렇게 좃같이 늘어놓는거 하지 마라」「저게 말이 되는거냐?」 소속도 편도 다른(서로 적인) 인물들을 한 팀처럼 어깨 겹쳐 세운 표지.
- 「셋다 병신같은데 진짜 이게 최선이야?」「개밥 쉰내나게 만들지좀 말고」 시안 셋이 「그림 한 장 → 제목 → 테두리 상자 줄 세우기 → 캡처」 같은 뼈대에 색만 달랐다. 어두운 바탕 + 붉은 그라데이션 + 테두리 카드 + 자간 벌린 영문 라벨(ANOMALY SIMULATION · RISUAI) + 칩 + 큰 번호(01, 05).
- 「넌 너무 감각이 없어」「봇 소개 페이지를 디자인하는거야」「왜 말투는 개 좃같이 싸구려 AI 문체에」「어느 쪽에 설까요?」 지어낸 광고 문구.
- 「좀 감각적이고」 ← 이것이 요구다.

## 만드는 형식 — 아카라이브 제약을 넘는 방법
아카라이브 글은 인라인 style만 되고 `position`·`flex`·`grid`·배경 그림·겹치기가 전부 막힌다(자세한 것은 `kit/아카라이브_HTML_GUIDE_v6.7.1.md` 1장·6장·7-7-1). 그래서 페이지를 두 가지 조각을 세로로 쌓아 만든다.

- **`.plate` = 그림 조각.** 자유 CSS로 마음껏 디자인한다(겹치기, 큰 글자, 웹폰트, 그림 위 글자 전부 됨). 빌드할 때 통째로 JPG 한 장으로 찍혀 글에 그림으로 들어간다. 폭은 반드시 860px.
  - 폰에서는 이 그림이 폭 360px로 줄어든다(0.42배). **그림 속에서 읽혀야 하는 글자는 30px 이상**(가능하면 34px 이상)으로. 그보다 작은 글자는 폰에서 안 읽힌다 — 안 읽혀도 되는 장식에만 쓰고 그 요소에 `data-deco`를 붙인다.
  - 긴 글·작은 글은 그림에 넣지 말고 `.arca`로.
- **`.arca` = 진짜 HTML 조각.** 아카라이브에 그대로 붙는 글. 인라인 `style`만, class 금지, 지침서의 금지 목록(flex·grid·position·overflow·opacity·transform·filter·url() 등)과 금지 태그 금지. 가로 나란히는 `display:inline-block`이나 `display:table`/`table-cell`. 글자 14px 이상. 폰 360px에서 줄이 깨지지 않게. 폰트는 기기 것이 쓰이니 `font-family:'Pretendard','Noto Sans KR','Apple SD Gothic Neo','Malgun Gothic',sans-serif` 또는 명조 `'Noto Serif KR','Nanum Myeongjo','AppleMyungjo','Batang',serif` 계열로 적고 폰트 이름에 기대지 않는다.
  - 아카라이브 바탕은 라이트(#fff)·다크(#222) 둘 다다. `.arca` 조각은 자기 바탕색을 스스로 가진다. 밝은 바탕에 어두운 글자를 쓰면 다크모드에서 글자색이 지워지니 지침서 7-7-1의 `background-color:rgba(0,0,0,0.004)` 가드를 글자색 있는 요소마다 붙인다.
  - 받기 단추는 지침서 6-6 방식(`<a>` 안의 inline-block 자식에 모양).
- 그림 조각과 HTML 조각이 **이음매 없이 한 페이지로 보여야** 한다(바탕색·여백·글자 결을 맞춘다).

## 감각에 대하여
- 「감각적」이란 장식을 더하는 것이 아니다. 무엇을 크게, 무엇을 비워 둘지의 결단, 그림을 자르는 눈, 글자의 크기 대비와 자간·행간, 한 페이지를 내려가는 호흡이다. 잡지·화보·영화 포스터·전시 도록을 만드는 아트 디렉터의 눈으로.
- 상자에 넣고 테두리 치는 버릇, 구획마다 같은 틀을 반복하는 버릇, 칩·배지·번호 붙이는 버릇, 가운데 정렬로 도망가는 버릇, 그라데이션으로 때우는 버릇을 버린다.
- 이 봇의 맛은 「출근하는 괴담」이다. 검은 정장, 회사 말투, 붉은 가로등, 그리고 위키의 건조한 농담(「재방문 후기: 없음」「회식: 근처 파스타집」). 무섭게 꾸미지 말고 그 건조함을 살린다.
- 글은 적게, 그러나 실제 글의 좋은 문장을 골라 크게. 좋은 문장을 고르는 것이 이 일의 절반이다. 자료를 충분히 읽는다.
- 금지 재탕: 「검정+진홍 그라데이션 포스터」「크림 종이 대외비 문서·도장」「청록 CCTV 상황실」 — 앞서 버려진 세 가지다.
