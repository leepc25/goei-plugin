# 필드 배경을 조립식 타일로 (2026-10-28, 사용자 결정 정리)

## 정한 것

- **3D 캐릭터는 멈춘다.** 모델·동작·렌더링 모두 쓸 수 없는 품질(사용자). 코드와 도구는 남기고 기록은 `docs/3D_캐릭터_제작_정리.md`.
- **배경을 GPT 한 장 그림으로 통째로 그리는 방식은 그만 간다.** GPT는 창밖 풍경·먼 배경 정도만.
- **바닥·벽·가구·소품을 PixelLab으로 뽑아 조립한다.** 요원 그림과 같은 **low top-down** 시점·같은 도트 기준.
  - 바닥: 타일셋(`/create-tileset`, 두 재질 16칸 오토타일) + 변형 타일(`/create-tiles-pro`)
  - 벽·문·기둥·계단: 건물 세트(`/create-tiles-pro`, `tile_feature: building`)
  - 가구·소품: 낱개 물건(`/map-objects` 또는 `/create-1-direction-object`). 의자·소파·침대는 좌석 높이·깊이를 표준으로 맞춰 앉는 그림 하나가 다 맞게.
- **타일 방에서는 원근(안쪽 85% 축소)을 쓰지 않는다.** 던파처럼 앞뒤 같은 크기. 사용자: "원근은 안 해도 돼, 포기해도 상관없어".
- 방은 별도 맵 에디터(리스 밖 HTML)로 조립 → zip 내보내기 → 저장소에 올리면 빌드가 게임 팩으로.

## 비용

PixelLab 월 구독(Tier 3)의 생성 횟수에서 빠진다. 추가 결제 없음. 10-28 잔량 약 11,400 / 44,069.
- 낱개 물건(1방향): 10~25회. 상태 바꾸기·작은 수정: 1회 안팎.
- 타일셋·타일·맵 오브젝트: 문서에 단가 없음 → 첫 호출 때 잔량 차이로 재서 여기 적는다.

## 아직 안 한 것

- 첫 시험(타일셋 1벌 + 소품 몇 개로 방 하나 조립) — 사용자 승인 대기.
- 맵 에디터.
