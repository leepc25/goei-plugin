# 4.8_블라렛 기술 재설계

- 근거: 교황청 특급 전투 수녀, 반흡혈귀 신체. 「어떤 십자가에서든 빛나는 흰 십자가 모양의 신성한 장검을 뽑아낸다」, 손바닥에서 신성한 불꽃, 주무기 「은탄 쌍권총, 은 말뚝, 그리고 아무 십자가」, 근처 교회를 「고딕 십자군 대성당」으로 바꾸고 갑옷 성기사가 걸어 나옴(위키). 능력 쓰기 전 「재밌는 거 보여 줄까요? …찰칵.」 과시형 자신감.
- 싸우는 방식 한 줄: 「십자가에서 뽑은 빛의 장검으로 크게 베고, 쌍권총과 손바닥 성화로 밀어붙이는 결투가형 사냥꾼」

## 고유기술(D) 「성검 발현」
- 하는 일: 가슴의 은 십자가를 두 손으로 쥐어 뒤 어깨 옆으로 당기면 십자가에서 흰 빛의 십자 장검이 뽑혀 나오고, 아주 깊은 런지와 함께 앞 무릎 높이까지 크게 내려벤다. 앞 0.5~2.5m, 위에서 아래로 큰 호 한 번. 맞은 적은 바닥에 내리꽂혔다 튕긴다. 검은 베고 나면 빛으로 흩어짐.
- 분류: 공격(앞 큰 내려베기 호)
- 상대 반응: 쓰러지기(바닥에 내리꽂혀 작게 튕김)
- 전용 이펙트: GPT `fx_블라렛_성검`(6장 · 96×256 손에 생기는 흰 십자 장검, 빛줄기) · `fx_블라렛_성검베기`(6장 · 256×128 흰 금빛 내려베기 궤적). 코드: 괴이 적을 맞히면 흰 연기(그림만, 피해 같음).
- 동작: 22번 그대로(5~7장 두 손 무릎 높이 = 내려베기).

## 충전기(S) 「은탄」
- 두 권총을 가슴 앞에 X자로 교차해 모으고(눈이 초록으로 빛남), 단계에 따라 쏘는 모양이 바뀐다.
- 0단: 쌍권총 한 발씩 두 발 → 앞 직선 8m, 가는 탄 두 줄.
- 1단: 좌·우 번갈아 6연사 → 위아래로 조금씩 퍼지는 탄 다발(앞 8m, 폭 0.8m 띠).
- 2단: 총을 쏘지 않고 앞 권총을 허리로 내린 뒤 손바닥을 내밀어 성화를 뿜음 → 앞 부채꼴 4m(60도)를 흰 금빛 불꽃이 덮고, 맞은 적은 불길에 떠밀려 크게 밀려남.
- 모양 변화: 가는 직선 두 줄 → 굵은 직선 다발 → 짧고 넓은 부채꼴
- 분류: 0·1단 공격(투사체) / 2단 공격+제압(밀쳐 냄)
- 상대 반응: 0단 맞기(상단) / 1단 맞기 여러 번(경직) / 2단 크게 밀려나기
- 전용 이펙트: 공용: 총구 두 개. GPT `fx_블라렛_성화`(8장 · 320×160 손바닥에서 퍼지는 흰 금빛 불꽃, 끝이 투명).
- 동작: 모으기 23번 그대로. 방출 0단 = 24번 2~3장 / 1단 = 24번 1~5장(사격 구간 2~4장 한 번 더 반복) / 2단 = 24번 1장 + 6~8장(손바닥 성화).

## 필살기(F) 「영원한 십자군」
- 연출 순서:
  1. 컷인(십자가에서 장검이 사선으로 뻗어 나오는 그림) + 「재밌는 거 보여 줄까요? …찰칵.」
  2. 묵주를 풀어 쥐고 성호를 긋는 동안, 화면 뒤 땅을 뚫고 반투명 고딕 대성당이 솟아오름(첨탑 끝이 화면 위를 넘음).
  3. 은 십자가를 높이 쳐들면 대성당의 스테인드글라스 창 다섯 개에서 색 빛기둥이 차례로 적 머리 위로 내리꽂힘(빛기둥마다 적을 바닥에 짓눌렀다 튕김).
  4. 「나와라!」 앞으로 내지르면 대성당 정문이 열리고 갑옷 성기사 여섯이 한 줄로 걸어 나와 일제히 장검을 내려침 → 앞쪽 화면 가로 전체 띠에 흰 빛 충격.
  5. 그녀가 장검을 쥔 자세로 앞장서면 성기사와 대성당이 흰 빛 가루로 흩어짐.
- 상대 반응: 빛기둥 맞기(하단) → 띄워지기 → 쓰러지기
- 전용 이펙트(크고 화려하게): GPT `fx_블라렛_대성당`(8장 · 768×512 솟아오르는 반투명 고딕 대성당 실루엣, 스테인드글라스 빛) · `fx_블라렛_빛기둥`(6장 · 128×512 위에서 내리꽂히는 붉고 푸른 스테인드글라스 색 빛기둥) · `fx_블라렛_성기사`(걷기 6장 + 내려베기 4장 · 128×256 반투명 흰 금빛 갑옷 기사, 얼굴 없는 투구). 코드: 흔들림 강, 마지막 화면 흰 번쩍임.
- 동작: 25번 그대로(묵주·성호 = 2단계, 십자가 쳐들기 = 3단계, 내지르기 = 4단계, 검 쥔 자세 = 5단계).

## 앞 설계와 달라진 점
- 고유기술·충전기의 「흡혈귀·괴이 피해 2배」「2초·3초 화상」(강화·표식 성격) → 뺌, 괴이 적은 흰 연기 그림만.
- 충전기는 「같은 사격이 세지기」에서 「두 발 → 다발 → 성화 부채꼴」로 모양이 바뀌게.
- 필살기 성기사 12초 소환 돌격(살라딘 군세 돌격과 겹침) → 대성당 스테인드글라스 빛기둥이 위에서 내리꽂히고 성기사가 한 줄로 일제히 내려베는 그림으로. 구속·표식·강화 0개.
