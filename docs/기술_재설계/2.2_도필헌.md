# 2.2_도필헌 기술 재설계

- 근거: 위키 「수갑부터 풀게 하고, 의자를 권하고, 반갑다고 인사한다」, 「가만히 앉아 있는 것만으로 방을 장악하는 타입」, 「미끼 같은 질문을 하나 던지고, 반응을 본 다음 값을 매겨서 다음 정보를 꺼낸다」, 「현장 장비는 하나도 들고 다니지 않는다」. 동작표: 몸은 택견 발질(째차기·발따귀·곁차기·두발당성·딴죽).
- 싸우는 방식 한 줄: 「점잖게 의자를 권하는 손짓 그대로 딴죽으로 주저앉히고, 손은 안 쓰고 택견 발로 처리하는 면담실 주인」

## 고유기술(D) 「앉게.」
- 하는 일: 한 보폭 내디디며 손바닥을 위로 낮게 펼쳐 자리를 권하는 손짓과 함께, 뒷다리 위로 낮게 내려앉아 바닥을 미끄러져 들어간다(앞 3m) → 앞발로 적의 발목을 걸어 당기면 적이 다리가 걷혀 뒤로 넘어가며 등부터 바닥에 떨어진다. 도필헌은 일어나 허리 숙여 인사하고 선글라스를 밀어 올린다.
- 분류: 이동+제압(넘어뜨림)
- 상대 반응: 맞기 하단(발목) → 주저앉아 뒤로 쓰러지기
- 전용 이펙트: 없음. 공용: 흙먼지(미끄러짐 띠), 타격_약(발목). 코드: 발끝 황동색 짧은 호.
- 동작: 22번 1~3장(권하는 손) + 13번(돌진 딴죽) 그대로 + 22번 4~8장(인사·선글라스)

## 충전기(S) 「값을 매기지」
- 모으는 동안: 턱을 괴고 상대를 재는 자세. 단계가 오를 때마다 머리 위에 황동색 주판알 도트가 하나씩 튀어 오름(단계 표시만).
- 0단: 곁차기 — 발바닥으로 가슴 높이를 곧게 밀어 앞 1.5m 적을 직선으로 3m 밀쳐 냄.
- 1단: 발따귀 — 뒷발을 머리 높이로 곧게 차올려 앞 1.5m 적을 위로 높이 띄움(공중 추가타 가능).
- 2단: 악수를 청하듯 손을 내밀어 앞 2m 적의 손을 잡고 내 앞으로 홱 끌어당긴 뒤, 두발당성으로 공중에서 두 발을 차례로 차올려 적을 2연타로 높이 띄우고 착지 둘레(반경 1.5m)에 발 구름 충격파.
- 분류: 공격(밀어차기 / 올려차기 / 끌어당겨 공중 2연타 + 둘레 원)
- 상대 반응: 0단 크게 밀려나기 · 1단 띄워지기 · 2단 끌려옴 → 띄워지기 ×2 / 둘레 적 밀려나기
- 전용 이펙트: 공용: 타격_약·타격_강·충격파, 발끝 황동색 호(코드, 발 궤적 1줄)
- 동작: 모으기 23번(턱 괴고 재기) · 0단 = 11번 약3 곁차기 그대로 · 1단 = 10번 약2 발따귀 그대로 · 2단 = 24번 1~4장(악수 런지 = 잡아끎) + 12번 강 두발당성

## 필살기(F) 「거짓말이 빠진 방」
- 연출 순서:
  1. 컷인 뒤 화면 가장자리가 어두워지며 위에서 면담실 조명 원뿔 하나가 도필헌 위로만 내려옴(코드 조명). 그는 앉은 듯 무게를 낮추고 손바닥을 위로 펴 자리를 권한다.
  2. 낮게 미끄러지는 딴죽으로 화면을 한 번 가로지르며 길 위 적마다 발목을 걸어 다리를 걷어 뒤로 넘어뜨린다(앞 줄 전원).
  3. 끝에서 일어나 곁차기 → 발따귀를 이어 가장 강한 적을 밀었다 머리 높이로 차올리고, 이어 깊이 웅크렸다 두발당성으로 공중에서 두 발을 차례로 차올려 그 적을 높이 띄운다.
  4. 「앉게」 손을 앞 아래로 내미며 깊이 무게를 낮추는 순간, 두발당성 착지 충격이 황동색 고리로 화면 바닥 폭 전체에 퍼져 넘어져 있던 적 전원이 사방으로 튕겨 다운.
- 상대 반응: 쓰러지기(다리가 걷혀 등부터) → 대상은 밀려났다 띄워지기 ×3 → 착지 충격에 전원 띄워졌다 다운
- 전용 이펙트(크게): 없음 — 화면 바닥 폭으로 퍼지는 황동색 착지 충격 고리(공용: 충격파를 황동색으로 크게), 딴죽이 지나간 길의 흙먼지 띠, 발끝 황동색 호(코드). 조명 원뿔·가장자리 어둠(코드). 공용: 타격_강.
- 동작: 25번 1~2장(권하는 손) → 13번(딴죽) 길게 → 11번(곁차기) + 10번(발따귀) + 12번(두발당성) → 25번 6~12장(「앉게」 · 앉은 듯 = 충격, 전투 자세). 모두 기존 줄.

## 앞 설계와 달라진 점
- 고유기술: 「손님」 3초 구속 + 받는 피해 +50% 표식 → 의자가 오금을 쳐서 주저앉혀 넘어뜨리는 제압.
- 충전기: 약점 표시(표식)·공격 +15%(강화)·적 영입(소환·싸움 밖) → 택견 발질 세 가지로 단계마다 밀기·띄우기·끌어당겨 공중 연타.
- 필살기: 속임수 해제·피해 -20%(강화) 같은 보이지 않는 규칙 → 의자 빼기·책상 낙하로 실제로 쓰러뜨리는 면담실.
- 구속 0, 표식 0, 강화 0.
- (맥락 정리) 고유기술의 미끄러져 오는 면담 의자, 필살기의 적마다 솟는 의자·빼 주는 의자·떨어지는 면담 책상·쏟아지는 서류·명패·찻잔을 모두 걷어 냈다(위키 「현장 장비는 하나도 들고 다니지 않는다」). 「앉게.」는 동작표 13번 딴죽으로 엉덩방아를 찧게 하는 것으로, 필살기는 딴죽 → 택견 세 발 → 두발당성 착지 충격 고리로. 물건 그림 3개(의자·책상·서류 묶음)가 빠짐.
- (톤 정리) 고유기술·필살기의 딴죽 결과 「털썩 엉덩방아」를 다리가 걷혀 등부터 바닥에 떨어지는 넘어짐으로 바꿨다(13번 그대로).
