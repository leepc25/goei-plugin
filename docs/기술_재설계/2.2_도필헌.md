# 2.2_도필헌 기술 재설계

- 근거: 위키 「수갑부터 풀게 하고, 의자를 권하고, 반갑다고 인사한다」, 「가만히 앉아 있는 것만으로 방을 장악하는 타입」, 「미끼 같은 질문을 하나 던지고, 반응을 본 다음 값을 매겨서 다음 정보를 꺼낸다」, 「현장 장비는 하나도 들고 다니지 않는다」. 동작표: 몸은 택견 발질(째차기·발따귀·곁차기·두발당성·딴죽).
- 싸우는 방식 한 줄: 「점잖게 의자를 권하는 손님 대접 몸짓으로 적을 주저앉히고, 손은 안 쓰고 택견 발로 처리하는 면담실 주인」

## 고유기술(D) 「앉게.」
- 하는 일: 한 보폭 내디디며 손바닥을 위로 낮게 펼쳐 의자를 권하면, 바닥을 미끄러져 온 면담실 의자 하나가 앞 3m 적의 오금을 탁 침. 적은 털썩 의자에 주저앉았다가 의자째 뒤로 넘어감. 도필헌은 허리 숙여 인사하고 선글라스를 밀어 올림.
- 분류: 제압(넘어뜨림)
- 상대 반응: 맞기 하단(오금) → 앉았다 뒤로 쓰러지기
- 전용 이펙트: `fx_도필헌_의자`(가죽 면담 의자가 미끄러져 오는 2장 + 넘어가는 4장, 64×96), 공용: 흙먼지(작게)
- 동작: 22번 그대로(2~3장 권하는 손 = 의자 출발, 4~6장 인사, 7~8장 선글라스)

## 충전기(S) 「값을 매기지」
- 모으는 동안: 턱을 괴고 상대를 재는 자세. 단계가 오를 때마다 머리 위에 황동색 주판알 도트가 하나씩 튀어 오름(단계 표시만).
- 0단: 곁차기 — 발바닥으로 가슴 높이를 곧게 밀어 앞 1.5m 적을 직선으로 3m 밀쳐 냄.
- 1단: 발따귀 — 뒷발을 머리 높이로 곧게 차올려 앞 1.5m 적을 위로 높이 띄움(공중 추가타 가능).
- 2단: 악수를 청하듯 손을 내밀어 앞 2m 적의 손을 잡고 내 앞으로 홱 끌어당긴 뒤, 두발당성으로 공중에서 두 발을 차례로 차올려 적을 2연타로 높이 띄우고 착지 둘레(반경 1.5m)에 발 구름 충격파.
- 분류: 공격(밀어차기 / 올려차기 / 끌어당겨 공중 2연타 + 둘레 원)
- 상대 반응: 0단 크게 밀려나기 · 1단 띄워지기 · 2단 끌려옴 → 띄워지기 ×2 / 둘레 적 밀려나기
- 전용 이펙트: 공용: 타격_약·타격_강·충격파, 발끝 황동색 호(코드, 발 궤적 1줄)
- 동작: 모으기 23번(턱 괴고 재기) · 0단 = 11번 약3 곁차기 그대로 · 1단 = 10번 약2 발따귀 그대로 · 2단 = 24번 1~4장(악수 런지 = 잡아끎) + 12번 강 두발당성

## 필살기(F) 「거짓말이 빠진 방」
- 연출 순서:
  1. 컷인 뒤 화면 가장자리가 어두워지며 위에서 면담실 조명 원뿔 하나가 내려옴. 화면 안 적마다 등 뒤 바닥에서 면담 의자가 하나씩 솟아남.
  2. 도필헌이 두 손으로 의자 등받이를 쥐고 뒤로 빼 주는 순간, 적들 뒤의 의자가 일제히 뒤로 홱 빠짐 → 앉으려던 적 전원이 엉덩방아를 찧음.
  3. 「앉게」 손을 앞 아래로 내미는 순간, 화면 위에서 커다란 면담 책상이 쿵 떨어져 화면 가운데를 내리찍음(책상 다리 네 개 자리에 충격파).
  4. 도필헌이 앉은 듯 깊이 무게를 낮추면 책상 위의 서류·명패·찻잔이 적 쪽으로 쏟아져 날아가고, 바닥에 주저앉은 적 전원이 책상 충격파에 사방으로 튕겨 다운.
- 상대 반응: 쓰러지기(엉덩방아) → 띄워지기 → 다운
- 전용 이펙트: `fx_도필헌_면담책상`(384×256, 위에서 떨어져 박히는 짙은 나무 책상 8장), 적마다 `fx_도필헌_의자` 빠지는 장, 조명 원뿔·가장자리 어둠(코드), 공용: 충격파(크게)·흙먼지
- 동작: 25번 그대로(1~5장 의자 빼 주기, 6~8장 「앉게」 = 책상 낙하, 9~11장 앉은 듯 = 충격, 12장 전투 자세)

## 앞 설계와 달라진 점
- 고유기술: 「손님」 3초 구속 + 받는 피해 +50% 표식 → 의자가 오금을 쳐서 주저앉혀 넘어뜨리는 제압.
- 충전기: 약점 표시(표식)·공격 +15%(강화)·적 영입(소환·싸움 밖) → 택견 발질 세 가지로 단계마다 밀기·띄우기·끌어당겨 공중 연타.
- 필살기: 속임수 해제·피해 -20%(강화) 같은 보이지 않는 규칙 → 의자 빼기·책상 낙하로 실제로 쓰러뜨리는 면담실.
- 구속 0, 표식 0, 강화 0.
