- 이미 있는 쟈알디 이펙트 4개(손바닥 폭파·연쇄·원형·필살 폭발)와 공용 바닥 파괴 1개는 「있음 · 다시 뽑기: 검토」로 적었다. 위 숫자에 들어 있다.

- 크기: 작음 = 손 앞 / 중간 = 사람만 함 / 큼 = 화면 절반 이상.
