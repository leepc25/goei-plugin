# 1.3_잼트리 기술 재설계

- 근거: 위키 「초능력은 없다. 전투 기록도 없다」, 「손에는 늘 태블릿, 탕비실에는 늘 연유 커피」, 「복장은 검은 오피스 스커트 정장에 하이힐 … 또각또각」, 「웃는 얼굴 그대로 "스톱. 이름 말하지 마."」, 「그 미소는 필요 없어지면 완전히 꺼진다 … 독기 서린 날카로운 눈빛」. 동작표 개성표: 전투 자세는 뒷손 허리·앞손 검지로 겨눔(「스톱.」), 약1 두 손가락 찌르기·약2 손등 털기·약3 하이힐 내리찍기·강 붙잡아 무릎 올려치기·돌진 다이빙 두 손바닥 밀치기.
- 싸우는 방식 한 줄: 「웃는 얼굴 그대로 두 손가락으로 목덜미를 찌르고, 웃음이 꺼지면 붙잡아 무릎과 하이힐 굽으로 끝내는 맨손 근접형」

전투 능력이 없는 인물이라 기준 1-4대로 물건을 지어내지 않고 동작표의 몸 기술(두 손가락 찌르기·손등 털기·하이힐 굽·붙잡아 무릎)로만 싸운다. 위키 「누가 커피를 한 모금 마시는 순간을 노려 목덜미나 등을 손끝으로 쿡 찌른다」가 손버릇의 근거. 회복·정보·버프는 두지 않는다.

## 고유기술(D) 「목덜미 쿡」
- 하는 일: 또각 한 발 깊은 런지로 파고들며 두 손가락을 목 높이로 곧게 찔러 넣는다(앞 0.5~1.2m) → 거두는 손 대신 허리의 뒷손이 올라와 얼굴 높이를 손등으로 납작하게 턴다. 첫 찌르기에 적이 목을 움츠리며 움찔하고, 손등에 고개가 옆으로 꺾이며 뒤로 밀려난다.
- 분류: 공격(짧은 앞 2연타)
- 상대 반응: 맞기 상단(목) → 맞기 상단·밀려나기
- 전용 이펙트: 없음. 공용: 타격_약(손끝 점·손등). 코드: 손끝에 올리브 초록 짧은 섬광.
- 동작: 9번(약1 두 손가락 찌르기) + 10번(약2 손등 털기)을 빠르게 이어 붙임. 22번(두 손 내밀기)은 쓰지 않는다.

## 충전기(S) 「정보 정리」
- 0단: 손바닥을 두드리던 손을 멈추고 몸을 수평으로 날려 두 손바닥으로 밀친다 → 앞 3m 일직선 다이빙, 처음 닿은 적이 가슴을 밀려 뒤로 크게 밀려난다.
- 1단: 웃음이 꺼지며 한 걸음 붙어 앞 적을 두 손으로 움켜쥐고 끌어내리며 뒷무릎을 가슴 높이로 올려친다 → 앞 1m 한 명, 적이 접히듯 떠올랐다 떨어진다.
- 2단: 1단처럼 무릎으로 띄운 적이 떨어지는 자리에 하이힐 굽을 체중 실어 내리찍어 바닥에 박고, 고개를 들어 「스톱.」 검지를 내지른다 → 박힌 자리 둘레(반지름 1.5m)로 작은 충격이 퍼져 옆 적들도 휘청한다. 한 박자 뒤 다시 환하게 웃는다.
- 모양 변화: 앞으로 뻗는 돌진 → 붙어서 한 명 띄움 → 박아 넣고 둘레 원
- 분류: 0단 이동+제압(밀쳐 냄) / 1단 공격(띄움) / 2단 공격(박음 + 둘레 원)
- 상대 반응: 0단 크게 밀려나기 / 1단 띄워지기 → 쓰러지기 / 2단 바닥에 박혀 바운드, 둘레 적 맞기 하단
- 전용 이펙트: 없음. 공용: 타격_강(무릎·굽), 충격파(작게, 2단 둘레), 흙먼지(0단 착지).
- 동작: 모으기 23번 그대로(손바닥 두드리기). 방출 0단 = 13번(다이빙 두 손바닥 밀치기) 그대로 / 1단 = 12번(붙잡아 무릎 올려치기) 그대로 / 2단 = 12번 + 11번(약3 하이힐 내리찍기) 4~8장 + 24번 그대로(노려보며 검지 → 웃음).

## 필살기(F) 「모두의 언니」
- 연출 순서:
  1. 컷인(햇살 미소, 눈 끝만 차갑게) → 하이힐 굽을 두 번 구르는 소리가 복도에 울린다.
  2. 웃음이 꺼진다. 허리 높이로 숙여 종종 파고드는 걸음으로 화면 안 적 사이를 차례로 누비며, 지나치는 적마다 목덜미를 두 손가락으로 깊이 찔러 넣는다(최대 6명). 찔린 적은 목을 움켜쥔 채 숨이 막혀 그 자리에 무릎이 꺾인다.
  3. 끝에서 되돌아서 무릎 꿇은 적들 사이를 거꾸로 다시 누비며, 적마다 앞무릎을 들었다 하이힐 굽을 체중 실어 어깨·등에 내리찍어 얼굴부터 바닥에 박는다. 굽이 박힐 때마다 올리브 초록 타격 불꽃이 크게 터지고 바닥이 울린다.
  4. 처음 자리 앞의 마지막 적을 두 손으로 움켜쥐어 무릎으로 높이 올려치고, 떨어지는 그 적을 손등으로 후려쳐 바닥에 내동댕이친다.
  5. 고개를 들어 차갑게 노려보며 「스톱.」 검지를 내지르고, 한 박자 뒤 다시 환하게 웃는다.
- 상대 반응: 찔림 = 맞기 상단 → 무릎 꿇기(목을 움켜쥠) → 굽에 바닥에 박혀 바운드 → 다운. 마지막 대상은 띄워졌다 손등에 내동댕이쳐져 다운. 몸동작 내내 무적.
- 전용 이펙트(크게): 없음 — 굽이 박힐 때마다 크게 터지는 올리브 초록 타격 불꽃(공용: 타격_강을 초록으로 크게, 적마다 차례로), 누빈 길의 낮은 초록 잔상(코드). 공용: 흔들림(필살).
- 동작: 25번 1~3장(굽 두 번) → 16-1번(앞 회피 숙여 파고들기) + 9번 4~6장(찌르기)을 적 수만큼 빠르게 → 16-1번 + 11번 4~8장(하이힐 내리찍기)을 적 수만큼 → 12번(붙잡아 무릎) + 10번(손등 털기) → 24번 그대로(노려보며 검지 → 웃음). 25번 4~12장(두 팔 활짝·손가락 총 윙크)은 쓰지 않는다. 모두 기존 줄.

## 앞 설계와 달라진 점
- 고유기술의 회복·「공격 속도 +15%」, 충전의 숨은 적 표시·「기록 삭제」(구속), 필살기의 회복·「받는 피해 -30%」·「정리 대상」 표식을 모두 지웠다. 구속·표식·강화 0개.
- 같은 물건·몸짓(커피 잔 내밀기, 태블릿 두드리기 → 「스톱.」, 하이힐 또각)을 그대로 두고 그 물건이 적을 치게 바꿨다.
- (겹침 정리) 충전 2단의 「하늘에서 떨어지는 바인더」와 필살기의 「화면 위에서 쏟아지는 물건 비·떨어지는 거대 머그잔」은 위에서 떨어지는 물체 묶음(브라우니·도필헌·강이학 등)과 겹쳐, 2단은 볼펜 여덟 자루 둘레 방사로, 필살기는 적마다 커피를 끼얹고 손에 든 큰 잔을 기울여 물결을 쏟는 장면으로 바꿨다. 굽 소리 파문 두 번은 고영은 필살기의 바닥 빛 고리 두 번과 같아 뺐다.
- (맥락 정리) 커피 끼얹기·머그잔·볼펜 투척·커피 물결을 모두 걷어 냈다(위키 「초능력은 없다. 전투 기록도 없다」, 등록 그림에 소품 없음). 고유기술은 두 손가락 찌르기 + 손등 털기, 충전은 다이빙 밀치기 → 붙잡아 무릎 → 굽으로 박기, 필살기는 적 사이를 누비며 목덜미를 찌르고 손가락 총 윙크에 일제히 쓰러뜨리는 장면으로 바꿨다. 물건 그림 3개(머그잔·볼펜·큰 머그잔)와 전용 커피 물결이 빠짐.
- (톤 정리) 필살기의 「손가락 총 윙크에 찔린 적이 일제히 쓰러짐」(개그)을 뺐다. 찌르기에 숨이 막혀 무릎 꿇은 적들을 되짚어 가며 하이힐 굽으로 하나씩 바닥에 박고, 마지막 적을 무릎 + 손등으로 내동댕이친 뒤 「스톱.」으로 끝낸다(9·11·12·10·16-1·24번, 새 동작 0). 컷인의 윙크도 뺐다.
