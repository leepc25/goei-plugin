# 4.7_신유리 기술 재설계

- 근거: 지하 2층 창고 B-7 「영창컨설팅」 사채업자·담보 전문가. 근거리 나이프 전투 훈련, 「일부러 비좁게 만든 자기 사무실 안에서」 강함, 난동 부린 덩치를 「몇 초 만에 철제 의자에 도로 앉혔다. 의자에서 일어나지도 않았다」(위키). 허리 뒤 짧은 고정날 나이프, 철판 안전화, 데드볼트 세 개 달린 철문, 계약서 한 장을 책상 위로 밀며 「추심 시 사전 통보 없음」.
- 싸우는 방식 한 줄: 「말없이 붙어 단검으로 찌르고, 붙잡아 바닥에 눌러 앉히는 좁은 방 근접형」

## 고유기술(D) 「추심」
- 하는 일: 몸을 거의 안 움직이고 단검을 가슴 높이로 한 번, 무릎을 굽혀 배 높이로 한 번 짧게 찌른다. 앞 0.5~1.2m, 두 번. 두 번째 낮은 찌르기에 맞은 적은 배를 감싸며 허리가 꺾인다.
- 분류: 공격(짧은 앞 찌르기)
- 상대 반응: 맞기(상단) → 맞기(하단)
- 전용 이펙트: 공용: 베기(작게, 찌르기 모양 직선). 코드: 칼끝에 짧은 은빛 반짝.
- 동작: 22번 그대로(1~2장 높게, 6~7장 낮게).

## 충전기(S) 「도로 앉아」
- 0단: 그 자리에서 앞손으로 앞 0.8m 적의 어깨를 움켜쥐고 아래로 꾹 누른다 → 적이 그 자리에 무릎 꿇었다가 바로 일어남(짧은 잡기 1명).
- 1단: 앞발을 길게 내디디며 바닥을 미끄러져 3m 앞으로 파고들어 그 자리의 적을 잡아 바닥에 엎어 누른다 → 이동하며 잡기, 적은 엎어져 쓰러짐.
- 2단: 1단처럼 파고들어 잡은 뒤, 적 발밑 바닥에서 볼트로 박힌 맨 철제 의자가 솟아오르고 그 위로 적을 내리꽂는다 → 의자가 찌그러지며 부서지고 둘레 1.5m 원으로 철 파편·충격이 튀어 주변 적도 밀려남.
- 모양 변화: 제자리 한 명 잡기 → 앞으로 미끄러지는 잡기 → 잡아 내리꽂아 둘레 원
- 분류: 제압(잡아 주저앉힘·엎어뜨림) / 2단은 공격(둘레 원)도
- 상대 반응: 0단 무릎 꿇기(짧은 경직) / 1단 엎어져 쓰러지기 / 2단 잡힌 적 쓰러지기, 둘레 적 밀려나기
- 전용 이펙트: GPT `fx_신유리_철제의자`(솟음 2장 + 찌그러져 부서짐 3장 · 64×96 맨 철제 의자) · 공용: 충격파(둘레 원), 흙먼지(1단 미끄러짐).
- 동작: 모으기 23번 그대로. 방출 0단 = 24번 4~8장(움켜쥐어 누름부터) / 1단 = 24번 그대로, 1~3장 내디딤 동안 코드가 몸을 앞으로 3m 옮김 / 2단 = 1단과 같고 5~6장 누르는 장에서 의자 솟음·내리꽂음.

## 필살기(F) 「추심 시 사전 통보 없음」
- 연출 순서:
  1. 컷인(앞머리 하나 없는 얼굴, 계약서를 화면 앞으로 쓱 미는 손). 화면에 「추심 시 사전 통보 없음」 글씨.
  2. 계약서를 앞으로 미는 순간 화면 양옆에서 맨 콘크리트 벽이 좁혀 들어온다 → 벽이 적 전원을 화면 가운데 좁은 칸으로 밀어 모음(창고 B-7처럼 비좁아짐, 천장 LED가 매섭게 켜짐).
  3. 앞을 막는 철문이 쾅 닫히고 데드볼트 세 개가 차례로 「철컥·철컥·철컥」 잠김 → 잠길 때마다 철문이 앞으로 한 번씩 떨려 모인 적들을 한 대씩 침.
  4. 낮게 웅크려 단검을 빠르게 세 번 찌를 때마다 그녀가 모인 적들 사이를 짧게 오가며 찌름(찌르기마다 은빛 선이 무리를 꿰뚫음).
  5. 넘긴 머리를 뒤로 한 번 쓸어 정리하면 벽과 철문이 먼지로 무너지고 적들이 바깥으로 튕겨 쓰러짐.
- 상대 반응: 끌려옴(벽에 밀려 모임) → 맞기 3회 → 맞기 3회 → 밀려나 쓰러지기
- 전용 이펙트(크고 화려하게): GPT `fx_신유리_콘크리트벽`(6장 · 화면 높이 전체의 콘크리트 벽 두 장이 양옆에서 밀려옴, 드러난 배관) · `fx_신유리_철문`(6장 · 「B-7」 철문 닫힘 + 데드볼트 세 개 잠김) · 공용: 베기(찌르기 직선), 흙먼지 대(벽 무너짐). 코드: 화면 가장자리 어둡게 좁힘, 잠길 때마다 흔들림 중.
- 동작: 25번 그대로(1~2장 계약서 밀기 = 벽, 3~8장 찌르기, 9~10장 머리 쓸기 = 무너짐).

## 앞 설계와 달라진 점
- 고유기술 「담보 표식 · 도망치면 끌려옴 · 좁은 곳 피해 +40%」(표식·구속·강화) → 그냥 두 번 찌르기.
- 충전기 「도망 봉인」(구속·정보)·「3초 고정」(구속) → 잡아 눌러 앉히고 철제 의자에 내리꽂는 잡기(넘어짐으로 끝남).
- 필살기 「표식된 적의 버프 빼앗기·아군 회복」(싸움 밖) → 콘크리트 벽으로 적을 좁은 방에 몰아넣고 찌름. 구속·표식·강화 0개.
