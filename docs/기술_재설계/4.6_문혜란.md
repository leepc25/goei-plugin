# 4.6_문혜란 기술 재설계

- 근거: 중림 지하상가 일자리 알선소 「대박알선」 해결사. 전직 프리랜서 5년, 접이식 진압봉 솜씨가 「쓸 만하고 감상적이지 않다」, 행패 부린 손님을 몇 초 만에 바닥에 엎드리게 하고 「어이, 친구, 바닥 차갑지? 일어나서 사인부터 하자」(위키). 손님맞이 「앉아, 앉아」, 금장 시계 한 번 톡, 뒷방 포커 테이블·낡은 가죽 소파·네온 OPEN 간판·카운터 뒤 야구방망이·표시된 카드 한 벌.
- 싸우는 방식 한 줄: 「진압봉으로 걸어 넘어뜨리고, 사무실 가구와 카드를 날려 상대를 주저앉히는 접대형 제압가」

## 고유기술(D) 「바닥 차갑지?」
- 하는 일: 진압봉을 어깨 위에서 허리 높이로 내려치고, 가슴 높이로 올려친 뒤, 앞발로 상대 발목을 걸어 몸 쪽으로 당긴다. 앞 0.5~1.5m, 세 번 친다. 마지막 발목 걸기에 맞은 적은 앞으로 고꾸라져 엎어진다.
- 분류: 제압(넘어뜨림)
- 상대 반응: 맞기(상단) → 맞기(상단) → 앞으로 쓰러지기(엎어짐, 일반 다운 시간)
- 전용 이펙트: 공용: 타격 약·강. 코드: 진압봉 궤적에 짧은 은색 선.
- 동작: 22번 그대로(3장 내려침, 5장 올려침, 4~5장 발목 걸기).

## 충전기(S) 「앉아, 앉아」
- 시계를 보여 주며 모았다가, 진압봉 끝으로 시계를 톡 친 뒤 손바닥으로 「앉아」 누르는 순간 대박알선 가구가 튀어나온다.
- 0단: 바퀴 달린 사무실 의자 하나가 그녀 옆에서 튕겨 오르며 **공중으로 빙글빙글 돌며 날아가** 앞 5m 안 첫 적의 몸통에 부딪힌다 → 그 적이 뒤로 나자빠짐(바닥을 굴러가 앉히지 않음).
- 1단: 낡은 가죽 소파 하나가 그녀 옆에서 바닥을 축으로 **반 바퀴 크게 휘돌며** 앞 반원(반지름 2.5m)을 쓸어 친다 → 반원 안 적이 소파 등받이에 얻어맞아 옆으로 날아가 쓰러짐. 소파는 다 돈 뒤 뒤집혀 사라짐.
- 2단: 표시된 카드 다섯 장을 손목 스냅으로 딜하듯 튕긴다 → 앞 6m 안 적 다섯에게 한 장씩 곧게 날아가 꽂히고(자동 조준), 카드마다 맞은 적이 움찔하다 다섯째 장이 꽂힐 때 다 같이 무릎이 꺾여 털썩 주저앉음(「앉아, 앉아」).
- 모양 변화: 한 명에게 날아가는 큰 것 → 앞 반원을 휩쓰는 것 → 여러 명에게 갈라져 꽂히는 작은 것
- 분류: 공격·제압(0단 투사체 / 1단 반원 휩쓸기 / 2단 여러 점 자동 조준 → 주저앉힘)
- 상대 반응: 0단 뒤로 쓰러지기 / 1단 옆으로 날아가 쓰러지기 / 2단 맞기 상단 → 주저앉기(짧은 다운)
- 전용 이펙트: GPT `fx_문혜란_의자`(4장 · 회전하며 날아가는 바퀴 의자) · `fx_문혜란_소파`(4장 · 휘도는 낡은 갈색 가죽 소파) · 2단 카드는 필살기의 표시된 카드 낱장을 다시 씀. 코드: 톡 하는 장에 「째깍」.
- 동작: 모으기 23번 그대로. 방출은 세 단 모두 24번 그대로(1장 톡 = 째깍, 4~5장 손바닥 누름 = 가구 등장·카드 튕김).

## 필살기(F) 「대박알선 뒷방」
- 연출 순서:
  1. 컷인(카드를 부채처럼 펼친 손, 금장 시계). 화면이 어두워지고 뒤에 촌스러운 네온 OPEN 간판이 깜빡이며 켜짐, 뒷방 포커 테이블 조명 하나가 위에서 내려옴.
  2. 재킷 안에서 표시된 카드 한 벌을 꺼내 펼쳐 앞으로 내던짐 → 카드 수십 장이 한 줄로 이어져 화면을 가로질러 날아가며 앞쪽 적들을 연달아 베고 지나감(적마다 여러 번).
  3. 「재협상? 하하하하! …9조에 안 된다고 나와 있어.」 글씨, 한 박자 정적.
  4. 진압봉 자리에 카운터 뒤 비상용 야구방망이가 겹쳐 보이며 두 손으로 머리 뒤에서 크게 내려침 → 앞 3m 바닥을 쾅 내리찍어 바닥이 갈라지는 충격이 앞 넓은 원으로 퍼지고 적 전원이 튕겨 올랐다 떨어짐.
  5. 네온 간판의 O자가 툭 꺼지고(「PEN」만 남음) 화면이 돌아옴.
- 상대 반응: 카드 베기 맞기 여러 번 → 띄워지기 → 쓰러지기
- 전용 이펙트(크고 화려하게): GPT `fx_문혜란_네온`(4장 · 192×64 깜빡이는 네온 「OPEN」 간판, 원작 간판 그대로 영문 예외) · `fx_문혜란_카드행렬`(6장 · 화면 가로 길이로 이어진 회전 카드 띠) · `fx_문혜란_방망이`(4장 · 진압봉 위에 덮는 나무 야구방망이 휘두름 궤적) · 공용: 충격파 대(바닥). 코드: 흔들림 강, 네온 분홍 번짐.
- 동작: 25번 그대로(카드 꺼냄 = 2단계, 앞으로 뻗음 = 던짐, 진압봉 크게 내림 = 4단계).

## 앞 설계와 달라진 점
- 고유기술 「3초 못 일어남」(구속) → 그냥 발목 걸어 엎어뜨림(일반 다운).
- 충전기 「압박 · 공속 -30%」(표식·숫자)·「적 고용」(구속·싸움 밖) → 의자를 날리고 소파를 휘두르고 카드를 꽂아 주저앉힘.
- 필살기 「받는 피해 -50%」(강화)·「빚」 표식 → 카드 행렬 베기 + 방망이 바닥 내리찍기. 구속·표식·강화 0개.
- (겹침 정리) 충전 0단의 「굴러온 의자가 무릎 뒤를 쳐 앉혔다가 의자째 뒤로 넘어뜨림」은 도필헌 고유기술 「앉게.」와 같은 문장·같은 그림이라 공중으로 날아가는 의자로, 1단 「바닥을 미끄러지는 소파에 다리가 걸림」은 땅을 타고 가 넘어뜨리는 묶음과 겹쳐 반원을 휘도는 소파로, 2단 「위에서 떨어지는 포커 테이블」은 위에서 떨어지는 묶음과 겹쳐 다섯 명에게 꽂히는 카드로 바꿨다.
