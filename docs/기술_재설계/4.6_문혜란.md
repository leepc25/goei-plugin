# 4.6_문혜란 기술 재설계

- 근거: 중림 지하상가 일자리 알선소 「대박알선」 해결사. 전직 프리랜서 5년, 접이식 진압봉 솜씨가 「쓸 만하고 감상적이지 않다」, 행패 부린 손님을 몇 초 만에 바닥에 엎드리게 하고 「어이, 친구, 바닥 차갑지? 일어나서 사인부터 하자」(위키). 손님맞이 「앉아, 앉아」, 금장 시계 한 번 톡, 뒷방 포커 테이블·낡은 가죽 소파·네온 OPEN 간판·카운터 뒤 야구방망이·표시된 카드 한 벌.
- 싸우는 방식 한 줄: 「진압봉으로 걸어 넘어뜨리고, 래리어트·밀어차기로 밀어붙이고, 표시된 카드를 던져 주저앉히는 접대형 제압가」

## 고유기술(D) 「바닥 차갑지?」
- 하는 일: 진압봉을 어깨 위에서 허리 높이로 내려치고, 가슴 높이로 올려친 뒤, 앞발로 상대 발목을 걸어 몸 쪽으로 당긴다. 앞 0.5~1.5m, 세 번 친다. 마지막 발목 걸기에 맞은 적은 앞으로 고꾸라져 엎어진다.
- 분류: 제압(넘어뜨림)
- 상대 반응: 맞기(상단) → 맞기(상단) → 앞으로 쓰러지기(엎어짐, 일반 다운 시간)
- 전용 이펙트: 공용: 타격 약·강. 코드: 진압봉 궤적에 짧은 은색 선.
- 동작: 22번 그대로(3장 내려침, 5장 올려침, 4~5장 발목 걸기).

## 충전기(S) 「앉아, 앉아」
- 시계를 보여 주며 모았다가, 진압봉 끝으로 시계를 톡 친 뒤 몸으로 들어간다. 단계마다 들어가는 거리와 몸 기술이 바뀐다.
- 0단: 달려 나가 앞팔을 곧게 뻗어 팔뚝을 목 높이로 거는 래리어트 → 앞 4m 일직선, 처음 걸린 적이 목이 걸려 뒤로 붕 떠 등부터 떨어진다.
- 1단: 「문 밖으로」 — 한 걸음 붙어 앞무릎을 가슴까지 접었다가 구두 밑창을 가슴 높이로 다리 끝까지 밀어 찬다 → 앞 1.5m 한 명, 맞은 적이 일직선으로 4m 날아가 쓰러지고 그 길에 있던 적도 부딪혀 휘청한다.
- 2단: 표시된 카드 다섯 장을 손목 스냅으로 딜하듯 튕긴다 → 앞 6m 안 적 다섯에게 한 장씩 곧게 날아가 꽂히고(자동 조준), 카드마다 맞은 적이 움찔하다 손바닥으로 「앉아」 내리누르는 순간 다 같이 무릎이 꺾여 털썩 주저앉음.
- 모양 변화: 앞으로 달려가 거는 긴 직선 → 붙어서 한 명을 멀리 날림 → 여러 명에게 갈라져 꽂히는 작은 것
- 분류: 0단 이동+제압(넘어뜨림) / 1단 공격(밀어 날림) / 2단 여러 점 자동 조준 → 주저앉힘
- 상대 반응: 0단 띄워졌다 뒤로 쓰러지기 / 1단 크게 날아가 쓰러지기, 길 위 적 맞기 상단 / 2단 맞기 상단 → 주저앉기(짧은 다운)
- 전용 이펙트: 없음(0·1단). 2단 카드는 필살기의 표시된 카드 낱장을 다시 씀. 공용: 타격_강(래리어트·밀어차기), 흙먼지(0단 착지). 코드: 톡 하는 장에 「째깍」.
- 동작: 모으기 23번 그대로. 방출 0단 = 24번 1~3장(톡) + 13번(래리어트) 그대로 / 1단 = 24번 1~3장 + 12번(긴 다리 밀어차기) 그대로 / 2단 = 15번(카드 던지기) + 24번 4~8장(손바닥 누름 = 주저앉음).

## 필살기(F) 「대박알선 뒷방」
- 연출 순서:
  1. 컷인(카드를 부채처럼 펼친 손, 금장 시계). 화면 가장자리가 어두워지고 그녀 둘레만 낮은 조명처럼 남는다(코드).
  2. 재킷 안에서 표시된 카드 한 벌을 꺼내 펼쳐 앞으로 내던짐 → 카드 수십 장이 한 줄로 이어져 화면을 가로질러 날아가며 앞쪽 적들을 연달아 베고 지나감(적마다 여러 번).
  3. 「재협상? 하하하하! …9조에 안 된다고 나와 있어.」 한 박자 정적.
  4. 진압봉을 두 손으로 머리 뒤에서 크게 들었다가 깊은 런지로 앞 3m 바닥을 쾅 내리찍음 → 은색 진압봉 궤적이 큰 호로 남고, 바닥이 갈라지는 충격이 앞 넓은 원으로 퍼져 적 전원이 튕겨 올랐다 떨어짐.
  5. 일어나 진압봉 자세로 내려다보며 웃는다. 「어이, 친구, 바닥 차갑지?」
- 상대 반응: 카드 베기 맞기 여러 번 → 띄워지기 → 쓰러지기
- 전용 이펙트(크고 화려하게): GPT `fx_문혜란_카드행렬`(6장 · 화면 가로 길이로 이어진 회전 카드 띠) · `fx_문혜란_진압봉호`(4장 · 머리 뒤에서 앞 아래로 내리긋는 굵은 은색 궤적 호, 형체 없음) · 공용: 충격파 대(바닥)·바닥 파괴. 코드: 흔들림 강.
- 동작: 25번 그대로(카드 꺼냄 = 2단계, 앞으로 뻗음 = 던짐, 진압봉 크게 내림 = 4단계).

## 앞 설계와 달라진 점
- 고유기술 「3초 못 일어남」(구속) → 그냥 발목 걸어 엎어뜨림(일반 다운).
- 충전기 「압박 · 공속 -30%」(표식·숫자)·「적 고용」(구속·싸움 밖) → 의자를 날리고 소파를 휘두르고 카드를 꽂아 주저앉힘.
- 필살기 「받는 피해 -50%」(강화)·「빚」 표식 → 카드 행렬 베기 + 방망이 바닥 내리찍기. 구속·표식·강화 0개.
- (겹침 정리) 충전 0단의 「굴러온 의자가 무릎 뒤를 쳐 앉혔다가 의자째 뒤로 넘어뜨림」은 도필헌 고유기술 「앉게.」와 같은 문장·같은 그림이라 공중으로 날아가는 의자로, 1단 「바닥을 미끄러지는 소파에 다리가 걸림」은 땅을 타고 가 넘어뜨리는 묶음과 겹쳐 반원을 휘도는 소파로, 2단 「위에서 떨어지는 포커 테이블」은 위에서 떨어지는 묶음과 겹쳐 다섯 명에게 꽂히는 카드로 바꿨다.
- (맥락 정리) 충전 0·1단의 회전하며 날아가는 바퀴 의자·반 바퀴 휘도는 가죽 소파를 걷어 내고 동작표 몸 기술(13번 래리어트·12번 「문 밖으로」 밀어차기)로 바꿨다. 필살기의 네온 OPEN 간판(「PEN」만 남는 개그)과 진압봉에 겹치는 야구방망이를 빼고, 진압봉 자체의 큰 내리찍기 궤적으로. 표시된 카드는 위키 장비이자 동작표 원거리라 남김.
