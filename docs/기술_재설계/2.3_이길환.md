# 2.3_이길환 기술 재설계

- 근거: 위키 「같은 음량, 같은 속도, 같은 따뜻함으로 말을 이어 간다 … 계속 말하다 보면 방 안이 먼저 지친다」, 「세상에서 가장 친절한 벽」, 개회 인사 「아, 아, 테스트, 테스트」(마이크를 두 번 톡톡), 「충분히 이해한다고, 그래도 양해 부탁드린다고」, 별명 「튜토리얼 요정」. 동작표: 손을 안 쓰고 둥근 배·토닥·꾸벅·턱짓으로 싸움.
- 싸우는 방식 한 줄: 「마이크 하울링과 같은 음량으로 끝없이 이어지는 말소리로 밀어붙이고, 둥근 배로 들이받는 친절한 벽」

## 고유기술(D) 「아, 아, 테스트」
- 하는 일: 마이크를 입에 대고 손끝으로 톡톡 두 번. 톡마다 마이크에서 「삐익—」 하울링 음파 고리가 앞 부채꼴(3m)로 한 겹씩 퍼짐. 첫 고리에 적이 귀를 막고 움찔, 두 번째 고리에 뒤로 밀려남. 손을 머리 위로 들어 「여러분~」 하며 웃음.
- 분류: 공격(앞 부채꼴 음파 두 겹)
- 상대 반응: 1겹 경직(귀 막기) → 2겹 밀려나기
- 전용 이펙트: `fx_이길환_하울링`(192×128, 살구색 도트 음파 고리가 부채꼴로 퍼지는 6장, 가장자리에 날카로운 지그재그), 마이크 머리 반짝(코드)
- 동작: 22번 그대로(2·4장 톡톡 = 고리 두 번, 6~8장 「여러분~」)

## 충전기(S) 「충분히 이해합니다」
- 모으는 동안: 마이크를 입에 댄 채 끄덕이며 같은 음량·같은 속도로 계속 말한다(입 앞 살구색 음파 잔물결, 코드). 단계마다 마이크 머리가 한 번씩 반짝.
- 0단: 「양해 부탁드립니다」 목례 — 숙이는 순간 마이크 앞에서 짧고 굵은 살구색 음압 덩어리가 앞 1m로 퍽 터져 붙어 있던 적을 밀쳐 낸다(짧은 한 점).
- 1단: 목례하다 그대로 두 발로 떠서 둥근 배부터 날아든다(날아 배치기) → 앞 4m 일직선, 처음 부딪힌 적이 배에 튕겨 뒤로 넘어지고 이길환은 배로 착지해 일어난다.
- 2단: 수평 목례를 한 채 멈추지 않고 말을 이어 간다 → 마이크에서 같은 굵기의 살구색 음파 고리가 이길환 **둘레 원**(반지름 3m)으로 천천히 세 번 퍼져 나가고, 닿을 때마다 원 안 적이 한 걸음씩 밀려나 셋째 고리에 주저앉는다(「계속 말하다 보면 방 안이 먼저 지친다」).
- 분류: 0단 제압(밀쳐 냄) / 1단 이동+공격(일직선 몸통 박치기) / 2단 제압(둘레 원 세 번)
- 상대 반응: 0단 밀려나기 · 1단 뒤로 쓰러지기 · 2단 밀려나기 ×2 → 주저앉기(짧은 다운)
- 전용 이펙트: `fx_이길환_하울링`(고유기술 것)을 0단은 작게 한 번, 2단은 둘레 원으로 펼쳐 세 번(코드가 둥글게 이어 붙임). 공용: 흙먼지(1단 착지).
- 동작: 모으기 23번(끄덕이며 손을 가슴에) 그대로 · 방출 0단 = 24번 앞 4장만 빠르게 / 1단 = 24번 1~3장 + 13번(날아 배치기) 그대로 / 2단 = 24번 그대로(수평 목례 장을 늘려 유지).

## 필살기(F) 「튜토리얼」
- 연출 순서:
  1. 컷인 뒤 화면이 강당처럼 어두워지고 이길환 한 사람만 밝게 남는다(코드). 발끝으로 서서 마이크를 머리 위로 들고 「아, 아, 테스트, 테스트」 — 톡톡 두 번에 마이크 머리가 번쩍인다.
  2. 앞팔로 방 전체를 크게 쓸어 가리키면, 마이크 하울링이 살구색 음파 막이 되어 화면 앞에서 뒤까지 가로로 한 번 쓸고 지나간다 → 막에 닿은 적 전원이 귀를 감싸 쥐고 무릎이 꺾여 그 자리에 주저앉는다(한쪽으로 몰지 않음).
  3. 두 손을 배 앞에 모아 깊이 꾸벅하며 「양해 부탁드립니다」 — 마이크에서 화면을 덮는 살구색 겹고리 음파 네 겹이 이길환을 가운데로 한꺼번에 퍼져 나간다(화면 출렁).
  4. 고리가 지날 때마다 주저앉은 적들이 한 겹씩 밀려나고, 넷째 고리에 적 전원이 화면 바깥쪽으로 크게 날아가 쓰러진다.
  5. 마이크를 입에 대고 웃으며 「여러분~」.
- 상대 반응: 주저앉기(음파 막) → 밀려나기 ×3 → 크게 날아가 다운
- 전용 이펙트(크게): 화면을 가로로 쓸고 가는 살구색 음파 막(`fx_이길환_하울링`을 화면 깊이 폭으로 늘림, 코드), 화면을 덮는 살구색 겹고리 음파 4개(`fx_이길환_화면음파`). 공용: 흔들림(필살).
- 동작: 25번 그대로(1~2장 마이크 위 = 테스트, 2~5장 팔 쓸기 = 음파 막, 6~10장 꾸벅 = 겹고리, 11~12장 마이크 자세)

## 앞 설계와 달라진 점
- 고유기술: 다음 행동 0.6초 늦춤 + 공격 경로 「!」 표시(구속·표식, 안 보임) → 톡톡에 맞춰 두 번 퍼지는 하울링 음파로 밀쳐 냄.
- 충전기: 적 공격 속도 -40%·「지침」 구속(숫자·상태) → 쌓인 말풍선을 부풀려 터뜨리고·감싸 띄우고·느리게 퍼뜨리는 공격.
- 필살기: 피해 -40%·예고선·버티기(강화·지원) → 현수막으로 걸어 넘어뜨리고 스피커로 날려 버리는 공격.
- 구속 0, 표식 0, 강화 0.
- (겹침 정리) 충전 0단 목례 박치기는 이성해 충전 0단(90도 꾸벅 박치기)과, 1단 「바닥을 굴러가 발을 거는 말풍선」은 땅을 타고 가 넘어뜨리는 묶음과, 2단 「위에서 무너져 덮치는 말풍선 탑」은 위에서 떨어지는 물체 묶음과 겹쳐 셋 다 바꿨다. 필살기의 「한쪽으로 몰아 벽에 박기」는 콘쥬스 필살기(잔해 파도로 벽에 박음)와 겹쳐 스피커마다 원 바깥으로 날리게 했다.
- (맥락 정리) 충전의 부풀어 터지는·사람을 감싸 띄우는·떠 가는 말풍선과 필살기의 「즐거운 신입 교육」 현수막·천장 스피커 넷을 모두 걷어 냈다. 위키 「마이크는 늘 개인 장비」·「같은 음량, 같은 속도로 말을 이어 간다 … 방 안이 먼저 지친다」대로 마이크 음압과 몸(날아 배치기)으로만 친다. 물건 그림 1개(스피커)와 전용 말풍선·현수막이 빠짐.
