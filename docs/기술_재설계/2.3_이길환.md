# 2.3_이길환 기술 재설계

- 근거: 위키 「같은 음량, 같은 속도, 같은 따뜻함으로 말을 이어 간다 … 계속 말하다 보면 방 안이 먼저 지친다」, 「세상에서 가장 친절한 벽」, 개회 인사 「아, 아, 테스트, 테스트」(마이크를 두 번 톡톡), 「충분히 이해한다고, 그래도 양해 부탁드린다고」, 별명 「튜토리얼 요정」. 동작표: 손을 안 쓰고 둥근 배·토닥·꾸벅·턱짓으로 싸움.
- 싸우는 방식 한 줄: 「마이크 소리와 끝없이 쌓이는 말로 밀어붙이는, 둥근 몸의 친절한 벽」

## 고유기술(D) 「아, 아, 테스트」
- 하는 일: 마이크를 입에 대고 손끝으로 톡톡 두 번. 톡마다 마이크에서 「삐익—」 하울링 음파 고리가 앞 부채꼴(3m)로 한 겹씩 퍼짐. 첫 고리에 적이 귀를 막고 움찔, 두 번째 고리에 뒤로 밀려남. 손을 머리 위로 들어 「여러분~」 하며 웃음.
- 분류: 공격(앞 부채꼴 음파 두 겹)
- 상대 반응: 1겹 경직(귀 막기) → 2겹 밀려나기
- 전용 이펙트: `fx_이길환_하울링`(192×128, 살구색 도트 음파 고리가 부채꼴로 퍼지는 6장, 가장자리에 날카로운 지그재그), 마이크 머리 반짝(코드)
- 동작: 22번 그대로(2·4장 톡톡 = 고리 두 번, 6~8장 「여러분~」)

## 충전기(S) 「충분히 이해합니다」
- 모으는 동안: 끄덕이며 계속 말함. 머리 위에 도트 말풍선이 하나씩 쌓여 탑이 됨(단계마다 탑이 높아짐).
- 0단: 「양해 부탁드립니다」 목례 — 허리를 수평으로 숙인 정수리가 앞 1m를 박아 밀쳐 냄(말풍선 1개가 앞으로 툭 떨어짐).
- 1단: 목례와 함께 쌓인 말풍선 덩어리가 바닥으로 쏟아져 앞으로 데굴데굴 굴러감(땅을 타고 5m, 높이 무릎). 지나는 적은 발이 걸려 넘어짐.
- 2단: 머리 위 말풍선 탑(키 세 배)이 목례 방향으로 통째로 쓰러져, 앞 3~6m 지점 넓은 원(반경 2m) 위에 우르르 떨어져 덮침.
- 분류: 공격(박치기 / 땅을 타고 굴러감 / 위에서 떨어짐)
- 상대 반응: 0단 밀려나기 · 1단 맞기 하단 → 쓰러지기 · 2단 위에서 눌려 쓰러지기(바운드)
- 전용 이펙트: `fx_이길환_말풍선`(흰 도트 말풍선 낱개 2장 + 굴러가는 덩어리 4장 + 무너지는 탑 6장, 글씨칸 비움), 공용: 흙먼지
- 동작: 모으기 23번(끄덕이며 손을 가슴에) · 방출 24번(수평 목례) 그대로, 0단은 24번 앞 4장만 빠르게

## 필살기(F) 「튜토리얼」
- 연출 순서:
  1. 컷인 뒤 이길환이 발끝으로 서서 마이크를 머리 위로 들면, 천장에서 「즐거운 신입 교육」 대형 현수막과 강당 스피커 네 개가 줄에 매달려 쿵 내려옴.
  2. 앞팔로 방 전체를 크게 쓸어 가리키면, 현수막이 화면 앞에서 뒤까지 가로로 쓸고 지나가며 적들을 한쪽(화면 앞쪽 끝)으로 우르르 몰아붙임. 바닥에 안내 화살표 도트가 켜짐.
  3. 두 손을 배 앞에 모아 깊이 꾸벅하는 순간, 네 스피커에서 「양해 부탁드립니다」 음파가 한꺼번에 터짐(화면이 출렁이는 겹고리 네 개).
  4. 몰려 있던 적 전원이 음파에 날아가 화면 끝 벽에 부딪혀 쓰러짐. 현수막이 천천히 펄럭이며 다시 올라감.
- 상대 반응: 밀려나기(몰림) → 크게 날아가기 → 벽에 박힘 → 다운
- 전용 이펙트: `fx_이길환_안내판`(384×192, 내려와 흔들리는 현수막 · 글씨는 코드), `fx_이길환_스피커`(96×96 4개, 터질 때 콘이 튀어나옴), 화면을 덮는 살구색 겹고리 음파 4개(코드 + `fx_이길환_하울링` 크게)
- 동작: 25번 그대로(1~2장 마이크 위 = 현수막 낙하, 2~5장 팔 쓸기 = 몰아붙임, 6~10장 꾸벅 = 음파, 11~12장 마이크 자세)

## 앞 설계와 달라진 점
- 고유기술: 다음 행동 0.6초 늦춤 + 공격 경로 「!」 표시(구속·표식, 안 보임) → 톡톡에 맞춰 두 번 퍼지는 하울링 음파로 밀쳐 냄.
- 충전기: 적 공격 속도 -40%·「지침」 구속(숫자·상태) → 쌓인 말풍선을 박고·굴리고·무너뜨리는 공격.
- 필살기: 피해 -40%·예고선·버티기(강화·지원) → 현수막으로 몰고 스피커로 날려 버리는 공격.
- 구속 0, 표식 0, 강화 0.
