# 4.10_아벤샤 기술 재설계

- 근거: 발푸르기스 협회 십마녀 「모래의 마녀」. 「폭발하는 모래 기둥을 세우고, 모래 방벽을 치고, 압축한 모래를 탄환처럼 쏜다. 요새 높이의 모래 해일」, 「본인이 흐르는 모래가 되어 … 어디든 순식간에 이동」(위키). 정장 위 보랏빛 후드 망토, 에메랄드 브로치, 감탄하면 눈이 별빛처럼 반짝임. 「세계에서 가장 가볍게 사람을 죽이는 마법사」 — 손짓은 우아하고 가볍다.
- 싸우는 방식 한 줄: 「손가락 튕김 모래탄으로 견제하고, 모래가 되어 흘러 다니다 기둥과 해일로 터뜨리는 우아한 원거리 마녀」

## 고유기술(D) 「모래 탄환」
- 하는 일: 망토 자락을 뒤로 젖히고 앞손을 어깨 높이로 뻗어 손가락을 세 번 튕긴다. 튕길 때마다 압축된 금빛 모래 덩어리가 한 발씩 앞 직선 8m로 날아감. 세 번째 탄은 맞으면 모래가 퍽 터지며 상대를 조금 밀어 냄.
- 분류: 공격(앞 직선 투사체 3발)
- 상대 반응: 맞기(상단) → 맞기(상단) → 밀려나기
- 전용 이펙트: GPT `fx_아벤샤_모래탄`(4장 · 48×24 금빛 압축 모래 덩어리, 모래 가루 꼬리) · 공용: 흙먼지(작게, 금빛 덧칠 · 맞은 자리 퍽).
- 동작: 22번 그대로(4·5·6장 손가락 펼 때마다 한 발).

## 충전기(S) 「흐르는 모래」
- 0단: 망토를 펼치며 일어서는 순간 앞 1m에 사람 키 반만 한 모래 방벽이 솟음 → 1.5초 서서 앞에서 오는 투사체를 막고(맞으면 모래가 튐), 솟을 때 닿은 가까운 적을 밀쳐 냄. 그 뒤 무너짐.
- 1단: 망토로 몸을 감싸 웅크리면 몸이 모래로 무너져 바닥을 타는 모래 줄기가 되어 앞 5m를 흘러가고, 끝에서 망토를 펼치며 다시 일어섬 → 흘러간 줄 위의 적은 다리를 휩쓸려 넘어짐.
- 2단: 1단처럼 흘러가 일어선 뒤 두 손바닥을 퍼 올리면, 앞 2m·3.5m·5m 세 자리에서 모래 기둥이 차례로 폭발하며 솟음 → 앞으로 이어지는 세 기둥, 맞은 적 높이 띄움.
- 모양 변화: 앞에 서는 벽(방어) → 바닥을 타는 선(이동) → 이동 끝에서 앞으로 이어지는 세 기둥(위로 솟음)
- 분류: 0단 방어 / 1단 이동+제압(넘어뜨림) / 2단 이동+공격(띄움)
- 상대 반응: 0단 밀려나기 / 1단 쓰러지기 / 2단 띄워지기 → 떨어져 쓰러지기
- 전용 이펙트: GPT `fx_아벤샤_모래방벽`(솟음 3장 + 무너짐 3장 · 128×128) · `fx_아벤샤_모래줄기`(6장 · 바닥을 흐르는 모래 물결) · `fx_아벤샤_모래기둥`(8장 · 128×320). 코드: 몸 그림을 아래에서 위로 모래 입자로 흩음/모음.
- 동작: 모으기 23번 그대로. 방출 0단 = 24번 5~8장(망토 펼치며 일어섬)만 / 1단 = 24번 그대로(감싸 웅크림 = 사라짐, 펼침 = 나타남) / 2단 = 24번 그대로 + 11번(약3 손바닥 퍼 올리기) 5~7장.

## 필살기(F) 「모래 해일」
- 연출 순서:
  1. 컷인(별빛처럼 반짝이는 에메랄드 눈, 손바닥 위 금빛 모래 소용돌이) + 「제 실력을 증명할 수 있어서 너무 기뻐요!」
  2. 브로치를 쥐고 망토를 휘두르면 화면 바닥 전체가 금빛 모래로 물결치기 시작함.
  3. 두 팔을 퍼 올리는 동안 화면 뒤에서 요새 높이(화면 높이 넘게)의 모래 해일이 솟아오름, 꼭대기에서 모래 물보라.
  4. 앞으로 내리꽂으면 해일이 화면 앞으로 무너져 덮침 → 적 전원이 모래에 휩쓸려 화면 끝까지 떠밀려 감, 아벤샤는 해일 꼭대기를 타고 망토를 휘날리며 지나감.
  5. 모래가 걷히면 적들이 모래 더미에서 튕겨 나와 쓰러짐(쓰러진 적은 모래로 부서지는 연출로 처치).
- 상대 반응: 휩쓸려 크게 밀려나기(여러 번) → 띄워지기 → 쓰러지기
- 전용 이펙트(크고 화려하게): GPT `fx_아벤샤_모래해일`(10장 · 1280×512 화면 뒤에서 솟아 앞으로 무너지는 거대한 금빛 모래 파도, 꼭대기 물보라) · 공용: 흙먼지 대(금빛). 코드: 흔들림 강, 화면이 모래빛으로 덮였다 걷힘, 처치된 적은 모래 입자로 흩음.
- 동작: 25번 그대로(망토 휘두름 = 2단계, 퍼 올림 = 3단계, 내리꽂음 = 4단계, 뻗은 자세 = 해일 타기).

## 앞 설계와 달라진 점
- 고유기술 「모래 더미 위 이동 -30%」(표식·숫자) → 뺌, 세 번째 탄이 밀어 냄.
- 충전기 「모래화 4초 굳음 · 30% 이하 즉사」(구속) → 방벽 / 흐르는 모래 이동 / 기둥 세 개로 모양이 바뀌게.
- 필살기 「3초 굳음 · 바닥 모래 10초 기술 강화」(구속·강화) → 해일로 휩쓸어 밀어 내는 한 장면. 구속·표식·강화 0개.
