# 3.14_이연화 기술 재설계

- 근거: 위키 「전투: 없다. 조심성, 분석, 빌린 장비로 살아남는다」, 「이 대리님이 멈추라고 하면 멈춰라」(「잠깐만요」), 「포션 제조 장비를 손으로 직접 다루고 고친다」, 연료 「카페인」, 주간 「과장님!」 횟수 평균 2회.
- 싸우는 방식 한 줄: 「겁먹은 거리를 지키며 멈춤 손바닥으로 밀쳐 내고, 직접 만든 시약병을 끼얹고 굴리고 터뜨리는 거리 두기형」

## 고유기술(D) 「잠깐만요」
- 하는 일: 앞손을 귀 옆으로 당겼다가 깊은 런지로 머리보다 높이 쭉 뻗어 손바닥을 세운다. 그 손바닥에서 앞으로 짧은 충격 고리가 터져 앞 1.5m 안 적을 멈춰 세우고 뒤로 튕겨 낸다. 달려들던 적(돌진 중)이 이 손바닥에 걸리면 몸이 뒤로 젖혀지며 휘청한다.
- 분류: 방어/제압(밀쳐 냄)
- 상대 반응: 크게 밀려나기(18-2). 돌진 중이던 적은 스턴(21) 짧게 — 손바닥에 얼굴을 정면으로 박아서.
- 전용 이펙트: 손바닥 앞 남보라 충격 고리(세로 타원), 화면 위 작은 「잠깐만요!」 도트 글씨. 공용: 충격파(작게).
- 동작: 22번 그대로(정점에서 멈춘 손바닥을 앞 장 거꾸로 틀어 전투 자세로).

## 충전기(S) 「배합 실험」
- 0단: 흔든 병을 앞으로 끼얹는다 → 앞 2m 부채꼴로 시약 물보라가 퍼져 맞은 적이 따가워 몸을 숙인다.
- 1단: 병을 볼링 공처럼 낮게 굴려 보낸다 → 병이 바닥을 타고 앞으로 4m 굴러가며 뒤에 미끄러운 시약 줄기를 남기고, 끝에서 깨진다. 그 줄기 위에 있던 적은 발이 미끄러져 넘어진다.
- 2단: 병을 머리 위로 높이 들어 하늘로 던진다 → 앞 3m 위 공중에서 터져 넓은 원으로 시약 비가 쏟아지고 남보라 연기가 피어올라, 원 안 적은 기침하며 그 자리에 주저앉는다(연기 때문에 기절).
- 분류: 공격(0단 부채꼴 · 1단 땅을 타고 감 · 2단 위에서 떨어지는 원)
- 상대 반응: 0단 맞기 상단 / 1단 쓰러지기(19, 미끄러져) / 2단 스턴(21, 연기에 기침).
- 전용 이펙트: 부채꼴 물보라(0단), 굴러가는 병과 바닥에 남는 번들거리는 시약 줄기(1단, 바닥 띠), 공중에서 터지는 병·시약 비·남보라 연기 원(2단). 공용: 유리 깨짐 파편.
- 동작: 모으기 23번 그대로(병 흔들기). 방출 0단 = 15번(포션병 끼얹기) 그대로, 1단 = 15번 빠르게(낮게 당겼다 앞으로 뻗는 손 = 굴려 보냄), 2단 = 24번 1~4장(병을 머리 위로 들어 올림 = 던짐) + 24번 5~8장(한숨).

## 필살기(F) 「과장님!」
- 연출 순서:
  1. 컷인(다크서클 위 안경, 앞으로 뻗은 멈춤 손바닥, 반쯤 남은 커피 잔) 뒤, 커피를 고개 젖혀 원샷한다. 안경알이 하얗게 번뜩인다.
  2. 「과장님!」을 외치는 순간 입에서 거대한 도트 글씨 「과장님!」이 덩어리째 튀어나와 앞으로 화면 끝까지 날아간다. 글씨에 부딪힌 적들은 줄줄이 들이받혀 밀려간다.
  3. 런지로 앞팔을 뻗어 가장 가까운 적의 옷깃을 움켜쥐고 허리로 확 끌어당겨 바닥에 메다꽂는다.
  4. 다른 손으로 입을 탁 가리는 순간, 화면 끝에 박힌 「과장님!」 글씨가 산산조각 나 파편이 앞쪽 적들 위로 쏟아진다.
  5. 안경을 밀어 올리고 전투 자세로 돌아온다.
- 상대 반응: 글씨에 맞은 적은 크게 밀려나기 → 화면 끝에서 벽에 박힘, 움켜쥔 적은 끌려와 메다꽂혀 쓰러지기, 파편에 맞기 하단.
- 전용 이펙트(크게): 화면 높이 1/3 크기의 「과장님!」 도트 글씨 덩어리가 앞으로 날아감(지나간 자리에 남보라 바람 줄), 끝에서 부서지는 글자 파편 비, 메다꽂는 자리 바닥 금. 화면 흔들림 중.
- 동작: 25번 그대로.

## 앞 설계와 달라진 점
- 「아군 전원 정지·위험 지점 표시」 표식, 「회복 포션」, 「위험 면역 포션」 강화, 「곽제강 회복·무적」, 「규칙 정지·이동 +20%」를 전부 지웠다. 멈추라는 손바닥은 밀쳐 내는 손바닥으로, 포션은 끼얹고 굴리고 터뜨리는 시약 공격으로, 「과장님!」 외침은 글씨 덩어리를 날리고 멱살을 잡아 메다꽂는 장면으로 바꿨다.
- 구속·표식·강화 0개(움켜쥐어 끌어당기기는 한 번 메다꽂고 끝나는 잡기라 구속이 아님).
