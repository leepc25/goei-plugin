# 3.11_강이학 기술 재설계

- 근거: 위키 「흥정과 프레이밍: 싸움을 거래로 바꾼다」, 「감정과 중개: 방 안의 모든 물건, 시체, 비밀의 값을 즉석에서 매긴다」·「무게만으로 "최소 열 돈"을 맞힌다」, 「괴이 등급 화폐 지갑: 여러 괴담을 드나들며 모은 동전 형태의 화폐」, 「"평사원 둘이어도 괜찮아요. 매뉴얼만 지키면요."」, 엄지·검지 동전 동그라미와 엄지척 버릇.
- 싸우는 방식 한 줄: 「활짝 웃으며 값을 매기고, 지갑의 괴이 화폐를 흩뿌리고 쏟아붓고 떨어뜨리는 동전 물량형」

## 고유기술(D) 「값 매기기」
- 하는 일: 엄지·검지 동그라미를 한쪽 눈에 대고 상체를 쑥 내밀며 앞으로 2m 미끄러져 들어감. 몸을 세우며 엄지척 주먹을 턱 밑에서 위로 올려 앞 1m 적을 쳐 올림. 맞은 적 머리 위로 금빛 「최소 열 돈!」 글자가 튐.
- 분류: 이동(짧은 파고들기) → 공격(올려 치기)
- 상대 반응: 띄워지기(작게) → 쓰러지기
- 전용 이펙트: 동그라미 손 안 금빛 반짝임(코드 점), 「최소 열 돈!」 금빛 도트 글씨(문구는 코드가 몇 개 중 고름) · 공용: 타격_약
- 동작: 22번 그대로(1~3장 들여다보며 내밂 = 미끄러짐, 4~6장 엄지척 = 판정)

## 충전기(S) 「협상 테이블」
- 0단 「착수금」: 내민 손바닥에서 동전 한 줌이 앞 2.5m 부채꼴(60도)로 산탄처럼 흩뿌려짐. 가까이 넓게.
- 1단 「일시불」: 내민 손바닥에서 동전이 줄줄이 이어 쏟아져 나가 앞 7m 직선을 관통하는 금빛 동전 줄기. 맞은 적 전원 밀려남.
- 2단 「연체 시 즉시 해지」: 꾸벅 숙였다 지갑을 앞으로 펼쳐 내미는 순간, 앞 6m 안 가장 먼 적 한 명의 몸에서 구멍 뚫린 괴이 화폐가 줄줄이 뽑혀 나와 강이학 지갑으로 **거꾸로 빨려 들어오는 동전 줄기**가 된다(값을 받아 냄). 다 뽑힌 적은 휘청이다 무릎부터 털썩 쓰러지고, 빨려 오는 줄기가 지나는 길의 다른 적들은 등 쪽부터 동전에 두들겨 맞으며 강이학 쪽으로 고꾸라짐.
- 분류: 공격(0단 가까운 부채꼴 / 1단 긴 직선 / 2단 먼 적에서 거꾸로 빨려 오는 직선)
- 상대 반응: 0단 맞기 상단(여러 번 약) · 1단 밀려나기 · 2단 뽑힌 적 쓰러지기, 길 위 적 앞으로(강이학 쪽) 쓰러지기
- 전용 이펙트: `fx_강이학_동전`(32×32 금빛 동전 회전 6장, 괴이 화폐는 구멍 뚫린 문양), 동전 줄기(이음 조각, 2단은 거꾸로 흐름)
- 동작: 모으기 23번 그대로(한 무릎 꿇고 맞잡은 손을 비빔) · 0·1단 = 24번 1~3장(손바닥 위로 내밂 = 동전이 나감) · 2단 = 24번 그대로(5~7장 꾸벅 뒤 내밂 = 동전이 빨려 옴)

## 필살기(F) 「매뉴얼만 지키면요」
- 연출 순서:
  1. 컷인 뒤 발끝으로 서서 한 손을 머리 위로 흔들면 지갑에서 금빛 동전이 하늘로 솟구쳐 화면 위가 금빛으로 덮이고, 사람 키만 한 거대한 금화 세 개가 공중에 떠오름.
  2. 검지로 앞을 머리·가슴·무릎 높이로 하나씩 가리키며 값을 부름 — 가리킬 때마다 거대한 금화 하나가 바퀴처럼 세워져 굴러가 그 줄(화면 위쪽·가운데·아래쪽 줄)을 화면 끝까지 휩쓸어 치고 감.
  3. 가슴 앞에서 손뼉 「짝」 — 화면 전체에 동전 비가 한꺼번에 쏟아져 적 전원을 여러 번 때림.
  4. 허리 깊이 꾸벅 — 화면 한가운데 큰 금빛 「낙찰!」.
  5. 엄지척하며 일어나면 쓰러진 적들 위에 쌓인 동전이 반짝이며 사라짐.
- 상대 반응: 금화에 치여 쓰러지기(줄마다) → 동전 비 다단 맞기 → 쓰러진 채 바운드
- 전용 이펙트(크게): 거대한 금화 굴러감(192×192 회전 6장, 세 줄 화면 폭 전부), 화면 전체 동전 비(동전 수십 개, 코드가 `fx_강이학_동전`을 뿌림), 「낙찰!」 큰 금빛 도트 글씨, 화면 금빛 번쩍 · 공용: 흔들림(필살)
- 동작: 25번 그대로(1~2장 손 흔들기, 3~6장 세 번 가리키기 = 금화 셋, 7장 손뼉 = 동전 비, 8~10장 꾸벅, 11~12장 엄지척)

## 앞 설계와 달라진 점
- 고유기술: 「값」 표식 + 받는 피해 +15% → 들여다보며 파고들어 엄지척으로 쳐 올리기.
- 충전기: 거래 중 정지·매수(구속, 적 AI만 바뀜) → 동전 부채꼴·동전 줄기·거꾸로 빨려 오는 동전 줄기로 모양이 바뀌는 공격.
- 필살기: 경매 매수 + 받는 피해 +30% + 이동 속도 +20% → 거대한 금화 세 개와 동전 비. 구속·표식·강화 0개.
- (겹침 정리) 충전 2단의 「적 머리 위로 떨어지는 화폐 자루」는 위에서 떨어지는 묶음과 겹쳐, 먼 적에게서 값을 받아 내듯 동전이 거꾸로 빨려 오는 줄기로 바꿨다. 필살기의 동전 비는 지갑을 쏟아붓는 이 인물의 정체라 남겼다.
