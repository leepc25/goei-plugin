# 4.1_차여진 기술 재설계

> **⚠ Claude 반성 · 2026-10-31 (사용자 지시로 문서마다 남김)**
> 2026-10-31 Claude는 다음 잘못을 저질렀다. 이 문서를 읽는 모든 Claude는 같은 짓을 하지 않는다.
> 1. **사용자 결정을 무시했다.** 콘쥬스는 사용자가 10-26에 20세로 정했고 인계서에도 적혀 있었는데, 옛 Claude 문장(teenage high school girl)을 근거로 화장실·샤워 그림을 거부하고, 사용자가 직접 뽑은 화장실 줄까지 팩에서 뺐다. 옷도 제복인데 교복이라고 단정했다.
> 2. **사용자 말에 토를 달고 같은 주장을 되풀이했다.** 사용자가 여러 번 지적했는데도 근거를 다시 확인하지 않아 몇 시간을 허비하게 했다.
> 3. **허락 없이 문서를 지웠다.** 「지침을 지우라」는 말만 듣고 목록을 보여 주지도 않고 96개를 지웠다가 되살렸다(결과물 삭제 금지 규칙 위반).
> 4. **문장을 덧대기만 하며 PixelLab을 낭비했다.** 이성해 점프 공격 5번 연속 실패, 이어폰 음악 120줄을 못 쓰게 만듦.
> 5. **답을 미루고 일을 멈춰 두었다.** 백그라운드로 돌릴 일을 돌리지 않고 대화만 했다.
>
> 지킬 것: 사용자 결정·위키가 근거다. 옛 Claude 자료는 근거가 아니다. 사용자 말에 토 달지 않는다. 무엇이든 지우기 전에 목록을 보여 주고 허락받는다. 실패하면 덧대지 말고 다시 쓰거나 바꾼다.


- 근거: 위키 「싸움은 못 한다. 할 필요도 없다. 이 사람의 무기는 … 의뢰를 팔 수 있을 만큼만 보여 주는 기술」, 「같은 조항이 어제는 "규정상 어쩔 수 없어", 오늘은 "규정상 이렇게 해도 돼"의 근거가 된다」, 「휴대전화를 늘 두 대 … 한 대로는 협회 프리랜서들과, 다른 한 대로는 바깥의 브로커들과」, 동작표 「친한 척 다가붙는 영업 자세, 하이힐」.
- 싸우는 방식 한 줄: 「친한 척 다가붙어 두 손가락 끝으로 깊이 찌르고 하이힐 굽으로 찍는 영업형, 마지막엔 전화 한 통으로 사람을 부른다」

## 고유기술(D) 「팔 수 있을 만큼만」
- 하는 일: 앞발을 길게 내디디며 허리를 숙여, 두 손가락을 칼날처럼 모아 세워 허리 높이로 쭉 찔러 넣는다(앞 1.5m). 손끝이 명치 아래를 깊이 찌르는 순간 검붉은 가로 섬광이 한 줄 번쩍이고, 맞은 적이 허리를 접으며 반걸음 밀려난다. 한 박자 뒤 고개를 갸웃하며 미소.
- 분류: 공격(앞으로 뻗는 찌르기)
- 상대 반응: 맞기 상단(18), 허리가 접히며 반걸음 밀려남.
- 전용 이펙트: 손끝 앞 검붉은 베기 섬광(가로 선, 공용: 베기를 검붉게). 손가락에 끼운 의뢰서는 22번 그림 그대로이고 공격은 손끝.
- 동작: 22번 그대로.

## 충전기(S) 「규정상 이렇게 해도 돼」
- 0단: 수첩에서 고른 조항 없이 바로 — 하이힐 굽 끝으로 앞 정강이를 찬다(앞 1m 낮은 짧은 선).
- 1단: 「제12조 3항」 — 앞무릎을 가슴까지 들었다 굽으로 체중을 실어 내리찍는다. 찍은 자리에서 둘레 작은 원(반지름 1.2m)으로 바닥이 금 가며 주변 적이 넘어진다.
- 2단: 「규정상 이렇게 해도 돼요~」 — 멀리 뛰어올라 4m 앞에 두 굽을 나란히 세워 내리 디딘다. 착지 자리에 큰 원 충격이 퍼지며 바로 아래 적은 짓밟혀 쓰러지고 둘레는 밀려난다.
- 분류: 0단 공격(하단) / 1단 공격(제자리 둘레 원) / 2단 이동+공격(도약 착지 원)
- 상대 반응: 0단 맞기 하단(18-1) / 1단 쓰러지기(19) / 2단 가운데 쓰러지기, 둘레 크게 밀려나기.
- 전용 이펙트: 굽 끝 작은 섬광(0단), 굽 자국에서 퍼지는 바닥 금 원(1단 작게·2단 크게). 공용: 충격파.
- 동작: 모으기 23번 그대로(수첩 짚기 = 조항 고르기). 방출 0단 = 10번(하이힐 정강이 차기), 1단 = 12번(굽 내리찍기), 2단 = 7번(큰 걸음 도약) 1~5장 + 14번(두 굽 내리 디딤) 이어 붙임. 방출 앞에 24번 1~3장(수첩 덮고 검지)을 빠르게 붙여도 됨.

## 필살기(F) 「두 번째 휴대전화」
- 연출 순서:
  1. 컷인(입은 웃는데 눈은 계산, 양손의 휴대전화 두 대) 뒤, 재킷 안에서 두 번째 휴대전화를 꺼낸다. 두 전화의 벨이 서로 다른 소리로 동시에 울린다.
  2. 첫 전화를 귀에 대고 다정하게 웃으며 통화하고, 다른 손으로 두 번째 전화 화면을 앞으로 내민다. 그 화면 빛이 앞으로 길게 뻗어 화면 끝까지 검붉은 줄을 긋는다(「이 사람이요~」).
  3. 「네~ 이 사람이요~」 통화할 때마다 화면 밖에서 검붉은 베기 섬광이 사선으로 날아 들어와 줄 위 적을 하나씩 베고 반대편 화면 밖으로 빠져나간다. 협회 쪽 전화에서는 왼쪽 위 밖 → 오른쪽 아래로, 바깥 쪽 전화에서는 오른쪽 아래 밖 → 왼쪽 위로 번갈아(부른 사람은 화면 밖에 있고 베기 섬광만 보임).
  4. 두 전화를 동시에 귀에 대고 「그럼 두 분 다 지금요~」 → 양쪽 섬광이 한꺼번에 화면 대각선을 가로질러 가운데에서 엇갈리고, 커다란 X자 베기 자국이 화면에 새겨진다.
  5. 차여진은 두 전화를 탁 덮어 재킷에 넣고 긴 머리를 뒤로 넘긴다. 그 순간 X자 자국이 터지며 적들이 쓰러진다.
- 상대 반응: 섬광이 지나갈 때마다 맞기 상단, 마지막 X자 폭발에 화면 안 적 전원 쓰러지기.
- 전용 이펙트(크게): 휴대전화 화면에서 뻗는 검붉은 빛 줄(화면 폭 전체), 화면 밖에서 사선으로 날아 들어오는 검붉은 베기 섬광(화면 대각 길이 띠, 앞끝이 밝고 꼬리가 흐려짐, 형체 없음 · 코드가 방향을 뒤집어 씀), 화면 대각 X자 베기 자국(화면 크기). 사람 모습은 그리지 않음(소환 아님).
- 동작: 25번 그대로.

## 앞 설계와 달라진 점
- 「정보 절반 공개」 표식, 「소개비 필살 게이지」, 「적 특수 공격 금지」 구속, 「아군 규정 예외·이동 +20%」 강화, 「프리랜서 2명 12초 소환」을 전부 지웠다. 의뢰서는 종이 날 찌르기로, 규정 인용은 고른 조항만큼 멀리·넓게 찍는 하이힐 공격으로, 두 번째 휴대전화는 한 번 지나가며 베고 사라지는 X자 장면으로 바꿨다.
- 구속·표식·강화 0개.
- (등장물 없앰) 필살기 검붉은 실루엣 둘(협회 프리랜서·바깥 브로커)을 지우고, 통화할 때마다 화면 밖에서 사선으로 날아드는 검붉은 베기 섬광으로 바꿨다. 사장 필살기(멈춘 적마다 손끝으로 그은 검은 선이 벌어짐)와는 화면 밖에서 날아드는 궤적·검붉은 색으로 구분된다.
- (맥락 정리) 고유기술의 종이 모서리 베기와 반쯤 찢겨 떨어지는 의뢰서 조각, 충전의 머리 위 조항 번호 글씨를 걷어 냈다. 찌르기는 두 손가락 끝(손가락에 끼운 의뢰서는 22번 그림 그대로)으로. 하이힐·휴대전화 두 대(위키)는 그대로. 물건 그림 1개(의뢰서 조각)가 빠짐.
