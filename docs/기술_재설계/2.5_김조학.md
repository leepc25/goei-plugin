# 2.5_김조학 기술 재설계

- 근거: 위키 「상대에 대한 두꺼운 서류철, 그리고 … 노트북. 이 두 가지가 김조학의 무기다. 총은 문밖에 서 있는 사람들이 들고 있다」, 「공포, 침묵, 선택적인 증거 제시」, 「김조학 과장에게 책상 내려치는 소리를 듣던 사람」, 「영상 올리기 전에 김조학 생각해라」, 필수품 「아이스커피 두 잔」.
- 싸우는 방식 한 줄: 「두꺼운 서류철로 내리치고 증거 서류를 칼날처럼 흩뿌리는, 팔짱 낀 심문관」

## 고유기술(D) 「책상 내려치기」
- 하는 일: 닫힌 서류철을 두 손으로 머리 위로 들었다가 앞 1.5m 허리 높이 허공(책상 자리)에 쾅 내리침. 바로 앞 적은 정수리를 맞아 무릎이 꺾이며 주저앉고, 내리친 자리에서 종이 몇 장이 튀어 오름. 김조학은 무심하게 한 장을 넘김.
- 분류: 공격(위에서 내리침) + 제압(머리 맞아 주저앉음)
- 상대 반응: 맞기 상단 → 무릎 꿇고 주저앉기(짧은 다운)
- 전용 이펙트: 내리치는 순간 납작한 충격선 `fx_김조학_쾅`(128×64, 4장), 종이 도트 3장 튐(코드), 화면 흔들림 약
- 동작: 22번 그대로(2장 머리 위, 4장 내리침 = 타격 장, 6~8장 한 장 넘김)

## 충전기(S) 「선택적인 증거 제시」
- 모으는 동안: 서류철을 펼쳐 펼친 면을 상대 쪽으로 들이밀고 지루한 얼굴로 가리킴. 펼친 면 위에 노트북 화면 같은 푸른 빛이 켜지고 단계마다 종이가 한 겹씩 부풀어 오름.
- 0단: 덮는 순간 서류 한 장이 날아가 앞 직선 6m를 종이 칼날처럼 가르며 지나감(관통).
- 1단: 증거 사진 다섯 장이 앞 부채꼴(70도, 4m)로 쫙 흩뿌려져 날아감.
- 2단: 서류철이 통째로 터지며 앞 3m 지점에 종이 회오리 기둥이 서서, 둘레 2m 안 적을 안으로 빨아들였다가 위로 휘감아 올려 던짐.
- 분류: 공격(관통 직선 / 부채꼴 투사체 / 회오리 기둥)
- 상대 반응: 0단 맞기 상단 · 1단 장마다 경직 → 밀려나기 · 2단 끌려옴 → 띄워지기 → 쓰러지기
- 전용 이펙트: `fx_김조학_노트북화면`(96×64, 펼친 서류철 위 푸른 빛), `fx_김조학_서류칼날`(64×32, 회전하며 나는 종이 4장), `fx_김조학_종이회오리`(128×256, 8장)
- 동작: 모으기 23번(펼쳐 들이밀기) · 방출 24번(탁 덮고 내려다봄) 그대로, 2단은 24번 뒤에 15번 원거리 5~8장(팔 다 펴 들이밀기 = 회오리 던짐) 이어 붙임

## 필살기(F) 「영상 올리기 전에」
- 연출 순서:
  1. 컷인 뒤 김조학이 빈손을 입에 대 아이스커피를 한 모금(얼음 소리). 화면이 푸르게 어두워짐.
  2. 서류철을 머리 높이로 활짝 펼쳐 보이면 화면 안 적마다 머리 위에 도트 파일 창이 하나씩 떠오름(줄무늬 칸, 진행 막대).
  3. 검지로 펼친 면을 톡(엔터) — 진행 막대가 꽉 차며 파일 창들이 그대로 커져 무거운 판처럼 적 머리 위에 쾅 떨어져 짓누름.
  4. 선글라스를 고쳐 쓰고 어깨 너머 뒤(문)를 가리키면, 화면 양 끝에서 검은 정장 경비 둘이 뛰어들어 화면을 가로지르는 태클로 일어나던 적들을 쓸어 넘어뜨리고 반대편으로 빠짐.
- 상대 반응: 위에서 눌려 쓰러지기(바운드) → 태클에 쓸려 다운
- 전용 이펙트: `fx_김조학_파일창`(128×96, 떠오름 2장 + 떨어져 박히는 4장, 박힐 때 깨지는 화면 조각), 경비는 가짜 관리국 기본 요원 그림 13번 돌진(코드), 푸른 화면 덮개(코드)
- 동작: 25번 그대로(1~2장 한 모금, 3~6장 펼쳐 보임, 7~8장 톡 = 낙하, 9~12장 선글라스·문 가리킴 = 경비 돌입)

## 앞 설계와 달라진 점
- 고유기술: 공포 경직 + 방어 -25%(구속·강화) + 3회째 「자백」 표식 → 서류철로 정수리를 내리쳐 주저앉히는 공격.
- 충전기: 공포(뒤로 물러남)·「퇴장」(싸움 밖) → 서류를 날리는 세 모양(관통 직선·부채꼴·회오리).
- 필살기: 3초 정지·은신 해제·기술 봉인·경비 6초 소환 → 파일 창이 떨어져 짓누르고 경비가 한 번 쓸고 지나가는 연출.
- 구속 0, 표식 0, 강화 0.
