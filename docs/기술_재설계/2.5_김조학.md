## 고유기술(D) 「책상 내려치기」
- 하는 일: 닫힌 서류철을 두 손으로 머리 위로 들었다가 앞 1.5m 허리 높이 허공(책상 자리)에 쾅 내리침. 바로 앞 적은 정수리를 맞아 무릎이 꺾이며 주저앉고, 내리친 자리에서 종이 몇 장이 튀어 오름. 김조학은 무심하게 한 장을 넘김.
- 분류: 공격(위에서 내리침) + 제압(머리 맞아 주저앉음)
- 상대 반응: 맞기 상단 → 무릎 꿇고 주저앉기(짧은 다운)
- 전용 이펙트: 내리치는 순간 납작한 충격선 `fx_김조학_쾅`(128×64, 4장), 종이 도트 3장 튐(코드), 화면 흔들림 약
- 동작: 22번 그대로(2장 머리 위, 4장 내리침 = 타격 장, 6~8장 한 장 넘김)

## 충전기(S) 「선택적인 증거 제시」
- 모으는 동안: 서류철을 펼쳐 펼친 면을 상대 쪽으로 들이밀고 지루한 얼굴로 가리킴(단계마다 한 장씩 넘김, 코드).
- 0단: 탁 덮은 서류철을 런지와 함께 팔 다 펴서 앞으로 곧게 들이민다 → 서류철 모서리가 앞 1.5m 적의 명치를 찔러 밀쳐 낸다(짧은 한 점).
- 1단: 덮자마자 팔짱을 끼고 상체를 낮게 숙여 앞어깨부터 몸통째 들이받으며 돌진 → 앞 5m 일직선, 처음 부딪힌 적을 어깨에 걸어 밀고 가다 끝에서 뒤로 넘어뜨린다.
- 2단: 덮은 뒤 턱을 들어 내려다보다가, 팔짱 낀 채 앞무릎을 가슴까지 들었다 한 보폭 앞 바닥을 뒤꿈치로 쾅 밟는다(「책상 내려치는 소리」) → 둘레 원(반지름 2.5m)으로 바닥이 울려 금이 가고, 원 안 적이 다리가 꺾여 주저앉았다 튕겨 오른다.
- 분류: 공격(0단 짧은 점 / 1단 일직선 돌진 / 2단 둘레 원)
- 상대 반응: 0단 밀려나기 · 1단 끌려가다 뒤로 쓰러지기 · 2단 주저앉기 → 띄워지기 → 쓰러지기
- 전용 이펙트: 없음. 2단은 `fx_김조학_쾅`(고유기술 납작한 충격선)을 둘레 원으로 펼쳐 씀. 공용: 타격_강·흙먼지(1단)·바닥 파괴(2단, 작게).
- 동작: 모으기 23번(펼쳐 들이밀기) · 방출 24번(탁 덮고 내려다봄) 1~4장 뒤 — 0단 = 15번(원거리 들이밀기) 4~6장 / 1단 = 13번(어깨 들이받기) 그대로 / 2단 = 12번(강, 구둣발 내려밟기) 그대로

## 필살기(F) 「영상 올리기 전에」
- 연출 순서:
  1. 컷인 뒤 김조학이 빈손을 입가에 댄 채 화면을 한 번 훑는다. 화면이 푸르게 어두워지고 소리가 낮게 가라앉는다(공포, 침묵).
  2. 서류철을 머리 높이로 활짝 펼쳐 보이며 천천히 걸어 들어가, 가장 가까운 적부터 차례로 서류철을 머리 위에서 내리쳐 정수리를 친다(세 명, 적마다 무릎이 꺾여 주저앉음).
  3. 선글라스를 고쳐 쓰고 어깨 너머 뒤(문)를 가리키면, 화면 양 끝에서 검은 정장 경비 둘이 뛰어들어 화면을 가로지르는 태클로 남은 적들을 쓸어 넘어뜨리고 반대편으로 빠짐(위키 「총은 문밖에 서 있는 사람들이 들고 있다」).
  4. 서류철을 탁 덮고 팔짱 낀 채 구둣발로 바닥을 쾅 밟는다 → 푸른 기가 도는 납작한 충격선이 화면 바닥 폭 전체로 퍼져 쓰러져 있던 적 전원이 튕겨 올랐다 다운.
- 상대 반응: 정수리 맞아 주저앉기 → 태클에 쓸려 쓰러지기 → 마지막 충격에 띄워졌다 다운
- 전용 이펙트(크게): `fx_김조학_쾅`(고유기술 납작한 충격선)을 화면 바닥 폭으로 늘림, 경비는 가짜 관리국 기본 요원 그림 13번 돌진(코드), 푸른 화면 덮개(코드). 공용: 타격_강·흔들림(필살).
- 동작: 25번 1~6장(입가 손·펼쳐 보임) → 22번(서류철 내리치기) 빠르게 ×3 → 25번 9~12장(선글라스·문 가리킴 = 경비 돌입) → 12번(구둣발 내려밟기). 모두 기존 줄.

## 앞 설계와 달라진 점
- 고유기술: 공포 경직 + 방어 -25%(구속·강화) + 3회째 「자백」 표식 → 서류철로 정수리를 내리쳐 주저앉히는 공격.
- 충전기: 공포(뒤로 물러남)·「퇴장」(싸움 밖) → 서류를 날리는 세 모양(관통 직선·부채꼴·회오리).
- 필살기: 3초 정지·은신 해제·기술 봉인·경비 6초 소환 → 파일 창이 떨어져 짓누르고 경비가 한 번 쓸고 지나가는 연출.
- 구속 0, 표식 0, 강화 0.
- (맥락 정리) 충전의 노트북 화면 빛·종이 칼날·증거 사진 다섯 장·종이 회오리, 필살기의 아이스커피 한 모금과 적 머리 위로 떨어지는 파일 창을 걷어 냈다. 충전은 동작표 몸 기술(서류철 들이밀기·팔짱 어깨 들이받기·구둣발 내려밟기)로, 필살기는 서류철 내리치기 세 번 → 위키의 문밖 경비 태클 → 구둣발 충격선. 서류철(위키 「두꺼운 서류철 … 김조학의 무기」)은 그대로. 물건 그림 2개(서류 칼날·증거 사진)와 전용 노트북 빛·종이 회오리·파일 창이 빠짐.
