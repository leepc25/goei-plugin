# 2.13_김성진 기술 재설계

- 근거: 위키 「사격과 체력은 신입 표준 수준 … 싸움에서 이 사람의 진짜 자산은 따로 있다. 멈추지 않는다」, 「"야 저거 봤냐", "와 미쳤다", "나 방금 멋있지 않았냐"」, 「휴대폰을 꺼내면 동기들이 반사적으로 화면을 가린다. 본인은 셀카 찍으려던 거라고 억울해한다」, 「자원을 찾고, 일정을 정찰하고, 움직일 타이밍을 잰다 … 한설인육공장 생환 기록」, 별명 「오뚝이」. 동작표: 「덤벼」 손짓, 쉬지 않고 걸으며 쏘기, 길바닥 막싸움.
- 싸우는 방식 한 줄: 「떠들면서 멈추지 않고 걸어 들어가며 쏘고, 셀카 플래시와 바닥에서 주운 것까지 다 쓰는 길거리 생존형」

같은 7팀 송진섭(제자리에서 한 발, 자동 조준)과 겹치지 않게, 김성진의 사격은 **걸으며 여러 발**이다.

## 고유기술(D) 「야 저거 봤냐」
- 하는 일: 빈손 검지로 앞을 가리키며 권총을 어깨 높이로 내리고, 반 걸음씩 걸어 나가며 세 번 쏜다(앞 일직선 7m). 한 발마다 앞으로 반 걸음 → 총 1.5m 전진. 맞은 적은 두 번 움찔하고 세 번째에 뒤로 밀린다. 끝에 총을 볼 옆에 세우고 으스댄다(머리 위 「봤냐?」 말풍선, 꾸밈).
- 분류: 공격(앞 직선 투사체 3발) + 짧은 전진
- 상대 반응: 맞기 상단 2번 → 밀려나기
- 전용 이펙트: 공용: 총구 불꽃, 탄 줄기. 「봤냐?」 도트 말풍선(코드).
- 동작: 22번 그대로

## 충전기(S) 「셀카」
- 0단: 휴대폰을 머리 위로 들어 한 번 찰칵 → 김성진 **둘레 1.5m 원**이 하얗게 번쩍, 붙어 있던 적이 눈을 가리며 움찔(경직).
- 1단: 팔을 앞 위로 쭉 뻗어 찍는다 → **앞쪽 부채꼴 4m**가 번쩍, 그 안 적은 눈이 부셔 두 손으로 얼굴을 가리고 휘청(짧은 스턴 — 섬광 때문임이 보임).
- 2단: 1단 섬광 뒤 「오, 저거!」 하고 휴대폰을 재킷에 넣고 쪼그려 바닥의 돌·병 조각을 한 줌 쥐어 일어나며 앞으로 뿌린다 → 앞 3m **산탄 모양 파편**이 눈먼 적들을 맞혀 넘어뜨린다.
- 분류: 제압(0단 둘레 원, 1단 앞 부채꼴 섬광, 2단 섬광 + 앞 산탄 파편)
- 상대 반응: 0단 경직 / 1단 스턴(눈 가리고 휘청) / 2단 스턴 → 쓰러지기
- 전용 이펙트: 휴대폰 플래시 섬광(둘레 원·앞 부채꼴 두 모양, 흰색 + 연두 테두리), 흩어지는 돌·유리 파편 산탄(128×64), 눈 가린 적 머리 위 작은 별(코드).
- 동작: 23번 그대로(휴대폰 높이 들고 씩) → 0·1단 24번 1~2장(움찔 솟기)만, 2단 24번 그대로(쪼그려 줍고 튀어 일어나는 장이 뿌리기)

## 필살기(F) 「생환 기록」
- 연출 순서:
  1. 컷인(선글라스를 이마에 올린 씩 웃음, 휴대폰 불빛) → 김성진이 넘어질 듯 뒤로 크게 젖혀진다. 그 순간 화면이 거의 멈춘 듯 느려지고 김성진만 빼고 회색이 된다. 날아오던 적 탄·투척물이 공중에 멈춰 있고, 그 몇 개가 젖힌 몸 바로 위를 스쳐 지나가 있다.
  2. 앞발을 다시 딛고 버티며 고개를 들어 씩 웃는다. 「나 방금 멋있지 않았냐?」
  3. 권총을 두 손으로 겨누고 네 걸음 걸어 나가는 동안, 느린 화면 속에서 화면 안 적마다 두세 발씩 탄이 차례로 날아가 멈춘다(탄 줄기가 공중에 줄줄이 그려짐). 공중에 멈춘 적 투사체도 맞아서 깨진다.
  4. 무기 자세로 돌아오는 순간 시간이 원래대로 — 멈춰 있던 탄이 한꺼번에 꽂혀 화면 안 적이 동시에 뒤로 튕겨 넘어진다.
- 상대 반응: (느린 화면 동안 정지) → 동시에 크게 밀려나 다운. 내내 무적.
- 전용 이펙트: 화면 회색·느려짐(코드), 공중에 멈춘 탄 줄기 여러 줄(코드 선 + 탄 도트), 깨지는 적 투사체 조각, 시간이 풀릴 때 화면 흰 번쩍 1장. 공용: 총구 불꽃, 흔들림(필살).
- 동작: 25번 그대로(마지막 무기 자세 잇기는 코드)

## 앞 설계와 달라진 점
- 고유기술의 이동 속도 +10% 중첩(강화), 충전의 숨은 물건 표시(정보)·아이템 줍기(회복)·은신, 필살기의 8초 안 쓰러짐·공격 속도·이동 속도 증가·체력 회복(강화·회복)을 모두 뺐다. 휴대폰은 셀카 섬광으로 눈을 멀게 하는 무기로, 「생존 감각」은 느린 화면 속 연속 사격 한 장면으로 바꿨다. 구속·표식·강화 0개.
