# 2.13_김성진 기술 재설계

- 근거: 위키 「사격과 체력은 신입 표준 수준 … 싸움에서 이 사람의 진짜 자산은 따로 있다. 멈추지 않는다」, 「"야 저거 봤냐", "와 미쳤다", "나 방금 멋있지 않았냐"」, 「휴대폰을 꺼내면 동기들이 반사적으로 화면을 가린다. 본인은 셀카 찍으려던 거라고 억울해한다」, 「자원을 찾고, 일정을 정찰하고, 움직일 타이밍을 잰다 … 한설인육공장 생환 기록」, 별명 「오뚝이」. 동작표: 「덤벼」 손짓, 쉬지 않고 걸으며 쏘기, 길바닥 막싸움.
- 싸우는 방식 한 줄: 「떠들면서 멈추지 않고 걸어 들어가며 쏘고, 따귀·태클·박치기 막싸움으로 버티는 길거리 생존형」

같은 7팀 송진섭(제자리에서 한 발, 자동 조준)과 겹치지 않게, 김성진의 사격은 **걸으며 여러 발**이다.

## 고유기술(D) 「야 저거 봤냐」
- 하는 일: 빈손 검지로 앞을 가리키며 권총을 어깨 높이로 내리고, 반 걸음씩 걸어 나가며 세 번 쏜다(앞 일직선 7m). 한 발마다 앞으로 반 걸음 → 총 1.5m 전진. 맞은 적은 두 번 움찔하고 세 번째에 뒤로 밀린다. 끝에 총을 볼 옆에 세우고 으스댄다.
- 분류: 공격(앞 직선 투사체 3발) + 짧은 전진
- 상대 반응: 맞기 상단 2번 → 밀려나기
- 전용 이펙트: 공용: 총구 불꽃, 탄 줄기.
- 동작: 22번 그대로

## 충전기(S) 「주운 거 다 써」
- 휴대폰을 들고 씩 웃으며 모은다(셀카 자세, 효과 없음). 단계마다 몸을 던지는 거리와 방식이 바뀐다.
- 0단: 「오, 저거!」 앞손 따귀를 얼굴 높이로 크게 휘두르고 이어 뒷주먹 훅을 머리 높이로 둘러 친다 → 앞 1m 2연타, 훅에 맞은 적이 옆으로 고개가 돌아가며 휘청.
- 1단: 「야 이거 봐라!」 달리다 몸을 허리 높이로 숙여 앞어깨로 몸통째 들이받는다 → 앞 4m 일직선, 처음 부딪힌 적이 뒤로 넘어지고 김성진은 튕겨 일어난다.
- 2단: 「나 방금 멋있지 않았냐?」 한 걸음 붙어 두 손으로 앞 적의 어깨를 움켜잡고 고개를 뒤로 크게 젖혔다가 온몸을 던져 이마로 들이받는다 → 맞은 적이 일직선으로 5m 날아가며 뒤에 선 적과 부딪혀 함께 넘어지고, 김성진은 비틀하다 오뚝이처럼 다시 서서 씩 웃는다.
- 분류: 0단 공격(붙어서 2연타) / 1단 이동+공격(일직선 태클) / 2단 공격(붙잡아 박치기, 한 명을 멀리 날림)
- 상대 반응: 0단 맞기 상단 → 휘청 / 1단 뒤로 쓰러지기 / 2단 이마에 받혀 고개가 꺾임 → 크게 날아가 쓰러지기, 부딪힌 적 쓰러지기
- 전용 이펙트: 없음. 공용: 타격_약·타격_강, 흙먼지(1·2단 착지).
- 동작: 23번 그대로(휴대폰 높이 들고 씩) → 0단 = 9번(앞손 따귀) + 10번(뒷손 훅) 빠르게 / 1단 = 13번(어깨 태클) 그대로 / 2단 = 12번(강, 박치기) 그대로

## 필살기(F) 「생환 기록」
- 연출 순서:
  1. 컷인(선글라스를 이마에 올린 씩 웃음, 휴대폰 불빛) → 김성진이 넘어질 듯 뒤로 크게 젖혀진다. 날아오던 적 탄·투척물이 젖힌 몸 바로 위를 스쳐 지나간다(시간은 그대로 흐르고, 몸으로 피함).
  2. 오뚝이처럼 튀어 다시 딛고 서며 고개를 들어 씩 웃는다. 「나 방금 멋있지 않았냐?」
  3. 권총을 두 손으로 겨누고 네 걸음 걸어 나가는 동안 쉬지 않고 쏜다 — 걸음마다 앞 부채꼴(앞 8m)을 한 줄씩 탄으로 쓸어, 앞쪽 적들이 맞을 때마다 한 걸음씩 밀린다.
  4. 마지막 걸음에서 발을 박고 멈춰 남은 탄을 앞 부채꼴에 한꺼번에 쏟아부어, 밀리던 적 전원이 총탄에 떠밀려 뒤로 넘어진다. 겨눈 자세를 풀지 않은 채 씩 웃는다.
- 상대 반응: 연속 맞기 → 밀려나기 → 쓰러지기(다운). 내내 무적.
- 전용 이펙트: 걸음마다 부채꼴로 쓸리는 탄 줄기(공용: 탄 줄기 여러 줄). 공용: 총구 불꽃(마지막 몰아 쏘기는 크게), 흔들림(필살).
- 동작: 25번 그대로(마지막 무기 자세 잇기는 코드)

## 앞 설계와 달라진 점
- 고유기술의 이동 속도 +10% 중첩(강화), 충전의 숨은 물건 표시(정보)·아이템 줍기(회복)·은신, 필살기의 8초 안 쓰러짐·공격 속도·이동 속도 증가·체력 회복(강화·회복)을 모두 뺐다. 「생존 감각」은 피하고 오뚝이처럼 일어나 걸으며 쏘는 한 장면으로 바꿨다. 구속·표식·강화 0개.
- (겹침 정리) 충전의 「셀카 플래시로 눈 멀게」는 고영은(헤드램프로 눈을 멀게 함이 정체성)과 겹쳐, 바닥에서 주운 돌·병을 던지는 공격으로 바꿨다. 필살기의 「세상이 회색으로 멈추고 공중에 멈춘 탄이 한꺼번에 꽂힘」은 사장 필살기(시간 정지 — 위키 그대로)와 같은 그림이라 시간은 멈추지 않고 걸으며 쓸어 쏘는 장면으로 바꿨다.
- (맥락 정리) 충전의 바닥에서 주운 돌멩이·빈 병·돌 조각 산탄(장면에 없던 물건 투척)과 고유기술의 「봤냐?」 말풍선, 필살기 끝의 돌멩이 줍기를 걷어 냈다. 충전은 동작표 막싸움(따귀·훅 → 어깨 태클 → 붙잡아 박치기)으로. 권총(위키)은 그대로. 물건 그림 1개(돌멩이·빈 병)와 전용 산탄 파편이 빠짐.
- (톤 정리) 필살기 끝 「다 쏜 권총을 던져 이마 별 → 전원이 넘어지고 튕겨 나온 권총을 받아 쥠」(개그)을 마지막 걸음에서 남은 탄을 몰아 쏴 넘어뜨리는 것으로 바꿨다(25번 겨눠 걷기 그대로). 충전 2단의 「이마 별」도 뺐다.
