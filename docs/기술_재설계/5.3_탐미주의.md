# 5.3_탐미주의 기술 재설계

- 근거: 단일 개체형 괴이, 자칭 예술가, 관리국 「열강」 중 유일한 개인. 「멀리서 손을 한 번 까딱하면 상대의 목이 막히고 … 검은 물감을 토한다」, 마네킹 사이를 옮겨 다니며 「받는 쪽에서 지지직 잡음」, 「관절이 사람과 반대 방향으로 꺾이고 … 무너진 벽과 쓰러진 기둥 사이를 그대로 뚫고 달려온다」, 최상위 전투원의 공격을 맨손으로 쳐냄, 「예술은 조각이라고 선언하자 들리는 범위 안의 모든 사람이 … 조각상처럼 굳어 버렸다」(위키).
- 싸우는 방식 한 줄: 「멀리서 손목 까딱으로 목을 막고, 마네킹을 갈아타며 등 뒤에 나타나 맨손으로 쳐내는 전시장 사냥꾼」

## 고유기술(D) 「물감」
- 하는 일: 앞팔을 곧게 뻗은 채 손목만 아래로 까딱한다 → 앞 7m 안 첫 적의 목에 검은 물감 소용돌이가 감기고, 적이 목을 움켜쥐며 허리를 접고 검은 물감을 바닥에 쏟는다(웅덩이는 그림만, 곧 마름).
- 분류: 공격(먼 거리 한 명, 자동 조준)
- 상대 반응: 맞기(하단) — 목을 움켜쥐고 허리가 꺾이는 경직
- 전용 이펙트: GPT `fx_탐미주의_물감`(6장 · 96×64 목에 감기는 검은 소용돌이 + 바닥에 번지는 검은 물감, 구토 묘사 없이 웅덩이만).
- 동작: 22번 그대로(5~6장 손목 까딱).

## 충전기(S) 「갈아타기」
- 관절이 하나씩 잘못된 방향으로 꺾이며 모으고, 단계에 따라 마네킹을 어디로 갈아타는지가 바뀐다.
- 0단: 갈아타지 않고 허리를 접은 채 하이힐로 빠르게 디디며 앞 3m를 달려들어 손등으로 가로 쳐냄 → 짧은 돌진 공격.
- 1단: 앞 6m 지점에 빈 여성형 마네킹이 지지직 잡음과 함께 서 있다가, 그녀가 그 마네킹으로 갈아탐(순간 이동). 원래 자리에 남은 빈 마네킹은 금이 가며 터져 둘레 원(반지름 1.5m)에 대리석 조각을 튀김.
- 2단: 가장 가까운 적의 바로 등 뒤에 마네킹이 지지직 나타나고 그쪽으로 갈아탐 → 등 뒤에서 손등으로 쳐내 그 적을 원래 그녀가 있던 쪽으로 날려 보냄.
- 모양 변화: 앞 짧은 돌진 → 먼 앞 순간 이동 + 남은 자리 둘레 원 → 적 등 뒤 순간 이동 + 날려 보냄
- 분류: 0단 이동+공격 / 1단 이동+공격(둘레 원) / 2단 이동+제압(날려 보냄)
- 상대 반응: 0단 밀려나기 / 1단 맞기(상단)·밀려나기 / 2단 날아가 쓰러지기
- 전용 이펙트: GPT `fx_탐미주의_마네킹`(서 있음 2장 + 금 가며 터짐 4장 · 128×256 빈 여성형 마네킹, 얼굴 없음). 코드: 받는 쪽 마네킹에 지지직 잡음 도트 + 「치직」, 갈아타기 직전 화면이 살짝 흔들림(두통).
- 동작: 모으기 23번 그대로. 방출 0단 = 24번 그대로 / 1단 = 23번 끝 장에서 몸 숨김 → 새 자리에서 24번 7~8장(고개 딸깍 되돌림) / 2단 = 23번 끝 장에서 몸 숨김 → 적 등 뒤에서 9번(약1 손등 쳐내기) 4~8장, 좌우를 뒤집어 씀.

## 필살기(F) 「예술은 조각이다」
- 연출 순서:
  1. 컷인(어긋난 웃음, 엄지·검지 네모 액자에 보는 사람을 가둠) + 화면 아래로 숨도 안 쉬고 이어지는 문장 하나가 끊김 없이 흐름.
  2. 두 팔을 지휘자처럼 드는 순간 화면 전체가 0.3초 흑백 → 적 전원이 회색 대리석 결로 덮이며 굳고, 발밑에서 받침대와 빈 작품 명패가 솟아 적들을 들어 올림(「무제 #12」 같은 제목을 코드가 씀).
  3. 손가락 액자를 만들어 화면을 훑으면, 액자 안에 들어온 조각상마다 금이 쩍쩍 감.
  4. 두 손을 턱 아래 모아 황홀하게 고개를 젖히면 조각상들이 한꺼번에 산산조각 남 → 대리석 파편이 화면 가득 튐.
  5. 어긋난 웃음으로 고개를 기울이면 받침대가 무너지고, 껍질이 깨진 적들이 바닥에 쓰러짐.
- 상대 반응: 굳음(연출 안 1.5초) → 금 감 → 깨지며 크게 맞기 → 쓰러지기
- 전용 이펙트(크고 화려하게): GPT `fx_탐미주의_받침대`(솟음 3장 + 무너짐 3장 · 96×64 대리석 받침대와 빈 명패) · `fx_탐미주의_대리석파편`(8장 · 384×256 화면 가득 튀는 회색 대리석 조각과 먼지). 코드: 굳은 적을 회색 대리석 결 도트로 덧칠, 액자 안 조각상에 금 선, 화면 0.3초 흑백, 흔들림 강.
- 동작: 25번 그대로(지휘자 = 굳힘, 액자 손 = 금 감, 황홀 = 깨짐, 고개 기울임 = 끝).

## 앞 설계와 달라진 점
- 고유기술 「3초 침묵 · 경직 · 물감 웅덩이 이동 -30%」(구속·표식·숫자) → 목을 움켜쥐고 꺾이는 맞기 한 번.
- 충전기 「남은 마네킹이 미끼로 공격 받음 · 체력 0이면 마네킹으로 버팀」(강화) → 갈아타는 자리가 단계마다 달라지는 순간 이동 공격, 남은 마네킹은 터지는 공격으로.
- 필살기 「8초 굳음 · 받는 피해 +50% · 25% 이하 즉사」(구속·표식) → 굳힌 뒤 곧바로 깨뜨리는 한 장면. **구속 1개(필살기의 굳힘)**: 「예술의 논리가 물리 법칙이 된다 — 조각상처럼 굳어 버렸다」가 이 인물의 정체 그 자체라 남김. 굳는 시간은 연출 안 1.5초뿐이고, 받침대 위로 들려 굳는 모습·금 가는 모습·깨지는 모습이 모두 눈에 보이며, 끝나면 쓰러짐으로 풀린다. 표식·강화 0개.
