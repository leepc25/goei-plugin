# 3.16_제이 기술 재설계

- 근거: 위키 「부분 발현 때는 몸을 찢고 거대한 그림자 늑대의 앞발이 튀어나와, 단두대처럼 검은 발톱을 내리꽂고 대상을 짓뭉갠 뒤 다시 팔 안으로 들어간다. 그림자가 길게 늘어나 작은 것을 통째로 삼키기도 한다」, 「완전 발현 때는 이빨과 눈알이 여기저기 흩어져 박힌 거대한 늑대가 된다 … 그 덩치가 접히듯 말려 들어가고」, 「늘어진 움직임이 기본값이지만 위협이 감지되는 순간 동작이 기계처럼 정확해진다」.
- 싸우는 방식 한 줄: 「축 늘어져 있다가 단두대처럼 떨어지는 그림자 발톱 궤적과, 바닥을 타고 뻗어 가 무는 그림자로 싸우는 늑대 발현형」

## 고유기술(D) 「앞발」
- 하는 일: 모자챙을 고쳐 잡고 앞팔을 머리 위로 곧게 든다. 팔을 바닥까지 떨어뜨리는 순간 팔 그림자가 찢기듯 늘어나, 떨어지는 팔을 따라 검은 그림자 발톱 궤적 세 줄이 앞 1~3m에 단두대처럼 위에서 아래로 내리꽂힌다(앞발의 모양은 없고 발톱이 지나간 검은 궤적만). 짓뭉갠 뒤 궤적은 연기처럼 팔로 빨려 들어가고, 팔은 축 늘어진다.
- 분류: 공격(위에서 떨어짐)
- 상대 반응: 1타 맞기 상단, 2타(짓뭉갬) 바닥에 튕기며 쓰러지기(바운드 → 19).
- 전용 이펙트: 위에서 아래로 떨어지는 검은 그림자 발톱 궤적 세 줄(128×192 한 장, 가장자리 털이 연기처럼 흩어짐, 형체 없음), 내리꽂힌 자리 바닥 발톱 자국 세 줄. 공용: 충격파.
- 동작: 22번 그대로.

## 충전기(S) 「냄새가 달라요」
- 0단: 손바닥으로 바닥을 쓸어 내면 발밑 그림자가 바닥을 타고 앞으로 2m 뻗어 가 끝에서 작은 이빨로 발목을 문다.
- 1단: 그림자가 화면 절반(5m)까지 길게 바닥을 타고 뻗어 가, 끝에 닿은 적 발밑에서 바닥 그림자가 작은 입처럼 벌어졌다 탁 닫히며 발목을 물어 위로 튕겨 올린다(긴 선 끝의 한 점, 2단 그림자 입을 작게).
- 2단: 느릿느릿 두 걸음 걸어 나간 뒤 멈춰 바닥을 내려다본다 → 발밑 그림자가 둘레 원(반지름 3m)으로 퍼져 바닥 전체가 입처럼 벌어졌다 닫히며 원 안 적을 모두 아래에서 삼켰다가 뱉는다.
- 분류: 공격(0·1단 땅을 타고 감 · 2단 둘레 원)
- 상대 반응: 0단 맞기 하단(18-1) / 1단 띄워지기(18-3) / 2단 원 안 적은 바닥 아래로 꺼졌다가 위로 뱉어져 띄워졌다 쓰러지기.
- 전용 이펙트: 바닥을 타고 뻗는 검은 그림자 띠(0·1단, 길이 둘), 끝에서 벌어졌다 닫히는 작은 그림자 입(1단, 2단 그림을 작게 다시 씀), 발밑 둘레로 퍼져 벌어졌다 닫히는 그림자 입(2단, 위에서 본 원을 옆에서 본 납작한 타원) + 삼킨 뒤 바닥 검은 얼룩.
- 동작: 모으기 23번 그대로(킁킁). 방출 0단 = 15번(그림자 늘이기) 빠르게, 1단 = 15번 그대로, 2단 = 24번 그대로.

## 필살기(F) 「완전 발현」
- 연출 순서:
  1. 컷인(모자챙 아래 노랗게 빛나는 눈, 팔 뒤 그림자에서 비어져 나오는 거대한 앞발) 뒤, 모자챙을 눈 위로 꽉 눌러 내린다.
  2. 네발로 엎드려 등을 둥글게 웅크린다. 엎드린 제이의 발밑 그림자가 화면 바닥 전체로 단숨에 번져, 화면 바닥이 털 가장자리가 연기처럼 일렁이는 검은 그림자 바다가 된다.
  3. 그림자 바다가 왼쪽에서 오른쪽으로 내달리듯 물결치며(지나간 자리에 검은 털 띠), 적마다 발밑에서 그림자 입이 벌어져 차례로 삼켰다 뱉는다. 유령·구조물·연기형 적도 똑같이 물린다.
  4. 엎드린 채 고개를 번쩍 드는 순간 화면 위 끝과 아래 끝에서 검은 그림자 막이 흰 이빨 가장자리를 세우고 화면 가운데로 쾅 닫힌다(화면 전체가 한 번 크게 물리는 장면). 화면이 노랗게 번쩍인다.
  5. 그림자가 종이처럼 접히듯 제이 발밑으로 말려 들어가고, 마른 경비원이 천천히 일어나 모자챙을 고친다.
- 상대 반응: 물릴 때마다 띄워졌다 떨어지기, 마지막 화면 물어뜯기에 화면 안 적 전원 멀리 날아가 쓰러지기.
- 전용 이펙트(크게): 화면 바닥 전체로 번졌다 접혀 말려 드는 그림자 바다(1280×200, 번짐 → 일렁임 루프 → 접힘), 화면 위아래에서 닫히는 흰 이빨 가장자리 그림자 막(1280×360, 형체 없는 어둠), 적마다 그림자 입은 충전 2단 것을 다시 씀, 지나간 자리 검은 털 도트 띠, 닫히는 순간 화면 노란 번쩍(코드). 화면 흔들림 강.
- 동작: 25번 그대로(엎드려 긴장한 웅크림을 유지하는 동안 그림자가 움직임, 몸은 숨기지 않음).

## 앞 설계와 달라진 점
- 「사칭·은신 적 드러내기」 표식 두 곳과 「끝난 뒤 이동 속도 -30%」를 지웠다. 충전은 냄새 맡기 뒤 그림자가 짧게·길게·둘레로 뻗어 무는 세 모양 공격으로 바꿨다. 앞발과 완전 발현은 앞 설계가 이미 눈에 보이는 공격이라 거의 그대로 두었다.
- 구속·표식·강화 0개.
- (등장물 없앰) 고유기술 그림자 늑대 앞발 → 위에서 떨어지는 검은 발톱 궤적 세 줄, 충전 1단 솟는 늑대 아가리 → 그림자 끝에서 벌어졌다 닫히는 작은 그림자 입(2단 그림 재사용), 필살기 거대 검은 늑대 → 화면 바닥 그림자 바다 + 적마다 그림자 입 + 화면 위아래에서 닫히는 이빨 그림자 막.
