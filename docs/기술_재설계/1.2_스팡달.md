# 1.2_스팡달 기술 재설계

- 근거: 위키 「몸에서 검은 바늘 가시를 마음대로 만들어 낸다. 고위급 개체를 꿰뚫는 관통 연사, … 격자 구속」, 「그림자 속으로 녹아들었다가 다른 곳에서 다시 나타난다」, 「표적 뒤의 그림자에서 솟아올라 검은 가시 하나로 뇌간을 꿰뚫는 것」, 정체 논쟁(불빛이 꺼지고 몸이 새까매지며 눈이 여러 개 뜨이고 사방에서 가시가 터져 나옴). 동작표: 주먹 없음, 손끝·갈고리 손, 가라앉았다 솟는 몸짓.
- 싸우는 방식 한 줄: 「그림자로 가라앉아 등 뒤에서 솟으며 검은 가시로 꿰어 올리는 후방 암살형」

## 고유기술(D) 「그림자 이동」
- 하는 일: 고개를 기울여 반쯤 웃고 발밑 검은 웅덩이로 수직으로 가라앉는다(가라앉는 동안 무적) → 앞 6m 안 가장 가까운 적의 **등 뒤** 바닥에 웅덩이가 번진다 → 거기서 솟으며 손끝과 함께 검은 바늘 한 다발이 위로 찔러 올라 적을 띄운다. 적이 없으면 앞 4m로 옮겨 가 솟기만 한다.
- 분류: 이동 + 공격
- 상대 반응: 띄워지기(등 쪽에서 맞아 앞으로 고꾸라지듯 뜸)
- 전용 이펙트: 바닥에 번졌다 줄어드는 검은 그림자 웅덩이(가라앉는 자리·솟는 자리 둘 다), 바닥에서 위로 솟는 검은 바늘 다발. 등 뒤 출현 순간 화면이 아주 짧게 어두워짐(코드).
- 동작: 22번 그대로

## 충전기(S) 「가시 격자」
- 0단: 손끝에서 검은 바늘 세 개를 **앞으로 일직선** 연사한다(앞 7m, 관통). 줄에 선 적을 모두 꿰뚫으며 맞을 때마다 고개가 젖혀진다.
- 1단: 내뻗은 손 앞 바닥에서 가시 줄이 **땅을 타고** 앞으로 달려 나가며(앞 1~6m) 솟았다 꺼지기를 이어 간다. 줄 위 적은 차례로 위로 꿰어 띄워진다.
- 2단: 앞 4m × 깊이 ±1m 사각 범위 바닥에서 가시가 비스듬히 **엇갈려 한꺼번에 솟아 격자**를 이룬다. 범위 안 적은 모두 가시에 떠받쳐 높이 띄워지고, 손목을 비틀어 당기는 순간 격자가 부서지며 떨어져 쓰러진다.
- 분류: 공격(0단 투사체, 1단 땅을 타고 감, 2단 범위 솟음)
- 상대 반응: 0단 맞기 상단 · 작게 밀려나기 / 1단 띄워지기 / 2단 띄워지기 → 쓰러지기
- 전용 이펙트: 검은 바늘 투사체(가늘고 긴 검은 선 3개), 땅을 타고 연달아 솟는 가시 줄, 엇갈려 솟았다 부서지는 가시 격자(384×192 정도). 모으는 동안 손끝 사이 검은 실 같은 가시가 길어짐(코드).
- 동작: 23번(모으기) 그대로. 방출 0단 = 15번 그대로(손끝 세 번 튕기기), 1·2단 = 24번 그대로(쥐며 뻗기 = 솟음, 비틀어 당기기 = 격자 부서짐)

## 필살기(F) 「우습네. 정말.」
- 연출 순서:
  1. 컷인(빛 없는 금색 눈 한쪽, 얼굴 반은 그림자, 가시 손끝을 입가에 「쉿」) → 화면 조명이 한 단계 꺼진다.
  2. 스팡달이 가라앉고, 화면 안 적 각각의 등 뒤에 웅덩이가 하나씩 번진다.
  3. 웅덩이마다 차례로 솟아 오른손·왼손 번갈아 찌르며 적을 하나씩 띄운다(최대 8명).
  4. 화면 가운데에서 솟아 머리 위에서 두 손을 X로 겹쳐 내리긋는다 → 화면을 가르는 검은 X자 두 줄.
  5. X자가 닿는 순간 화면 바닥 전체에서 검은 가시 숲이 사방으로 터져 오르고(정체 논쟁의 「사방에서 가시가 한꺼번에」), 어둠 속에 작은 눈들이 잠깐 떴다 감긴다.
  6. 조명이 돌아오고 손끝을 턴다.
- 상대 반응: 적마다 띄워지기 → (X자) 쓰러지기 → (가시 숲) 다시 띄워졌다 다운. 몸동작 내내 무적.
- 전용 이펙트: 화면을 가르는 검은 X자(384×384 이상, 화면 대각선 길이), 화면 바닥 전체 가시 숲(가로 화면 폭 × 높이 화면 절반), 어둠 속 눈들. 웅덩이·바늘 다발은 고유기술 것 다시 씀.
- 동작: 25번 그대로(가라앉기·솟기 두 번은 적마다 반복 재생)

## 앞 설계와 달라진 점
- 「백어택 2배」 강화와 「격자 구속」(묶어 2~3초 고정)을 지웠다. 격자는 묶는 대신 범위 안 적을 가시로 떠받쳐 띄우는 공격으로 바꿨다. 구속·표식·강화 0개.
- 충전 0·1단이 같은 가시였던 것을 투사체 일직선 → 땅을 타고 가는 줄 → 사각 격자로 모양을 나눴다.
