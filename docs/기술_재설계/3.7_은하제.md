# 3.7_은하제 기술 재설계

- 근거: 위키 장비 「보이지 않는 사슬로 이어져 착용자들을 일정 반경 안에 묶어 두는 수갑」·「괴이 안에서도 통화가 되게 해 주는 휴대폰 보조배터리」, 일화 「벽에 등을 붙이고 앉아 수첩을 펴더니 십오 분 동안 아무 말도 하지 않았다… 수첩을 찢어 이자헌에게 건넸다」, 「신입과 은하제가 수갑으로 손목이 이어진 채 걸어 나왔다」, 「전투: 일반 요원 수준」, 말버릇 「응, 그래. 됐고.」.
- 싸우는 방식 한 줄: 「귀찮다는 듯 수갑을 던져 끌어 엎고, 팔꿈치·무릎 막싸움으로 마무리하는 지친 기자 출신 견제형」

## 고유기술(D) 「수갑」
- 하는 일: 허리 높이에서 손목 스냅으로 은색 수갑을 앞 직선 6m로 귀찮게 던짐. 처음 닿은 적 손목에 철컥 채워지고, 은하제 손까지 반짝이는 점선(보이지 않는 사슬)이 이어짐. 은하제가 손을 두 번 털면 사슬이 홱 당겨져 그 적이 앞으로 고꾸라지며 1.5m 끌려와 엎어짐. 엎어지는 순간 수갑이 풀려 은하제 손으로 돌아옴.
- 분류: 제압(끌어와 넘어뜨림)
- 상대 반응: 맞기 상단(약) → 끌려옴 → 쓰러지기(앞으로)
- 전용 이펙트: `fx_은하제_수갑`(48×32 회전하는 은색 수갑 4장, 손목에 채워지는 1장), 사슬 점선(1.5px 반짝 점 몇 개, 코드) · 공용: 흙먼지
- 동작: 22번 그대로(1~3장 밑던지기, 4~6장 손 털기 = 당김, 7~8장 다시 쥠)
- 구속을 쓴 까닭: 「보이지 않는 사슬 수갑」이 이 인물의 대표 장비이고 일화도 수갑으로 사람을 묶어 끌고 나온 것. 묶인 시간은 끌려와 엎어질 때까지뿐이고 결과는 엎어짐으로 보임.

## 충전기(S) 「지도 없는 층」
- 모으는 동안: 바닥에 털썩 앉아 수첩에 빠르게 적음. 앉아 있어 몸이 낮으므로 머리·가슴 높이 공격과 투사체는 머리 위로 지나감(낮은 공격은 그대로 맞음).
- 0단 「메모」: 일어나며 찢은 한 장을 내밀면 종이가 앞 3m로 휙 날아가 처음 닿은 적 얼굴에 철썩 붙음. 그 적은 두 손으로 얼굴의 종이를 쥐어뜯으며 허우적 뒷걸음질(눈이 가려져 잠깐 기절).
- 1단 「약도」: 찢은 장이 날며 펼쳐져 커지고, 바닥에 깔려 앞으로 5m 미끄러져 나감(바닥을 타는 넓은 종이 띠). 밟힌 적은 종이에 발이 미끄러져 뒤로 넘어짐.
- 2단 「층 지도」: 수첩을 통째로 찢어 앞 하늘로 뿌림 → 앞 4m 지점 지름 4m 원 위로 파란 펜 선이 그어진 종이 수십 장이 폭포처럼 쏟아짐. 종이 모서리가 원 안 적을 여러 번 베고 위로 띄움.
- 분류: 방어(앉아서 높은 공격 흘림) + 공격·제압(0단 얼굴 한 점 / 1단 바닥을 타는 띠 / 2단 위에서 쏟아지는 원)
- 상대 반응: 0단 기절(얼굴 감싸고 뒷걸음) · 1단 쓰러지기(뒤로) · 2단 다단 맞기 → 띄워지기
- 전용 이펙트: 수첩 종이(얼굴에 붙는 한 장 32×32, 바닥에 미끄러지는 큰 장 192×48, 쏟아지는 종이 떼 256×256 6장, 파란 펜 선 무늬) · 공용: 타격_약
- 동작: 모으기 23번 그대로(앉아 수첩에 적기) · 방출 24번 그대로(1~3장 찢어 내밂 = 종이가 나감, 4~8장 일어나 전투 자세)

## 필살기(F) 「통화 연결」
- 연출 순서:
  1. 컷인 뒤 수갑을 어깨 너머로 크게 던짐. 수갑이 적에서 적으로 튕겨 다니며 화면 안 적 최대 6명의 손목에 차례로 철컥 철컥 채워지고, 반짝이는 사슬 한 줄로 전부 엮임.
  2. 은하제는 보조배터리가 매달린 휴대폰을 꺼내 귀에 댐 — 「응, 그래. 됐고.」 엮인 적들은 서로 잡아당겨져 허둥지둥 비틀거림.
  3. 앞머리를 두 번 쓸어 넘기고 휴대폰을 넣으며 턱을 까딱 — 사슬 끝을 쥔 손목을 탁 텀.
  4. 사슬이 채찍처럼 크게 물결치며 줄 앞쪽부터 한 명씩 차례로 바닥에 내리쳐짐 — 도미노처럼 줄줄이 쓰러짐.
  5. 마지막 한 명이 은하제 앞으로 끌려오면 목덜미를 잡아 끌어내리며 무릎으로 찍음. 사슬이 풀리며 화면 위 「…좀 곤란한데.」.
- 상대 반응: 묶여 비틀거림 → 끌려 차례로 내리쳐짐(쓰러지기 연속) → 마지막 1명 끌려옴 → 띄워지기 → 쓰러지기
- 전용 이펙트(크게): 튕겨 다니는 수갑 궤적(은빛 잔상), 화면을 가로지르는 사슬 점선(물결칠 때 굵고 밝게, 화면 폭 전부), 내리쳐질 때마다 바닥 먼지 6번, 휴대폰 화면 불빛(코드) · 공용: 흔들림(필살)·타격_강
- 동작: 15번 원거리 「수갑 어깨 너머 던지기」 그대로 + 25번 그대로(휴대폰·머리 쓸기·턱 까딱) + 22번 4~6장(손 털기 = 사슬 당김) + 12번 강 「잡고 무릎」 그대로
- 구속을 쓴 까닭: 고유기술과 같음(사슬 수갑이 정체성). 묶여 있는 동안 적이 끌려 비틀거리는 것이 보이고, 결과는 줄줄이 쓰러짐으로 끝남.

## 앞 설계와 달라진 점
- 고유기술: 4초 구속(묶여 서 있기만 함) → 채우자마자 당겨 엎어뜨리고 바로 풀림.
- 충전기: 규칙·함정·지도 공개(싸움 밖 정보) → 수첩 종이를 얼굴·바닥·하늘로 날리는 공격, 모으는 동안 낮게 앉아 피함.
- 필살기: 이자헌·박민성 호출과 회복(남의 손) → 은하제 자기 손으로 수갑을 채우고 사슬을 당기는 연출. 구속 2곳(고유기술·필살기, 둘 다 수갑), 표식·강화 0개.
