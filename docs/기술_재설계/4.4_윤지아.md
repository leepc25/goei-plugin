# 4.4_윤지아 기술 재설계

- 근거: 위키 「허리 파우치: 붕대, 사탕, 비상 간식」, 「"오늘 날씨 진짜 이상하죠?"로 시작한 대화가 끝날 즈음이면 칼을 쥐고 있던 손님이 칼을 내려놓고 사탕을 까먹고 있다」, 「몸놀림이 가볍고, 손은 늘 무언가로 바쁘다」, 「원장이 칼이라면 조수는 칼집」, 동작표 「일단 앉으세요」 앉히기.
- 싸우는 방식 한 줄: 「순한 얼굴 그대로 손목을 잡아 비틀어 무기를 놓게 하고, 날아 밀고, 붙잡아 바닥에 내리꽂아 앉히는 작은 간호 보조 제압형」

## 고유기술(D) 「잠깐만요」
- 하는 일: 파우치를 톡 치고 오므린 두 손을 앞으로 내미는 순간, 앞 0.8m 적의 무기 든 손목을 두 손으로 감싸 쥐고 바깥으로 비튼다 → 그 적이 손에 든 것을 떨어뜨리고 손목을 감싸며 휘청 물러난다(「칼을 내려놓고」).
- 분류: 제압(손목 비틀어 무기를 놓치게 함)
- 상대 반응: 맞기 상단 → 작게 밀려나기(무기를 놓침, 잠깐 맨손으로 움찔)
- 전용 이펙트: 없음. 공용: 타격_약(손목 잡는 순간). 코드: 떨어뜨린 무기는 그 적 그림의 무기 장을 지우고 바닥에 작은 회색 점.
- 동작: 22번 그대로(파우치 톡 → 두 손 내밀기 = 손목 잡기).

## 충전기(S) 「오늘 날씨 진짜 이상하죠?」
- 0단: 「비켜 주세요」 — 두 발로 앞으로 낮게 뛰어 두 손바닥을 가슴 높이로 함께 밀어 낸다 → 앞 3m 일직선, 처음 닿은 적이 밀쳐져 뒤로 크게 밀려난다.
- 1단: 런지로 내디디며 두 손을 가슴 앞에 모으고 그대로 높이 뛰어 앞다리를 곧게 뻗어 발바닥으로 찬다 → 앞 5m 지점까지 날아들어 첫 적의 가슴을 차 뒤로 넘어뜨린다(멀리 날아드는 한 점).
- 2단: 「일단 앉으세요」 — 한 보폭 뛰어들어 앞 적의 어깨를 두 손으로 붙잡고 온몸 무게로 끌어내려 허리부터 바닥에 내리꽂는다. 내리꽂힌 충격이 둘레 원(반지름 1.5m)으로 퍼져 옆 적들도 휘청한다.
- 분류: 0단 이동+제압(밀쳐 냄) / 1단 이동+공격(도약 발바닥) / 2단 제압(붙잡아 주저앉힘 + 둘레 원)
- 상대 반응: 0단 크게 밀려나기 / 1단 뒤로 쓰러지기(19) / 2단 붙잡힌 적은 39번처럼 주저앉아 잠깐 못 일어남, 둘레 적은 맞기 하단(18-1).
- 전용 이펙트: 없음. 공용: 타격_약·타격_강(1단 발바닥), 흙먼지(주저앉는 자리 원).
- 동작: 모으기 23번 그대로(붕대 감기). 방출 0단 = 13번(「비켜 주세요」 날아 밀기) 그대로 / 1단 = 24번 1~4장(런지하며 두 손 모음) + 14번(점프 공격 발바닥 뻗기) / 2단 = 12번(「일단 앉으세요」 앉히기) 그대로.

## 필살기(F) 「시술 준비 끝」
- 연출 순서:
  1. 컷인(두 손을 모아 내민 순한 얼굴, 웃는데 대기실 전체를 읽는 눈) 뒤, 파우치를 톡톡 두 번 친다.
  2. 「일단 앉으세요.」 — 화면 앞쪽 적에게 한 보폭 뛰어들어 어깨를 붙잡고 온몸 무게로 끌어내려 허리부터 바닥에 내리꽂는다. 내리꽂힌 충격이 둘레 1.5m 원으로 퍼진다.
  3. 곧장 화면 가운데 깊이의 적에게 뛰어들어 똑같이 내리꽂는다 — 이번 충격 원은 둘레 3m.
  4. 화면 뒤쪽 깊이의 적에게 세 번째로 뛰어들어 내리꽂는 순간, 충격이 화면 바닥 절반을 덮는 살구색 먼지 고리로 퍼져 화면 안 남은 적 전원이 다리를 맞아 꺾이며 주저앉는다.
  5. 두 발을 모아 깊이 꾸벅 인사하고 머리끈을 고쳐 묶는다.
- 상대 반응: 붙잡힌 셋은 주저앉아 잠깐 못 일어남(39번) → 커지는 충격 원마다 둘레 적 휘청 → 셋째 원에 화면 안 적 전원 주저앉아 쓰러지기.
- 전용 이펙트(크게): 없음 — 앉힐 때마다 커지는 살구색 먼지 충격 고리 세 번(공용: 충격파를 살구색 흙먼지로, 1.5m → 3m → 화면 바닥 절반). 공용: 흙먼지, 흔들림(필살).
- 동작: 25번 1~2장(파우치 톡톡) → 12번(「일단 앉으세요」 앉히기) 세 번(뛰어드는 거리는 코드) → 25번 끝 장(두 발 모아 꾸벅 → 전투 자세).

## 앞 설계와 달라진 점
- 「무기 내려놓게 함·적대 해제」 구속 세 곳, 「숨긴 무기 표시」 표식, 「회복」, 「재사용 -30%」 강화를 전부 지웠다. 사탕은 튕겨 이마를 맞히는 투사체로, 잡담 진정은 손뼉 손목 잡기·사탕 깔기·붙잡아 앉히기로, 시술 준비는 사탕을 연달아 튕겨 주저앉히는 장면으로 바꿨다.
- 구속·표식·강화 0개(앉히기는 한 번 주저앉히고 일어나는 넘어뜨림이라 구속이 아님).
- (겹침 정리) 충전 0단의 「손뼉 소리 충격으로 밀쳐 냄」은 브라우니 고유기술(손뼉 공기 충격)과, 1단의 「바닥을 굴러가는 붕대에 발이 걸림」은 땅을 타고 가 넘어뜨리는 묶음·고영은(압박붕대)과, 필살기의 「하늘에서 쏟아지는 사탕 비」는 강이학 필살기(동전 비)와 같은 그림이라 바꿨다. 사탕을 바닥에 깔아 미끄러뜨리는 것은 앞 필살기 끝 장면을 충전 1단으로 옮긴 것이다.
- (맥락 정리) 포장 사탕을 튕겨 이마 맞히기·바닥에 사탕을 깔아 미끄러뜨리기·사탕 연사를 모두 걷어 냈다(생활 소품을 무기로 쓰지 않음, 원작 전투 능력 없음). 고유기술은 앞 0단의 손목 잡아 비틀기를 옮겨 오고, 충전은 날아 밀기 → 도약 발바닥 → 「일단 앉으세요」, 필살기는 세 번 뛰어들어 앉힐 때마다 엉덩방아 충격 고리가 커져 마지막에 적 전원을 주저앉히는 장면. 물건 그림 1개(사탕)와 전용 사탕 반짝 줄이 빠짐.
- (톤 정리) 충전 2단·필살기의 「털썩 엉덩방아」와 1단의 「손뼉 짝」·「벌러덩」을 뺐다. 붙잡은 적을 온몸 무게로 끌어내려 허리부터 바닥에 내리꽂는 충격으로 적었다(12·14·24번 그대로, 충격 고리 수 그대로).
