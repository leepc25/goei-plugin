# 1.5_고그니쟈 기술 재설계

- 근거: 위키 「겉보기엔 완벽한 비전투원이다 … 대신 연구실 자체가 방어 설비와 비상 장치로 꽉 차 있어서」, 「시설 전체가 이 사람 몸의 일부처럼 움직인다」, 「지하 깊은 곳까지 … "꽤 깊지!"」, 「"오오, 그 녀석은 성질이 좀 있지!" 하고 반려동물 얘기하듯」. 동작표: 두 팔을 활짝 벌린 「환영」 자세, 작은 검은 리모컨, 지휘하는 손짓.
- 싸우는 방식 한 줄: 「리모컨과 지휘 손짓으로 바닥·벽의 격리 설비를 터뜨려 적을 치는 시설 조종형」

## 고유기술(D) 「비상 장치 가동」
- 하는 일: 고글을 밀어 올리고 리모컨을 머리 높이로 쳐들어 엄지로 꾹 누른다 → 앞 2~3m 바닥 해치가 덜컹 열리며 노란 줄무늬 강철 기계 팔(집게 달린 피스톤)이 위로 튀어나와 적을 쳐올린다 → 기계 팔은 바로 바닥으로 들어간다. 고그니쟈는 허리를 젖혀 웃는다.
- 분류: 공격
- 상대 반응: 띄워지기
- 전용 이펙트: 바닥 해치가 열렸다 닫힘 + 아래에서 솟는 노란·검정 줄무늬 기계 팔(128×192 정도), 해치 둘레 노란 경고등 한 번 깜빡.
- 동작: 22번 그대로

## 충전기(S) 「꽤 깊지!」
- 0단: 지휘하던 손을 내리자 발 앞 바닥 판 하나가 **튀어 오르는 발판**(앞 1~2m)으로 퉁 하고 들려 위에 선 적을 짧게 튕겨 낸다.
- 1단: 화면 뒤쪽 벽(깊이 위 끝)에서 노란 줄무늬 강철 격리 셔터 한 장이 **깊이 방향으로 수평으로** 쾅 튀어나와 앞 3m 지점을 화면 앞쪽 끝까지 가로지른다(두께 1m, 길이는 깊이 전체). 셔터 줄에 선 적은 모두 화면 앞쪽(깊이 아래)으로 밀쳐져 넘어지고, 셔터는 다시 벽으로 들어간다.
- 2단: 고그니쟈 앞 넓은 **원**(앞 3m 중심, 반지름 2.5m) 바닥이 통째로 열려 깊은 구멍이 드러나고, 노란 경고등 속에서 지하 격리 개체의 거대한 검은 팔이 솟아 원 안을 한 바퀴 휘저어 적을 모두 날려 띄운 뒤 구멍으로 돌아가고 바닥이 닫힌다.
- 분류: 공격(0단 발판, 1단 벽에서 깊이 방향으로 튀어나오는 셔터, 2단 범위 + 큰 몸체)
- 상대 반응: 0단 작게 띄워지기 / 1단 옆(화면 앞쪽)으로 밀쳐져 쓰러지기 / 2단 크게 띄워지기 → 쓰러지기
- 전용 이펙트: 튀어 오르는 바닥 판, 벽에서 깊이 방향으로 튀어나왔다 들어가는 격리 셔터(192×96, 코드가 깊이 길이만큼 늘림), 열리는 원형 바닥 + 깊은 구멍 속 경고등 + 휘젓는 거대한 검은 팔(384×256 정도). 모으는 동안 바닥 틈에서 노란 불빛이 새어 나옴(코드, 단계마다 넓어짐).
- 동작: 23번(모으기 = 지휘) · 24번(방출 = 두 손 번쩍 → 바닥 누르기) 그대로

## 필살기(F) 「오오, 그 녀석은 성질이 좀 있지!」
- 연출 순서:
  1. 컷인 → 머리 위로 손가락을 튕기면 화면 전체가 노란 경고등으로 깜빡이며 사이렌.
  2. 화면 뒤쪽 끝 벽이 커다란 격리문처럼 위아래로 갈라져 열린다.
  3. 고그니쟈가 한 걸음 비켜서며 허리 숙여 길을 내준다 → 문 안에서 화면 높이만 한 격리 개체(검은 몸, 노란 격리 띠 조각이 매달린)가 뛰쳐나와 화면 끝에서 끝까지 짓밟으며 달려 지나간다.
  4. 지나간 자리의 적은 모두 높이 튕겨 오르고, 바닥에 발자국 금이 남는다.
  5. 개체가 반대편으로 사라지고 문이 쾅 닫힌다. 고그니쟈는 두 손을 비비며 웃다가 두 팔을 활짝 벌린다.
- 상대 반응: 크게 띄워지기 → 바운드 → 다운. 몸동작 내내 무적.
- 전용 이펙트: 화면 뒤 벽이 갈라지는 격리문(화면 폭 절반), 화면을 가로지르는 거대한 개체의 달리기(높이 화면의 2/3, 길게 늘어진 그림자 실루엣이어도 됨), 바닥 발자국 금, 화면 노란 경고등 깜빡임(코드). 공용: 흔들림(필살).
- 동작: 25번 그대로

## 앞 설계와 달라진 점
- 고유기술의 격리관 가두기(구속)와 충전의 소환 지원을 지웠다. 장치는 가두지 않고 직접 적을 쳐올리거나 넘어뜨린다. 구속·표식·강화 0개.
- 충전을 발판(점) → 벽 셔터(깊이 방향 줄) → 원형 바닥 개방 + 개체 팔로 모양을 나눴다.
- (겹침 정리) 충전 1단의 「앞으로 줄지어 뒤집히는 바닥 판에 넘어짐」은 땅을 타고 가는 선이 넘어뜨리는 묶음(이연화·은하제·백석주 등)과 같아, 벽에서 깊이 방향으로 튀어나오는 격리 셔터로 바꿨다(시설이 몸처럼 움직임).
