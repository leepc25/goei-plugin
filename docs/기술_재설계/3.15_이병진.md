# 3.15_이병진 기술 재설계

- 근거: 위키 「전투력: 없음」, 「들어가 보지도 않은 사람이 빨간 펜을 든다」, 매뉴얼에 「승인 도장」을 찍는 사람, 「진짜로 무너지면 … 바닥을 기어가 옆 사람의 바짓가랑이에 매달린다」, 특기 「한문 해독」(바지를 붙잡고 떨던 과장님이 갑자기 안경을 고쳐 쓰고 줄줄 읽는 순간).
- 싸우는 방식 한 줄: 「눈 감고 허우적대며 빨간 펜으로 긋고 도장으로 찍어 대다가, 무너지면 다리에 매달려 넘어뜨리는 사무직 패닉형」

## 고유기술(D) 「빨간 펜」
- 하는 일: 앞으로 디디며 빨간 사인펜을 눈높이로 뻗었다가 무릎 높이까지 쭉 내리긋는다. 펜 끝이 지나간 자리에 빨간 사선 획이 남고, 그 획에 닿은 앞 1.5m 안 적이 위에서 아래로 베인다.
- 분류: 공격(앞 세로 베기)
- 상대 반응: 맞기 상단(18) → 마지막에 무릎이 꺾이는 맞기 하단(18-1).
- 전용 이펙트: 위에서 아래로 그어지는 굵은 빨간 사선 획(펜 길이의 5배, 잠깐 남았다 번짐), 획 끝 잉크 방울.
- 동작: 22번 그대로.

## 충전기(S) 「급행 처리」
- 0단: 손바닥에 쥔 승인 도장으로 눈 감고 앞을 쾅 민다 → 바로 앞 1m에 빨간 원형 도장 자국이 찍히며 상대가 밀려난다.
- 1단: 눈 감은 채 양손으로 번갈아 두 번 쾅쾅 밀고 들어간다 → 두 걸음 앞으로 가며 도장 자국이 앞으로 두 개 이어 찍히고, 두 번째에 상대가 멀리 밀려난다(앞으로 길어지는 2연타).
- 2단: 「이, 이사님!」 비명과 함께 낮게 몸을 날려 상대 다리에 매달린다 → 앞 4m까지 미끄러져 가 부딪힌 적의 바짓가랑이를 붙잡아 앞으로 넘어뜨리고, 엎어진 등에 도장을 쾅 찍는다.
- 분류: 0·1단 공격(밀쳐 냄) / 2단 제압(넘어뜨림)
- 상대 반응: 0단 밀려나기 / 1단 1타 맞기 상단, 2타 크게 밀려나기(18-2) / 2단 앞으로 쓰러지기 + 등에 찍히는 도장에 한 번 더 움찔.
- 전용 이펙트: 빨간 원형 승인 도장 자국(바닥·공중에 찍힘, 글씨칸은 코드가 「승인」), 2단 미끄러지는 먼지 줄기 + 땀방울 도트. 공용: 충격파(작게).
- 동작: 모으기 23번 그대로(굽실 손 비빔 = 도장에 인주 묻히기). 방출 0단 = 9번(눈 감고 손바닥 밀치기), 1단 = 9번 + 10번 이어 붙임, 2단 = 13번(바짓가랑이 매달리기) 그대로. 24번(실패 줄)은 쓰지 않는다.

## 필살기(F) 「처음으로 쓸모 있어진 순간」
- 연출 순서:
  1. 웅크려 떨던 자세(41번)에서 컷인(안경알이 하얗게 번뜩, 이번만은 입을 꾹 다문 얼굴, 검지 끝 붉은 획 조각).
  2. 안경을 밀어 올리고 검지를 머리 높이로 뻗는다. 화면 위쪽 허공에 낡은 제문의 한자 획 조각들(뜻 없는 획)이 붉게 줄지어 떠오른다.
  3. 그가 글줄을 한 줄 짚어 읽을 때마다 그 줄의 획들이 칼날처럼 떨어져 화면 안 적들을 위에서 내리꽂는다(두 줄, 두 번).
  4. 마지막 줄을 다 읽는 순간 남은 획들이 화면 가운데로 모여 거대한 붉은 네모 도장(낙관) 모양이 되고, 화면 가운데 바닥에 쾅 찍힌다. 찍힌 충격이 화면 바닥 전체로 퍼진다.
  5. 그는 숨을 몰아쉬고 다시 엉거주춤 자세로 돌아간다(평소의 겁먹은 얼굴로).
- 상대 반응: 떨어지는 획마다 맞기 상단, 마지막 낙관 충격에 화면 안 적 전원 띄워졌다 쓰러지기.
- 전용 이펙트(크게): 화면 폭 전체에 떠오르는 붉은 한자 획 조각 두 줄(뜻 없는 획), 내리꽂히는 획 칼날(세로 줄기), 화면 높이 절반 크기의 붉은 네모 낙관이 내려와 찍히는 장면 + 바닥 전체 붉은 충격 띠. 화면 흔들림 강.
- 동작: 41번(웅크려 떨기) 1~4장 + 25번 그대로 이어 붙임.

## 앞 설계와 달라진 점
- 「기술 1개 봉인」 구속, 「필살 게이지 +20·+10」, 「백일몽 적 공격 안 함」, 「의식형 적 정지·결계 해제」 구속을 전부 지웠다. 빨간 펜은 내리긋는 베기로, 급행 도장은 눈 감고 찍어 밀치는 연타와 매달려 넘어뜨리기로, 한문 해독은 읽는 대로 떨어지는 획 칼날과 거대한 낙관으로 바꿨다.
- 구속·표식·강화 0개.
