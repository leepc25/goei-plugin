# 4.5_마덕희 기술 재설계

- 근거: 중림 지하상가 장물 매입점 「헐값매입」 주인, 감정사·장물아비(위키). 가게 한가운데 육중한 나무 감정대와 잠긴 유리판, 판매자는 쟁반에 물건을 올림. 흥정 끝 신호 「80. 얘기 끝났어요. 쟁반 열렸습니다.」 원작 전투 능력 없음(기술안) → 가게 물건(놋쇠 쟁반·감정대·유리판·감정 저울)을 그대로 무기로 쓴다. 동작표: 싸움은 한 손으로, 턱 들고 내려다봄, 무기 없음.
- 싸우는 방식 한 줄: 「가게 집기를 던지고 떨어뜨리고 깨뜨려 거리를 두고 값을 후려치는 집기 투척형」

## 고유기술(D) 「쟁반 열렸습니다」
- 하는 일: 허리를 감았다가 허리 높이에서 사이드암으로 놋쇠 감정 쟁반을 수평으로 날린다. 쟁반은 바닥 위 무릎~허리 높이로 빙글빙글 돌며 앞 직선 7m를 날아가 첫 적의 정강이를 치고, 그 자리 바닥에 떨어져 「쨍」 하고 한 번 더 튀며 둘레 작은 원(반지름 0.8m)을 친다.
- 분류: 공격(투사체 + 떨어진 자리 작은 원)
- 상대 반응: 첫 타 맞기(하단) → 바닥 튐 작은 밀려나기
- 전용 이펙트: GPT `fx_마덕희_쟁반`(4장 · 회전하는 납작한 놋쇠 쟁반, 옆에서 본 타원) · 공용: 작은 충격파(바닥 튐)
- 동작: 15번(사이드암 던지기) 그대로, 빠르게(재생 속도 올림). 15번 5장 손을 놓는 장에서 쟁반이 나감. 일반 원거리(15) 투사체는 반지로 두고 쟁반은 이 기술 전용.

## 충전기(S) 「80. 얘기 끝났어요」
- 0단: 손바닥으로 쟁반을 앞으로 쭉 밀어 낸다 → 앞 1.5m 짧은 직선, 가까운 적 하나를 밀쳐 냄(「여기 올려놓으세요」).
- 1단: 손을 머리 위로 들었다 앞으로 내리며 미는 순간, 옆에 있던 육중한 나무 감정대가 바닥을 쿵쿵 미끄러져 앞 3m까지 밀려 나가 그 앞 적을 들이받는다 → 들이받힌 적은 뒤로 넘어짐. 감정대는 멈춘 자리에 1.5초 서서 앞에서 날아오는 투사체를 막고(맞으면 나무 조각 튐) 부서져 사라짐.
- 2단: 1단처럼 감정대를 밀어 보낸 뒤, 그 위 잠긴 유리판을 팔꿈치로 내리찍어 깬다 → 유리 파편이 감정대 앞쪽 부채꼴(4m · 60도)로 쏟아져 나감. 감정대는 남지 않음.
- 모양 변화: 짧은 앞 직선 → 앞으로 밀려 나가는 한 덩어리 + 잠깐 벽 → 앞 넓은 부채꼴
- 분류: 0단 제압(밀쳐 냄) / 1단 공격(밀려 나가는 감정대)+방어 / 2단 공격(부채꼴)
- 상대 반응: 0단 크게 밀려나기 / 1단 쓰러지기 / 2단 맞기(상단) 여러 번 → 마지막 밀려나기
- 전용 이펙트: GPT `fx_마덕희_감정대`(미끄러짐 3장 + 부서짐 3장 · 유리판 덮인 나무 감정대) · `fx_마덕희_유리파편`(6장 · 부채꼴로 쏟아지는 유리 조각과 반짝임) · 공용: 흙먼지(감정대 미끄러짐)
- 동작: 모으기 23번 그대로. 방출 0단 = 24번 4~6장(앞손바닥 허리 높이로 밀기)만 / 1단 = 24번 그대로(머리 위로 든 손 = 감정대를 잡음, 앞으로 내리는 손 = 밀어 보냄) / 2단 = 24번 1~3장 + 12번(강, 팔꿈치 내려찍기) 4~8장.

## 필살기(F) 「헐값매입」
- 연출 순서:
  1. 컷인(보조개 웃음, 돋보기안경). 배경이 어두워지고 헐값매입 가게의 유리 진열장 실루엣이 뒤에 깔림.
  2. 안경을 쓰고 화면을 훑는 동안, 화면 위에서 거대한 놋쇠 감정 저울(양팔 저울)이 내려옴. 한쪽 접시가 화면 앞쪽 바닥에 넓게 내려앉아 화면 앞쪽 절반이 통째로 접시 위가 됨(적들은 끌려오지 않고 선 자리 그대로 접시에 실림).
  3. 검지로 높이·가운데·낮게 짚을 때마다 접시 위 적 머리 위에 버건디 가격표가 철커덕 박히며 한 대씩 맞음(짚는 손짓 = 타격 3회, 가격표는 그림만).
  4. 「이 가격」 손을 들어 올리면 다른 쪽 빈 접시에 반지 하나가 툭 떨어짐 → 반지 쪽이 쾅 내려가고 적 쪽 접시가 하늘로 튕겨 올라 적 전원이 높이 띄워짐.
  5. 팔짱을 끼는 순간 적들이 바닥으로 떨어져 쓰러지고 저울이 금빛 가루로 흩어짐.
- 상대 반응: 접시에 실림 → 맞기 3회 → 높이 띄워지기 → 떨어져 쓰러지기
- 전용 이펙트(크고 화려하게): GPT `fx_마덕희_저울`(10장 · 화면 높이의 3분의 2를 차지하는 놋쇠 양팔 저울, 접시가 내려와 쓸고 한쪽이 튕겨 오름) · `fx_마덕희_가격표`(4장 · 48×32 버건디 가격표 흔들림, 글씨 없음, 코드가 「₩」만 씀) · `fx_마덕희_반지`(2장 · 작은 금반지 떨어짐 반짝). 코드: 접시 튕길 때 흔들림 강, 금빛 가루.
- 동작: 25번 그대로(안경 = 2단계, 세 번 짚기 = 3단계, 손 들기 = 4단계, 팔짱 = 5단계).

## 앞 설계와 달라진 점
- 고유기술 「방어력 -30%」(표식·숫자 버프) → 놋쇠 쟁반을 실제로 던져 정강이를 침.
- 충전기 「정보원(체력·약점 표시)」(정보 기술, 싸움 밖) → 감정대를 밀어 보내고 유리판을 깨는 공격으로.
- 필살기 「최대 체력 -25%·받는 피해 +20%」(표식·숫자) → 감정 저울 접시에 적을 실어 하늘로 튕겨 올리는 장면으로. 구속·표식·강화 0개.
- (겹침 정리) 충전 1·2단의 「허공에서 떨어지는 감정대」는 위에서 떨어지는 묶음과 겹쳐 손으로 밀어 미끄러뜨리는 것으로, 필살기의 「접시가 쓸어 담아 적을 끌어모음」은 끌어모으기 묶음(로제몬·신유리)과 겹쳐 선 자리 그대로 접시에 실리는 것으로 바꿨다.
