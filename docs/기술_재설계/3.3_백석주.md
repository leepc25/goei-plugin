# 3.3_백석주 기술 재설계

- 근거: 위키 「감탄하면 대놓고 박수를 친다」, 「마음에 드는 후배는 어깨를 두드리는데, 이게 사실상 "이 애는 내 거"라는 도장」, 「웃으면서 체크리스트부터 꺼낸다. 진입 전 점검표, 위계, 규율」·「조장이 줄을 세우면 조원들은 군말 없이 선다」, 「치유 반지: 살을 되감는 개인 등급 재생 장비」·「누군가의 실수로 자기 조원이 다치면 눈에 핏발이 선다」, 「개인 전투력도 당연히 정예급」.
- 싸우는 방식 한 줄: 「웃으며 다가가 어깨를 두드리고 두 손바닥으로 귀를 치며, 손날·팔뚝 쓸기·V자 돌진으로 끝내는 상사 근접형」

## 고유기술(D) 「어깨 도장」
- 하는 일: 성큼 한 걸음 나가 앞 적의 어깨를 손바닥으로 두 번 톡톡 두드림(1.2m 안 1명, 두 번 다 작은 타격, 어깨에 초록 손바닥 자국 — 「이 애는 내 거」). 이어 웃는 얼굴 그대로 두 손바닥을 양옆에서 모아 그 적의 두 귀를 동시에 세게 후려침 → 귀와 관자놀이를 한꺼번에 맞은 적이 고개가 흔들리며 비틀거리다 그 자리에 잠깐 굳음(머리를 맞아서).
- 분류: 공격(두드림) → 제압(두 손바닥으로 귀를 쳐 휘청)
- 상대 반응: 맞기 상단 두 번(작게) → 기절(짧게, 고개가 흔들리며 비틀거림)
- 전용 이펙트: 어깨에 찍히는 초록 손바닥 자국(작은 도트 2장) · 공용: 타격_약(두드림)·타격_강(두 귀 치기)
- 동작: 22번 그대로(2~4장 두 번 얹기 = 두드림, 6장 두 손 모으기 = 두 귀 치기)

## 충전기(S) 「진입 전 점검」
- 0단 「체크」: 앞 편 손을 머리 옆으로 들었다 런지하며 손날로 쇄골 높이를 앞 아래로 내려친다 → 바로 앞 1.5m 한 점, 맞은 적이 어깨가 꺾이며 무릎이 내려앉는다.
- 1단 「줄 서」: 달리던 몸을 낮춰 앞팔뚝을 가슴 높이로 크게 바깥으로 쓸어 치우며 앞으로 3m 미끄러진다 → 팔뚝이 화면 깊이 방향(위아래 4m 폭)을 쓸어, 걸린 적들이 모두 가슴을 맞아 뒤로 밀려나며 한 줄로 늘어선다(여러 명).
- 2단 「들어가.」: 턱을 까딱하는 순간 백석주가 몸째 V자로 꺾여 앞으로 3m 돌진한다 — 아래로 비스듬히 파고들며 손날로 무릎을 치고, 위로 길게 치솟으며 손날로 턱을 올려친다. 꺾이는 궤적을 따라 초록 손날 잔광이 V자로 남고, 걸린 적은 휘청였다가 치솟는 손날에 높이 띄워진다.
- 분류: 공격(0단 점 / 1단 깊이 방향 넓은 쓸기 / 2단 V자 돌진)
- 상대 반응: 0단 맞기 하단(무릎 내려앉음) · 1단 밀려나기 · 2단 맞기 하단 → 크게 띄워지기
- 전용 이펙트: 없음. 공용: 베기(초록, 0단 내려치기·2단 V자 두 획을 이어 그림), 타격_약(1단 팔뚝). 2단 돌진 잔상(코드, 초록)
- 동작: 모으기 23번 그대로(왼손바닥을 판처럼 들고 검지로 짚어 내려감) · 방출 0단 = 9번(약1 앞손 손날 내려치기) / 1단 = 13번(돌진 「사과 반려」 팔뚝 쓸기) / 2단 = 24번 6장(턱 까딱) + 9번 빠르게 + 12번 1~4장(솟아 올라감), V자 이동은 코드

## 필살기(F) 「A조에 온 걸 환영해」
- 연출 순서:
  1. 컷인 뒤 백석주가 반지 낀 왼손을 머리 위로 높이 들면 손끝 위로 초록 고리(반지 모양)가 커지며 떠오름.
  2. 손을 천천히 쓸어내리면 그 고리가 앞 화면 바닥에 지름 6m로 내려앉고, 시곗바늘 반대로 도는 초록 빛줄기가 감기며 고리 안 적들이 지나온 길을 거꾸로 되감듯 뒤로 미끄러져 고리 뒤쪽 테두리를 따라 **한 줄로 늘어섬**(「조장이 줄을 세우면 조원들은 군말 없이 선다」 — 가운데로 모으지 않음).
  3. 고개를 홱 앞으로 — 가면 눈구멍 너머 붉은 눈이 번쩍, 화면 가장자리가 0.3초 붉게 물듦. 입은 그대로 웃음.
  4. 늘어선 줄을 따라 성큼성큼 걸으며 한 명씩 손날로 두 번씩 쳐 내려감(줄 전체 2타), 줄 끝 1명을 붙잡아 무릎으로 높이 띄움.
  5. 마지막에 가슴 앞에서 「짝」 — 화면 절반 너비의 박수 충격 고리가 터져 줄 선 적 전원이 화면 끝 벽까지 날아가 박힘.
- 상대 반응: 뒤로 되감겨 줄 섬 → 맞기 상단 2번 → 띄워지기 → 날아가 벽에 박힘 → 쓰러지기
- 전용 이펙트(크게): 바닥 초록 고리 `fx_백석주_되감기`(지름 6m, 거꾸로 감기는 빛줄기 8장, 화면 앞쪽 바닥 절반을 덮음), 적이 되감겨 갈 때 남는 초록 잔상, 화면 붉은 테두리(코드), 마지막 박수 충격 고리(화면 높이 절반·폭 절반, 흰 공기 고리 5겹) · 공용: 타격_강·흔들림(필살)
- 동작: 25번 그대로(1~3장 손 듦, 4~5장 쓸어내림 = 고리 내려앉음, 6장 노려봄, 7~10장 손날 두 번 + 무릎) + 15번 원거리 「박수 장풍」 3~6장(마지막 짝)

## 앞 설계와 달라진 점
- 고유기술: 아군 「내 사람」 표식 + 공격 +25% 강화 → 적 어깨를 두드리고 손뼉으로 머리를 쳐 휘청이게 하는 근접기. 구속·표식·강화 0개.
- 충전기: 받는 피해 -15%/-25% 버프 → 체크 획·깊이 방향 줄 획·V자 돌진 획으로 모양이 바뀌는 공격.
- 필살기: 아군 회복·부활 → 반지의 「되감기」를 적을 거꾸로 되감아 한 줄로 세우는 바닥 고리로 바꾸고, 손날·무릎·박수로 끝냄.
- (겹침 정리) 고유기술의 「어깨를 눌러 무릎 꿇림 + 박수 공기 고리로 밀쳐 냄」은 신유리 충전 0단(어깨 눌러 무릎 꿇림)·브라우니 고유기술(손뼉 공기 충격)과 겹쳐, 어깨 두드림 + 손뼉으로 머리를 치는 기절로 바꿨다(큰 박수 충격은 필살기 마무리에만 남김). 충전 1단 「바닥을 타는 점선에 발목이 걸림」은 땅을 타고 가 넘어뜨리는 묶음과, 2단 「위에서 내리찍히는 큰 체크」는 위에서 떨어지는 묶음과 겹쳐 깊이 방향 줄 획·V자 돌진 획으로 바꿨다. 필살기의 「고리 한가운데로 끌어모음」은 끌어모으기 묶음(로제몬·신유리)과 겹쳐 뒤로 되감아 한 줄로 세우는 것으로 바꿨다.
- (맥락 정리) 충전의 허공에 그어지는 초록 체크 표시 획·깊이 방향 줄 획(「점검표」를 그대로 그림으로 옮긴 말장난)을 걷어 냈다. 0단은 손날 내려치기, 1단은 13번 「사과 반려」 팔뚝 쓸기로 줄 세우기, 2단은 V자로 꺾이는 손날 돌진(공용 베기 초록). 치유 반지 되감기(위키 장비)와 박수(위키)는 필살기 그대로. 전용 체크 획 2개·줄 획 1개가 빠짐.
- (톤 정리) 고유기술의 「양 볼을 손뼉 사이에 끼워 짝 · 머리 위 별」을 두 손바닥으로 두 귀를 동시에 후려쳐 비틀거리게 하는 것으로 바꿨다(22번 6장 그대로). 필살기 마지막 손바닥 충격 고리는 실제로 벽까지 날려 박는 타격이라 그대로.
