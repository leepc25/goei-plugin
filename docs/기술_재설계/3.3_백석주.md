# 3.3_백석주 기술 재설계

- 근거: 위키 「감탄하면 대놓고 박수를 친다」, 「마음에 드는 후배는 어깨를 두드리는데, 이게 사실상 "이 애는 내 거"라는 도장」, 「웃으면서 체크리스트부터 꺼낸다. 진입 전 점검표, 위계, 규율」·「조장이 줄을 세우면 조원들은 군말 없이 선다」, 「치유 반지: 살을 되감는 개인 등급 재생 장비」·「누군가의 실수로 자기 조원이 다치면 눈에 핏발이 선다」, 「개인 전투력도 당연히 정예급」.
- 싸우는 방식 한 줄: 「웃으며 다가가 어깨를 눌러 앉히고 박수 한 번으로 날려 보내는, 손바닥과 손날만 쓰는 상사 근접형」

## 고유기술(D) 「어깨 도장」
- 하는 일: 성큼 한 걸음 나가 앞 적의 어깨를 손바닥으로 두 번 꾹꾹 누름(1.2m 안 1명, 두 번 다 작은 타격). 누를 때마다 그 적 무릎이 꺾여 내려앉음. 이어 가슴 앞에서 손뼉을 「짝」 치면 손바닥 사이에서 작은 공기 고리가 터져 바로 앞 적을 2m 뒤로 밀쳐 냄.
- 분류: 제압(눌러 앉힘) → 공격(박수 밀쳐 냄)
- 상대 반응: 맞기 하단 두 번(무릎 꺾임) → 크게 밀려나기
- 전용 이펙트: 어깨에 찍히는 초록 손바닥 자국(작은 도트 2장), 박수 공기 고리(흰 고리 3겹, 원거리 「박수 장풍」 것을 작게) · 공용: 타격_약
- 동작: 22번 그대로(2~4장 두 번 얹기 = 누르기, 6장 손뼉 = 고리)

## 충전기(S) 「진입 전 점검」
- 0단 「체크」: 검지 한 획에 바로 앞 1.5m 허공에 초록 체크 표시(V자) 획이 그어지며 그 자리 적을 아래에서 위로 베어 올림. 짧고 좁은 한 점.
- 1단 「줄 서」: 체크 획 대신 발끝에서 초록 점선 한 줄이 바닥을 타고 앞으로 6m 쭉 그어짐. 점선이 지나간 자리의 적은 발목이 걸려 앞으로 고꾸라짐(관통, 여러 명).
- 2단 「들어가.」: 턱을 까딱하는 순간 앞 3~7m 바닥에 가로 4m짜리 점검표 칸(초록 네모 줄 세 칸)이 깔리고, 그 위로 커다란 체크 표시가 위에서 쾅 내리찍힘. 칸 안 적 전원이 바닥에 깔려 쓰러지고, 체크의 긴 획 방향(앞)으로 튕겨 굴러감.
- 분류: 공격(0단 점 / 1단 땅을 타는 선 / 2단 위에서 떨어지는 넓은 판)
- 상대 반응: 0단 띄워지기(작게) · 1단 쓰러지기(앞으로) · 2단 쓰러지기 → 앞으로 굴러감
- 전용 이펙트: 초록 체크 획(작은 것 64×64 / 큰 것 256×192, 그어지는 4장), 바닥 점선(이음 조각), 점검표 칸 바닥 무늬 · 공용: 충격파(2단 착지)
- 동작: 모으기 23번 그대로(왼손바닥을 판처럼 들고 검지로 짚어 내려감) · 방출 24번 그대로(1~4장 검지 획 = 0·1단 판정, 6장 턱 까딱 = 2단 내리찍기)

## 필살기(F) 「A조에 온 걸 환영해」
- 연출 순서:
  1. 컷인 뒤 백석주가 반지 낀 왼손을 머리 위로 높이 들면 손끝 위로 초록 고리(반지 모양)가 커지며 떠오름.
  2. 손을 천천히 쓸어내리면 그 고리가 앞 화면 바닥에 지름 6m로 내려앉고, 시곗바늘 반대로 도는 초록 빛줄기가 감기며 고리 안팎 적들이 지나온 길을 거꾸로 되감듯 미끄러져 고리 한가운데로 모여듦.
  3. 고개를 홱 앞으로 — 가면 눈구멍 너머 붉은 눈이 번쩍, 화면 가장자리가 0.3초 붉게 물듦. 입은 그대로 웃음.
  4. 성큼 나가 모인 무리에 손날을 두 번(무리 전체 2타), 앞 1명을 붙잡아 무릎으로 높이 띄움.
  5. 마지막에 가슴 앞에서 「짝」 — 화면 절반 너비의 박수 충격 고리가 터져 무리 전체가 화면 끝 벽까지 날아가 박힘.
- 상대 반응: 끌려옴(되감기) → 맞기 상단 2번 → 띄워지기 → 날아가 벽에 박힘 → 쓰러지기
- 전용 이펙트(크게): 바닥 초록 고리 `fx_백석주_되감기`(지름 6m, 거꾸로 감기는 빛줄기 8장, 화면 앞쪽 바닥 절반을 덮음), 적이 끌려올 때 뒤로 남는 초록 잔상, 화면 붉은 테두리(코드), 마지막 박수 충격 고리(화면 높이 절반·폭 절반, 흰 공기 고리 5겹) · 공용: 타격_강·흔들림(필살)
- 동작: 25번 그대로(1~3장 손 듦, 4~5장 쓸어내림 = 고리 내려앉음, 6장 노려봄, 7~10장 손날 두 번 + 무릎) + 15번 원거리 「박수 장풍」 3~6장(마지막 짝)

## 앞 설계와 달라진 점
- 고유기술: 아군 「내 사람」 표식 + 공격 +25% 강화 → 적 어깨를 눌러 앉히고 박수로 날리는 근접기. 구속·표식·강화 0개.
- 충전기: 받는 피해 -15%/-25% 버프 → 체크 획·바닥 점선·위에서 떨어지는 점검표로 모양이 바뀌는 공격.
- 필살기: 아군 회복·부활 → 반지의 「되감기」를 적을 거꾸로 끌어오는 바닥 고리로 바꾸고, 손날·무릎·박수로 끝냄.
