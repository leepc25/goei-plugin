# 3.4_진나솔 기술 재설계

> **⚠ Claude 반성 · 2026-10-31 (사용자 지시로 문서마다 남김)**
> 2026-10-31 Claude는 다음 잘못을 저질렀다. 이 문서를 읽는 모든 Claude는 같은 짓을 하지 않는다.
> 1. **사용자 결정을 무시했다.** 콘쥬스는 사용자가 10-26에 20세로 정했고 인계서에도 적혀 있었는데, 옛 Claude 문장(teenage high school girl)을 근거로 화장실·샤워 그림을 거부하고, 사용자가 직접 뽑은 화장실 줄까지 팩에서 뺐다. 옷도 제복인데 교복이라고 단정했다.
> 2. **사용자 말에 토를 달고 같은 주장을 되풀이했다.** 사용자가 여러 번 지적했는데도 근거를 다시 확인하지 않아 몇 시간을 허비하게 했다.
> 3. **허락 없이 문서를 지웠다.** 「지침을 지우라」는 말만 듣고 목록을 보여 주지도 않고 96개를 지웠다가 되살렸다(결과물 삭제 금지 규칙 위반).
> 4. **문장을 덧대기만 하며 PixelLab을 낭비했다.** 이성해 점프 공격 5번 연속 실패, 이어폰 음악 120줄을 못 쓰게 만듦.
> 5. **답을 미루고 일을 멈춰 두었다.** 백그라운드로 돌릴 일을 돌리지 않고 대화만 했다.
>
> 지킬 것: 사용자 결정·위키가 근거다. 옛 Claude 자료는 근거가 아니다. 사용자 말에 토 달지 않는다. 무엇이든 지우기 전에 목록을 보여 주고 허락받는다. 실패하면 덧대지 말고 다시 쓰거나 바꾼다.


- 근거: 위키 「떼어 낼 수 있는 네일아트 손톱에서 사실상 끝없이 이어지는 반투명 고장력 실… 쏘고, 걸고, 매달려 날고, 자르고, 해체하는 데까지 다 쓴다」, 「외알 안경: 손짓 한 번에 걸쳐 쓰고」, 「전투는 효율적이고, 과시가 없고, 빨리 끝난다」, 「"그럴 시간에 퇴근해"」, 만성 편두통.
- 싸우는 방식 한 줄: 「손가락만 까딱해 손톱을 쏘고 실을 당겨 끌어오고 가르는, 거의 움직이지 않는 실 중거리형」

## 고유기술(D) 「당기기」
- 하는 일: 앞손을 뻗어 손톱 하나를 앞 직선 7m로 쏨(보라 손톱 조각 + 뒤로 이어지는 흰 실). 처음 닿은 적에 박히면, 주먹을 쥐며 허리로 당기는 순간 실이 팽팽해져 그 적이 진나솔 앞 1m까지 질질 끌려오고 발이 걸려 앞으로 엎어짐. 손톱은 실을 타고 되돌아와 손가락에 붙음.
- 분류: 제압(끌어옴)
- 상대 반응: 맞기 상단(약) → 끌려옴 → 쓰러지기(앞으로)
- 전용 이펙트: `fx_진나솔_실`(1px 반투명 흰 실, 끝에 보라 손톱 조각 · 늘림용 조각), 당길 때 실을 따라 달리는 반짝임(코드) · 공용: 흙먼지(끌린 자국)
- 동작: 22번 그대로(1~2장 뻗어 쏨, 4~5장 주먹 쥐고 당김, 7~8장 손톱 들여다봄)

## 충전기(S) 「외알 안경」
- 0단 「한 발」: 안경 너머로 겨눈 그대로 검지 끝에서 손톱 한 개가 곧게 날아감(직선 9m, 가늘고 빠름, 1명).
- 1단 「가로 실」: 검지 끝에서 실 한 가닥이 가슴 높이로 앞 9m까지 수평으로 쭉 뻗었다가 팽팽해짐. 실이 지나간 높이의 적 전원이 가로로 베여 뒤로 젖혀짐(관통하는 가로 칼날 선).
- 2단 「해체」: 겨눈 지점(앞 5m)을 가운데로 실 다섯 가닥이 별 모양으로 교차해 걸리고(지름 3m 원), 조여 들며 교차점으로 오그라듦. 원 안 적 전원이 여러 갈래로 베이며 위로 띄워짐.
- 분류: 공격(0단 점 / 1단 긴 가로선 / 2단 별 모양 원)
- 상대 반응: 0단 맞기 상단 · 1단 크게 밀려나기(상체 젖힘) · 2단 띄워지기 → 쓰러지기
- 전용 이펙트: 겨눌 때 눈앞 보라 원형 렌즈 테두리(코드), 1단 수평 실(`fx_진나솔_실` 늘림), 2단 별 모양 실 다섯 가닥이 조이는 그림 `fx_진나솔_별실`(192×192, 4장) · 공용: 타격_약(베임 점)
- 동작: 모으기 23번 그대로(관자놀이를 누르고 두 손가락을 눈가에 = 안경으로 겨눔) · 방출 24번 그대로(검지로 앞을 가리킴 = 실이 나감)

## 필살기(F) 「퇴근」
- 연출 순서:
  1. 컷인 뒤 두 손을 펴 열 손가락을 동시에 튕김 → 손톱 10개가 화면 곳곳(벽·바닥·천장·적)에 박힘.
  2. 한 팔을 머리 위로 뻗어 실에 매달린 채 화면을 한쪽 끝에서 반대쪽 끝까지 그네 타듯 가로지름(몸이 실제로 화면을 건너감). 지나간 자리마다 흰 실이 그물처럼 깔림.
  3. 반대편에 웅크려 착지, 검지 하나만 몸 쪽으로 까딱.
  4. 화면 전체 실 그물이 한꺼번에 조이며 하얗게 빛나고, 그물 안 적 전원이 여러 번 베이며 공중으로 들렸다 떨어짐.
  5. 일어나 왼손목을 들어 시계를 보고, 손가락을 접어 실을 거둬들인다.
- 상대 반응: 다단 베임(맞기 상단 연속) → 띄워지기 → 쓰러지기
- 전용 이펙트(크게): `fx_진나솔_실그물`(화면 전체 1280×360, 흰 실 20여 줄이 펼쳐졌다 조이는 6장), 그네 궤적 잔상(보라), 조일 때 화면 흰 번쩍 · 공용: 흔들림(필살)
- 동작: 25번 그대로(1~2장 열 손가락, 3~6장 그네, 7~8장 착지 까딱, 9~10장 시계)

## 앞 설계와 달라진 점
- 고유기술: 앵커 3개 유지·다시 눌러 당기기의 복잡한 규칙 → 쏘고 당겨 끌어와 엎어뜨리는 한 동작.
- 충전기: 은신 적 드러냄 표식 + 급소 실 자동 걸림 → 안경으로 겨눈 뒤 점·가로선·별 모양으로 모양이 바뀌는 실 공격.
- 필살기: 「30초 안에 쓰면 피해 +50%」 강화를 지움. 구속·표식·강화 0개(끌어옴은 제압으로 바로 끝남).
- (톤 정리) 필살기 끝 화면 도트 시계 「18:00」(퇴근 개그 글씨)을 뺐다. 시계를 보는 몸짓(25번 9~10장)만 둔다.
