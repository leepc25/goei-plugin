# 1.11_로제몬 기술 재설계

- 근거: 위키 「머리에서 굵은 보라색 실이 뻗어 나가 시선을 따라 움직이고, 닿은 것과 연결된다」, 「여러 인형을 무서운 속도로 동시에 움직이는데, 마치 앙상블 배우들을 지휘하는 것 같다」, 「전투력은 이름 붙일 만한 게 없다. 대신 다른 것들이 싸우게 만들어서 이긴다. 그리고 모두가 어디로 뛰어야 하는지 극적으로 손가락질한다」, 불완전 최면 「눈이 보랏빛으로 번쩍였고 … "돌아가."」.
- 싸우는 방식 한 줄: 「본인은 손가락만 까딱이고, 머리에서 뻗은 보라 실로 적의 몸을 끌어오고 들었다 내리꽂는 인형사 중거리형」

## 고유기술(D) 「돌아가.」
- 하는 일: 두 손가락으로 자기 눈을 가리켰다가 앞으로 겨누는 순간, 손끝에서 동전 하나가 튕겨 나가 앞 직선 5m를 날아감. 맞은 적은 이마에 동전을 맞아 고개가 젖혀지고, 동시에 로제몬 눈이 보랏빛으로 번쩍하며 그 적의 몸이 홱 뒤로 돌아 비틀비틀 2m 밀려 걸어감(등을 보임). 동전은 바닥에 떨어져 앞면/뒷면으로 굴러 멈춤(그림만, 효과 차이 없음).
- 분류: 제압(밀쳐 냄 + 뒤돌기)
- 상대 반응: 맞기 상단(고개 젖힘) → 뒤로 돌아 밀려나기 2m, 0.6초 동안 등을 보인 채 걸음
- 전용 이펙트: `fx_로제몬_동전`(돌며 날아가는 동전 6장, 바닥에 떨어져 앞뒷면 2장), 눈빛 번쩍(코드, 보라 점 2개), 공용: 타격_약
- 동작: 22번 그대로(4장 「두 손가락으로 겨눔」에서 동전이 나감, 8장 턱 듦)

## 충전기(S) 「인형술」
- 0단: 정수리에서 보라 실 한 가닥이 앞 직선 6m로 뻗어 처음 닿은 적 1명에 붙고, 곧장 로제몬 앞 1m까지 질질 끌려옴(바닥에 끌린 자국).
- 1단: 실 한 가닥이 붙은 적을 머리 위 높이까지 공중으로 쭉 들어 올렸다가 발 앞 바닥에 거꾸로 내리꽂음(바운드).
- 2단: 실 세 가닥이 앞 부채꼴(60도, 6m)로 갈라져 적 최대 3명에 붙고, 세 명이 한가운데 한 점으로 끌려와 서로 머리를 부딪침 → 다 같이 쓰러짐.
- 분류: 제압(끌어옴 / 띄웠다 내리꽂기 / 모아 부딪치기)
- 상대 반응: 0단 끌려옴(경직 유지) · 1단 띄워지기 → 바운드 → 다운 · 2단 끌려옴 → 머리 박음(별) → 쓰러지기
- 전용 이펙트: `fx_로제몬_실`(이음 조각 4장 반복, 코드가 정수리에서 대상까지 이어 그림 · 2단은 세 갈래), 공용: 흙먼지(끌린 자국)·타격_강(박치기 별)
- 동작: 모으기 23번(벽에 기대 손가락 까딱) · 0단 = 12번 강 「…당겨.」 그대로 · 1단 = 24번 1~4장(두 손 홱 위로 = 들어 올림) + 11번 약3 4~8장(바닥까지 내리꽂기) · 2단 = 24번 그대로 + 12번 5~8장(뒤로 젖혀 끌어 모음)
- 구속을 쓴 까닭: 실로 남의 몸을 붙잡아 움직이는 것이 이 인물의 능력 그 자체(위키 「닿은 것과 연결된다」). 붙어 있는 시간은 끌려오고 내리꽂히는 동안뿐이고, 결과는 끌려옴·내리꽂힘·부딪힘으로 보임.

## 필살기(F) 「앙상블」
- 연출 순서:
  1. 컷인 뒤 로제몬이 발끝으로 솟으며 검지를 하늘로 쳐들면, 정수리에서 굵은 보라 실 여섯 가닥이 화면 곳곳의 적 최대 6명에게 동시에 뻗어 꽂힘.
  2. 지휘하듯 두 손을 머리 위로 올리면 적 전원이 꼭두각시처럼 팔다리가 늘어진 채 공중으로 들림.
  3. 두 손을 무릎 아래로 내리면 전원이 바닥에 쾅 내리꽂힘(바닥에 원형 충격파 6개). 2~3을 한 번 더 크게.
  4. 앞발을 쿵 구르며 두 손을 가슴 앞에 모아 쥐면 여섯 명이 화면 한가운데로 끌려와 한 덩어리로 박치기 → 커다란 별과 함께 사방으로 튕겨 다운.
  5. 로제몬이 머리를 쓸어 넘기며 턱(「봤어?」).
- 상대 반응: 끌려 떠오름 → 내리꽂힘(바운드) ×2 → 가운데로 끌려와 부딪힘 → 사방으로 날아가 다운
- 전용 이펙트: `fx_로제몬_실` 여섯 갈래(화면 전체에 펼쳐진 보라 실 그물이 크게 보이게, 실이 당겨질 때 굵어짐), 가운데 박치기 별 `fx_로제몬_박치기별`(256×256, 보라 별과 실 끊김 조각) · 공용: 충격파 6개
- 동작: 25번 그대로(1장 검지 하늘, 2~7장 지휘 두 번, 8~9장 모아 쥠 = 박치기, 10~12장 머리 넘김)
- 구속을 쓴 까닭: 고유기술과 같음(실 조종이 정체성). 연출 중에만 붙고 결과는 내리꽂힘·박치기로 보임.

## 앞 설계와 달라진 점
- 고유기술: 50% 확률 「최면 성공」 표식 + 4초 구속(눈에 안 보이고 운에 맡김) → 동전 투사체 + 눈빛으로 적이 뒤돌아 밀려나는, 확률 없는 제압.
- 충전기: 「우리 편 인형 6초/10초」 구속(적 AI가 바뀌는 것뿐이라 화면에서 안 보임) → 단계마다 모양이 다른 끌어오기·내리꽂기·세 명 박치기.
- 필살기: 박치기만 있던 것을 들었다 내리꽂기 두 번 + 박치기로 25번 지휘 몸짓에 맞춤.
- 구속 2(충전기·필살기의 실), 표식 0, 강화 0.
