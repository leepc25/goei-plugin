**다시는 물건을 빼지 마라 (사용자 2026-10-30).** 배경 요청문이 2,000자를 넘어도 물건 줄을 빼지 않는다.
- 줄일 것은 군말: 재질·색·같은 뜻·벽/팔레트 칸·자리 묶음 말·크기 숫자 중복.
- 근거가 약해 보여도 내가 판단해 빼지 않는다. 빼야 할 것 같으면 사용자에게 묻는다.
- 왜: 대기실 v6에서 2,000자에 맞춘다며 TV·목발·우산꽂이·구급함·발판·선풍기를 빼서 휑해졌고, v7에서 또 발판을 뺐다.
- 도구가 막는다: `tools/pixellab/bg_check.py` 0번 규칙 — 앞 판 명세(같은 이름 _v<n-1>)에 있던 물건이 없으면 FAIL, `removed_items` 칸이 있으면 FAIL, brief.items의 omit 이유가 글자 수면 FAIL.
- 지침: docs/배경_생성_공용지침.md 2-0.
