2026-10-21 사용자: 쟈알디를 중간 확인 없이 계획안 41행 전부 한 번에 만들게 했더니(126회, 뼈대 도구, 재킷 고친 A 기준) "차라리 한방에 하는게 훨씬 낫네".
**Why:** 단계마다 멈추고 확인받는 방식이 며칠씩 걸리고 크레딧을 낭비했다고 사용자가 크게 화냄.
**How to apply:** 기준 그림과 방식이 정해진 뒤의 캐릭터 제작은 전체 동작을 한 번에 완성해 시연판·사용 횟수·결함 목록과 함께 가져온다. 새 캐릭터 시작 시 이 방식을 기본으로 제안. 결과물 release/demo/jyaldi-full.html. See [[game-design-feedback]], [[pixellab-usage-tips]].
