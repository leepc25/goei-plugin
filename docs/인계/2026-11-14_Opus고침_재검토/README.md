## 3. 11-14 사용자 결정 (검토할 때 근거)

- **블라렛 혈통(위키)**: 공개된 사실이 아니다. 교황청과 극소수만 안다. 고위 흡혈귀는 느낄 수 있을 뿐이다. 그래서 위키 문서(블라렛·세크리엠·흡혈귀·기독교 상점)에 반흡혈귀·혼혈이라는 말을 쓰지 않는다. 인물 기록(src/data/world/agents.json)은 그대로 둔다.
- **「실제 한국 물가처럼」**: 일반 상점에만 적용한다. 포인트몰·우주몰에서는 뺐다.
- **연어 마켓 말투**: DC 말투 문장을 뺐다. 그 자리에 여러 사람이 쓰는 중고 거래 앱 말투 문장(SALMON_TONE, src/core/guides.ts)을 넣었다. 「all listed in the same plain resale tone」도 뺐다.
- **📜Faction**: 맨 앞 「Factions: 1 …」 범례 줄을 뺐다.
- **직접 버린 물건**: 메인 요청 This turn에 「threw X away — the protagonist discarded it on purpose and no longer has it」을 넣는다. 「버렸다」는 뜻이 분명해야 한다.
- **소지품 칸**
  - 장착 칸은 손 2칸과 장비 6칸이다. 손 칸에는 아무 물건이나 들 수 있다(Item.held). 장비 칸에는 입거나 차는 물건만 들어간다.
  - 물건 개념(사용자): 장비냐 → 손이냐 → 사용 기능이 있냐. 장비가 아니면 → 사용 가능하냐 → 소모성이냐.
  - 단추 말: 손 칸은 「들기」/「넣기」, 장비 칸은 「장착」/「해제」다(카드로 고름). 「내려놓기」와 「장착 풀기」는 사용자가 싫다고 했다.
  - 무기·도구처럼 원래 손에 드는 물건은 「사용」을 누르면 빈 손 칸에 먼저 들고 쓴다. 두 손이 차 있으면 알린다.
  - 장비 칸 물건은 장착해야 「사용」이 켜진다. 해제하면 올려 둔 사용도 빠진다.
  - 끄는 순간 놓을 수 있는 칸은 밝게, 못 놓는 칸은 흐리게 한다.
  - 판정 표 기본값은 비운다. 모델이 지침대로 정한다(손 = 손에 들고 쓰거나 싸우는 것, 장비 = 몸에 입거나 차는 것만, 없음 = 주머니·가방에만). 설정 설명의 예시 「예: 망치 → 손」은 남긴다(사용자: 예시는 있어야 한다).
  - 메인 요청 표시는 [in hand]/[worn]이다. 갱신기 items_now는 손 칸을 hand로 보낸다.
- **교훈(사용자가 크게 화냄)**
  - 확인을 기다리는 안이 있으면, 릴리스 전에 넣을지 묻는다. 말없이 빼고 릴리스하지 않는다(v0.21.13).
  - 시키지 않은 말(들기·내려놓기)을 마음대로 만들지 않는다.
