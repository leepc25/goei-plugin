2026-11-01 사용자: 「과녁까지 만들 필요 없고 적당히 끊어」→ Claude가 칸막이 부스(가림 따기 힘듦), 뒷벽 창(북쪽 사격 모션 없음), 탄막이 벽+코드 과녁(「과녁 필요 없다고 몇 번을 말하냐」「쏘는 것만 보이고 뒤는 생략」)을 차례로 제안해 격노 「한 번 말하면 알아들어」.
- 정답: 요원은 동·서로만 쏜다. 사격장은 쏘는 자리(바닥 사격선)만 그리고, 사로는 그림 오른쪽 끝 밖으로 넘어가 안 보임. 과녁·탄막이 없음. 잇기 1번(요청문 specs/hq_b1_training_ext1R_prompt.txt).
**How to apply:** 사용자 말을 한 번에 글자 그대로 받는다. 「필요 없다」는 코드로도 넣지 않는다는 뜻. 설계 제안 전 모션 방향(옆만)·가림 따기를 먼저 점검. See [[goei-hq-interior-rooms-1101]], [[goei-hq-layout-rules]].
