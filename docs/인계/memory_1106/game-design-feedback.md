- **최우선 = 액션성**: 손맛(타격 반응, 예비동작·마무리 과장, 연타 리듬, 조작 반응)부터 본다. 동작은 크게·확실하게(미스타라·던파, 기본기획서 1.1.1).
- **상식선 설계**: 장르 관례가 기본값(근접 = 주먹, 공중 = 점프 킥). 원작에 없는 동작은 Claude 창작이라 밝히고 확인받기.
- **모든 자세는 실제 무술·동작 근거**(docs/캐릭터제작서/동작근거_쟈알디_무술.md). 타격은 디딤발 → 허리 → 어깨 → 팔. 연타는 손 번갈이, 뒤로 갈수록 묵직하게, 능력은 고유기 전용.
- **추측 수치·눈대중을 사실처럼 말하지 않는다.** 먼저 잰다.
- **다음 할 일은 Claude가 제안.** 동작 목록도 Claude가 기획서 전체와 대조해 빠짐없이 짠다(docs/캐릭터제작서/공통_생활동작목록.md).
- **범위를 늘릴 땐 비용부터**: 개수·회수·8명 환산을 말하고 승인 후 생성. 옷 갈래 나누기 금지.
- **한 번에 끝까지**: 기준이 정해진 뒤 양산은 중간 확인 없이 묶어서, 결함 목록과 함께.
- **검수·수정은 Claude가 전부**(GPT 결과 포함). 결함을 사용자가 찾게 하지 않는다.
- 그림 규칙(캐릭터만, 손 좌표, 팔꿈치 버그)은 [[character-art-rules]].
