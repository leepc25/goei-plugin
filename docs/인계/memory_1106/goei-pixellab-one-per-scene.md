2026-11-01 07:47 사용자: 「왜 똑같은 걸 3장 뽑아?」「돈이 남아 돌아?」. Claude가 카메라 흔들림 대비로 1층·B2를 3장씩(150회) + 1층 옆벽 현관 3장(75회) 보냄.
**Why:** 생성 1장 = 25회. 「동시에 보내라」는 서로 다른 작업을 병렬로 보내라는 뜻이지 같은 것을 여러 장 뽑으라는 뜻이 아니다.
**How to apply:** 장면당 1장. 병렬은 서로 다른 장면·구간에만. 결과가 틀리면 요청문을 고쳐 다시 1장. 1층 현관은 **왼쪽 옆벽**에 둔다(뒷벽에 두면 안 됨, 사용자 07:46). See [[pixellab-concurrency]], [[goei-bg-attach-immediately]].

**2026-11-01 08:36 새 스레드**: 「저부분 다시 고쳐」「장난하냐」를 생성 지시로 읽고 키오스크 다시 그리기 1장을 보냈다가 「왜 시키지도 않았는데 막 보내지?」. 고치라는 말·화난 말은 생성 지시가 아니다. 생성은 사용자가 「뽑아」라고 할 때만, 그 전엔 무엇을 몇 장 보낼지 말하고 기다린다.
