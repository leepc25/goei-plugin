사용자 14:33 「참고 이미지 넣지 말라고 몇번을 말하냐」. 남자 탈의실 p2에 여자 탈의실 그림을 참고로 넣어 똑같이 나옴(14:31 크게 혼남).
**Why:** 참고 그림이 방 구성까지 베껴 결과를 망침. 사용자가 여러 번 금지함.
**How to apply:** gen_bg.py 둘째 인자는 항상 ''. 넣으면 도구가 중단(14:33 장치). 다른 생성 도구도 참고 그림 없이. See [[goei-restroom-stalls-1101]].

**2026-11-01 16:43 정정:** 이 금지는 「다른 방 그림」을 참고로 넣는 일에 대한 것. 3층 원본·훈련장이 쓴 화풍 그림 `specs/style_eileen_256.png`(에일린 스프라이트, color_palette False)은 사용자가 휴게실에서 「화풍 넣고 다시 뽑아」로 직접 지시해 다시 씀. 화풍 없이 뽑은 p5·p6는 흐리고 상자 방으로 나와 「엉망진창」. gen_bg.py 둘째 인자 = 그 파일, 여섯째 1.0, STYLE_NO_COLOR=1.
