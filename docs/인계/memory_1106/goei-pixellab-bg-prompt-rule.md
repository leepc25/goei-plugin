2026-11-01 사용자: 「픽셀랩은 뭔가를 강제하려고 하면 1층처럼 허접하게 뽑아낸다. 특히 꽉 채우라는 지침이 잘못되면 허접하게 나온다. 도대체 왜 지시를 따르지 않지?」
Claude가 1층·2층·B1·B2 첫 판 요청문에 층마다 물건 10개 가까이 나열하고 벽·천장·바닥 재질을 못 박음 → 1층 결과 엘리베이터가 가운데서 밀려나고 바닥이 비고 허접.
**Why:** 인계서(docs/인계/중림필드_인수인계_2026-10-31_결정.md)에 「요청문은 자유롭게 최소 지시만, 꽉 채우게, bg_prompt 도구·고정 틀 안 씀」이 있었는데 사용자가 「층마다 특색」을 말하자 물건 목록으로 답했다.
**How to apply:** 새 배경 요청문은 `game-src/art/pixellab-hq-20261031/specs/hq_f3_v3_p1f_prompt.txt`를 글자 그대로 복사하고 (1) 장소 이름 한 구절 (2) 문 한 가지 (3) 분위기 한 구절만 바꾼다. 「Everything else is up to you」와 채우기 문장은 그대로 둔다. 물건 목록·재질·조명 색을 적지 않는다. 층 특색은 문 종류와 분위기 한 구절로만 준다. See [[goei-merge-1101]].
