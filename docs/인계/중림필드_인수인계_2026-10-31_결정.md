# 중림 필드 결정 (2026-10-31 사용자)
- 지하 → 지상으로 올라올 때 캐릭터가 작아지는 차이(지상 dotK 0.85, 지하 1.429): **일단 그대로 두고 나중에 생각.**
- 버스 정류장 = **모든 목적지를 잇는 허브.** 아직 연결 단계가 아니라 지금은 안내 「버스 정류장」만, 행선지는 임시(종로 street) 그대로. 연결 단계에서 목적지 고르기로 만든다.

# 관리국 본부 최소화 (2026-10-31 사용자)
- 기존 본부 구조는 전부 날린다(사용자 「불필요한것을 제외하고 최소화」「기존건 전부 날리고」).
- 층과 방(서 → 동, 층마다 복도 한 장, 이어 그리기 없음):
  - 1F 로비: 유리 현관(→종로) · 안내 데스크 · 엘리베이터
  - 2F: 진압팀 사무실 · 화장실(남) · 엘리베이터
  - 3F: 종합대응팀 사무실 · 화장실(여) · 휴게실 · 엘리베이터
  - B1: 훈련장 · 샤워실(남) · 샤워실(여) · 엘리베이터
  - B2: 격리팀 사무실 겸 실험실 겸 의무실 · 격리시설 · 엘리베이터
- 계단 없음. 엘리베이터만, 모든 층 같은 자리(복도 오른쪽 끝 뒷벽 정면). 옆벽에 박지 않는다(중림 ①처럼 막다른 구석이 그려짐).
- 기능 이동: 정비·보급 → 잼트리와의 대화(사용자). 출동 → 잼트리 자리(B3 승합차 없앰). 커피(탕비실) → 휴게실. 감정·연구·의무 → 격리팀 사무실. 이빨 요정 → 격리시설. 훈련 기록 → 훈련장.
- 면담: 구조 콘텐츠가 사실상 없어 방을 만들지 않는다. 구조·면담 코드는 남기고 자리만 안 보이게(나중에 휴게실 등에 다시 붙일 수 있음).
- 없앰: 3층 탕비실 방, 교육장, 회의실, 심문실, 창고·서고, 지하 주차장(B3), 계단, 면담실.
