2026-10-21 사용자 크게 화냄("왜 자꾸 샤워 부스 그리는", "욕조는 씨발 뭔", "총체적 난국", "방향을 달리 생각해봐").
- 프롬프트에 샤워·욕조·사다리·문·손전등 같은 장면·물건 이름을 쓰면 생성기가 그것까지 그림. 몸 자세와 움직임만 설명.
- 클립엔 캐릭터만. 가구·배경·빛·물줄기·불꽃 등 효과는 게임이 코드로 그림.
- 손에 드는 작은 물건은 사용자 결정에 따라 그림에 둠(손전등: 그림에, 불빛만 코드).
- 방향 전환: 활동마다 고유 클립을 만들지 않고 몇 개의 재사용 기본 클립 + 배경 오브젝트 + 엔진 효과로 조합(예: 목욕 = 앉기 + 욕실 배경 + 물 레이어). 새 목록은 쟈알디 결함 목록 정리 스레드가 작성.
- 관절: rig.clip()의 anatomic()이 팔꿈치·무릎 역방향 자동 보정, scripts/audit_joints.py로 검사.
