2026-11-01 09:36~09:37 통합창 뱃지: Claude가 능력 목록·그림 배정 없이 「시험 한 장 뽑을까요」를 반복 → 사용자 격노(「밑그림도 안 그려놓고 뽑기부터」).
사용자가 정한 순서: ① 퍽(능력) 목록 전부 끌고 와 정리 ② 이미지마다 무엇을 그릴지 겹치지 않게 정리 ③ 설명 문구 + 위트 있는 한 줄 정리 ④ 그다음 작업(생성).
**Why:** 무엇을 뽑을지 정하지 않은 생성 제안은 돈 낭비이자 일 순서가 거꾸로다.
**How to apply:** PixelLab 생성 얘기는 대상 목록·장마다 그림 내용·화면 문구가 모두 문서로 나와 사용자가 본 뒤에만 꺼낸다. 「시험」도 생성이다. See [[goei-window-decisions-1101b]], [[goei-pixellab-one-per-scene]].

**10:32 추가:** 메달 뱃지 1판(25회)을 「silver medals」+ 컬러 요원(검은 정장·흰 셔츠)으로 보내 남색 판 컬러 그림이 나옴 → 사용자 「단색 은메달이라고 했지」 격노. 사용자 뜻 = 메달 전체 은색 한 가지, 요원·동작은 은색 양각. 요청문에 사용자가 정한 핵심 단어(단색·은메달)를 맨 앞·그대로 넣고, 그와 부딪히는 색 지시(정장 색 등)를 넣지 않는다.

**10:41 추가:** 뱃지 2~5판(100회) 실패 — 2,000자 제한(422)에 맞추려 잘 나온 1판 요청문 머리말을 고쳐 짧게 하자 그림체가 바뀜(흰 평면 바탕, 영어 라벨, 색 섞임). 잘 나온 요청문의 머리말은 글자 그대로 두고 칸 설명만 줄인다. 크기도 승인된 판(512x256)을 바꾸지 않는다(512x64는 납작해짐).
