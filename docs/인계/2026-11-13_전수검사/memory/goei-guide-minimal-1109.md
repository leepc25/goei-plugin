11-09 USER (shop owner talk variety discussion): 「저렇게 기계적으로 정해 놓기보다는 응대 지침을 풍부하게 하는 선으로 하고 모델에게 맡겨야」「굳이 정하지 않아도 당연한 지침들이 있는데」「모델은 바보가 아니잖아」.
- Do NOT bolt code dice / owner cards onto the common shop: preset lore owners (중림 지하상가 문혜란·고연지·신유리 etc.) would be overwritten. Owners can be 사람·괴이·기계·ARS — never apply human-only frames.
- 11-09 16:00 USER: 「플러그인으로 방향 설정까지는 괜찮은데 지침을 덕지덕지 붙여서는 안돼」「너무 강제하면 모델 지능이 저하돼」. Common shop guide left unchanged.
- Guides: write only what the model would NOT do by itself (known bad habits: repeating lines/jokes, ending every reply with a question, generic lines). Skip obvious behaviour (react to scene, follow owner lore, shop-specific trade style).
**How to apply:** before proposing any guide text or mechanic, cut every rule a capable model already follows. Related: [[goei-cos-mall-decisions-1109]].
