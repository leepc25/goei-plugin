- 2026-10-21 사용자: 임무 상세 창 = 상황판 CCTV 화면 그대로(가로 600, 비율 534/440). 효과: 찢김·SIGNAL LOST 좋음, 붉은 숨은 늘 켜면 과함(가끔만), 시계 오류 → 화면 글자 전부 깨짐, 그림자는 뒤에서 걷는 사람 말고 렌즈 바로 앞을 큰 형체가 휙(0.22초).
- **빈도는 사람이 실제로 보는 시간 기준.** 사용자 화남: "1분 반에 한 번이면 누가 1분 동안 보고 있냐", "30초 25초 제정신이야?". 지금: 화면이 새로 뜰 때마다 1.5초 안에 하나 반드시, 보는 동안 평균 3~4초마다 하나. 효과 시연 영상에서 일부러 연달아 터뜨린 건 미리 말할 것.
- **Why:** 수십 초 단위 확률이면 아무도 못 봄. 체감 기준으로 설계해야 함.
- **How to apply:** UI 연출 빈도·시간은 사용자가 그 화면에 머무는 시간(수 초)으로 먼저 잡는다. 영상 요청엔 고친 뒤 결과물만 짧게 (하루종일 찍지 말 것).
- 등급(괴이 태그의 S~D 글자)은 위협도가 아님. 효과 세기에 씀. 사용자가 빼라 하면 뺄 것.
- 2026-10-21 사용자: 신호 끊김 뒤 "그냥 쓱 켜진다" → 돌아오는 연출(fx-back, 1.3초, 브랜치 lq1jt8 fea645a, 미릴리즈): 브라운관 한 줄 켜짐·음화·세로 흘림·한 번 꺼짐, 형체 연출 5종 무작위 (stand 핏빛/flee 휙 도망/near 다가옴/peek 숨었다 빠짐/lens 렌즈에 붙음). 사용자 요청: "다양하게".
