### 6-3. 우주몰 팝업 스토어 (이벤트)
**언제 생기나 (현실적인 문제)**: 로어북 「우주 쇼핑몰」은 낱말이 나와야 켜지는 항목이라, 본편 모델이 혼자서 우주몰을 꺼내는 일은 드물다. 그래서 이벤트를 여는 길을 둘 둔다.
1. **사이트 공지로 알림 (추천)**: 인터넷 우주몰 진열을 새로 짤 때, 모델이 가끔 `<popup>장소 한 줄</popup>`을 같이 쓴다(예: 「망원동 ○○상가 1층 빈 점포, 오늘만」). 설정 「팝업 스토어 공지」 켬/끔. 공지는 사이트 첫 화면 띠에 보이고, 본편에는 [Inventory] 옆 한 줄로 넘어간다(「우주 쇼핑몰 팝업 스토어가 오늘 ○○에 열려 있다」). 이 줄에 「우주 쇼핑몰」 낱말이 들어가서 로어북도 켜진다. 공지는 다음 진열을 짤 때 새 공지가 없으면 빠진다(따로 날짜를 세지 않음).
2. **본편에서 우연히**: 플레이어가 상가를 지나가거나 찾아가면, 본편 모델이 로어북대로 입구를 쓰고 표식을 단다. 플러그인은 따로 하는 일이 없다.
- 표식은 지금 상점 것 그대로(`[shop: 우주 쇼핑몰]`) 쓴다. 이름 맞추기로 `site:'cos'`가 붙는다.

**창**: 지금 상점 창(`ui/shop.ts`)을 그대로 쓰고 `site==='cos'`일 때만 바꾼다.
- 주인 사진 → 안내판, 대사 상자 → 단말기 화면, 「주인에게 말하기」 → 「단말기에 묻기」, [판매] 단추 숨김, 구획 이름은 사이트와 같게.
- 묻기 대답은 talkPrompt를 그대로 쓰되, 받은 응답에서 대사만 쓰고 「바꾸기」는 버린다(값 고정, 사용자 확정).
- **사기**: 물건 → [산다] → 단말기 창(현금/카드/그만). 둘 다 지금 buy와 같이 가계부에서 빼고 소지품에 넣는다. 다른 점은 가계부 메모뿐이다: 「가맹점 ○○ (우주 쇼핑몰)」. 가맹점 이름은 첫 진열 호출 때 모델이 `<merchants>`로 4~6개를 같이 주고, 살 때마다 차례로 쓴다(값을 박지 않음). 현금/카드 고르기는 기록 글만 다르다(잔고는 하나).
- 설정: 우주 쇼핑몰 설정 페이지 값을 그대로 읽는다(자동 호출 칸만 팝업에 안 씀). 새 칸은 「팝업 스토어 공지」 하나뿐.
- 지침: 「우주 쇼핑몰」 지침에 절 둘을 더한다. `POPUP_COMMON`(현장 무인 상가·단말기·현금/카드·안내판, 지금 COMMON과 바꿔 끼움)과 `POPUP_NOTICE`(사이트 진열 때 공지를 쓸지·어떻게). shelfPrompt·talkPrompt에 「COMMON 대신 쓸 절 이름」 인자 하나를 더한다.

**작업량**: 새 화면 조각 둘(안내판·단말기 칸, 결제 창), 상점 창 갈림 몇 곳, 지침 절 둘, 사이트 공지 띠 하나, 본편 넘김 한 줄. 상점의 나머지는 그대로라 위험이 작다.

### 6-4. 망상홈쇼핑 — 안별 구현

**공통 (세 안 모두)**
- **값 = 할부 회차**: 진열 줄의 값 칸에 「무이자 10회」처럼 글로 받는다. 지금 `pay` 처리 그대로이고, 원 값은 0이다. 산 물건에는 `paidWith: 망상홈쇼핑 무이자 10회 할부`가 남는다. **확인해 보니 지금 이 글은 산 턴의 「새로 산 것」에만 한 번 가고, 매 턴 소지품 줄에는 안 간다.** 그래서 소지품 줄 만들기(`core/items.ts` 인벤토리 글)에서 「원이 아닌 값으로 산 물건」만 줄 끝에 「(할부: …)」를 늘 붙이게 한 곳 고친다(「이름만」 설정이어도 붙임). 그러면 본편 모델이 로어북(할부 = 출연 의무, 미납 = 금요일 소환)대로 쓴다. **회차를 세는 장부는 따로 만들지 않는다**(현실적으로: 갚는 장면은 본편이 쓰고, 프로그램이 셀 근거가 없다). 나중에 필요하면 보조 모델이 「n회 남음」을 소지품 설명에 고치게 하면 된다(지금 update 경로로 가능).
- **맞교환**: 흥정에서 상담원·러너가 「쓰시던 ○○로」를 받아들이면 pay 글이 그것으로 바뀐다(지금 흥정 경로). 내 물건을 실제로 빼는 건 상점 「팔기」 흐름과 같이 묶는다(쇼룸에서만, 전화는 글로만 약속 → 본편이 처리).
- **숨은 원래 용도**: 플러그인에 칸을 따로 두지 않는다. 사용법 스티커 문구는 물건 설명에 넣고, 원래 용도가 터지는 건 로어북의 상품 패턴(스티커 아래 원래 용도, 어기면 발동)대로 본편 모델이 정한다. 숨김 칸을 두면 본편에 몰래 넘겨야 하는데, 모델이 미리 흘릴 위험이 크고 장치가 늘어서다.
- **택배(전화 주문)**: 전화로 산 물건은 바로 소지품에 넣지 않고 사이트 상태의 「배송 중」 목록에 둔다. 본편에는 「주문함: ○○ — 택배로 올 것, 남의 이름일 수 있음」을 This turn과 그 뒤 매 턴 짧게 넘긴다. 본편에서 상자를 받아 열면 보조 모델이 평소처럼 「새 물건」을 보고하는데, 이름이 배송 중 목록과 맞으면(`sameItemName`) 플러그인이 주문 때 받은 판정·설명·그림·paidWith로 채우고 배송 중에서 뺀다. 맞는 게 없으면 평소대로 들어간다. 걸리는 점: 보조 모델이 「택배 상자」처럼 다른 이름으로 보고하면 안 맞는다. 그래서 보조 모델 자료(지금 가진 것 목록)에 「배송 중: ○○」 줄을 같이 넘겨, 상자를 열면 그 이름으로 보고하게 한다(자료 한 줄 더하기).

**A안 — 상점 창 그대로**
- 6-2의 `site:'ds'`만으로 된다. 본편 표식 `[shop: 망상홈쇼핑|레드 프라이데이]`(금요일 끼어들기·앱)에서 상점 창이 열리고, 피부만 방송 모양, 주인 칸에 진행자, 말하기는 「상담원에게 전화로 말하기」로 바꾼다.
- 할부는 공통 pay를 그대로 쓰고, 산 것은 바로 소지품에 들어간다(택배를 넣으려면 공통의 배송 중 장치가 따로 필요).
- 작업량: 가장 작다(우주몰 팝업과 같은 정도). 채팅·편성·방청 신청은 없다.

**B안 — 따로 방송 창**
- 새 팝업 창 하나(방송 화면, 채팅, 편성, 전화 창)와 그 상태·호출·해석을 새로 만든다. 열기는 새 표식 `[homeshop:]` + 새 카드.
- 쇼룸은 결국 상점 창(`site:'ds'`)이 따로 있어야 한다. 그래서 창이 둘이 되고, 메뉴 밖에서만 열려서 다시 보기가 어렵다.
- 작업량: 가장 크다. 창 틀·크기·폰 전체 화면을 상점과 별개로 다시 만들어야 한다.

**C안 — 인터넷 사이트 + 쇼룸 이벤트 (추천)**
- **사이트**: 쇼핑몰 틀(`core/malls.ts`)에 `'ds'`를 더한다. 그러면 설정 변수(`$ds_sh_*`), 상태(`$ds_shop`), 지침 이름(Ds), 자동 호출(수동/창 열 때/매 턴), 매 턴 새로 짜기, 사기(buy)가 우주몰·포인트몰과 똑같이 따라온다. 브라우저 SITES·로고·폰 서랍에 한 줄씩 더한다.
- **한 번 호출로 받는 것**: 지금 진열 요청문(shelfPrompt)에 방송용 블록 둘을 더 받는다. `<host>`(진행자 자막 2~4줄, 지금 방송 중인 상품 번호)와 `<chat>`(채팅 n줄, 이름|말). 진열 줄(`<shelf>`)은 「오늘 편성」으로 그대로 쓴다. 파서는 parseShelf에 블록 둘을 읽는 작은 함수를 붙인다. 지금 몰의 「한마디」(mallNote) 자리에 진행자 자막을 둔다.
- **채팅 보내기**: 따로 호출하지 않는다. 적은 말은 상태에 쌓아 두었다가 다음 새로 짜기 때 같이 넘긴다(호출 아낌). 화면에는 바로 내 줄로 보인다.
- **전화 주문 창**: 우주몰 「운영자에게 질문」 창(talk 호출, 물건 붙이기)을 그대로 가져와 상담원으로 바꾼다. 흥정은 회차·맞교환(pay)만 바꾼다. [주문 확정] → 공통 택배(배송 중 목록).
- **방청 신청**: 단추 → 상태에 「신청함」 → 다음 턴 본편에 「스튜디오 방청객으로 신청했다」를 넘긴다. 본편이 다음 방송 때 끌려가는 장면을 쓰고, 광고 시간 쇼룸에서 `[shop: 망상홈쇼핑 쇼룸|러너]` 표식 → 상점 창(`site:'ds'`, 6-2). 쇼룸은 흥정·팔기(맞교환) 다 되고, 출구 선물 가방이라 바로 소지품에 들어간다. 쇼룸 지침 절(SHOWROOM_COMMON)은 Ds 지침 안에 둔다.
- **금요일 끼어들기**: 새 표식 `[homeshop: 망상홈쇼핑]` → 카드 「채널이 바뀌었다 · 보기」 → 인터넷 탭을 망상 사이트로 연다(`focusSite('ds')`, 이미 있는 함수). 카드는 상점 카드와 같은 코드를 쓰고 글·단추만 다르다. 본편 지침 표식 절에 한 줄을 더하고, 상점 표식의 「home shopping」을 뺀다.
- **탭 닫기·채널 돌리기**: 처음엔 넣지 않는다(본편에 넘길 근거가 약하고 탭 닫기는 다른 사이트에도 없다). 필요하면 나중에.
- 작업량: 중간. 화면은 새로(시안 09·10을 그대로 옮김), 나머지는 우주몰 사이트 코드를 거의 그대로 쓴다. 쇼룸은 6-2와 같이 끝난다.
