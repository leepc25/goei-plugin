## 0. 이 스레드에서 사용자가 특히 화낸 것 (반드시 지킬 것)

1. **시키지 않은 생성 금지.** 「필요해」「좋은 생각」은 뽑으라는 뜻이 아니다. 「뽑아」「해」「시작해」라고 해야 크레딧을 쓴다. 이 스레드에서 세 번 어겨 크게 혼남(장소 자세 77줄 무단 생성 등).
2. **맥락에 맞게.** 코믹·개그 연출, 갑자기 나오는 가구·소품 공격 금지(기술 재설계 기준 1-4). 기술은 그 인물이 실제 가진 능력·무기·몸 기술에서만.
3. **이미 돈 들인 결과는 버리지 않고 쓴다.**
4. **확인 요청을 일일이 하지 말 것**("내가 일일이 정해줄 수 없어"). 단, 크레딧이 드는 시작과 방향·배치 같은 결정은 묻는다.

## 3-2. 앉기 손 문제 수습 (2026-10-27, 생성 0)

- 문제: 정면 앉기(60)·옆 앉기(96)를 126명 모두 「두 아래팔을 허리 높이 앞으로」로 뽑아, 책상 없는 자리에서 손을 들고 앉아 있음. 거기서 시작한 수다(62·97)·졸기(66)도 두 손을 든 채. 3명 시험 없이 전원 뽑은 Claude 잘못(사용자 크게 화냄).
- 사용자 지시: **크레딧 더 쓰지 말고 수습.** 다시 뽑지 않음.
- 수습(코드만, `game-src/action/motion3/seated_idle.json`):
  - **책상 없는 정면 자리 대기** = 기대 쉬기(73) **5번째 장**(126명 모두 손을 옆 자리 위에 내림). 숨쉬기는 코드로 1px 들썩임. 앉을 때: 정면 앉기(60) → 기대 쉬기(73) 1~5장 재생(손이 내려감) → 5장 유지.
  - **책상 없는 옆 자리 대기** = 눕기(75) **2번째 장**(손을 무릎·자리에 둔 옆 앉은 자세). 앉을 때 75의 1~2장, 일어날 때 거꾸로. 몇 명은 조금 뒤로 기댐.
  - **책상 없는 자리의 수다·졸기** = 위 대기 장 + 코드(말풍선·고개 1px 끄덕, 졸기는 고개 아래로 2px + Zzz). 62·66·97은 쓰지 않음.
  - **책상 있는 자리**(사무 책상·식당 테이블)는 지금 그림(60·62·63·64·65·66·96·97·105) 그대로. 손이 책상 위라 자연스러움. 책상이 몸 앞을 가리면 더 자연스러움 → 배치 때 책상 자리는 책상을 캐릭터 앞 층에.
  - 치료받기(78)는 팔을 내미는 동작이라 그대로.
- 규칙(작업자 지침 7절): 다른 줄의 시작 장이 되는 줄은 3명 시험 → 사용자 확인 → 전원.

## 5. 도구와 돌리는 법

- 큐: `python3 game-src/action/motion3/m3.py enq <키> <줄…>` → `daemon`(20개 동시). 표 메모에 「엔진 v3」이면 v3 엔진.
- 자동 검수: `python3 game-src/action/motion3/mwatch.py <키…>`(환경변수 T0=시작 시각 epoch, 그 뒤 결과만 봄): 새 결과를 mech.check 하고 통과면 `m3 ok`, 실패면 한 번 다시.
- **ok 를 안 해 주면 뒤 줄(「N번 끝 장」에서 시작)이 영원히 기다린다.** 이 스레드에서 검사기가 꺼져 1시간을 날림.
- 백그라운드 명령은 최대 2시간. 컨테이너 재시작이면 일꾼·검사기 다 꺼짐 → running을 pending으로 옮기고 다시 띄움(그때 돌던 줄은 다시 비용).
- 다시 뽑기 절차: `audit.py` → `refine.py` 기준 → `fix_list.json` → `fixrun.py prep` → `enhance.py fix_actions.json`(PixelLab 지침) → `fixrun.py apply`(표 고치고 enq).
- 캐릭터 다시 등록(그림 그대로 크기만): `create-character-v3`에 `reference_image`(남) + `direction_images`(나머지 7방향)를 주면 **그림을 그대로 받아들임**(0.25회).
- 이펙트: `motion3/gen3.py`(manifest → VFX pro + 캐릭터 지우기 + 기계 검사), `vfx.py`(캐릭터가 안 그려진 이펙트는 지우기 건너뜀, 원본 `vfx/raw/`).
