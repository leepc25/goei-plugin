## 3. 메모리에서 옮긴 규칙 (빠짐없이; 원문은 `memory_1106/MEMORY.md`)

### 말하는 법
- 한국어만, 짧고 쉬운 말. 스레드에서는 존댓말. 묻는 말에 먼저 한 줄로 답한다.
- 질문은 무엇이 문제인지 + 선택지 + 추천.
- 모든 사실에 확인한 파일 경로를 붙인다. 확인 못 한 것은 「확인 안 됨」. **지금 살아 있는 카드·저장소만 근거**(옛 2.3 jpeg 카드는 로어북 대조용으로만).
- 있는지 확인하지 않고 「없다」고 하지 않는다. 링크는 확인한 뒤 준다.
- 품질을 직접 보지 않고 「됐다·OK·잘됐다」 하지 않는다. 증거 없이 「이 품질 가능하다」 하지 않는다. 증거 없는 「공짜니 한번 해 보죠」 제안 금지.

### 일하는 법
- 시키지 않은 일 금지. 특히 **시키지 않은 UI 추가 금지**(11-05 폰 머리 뒤로가기 단추가 배치를 깸; 폰 뒤로가기는 이미 스와이프).
- 「기다려봐」= 멈춤. 「계속 가」= 끝까지. 「확정」= 뒤따르는 일까지 스스로. 「합쳐」= PR. 「릴리스해」= 릴리스. 「닫아」= 스레드 정리, 「치워」= 교체.
- 사용자 말을 글자 그대로. 사용자가 짚은 곳을 먼저 본다. 정한 규격에서 벗어나지 않는다. 해석을 턴마다 뒤집지 않는다.
- 하나를 고치면 **그 여파까지** 고친다(지운 칸이 빈 줄을 남김, 「호감 +2」는 누구의 것인지). 「고쳤다」 화면을 보이기 전에 실제 폰+PC 캡처에서 남은 것·중복을 확인한다.
- **PC와 폰을 똑같이 만들지 않는다.** 폰 하단 바는 최대 5칸이라 다르게 만든 것. 「통일」은 각 플랫폼 안에서만. 맨 위 단추 줄(잔고 등)은 모든 화면에 남긴다.
- 창 머리 = 유령 아이콘 + 메뉴 제목만. 「괴이 ː ANOMALY」 넣지 않음. 이름 표기는 「괴이 ː ANOMALY」.
- 「이면/이면세계/이면의 문」 개념·제목은 **폐기**. 요청문·글·제목 어디에도 쓰지 않는다.
- 시작 화면 세력 그림은 정확히 5장(`assets/wiki/Factions/` 관리국·가짜관리국·백일몽·프리랜서·민간인 .avif, 600×600; `src/core/factions.ts`, `src/ui/images.ts`). 세력 그림은 장소·물건 장면(어두운 애니 셀, 사람 거의 없음), 단체 사진 아님. 봇 카드 사진은 1024×1024 정사각도 됨(현재 main.png 832×1216).
- 설계 전에 원 설정(위키 카드 `card/wiki-base.json`, 로어북)을 먼저 읽는다. 장소를 지어내지 않는다(관리국=종로, 백일몽 본사=강남, 협회=영등포).
- 지우기 전에 목록을 보여 주고 허락받는다. 결과물 삭제 금지.
- 긴 일은 백그라운드로, 사용자 말엔 바로 답한다. 대기 루프 `while pgrep -f X`는 자기 자신을 잡으니 `pgrep -f 'python3 -I X'`나 파일로 확인.
