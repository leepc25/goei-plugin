## 2. 꼭 지킬 것

1. **사용자가 시킨 것만 뽑는다.** 뽑기 전에 회수를 말하고, 한 장(동작 하나)씩 확인하고, 장마다 쓴 회수와 남은 잔액을 알린다. 시험 삼아 수백 회를 쓴 일로 사용자가 크게 화낸 적이 있다.
2. **처음엔 한 명, 위험한 동작부터 시험**: 누운 자세(날아가 쓰러지기, 예전에 얼굴이 뭉개짐), 무기가 손에 생기는 공격, 담배 든 대기. 결과를 보고 프롬프트를 고친 뒤 넓힌다.
3. 생성 결과(프레임 PNG·시트)와 바뀐 문서는 **생길 때마다 이 브랜치에 커밋·push**. main push·릴리스는 사용자가 「릴리스해」라고 할 때만.
4. 쟈알디(46개)·스팡달(31개)의 기존 동작은 다 지우고 새로 만든다(사용자 말). 지우기는 사용자가 시킬 때 `DELETE /v2/characters/{id}/animations/{animation_group_id}`.

## 3. 뽑는 법 (API)

- 인증은 환경 프록시가 붙인다(`api.pixellab.ai`). 결과 그림은 `backblaze.pixellab.ai` — 환경 허용 도메인에 들어 있어야 받을 수 있다(2026-10-24 사용자가 추가함).
- 캐릭터 id: `docs/인계/픽셀랩_캐릭터목록_2026-10-24.md`, 동작표 머리줄.
- **커스텀 동작** = `POST https://api.pixellab.ai/v2/characters/animations`
  ```json
  {
    "character_id": "<id>",
    "mode": "pixminimax",
    "action_description": "<표의 영어 프롬프트>",
    "animation_name": "<번호> <동작 이름>",
    "directions": ["<표의 방향: east / west / south-east / south-west>"],
    "frame_count": <표의 장 수>,
    "subject_description": "<머리줄 Subject>",
    "initial_pose": "<표의 Starting pose>",
    "custom_start_frame": "<시작 장 PNG base64 — 표의 「시작 장」이 다른 동작의 장이면 그 장, 아니면 생략(등록 그림)>",
    "end_frame": "<끝 장 PNG base64 — 표에 끝 장이 정해진 동작만>",
    "keep_first_frame": false,
    "enhance_prompt": false
  }
  ```
  배경 없음은 캐릭터 기본값. 응답의 background job id로 `GET /v2/background-jobs/{id}`를 2~5초마다 확인하고, 끝나면 `GET /v2/characters/{id}`로 동작과 프레임 주소를 받는다.
- **걷기·뛰기 견본**: 웹 「Free motion → PixMiniMax → walking / running」. API에서 같은 것을 고르는 값은 아직 확인 안 함 → 처음 한 번은 사용자에게 웹으로 뽑아 달라고 하거나, 같은 엔드포인트에 `action_description: "walking"`로 시험(1회)하고 결과를 사용자와 비교.
- **비용**: PixMiniMax는 8장까지 1회, 8장 넘으면 2회(사용자 확인). 잔액은 `GET /v2/balance`.
- 프레임 받기는 curl(`?t=` 포함 주소 그대로).

## 4. 연결 순서 (시작 장이 앞 동작의 장인 것)

같은 인물 안에서 이 순서로 뽑아야 시작 장을 넘길 수 있다.

1. 1 평상 대기, 3 전투 대기 (등록 그림에서 시작)
2. 9 약1 → 10 약2(9 끝 장) → 11 약3(10 끝 장)
3. 19 날아가 쓰러지기 → 20 일어나기(19 끝 장), NPC는 15 → 16(15 끝), 30 엎드려 기기(15 끝)
4. 23 충전 모으기 → 24 방출(23 끝 장)
5. 5 뛰기 → 8 달리다 점프, 13 돌진(뛰는 중 한 장)
6. 7 방향 점프 → 14 점프 공격(7의 꼭대기 장)
7. 비전투·NPC: 40 주저앉기 → 39 네발로(40 끝), NPC는 32 → 31
8. 나머지는 1번 또는 3번 첫 장에서.

## 5. 보고 형식 (장마다)

「<인물> <번호> <동작> · <장>장 · 쓴 회수 n · 잔액 m」 + 결과 그림(첨부) + 문제가 보이면 한 줄. 사용자가 보기 전에 다음 동작으로 넘어가지 않는다(사용자가 「계속 가」라고 하면 그 범위는 끝까지).
