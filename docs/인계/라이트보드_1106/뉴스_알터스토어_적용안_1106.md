## 1. 이미 있어서 다시 만들지 않는 것 (라이트보드 작업 스레드 결과)

브랜치 `claude/project-thread-rwcsxj`에 들어간 공통 부품. 두 새 기능은 이걸 그대로 쓴다.

| 원본 항목 | 우리 쪽 | 새 기능이 할 일 |
|---|---|---|
| 생각보조(적고 제거/생각만/안하기) | `src/core/craft.ts` craftSettings·craftMessages, 지침 파일의 `THOUGHTS` 절 | 새 지침 파일에 `THOUGHTS` 절만 쓰면 된다 |
| 비망록(탈옥) | craft.ts `MEMO.*` 절 | 같은 절 이름으로 쓰면 된다 |
| 다시 보기, 동시 요청 수, 재시도 원인 분석 | `src/host/llm.ts`, `RETRY_ANALYZE` | 호출만 하면 된다 |
| 유저 메시지 빼기, 생성 언어, 토큰 상한, 재시도 | `src/core/advanced.ts` `gen` 공통 | 기능 코드(`AdvFeature`)를 하나 더 늘리면 고급 칸이 생긴다 |
| 기능별 전용 모델 | craft.ts `featureModel` | 같음 |
| 다양성 강화(확률+seed) | 괴담넷에 들어감 | 뉴스는 그대로 옮기면 된다. 상점은 원본도 「생각 보조 필요」 조건부라 뺄 수 있다 |
| 누르면 불러오기(lazy) | 괴담넷·괴담톡의 「열 때 확인」(`gnetOpenCheck`) | 같은 방식 |
| 컨텍 포함/제거 | 지침 `MAIN_CONTEXT` 절 + `mainContextRules` | 같은 방식 |
| 반응 그림([콘:이름]) | 괴담넷 | 뉴스 머리기사 사진에 쓸 수 있다 (3-6 참고) |

겹치지 않게 뺀 것: TOON(사용자 결정 JSON 유지), 커스텀 블록·테마.

## 2. 공통 결정: 어디에 붙이나

새 탭을 둘이나 더 만들기엔 모바일 아래 바가 다섯 칸으로 꽉 차 있다(`src/ui/app.ts` mobileBar: 위키·임무·상황판·괴담톡·괴담넷). 후보:

- **(가) 괴담넷 안의 하위 탭** — 괴담넷은 이미 「게시판 / 쪽지」 하위 탭 구조(`gnet.sub`). 여기에 「뉴스」「장터」를 더한다. 메뉴를 안 건드리고, 모델 요청·저장·설정 코드를 가장 많이 재활용한다. **추천.**
- (나) 기록 탭의 하위 탭 — 기록은 일지·가계부·인물·세력. 장터는 가계부 옆이 어울리지만 뉴스는 아니다.
- (다) 새 탭 — PC는 왼쪽 메뉴에 자리가 있지만 모바일은 바를 여섯 칸으로 늘려야 한다.

이름 후보(괴담넷 하위 탭 기준): 뉴스 = 「뉴스」「신문」「소식」. 장터 = 「장터」「상점」「매점」. 아래는 (가)를 전제로 쓴다.

## 3. 뉴스 적용안

### 3-1. 저장
- 채팅 변수 하나(후보 `$nw_news` 또는 `$gn_news`). JSON: `{ issues: [{ id, datetime, name, posts[], topAds[], bottomAd, mine:false }] }`. 괴담넷처럼 판마다 쌓고, 보관 상한(기본 10판)을 고급 칸에 둔다.
- 원본은 TOON이지만 우리는 JSON(사용자 결정). 괴담넷 `boardJson`과 같은 틀.

### 3-2. 지침 파일
`src/data/guides/news.txt`(새 파일). 절 이름은 위키·괴담넷 규칙을 따른다.
- `NS.GUIDE`: 원본 lb-news.lb 「About the board」「Topics」「Advertisements」「Privacy」를 옮긴다. 세계관 문장은 바꿔 쓴다(아래 3-5).
- `NS.PRIVACY_0`~`NS.PRIVACY_4`: 사생활 5단계 문장(원본 그대로 옮기면 됨).
- `NS.FORMAT`: JSON 출력 틀.
- `NS.CHANGE`: 신문 바꾸기 지시.
- `MAIN_CONTEXT`: 「뉴스는 광고·소문·오보가 섞여 있어 진실이 아닐 수 있다」(원본 「News」 로어북).
- `THOUGHTS`, `MEMO.*`: 공통 부품용.
- 사전설정 1980·됴션휘보 문장은 `NS.PRESET_1980`, `NS.PRESET_OLD`로 두되, **기본 꺼짐**. 이 두 사전설정은 우리 세계(현대 서울)와 안 맞아서 쓸 일이 드물다. 넣을지 말지는 사용자 결정(뺴도 된다).

### 3-3. 설정 항목 (괴담넷 설정 페이지와 같은 모양)
| 원본 | 우리 후보 | 기본값 제안 |
|---|---|---|
| 모드 | 켬/끔 (모델은 공통 「보조」 설정을 따름, 전용 모델은 고급 칸) | 끔 |
| 발동 | 즉시 / 열 때 확인 | 열 때 확인 |
| 주제 | 글칸 「구독 분야」 | 비움 |
| 사생활 | 5단계 그대로 | 자율 |
| 누구 | 글칸 (비우면 플레이어) | 비움 |
| 느낌 | 글칸 | 비움 |
| 대표사진 | 3-6 참고 | 끔 |
| 다양성 강화 | 괴담넷과 같은 칩 | 끔 |
| 생각 단계·비망록·다시 보기·전용 모델 | 고급 칸(공통 부품) | 공통 기본값 |
| 컨텍 | 본편 반영 켬/끔 | 켬 |
| 밝기 | 안 넣음 (우리 테마 따름) | — |

### 3-4. 화면
- 신문 모양 한 장: 제호(신문 이름)·날짜 줄 → 위 광고 2칸 → 머리기사(제목 크게, 본문 전체) → 작은 기사 목록(제목·분류·시각·첫 줄) → 아래 광고 1칸. 지난 판은 위 날짜 줄에서 넘겨 본다(괴담넷 게시판 목록처럼 세로 목록도 가능).
- 광고 CSS: 원본은 모델이 인라인 CSS를 쓴다. 우리는 `src/core/sanitize.ts`류의 안전 처리가 필요하다(허용 속성: background, color, border, padding, text-align, font-size, border-radius, box-shadow 정도로 거른다). 거른 뒤 남는 게 없으면 기본 광고 칸 모양.
- 글꼴: 원본 조선일보 명조 CDN은 넣지 않는다(외부 요청). 우리 명조 계열 시스템 글꼴로.
- 단추: 새로고침, 신문 바꾸기(글칸 하나: 「어떤 신문」), 설정.

### 3-5. 세계관 문장 (후보)
원본 지침은 세계 중립이라 바꿀 게 적다. 다만 「어느 신문인가」를 정해 둬야 매번 신문사 이름을 지어내지 않는다.
- 후보 A: **바깥 세상 신문** — 이면을 모르는 일반 언론. 괴이 사건은 「가스 누출」「실종」「원인 미상 화재」로 보도되고, 관리국은 이름 없이 「관계 당국」으로만 나온다. 위키의 세광특별시(「뉴스에도 안 나오고」), 광기로 점철된 성당(「가스 누출이라는 명목」), 반짝반짝 용궁(「뉴스 단신」) 문장과 맞는다. **추천.** 플레이어가 괴담넷(이면 커뮤니티)과 신문(바깥)을 나란히 보는 재미가 생긴다.
- 후보 B: 이면 전용 소식지 — 괴담넷과 겹친다.
- 후보 C: 둘 다, 「신문 바꾸기」로 고른다.

후보 A 기준 지침 추가 문장(안): 「기자들은 이면세계를 모른다. 괴이·관리국·협회·백일몽 같은 이름은 기사에 나오지 않는다. 그런 사건은 사고·범죄·괴소문·도시 전설로만 다룬다. 플레이어와 동료의 행동은 목격자가 있는 공개 장소에서 한 것만, 그것도 ‘신원 미상’으로 쓴다.」 (사생활 단계와 같이 작동.)

신문 이름 후보(모델이 지어내지 않게 하나 박아 둘 경우): 「서울일보」「매일서울」「수도신문」. 이면 소식지로 갈 경우: 「이면통신」「뒷골목 소식」.

### 3-6. 대표사진
- 원본은 라이트보드 공용 그림 모듈로 **생성**한다. 우리 플러그인에는 그림 생성 경로가 없다(`src/host`·`src/core`에 생성 호출 없음). 넣으려면 Risu 이미지 생성 API 연결부터 새로 만들어야 해서 이번 범위에서 뺀다.
- 대신 후보: 괴담넷에 이미 들어간 「반응 그림([콘:이름])」 방식으로, 머리기사에 **등장 인물이 있을 때만** 그 인물의 표정 그림을 기사 옆에 붙인다(모델이 `portrait: 이름_표정`을 적음, 위키 정보칸 표정과 같은 부품). 생성 비용 0.

### 3-7. 본편 주입
- 괴담넷과 같은 방식: 컨텍 켬이면 최근 1판의 머리기사 제목·작은 기사 제목만 참고 블록으로 넣고, `MAIN_CONTEXT` 한 줄을 붙인다. 본문 전체는 넣지 않는다(토큰).

### 3-8. 비용·크기
- 요청 1회당 괴담넷 새로고침과 비슷(지침 ≈2,500토큰 + 참고 자료). 코드는 괴담넷 복사 후 줄이기라 중간 크기. 괴담넷 1,190줄 대비 뉴스는 상호작용이 하나뿐이라 절반 이하.

### 4-2. 상점을 무엇으로 두나 (세계관 각색, 핵심 결정)
위키에 이미 상점이 많다. 지어내지 않고 이걸 쓴다.

| 위키 문서 | 결제 | 성격 |
|---|---|---|
| 얼굴 없는 장터 | 물물교환(팔 대 팔) | 이면 전체 익명 장터, 모든 맨홀 |
| 중림 지하상가 | 현금·이상 물품·관리국 장비·호의·신체 | 암시장. 장물아비(마덕희)·손길 의원(고연지)·영창 컨설팅(신유리, 사채) |
| 우주 쇼핑몰 | 현금·카드 | 외계산 이상 물품, 값이 월급 단위 |
| 무엇이든 자판기 | 신체 부위만 | 상황 맞춤 물건 |
| 도깨비 공방 | 선물(술·음식·희한한 재료) | 주문 제작·수리 |
| 이정 책방 | 업보 할인 | 영물·부적·정화. 관리국 단골 |
| 달빛 타투샵 | 물물교환 | 초능력 문신 |
| 기독교 상점 | 현금 | 축복받은 성물. 교황청 거점 |
| 백일몽 복지몰 | 회사 포인트 | 사내 경제(등급별 클리어 보상 포인트표가 위키에 있음) |
| 협회 장비 창구 | 대여료 | 프리랜서용 |
| 소토스 백화점·룩키마트 | 신체·보석 | 괴담 자체. 상점으로 쓰면 안 됨 |

후보:
- **(ㄱ) 한 상점, 현금만** — 「중림 지하상가」를 기본 상점으로. 현금 결제라 가계부와 바로 맞고, 암시장이라 「재고가 그때그때 바뀜」「환불 없음」「값이 사정에 따라 다름」이 원본 지침과 그대로 맞는다. 대출(영창 컨설팅)·치료(손길 의원)·장물 판매(헐값매입)가 같은 문서 안에 있어 원본의 Buy·Loan을 각색할 거리가 다 있다. **추천.**
- (ㄴ) 세력별 상점 — 관리국은 장비 신청(지급, 돈 안 듦), 백일몽은 복지몰(포인트), 협회·프리랜서는 협회 창구+중림, 이면의 주민들은 얼굴 없는 장터. 세계관에는 제일 맞지만 결제 수단이 넷이라 장부 연결을 세력마다 따로 만들어야 한다. 크기 2~3배.
- (ㄷ) 「장터 바꾸기」로 위 표 중 현금 받는 곳(중림·우주 쇼핑몰·기독교 상점)만 고른다. (ㄱ)에 단추 하나 더. 비현금 가게(자판기·장터·공방·책방·타투샵)는 본편 이야기로 남겨 둔다.

이름 후보: 탭 이름 「장터」「상가」「중림」. 상점 머리글은 위키 제목 그대로 「중림 지하상가」.

### 4-3. 지침 파일
`src/data/guides/store.txt`(새 파일).
- `ST.GUIDE`: 「서울 중구 중림동 지하 암시장. 겉은 망해 가는 지하상가. 조직이 아니고 자영업자 그물망. 가격은 부풀려져 있고 환불 없음. 재고는 그때그때. 관리국 장비·비인가 백일몽 제품·이상 물품이 장물로 돈다.」 위키 문장을 모델이 읽게 하는 게 아니라, 플러그인이 위키 「중림 지하상가」 문서를 참고 자료로 같이 넣는다(위키 참고 부품 `refs.ts` 재활용).

### 4-5. 대출 각색
원본 「시스템 대출(주 10%, 랭크별 한도, 미상환 디버프)」은 위키의 **영창 컨설팅(신유리)** 와 거의 같은 구조다. 「이자는 7일마다 이자만, 못 낸 이자는 원금에 복리, 담보는 능력·점포·신체」.
- 후보 A: 넣는다. 장부에 `+금액 (영창 컨설팅 대출)` 거래, 채팅 변수에 대출 원금·이자·다음 이자일 기록, 상태창 날짜가 7일 지날 때마다 참고 블록에 「이자 x원 납기」를 넣어 본편 모델이 독촉 장면을 쓸 수 있게 한다. 갚기는 장부 `−금액`. 미상환 디버프는 숫자 능력치가 없으니 본편 주입 문장(「채무 불이행 중, 중림 출입 제한, 회수 인력이 찾고 있음」)으로.
- 후보 B: 1차엔 뺀다. 사기·새로고침만. 대출은 이야기로.
- 추천: B로 먼저 내고 A는 따로. (대출은 날짜 계산·상태 유지가 붙어 혼자서도 PR 하나 크기.)

### 4-6. 산 물건은 어디로 가나
원본은 「옆에 나타난다」 한 줄. 우리는 본편 소지품 칸이 없다. 후보:
- (가) 참고 블록 「최근 구매」 — 최근 n건의 이름·효과를 본편 요청에 넣는다. 가장 작다. **1차 추천.**
- (나) 인물 기록의 물품 문서(`docs_item`, `src/core/people/types.ts` DocType `item`)에 자동 등록 — 이미 있는 부품이라 붙이기 쉬운데, 그쪽은 Director가 본편에서 발견한 물품을 적는 자리라 성격이 조금 다르다. 확인 필요.
- (다) 위키 자동 작성 — 「귀한 것」 이상만 위키 문서로. 토큰 비용 큼.
