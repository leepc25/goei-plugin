## 2. 사용자 확정 (바꾸지 말 것) — 메모리 goei-wait-fight 와 같음
- PC 전용, 본문 위 투명. 본문 덮는 판·띠·번쩍임 X. 글자는 전부 도트(pixelHud dotText), 칸은 HUD 도트 틀. 그라데이션 X.
- 키: ←→ 이동(기본 달리기), 방향 두 번 대시, 뒤 = 막기(헛손질엔 X), A 약 · S 강 · D 충전 · Q 원거리 · W 특수기, A+S 필살, Z 주저앉기 · X 웅크리기. 쿨타임 X.
- 콤보: 약약강 = 띄우기, 약약약강 = 멀리 날려 쓰러뜨리기, 6연타(막기 포함) 강제 다운. 쓰러진 상대 때림.
- 후딜 약 1.5배 · 강 2배(필드 대비). 예약 공격(버퍼가 늦게 나가는 것) X.
- 원거리: 내 탄이 화면에 있는 동안 못 쏨.
- 맞으면 날아감(제자리 X). K.O.: 슬로 0.3배로 날아가 쓰러짐 + 화면 빛 + 캐릭터만 붉게, UI 숨김 → WINNER + 승리 동작(35), 진 쪽 화내기(32).
- 필살기: 띠 오버레이 X. 배경만 어두워지고 캐릭터 하얗게 번쩍 + 둘레 빛 + 기술 이름 도트 글자. 사용자 바람: 달려들어 수십 대 때리고 띄우는 화려한 연출.
- AI: 막기 너무 잘함 X, 몸 비비며 공격 X(밀어내기 상자).
- 뒷걸음은 걷기 거꾸로(겁먹은 뒷걸음 37 X). 데미지 숫자 X, 콤보 HIT 수는 있음. 방어 게이지 X. 대전엔 NPC 스탯 뻥튀기 X. 체력 3배.
- 모드: 1 VS 1(3판 2선승) / 태그매치 / 서바이벌. 라운드 시작 때 둘 다 가운데 서 있기(벽에서 뛰어나오기 X).
