## 쓰임
- 소지품 격자 칸의 그림. 종류 기본 그림 14장 + 자주 나올 물건 그림. 물건 이름을 키워드로 맞춰 고르고, 없으면 그 종류의 기본 그림.
- 매칭 표는 `game-src/items/icons.json` 으로 둘 예정: `{ "keywords": ["소금", "소금 봉지"], "file": "charm_salt.png", "kind": "charm" }` 줄들. 긴 키워드 먼저 맞춘다.
- 이름 출처: 위키(`card/wiki-base.json`)에 나오는 물건(와이더 무전기·앨리스 피크닉 세트·은화 뱀·포크와 나이프 무기 세트·위 헬프!·「천사의 한숨」 카세트·유리 등롱 부적·동물 가면·은탄 쌍권총·빨간 손전등 등) + 현대 서울 배경에서 흔한 물건.

## 뽑는 조건(안 — 사용자 확인 후)
- PixelLab `generate-image-v2`(pixflux), 64×64, `no_background: true`, 시점 정면 약간 위(아이콘), 어두운 톤·민트 강조 없음(격자 배경이 어두우니 물건 자체는 밝게).
- 공용 글: `pixel art item icon, single object, centered, dark modern Korean urban horror setting, clean outline, 64x64, no background`.
- 순서: 종류 기본 14장 먼저(1장 뽑아 격자에 놓고 확인 → 나머지 13장) → 물건 그림은 종류별로 묶어 10장씩.
- 회수: 기본 14 + 물건 약 130 = 약 144회. `.pixellab_ok` 는 사용자가 「뽑아」 한 뒤에만 적는다. 이 스레드는 키가 없어 못 보냄 → 「괴이봇」 환경의 새 스레드에서.
