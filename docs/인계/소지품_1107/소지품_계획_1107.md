# 지난 논의 기록 (근거 아님, 흐름 참고용)

## 1. 한 줄 요약

가계부와 같은 꼴로 **소지품 장부**를 하나 더 둔다. 물건은 장터에서 사거나, 사용자가 손으로 넣거나, (켜면) 갱신기가 본문에서 읽어 넣는다. 본편 요청에는 `[Inventory]` 한 블록으로 붙어 모델이 「갖고 있는 것」을 알고 쓴다. 화면은 기록 › 소지품 하위 탭.

## 2. 저장 모양 (`src/core/items.ts`, 새 파일)

채팅 변수 `$st_items` (JSON). 가계부(`$st_wallet`)와 같은 원리: 기준 메시지(anchor)가 채팅에 남아 있을 때만 산다 → 다시 굴리기·메시지 삭제에 저절로 맞춰진다. 손으로 넣은 건 anchor 빈 문자열(늘 산다).

```ts
interface Item {
  id: string;          // 'i_' + hash(anchor|name|from)
  name: string;        // ≤30
  desc: string;        // 한 줄 ≤80 (모델에 넘기는 설명)
  effect?: string;     // 한 줄 ≤60 (있으면 모델에 넘김)
  qty: number;         // 1 이상
  from: 'store' | 'story' | 'manual';
  anchor: string;      // 기준 메시지 키. manual 은 ''
  price?: number;      // 장터에서 산 값 (가계부 줄과 짝)
  walletId?: string;   // 짝인 가계부 거래 id (되돌릴 때 같이)
  quote?: string;      // story: 근거 문장 ≤120
  at: string;          // ISO
}
interface ItemLog { list: Item[]; used: UsedRow[] }   // used = 쓴·버린 기록 (장부처럼 남김, 상한 200)
```

- 읽기/쓰기: `readItems / itemsVars / liveItems(alive)` — 가계부의 `readWallet / walletVars / liveWallet` 과 같은 이름 규칙.
- 더하기: `addItem(log, item)` 같은 이름+같은 anchor 면 qty 만 더함. 상한: 종류 60, 전체 줄 400.
- 빼기: `useItem(log, id, n, why: 'used'|'dropped'|'lost')` qty 를 줄이고 `used` 에 한 줄. 0 이면 목록에서 뺀다. 수동 빼기는 anchor 없음.
- 모델에 넘길 글: `itemsBlock(list)` → `[Inventory]` 아래 `- 이름 ×2 — 설명 (효과)` 줄. 20줄 넘으면 많은 순으로 자르고 「외 n종」.

## 4. 화면 (`src/ui/items.ts`, 새 파일 + `records.ts` 하위 탭)

- 기록 › 하위 탭 `[일지 | 연대기 | 가계부 | 소지품 | 인물 | 세력]`. 모바일 아래 바는 다섯 칸이 꽉 차서 새 탭은 못 넣고, 가계부처럼 기록 안으로.
- 위: 종류 수·전체 개수. 아래 목록: 이름 ×개수 · 설명 · 출처 아이콘(장터/본문/직접) · 근거(장터는 값·날짜, 본문은 인용). 줄을 누르면 펼쳐서 「하나 쓰기」「버리기」「개수 고치기」.
- 맨 아래 「직접 넣기」(이름·설명·개수). 「쓴·버린 기록」 접힌 칸.
- 장터를 만들면 장터 쪽 「내 물건」 칸은 이 목록을 그대로 보여 주고, 들어가면 기록 › 소지품으로.

## 5. 본편 연결 (`src/body.ts`)

- `withStatusBlock` 바로 뒤에 `withItemsBlock`: `[Previous status]` 블록 다음 줄에 `[Inventory]` 를 같은 system 메시지로 붙인다 (메시지 수 안 늘림). 목록이 비어 있으면 안 붙인다.
- 설정 「소지품」 묶음(`$it_*`): 본편에 참고로 넘김(기본 켬) · 본문에서 자동 읽기(기본 **끔**, 아래 결정) · 모델에 넘길 줄 상한(기본 20).
- 상태창 칸(10칸)은 건드리지 않는다. 상태창에 소지품 칸을 넣으면 모델이 매 턴 베껴 써야 해서 어긋남이 생긴다(가계부 때 같은 문제).

## 10. 대화로 바뀐 것 (11-07 04:44~05:00, 사용자와 합의)

- **소모품/장비 구분**을 물건마다 둔다(`kind: 'consumable' | 'gear'`). 「썼다」일 때 줄어드는지는 모델이 아니라 플러그인이 이 표시로 정한다. 장터 목록·직접 넣기·보조 모델 얻음 보고에서 함께 적는다.
