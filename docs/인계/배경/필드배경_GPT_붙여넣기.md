# 필드 배경 GPT 요청 (관리국·가짜 관리국 실내 부품 시트)

## 붙여 넣을 말 (쟈알디 방 기준 그림을 같이 첨부)

GitHub 저장소 leepc25/goei-plugin(main)의 docs/필드_그림_통합_지침.md
(https://github.com/leepc25/goei-plugin/blob/main/docs/필드_그림_통합_지침.md)를 읽고,
「배경 지침」의 「0. 최신 결정」과 「0-1. 부품 시트」를 그대로 따라서 시트 8장(P1_책상의자 ~ P8_문2)을 순서대로 그려줘.
화풍은 첨부한 「쟈알디 방」 그림을 따르고, 두 번째 시트부터는 먼저 만든 시트도 같이 보고 같은 화풍으로 그려.
한 장 끝날 때마다 멈추지 말고 8장을 계속 그려. 물건 목록과 크기는 docs/필드_거점_설계안.md 1-4(문), 1-8(집기·소품)에 있어.
저장은 game-src/art/field/parts/<시트 id>.png. 먼저 P1만 그려서 보여주고, 내가 「계속」이라고 하면 나머지를 이어서 그려.

## 확인 방법
- P1을 받으면: 물건들이 같은 화풍·같은 배율인지, 마젠타 배경에 그림자·번짐이 없는지, 물건 사이 30px 이상 떨어져 있는지 본다.
- 이 파일은 지침의 요약이 아니라 붙여 넣는 말 한 가지뿐이다. 규칙은 모두 지침 문서에 있다.
