## 1. 원칙

- **구역 보스(수호자)** = 층 유형마다 1, 재현 세트마다 주인 1. 원문 "수호자는 자기 층 규칙을 절대 따른다 → 규칙을 알면 약점이 보인다"를 그대로 공략법으로 쓴다.
- **중간 보스** = 구역당 0~1. 곁가지 끝·잠긴 문 뒤에 있어 피할 수 있다. 잡으면 유물 후보·큰 회수물.
- **노는 법이 전부 다르다.** 아래 표의 「핵심 기믹」 열에 같은 동사가 두 번 나오지 않는다 (잠입 / 막기 / 빛 / 소음 / 순서 / 대화 / 세로 추격 / 인내 시계 / 숨 참기 / 미끼 목소리 / 갑옷 깨기 / 인질 / 두 표적 / 고백 / 혼 / 시각표).
- 연출·패턴·페이즈 규격은 3장. 경 아머·그로기 게이지는 README 3장 그대로.

## 2. 크기 등급

쟈알디 = 키 약 93 도트(192×144 캔버스), PIXEL 2.75에서 화면 높이 720 ≈ **262 도트**. PixelLab 한 장 상한 256.

| 등급 | 키 (도트) | 화면에서 | 캔버스 | 만드는 법 |
| --- | --- | --- | --- | --- |
| S | 95~125 | 쟈알디와 비슷~조금 큼 | 192×144 | 쟈알디와 같은 방식 (캐릭터 + 뼈대 클립) |
| M | 130~200 | 쟈알디 1.5~2배 | 256×256 | 한 장 생성, 큰 동작은 단계로 쪼갬 |
| L | 200 이상, 화면을 넘음 | 화면 높이 이상, 일부만 보임 | 부위마다 ≤256 | **다부위**: 머리·몸통·팔·다리를 따로 그리고 엔진이 관절로 움직임. 부위마다 작은 반복 클립만 생성 |
| 화면 | 방·칸 자체가 몸 | 배경 전체 | 배경 | 배경 그림 변형 + 약점 소품 몇 개. 배경과 같은 GPT 평면 그림 → 코드 도트화(방법 B) 가능 |

비용 가정: 뼈대 클립 8장 = 3회. 사람 크기 보스 클립 1개 ≈ 3.3회, 256 캔버스 ≈ 4회, 기준 그림 보스당 약 6회. L급은 부위 정지 그림 + 짧은 반복만 만들고 큰 움직임은 엔진이 부위를 돌려서 낸다(그래서 덩치에 비해 싸다).

## 3. 보스다운 보스 공통 규격 (사용자 2026-10-22 "보스는 보스답게", "원패턴 난사 금지", "필요하면 페이즈 전환")

### 3.1 크기와 존재감
- **사람 크기 보스는 없다.** 1판 9종 모두 M(쟈알디 1.5~2배) 이상, 대부분 L(화면 높이 이상·다부위) 또는 화면(무대가 몸).
- 평소 사람 크기로 숨어 있던 것은 **발각되는 순간 커진다**(경비원·208호 가족). 크기 변화 자체가 등장 연출.
- 보스 방에 들어서면: 등장 컷신(GPT 도트 영상 4~6컷) → 화면 위 큰 이름판(이름 + 부제, 예 「낡은 제복의 경비원 · 로비 L3 수호자」) → 단계 칸이 나뉜 긴 체력 줄 + 그로기 줄.

### 3.2 패턴 (한 기술 난사 금지)
- **단계마다 기술 6~8개**, 보스 하나에 합계 15~22개. 단계가 넘어가면 앞 단계 기술은 강화판으로 일부만 남고 새 기술이 들어온다.
- **기술 덱**: 같은 기술 연속 2회 금지, 최근 3수 안에 쓴 기술은 무게 절반.
- **상황 반응**: 거리(근·중·원), 플레이어가 공중인가, 막기를 오래 하는가(→ 잡기·막기 깨기), 멀리서 쏘기만 하는가(→ 돌진·당기기), 등 뒤에 있는가(→ 뒤돌아 쓸기)를 보고 고른다.
- **연계**: 기술 2~3개를 이은 묶음(예: 짧은 견제 → 큰 내려치기, 가짜 예고 → 반대쪽 공격). 같은 기술도 예고 길이 2종(빠른/느린)으로 박자를 흔든다.
- **무대 사용**: 기둥·가구·셔터·천장 같은 무대 소품을 집거나 부수고, 부서진 무대는 그 싸움 동안 그대로 남는다.
- **숨 고르기**: 큰 연계 뒤 1~2초 빈틈(헐떡임·도발)을 반드시 둔다. 보스가 쉬지 않고 패지 않는다.
- **필살기**: 단계마다 체력 경계에서 1회, 화면 전체를 쓰는 큰 기술. 피하는 법은 무대·규칙 안에 있다.

### 3.3 페이즈 전환
- 체력 경계(보통 70%·35%)에서 전환. 전환 중 보스 무적 2~3초 + 짧은 연출(포효, 무대 붕괴, 조명 변화).
- **전환 때 무대가 바뀐다**: 바닥이 꺼지거나 벽이 무너져 넓어지거나, 어두워지거나, 싸움터가 다른 곳(승강로·운동장)으로 옮겨진다.
- 마지막 일격은 화면 정지 + 느린 화면 + 보스마다 다른 사망 연출(무너짐·녹음·접힘). 규칙으로 끝내면 따로 「규칙 통과」 연출.

### 3.4 제작 방식
- M급(256 캔버스 한 장): 쟈알디와 같은 기준 그림 + 뼈대 클립. 큰 공격은 예비·타격·회수로 쪼개 16장.
- L급: 부위(머리·몸통·팔 마디·다리 마디·손)를 따로 그리고 엔진이 관절로 움직인다. 부위마다 표정·주먹 쥐기 같은 짧은 반복만 생성. 덩치에 비해 회수가 적다.
- 화면급: 무대 배경 변형(GPT 평면 그림 → 코드 도트화) + 약점 소품 클립.
- 등장·전환·사망 컷신은 GPT 도트 영상으로 따로 의뢰(PixelLab 회수 0).

## 4. 1판 보스 9종 상세

표기: 기술 이름 — 하는 일 (예고 / 피하는 법). ★ = 필살기. 수치는 시험판에서 조정.

### #1 낡은 제복의 경비원 — 로비 L3 수호자 (첫 보스)
원문: 수십 년 전 제복, 정해진 경로 순찰, 소리·움직임에 반응하고 완전히 멈춘 사람은 무시, 방심하게 만드는 무해해 보이는 수호자.
크기: 순찰 중 사람 크기(키 95) → 발각되면 **목과 팔다리가 늘어나 키 200**(M, 256). 3단계에서 제복이 터지며 팔 넷.
무대: 로비 안내 데스크·회전문·기둥 4개·셔터.

| 단계 | 기술 |
| --- | --- |
| 1 순찰 (사람 크기) | 순찰 걷기(바닥에 경로 표시) · 손전등 비추기(원뿔 안에 들면 발각) · 뒤돌아보기(가짜 예고 섞임) · 무전 듣기(빈틈). **발각 전 등 뒤를 치면 2배 + 2단계 체력 10% 깎고 시작** |
| 2 늘어남 (70%까지) | 경봉 2연타 — 근거리 / 손전등 돌진 — 원뿔로 겨눈 뒤 직선 돌진, 기둥에 박으면 휘청 / 내리치기 — 충격파 바닥 줄 따라 / 긴 팔 잡기 — 멀리 있으면 팔을 뻗어 끌어옴 / 경봉 돌려 막기 — 정면 공격 튕김, 뒤로 돌아가야 함 / 호루라기 — 로비 잡몹 2체 깨움(1단계당 1회) / 데스크 밀기 — 안내 데스크를 밀어 길을 막음 |
| 전환 70% | 로비 조명이 꺼지고 비상등. 기둥 하나가 무너짐 |
| 3 팔 넷 (35%까지) | 4연타(두 경봉 엇갈림) / 교차 원뿔 — 손전등 2개가 X자로 쓸고 감 / 기둥 뽑아 휘두르기 / 천장 매달려 내려찍기 / 회전문 돌리기 — 회전문 날개가 밀어냄 |
| ★ 35% | **통금** — 양쪽 셔터가 내려오며 무대가 절반으로 좁아지고 원뿔 4개가 돌며 쓸고 감. 원뿔 사이 그림자에서 완전히 멈추면 무사 |
| 4 마지막 (35% 아래) | 2·3단계 기술 섞어 연계, 숨 고르기 짧아짐 |
| 사망 | 모자가 떨어지고 제복만 바닥에 납작하게 남음 |

클립(256): 순찰 걷기·비추기·뒤돌아보기·무전·늘어나기(변신 16장) 5 / 대기·걷기·2연타·돌진·내리치기·팔 뻗기·돌려 막기·호루라기·데스크 밀기·피격·그로기 11 / 팔 넷 대기·4연타·교차 원뿔·기둥 휘두르기·매달려 내려찍기·회전문·통금·사망 8 = **24클립 · 약 110회**

### #2 다리 많은 것 — 추격 층 수호자
원문: 벽·천장을 기고 몸보다 훨씬 작은 틈으로 빠져나가는 다리 많은 것, 열 추적.
크기: **L, 몸길이 약 420**(화면 1/3), 사람 등뼈 같은 몸통 + 다리 8 + 사람 얼굴 비슷한 머리. 부위 그림 + 엔진 관절.
무대: 추격 층 끝 환풍 홀. 벽·천장에 틈새 6곳.

| 단계 | 기술 |
| --- | --- |
| 1 천장 (몸은 안 보임) | 다리 찌르기 — 천장에서 다리만 내려와 찌름(바닥에 다리 그림자) / 다리 비 — 3~5개 연속 / 틈새 낚아채기 — 벽 틈 가까이 서면 끌고 들어감(연타로 탈출) / 열 추적 — 오래 서 있으면 찌르기가 정확해짐 |
| 전환 70% | 천장이 무너지며 몸 전체가 떨어짐 |
| 2 지상 | 다리 쓸기(하단, 점프) / 앞다리 2연 찌르기 / 거미줄 뱉기(둔화) / 몸통 덮치기(넓은 그림자) / 벽 타고 돌기 — 무대 벽을 한 바퀴 돌며 위에서 덮침 / 틈새 이동 — 사라졌다 다른 틈새에서 튀어나옴(나오기 직전 그 틈에서 먼지) |
| ★ 35% 전환 | **둥지** — 여섯 틈새에서 동시에 다리가 쏟아짐. 막은 틈새는 안 나옴 → 1·2단계에 틈을 막아 둔 만큼 쉬워짐. 그 뒤 바닥이 꺼져 자동 스크롤 추격으로 넘어감 |
| 3 추격 (자동 스크롤) | 화면 뒤쪽 전체를 채운 몸이 쫓아옴. 다리가 화면 밖에서 찔러 들어옴 / 문 닫기(E)로 다리를 끼우면 큰 피해 / 앞 통로 천장을 무너뜨려 장애물 생성 |
| 사망 | 마지막 문에 끼어 다리가 하나씩 접히고 몸이 틈 속으로 짓눌려 들어감 |

규칙 약점: 틈새를 소품 밀기(E)로 막으면 나올 곳이 줄고, 다 막히면 못 나와 4초 넘어짐.
부위: 몸통 4자세·머리 6표정·다리 마디 3종(위/아래/발톱) 정지 그림 + 반복(머리 비명·입 벌림·몸통 꿈틀·거미줄 뱉기·넘어짐·끼임) 8 = **약 75회**

### #3 그림자 — 어둠 층 수호자
원문: 직접 보면 단단해지는 그림자, 곁눈으로 봐야 함. 어둠 층은 빛이 몇 초 만에 꺼지고 체온으로 추적.
크기: 바닥 얼룩 → **화면 높이(키 260)까지 서는 반쯤 녹은 사람** → 3단계 천장까지 번져 화면을 덮음(L).
무대: 어둠 층 넓은 사무실. 책상·칸막이 뒤 그림자.

| 단계 | 기술 |
| --- | --- |
| 1 얼룩 | 솟기 — 멈춘 사람 밑에서 띄움 / 얼룩 쫓기 — 바닥 따라 빠르게 / 가짜 얼룩 2개(진짜만 손전등에 반응) / 칸막이 그림자로 숨기 |
| 전환 70% | 얼룩이 모여 일어섬, 모든 조명 꺼짐 |
| 2 서기 | 손 모으기(양쪽에서, 구속) / 길게 쓸기(하단·상단 번갈아) / 늘어난 팔 찌르기(멀리서) / 녹아 사라졌다 등 뒤에서 / 책상 삼키기 — 소품을 삼켜 던짐 / 빛 먹기 — 손전등을 켜면 그쪽으로 몸을 숙여 덮침 |
| ★ 35% 전환 | **삼키기** — 화면이 위에서부터 검게 덮임. 손전등을 켠 원 안만 안전, 3초 손전등을 언제 켜나 |
| 3 번짐 | 천장·벽에서 손이 여럿 / 시야 원 축소 / 얼굴이 화면 가장자리 아무 데나 떠오름(그때가 약점) / 2단계 기술 강화 |
| 사망 | 손전등 빛 한가운데서 연기처럼 증발, 바닥에 얼룩만 |

규칙 약점: 손전등을 비추면 단단해져 피해가 들어가지만 반격도 세짐. 빛을 끄면 흐려져 무적.
부위: 녹은 상반신 4자세·손 5종·얼굴 4·하반신 녹음 3 + 반복(솟기·녹기·손 모으기·삼키기) = **약 65회**

### #4 소리와 냄새 — 침묵 층 수호자
원문: 몸 없는 발소리·목소리, 다가오는 썩은 내.
크기: 평소 안 보임. 드러날 때 **화면 2/3를 채운 흐릿하고 썩은 거대한 얼굴과 손**(화면급).
무대: 침묵 층 식당 홀. 뒤집힌 그릇·솥 여럿, 깨지기 쉬운 접시 더미(밟으면 소리).

| 단계 | 기술 |
| --- | --- |

### #5 불가능한 입체 도형 — 퍼즐 층 수호자
원문: 움직이면 멀미·방향 감각 상실을 주는 불가능한 3차원 도형.
크기: 1단계 방 높이 펜로즈 상자(M~L) → 2단계 펼쳐져 무대보다 커짐 → 3단계 **플레이어가 도형 안을 걷는다**(무대 자체가 도형, 화면급).
무대: 퍼즐 층 하얀 방.

| 단계 | 기술 |
| --- | --- |
| 1 상자 | 보면 조작 반전·흔들림 / 모서리 빛(빔) / 회전 밀치기 / 조각 날리기 |
| 전환 70% | 펼쳐지며 방 바닥이 계단 모양으로 꺾임 |
| 2 펼침 | 펼쳐 내려찍기 / 면 하나가 벽이 되어 밀고 옴 / 계단이 거꾸로 이어짐(위로 걸으면 아래로) / 모서리 4색 순서가 섞임 |
| ★ 35% 전환 | **안으로** — 플레이어가 도형 안에 갇힘. 화면이 90°씩 돌아가며 중력 방향이 바뀜 |
| 3 안쪽 | 벽·천장·바닥이 돌아가며 공격 / 모서리가 무대 네 귀퉁이에 / 등 돌리기(반전 해제)와 소리로 위치 |
| 사망 | 접혀서 점 하나가 되어 툭 떨어짐 |

규칙 약점: 모서리 넷을 번호 순서대로 → 접혀 떨어짐(5초 3배). 틀리면 처음부터 + 빔.
제작: 회전·펼침·안쪽 무대는 코드 3D를 도트로 그림. 모서리 깨짐·접힘 효과만 생성 = **약 20회**

| 사망 | 균형추에 짓눌려 승강로 아래 어둠으로 미끄러짐 |

### 4장 밖 메모

- **시험 층**은 원문 "수호자가 가장 많이 목격되는 곳"이라 #1~5 중 하나를 무작위로 부른다. 지금 시험 층에 있는 「낡은 제복의 차장」은 유계역 세트로 옮긴다(5장 #17). 경비원 색 바꾸기 복제를 피하고 원문 차장(conductor)이 지하철에 맞기 때문이다.
- B-12 「만지는 것들」은 보스가 아니라 60초 버티기 연출(생성 0).
- (선택) **승강기의 의식** — EXIT 앞 마지막 칸이 몸(화면급). 천장 카메라 눈, 문이 철컥 닫히며 압착, 층 표시가 미친 듯 돌며 바닥↔천장 중력 뒤집힘, 요원 호명이 공격 예고. 때리면 총애가 깎이고 패턴이 늘어나며, 규칙서 줄을 지켜 "문을 열게" 해야 끝. 승강기 설계서 10장 "최종 보스 없음"을 바꾸는 일이라 사용자 결정.
