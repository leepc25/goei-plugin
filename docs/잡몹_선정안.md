# 잡몹 선정안

작성 2026-10-22 · 「잡몹 괴이 선정」 스레드 · 상태: **사용자 선택 대기** (그림 생성 0회)

근거: 위키 「차원 승강기」(로비·지하층·정비 구역·떠도는 승객·재현의 층), 「명일 아파트」, 「강서 대학병원」, 「학교의 악몽」, 「유계역」, 「원숭이 꿈 괴담」. 코드 `src/game/action/enemy/roster.ts`, 의뢰서 `docs/적_그림의뢰서.md`.
제외: 가짜 관리국, 백일몽, 블라렛·살라딘 (다른 스레드), 수호자(구역 보스).

## 원칙

- 주무대는 차원 승강기. 잡몹은 **① 승강기 고유**(모든 출동에 나옴)와 **② 재현의 층 세트**(층 하나 = 다른 괴이 하나)로 나뉜다. 위키 원문이 재현 장소로 병원·학교·지하철역·아파트를 직접 꼽는다.
- 괴이마다 3~5종 + 정예 1, 다른 괴이로 재사용 안 함 (기본 기획서 10.2).
- **같은 행동 규칙을 두 종이 나눠 쓰지 않는다.** 아래 표의 「노는 법」이 모두 다르다.
- 장면 수: 사람 크기 일반 = 기본 8장면(서기·걷기·피격 약·피격 강·공중·누움·일어서기) + 공격마다 3장면(예비·공격·회복). 공격 2개면 **14장면 ≈ 28장**.

B-12 「만지는 손」은 전투가 아니라 버티기 연출이라 잡몹에서 뺀다.

## 만드는 순서 제안

1. 1판 ①②를 실루엣에서 진짜 그림으로 (약 340장). 앞선 순서는 의뢰서대로 더는 사람이 아닌 것 → 해롭지 않아 보이는 것 → 사격하는 것 → 돌진하는 것 → 사는 척하는 주민.
2. 2판 세트 하나 (학교 추천, 약 130장).
3. 병원·지하철역은 그다음.

그림 출처(PixelLab / GPT)와 생성은 사용자 승인 뒤에 정한다.
