## 1. 본부 문·출입구 — codex/pixellab-doors-round2

```text

2. 첫 문 1종을 제작한다. 닫힘/열림 상태의 문틀 위치와 크기를 맞춘다. 출입구 표식은 별도 레이어로 납품하고 생성 이미지에 글자를 넣지 않는다.

4. game-src/art/hq-door-round2/에 원본·투명 PNG·크기·앵커·상태별 manifest·호출 기록을 보존한다. 기존 본부 그림과 공용 엔진은 수정하지 않는다.
5. 실제 게임 화면 위에 합성한 독립 HTML 검수판을 만들어 PC/모바일에서 문 크기·바닥 정렬·가독성을 확인한다.
6. 자기 브랜치에 commit/push하고 전체 커밋 SHA, 검수 링크, 실제 생성 수와 비용, 미완료 항목, 통합 좌표·최소 패치를 전달한다.

문 이동 로직과 최종 게임 반영은 메인 통합 담당이 처리한다. 인증 전에는 준비 작업을 진행하고 인증 후에는 실제 자산까지 완성한다.
```

## 2. 컷씬 환경 시범 — codex/pixellab-cutscene-round2

```text
기존 브랜치 작업을 이어가라. PixelLab 인증은 사용자가 연결한다. 인증 후 실제 연결·잔액·진행 중 작업을 확인하고, 이전 작업이 있으면 결과 회수부터 한다.

목표: ‘첫 출근’의 빈 본부 복도에서 문이 열리는 환경 컷 1개를 제작하고 재생 가능한 검수판으로 납품.

1. AGENTS.md, docs/PixelLab_사용법.md와 기존 제작 준비 문서를 읽는다. 본부 문 담당의 최신 기준·문 디자인을 공유받아 동일한 장소로 보이게 한다.
2. 최종 화면 640×360을 기준으로 구도·팔레트·픽셀 크기·재생 시간·필요 프레임을 설계한다. 실제 생성 지원 크기를 확인하고 확대가 필요하면 정수 배율과 여백 배치를 사용한다.
3. 첫 프레임 구도를 검수한 뒤 문 열림 동작을 제작한다. 문틀·벽·바닥이 프레임마다 흔들리지 않게 한다. 같은 프레임 복제로 부드러워졌다고 보고하지 않는다.
4. 담당 범위는 환경 컷이다. 캐릭터 애니메이션은 다른 제작 담당이 맡는다. 기존 반려 캐릭터 그림을 참조로 쓰지 않는다.

6. game-src/art/cutscene-production-round2/에 원본 프레임·재생 순서·프레임별 시간·manifest·호출 기록을 보존한다. 원본 컷씬과 공용 재생 엔진은 수정하지 않는다.
7. 독립 HTML에서 정상 속도/느린 재생/반복 재생을 제공하고 PC·모바일에서 프레임 일관성과 동작을 검수한다.
8. 자기 브랜치에 commit/push하고 전체 커밋 SHA, 검수 링크, 실제 생성 수와 비용, 미완료 항목, 교체 대상 컷과 통합 방법을 전달한다.

로딩·오디오·재생 엔진 수정과 최종 게임 반영은 메인 통합 담당이 처리한다. 인증 후에는 실제 환경 컷과 검수판까지 완성한다.
```
