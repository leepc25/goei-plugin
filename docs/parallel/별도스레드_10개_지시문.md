# 별도 Codex 스레드 10개 작업 지시문

아래 **공통 지시문 + 해당 번호의 지시문 하나**를 각각 새 스레드에 붙여 넣는다.
기준: `leepc25/goei-plugin`, `codex/metroidvania-run-system`의 `0d43a449`.

## 공통 지시문

```text
저장소 https://github.com/leepc25/goei-plugin 의 게임 개발을 이어간다.
먼저 AGENTS.md, docs/게임_기본기획서.md, docs/메트로배니아_시스템_분업.md를 읽는다.
origin/codex/metroidvania-run-system을 명시적으로 fetch하고 0d43a449에서 독립 worktree/branch를 만든다. 기존 dirty 작업은 덮어쓰지 않는다.
내 담당 파일만 수정한다. 공용 파일 연결이 필요하면 최소 patch와 재현/적용 위치를 남긴다.
캐릭터 그림은 동결이다. 새 캐릭터나 반려된 도트 재활용은 하지 않는다.
메인 통합 담당이 engine/game.ts,world.ts,modules.ts,hub.ts,player.ts,render.ts,propBlock.ts,progression.ts,sessionStore.ts,stage/,hq/,story/video.ts를 작업 중이므로 직접 수정하지 않는다.
다른 작업 브랜치 임의 병합, main/공용 브랜치 push, 플러그인 릴리스, 생성 HTML 커밋은 하지 않는다.
해당 기능을 실제로 사용해 실패를 재현하고 코드를 고친다. 검사만 하고 끝내지 않는다. 결함을 찾지 못했으면 억지로 변경하지 말고 검증 범위와 남은 불확실성을 보고한다.
별도 테스트 산출물 이름을 사용한다. 타입 검사/관련 회귀 검사와 가능한 Chromium 검증을 수행한다.
완료 후 자기 브랜치를 commit/push하고 커밋, 변경, 검증, 공용 연결 패치, 남은 문제를 한국어로 보고한다.
```

## 10. PixelLab 컷씬 시범 제작 · codex/pixellab-cutscene-round2

```text
PixelLab 컷씬 담당. 실제 PixelLab 도구/공식 사용법과 과금을 먼저 확인한다.
캐릭터 동결을 유지하며 '첫 출근'의 빈 본부 복도·문이 열리는 환경 컷 1개를 시범 제작한다. 기존 반려 캐릭터·이전 컷씬 프레임을 신규 생성 참조로 재활용하지 않는다.
기준은 현재 컷씬 640×360 화면, 게임의 픽셀 비율·팔레트·시점. 낮은 프레임을 단순 복제해서 부드러워졌다고 하지 않는다.
동작 설계와 필요한 키프레임/중간 프레임을 정하고, 생성 전에 실제 도구 차감 횟수를 명시한다. 한 번 실패하면 원인을 조사하고 같은 방식 반복 금지.
새 산출물은 game-src/art/cutscene-production-round2/에 보존하고 원본 컷씬과 runtime timing은 덮어쓰지 않는다. HTML 검수 샘플과 프레임 간 일관성·재생 타이밍·도구 호출 기록을 전달한다.
도구/인증/지원 해상도가 맞지 않으면 임의 우회 생성하지 말고 지원 방식과 준비된 프롬프트를 보고한다.
```

## 통합 담당 내부 작업과 충돌 방지

메인 대화 내부 6개 작업은 이동·충돌, stage 진행, HQ/저장, 성장 전투 효과 연결, PixelLab 공식 도구 사전 조사, 기존 컷씬 검증/패킹 도구다. 위 10개는 별도 worktree에서 독립 브랜치로 수행하고, 공용 파일 연결은 통합 담당이 병합한다. 외부 PixelLab 제작은 사용자가 해당 지시문을 새 세션에 붙여 넣어 특정 제작 범위를 지시하는 방식이다.
