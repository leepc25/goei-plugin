# PixelLab 캐릭터별 작업 지시 · 2026-10-22

사용자가 PixelLab 인증을 직접 연결한다. 기존 캐릭터 제작 총괄은 **큐·비용·검수**를 맡고, 아래 캐릭터 담당 9개 세션에 **공통 지시문 + 담당 블록 하나**를 전달한다. 메인 대화는 게임 시스템과 승인 자산 통합을 맡는다.

이 문서의 캐릭터 9번은 기존 [10개 분업 지시문](별도스레드_10개_지시문.md)의 9번과 다른 작업이다. **기존 본부 문 9번·환경 컷씬 10번 세션은 그대로 유지하고 새로 중복 개설하지 않는다.** 캐릭터 제작 재개는 이 문서의 담당 범위에 한정한다. 문·환경 담당에게 캐릭터 일을 섞지 않는다.
