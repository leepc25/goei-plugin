새 조직(F00, G00 …)을 명부에서 만들고, 시작 화면에서 그 조직으로 플레이할 수 있게 하는 설계다.
설계만 담았고 코드는 아직 바꾸지 않았다. 기준 버전은 v0.12.0.

## 1. 지금 요원 소속은 무엇을 위한 것인가

명부에서 요원에게 고르는 「소속 조직」은 **모델에게 직접 가는 값이 아니다.** 실제 소속은 인물 로어북 본문이 말한다
(🏷️Tag 로어북도 "use the character lore for actual affiliation"이라고 적어 둠).

플러그인 안에서 소속이 하는 일은 세 가지뿐이다.

| 쓰임 | 내용 | 위치 |
|---|---|---|
| 요원 목록 공개 대상 | 조직을 고르면 그 조직의 `roster_for`(어느 플레이 세력의 상황판 요원 목록에 뜨는지)가 요원에게 복사된다 | `world/directory.ts` buildOrgs·orgDefaults |
| 괴담톡 연락처 탭 | 같은 방식으로 `phone_tabs`가 복사된다 | 같은 곳 |
| 묶음 표시 | 명부 화면 정리, 괴담톡 연락처의 소속 줄 | `ui/directory.ts`, `core/phone.ts` |

즉 지금의 소속은 "요원 두 설정값의 출처이자 정리용 묶음"이다.
플레이 세력은 A00~E00 다섯 개로 굳어 있고, 이름만 있는 조직(협회·교황청 등)은 플레이할 수 없다.

## 2. A00~E00이 굳어 있는 곳

새 코드가 들어오면 손봐야 하는 곳 전체다.

**플러그인 코드**
- `core/types.ts` `FactionCode = 'A00'|…|'E00'` 타입
- `data/scenarios.json` 세력·시작 장면 목록 → `isFaction()`이 이 목록으로 판정
- `FACTIONS` 상수 3곳: `world/directory.ts`, `world/engine.ts`(`[AC]` 판정), `core/phone.ts` `NOTICE_CHANNELS`
- `core/refs.ts` `factionCodesToNames`의 정규식 `[A-E]00` (괴담넷·위키 프롬프트에서 코드를 이름으로 바꿈) → F00은 그대로 새어 나감
- 특수 규칙: D00·E00은 요원 목록을 함께 씀(`orgDefaults`), 공지 채널 이름·접근 범위(`phone.ts` 684~714행), 원본 Lua의 D00 "작전 없음"
- 표시명 기본값 `catalog.ts` FALLBACK_DISPLAY, `directory.ts` factionDisplayNames

**카드 로어북**
- 🏷️Tag: `[AC|code]` 설명의 `code = A00 | B00 | C00 | D00 | E00`과 코드별 영어 이름, 배치 칸의 Faction pool 줄
- 📜Faction: 세력 설명(GM용). B00 시점에서 A00/B00 설명이 뒤바뀌는 CBS 포함
- Faction display: 보는 세력별 표시명 표(JSON)
- Phone tabs: 탭마다 `visible_for` 코드 목록 (공용 탭 T04·T05·X01은 다섯 코드를 모두 나열)
- Start trigger: `A00-1:…` 시작 조합별 시드 로어북 목록
- 시작 인사말: Lite 카드의 `alternate_greetings`와 매니페스트 `A00-ko-1` 키

## 3. 제안

### 3-1. 세력 목록을 명부로 옮긴다

「괴이봇 명부」의 `조직` 항목을 넓혀서, 조직마다 "플레이 가능" 여부와 코드를 갖게 한다.
다섯 기본 세력은 지금처럼 항상 있고, 새 플레이 세력은 여기에만 산다. 명부는 카드 로어북이니 카드를 공유하면 같이 간다.

```json
"조직": {
  "발푸르기스 협회": {
    "code": "F00",
    "playable": true,
    "type": "조직형",
    "blurb": "세계 마법사들의 비밀 결사. …",            // 시작 화면 설명 (한국어)
    "gm_name": "Walpurgis Society",                    // [AC] 목록의 영어 이름
    "gm_desc": "The organized body of the world's sorcerers …", // 📜Faction에 들어갈 설명
    "display": { "B00": "…" },                        // 특정 시점에서 다르게 부를 때만
    "seed": ["발푸르기스 협회", "블라렛"],              // 시작 첫 턴에 함께 넣을 로어북
    "photo": "faction_walpurgis",                      // 시작 화면 사진 (에셋 이름, 없으면 유령)
    "roster_for": ["F00"],
    "phone_tabs": ["T06"]
  }
}
```

- **코드 배정**: "플레이 가능"을 켜는 순간 비어 있는 다음 코드(F00, G00 …)를 자동으로 준다. 한 번 준 코드는 조직을 지워도 다시 쓰지 않는다(옛 채팅이 그 코드를 들고 있으므로).
- **유형**: 기본 세력의 특수 규칙을 세 가지 유형으로 묶어 고르게 한다.
  - 조직형 (A00·B00·C00처럼): 작전 있음, 내부 공지, 자기 요원 목록
  - 민간형 (D00처럼): 작전 없이 방문·이동만, 시민 공개 공지
  - 프리랜서형 (E00처럼): 의뢰 중심, 등록 계약자 공지
  
  지금 코드에 `code === 'D00'`처럼 박혀 있는 판정은 모두 "이 코드의 유형"을 묻는 함수로 바꾼다.
- 기본 다섯 세력도 같은 칸으로 이름·설명·사진을 고칠 수 있게 하되, 삭제는 막고 "시작 화면에서 숨기기"만 허용한다.

### 3-2. 태그 로어북은 자리표시자로 바꾼다

하드코딩된 코드 목록을 채팅 변수로 바꾸고, 변수는 플러그인이 채운다.

| 로어북 | 바꿀 부분 | 자리표시자 |
|---|---|---|
| 🏷️Tag | `code = A00 \| … \| E00`와 코드별 설명 다섯 줄 | `{{getvar::fac_ac}}` |
| 🏷️Tag | 배치 칸 Faction pool 줄 | `{{getvar::fac_pool}}` |
| 📜Faction | 맨 끝에 새 세력 설명 추가 | `{{getvar::fac_extra}}` |

- A00/B00의 "Fake" 뒤바뀜 같은 시점별 문구는 플러그인이 지금 소속을 보고 글로 만들어 넣는다(CBS 대신 TS). 원본 문구와 똑같은 결과가 나오는지 테스트로 고정한다.
- 변수는 시작할 때, `[AC]`로 소속이 바뀔 때, 명부를 저장할 때 다시 채운다. 옛 채팅은 창을 열 때 한 번 채운다.
- 로어북 수정은 Lite 카드를 만들 때(`tools/build_lite_card.py`) 자동으로 한다. 원본 카드는 손대지 않는다는 원칙 그대로다. 명부 화면은 Tag에 자리표시자가 없으면 "이 카드는 새 세력을 아직 못 씀" 안내만 띄운다.
- Faction display 표와 Phone tabs는 로어북을 고치지 않고, 플러그인이 읽을 때 명부의 새 세력을 합친다.
  다섯 기본 코드를 모두 나열한 탭(T04·T05·X01)은 "모두 공개" 탭으로 보고 새 코드도 자동으로 포함한다.
  새 세력에 전용 연락처 탭이 필요하면 명부에서 "전용 탭 만들기"로 T06 …을 추가한다.

### 3-3. 코드 일반화

- `FactionCode`를 `string`으로 풀고, `FACTIONS` 세 곳과 `isFaction()`을 "기본 다섯 + 명부의 플레이 세력" 목록 하나(`core/factions.ts` 새 파일)로 모은다.
- `factionCodesToNames` 정규식을 `[A-Z]00`으로 넓힌다. 요원 코드(P001)와는 자리수로 구분된다.
- `[AC|F00]`도 정상 소속 변경으로 받는다. `$ib_affiliation`은 명부의 조직 이름으로 채운다.

### 3-4. 시작 화면

- 새 세력은 시작 화면 세력 목록 맨 뒤에 사진·설명과 함께 뜬다.
- 첫 장면은 원본 인사말이 없으므로 **「직접 입력」과 「커스텀 임무」 두 가지로만** 시작한다. 둘 다 Lite 카드에 이미 있는 공용 빈 인사말을 쓰므로 카드에 인사말을 더 넣을 필요가 없다.
- 시드는 명부의 `seed` 목록을 쓴다(Start trigger 로어북의 `F00-n` 줄 대신). 기본 시드는 그 조직 이름과 같은 로어북 하나.
- 나중에 원하면: 명부에서 "첫 장면 글"을 써 두면 그걸 첫 메시지로 넣는 시작 장면을 추가할 수 있다(2차 과제).

## 4. 작업 순서

1. 코드 일반화 (3-3). 동작 변화 없음, 기존 테스트가 그대로 통과해야 함.
2. 명부 조직 칸 확장 + 명부 화면의 "플레이 가능·유형·설명·사진·시드" 편집 (3-1).
3. Lite 카드 자리표시자 + 변수 채우기 + 원본 문구 일치 테스트 (3-2).
4. 시작 화면에 새 세력 노출 (3-4). 브라우저 테스트에 "F00으로 직접 입력 시작 → `[AC]` 변경 → 상황판 요원 목록" 시나리오 추가.

원본 카드를 그대로 쓰는 사람(자리표시자 없는 카드)은 1·2·4만 적용되고, 새 세력 선택지는 숨겨진다.

## 5. 정해 주실 것

1. **태그 로어북 손보는 방식**: Lite 카드 만들 때 자리표시자로 바꾸기(추천) / 로어북은 그대로 두고 요청 직전에 플러그인이 글을 바꿔치기
   - 추천 이유: 로어북에 무엇이 들어가는지 카드에서 바로 보이고, 사용자가 로어북을 직접 고쳐도 자리표시자만 남아 있으면 깨지지 않는다.
2. **새 세력 첫 장면**: 직접 입력·커스텀 임무만(추천) / 첫 장면 글도 써넣기까지
3. **기본 다섯 세력 편집 범위**: 이름·설명·사진 편집 + 숨기기(추천) / 지금처럼 고정
