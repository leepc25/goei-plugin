# 기본 피해 표준값 (안 · 2026-10-30)

10-30 사용자 결정: 테스트룸 기본 피해에 들어 있던 **역할별 차이를 없애고 기술 종류별 표준값 하나로 통일**한다. 인물 차이는 힘민체지정(`설계_능력치_기술피해_안.md`)·고유 퍽·NPC 등급 배수에서만 낸다. 속성은 `퍽/기술_속성표.md`.

## 1. 왜 바꾸나

- 테스트룸 값은 샌드백 체력 400에 맞춘 것이다(보통 인물이 약공 연타로 약 10초).
- 그 안에 역할별 평타 초당 피해가 들어 있다: 타격 46 · 돌격 42 · 제어·방패 34 · 사격 32 · 지원 30(`밸런스_설계.md`).
- 여기에 힘민체지정 배율을 곱하면 같은 차이를 두 번 매기게 된다.
- 새 설계의 체력은 1,000 단위(플레이어 1,000, 적 600~2,800)라 숫자 단위도 다시 맞춰야 한다.

## 2. 표준값 (능력치 5, 강화 0 기준)

평타는 단위만 **×2.5**(초당 40 → 100) 했다. 기술은 테스트룸 비율(고유기 = 평타 약 7초분, 필살 = 약 10초분)을 그대로 두면 필살 한 방에 일반 몹이 다 죽어서(10-30 사용자 지적) **평타 몇 초분**으로 다시 잡았다. 순서(평타 < 충전 0 < 1 < 2 < 고유기 < 필살)는 지킨다. **10-30 사용자: 일단 이렇게 해 놓고 나중에 조정.**

| 기술 종류 | 지금(테스트룸) | 표준값 | 비고 |
| --- | --- | --- | --- |
| 평타 연타 초당 피해 | 30~46(역할마다) | **100**(전원) | 3타 각각의 피해 = 100 × 그 타 동작 시간 |
| 강공 한 대 | 약 34 | **동작 시간 × 100**(약 45~55) | 10-30 넣을 때 고정 120 대신 평타와 같은 「초당 100」으로 셈 |
| 점프 약공 / 점프 강공 | 약공 1타 / 1.8배 | **동작 시간 × 100**(약 20) / 그 1.8배 | |
| 슬라이딩 | 약공 1타 | **동작 시간 × 100**(약 35~45) | |
| 사격 단발(권총 등) | 6~13 | **22**/발 | 총 없는 인물(투척 포함)도 같은 값 |
| 사격 연사 | 7 | **18**/발 | 발당 과열 9% 그대로 |
| 사격 강한 한 발 | 30(사격형 36) | **75** | 쿨 2.5초 그대로 |
| 투척 | 단발과 같음 | **22** | |
| 충전 0 / 1 / 2단 | 75 / 150 / 240 | **80 / 160 / 250** | 평타 0.8 / 1.6 / 2.5초분. 에일린 3단은 2단과 같은 250(지금 110으로 낮게 잘못 들어감) |
| 고유기 | 270 | **280** | 쿨 5초, 평타 2.8초분 |
| 두 번째 고유기 | 270 | **390** | 쿨 7초라 1.4배 |
| 필살 광역형(44명) | 380 | **450** | 평타 4.5초분, 여러 적에게 |
| 필살 단일형(11명) | 480 | **600** | 평타 6초분, 한 대상 |

- 여러 타로 나뉜 기술은 **합이 표준값**이 되게 나눈다. 타마다 비율은 지금 데이터 비율을 그대로 쓴다.
- 고칠 이상값:
  - 노기균 고유기 마지막 타 1,882(입력 실수로 보임)
  - 에일린 충전 3단 110
  - 2.5초 쿨이 붙은 강한 한 발 3명은 표준값으로 덮어쓴다

## 3. NPC가 쓸 때

인물 AI 적은 플레이어와 같은 기술을 쓴다. 그대로 두면 적 기술 한 방이 너무 세다.

- **NPC 기술 배율 0.5**: 고유기·두 번째 고유기·충전·필살에만 곱한다. 평타·사격에는 곱하지 않는다.
- 그 위에 등급 피해 배율을 곱한다(훈련 0.8 · 숙련 1.0 · 적당히 1.2 · 상당히 1.5).

## 4. 검산 (플레이어 체력 1,000, 능력치 5, 강화 0)

**플레이어가 쓰러뜨리는 데 드는 시간** (평타 연타만, 회피·막기 빼고)

| 적 | 체력(+방어막) | 평타만 | 목표 |
| --- | --- | --- | --- |
| 거리 몹 | 300 | 3초 | 콤보 2~3번 |
| 훈련 몹 | 600 | 6초 | 콤보 4~5번 |
| 숙련 몹 | 1,000 | 10초 | |
| 적당히 요원 | 1,300 + 260 | 16초 | 실제 싸움(회피·막기·기술 섞임) 약 30초 |
| 상당히 요원 | 2,000 + 800 | 28초 | 실제 싸움 약 1분 |

- 실제 싸움에서는 적이 막고 피하므로 평타 시간의 약 2배가 걸린다고 봤다.

**적이 플레이어에게 주는 피해 (체력 1,000 대비)**

| 공격 | 훈련(×0.8) | 적당히(×1.2) | 상당히(×1.5) | 목표 |
| --- | --- | --- | --- | --- |
| 평타 한 대(평균 약 33) | 2.7% | 4% | 5% | 3~5% |
| 고유기 280 × 0.5 | 11% | 17% | 21% | 15~25% |
| 필살 광역 450 × 0.5 | 18% | 27% | 34% | 25~45% |
| 필살 단일 600 × 0.5 | 24% | 36% | 45% | 35~45% |

**플레이어 기술 한 방에 깎이는 비율** (강화 0)

| 대상 | 고유기 280 | 필살 광역 450 | 필살 단일 600 |
| --- | --- | --- | --- |
| 거리 몹 300 | 93% | 한 방 | 한 방 |
| 훈련 몹 600 | 47% | 75% | 100% |
| 숙련 몹 1,000 | 28% | 45% | 60% |
| 적당히 요원 1,560 | 18% | 29% | 38% |

- 필살로 한 방에 죽는 건 거리 몹(불량배급)뿐이다. 단일 필살은 훈련 몹까지 잡는다(남기려면 500).

## 5. 코드에 넣는 자리

| 할 일 | 지금 | 바꿀 곳 |
| --- | --- | --- |
| 평타 줄 피해 | 인물 팩 `bal.atk`(줄마다, 역할로 다름) | 표준 초당 100 × 그 줄 동작 시간으로 다시 계산(55명 팩 일괄, 도구 하나) |
| 사격 | `bal.shotDmg` | 총 종류별 표준값 |
| 충전·고유기·필살 | 기술 자료 안 `hit.dmg` | 합이 표준값이 되게 비율 유지하며 다시 씀 |
| NPC 기술 배율 | 없음 | `FighterAi`에서 기술 출처 피해 × 0.5 |
| 등급 배수 | 없음(AI 체력 160 고정) | 인물 초기값 표 연결 |

- 테스트룸(시험장) 샌드백 체력도 400에서 1,000으로 올린다. 그래야 실측 감각이 같다.
- 바꾼 뒤 시험장에서 등급별 대련으로 4장 표를 실측한다.

## 6. 정할 것

- 10-30: 위 숫자로 일단 정하고 시험장 실측 뒤 조정한다.

## 7. 넣은 것 (10-30)

- `tools/damage_std.py`: 인물 팩 126개(`game-pack/char-*/char.json`)를 표준값으로 다시 씀. `bal.dmgStd = 1` 표시로 두 번 돌려도 같음. 팩을 다시 만들 때(`tools/build_char_packs.py`)도 자동으로 거침.
- `src/game/combat/grades.ts`: 등급 배수표, 이름 있는 55명 등급, NPC 기술 배율 0.5.
- 플레이어 기본 체력 220 → 1,000(`engine/progression.ts`), 시험장 샌드백 400 → 1,000(`engine/bodies.ts`).
- 인물 AI 적: 등급 체력·피해 배수(예: 쟈알디 상당히 → 체력 2,200, 피해 1.5배), 고유기·충전·필살 피해 0.5배(`fighter/core.ts`가 기술 동작 중 피해에 「기술」 출처를 붙임).
- 필드 몹: 시민 150 · 거리 300 · 훈련 600, 피해 0.3 / 0.5 / 0.8(`world/mobs.ts`).
- 시험장 확인: 쟈알디 약공 콤보로 샌드백 1,000 → 868, AI 쟈알디가 12초 동안 플레이어 체력 1,000 → 790.
- 아직 안 한 것: 힘민체지정(플레이어 능력치 산출), 방어막, 속성·판정 형태 배율, 퍽.
