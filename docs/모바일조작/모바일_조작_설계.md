# 모바일 필드 조작 설계 (2026-10-28, 사용자 결정 기록 · 미구현)

## 사용자가 정한 것
- 폰이면 **무조건 가로로 돌린 뒤 전체화면으로 꽉 차게**. (10-23 「창 안에서만」 결정을 이번 지시로 바꿈. 나가는 길은 메뉴)
  - 안드로이드: 전체화면 + 가로 고정. 아이폰: 진짜 전체화면·가로 고정이 없어 플러그인 창을 화면 가득 + 게임 90도 회전.
  - 필드 중에는 창 머리·아래 메뉴·신분증 칸·유령 버튼 숨김.
- 조이스틱·버튼 **종류는 어디서나 고정** (본부라고 조사만 띄우지 않음). 쓸 수 없을 때는 흐리게.
- 버튼(7 + 자동): 약공격 · 강공격 · 회피 · 막기(분리, 누르는 동안) · 점프 · 고유(길게 = 충전) · 필살 · 조사. 그 밖의 PC 키는 모바일에서 뺀다.
- 반투명, **동그란** 버튼 (PC 네모 버튼 아님), 흔한 모바일 게임처럼.
- 배치(배치안3.png): 왼쪽 절반 = 떠다니는 조이스틱. 오른쪽 아래 구석 약공격(가장 큼), 그 왼쪽 회피, 회피 왼쪽 막기, 약 왼쪽 위 강공격, 약 위 점프, 강 왼쪽 고유/충전, 고유 오른쪽 위 필살, 오른쪽 위 조사. **아래 가운데 자동전투 + 그 옆 메뉴(나가기·설정)**. 왼쪽 위 얼굴·체력바·아이콘, 오른쪽 위 시각·잔고는 그대로.
- 대사창이 뜨면: 약공격 자리 = 「선택」, 점프 자리 = 「취소」, 나머지 숨김. 조이스틱 위아래로 선택지 이동, **선택지 글자 직접 누르기도 허용**.
- 직접 대사 입력(키패드): 모든 버튼 숨김·비활성. 아이폰(회전 표시)에서는 글칸을 바로 세워 키패드 위에.
- **조이스틱·버튼(대사창 선택지·입력칸 예외) 밖의 터치는 먹지 않게**. 두 손가락 확대·길게 누르기 메뉴·글자 선택·Risu 뒤로 쓸기도 막음.
- 자동전투: 대련 전투 AI(가상 버튼)가 내 캐릭터 버튼을 대신 누름. **조이스틱을 만지면 잠깐 직접 조작 우선, 놓으면 다시 자동**. 싸움 없는 곳에서는 흐림.
- 아래 가운데 버튼은 홈 바 제스처와 겹치지 않게 아래 끝에서 띄움. 조이스틱 영역은 자동·메뉴와 안 겹치게.

## 버튼 디자인 (시안, 결정 대기)
