# 홍보글 2판 검수 보고서 (2026-10-30)

대상: `docs/홍보/홍보글_2판_초안.md`  
비교 기준: 1판 `docs/홍보/아카라이브_홍보글.html` 전문(문장 단위)  
검수 방법: 1판 문장마다 2판에 있는지 확인하고, 내용은 **코드·자료 파일을 직접 열어** 대조함(서브에이전트 보고는 쓰지 않음). 2판에 새로 넣은 숫자·예시도 같은 방식으로 다시 확인함.

## 1. 무엇이 잘못됐었나

| # | 잘못 | 원인 |
|---|---|---|
| 1 | 「전화 걸기」「읽씹」을 「없는 기능」이라며 뺌 | 자료 수집을 맡긴 서브에이전트 보고를 코드 확인 없이 그대로 믿음. 실제로는 `src/ui/phone.ts`에 전화 걸기 화면, `src/core/phone.ts`에 읽음 상태·재촉이 있음 |
| 2 | 「모델은 언제 부르나」 표에 인물 기록·괴담톡·괴담넷·위키를 「본편만으론 안 됨」으로 적음 | 같은 원인. 실제로는 넷 다 메인 모델 선택 가능(`src/ui/phone.ts` 946, `src/ui/wiki.ts` 546, `src/ui/people.ts` 334, `src/core/gnet.ts` 144) |
| 3 | 1판에 있던 내용을 2판에서 내 판단으로 많이 뺌 | 「구호 줄이기」를 이유로 1판 문장을 지움. 사용자 지시는 「내용이 부실하니 다시 만들라」였지 빼라가 아니었음 |
| 4 | 「대련 난이도」를 뺐다가 되돌림 | 코드와 차이가 있어도 지우지 말고 결정을 받아야 했음 |
