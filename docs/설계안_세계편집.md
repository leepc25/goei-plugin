# 설계안 · 세계 데이터 구조화와 편집 창 (2026-10-27 결정 기록)

사용자와 2026-10-27에 정한 내용을 그대로 적는다. 숫자·방식은 전부 사용자 결정이며, 바꿀 때는 사용자에게 묻는다.
백업: 작업 전 상태는 브랜치 `backup/before-world-restructure` (v0.16.65 + 이미지 태그 수정 + 로어 예산 기본값).

## 0. 목표

- 플러그인을 **아무 봇에나 설치해 쓸 수 있게**: 글(지침·세계 로어·명부)은 전부 플러그인이 들고, 카드는 그림 + 매니페스트 + 사용자 수정분만.
- 로어북 편집은 Risu 로어북 편집기 대신 **플러그인 편집 창**에서 한다. 앞으로 입력은 여기서만.
- 릴리스는 사용자가 「릴리스해」 할 때 한꺼번에.

## 1. 카드에서 플러그인으로 옮기는 것

| 지금 카드 | 처리 |

| 🌐세계 `🏷️Tag` | 플러그인이 **조립**하는 지침. 틀(편집 가능, 자리표) + 형식 부분(상태창 칸 정의에서 생성, 편집 불가) |

카드에 남는 것: `Directory`(명부 = 세계 데이터 + 사용자 수정분), `Plugin manifest`, 그림 1,751장, 아이콘.

**기본 세계 + 덧쓰기**: 플러그인이 기본 세계 데이터를 내장하고, 카드 명부에 같은 기록이 있으면 카드가 이김. 카드에만 있는 기록은 추가. 그래서 깡통봇은 기본 세계로 바로 돌고, 고친 것만 카드에 남는다.

## 2. 기록 종류와 기본 칸

모든 기록 공통: 기본 칸은 **항상 존재**(원문에 없으면 빈 칸), 빈 칸은 조립에서 생략. 기록별 「칸 추가」(이름+값, 그 기록에만), 칸 순서 바꾸기(기본·추가 모두, 손잡이 끌기 + ▲▼ + 「기본 순서로」), 칸별 토큰 + 합계, 「조립 글 보기」, 「글로 가져오기」(붙여 넣은 글을 제목 동의어 표로 칸에 배정, 안 맞는 절은 그 제목 그대로 추가 칸), 읽기 전용 값은 맨 아래 회색.

### 요원 (22칸)
- 식별: 한글 이름 · 영문명 · 별칭 · 옛 영문명(읽기 전용) · id(읽기 전용)
- 소속: 소속 · 부서 · 직급 · 역할
- 기본: 나이 · 성별
- 외모: 체격 · 외모 · 복장
- 글: 성격 · 말투 · 배경 · 능력 (각 1칸, 결점은 성격 안)
- 소개 (Roster 한 줄)
- 노출·사진: 보이는 세력(roster_for) · 괴담톡 탭 · 사진 · 얼굴 · 자르기

조립: `### Character - 영문명` → `#### Identity`(Age/Gender/Organization(호칭 표)/Department/Role) → `#### Appearance`(Physique/Appearance/Outfit) → `#### Character` → `#### Voice` → `#### Background` → `#### Abilities` → 추가 칸(절 제목 = 칸 이름). 지금 로어북 글과 같은 모양.

### 조직
- 이름 · 코드 · 영문명 · 보이는 세력 · 괴담톡 탭 (있음)
- **소개** (Faction 요약 + 세력 상세 Identity/Overview 겸용)
- 세력 상세 7칸: 교리·방침 · 본부·거점 · 조직 구조 · 계급 · 모집·첫 접촉 · 핵심 자산·특성 · 인원
- 적대 조직 절은 칸을 두지 않고 **세력 관계 격자 메모**로 옮김
- 코드 표기·B00 이름 바꿔치기는 명부 코드·호칭 표로 플러그인이 찍음

### 세력 관계 (명부 메뉴에 화면 하나, 조직별이 아님)
- 격자: 행 = 보는 쪽, 열 = 대상. 칸 34px, 색 칸 + 두 글자(적대·경계·호의·우호, 중립은 빈 회색), 첫 행·첫 열 고정, 가로·세로 스크롤.
- 5단계 = 세력 평판 단계 그대로(적대·경계·중립·호의·우호). 격자 값이 **평판 시작값**(단계 경계 설정의 중간값). 지금 `relations-base.json`의 조직×조직 시작값을 이 격자가 대신한다.
- 방향 따로. 기본 대칭(한 칸 누르면 반대 칸도), 「방향 따로」 토글.
- 칸마다 메모(선택). 칸을 누르면 격자 아래에 "A00 → B00 · 적대 · 메모 글칸".
- 유저 조직 행·열은 현재 평판 단계로 칠하고 테두리로 구분(살아 있는 값).
- 프롬프트: 항상 "중립 아닌 쌍만 목록" + 메모 (`A00 → B00: 적대 — 협상 불가…`). 표 안 그림.

### 공통 규칙 (세력 전체 글칸 하나)
원문 「Doctrine and Relations」 중 쌍 관계가 아닌 문장(각 세력은 유저와 무관하게 움직인다, 적대·협력의 형태, 민간인은 모른다, 각 관리국은 자기를 관리국이라 부른다).

### 괴이 (7칸 + 기본)
- 이름 · 영문명 · 별칭 · 무작위 발생 후보(preset; 화면 이름 「무작위 발생 후보」)
- 정체 · 입장 조건 · 공간·구조 · 규칙 · 개체 · 생존·탈출 · 비고
- 63개 공통 머리말("Instructions for the Implementation… [Simulation-only] …")은 플러그인 고정 문구. 이식 때 본문에서 뗀다.
- 생존·탈출 정보는 원문에서 구조·구역·개체 안에 흩어져 있다 → 수기 이식 때 뽑아 모은다.

### 파밍(미스틱 사이트) (6칸 + 기본)
- 이름 · 영문명 · 별칭 · 무작위 발생 후보
- 정체 · 접근 · 위치와 외관 · 환경 · 이용 규칙(거래·대가) · 주인/운영자

### 부록
- 본 항목(기록 직접 연결, 이름 앞부분 매칭 대신) · 켜지는 조건(키·본 항목 함께·본 항목 필수·목표일 때·장소·요원·해금) (있음)
- 본문 1칸

### 거점·호칭·괴담톡 탭·시작 로어북
명부에 있는 그대로.

## 3. 지침

- GNet·Phone·Wiki·Directive·Visit: 플러그인 데이터(`src/data/guides/`)로 내장. 편집 창 「지침」에서 글칸 하나 + 자리표 안내로 보이고 고칠 수 있다(기기 설정). 카드 로어북은 읽지 않는다.
- Tag: 조립형. 틀(글칸, 자리표 `{anomaly_report}` `{incident_report}` `{mission_report}` `{agent_report}` `{status_format}` `{status_examples}` `{faction_pool}`), 형식 부분은 상태창 칸 정의 한 곳에서 지침·예시·파서를 모두 생성. 세력 풀은 명부 조직에서.
- Faction·Roster: 2장의 조립기.
- 이미지 지침: 이미 설정(기존).
- 모든 지침 화면에 조립 결과 토큰 합계.

## 4. 요청 삽입 (beforeRequest)

- 지금 Risu 로어북 순서: Tag 100 → Faction 101 → Roster 102 → 세력 200 → Start 399 → 특수 400 → 괴이 500 → 요원 600.
- 플러그인이 같은 순서로 한 덩어리를 만들어 **카드 로어북 덩어리 뒤**(없으면 시스템 프롬프트 끝)에 끼운다. description RP 지침은 그 앞.
- 시드(Start Lore)는 첫 전송에만(processRequest에서 이미 시드 표식을 다룸).
- 로어 고르기(어느 세력·특수·괴이·요원을 넣나)는 지금 로직 그대로, 예산도 그대로.

## 5. 편집 창

- 설정 탭/상단 버튼 「세계 편집」 → 화면을 덮는 별도 창. 패널은 뒤에 그대로, 닫으면 복귀. 창 안에서 또 팝업 없음(확인 대화만).
- 크기: 폭 브라우저 90%(설정 슬라이더, 기본 90) 최대 1600px, 높이 90%, 가운데, 뒤 어둡게. 760px 이하 전체 화면, 트리는 서랍.
- 왼쪽 트리(260px): 요원 · 조직(세력 관계 · 공통 규칙 · 호칭) · 괴이 · 파밍 · 부록 · 거점 · 지침(Tag·Directive·괴담넷·괴담톡·위키·필드·이미지) · 기타(괴담톡 탭 · 시작 로어북 · 위키 사전) · 설치·점검.
- 오른쏙: 공통 편집기(2장 공통 기능). 머리(이름·토큰 합계·조립 글 보기) → 기본 칸 → 추가 칸 → 읽기 전용 → 하단 고정 바(저장·되돌리기·삭제).
- 상단에 "저장됨 / 고친 것 N개". 저장은 전부 카드 명부.
- 코드: 공통 편집기 하나 + 종류별 칸 정의표.

## 6. 설정 탭 정리

옵션만 남김: 화면(편집 창 크기 포함) · 캐릭터 이미지 · 상황판(상태창 칸 표 포함) · 기능별(괴담넷·괴담톡·위키·필드·인물 기록) · 고급 · 업데이트. 명부 세그먼트와 이미지 지침 페이지는 편집 창으로.

## 7. 상태창 칸

- 칸 10개: 날짜 · 시각 · 날씨 · 기온 · 위치 · 목표 · 동행 · 투입 · 신분 · **잔고**.
- 설정 표: 칸마다 **사용**·**표시**. 날짜·시각·위치는 사용을 끌 수 없음(시간 계산·장면·위키 연결). 플러그인이 값을 채우는 칸(잔고·투입)은 사용을 끄면 그 기능도 꺼진다고 표시.
- 사용 끈 칸은 태그에서 **아예 뺌**(빈 칸 유지 요구 안 함). 모양은 `[Previous status]`가 알려 준다.
- 파서는 채팅 변수에 기록된 "메시지 N부터 칸 구성"으로 읽는다. 칸 수가 안 맞으면 알려진 모양(6·8·9·10)으로 재시도, 그래도 안 되면 날짜·시각·위치만 믿는다.

## 8. 가계부(돈)

- 잔고 = 상태창 10번째 칸. 진실은 플러그인 가계부(변수). `[Previous status]`의 잔고 칸을 가계부 값으로 덮어써 모델 오차를 매 턴 교정.
- 갱신기(인물 기록 보조 호출)가 본문에서 **금액이 적힌 거래**만 뽑아 가계부에 반영. 금액 없는 거래는 기록하지 않음. 메인 지침에 "돈이 오가면 금액을 적어라" 한 줄.
- 플러그인이 아는 고정 가격(필드 가계부·명부 품목표)은 직접 반영. 세계 고유 품목만 명부 품목표에 가격.
- 표시: 상태창 상자 목표 줄 아래 `₩ 1,230,000` 줄(+ 이번 턴 변화 작게), 「표시」 토글로 끔. 메인 패널 상황판 신분 옆 잔고 칩 → 가계부 내역·수정.
- 필드·경제 세션이 3-2장 문서를 쓰기로 함(연동 세부는 그 문서).

## 9. 깡통봇 설치·점검

- 「설치」: ⚙️설정 폴더·매니페스트·명부(기본 세계) 생성, 인사말 57개 렌더해 심기, 그림 1,751장(93MB) `release/pic`에서 받아 에셋 저장소에(진행 표시), 아이콘은 기존 유지 + 우리 것 추가 후 메인 지정(사용자가 바꾸면 안 건드림).
- 매니페스트에 폴더·명부 **key**를 적어 이름 대신 key로 찾기. 매니페스트 없어도 Directory 있으면 괴이 카드로 인정.
- 「점검」: 없어진 폴더·로어북 목록, 버튼으로 재생성(빈 것으로).
- 명부 비면 임무판·필드·이동은 쓸 게 없다고 기능별 안내.

## 10. 카드 빌드

- 로어북 폴더(세계·세력·요원·괴이·파밍·부록·위키)와 지침·자리 로어북 제거. 남기는 것: 명부(기본 세계 전체 포함) · 매니페스트 · 그림 · 아이콘.
- `backgroundHTML` 비움, `creator_notes` 비움, 인사말은 그대로 구움(카드 경로), minPlugin 올림.
- 카드 업데이트 장치는 명부·인사말·그림만 다룸.
