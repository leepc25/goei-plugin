# 필드 클립 이름 약속 (2026-10-26)

> **⚠ Claude 반성 · 2026-10-31 (사용자 지시로 문서마다 남김)**
> 2026-10-31 Claude는 다음 잘못을 저질렀다. 이 문서를 읽는 모든 Claude는 같은 짓을 하지 않는다.
> 1. **사용자 결정을 무시했다.** 콘쥬스는 사용자가 10-26에 20세로 정했고 인계서에도 적혀 있었는데, 옛 Claude 문장(teenage high school girl)을 근거로 화장실·샤워 그림을 거부하고, 사용자가 직접 뽑은 화장실 줄까지 팩에서 뺐다. 옷도 제복인데 교복이라고 단정했다.
> 2. **사용자 말에 토를 달고 같은 주장을 되풀이했다.** 사용자가 여러 번 지적했는데도 근거를 다시 확인하지 않아 몇 시간을 허비하게 했다.
> 3. **허락 없이 문서를 지웠다.** 「지침을 지우라」는 말만 듣고 목록을 보여 주지도 않고 96개를 지웠다가 되살렸다(결과물 삭제 금지 규칙 위반).
> 4. **문장을 덧대기만 하며 PixelLab을 낭비했다.** 이성해 점프 공격 5번 연속 실패, 이어폰 음악 120줄을 못 쓰게 만듦.
> 5. **답을 미루고 일을 멈춰 두었다.** 백그라운드로 돌릴 일을 돌리지 않고 대화만 했다.
>
> 지킬 것: 사용자 결정·위키가 근거다. 옛 Claude 자료는 근거가 아니다. 사용자 말에 토 달지 않는다. 무엇이든 지우기 전에 목록을 보여 주고 허락받는다. 실패하면 덧대지 말고 다시 쓰거나 바꾼다.


캐릭터 동작 그림이 들어오면 필드 세계가 **자동으로 그 동작을 켠다.** 그러려면 클립 폴더 이름이 아래와 같아야 한다. 클립이 없는 행동은 꺼져 있다(사용자 결정: 눈속임 금지 — 없는 동작을 대기 그림으로 때우지 않는다).

## 넣는 곳

```
game-src/field-clips/<인물 이름>/<클립 이름>/*.png     (파일 이름 순서 = 재생 순서)
```

- 인물 이름은 위키 표기(쟈알디, 잼트리 …). 일반 NPC는 `game-src/field-clips/npc/<원형 이름>/<클립 이름>/` (몹 연결 때 같은 규칙).
- 그림 방향: 오른쪽을 보는 그림(왼쪽은 코드가 뒤집음). 발 가운데 기준은 빌더가 첫 장 아래쪽으로 잡는다.
- 넣은 뒤 `python3 tools/build_visit_agents.py` → `game-pack/visit-agents/`(atlas.png·frames.json)가 다시 만들어진다. 대기는 기존 `idle` 폴더.

## 이름표

| 클립 | 뜻 | 반복 | 켜지는 행동 |
| --- | --- | --- | --- |
| `walk` | 걷기 | 반복 | 이동할 때 (없으면 서 있는 그림이 미끄러짐 — 이동은 끌 수 없어서 예외) |
| `run` | 뛰기 | 반복 | 급할 때·도망 |
| `work` | 서서 하는 업무 | 반복 | 욕구 「업무」 |
| `eat` | 먹기·마시기 | 반복 | 욕구 「허기」 (전투 섭취와 같은 그림 가능) |
| `rest` | 휴게실에서 쉬기 | 반복 | 욕구 「피로」 |
| `pee` | 소변 | 반복 | 욕구 「배설(소)」 |
| `poo` | 대변 | 반복 | 욕구 「배설(대)」 |
| `hobby` | 인물별 취미(독서·샌드백·PC 등) | 반복 | 욕구 「휴식」 |
| `talk` | 말하며 손짓 | 반복 | 수다·대화 |
| `greet` / `bow` | 손 인사 / 목례 | 한 번 | 주인공·아는 사람 처음 볼 때 |
| `gesture` `nod` `shake` | 손짓·끄덕·젓기 | 한 번 | 대화 중 |
| `surprise` | 놀라기 | 한 번 | 위협·소란 |
| `stretch` `sigh` `armcross` `think` `scratch` | 기지개·한숨·팔짱·생각·머리 긁기 | 팔짱·생각만 반복 | 오래 대기할 때 |
| `laugh` `angry` | 웃기·화내기 | 한 번 | 대사 태그·사건 |
| `scared` `flee` `cower` | 겁먹기·도망·웅크려 떨기 | 반복 | 몹·인물 반응 |
| `down` `getup` | 쓰러짐·일어나기 | 한 번 | 맞았을 때 |

전투 동작(약·강·점프·회피·막기·기술·충전·필살)은 에일린 시험판 형식(`src/game/action/eileen/`)을 따른다 — 전투 AI 연결 때 따로.
