# 쟈알디 완전판 제작 기준서

2026-10-20. 이 대화에서 확정한 최신 지시를 통합한다. 충돌하는 과거 잠정 기준보다 이 문서를 우선한다. 최우선 합격 조건은 **통일성**이다. 이 문서는 완료 보고가 아니다.

## 1. 고정 규격과 통일성

- 원본 중립 정자세 키 128px, 게임 표시 정수 2배(256px). 256px 원본안은 비교 후 채택하지 않았다.
- 제한된 픽셀에서 읽히는 성인 게임 체형. 약 6등신을 출발점으로 삼되 장신·가는 팔다리의 실제 인체 비율을 우선하지 않는다.
- 한 신규 기준표의 얼굴, 두개골, 목, 어깨, 흉곽, 허리, 골반, 위팔, 전완, 허벅지, 종아리, 손발, 복식, 팔레트를 모든 자세·컷인에 유지한다.
- 원작 `assets/agents/Jyaldi_default.avif`와 설정의 긴 흑발·붉은 눈·검은 바지 정장·흰 셔츠·검은 넥타이·장갑을 따른다. 생성 결과를 원작 확정 설정으로 취급하지 않는다.
- 이전 반려 생성 도트는 신규 작화 입력으로 쓰지 않는다. 해상도 비교작도 승인된 최종 체형이 아니다. 신규 제작에서 정한 공통 기준표는 이후 모든 시트의 필수 참조다.
- 같은 바닥 위치·카메라·배율에서 모든 전환을 비교한다. 동작별 확대·축소, 머리 크기를 맞추기 위한 전신 리사이즈, 앉은 자세를 중립 키로 늘이기 금지. 현행 깊이 배율도 공용 제작 시 제거한다.
- 신체 투영 길이의 변화와 실제 신체 길이 변화는 구별한다. 관절 굽힘·원근 단축에는 자세 근거가 있어야 한다. 명백한 체격 튐은 숫자 평균이나 자동 검사로 면제하지 않는다.

## 2. 작화와 동작 원리

- 본체는 완성된 **전신 프레임**이다. 고정 몸통+팔다리 회전, 팔·다리 늘이기, 관절 구체 합성, 몸통 줄 단위 왜곡으로 움직임을 대체하지 않는다.
- 발 지지·중심 이동→골반/허리→흉곽/어깨→팔의 힘 전달. 보행은 반대 손발, 골반과 어깨의 반대 회전. 달리기는 전진 기울기와 추진·비행·착지. 앉아 이동도 지지발 교대.
- 큰 명암 덩어리와 실루엣을 먼저 만든다. 노이즈성 잔주름·불필요한 작은 색점·축소하면 사라지는 디테일을 줄인다. 고해상도 그림을 감색·축소했다는 이유로 도트 완성이라고 판단하지 않는다.
- 준비→가속→접촉→정지→후속→회수의 완급. 강한 3타는 전신 회전·전진과 읽히는 접촉 자세를 갖는다. 약약강 실제 팔은 좌우좌 또는 우좌우.
- 프레임 개수는 품질 보증이 아니다. 필요한 핵심 자세부터 만들고 전환에 필요한 그림만 추가한다. 똑같은 그림 복제로 장수를 늘리지 않는다.

### 전투 규칙

- 근접과 원거리는 별도 명령·키·터치 버튼. 수동 근접 입력이 거리 때문에 총격으로 변하지 않는다. 공중도 근접/원거리 구분. 자동 AI는 같은 두 명령을 상황에 맞게 선택한다.
- 구현 초안 키: Z 근접, D 원거리, R 재장전, G 잡기/놓기, 방향+G 던지기. 기존 X 점프/C 능력/A 방어/S 필살/QWE 아이템/Shift 회피·달리기 유지. 키 재지정은 후속 지원이며 명령 계층은 키와 분리한다.
- 입력 예약, 연계 창, 취소 가능/불가 구간, 헛침/명중 차이. 공격·피격·몸 밀기·잡기 영역과 깊이/높이/방향 분리.
- 타격 이벤트와 접촉 그림 동기화, 중복 피해 방지, 히트스톱·효과·밀림. 무적·슈퍼아머·경직 구분. 무한 공중 연계 방지와 기상 보호.
- 잡기 거리·대상 크기·유지 시간·탈출·실패 규칙. 던진 적의 적/벽/바닥 충돌, 아군 오인 타격 방지.
- 적도 발견/접근/공격 예고/공격/회수/피격/다운/기상/퇴장, 원거리 적은 조준/사격/재장전. 플레이어의 잡기 동작만 만들고 상대 반응을 생략하지 않는다.

## 5. 섭취와 치료: 전투·일상 공용

- 손으로 먹기: 꺼내기→입으로 가져가기→베어 먹기/씹기→정리.
- 식기로 먹기: 그릇 들기→숟가락/포크 사용→먹기→내려놓기.
- 병: 꺼내기→뚜껑 열기→입 접촉/기울여 마시기→닫기/정리.
- 캔: 꺼내기→따기→마시기→정리. 컵: 잡기→들기→마시기→내려놓기.
- 경구약: 꺼내기→복용→필요시 물→포장 정리.
- 붕대: 환부 확인→꺼내기→감기/고정→복귀. 소독/도포: 확인→사용→정리.
- 주입기: 꺼내기→부위 사용→회수/정리. 타인 치료: 접근→몸 낮추기→확인/치료→마무리/일어서기.
- 손·입·소품 접점과 소품 방향을 동작별로 검수한다. 몸을 찌그러뜨리는 섭취 표현 금지.
- 음식 종류·병 색은 동일 행동에 소품만 교체 가능. 잡는 법·사용법이 다르면 별도 동작. 일상은 반복/여유 있는 유지, 전투는 사용시간/피격/취소 규칙.
- 효과와 아이템 소비는 지정 이벤트에 한 번만 발생. 시작 즉시 회복하고 먹는 그림만 뒤늦게 재생하지 않는다. 중단 전후 소비 정책을 명시한다.

## 6. 최적화

- 우선순위: 통일성·가독성·힘 전달 유지→여백 트리밍→동일 프레임 중복 제거→패킹→필요한 자산만 로딩→표시 비용 조정.
- 본체의 공용 단위는 완성 전신 자세·반복 구간·동일 행동이다. 몸통 고정+팔다리 회전 최적화 금지. 소품·탄환·파괴 효과는 분리하되 손 접점을 검수한다.
- 전투/일상에서 같은 행동은 같은 본체 프레임과 다른 시간표·규칙을 사용한다. 방향 반전은 비대칭 복장·무기·손 순서를 검토한다.
- 적/NPC는 역할별 필요한 동작만 갖는다. 30명에게 모두 쟈알디의 전체 능력·생활 목록을 복사하지 않는다.
- 동작별 초기 그림 예산: 대기 4~6, 보행 각 6~8, 기본 한 타 4~7, 강공격/던지기 6~10, 점프 6~10, 피격 한 종류 2~4, 다운/기상 8~12, 생활 한 종류 4~8. 쟈알디 200~350개 고유 본체 그림은 검토용 추정이며 최소 제작량이나 확정 상한이 아니다.
- PNG 바이트, 아틀라스 RGBA, 캔버스/캐시, 전체 런타임 메모리를 구분한다. 30명 저장량과 동시 상주량도 구분한다. 같은 적 다수는 그림 공유.
- 수동 60/저사양 30FPS 표시와 고정 전투 계산 분리, 숨김/닫힘 시 실행 중지, 종료 시 자산/이벤트 정리. 반복 열기·닫기/장시간 자동/채팅 병행을 검증한다.

## 7. 제작·검수 순서와 완료 조건

1. 신규 기준표와 부위 치수·팔레트 정의. 정면/측면/게임 시점의 동일 인물 확인.
2. 대기·보행·달리기·앉기·타격·사격 대표 자세를 나란히 검수. 불일치면 양산 전 수정.
3. 같은 기준으로 계열별 제작, 각 시트에 원본 출처·공통 배율·발 기준점·손 접점·행동 ID 기록.
4. 동작별 준비/유지/접촉/회수/중단을 엔진에 연결. 전투·일상·메뉴·직접 입력으로 도달 가능해야 한다.
5. 모든 동작을 확인하는 뷰어와 실제 플레이 장면 제공. 느린 재생·한 그림씩·같은 바닥/배율 비교 포함.
6. 근접/원거리 분리, 잡기/던지기, 재장전, 소비 이벤트, 전환/중단, 저장 복원, 수동/자동/터치 검증.
7. 타입/동작 검사 통과와 시각 품질 합격을 구분한다. 이름만 있는 동작, 동일 그림 반복, 구형 반려 그림 혼합, 스크린샷만으로 최종 완료 보고 금지.
8. 최종 전달은 신규 그림·전체 동작·입력이 실제 반영된 단일 플레이 HTML, 공용 소스, 동작별 완성/검증 현황, 용량 보고. 미완성은 명시한다.

작업 저장: 기준서를 먼저 커밋하고 제작을 이어간다. 변경은 쟈알디 게임 범위로 제한하며 Claude 메인 봇 변경과 충돌을 확인한다. 공개 업로드가 도구에서 차단되면 로컬 작업을 계속하고 실제 저장 위치를 정확히 보고한다.
