# 로그라이크 전투·성장 설계 (하데스 벤치마킹, 1판 · 2026-10-29)

검수 전 설계안이다. 숫자는 모두 「처음 값」이고, 표의 **결정 필요** 칸은 사용자가 정한다. 구현은 괴이를 넣을 때 하고, 지금은 13장의 기틀만 만든다.

## 0. 이미 정해진 것 (사용자 2026-10-29)

- **보이는 스탯 칸(힘·민·체·지·정)과 레벨업은 없다.** 화면에는 체력바와 강화 설명만 보인다.
- 안쪽에는 하데스처럼 **숨은 능력치**(체력·공격·방어·속도 등)가 있다.
- 괴이 스테이지를 깨거나 이벤트를 하면 **강화 효과 3개 중 1개**를 고른다. 여러 종류를 섞어서 낸다.
- **죽으면 이번 판의 강화는 모두 사라진다.**
- 강화가 쌓이는 만큼 **괴이 난이도도 판이 진행될수록 오른다.** 무한히 쌓여 무적이 되지 않는다.
- 그래서 **강화 0개 상태의 인물 능력치(초기값)** 가 밸런스의 출발점이다.
- 마을 시민과 이름 있는 NPC도 각자 설정에 맞는 값을 가진다.
- 인물마다 처음부터 붙은 **고유 퍽**을 둘 수 있다.
- **각 세력 요원은 기본 상태의 플레이어보다 「적당히 강함」 또는 「상당히 강함」** 이어야 한다.

## 1. 하데스 조사

출처는 끝의 「출처」. 「확인 못 함」은 검색으로 확인하지 못하고 기억에 기댄 것이다.

### 1-1. 한 판의 구조

- 지역 4곳을 정해진 순서로 지난다: 타르타로스 → 아스포델 → 엘리시움 → 스틱스 신전 → 최종 보스.
- 한 지역은 방 12~20개다. 각 지역은 약 30개의 손으로 만든 방 중에서 뽑는다. 한 판은 20~40분이다.
- 방을 깨면 다음 방 문이 열리고, **문에 그 방 보상이 미리 그려져 있어** 보상을 보고 길을 고른다.
  - 금색 테두리 = 이번 판 보상(은혜·망치·석류·심장·돈), 파란 테두리 = 판 밖 재화(어둠·보석·열쇠·넥타르).
  - 해골 표시 = 더 어려운 싸움, 더 좋은 보상(미니보스, 신들의 시련 등).
- 지역 중간에 미니보스, 끝에 지역 보스가 있다. 보스 뒤에는 회복 샘이 있다.
- 특수 방: 카론의 상점(판 돈으로 산다), 혼돈의 문(체력을 내고 들어가 저주+축복), NPC 방 등.

### 1-3. 숨은 수치와 피해 공식

- 시작 체력은 50(확인 못 함). 심장 +25, 거울 「두꺼운 피부」 랭크마다 +5.
- **피해 = 기본 피해 × (1 + 피해 보너스 합).** 보너스는 **더한다.** 공격 은혜 +50%, 끓는 피 +50%, 뒤치기 +50%면 +150%. 초기 버전은 보너스를 곱했는데 피해가 폭주해서 더하기로 바꿨다.
- 치명타만 곱한다.
- 받는 피해 감소, 회피 확률, 이동 속도, 대시 횟수, 치명 확률이 은혜와 거울 특성으로 붙는다.

### 1-4. 적

- 지역마다 고유 적이 있다. 같은 적의 강화판은 방패·속도·새 공격 하나를 더 가진다.
- **엘리트는 체력 위에 방어막(노란 막대)이 있다.** 막이 남은 동안은 경직·밀쳐내기를 받지 않는다. 막을 깨면 잠깐 휘청인다. 막은 피해를 줄이지 않는 두 번째 체력이고, 넘친 피해는 버려진다.
- 미니보스(수호자)와 지역 보스.

### 1-5. 판 밖 성장

- **밤의 거울**: 판에서 모은 「어둠」으로 영구 특성을 산다. 특성마다 두 갈래 중 하나만 켠다.

| 특성 (갈래 A / 갈래 B) | 효과 |
| --- | --- |
| 그림자 존재 / 불타는 존재 | 뒤치기 피해 +10%·랭크(5) / 다치지 않은 적에게 +15%·랭크(5) |
| 지하의 활력 / 어둠의 재생 | 방 나갈 때 체력 +1·랭크(3) / 모은 어둠의 30%만큼 회복(2) |
| 죽음 거부 / 끈질긴 거부 | 죽을 때 체력 50%로 버팀, 랭크마다 1번(3) / 30%로, 방마다 1번(1) |
| 더 큰 반사 / 무자비한 반사 | 대시 +1 / 맞기 직전 대시하면 2초 동안 피해·회피 +50% |
| 두꺼운 피부 / 높은 자신감 | 체력 +5·랭크(10) / 체력 80% 이상일 때 피해 +5%·랭크(5) |
| 깊은 주머니 / 황금 손길 | 판 시작 돈 +10·랭크 / 지역을 깰 때 가진 돈 +5% |
| 특권 / 가문의 총아 | 상태 이상 2개 이상 걸린 적에게 +20% / 은혜 준 신마다 +2.5% |
| 올림포스의 호의 등 | 은혜 등급이 높게 나올 확률 +% |
| 정해진 권위 / 정해진 설득 | 다음 방 보상 바꾸기 / 은혜 후보 다시 뽑기 |

  - 처음 4개는 무료, 나머지는 열쇠로 둘씩 열고 어둠으로 랭크를 산다.
- **무기 형상**: 같은 무기의 다른 판. 티탄의 피로 연다.
- **처벌의 계약(Heat)**: 스스로 난이도를 올려 보상을 더 받는다. 합계 최대 63.

| 조건 | 1랭크당 |
| --- | --- |
| 고된 노동 | 적 피해 +20% (5랭크) |
| 지속되는 결과 | 회복량 −25% (4랭크) |
| 편의 수수료 | 상점 가격 +40% (2랭크) |
| 배심원 소환 | 일반 싸움 적 수 +20% (3랭크) |
| 극단적 조치 | 지역 보스가 새 기술을 씀 (지역 하나씩) |
| 체조 | 적 체력 증가 |
| 피해 통제 | 모든 적에게 처음 한 대를 막는 방패 |
| 승인 절차 | 은혜·강화 후보 하나 줄어듦 |
| 빡빡한 마감 | 지역마다 제한 시간(1랭크 9분) |
| 복리후생 | 방어막 적이 특전을 가짐 |

## 3. 숨은 능력치 (전투 몸 하나)

모든 싸우는 몸(주인공·AI 요원·필드 몹·괴이)이 같은 묶음을 쓴다. 코드의 `AgentStats`(`engine/progression.ts`)를 넓힌다.

| 값 | 뜻 | 플레이어 기본 | 코드에 걸리는 곳 |
| --- | --- | --- | --- |
| hp | 최대 체력 | **결정 필요 (안: 1,000)** | 체력바 |
| shield | 방어막: 남은 동안 경직·밀림 없음, 깨지면 잠깐 휘청 | 0 | 새로 (`applyHit` 앞) |
| dmg.melee | 근접 피해 보너스 (더함) | 0% | `hurtTarget` |
| dmg.ranged | 사격·투척 피해 보너스 | 0% | 〃 |
| dmg.skill / charge / super | 고유기·충전·필살 보너스 | 0% | 〃 (타격마다 출처 꼬리표) |
| dmg.el.<속성> | 속성 피해 보너스 | 0% | 〃 |
| crit / critDmg | 치명 확률 · 치명 배율(곱함) | 0% · 1.5배 | 새로 |
| guard | 받는 피해 감소 (최대 60%) | 0% | `applyHit` (이미 `defense`) |
| resist.<속성> | 속성별 받는 피해 감소 | 0% | 새로 |
| speed | 이동·회피 속도 | 1.0 | 이미 (`speedMul`) |
| dash | 연속 회피 횟수 | 1 | 엔진 회피 |
| cdr | 기술 쿨 감소 | 0% | 엔진 `setCd` |
| sp | 필살 게이지 차는 속도 | 1.0 | 이미 (`spMul`) |
| poise | 경직 저항 0~3 (방어막과 별개, 보스·괴이 전용) | 0 | 이미 |
| lifesteal / regen | 흡혈 · 방 넘길 때 회복 | 0 | 새로 |
| revive | 죽음 거부 횟수 | 0 | 새로 |

**쌓는 규칙 (하데스와 같게)**
- 피해 보너스는 같은 칸끼리 **더한다**: 피해 = 기본 × (1 + 근접 보너스 합 + 속성 보너스 합 + …). 곱하면 폭주한다(하데스 초기 교훈).
- 치명만 곱한다.
- 받는 피해 감소는 더하되 최대 60%.
- 피해 기본값은 테스트룸에서 실측해 맞춘 값 그대로다(약공 14~27, 충전 75/150/240, 고유기 270, 필살 380/480).

## 4. 인물 초기값 (강화 0개)

기준은 **플레이어 기본 상태 = 1배**다. 세력 요원·NPC는 이 배수로 정한다. 숫자는 안이다.

| 등급 | 누구 | 체력 | 주는 피해 | 방어막 | 그 밖 |
| --- | --- | --- | --- | --- | --- |
| 시민 | 시민·학생·상인·의사·간호사·청소부, 비전투 이름 인물 | 0.15배 (150) | 0.3배 | 없음 | 싸우지 않고 도망 |
| 거리 | 불량배·취객 | 0.3배 | 0.5배 | 없음 | |
| 훈련 | 경찰·경비·협회 직원·가짜 관리국 사원·관리국 직원 | 0.6배 | 0.8배 | 없음 | 막기·회피 씀 |
| **기본 플레이어** | 강화 0개 주인공 | **1배 (1,000)** | 1배 | 없음 | |
| 요원 「적당히 강함」 | 세력 이름 요원 대부분, 백일몽·프리랜서 정예 | 1.3배 | 1.2배 | 체력의 20% | 전투 AI 보통~어려움 |
| 요원 「상당히 강함」 | 간부·정예(쟈알디·고르고디오·이도형·곽성주·노기균·진나솔 등) | 2배 | 1.5배 | 체력의 40% | 전투 AI 어려움, 고유 퍽 강함 |
| 재난급 | 세크리엠·살라딘·탐미주의 | 보스 규칙 | 보스 규칙 | 여러 겹 | 단계 패턴 |

- 같은 등급 안에서 역할로 조금씩 다르게 한다(역할은 `docs/밸런스_분류.json`에 이미 있다): 방패형 체력 +20%·받는 피해 −10%, 타격형 속도 +10%, 사격형 사격 +10%, 지원·제어형은 기술 쿨 −10%.
- 플레이어로 고를 때도 그 요원의 역할 보정은 그대로 붙는다(고유 퍽 포함). 등급 배수(1.3배·2배)는 **적·동료로 나올 때만** 붙는다.
- 이 표로 계산한 「몇 대에 쓰러지나」(플레이어 강화 0개 기준):
  - 시민: 약공 콤보 한 세트(약 100) 반.
  - 훈련: 콤보 6세트, 고유기 두 방 반.
  - 요원 「적당히 강함」: 방어막 260을 깬 뒤 체력 1,300. 고유기 6방 남짓.
  - 요원 「상당히 강함」: 방어막 800을 깬 뒤 체력 2,000. 플레이어 혼자서는 강화 없이 어렵다(의도).
- **결정 필요**: 플레이어 기본 체력(1,000), 등급 배수, 방어막 비율.

## 5. 판 안 강화 (3개 중 1개)

### 5-1. 언제 받나
- 괴이 스테이지(방) 클리어, 이벤트(생존자 구조·괴이 규칙 풀기·본부 지원 요청 등), 미니보스·보스.
- 문에 보상을 미리 보여 주고 길을 고르게 한다(하데스 문 표시). 해골 = 어려운 방, 좋은 보상.

### 5-2. 무엇이 나오나 (후보 3개는 아래에서 섞어서)

| 종류 | 예 | 비고 |
| --- | --- | --- |
| **계통 강화** | 「폭발: 약공 마지막 타에 작은 폭발」 | 아래 계통 6개 × 기술 칸 |
| 정제 | 가진 강화 하나의 등급·수치 +1 | 석류 |
| 기술 변형 | 「고유기가 두 번 연달아 나감」, 「충전 2단이 넓어짐」 | 망치. 한 판 최대 2번. 새 그림 없이 수치·판정·이펙트만 |
| 체력 | 최대 체력 +10% / 즉시 회복 | 심장·샘 |
| 판 돈 | 상인에게 쓸 돈 | 오볼 |
| 판 밖 재화 | 해금용 | 어둠 |

### 5-3. 계통 6개 (하데스의 신 자리)

| 계통 | 거는 상태 (적에게) | 예 |
| --- | --- | --- |
| 단련 (물리) | 치명·출혈 | 약공 치명 +10%, 강공 출혈 |
| 폭발 | 화상(지속 피해)·연쇄 폭발 | 고유기 끝에 폭발, 쓰러뜨리면 터짐 |
| 염동 | 띄우기·고정 | 사격 맞은 적을 잠깐 띄움 |
| 정신 | 공포·혼란 | 충전 맞은 적이 2초 겁먹음 |
| 신성 | 정화·괴이 특효 | 괴이에게 피해 +30%, 맞으면 디버프 하나 지움 |
| 괴이 | 흡혈·저주 | 피해의 3% 회복, 저주 걸린 적 받는 피해 +15% |

- **기술 칸**(하데스 다섯 칸 자리): 약공 · 강공 · 사격 · 충전 · 고유기 · 필살 · 회피. 한 칸에 한 계통만, 새로 받으면 바꿔 끼운다.
- **등급**: 일반·희귀·영웅·전설. 수치가 1 / 1.3 / 1.6 / 2배.
- **조합 강화**: 두 계통을 함께 가지면 나오는 것(하데스 조합 은혜). 나중에.
- 지금 기술마다 속성 꼬리표가 없다(모두 「근접」으로 잡힘). 계통 강화가 「폭발 피해 +」처럼 걸리려면 타격마다 출처(평타·사격·충전·고유기·필살)와 속성 꼬리표가 있어야 한다. 엔진에서 피해가 나가는 곳은 세 군데뿐이라 붙이기 쉽다(평타·기술 타격·탄환).

## 6. 괴이 난이도 보정 (점점 강해짐)

- **깊이 보정**: 판에서 지난 구역 수에 따라 적 체력·피해가 오른다. 안: 구역마다 체력 +15%, 피해 +8%.
- **강화 수 보정**: 받은 강화 개수에 따라 엘리트(방어막) 비율과 적 수를 올린다. 안: 강화 3개마다 엘리트 확률 +5%p, 적 수 +1.
- **위험 단계**(하데스 계약): 판을 시작할 때 고르는 조건. 적 피해 +20%, 회복 −25%, 적 수 +20%, 방어막 추가, 보스 새 기술, 강화 후보 하나 줄임. 단계마다 보상이 늘어난다.
- 괴이는 사람과 같은 숨은 능력치 묶음에, 괴이 전용으로 **속성 저항**(예: 물리 −30%, 신성 +50%)과 경직 저항을 더 갖는다.
- **결정 필요**: 구역당 보정 크기, 강화 수 보정을 쓸지.

## 7. 판 밖 성장

하데스처럼 **숫자는 조금, 할 수 있는 건 많이**.

- **해금 재화**: 판에서 얻어 본부에서 쓴다. 이름은 설정에 맞게(예: 「잔흔」).
- **본부 해금**(거울 자리): 시작 체력 +, 죽음 거부 1회, 회피 +1, 강화 후보 다시 뽑기, 문 보상 바꾸기. 갈래 둘 중 하나만.
- **요원 숙련**(기본기획서 16.3): 그 요원으로 출동할수록 기술 변형 후보·고유 퍽 강화가 열린다.
- **동료**: 호감이 높은 요원을 지원으로 부른다(하데스 「소환」 칸).

## 8. 고유 퍽

인물마다 처음부터 붙은 효과 하나. 강화와 같은 숨은 능력치·조건 자리를 쓴다. 형식과 예만 둔다(정식 목록은 괴이 넣을 때).

| 형식 | 예 |
| --- | --- |
| 수치형 | 데드폴: 죽을 때 한 번 버팀(부활 3회 설정) |
| 조건형 | 스팡달: 등 뒤에서 때리면 피해 +50% |
| 계통형 | 쟈알디: 폭발 계통 강화가 1등급 높게 나옴 |
| 기술형 | 에일린: 사격 과열 한계 +30% |

- 근거는 `docs/기술_재설계/<인물>.md`·위키 설정에서 찾는다.

## 9. 판 구조 (안)

- 본부 필드 → 출동 → 구역 3~4곳(구역마다 방 8~12개, 미니보스, 보스) → 귀환.
- 방마다 끝나면 문 2~3개(보상 표시) 중 하나.
- 죽으면 본부 의무실로 후송. 판 안 강화·판 돈은 사라지고, 판 밖 재화는 남는다.
- 한 판 목표 20~40분.

## 10. 숫자 예 (플레이어 강화 0 → 판 끝)

- 강화 0: 체력 1,000, 약공 20, 고유기 270.
- 판 끝(강화 10개쯤): 고유기 보너스 +60%, 폭발 +40%, 치명 15% → 고유기 약 540, 치명이면 810. 체력 1,300.
- 그때 적(깊이 4구역): 체력 +60%, 피해 +32%. 「적당히 강함」 요원이 체력 약 2,100에 방어막 400.

1. 플레이어 기본 체력 (안: 1,000)

3. 계통 6개 이름과 효과 방향 (5-3)

6. 난이도 보정 크기 (6장)
7. 판 구조 (9장: 구역 수, 방 수)
8. 판 밖 해금 범위 (7장)

## 13. 지금 만들 기틀 (결정 뒤, 강화·괴이 구현은 나중)

1. **숨은 능력치 묶음** `src/game/combat/body.ts`: 3장 값과 쌓는 규칙(더하기·치명 곱·감소 최대). 강화가 붙을 자리(수정자 목록)만, 실제 강화는 없음.
2. **인물 초기값 표** `src/game/combat/roster-stats.json`: 126명 등급·역할 보정·고유 퍽 칸(비움). 4장 표로 채움.
3. **엔진 연결**: 주인공·AI 요원·필드 몹이 이 묶음을 읽는다. 지금 박혀 있는 주인공 220·AI 160·몹 등급 체력(50~170)을 표 값으로 바꾼다.
4. **타격 꼬리표**: 평타·사격·충전·고유기·필살 출처를 타격마다 붙여 넘긴다. 속성은 칸만(값은 계통 정할 때).
5. **방어막**: 정예·간부에게 노란 막대, 남은 동안 경직·밀림 없음, 깨지면 휘청.
6. 난이도 보정·강화 고르기 창·판 구조는 자리(함수 이름과 빈 표)만.
