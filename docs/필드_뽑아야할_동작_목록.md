# 필드에서 뽑아야 할 동작 목록 (2026-10-26)

> 이 대화(필드 세계 설계 스레드)에서 「뽑아야 한다」고 나온 동작을 모은 것. 이름 있는 인물 기준. 일반 NPC(몹) 71명은 그림·동작을 이미 뽑았다(사용자).
> 근거: `docs/필드_세계_NPC_설계.md` 5-1, `docs/인계/쟈알디/쟈알디_동작_최종세트_2판.md`, `docs/전투_AI_설계.md`.

## 1. 생활 (욕구용 — 사용자 결정: 눈속임 없이 실제 동작)

| 동작 | 쓰는 곳 | 비고 |
| --- | --- | --- |
| 걷기 | 모든 이동 | 지금은 서 있는 그림이 미끄러지듯 움직임 |
| 업무(서서) | 사무실·직무 자리 | 앉아서 하는 업무는 앉기 논의 뒤 |
| 먹기 | 허기 | 「섭취」 하나로 전투 아이템 사용과 같이 씀 |
| 휴게실에서 쉬기 | 피로 | 쉬는 장면 동작을 뽑으면 넣음 |
| 배설 — 소변 | 화장실 | 대변과 장소·시간 다름 |
| 배설 — 대변 | 화장실 | |
| 취미(인물별) | 휴식 | 에일린 독서, 고르고디오 샌드백, 큐라스 PC, 로제몬 기둥에 기대 과자 등 |
| 위생(목욕) | — | **보류** |

## 2. 반응·감정 (NPC 자동 행동용, 쟈알디 2판 12종)

인사/목례 · 손짓 · 끄덕 · 젓기 · 놀라기 · 기지개 · 한숨 · 팔짱 · 생각 · 머리 긁기 · 웃기 · 화내기

## 3. 전투 (쟈알디 2판 + 에일린 시험판 규칙)

- 약 3타 + 강 1타 (인물마다 따로)
- 점프 3종(제자리·방향·달리다), 점프 공격, 2단 점프
- 돌진 공격(달리다 약), 회피, 막기
- 뒤로 날아가 쓰러지기, 누운 상태, 스턴(헤롱헤롱)
- 고유기술, 충전기, 필살기, 원거리

## 4. 미룬 것

- 앉기: 동작을 뽑은 뒤 다시 논의.
- 목욕: 보류.
