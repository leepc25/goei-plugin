## 1. 꼭 지킬 사용자 규칙

1. **한국어로만, 짧게 답한다.** 코드 이름만 영어로 둬도 돼요.
2. **시키지 않은 일을 시작하지 않는다.** 질문에는 답과 추천만 하고 멈춰요. 「해 / 만들어 / 계속 가 / 릴리스해」라고 해야 시작해요. 「기다려 / 아직」이면 아무것도 안 해요. 「계속 가」를 들은 계획은 끝까지 하고, 특이한 점만 기록해요.

4. **배경은 가구 포함 완성 장면 → 같은 장면에서 오브젝트 분리 순서다.** 편집·합성·변환·리사이즈·코드 검증을 허용한다. 화풍 기준은 `game-src/art/start-room/design.png`, 현행 제작 규정은 `docs/필드_그림_통합_지침.md` 0-1절이다. GPT에 붙여 넣을 말에는 저장소 `leepc25/goei-plugin`(main)과 전체 URL을 넣는다.

7. **문서는 앱에서 열 수 있게 준다.** GitHub 링크만 주지 말고 파일을 첨부하거나 아티팩트로 줘요.

## 3-1. 리스 상황 재현 시험 도구 (2026-10-25 추가, 필수)

리스에서만 생기는 문제(좁은 창, 상황창 좌우 메뉴 줄, 필드 모드, NPC 대화창, 임무 창)는 시연판(1280×720)으로는 재현이 안 돼요. 필드 게임을 고치면 아래로 꼭 확인해요.

- **`tests/field-harness.mjs`**: 리스가 받는 게임 코드(`dist/game/goei-game.js`)와 팩(`dist/game/*.pack`)을 리스 상황창과 같은 틀(왼쪽 메뉴 줄 · 가운데 필드 · 오른쪽 신분증 줄, 기본 창 1873×1082)에 올리고 가짜 bridge(visit·field·talk·저장·팩·전체화면)를 줘요. 다른 시험에서 `import { openField, enterHub } from './field-harness.mjs'`로 쓰고, `node tests/field-harness.mjs [폭] [높이] [사진폴더]`로 본부까지 들어가 사진을 찍어요.
- **`tests/field-sweep.mjs`**: 전수 순회. 모든 장면의 문·자리에 다가가 안내가 뜨는지, E로 들어가지는지·창이 열리는지, 엘리베이터 층 이동, 오류 유무를 한 번에 표로 내요. 10분쯤 걸려요(`npm run build` 뒤 `node tests/field-sweep.mjs [사진폴더]`).
- 순서: `npm run build` → `npm test` → `node tests/engine-browser.mjs` → 필드를 건드렸으면 `field-harness`/`field-sweep`.
- 주의: 순회를 백그라운드로 돌리고 `pgrep -f field-sweep`으로 기다리면 그 명령 줄 자신이 걸려서 영원히 안 끝나요. 출력 파일을 직접 확인해요.

## 5. 진행 중인 일 ① 쟈알디 동작 세트 (가장 최근, 결정 대기)

사용자가 PixelLab에 **모든 캐릭터를 8방향으로 등록**해 두었고, 쟈알디만 동작 46개를 먼저 만들었어요(PixelLab 캐릭터 목록은 API `GET /v2/characters`, 쟈알디 id `5a76e1de-d1c9-4051-97c8-1deb5b58ab71`).

**테스트룸** `docs/인계/쟈알디/쟈알디_테스트룸_v2.html` (브라우저로 바로 열림, 4.7MB 한 파일. 옛 아티팩트 사본)
- 방향키 이동, Shift 뛰기, Z 연타, X 장풍, C 짧게=고유기술·길게=충전, S 필살기, Space 점프. 키 바꾸기, 숫자 1~9 감정 슬롯.
- 배경 원본 AVIF / 도트 2px / 3px, 낮·저녁·밤 전환, 깡패 적 더미, 효과음·배경음, 「균일」 단추(옛 재생 방식 비교).
- 액션식 재생: 예비 동작 짧게, 때리는 장 멈춤, 히트스톱, 끝 동작 캔슬, 장마다 발밑 그림자.

**테스트로 알게 된 것**
- 사용자 평: 동작이 「모탈컴뱃 1처럼 허우적거린다」. 원인은 장 간격이 균일한 재생 → v2에서 코드로 고침. 방향(남동·서 섞임)은 **상관없다**고 함.

- **걷기·뛰기는 PixMiniMax가 v3보다 낫다.**
- 0.73배처럼 애매한 배율로 줄이면 뭉개짐 → 캐릭터는 1배로 그리고 배경을 맞춰요. GPT 배경은 규격보다 작게 그려져 있어요.
- 용량: 쟈알디 356장 = PNG 시트 2.1MB, **WebP 무손실 0.75MB**. 도트 배경도 WebP 무손실 추천(AVIF는 도트 경계가 번짐). 원본 그림 그대로면 AVIF q65(2.5MB → 약 150KB).

**사용자 결정 (2026-10-24 11:46)** — 자세한 건 `docs/인계/쟈알디/쟈알디_동작_최종세트_2판.md`
- **부상 걷기 뺌**, 부상은 코드로 표현. **웅크리기·웅크려 걷기 뺌. 공중제비 뺌.**

- 견본 쓰러지기는 엉망. **뒤로 날아가 쓰러지기, 누운 상태, 스턴(헤롱헤롱)** 필요. 슈퍼아머는 이펙트로.
- **고유기술과 충전기는 한 키.** 먹기·마시기는 **섭취** 하나로.
- 감정 동작은 키용이 아니라 **NPC 자동 행동용**(오래 대기, 논플레이어블이 돌아다닐 때).
