## 사용자 확인이 필요한 것

1. **가짜 관리국 진압 A·B·C**: 등록 그림은 등에 소총을 멨는데, 규칙대로 원거리를 권총으로 씀. 소총으로 바꿀지.
2. **성인 불량배(여 1·여 3·남 2)**: 1번 평상 대기 첫 장(등록 그림)이 빈손이라 1번 안에서 담배가 생김. 1번을 먼저 뽑아 담배 든 장을 다른 비스듬 동작의 시작 장으로 쓰는 게 안전. 놀라기·주저앉기·웅크려 떨기에서는 담배를 떨어뜨리게 씀.
3. **15번 끝 자세가 묶음마다 다름**: 협회·프리랜서는 엎드림, 나머지는 등으로 누움. 각 NPC 안에서 16·30번과는 맞게 이어짐.
4. **치마 인물**(학생 여, 불량배 여 2, 관리국 여 A, 백일몽 여 A, 협회 여 2·3 등): 눕기·주저앉기·웅크리기는 무릎을 모으게 씀. 미성년(학생 전원, 불량배 여 2·남 1·남 3)은 생성 뒤 모든 장 확인 필요.
5. **불량배 남 1**: 등록 프롬프트는 고등학생인데 그림은 성인처럼 보임. 미성년 규칙대로 씀.
6. 서(W)를 고른 NPC: 경찰 여 2, 관리국 여 A, 백일몽 여 A, 불량배 여 3. 나머지 E.
