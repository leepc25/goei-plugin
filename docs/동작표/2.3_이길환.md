  1. 2·22·23·25번 「주먹을 입에 대기」에 생성기가 마이크를 그려 넣을 수 있음. 등록 그림엔 없으므로 그려지면 결함(사용자가 마이크를 들게 하고 싶으면 그때 바꿈).

  3. 26번 「작은 것을 입에 넣기」에 사탕이 손에 그려질 수 있음 → 크게 그려지면 다시 뽑기.
