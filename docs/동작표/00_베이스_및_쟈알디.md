## 0. 공통 규칙

### 0-1. 키 (안 · 게임 안에서 바꿀 수 있음)

테스트룸 v2 배치를 바탕으로 새 버튼을 넣었다.

| 키 | 행동 |
| --- | --- |
| ← → ↑ ↓ | 걷기(↑↓ = 앞뒤 줄) |
| Shift + 방향 | 뛰기 |
| Space | 점프 (공중에서 한 번 더 = 2단 점프) |
| Z | 약공격 (연타 = 약1 → 약2 → 약3) |
| X | 강공격 |
| A | 원거리 공격 |
| C 짧게 / 길게 | 고유기술 / 충전 → 떼면 방출 |
| S | 필살기 |
| D 짧게 / 길게 | 회피 / 막기 |
| E | 상호작용 · 섭취 · 줍기 |
| 상황 | 뛰다 Z = 돌진 공격, 공중 Z = 점프 공격 |

### 0-2. 방향

- 캐릭터마다 **동(E) 또는 서(W) 하나**를 고른다. 기준: 머리카락이 얼굴을 가리지 않는 쪽. 비스듬은 같은 쪽(E → 남동 SE, W → 남서 SW). 반대쪽은 게임이 뒤집는다.
- 표의 「옆」 = 고른 E/W, 「비스듬」 = 고른 SE/SW.
- 비스듬을 쓰는 동작: 평상 대기, 개인 대기, 제자리 점프, 섭취, 줍기, 스턴, 대화·반응. 고유기술·필살기는 캐릭터마다 판단.

### 0-3. 제작 방식

| 표기 | 뜻 |
| --- | --- |
| 견본 | PixMiniMax **Free motion**(walking / running). 프롬프트 없음 |
| 커스텀 | PixMiniMax **Describe your own**(API `animate-pixminimax`). 아래 옵션을 늘 채움 |
| 코드 | 그림 없음. 게임이 앞 동작의 장을 멈추거나 거꾸로 틀거나 효과를 얹음 |

**커스텀 옵션 (전 동작 공통)**

| 칸 | 값 |
| --- | --- |
| Subject | 캐릭터 머리줄의 Subject 한 구절 |
| Starting pose | 표의 「시작 장」 자세를 한 문장으로 |
| 시작 장 (first_frame) | 표의 「시작 장」 그림 |
| 끝 장 (last_frame) | 표에 적힌 것만. 나머지는 비움 |
| view / direction | low top-down / 그 동작의 방향 |
| Enhance prompt | 끔 |
| No background | 켬 |
| Keep first frame | 끔(시작 장이 다른 동작의 장이라 겹치지 않게) |

프롬프트에는 몸 움직임만 쓴다. 폭발·불꽃·빛·총알·연기·글씨·가구·장소는 쓰지 않는다(코드·GPT 시트 몫). 대기 중에 없던 물건이 손에 생기는 동작은 만들지 않는다. 원거리 공격의 총만 예외(빠른 동작이라 손에 바로 나타나도 됨).

### 0-4. 장 수 · 비용

- 장 수는 4 또는 8. 필살기만 12~16까지(API는 4의 배수 허용, 웹은 4·8만 보임).
- 비용 (사용자 확인 2026-10-24): **PixMiniMax는 8장까지 1회, 8장 넘으면 2회**(견본·커스텀 같음). 다시 뽑기는 따로.
