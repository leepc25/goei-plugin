- 걱정되는 점:
  1. 얼굴 그림자가 장마다 사라지거나 눈·코가 그려질 수 있음 → 모든 장에서 얼굴이 검은 면인지 먼저 확인. 입가 흰 선 하나만 남아야 함.

  3. 15·22번 손가락으로 긋는 선을 생성기가 검은 줄로 그릴 수 있음 → 선은 코드 몫이라 생기면 결함.
