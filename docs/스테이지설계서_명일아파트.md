## 1. 한 줄과 분위기

**낡은 복도식 아파트에 들어가면 5층에 서 있다. 내려갈수록 건물이 살아 있다.**

- 공포 축: 5층 "남의 것" → 4층 "예절" → 3층 "끝없음" → 2층 "건물이 사람을 잡는다".
- 감각 연출(원작): 벽이 숨 쉼(배경 미세 애니), 바닥이 맥박(화면 아주 작은 상하 흔들림 2px, 2층만), 달큰한 냄새(층이 내려갈수록 화면 가장자리에 옅은 붉은 비네트), 치수가 안 맞음(복도가 밖보다 김 = 방 폭이 화면 1.5~3배).
- 소리: 5층 멈춘 시계·바람, 4층 생활 소음과 TV 지직, 3층 내 발소리만, 2층 숨 쉬는 벽과 맥박.

## 4. 규칙 변형 (출동마다 1개, 씨앗)

1. 4층 주민은 존댓말 인사(E 길게 2회)에만 반응.
2. 5층 멈춘 벽시계가 가리키는 호수는 열면 안 됨.
3. 엘리베이터 7 표시(위험 보상 방 열림, 보상 2배·적 강화).
4. 402호 진짜 방송(괴이 난입 확률 30%).
5. 3층 표지가 거꾸로(반대 방향이 정답).
6. 2층 벽이 처음부터 붉음(모든 방 위험, 보상 증가).
7. 403호 이불 뭉치가 현관 앞(사건방 등장 확정).
8. 주민 단톡방 캡처가 거짓(규칙 9 힌트가 반대).

### 6.1 구역 보스

**5층 「일어난 집」(게임 설계)**: 물건을 너무 집으면 집 자체가 일어난다. 방 전체가 보스. 패턴: 가구가 날아옴(피하기) → 바닥이 기울어 미끄러짐 → 문이 닫히고 벽이 조여 옴. 약점: 멈춘 시계를 부수면(E 길게) 집이 다시 "떠난 집"이 됨(규칙 2·3을 알면 바로 끝낼 수 있음). 체력 800.

**4층 405호 노부부(원작)**: 밥상에 앉으라 권함. 얼굴이 거꾸로. 식탁에 미라 두 사람.
- 1단계(비전투): 밥상 앞에서 선택지. 「잘 먹었습니다」(규칙 7) → 노부부가 웃으며 배웅, 보스전 생략, 규칙서 보상. 먹기 → 큰 피해 + 2단계. 거절 없이 돌아서기 → 2단계.
- 2단계(전투): 할머니는 밥상을 들어 던짐(투사체), 할아버지는 느리게 다가와 안으려 함(잡히면 식탁에 앉혀짐 = 큰 피해). 미라 두 사람이 일어나 느리게 따라옴. 체력 1200(둘 합). 약점: 거꾸로 된 얼굴 = 머리 위쪽이 입 → 하단 공격·앉아 공격이 "입"을 때려 2배.
- 「아이고, 우리 아들이랑 딸이 곧 온다는구먼.」 → 체력 50%에서 현관문이 열리고 "곧 오는 누군가"(실루엣만, 공격 없음)가 들어옴 → 노부부가 멈춤 → 마무리 기회. 누구인지는 보여 주지 않는다(원작 떡밥 유지).

**3층 「복도의 끝」(탈출 사건)**: 전투 없음. 표지 3개를 순서대로 지나면 창문 집이 나타남. 시간이 길수록 체력 감소·화면 흐려짐. 백일몽 조가 길을 잃고 있음(조우: 같이 나가기 / 두고 가기).

**2층 208호 가족(원작)**: 보라색 머리 아주머니, 표정 굳은 아저씨. 「우리 애 못 봤어요?」
- 1단계: 부탁(선택지: 찾아 주겠다 / 모른다 / 무시). 어떤 답도 3번째 대화에서 턱이 찢어지며 전투.
- 2단계: 아주머니는 빠르게 돌진해 물기, 아저씨는 느리고 총 안 통함(원작 "총을 맞고도 비틀거리기만") → 근접·잡기·환경 무기만 유효. 체력 각 900.
- 약점: 방 안 아이 방 문(잠김)을 E로 열면(규칙 11을 알고 벽 얼굴을 안 건드렸을 때만 열쇠 드랍) 두 사람이 그쪽을 보고 멈춤 → 마무리. 아이의 행방은 보여 주지 않음(원작 미확정). 게임식 결말(이빨 요정 상자에서 "보라색 머리핀"이 나온다)은 사용자 승인 후.

**7층 최종(게임 설계, 승인 필요)**: 「자라는 것」. 건물의 심장. 15년간 먹은 사람들의 생활 소음이 한꺼번에 들림. 패턴은 1~4층 보스 패턴의 축약 재등장 + 벽·바닥·천장 전부 적. 쓰러뜨리면 건물이 "입주민 모집"을 멈춤(괴이가 사라지진 않음, 관리국 격리 대상이 됨). 또는 승인 안 되면 7층은 "원인 확인 조사"로 끝내고 보스 없음.

## 9. 컷신 대본 (초안)

**첫 투입 (한 장 그림 + 도트)**

- 노부부가 돌아봄(도트: 얼굴 거꾸로 2장).

**208호 등장**
- 아주머니: 「우리 애 못 봤어요? 보라색 머리인데. 아까까지 여기 있었는데.」 (3회, 점점 덜 다정)

**귀환**
