## 1. 세계관 기본

### 1-1. <어둠탐사기록>
- 정의(원문): "위험한 괴현상을 수집 및 관리하는 세 부류의 집단, 그들 각각의 괴담 관리방식과 탐사사례를 모아둔 괴담 위키."
- 사이트 제목 **[종말 예언 : 어둠탐사기록]**. 약칭 '어탐기'. 특정 운영자 없이 SNS 괴담이 모여 생긴 공유 창작 위키. 후원·광고로 유지됐다.
- **종말 예언 전제**: 수집할 만큼 괴현상이 만연함 → 콘텐츠 특성상 점점 더 위험해짐 → 결국 격리 실패로 인류가 멸망한다. 위키의 모든 괴담은 종말의 전조다. ("이런 괴담 있으면 인류 망했지ㅋㅋ / └어 그래서 망했어")
- 문서 형식: `어둠탐사기록 / 괴담` 항목 + `탐사기록 #n` 사례 목록. 아이템은 `어둠탐사기록 / 망상홈쇼핑 / 아이템`처럼 출처별로 분류.
- 탐사기록은 재미 위주로 쓰였다. 대량 투입·생존율 반토막 사례, 유독 운 좋은 생존 사례가 단골 소재다.
- 주인공이 그 세계에 개입한 뒤로 위키와 다르게 흘러간 사건이 있다. 위키가 실시간 수정된다는 설정.

### 1-2. 현실 쪽 이상 현상 (372~373화)
- 귀환 정확히 1년 뒤(7월 7일), 위키가 "종말이 왔습니다. / 정말 감사합니다"만 남기고 사라진다. 캡처를 극단 보정하면 숨은 문구가 나온다: **"집으로 돌아가신 후 / 종말이 왔습니다. / 정말 감사합니다 / 이름님."**
- 운영진은 팝업스토어 전에 모두 손을 뗐다. 운영자 없는 위키 자체가 괴담이 된 것으로 의심된다.
- 이동 경로: 베개 밑에 둔 굿즈 박스를 꿈속으로 가져감 → 철거된 팝업스토어 자리의 **캐릭터 메이커** → 남해지사에서 깨어남.

### 1-3. 시간·공간
- 주인공의 현실 1년 = 어둠탐사기록 세계 **약 3년**.
- 현실 한국 지명(제주 용머리 해안, 포항, 경상남도, 설악산 대청봉, 부산)과 가상의 **세광특별시**가 공존한다.
- 이면세계(토크쇼, 연옥합창단 등)가 따로 있다.

### 1-4. 어둠 등급과 식별코드
- 백일몽 식별코드: **`Qterw-[등급]-[번호]`**. 검열 시 `Qterw-■-■■■`. 하위 현상은 `Qterw-A-89/ 변칙 상황/ 1`, `Qterw-E-112 변칙 사례 / 악기`처럼 붙인다.
- 등급 문자: **A, B, C, D, E**가 확인되고 F도 언급된다.

| 등급 | 이름 | 확인된 내용 |

## 2. 조직

### 2-1. 백일몽 주식회사 (본사)

**성격**
- "소원을 들어주는 수상한 제약회사". 대외적으로는 상장한 지 얼마 안 된 대기업, 탈모약으로 돈을 잘 번다고 알려졌다.
- 어둠을 **종결하지 않고 '관리 및 운용'**한다. 어둠에서 **꿈결**을 뽑는 것이 목적이다. 종결은 재난관리국의 방식이라 백일몽에선 금기에 가깝다(목각인형의 부적을 일부러 떼어 둔 것도 이 때문으로 추정).
- 원문: "이 회사에서 직원 목숨보다, 어쩌면 다른 모든 것보다 중요하게 생각하는 자원의 정체를. 꿈결 용액." 고등급 꿈결이면 "말 그대로 사람도 죽일 수 있었다."
- 문화: 철저한 손익 계산, 목격자 제거에 거리낌이 없다. 임원 사이 사내 정치가 심하다. 동료를 버리고 물약만 챙기는 것이 '지극히 백일몽스러운 합리적 판단'이다.

**구조**
- 서울 본사 + 지방 곳곳의 지사 + 몇몇 특수 해외 지부.
- **이사진**: 호 이사(호유원, 개발부), 청 이사(개발부 단독 이사). 이사 아래 프로젝트 팀을 둔다(호 이사 프로젝트).
- **현장탐사팀**: 어둠 탐사의 핵심 부서. 조(組) 단위. **정예팀**(A조 등)과 **일반팀**(H조 등)이 있다. 사망률이 높아 조장 승진이 빠르다. 자기 조 담당이 아니면 등록 어둠 정보를 마음대로 못 본다. 정규직 엘리트는 **매뉴얼**을 지참한다.
- **보안팀(본사)**: 격리 실패 시 제압 인력. 지사 보안팀보다 훨씬 낫다고 여겨진다. "기이하고 위험한 분위기". 대표 인물 J3 경비반장(전 B조 늑대 조장으로 추정, 강력하고 특이한 오염 보유).
- **연구팀 / 연구직**, **처리반**(꿈결 이송·포인트 발급), **개발부**, **상층부**(감사 보고서 결재).
- **마무리팀**: "그냥 고기방패야. 일머리 있는 직원한테 주는 여벌 목숨 같은 거니까 신경 쓰지 마." 남해지사 Z 끝방 명패도 '마무리팀'이다.
- 직급: 이사 > 과장(조장) > 대리 > 주임 > 사원. 지사는 지부장 · 연구원 · 보안 직원 · 작업자.

**입사와 보상**
- 입사 시험 → 오리엔테이션(사회자 **곽제강**). 곽제강이 "포인트 더 빨리 벌고 싶으면 그쪽으로 연락하라"며 준 명함이 사실 **지사 관리직 발령 루트**다.
- **포인트(p)**: 사내 화폐. 꿈결을 포인트로 환산한다. 출처 증빙과 감사 보고가 필요해서 최소 일주일이 걸리고 수수료가 붙는다.
  - A등급 꿈결 = 10만 p. 담당 연구원은 인정 포인트의 절반쯤을 받는다(추정).
  - **꿈결 진통제** = 5,000 p, 보름간 통증 소멸.
  - **소원권** = 진통제 100회분, 약 50만 p(추정). 김솔음은 '진짜 소원권'으로 집에 돌아갔었다.
  - **재생 물약**: 손가락을 재생할 수 있다. 본사에서 가져와야 한다.
  - **백일몽 물약**: 소원을 이루는 물약으로 언급된다.
  - **복지몰**: 포인트로 물건을 사는 사내몰.
- 본사 숙소: 역세권 최신식 오피스텔(룸메이트 있음). 정규직 시절 '신비한 검은 상자에서 굿즈가 내려오던' 시절이 있었다.

**제도**
- **감사**: 사고가 난 지사에 본사 직원이 내려간다. 지사 쪽에선 본사가 포인트·매뉴얼을 가로채려는 핑계로 본다. 감사 담당자는 격리 구역과 어둠 관리 시스템에 접근할 수 있고, **임시 계류** 허가를 받으면 지사 임시 책임자가 되어 작업자 폐기 권한까지 갖는다.
- **기억 제거** 수단이 있지만 비싸서, 목격자가 적으면 "정신이 약해 맛이 간 걸로" 처리한다.
- **어둠 관리문서** 양식: 등록번호 / 작성자 / 관리 지침 / 위험성 / 격리 규칙 / 변칙 상황 / 추가된 권고사항 / 담당자 메모. 지사 단위로 '등록문서 N번'도 매긴다.
- 위키 속 평판: 수십~수백 명을 한 괴담에 동시에 처넣는 회사. 초창기 위키에 나온 '아이템 없이 맨몸으로 갈리는 이름 없는 번호표 직원들'은 사실 **지사**의 이야기였다.

### 2-2. 백일몽 남해지사

**위치·외관**
- **제주도 용머리 해안 근처의 지하 시설**. 비상 수직구로 나오면 검은 현무암 해안이다. 직원도 위치를 모른다. 선팅된 차로 실어 나르는데, 육지에서 차로만 왔는데 섬에 도착한다(그 차도 어둠일 가능성).
- 창문 없는 밀폐 시설. 폐광 갱도, 낡은 복도식 아파트, 교도소 같은 분위기. 습하고 물방울이 떨어진다. 작업자들은 옛 탄광이었다고 들었다.
- 시설 자체가 원래 어둠(하얀 끈) 위에 지어졌다.

**본사의 평가**: "환경이 열악한 대신에 효율이 좋다", "자원 재활용도 잘하고, 비품 소비도 덜하고", "시범 운영적인 지사". 표어 **"자원 절약하여 회사 이바지하자"**. 일만 잘하면 승진이 말도 안 되게 빠르다(호유원이 지사 직원에서 본사 이사가 됨).

**역사**
- 호유원이 지사 직원(관리문서 작성자, 하얀 끈 구역 담당)이던 시절에 옛 관계자 구역과 옛 중앙시스템이 쓰였다. 호유원은 떠나며 키 카드를 반납했다.
- **6년 전 재개발**: 비용 절감과 인력 배치 효율화를 이유로 구조를 바꿨다. 관계자 구역을 격리문 하나로만 분리해 본사 안전 규정에 미달한다. 하얀 끈의 금지 반경 500m 안 시설을 작업자 숙소로 재활용했다(호유원은 반대 기록을 남김).
- **1차 격리 실패**: 하얀 끈(386~390화). 이후 '기생충 방역 소동'으로 은폐.
- **2차 격리 실패**: 미인 약 → 연옥합창단(395~398화). 정규직 25명, 작업자 1,237명 사망, 지사 보안팀 78% 소실.

### 2-3. 남해지사 작업자 제도

**모집**
- 길거리 노란 코팅 전단지: "취직하실 분 / 급구! / …담전문대기업", 하단 "미친 복지", "지금 출근하세요!", 뒷면 사인펜 "지원 즉시 일당 지급! / 현금 50만원", 번호 조각 "070939312535이거전화번호아니야", 서명 "㈜백일몽주식회사 / 남해 지사".
- 전화를 걸면 "번호를 다시 보라고?" → 번호가 하나 더 생김 → 비명 → **"이리오세요."** → 실종. 전단지는 "구인 완료"로 바뀐다. 새 차수 공식 명칭은 "백일몽 남해지사에서 모집하는 인력 채용안내문".
- 대상: 빚쟁이·도박꾼·약쟁이 등 '없어져도 뒤탈 없는' 사람.

**조건(들은 것 vs 실제)**

| 들은 것 | 실제 |
|---|---|
| 일당 100만 원, 매일 현금. 작업 두 번이면 두 번 | 현금은 밖으로 못 가져간다. 매점·의료실·휴무 구역으로 회수 |
| 100일 합숙이면 5억("한 달 존버면 오천") | 30일마다 '작업자 정리(폐기)'. 100일을 채울 수 없다 |
| 30일 못 채우면 최저로 계산해 준다 | 말이 바뀌어 30일 전엔 못 그만둔다 |
| "일종의 약물 임상 겸 잡일, 보안이 중요해서" 외부 연락 불가 | 수면 상태로 옮겨져 작업복 차림으로 깨어난다 |
| 거부하면? | 번호 강등, 벌점, 일당 미지급, 투입 강행 |

**번호·조**
- 조: **X조 > Y조 > Z조**. 번호대 X100·X800·X900번대, Y400번대, Z800·Z900번대. Z999가 맨 끝.
- 새 차수엔 서명 후 **임시 번호**(예: 99번, 401번) → 입장 순서로 'n조'(25명) → **첫 작업 성과**로 번호·처우 결정. "제일 번호가 빠른 분은 서울 고급 호텔에서 룸서비스 먹듯이 100일".
- 연구원이 실적을 보고 **특별 재배치**(A4 공지 `Y492 -> X915`). 정식 조정은 매주.
- 실종자에겐 "업무 수행이 어려워 다른 곳에 배치되었다"고 둘러댄다.

**처우표**

| 조 | 숙소 | 식사 |
|---|---|---|
| Z (특히 Z990번대 끝방) | 방 하나 크기에 10명. 마감 안 된 흙벽, 변기 대용 구덩이, 터진 매트, 거미줄·곰팡이, 수도 없음. "쌍팔년도 감방". 실은 호유원의 옛 사무실을 흙벽으로 막은 방 | 식은밥 한 덩이 + 멸치볶음. 떡라면 추가 1만 원 |
| Y | 구축 아파트처럼 허름. 장판 거실 + 방 둘, 잠금장치·소파·욕실 | 정상 메뉴(돈까스, 제육볶음·미역국). 식사 포장 가능. 아침 식사는 Y부터 |
| X | 깨끗한 3인 1실, 1인 1침대, 거실, 수건·물병 비치 | 수육·보쌈김치 수준 |
| X 특권 | **휴무 구역 통행증**(주 1회, 평일 출입) | |

**표식과 장비**
- **목 스티커**(진나솔은 쇄골): 붉은 스티커. 지사가 특수생산했고 지사 약품 없이는 안 떨어진다. 떼려 하면 "작업규칙 위반 행위", 반복 시 벌점.
  - 평소: `Z999 / 분류 : 작업자 / 남은 기한 : 73일`
  - 지사 반경을 벗어나면: `Z999 / 자리를 이탈했습니다. / 포획 요망` → 시커멓게 변하고 발진·핏대가 번지며 목을 조른다. 돌아오면 원상태.
  - 만료: `소모품 / 소비기한 경과품 : 폐기 담당자를 호출하세요.`
  - 새 차수: `번호 미정 / 분류 : 작업자 / 남은 기한 : 100일`
  - 스티커 아래엔 **원료 주입구**(튜브 바람구멍 같은 구멍)가 있다. 떼면 원료가 새서 무너져 죽는다.
- **암밴드(보호대)**: 왼팔, 잠금식, 혈압계 같은 아대. 안에 작은 원통형 **꿈결 수집기**. 작업자 몰래 꿈결을 모은다. "그 밴드는 망가지면 다 월급에서 깔 거예요." 나오면 보안 직원이 회수한다.
- 작업복: 황토색·주황색.

**작업 방식**
1. 번호대로 호출("[Z800번대, 900번대 작업자들 이동 시작합니다. 걸음 지체하지 마세요.]").
2. 안대 → 광차 → 격리실 앞에서 암밴드 착용 → "[Z999번, 투입합니다.]" → 밀어 넣고 문을 닫는다.
3. **매뉴얼 없음.** 연구원이 스피커로 일방 지시. 결과는 알려 주지 않는다.
4. 불이행 시: "할 때까지 거기 놔둡니다", 일당 미지급, 벌점.
5. **야간 특별작업**: 수당 2~3배. 5인 1조 무작위, 백여 명을 한 어둠에 일괄 투입. 안내문은 주지만 손전등 요청은 묵살(대조군 확보 목적으로 몰래 가져온 손전등은 방치).
6. **근로실험**: 생산성 개선 명목으로 어둠을 몰래 먹인다(미인 약).
7. 꿈결 없이 죽으면 "폐기 처분 비용"이 든다.
8. 비상시 쓴 의료품·휴무 구역 물건은 '무단 점거 및 사용으로 인한 비용 징수' 청구서로 받아낸다.

**작업자 사회**
- 강약약강. 앞번호가 뒷번호를 '비둘기(둘기)', '구구구'라 부르며 괴롭히고 돈을 뜯는다. 앞번호는 낙관, Z900번대는 불안과 넋 나감.
- 실종자는 '기가 약해서', '운이 없어서'라고 여긴다. 뒷번호는 검증 안 된 액막이 주문을 중얼거린다.
- 연구원은 이 구조를 의도했다. 현금 → 도파민 → 지출 회피 → 앞번호 집착 → 위험한 일에 자원.

**진실: 작업자는 재활용품이다 (403~404화)**
- 30일 주기 '작업자 정리' 새벽에 수면제·이완제 → 안대·결박 → 철창 광차 → **처리 시설**(자동화).
- 몸 안은 주홍빛 **원료**로 차 있다. 처리 시설이 녹여서 기억을 지운 '막 고용됐을 때 상태'로 다시 찍어 낸다. 한 차수 999명.
- 상자 마크: "소비기한 : 100일" + 엄지 이모티콘 **"소비기한을 넘겨도 재활용할 수 있어요!"**
- 그래서 작업자는 지사를 떠날 수 없다. 진나솔이 "반년 전에 와 놓고 2주 있었다"고 말한 모순도 이것 때문이다.
- 김솔음의 해석: 복제가 아니라 '재활용'이므로, 재활용된 작업자는 **본인**이다.

### 2-4. 초자연 재난관리국 (재난관리국 · 재난국 · 관리국)
- 초자연 재난을 다루는 **정부 기관**. 어둠을 **종결**하는 쪽. '의식 전문 요원', '제사 전담 요원', 구조요원이 있다.
- 팀: **현무팀**(현무 1팀), **백호팀**. 채용은 공시. 연고 없고 똘똘한 피해 민간인에게 알바(전화 받기 등)를 준다.
- 응대 멘트: "[초자연 재난관리국입니다. 현재 구조가 필요하신 상황입니까?]" 민간인은 "시민님".
- **괴담 안에 구조요청 전화기를 숨겨 둔다.** 단축 3번 '24시 전문콜', 화면부는 검정 테이프. "선을 뽑아도 한 번은 연결된다."
- 사칭 대비: 가짜 구조 전단 맨 아래에 깨알 문구를 심는다. **"재난관리국에서는해당형식의안내문을배포하지않습니다이문구가보일시당장뒤돌아도망치십시오얼른"**
- 전화한 쪽이 장기실종자·오염체일 가능성을 늘 의심한다. 의심자는 '인도적 사살'도 있다.

- **코스**(원형, 갈림길에서 계속 왼쪽)

  - **경품 수령처**: 수련원 1층 안내실. 창구 어둠 속에서 경비원 옷을 입은 중년의 손이 나온다.
- **규칙**
  - 어떤 빛도 켜지 마라(손전등·라이터·스위치·수화기 불빛). 빛을 보면 즉시 눈을 감아라.
  - **불을 켠 당사자는 무조건 실종**된다. 빛을 안 봤어도, 남이 밀쳐서 스위치에 닿았어도 해당된다. 실종자의 모습을 한 무언가가 일행에 섞여 따라온다.
  - 괴이는 불을 켜게 만들려고 유혹한다: 뒤따르는 발소리, 손목 잡기, 위장 동행자, 사칭 전단, 전화기, "내가 지금 뭐하고 있게? 어떻게 생겼게?… 궁금하지?"
  - 위장 동행자가 길을 안내하면 반대로 간다. 반응하지 말고 무시한다.
  - 스탬프를 다 찍고 경품을 받은 뒤 수련원 구역을 벗어나야 클리어. 안개 속에서 격리실 문으로 걸어 나온다.
- **빛을 본 사람**: "훤하고 좋구만… 좋다. 좋다. 좋," → "어어어어 그래 좋좋아좋아아아아좋다" → "산에 있었어." 그리고 사라진다. 아이 흉내 목소리("작업번호가 뭐예요 아저씨?", "저 계속 여기 있었는데 저 안 보이세요?")가 조원 수를 속여 섞인다.
- **경품 뽑기**
  - 인당 1개. 재활용 종이박스에 구멍, 알록달록한 공. 등수 1~9(추정), **8등 = 참가상**, 4~5등부터 초자연 효과, **6등**은 수련원에 버려진 물건 재활용. 괴담이 열릴 때마다 원상 복구.
  - 작업복 천에 찍은 스탬프도 받아 준다.
  - **공략**: 공을 1번부터 넣었으니 높은 등수가 바닥에 있다. 상자 바닥 구석까지 침착하게 손을 넣으면 된다. 사례: 산악동호회 3등(#탐사기록 11, 묵주), 고교생 7명 4등, 연쇄살인마 2등, 1등은 김솔음이 처음.
- **숨은 진상 (재난관리국 정보 + 4번째 스탬프)**
  - 신마루수련원은 사랑낙원이 운영하던 수련원으로 **17년 전 폐관**. 폐관 닷새 전 담력 체험에 나간 고교생 수십 명이 전원 실종, 이후 시신 수십 구가 **"모두 두개골이 함몰된 상태로 웃고 있었다"**. 2·3층 학생 방엔 간헐적으로 불이 켜진다(접근·접촉 금지).
  - 관리국 대처: 스팟에서 떨어져 **오색약수터 근처 나무 틈에 숨어 눈을 감고** 기다린다. 로비에선 **유리창 밖을 보지 말 것**. **종교 상징물에 절대 손대지 말 것**("그냥, 하지 마세요."). 원한 풀기 금지.
  - **4번째 스탬프**: 로비 왼쪽 계단 옆 비품함 → 코르크 보드 뒤 시커먼 구멍 → 추락. 수련원은 **절벽 바로 위**이고, 아래가 선녀바위다. 학생들은 이 아래로 뛰어내려 바위 뒤에 머리를 부딪혔다(추정). 스탬프 4개의 그림을 합치면 **"하강 · 절벽 · 수련원"**.
  - 지하 **신마음수도원**: 경구 명패, 종교 상징물로 빼곡(불상, 마리아상, 십자가, 소머리 흉상, 홍옥이 드러난 쪼개진 머리, 잘린 쥐머리 더미, 성냥 신상, 금향로). 노끈으로 감긴 원통형 **신상**에 피가 묻으면 **낙원의 연인**을 부른다(추정).
  - 불을 켠 당사자는 4번째 스탬프를 찍은 작업복을 '추가 제출'해야 나갈 수 있었다.

### 5-3. 낙원의 연인 — 식별코드 불명 · 고등급
- 사랑낙원의 숭배 대상. 정의: **"당신이 사랑해야 하는, 무언가 지극히 아름답고 좋은 것."** 누구에게나 자기 이상형으로 보인다. '인간의 인지로 감당하기 힘든 무언가'.
- **외형**: 문틈으로 보인 길고 아름다운 손가락, 오색 자개빛이 도는 봉선화색 손톱. 제3자가 전화로 들으면 아름다운 목소리가 아니라 **"이상한 끼긱거림이랑, 살점 부딪히는 소리"**.
- **발현**: 지하에서 스탬프를 찍자 주변이 "밝고 아름다워"지며 나타났다. 김솔음을 남해지사까지 **쫓아왔다**. 정중하고 아름다운 노크 "똑똑똑".
- **구애 시**(청각을 무시하고 머릿속에 들림)
  - "산사나무 같은 나의 연인아 / 네 사랑은 / 참으로 곱고 어여쁘다"
  - "부름에 응답하여 내가 왔으니. / 뒤돌아 나를 맞이하라." / "이토록 기다리는데 / 돌아보지 않는구나."
  - "돌아보라 / 사랑하는 자야" / "기꺼이 열어 / 쏟아지는 열기를 맞이하라 / 어여쁜 것아" / "바구니 속 산비둘기처럼 / 내 사랑이 이 안에 있으니"
- **오염**: 감동, 그리움, 가족을 다시 만난 반가움, 죄책감, 인정받는 느낌, **통증이 사라지는 편안함** → 뒤돌아보거나 문을 열고 싶어진다. 판단력도 오염된다. 몸이 저절로 돌아가 목이 반쯤 돌고 팔이 꺾인다. 1인칭이 오염된다("내 사랑.", "나를 불렀군요."). 오염이 풀리면 큰 배신을 한 듯 대성통곡한다.
- **규칙**
  - 뒤돌아보지 마라. 보지 마라. 문을 열지 마라.
  - **말을 걸지 마라.** 대화는 존재를 인정하고 받아들인다는 뜻이다. "내가 허락한 일에 다시 허락은 필요하지 않다" → 잠긴 문도 스스로 연다.
  - 산소가 없어도 죽지 않는다("연인의 숨이 네 볼을 간지럽히고 / 우리 사랑은 끝나지 않으리").

- **결말**: 김솔음이 휴무 구역의 관계자 문을 모두 열어 하얀 끈을 중앙제어실로 끌어온다 → 신경 다발이 연인에게 꽂혀 함께 **지하로 끌려 내려간다**. 이후 **'지하 격리구역 1 (폐쇄)'**에 새 어둠으로 등록된다.
- **흔적**: 김솔음 손에 흐른 피 위의 **"고운 손자국"**.
