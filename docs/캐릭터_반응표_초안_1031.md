- 성격 근거: 「어차피 죽을 사람들인데요」 / 「진짜 위협 앞에서는 순식간에 아첨 모드로 바뀌어서 뇌물부터 꺼낸다」
- 무기를 겨눔: 웅크림 → 손 비비기(아첨) / `…` / 「사흘 치 월급」 뇌물 꺼내는 시늉. 틈 보이면 숨기
- 시체를 봄: 다가가 웅크려 뒤지기(아이템 챙기기) / `♪` (「건질 거 건지게」)
- 근처 소란: 안대 살짝 들어 확인 → 덕트·구석으로 숨기 / `…`
- 범죄 목격: 비웃기 / `…` / 무시하고 하던 일. 쓸 만하면 메모(약점 수집)
- 동료가 맞음: 비웃기 또는 무시 / `…`. 자리 내준 동료면 화냄(흰자위) `#` — 선택적
- 동료가 쓰러짐: 장비 뒤지러 다가감 / `?`. 자리 내준 동료면 화냄 / `#` (「포기하지 말고 생각 좀 하라고요!」)

### 고영은 (R조 사원)
- 전투 가능: 예 — 신입 수준 (「신입 수준. 대신 아이템, 지형, 빛으로 이긴다」)
- 성격 근거: 「사람이 재료보다 먼저고, 안전이 포인트보다 먼저다」 / 「다친 사람이 있으면 본능적으로 다가가고」
- 무기를 겨눔: 놀람(읽기 쉬운 공포) → 헤드램프를 상대 눈에 비춤 / `!` / 뒷걸음질
- 시체를 봄: 달려가 웅크려 맥 확인 / `?` / 이미 죽었으면 옆에 앉아 장비를 조심스럽게 정리
- 근처 소란: 머리 뒤로 넘기기 → 다가가 진정시키기 / `!` («영은 쌤 모드»)
- 범죄 목격: 노려보기 / `#` / 피해자부터 달려가 처치 (백사헌의 「목 따자」 제안을 노려보며 거절)
- 동료가 맞음: 달려감 → 웅크려 응급처치 / `!`
- 동료가 쓰러짐: 달려감 → 구급상자 열고 처치 / `!` (「괜찮아요? 어디 다쳤어요?」)

### 강이학 (I조 사원)
- 전투 가능: 예 — 신입 수준 (「전투력은 신입 수준이다. 대신 강이학이 있으면 싸울 일 자체가 줄어든다」)
- 성격 근거: 「표정이 1밀리도 안 바뀐다」 / 「싸움을 거래로 바꾼다」
- 무기를 겨눔: 웃으며 꾸벅 인사 → 두 손 모으기 / `♪` / 돈 동그라미 손짓(흥정 시도). 안 통하면 도망
- 시체를 봄: 웃는 얼굴로 다가가 값 매기기(만져 보기) / `♪` (「시체, 비밀의 값을 즉석에서 매기고」)
- 근처 소란: 웃으며 끼어들기 → 돈 동그라미 / `?` (싸움을 협상으로)
- 범죄 목격: 엄지 척 / `♪` / 무시하고 하던 일 (「그건 회사가 알아서 할 문제죠!」). 정보로 팔 거리면 장부에 적기
- 동료가 맞음: 계약·이득 있으면 끼어듦, 없으면 무시 / `…` — 로어북 근거: "she stays bought exactly as long as the payment lasts"
- 동료가 쓰러짐: 엄지 척 / `…` / 무시 (「다른 사람의 죽음에 동요하지 않는다」). 이득 계산 나오면 도움

### 장허운 (Y조 마무리조 사원)
- 전투 가능: 예 (「전투 가치는 단 하나, 도망가지 않는다」, 체력·현장 적응력)
- 성격 근거: 「상황이 감당을 넘어서면 얼어붙는다」 / 「친절을 기억한다. 그리고 이자까지 쳐서 갚겠다고 맹세한다」
- 무기를 겨눔: 얼어붙음(턱 하얗게 질림) / `…` / 구부정하게 고개 숙이기. 도망가지 않음
- 시체를 봄: 얼어붙음 / `!` (「무, 무슨…」 충격) — 로어북 근거: "Prone to freezing when the situation exceeds him"
- 근처 소란: 얼어붙음 → 큰 목소리 지시가 나오면 그대로 따름 / `!`
- 범죄 목격: 얼어붙음 / `…` / 자신 있는 목소리가 시키면 그대로 따름 — 로어북 근거: "obeying confident voices in the gap where his own judgment should be"
- 동료가 맞음: 달려가 막아섬(대신 맞음) / `!`
- 동료가 쓰러짐: 달려가 업기(등이 곧게 펴짐) / `!` (「동료를 업고, 막아 주고, 끌어낸다」)

### 곽제강 (원료개발부 연구1팀 과장)
- 전투 가능: 아니오 (「전투력: 전무」)
- 성격 근거: 「호기심이 걸리는 순간 자기 보존 본능이 사라진다」 / 「흥미로운 시체 앞에서 콧노래를 흥얼거린다」
- 무기를 겨눔: 놀람(처음 몇 분 겁) → 눈 반짝이며 다가감 / `?` / 노트 꺼내 받아 적기 (격리 존재 심문 일화)
- 시체를 봄: 다가가 웅크려 관찰 / `♪` (콧노래)
- 근처 소란: 신나서 달려가 구경 / `!` / 노트 꺼내 관찰
- 범죄 목격: 웃음 참는 표정 / `♪` / 관찰 노트 적기. 막지 않음
- 동료가 맞음: 관찰 / `?` / 서류 톡톡·턱 문지르기. 돕지 않음 (요원을 「실험쥐」로 봄)
- 동료가 쓰러짐: 다가가 관찰 / `?` / 「아깝다!」류 반응은 시료 놓쳤을 때. 구조 근거 없음

### 이연화 (원료개발부 연구1팀 대리)
- 전투 가능: 아니오 (「전투: 없다. 조심성, 분석, 빌린 장비로 살아남는다」)
- 성격 근거: 「사고 현장에 도착하면 시료보다 다친 사람을 먼저 처치한다」 / 「진짜 잔혹한 것을 보면 손으로 입을 가린다」
- 무기를 겨눔: 침 삼키기 → 뒷걸음질 / `…` / 떨지만 서서 버팀(목소리 안 흔들림)
- 시체를 봄: 손으로 입 가리기 / `!` / 이후 웅크려 살펴봄(재구성)
- 근처 소란: 멈춤 / `!` / 「잠깐만요」 손짓, 주변 공지문 훑기
- 범죄 목격: 이 악물기 → 노려보기 / `#` / 다친 사람 있으면 먼저 처치. 질문으로 확인 (「옆방」 일화)
- 동료가 맞음: 달려감 → 무릎 꿇고 지혈 / `!`
- 동료가 쓰러짐: 달려감 → 무릎 꿇고 지혈 / `!` (다른 세력이어도 「피가 나니까요」)

### 이병진 (행정지원·매뉴얼 심사 과장)
- 전투 가능: 아니오 (「전투력: 없음」, 「현장에서는 무력하고, 당황하고, 소리를 지른다」)
- 성격 근거: 「위험이 닥치면 말을 더듬고, 빌고, 눈을 질끈 감고 얼어붙는다」 / 「공포와 이기심이 먼저, 수치심은 그다음」
- 무기를 겨눔: 웅크림 → 기어가 바짓가랑이 잡기, 손 비비기(빌기) / `!` / 땀 흘림
- 시체를 봄: 소리치기 → 눈 질끈 감고 얼어붙음 / `!`
- 근처 소란: 안경 벗어 닦기 → 뒷걸음질 / `?` / 손가락 꺾기
- 범죄 목격: 안경 닦기, 눈알 굴리기 / `…` / 못 본 척 — 로어북 근거: "fear and self-interest lead, shame follows"
- 동료가 맞음: 웅크림·소리치기 / `!` / 숨음. 목숨 구해 준 은인이면 땀 흘리며 다가감 — 로어북 근거: "real courage, limited to repaying a debt"
- 동료가 쓰러짐: 얼어붙음 / `!` / 남이 업어 주길 기다림. 구조 행동 근거 없음

## 4부

### 제이 (백일몽 보안관리부 경비 3팀·경비반장)
- 전투 가능: 예 (몸에서 그림자 늑대가 튀어나와 "대상을 짓뭉갠" 뒤 들어감)
- 성격 근거: 「위협이 감지되는 순간 동작이 기계처럼 정확해지고 눈빛이 바뀐다」 / 「회사가 위협받는다는 소식에도 시큰둥하다. 다만 자기 앞에서 사람을 해치려 들면 이야기가 다르다」
- 무기를 겨눔: 늘어진 서기 → 순간 공격 자세(눈 노랗게) / … / 모자챙 고치는 손짓 후 늑대 앞발로 반격
- 시체를 봄: 웅크림(살핌) / … / 가면 너머로 냄새를 맡아 살피고 주변 위협 감지 — 로어북 근거: "Enhanced smell through the mask" / "total ambient threat awareness"
- 근처 소란: 처음엔 무시하고 하던 일(어깨 으쓱) / … / 사람이 다치려 하면 달려감
- 범죄 목격: 절도·규정 위반은 무시하고 하던 일, 사람을 해치는 범죄면 달려감 / … / 해치는 쪽 앞에 섬
- 동료가 맞음 (자기를 사람 대접한 사람·민간인): 달려감 / ! / 맞는 사람을 자기 등 뒤로 보내고 막아섬
- 동료가 쓰러짐: 달려감 → 웅크림 / … / 들어서 옮김 (「다 큰 성인을 한 손으로 들고 다님」). 스트레스가 크면 폭주 위험(위키 약점)

### 호유원 (백일몽 이사·신설 프로젝트팀 후원)
- 전투 가능: 불명 — 직접 싸운 기록 없음. 대신 빙의(남의 몸을 멀리서 조종)·손등 금제·구미호병 — 로어북 근거: "Combat: never observed needing any, which is its own kind of statement"
- 성격 근거: 「놀라서 표정이 흐트러져도 1초 안에 원래 미소로 돌아온다」 / 「호유원은 호의로 사냥한다」
- 무기를 겨눔: 놀람(1초) → 미소로 서기 / ♪ / 손을 먼저 내밂 (「늘 먼저 내미는 따뜻한 손」)
- 시체를 봄: 무시하고 하던 일 / … / 시체 옆에서 구두에 흙 묻었는지 확인 (「시체를 밟고 선 채로 구두에 흙이 묻었는지 확인」)
- 근처 소란: 태연히 걸어감 / … / 예의상 콜록거리는 척 (불타는 복도 일화)
- 범죄 목격: 미소로 지켜봄 / ♪ / 약점을 쥐고 다가가 손을 내밂 — 로어북 근거: "Conceals purposes and engineers exploitation within those bounds"
- 동료가 맞음 (이병진 등 자기 계열): 지켜봄 / … / 위키·로어북 근거 약함
- 동료가 쓰러짐: 다가가 웅크림 / ♪ / 손을 잡고 걱정하는 얼굴 (병문안 일화: 다친 직원 손을 잡고 회복을 빌어 줌 → 영입)

### 청달래 (백일몽 개발본부·전무)
- 전투 가능: 예 (「직접적인 폭력에 관해서는 압도적」, 가볍게 손을 뻗자 상대가 쓰러짐)
- 성격 근거: 「쓸모 있는 것은 계약해야 하고, 계약한 것은 내 것이다」 / 「목소리를 높이는 법이 없다」
- 무기를 겨눔: 서기(흔들림 없음) / … / 가볍게 손을 뻗어 쓰러뜨림 ("전무실 출장")
- 시체를 봄: 서기 / … / 손실 보고서 양식 요구하는 손짓 (학살 현장 일화)
- 근처 소란: 천천히 걸어감(구두 소리) / ? / 「무슨 소란인가」 상황 정리
- 범죄 목격: 지켜봄 / … / 회사 것에 대한 침해면 천천히 걸어가 정리 — 로어북 근거: "Possessively regards the company and everything bound to it as hers"
- 동료가 맞음 (계약된 직원 = 자기 소유): 천천히 걸어감 / … / 정리하러 감 (근거: 「직원도…자기 것으로 여긴다」, 직접 일화는 없음)
- 동료가 쓰러짐: 서기 / … / 서류(징계 문구·청구서·분할 상환 일정)를 내밂 (죽어 가는 부하 일화)

### 차여진 (협회 의뢰조정실·의뢰 조정관)
- 전투 가능: 아니오 (「싸움은 못 한다. 할 필요도 없다」)
- 성격 근거: 「웃음이 반 박자 늦게 시작된다. 계산이 끝난 다음에」 / 「아 진짜 아깝다…아무튼, 너 이번 주에 시간 돼?」
- 무기를 겨눔: 뒷걸음질 / ! / 반 박자 늦은 웃음 (위키·로어북 근거 약함)
- 시체를 봄: 잠깐 아까워하는 표정 → 무시하고 하던 일 / … / 휴대전화를 봄 ("협회식 조의")
- 근처 소란: 슬쩍 자리를 뜸 / … / 화제 돌리듯 커피 타러 일어나는 식 (회의 일화 응용, 위키·로어북 근거 약함)
- 범죄 목격: 못 본 척, 하던 일 / … / 위키·로어북 근거 약함
- 동료가 맞음 (서윤지): 흘끔 봄 / … / 서윤지는 2년째 자기를 대조하는 불편 요소 — 로어북 근거: "Seo Yun-ji has been cross-checking for two years"
- 동료가 쓰러짐: 잠깐 아까워함 → 하던 일 / … / 휴대전화(두 대) 만지작 (부고 다음 문장 일화)

### 서윤지 (협회 의뢰조정실·의뢰 조정관)
- 전투 가능: 아니오 (「싸우지 않는다」)
- 성격 근거: 「손님이 웃어도, 울어도, 화를 내도 같은 눈이다」 / 「무시된 증거는 지워진 증거가 아닙니다」
- 무기를 겨눔: 꼿꼿이 서기(표정 변화 없음) / … / 시각 확인 후 수첩에 기록 — 로어북 근거: "Records every clause read, form presented and sequence, initialed and timed"
- 시체를 봄: 서기 / … / 수첩에 기록, 기록을 두 번 확인 (오전의 의뢰인 일화: 슬픔이 아닌 책임 공포)
- 근처 소란: 무시하고 하던 일(자세 그대로) / … / 「이 창구의 업무 범위 밖」
- 범죄 목격: 지켜봄 / … / 수첩에 기록 (기록 습관, 「무시된 증거는…」)
- 동료가 맞음 (차여진): 지켜봄 / … / 기록 — 로어북 근거: "Watches Cha Yeo-jin work from four feet away ... and logs it"
- 동료가 쓰러짐: 서기 / … / 기록 후 하던 일 (오전의 의뢰인 일화)

- 성격 근거: 「관객의 반응을 원한다. 겁에 질리는 건 당연한 반응이고, 놀라게 만들면 박수를 받는다」 / 「대놓고 반항한 사람에게 화를 내기는커녕 신나서 박수를 쳤다」
- 무기를 겨눔: 신나서 박수 / ♪ / 맨손으로 쳐냄, 끝까지 즐거워 보임 (반항에 박수 증언, 「끝까지 즐거워 보였다」)
- 시체를 봄: 다가가 웅크려 들여다봄 / ♪ / 재료로 봄, 자기 작품이면 이름을 부르며 다듬음 (「몸은 재료… 죽음은 표현 기법 중 하나」, 「자기가 만든 작품은 절대 잊지 않는다」)
- 근처 소란: 하이힐 소리 내며 빠르게 다가감 / ♪ / 위키·로어북 근거 약함 (관객 반응을 원한다는 것에서 추정)
- 범죄 목격: 지켜봄 / ♪ / 위키·로어북 근거 약함
- 동료가 맞음: 해당 없음 (「소속: 없음. 혼자서 하나의 세력」). 대신 마네킹이 부서지면 다른 마네킹에서 지지직 잡음 → 고개 듦 / … (마네킹 이동 증언)
- 동료가 쓰러짐: 해당 없음 (동료 없음)
- 참고: 준비한 서프라이즈를 너무 빨리 눈치채면 대놓고 삐짐 / # (「…너무 빨리 눈치채네. 짜증 나.」). 흥미로운 사람은 살려 두고 쪽지를 남김. 다가오기 전에 두통이 먼저 옴. 필드에 평소 나오는 인물인지는 위키상 의문(전시장 안에서만 목격).
