# 캐릭터별 제작 기획서 · 공통 규격

작성일: 2026-10-20 / 작성: Claude / 상태: 사용자 검토 전

이 폴더의 문서 하나가 요원 한 명이다. 각 문서는 혼자서 읽어도 그 요원을 만들 수 있게 쓴다. 여기 README에는 모든 문서가 공유하는 규격만 둔다. 상위 문서는 `../게임_기본기획서.md`(정체성·시스템·조작 부록 A)와 `../캐릭터_분석_및_플레이어블_선정.md`(누구를, 어떤 순서로)다.

## 1. 모든 요원이 공유하는 것 (그림은 공유하지 않음)

- **행동 목록**(2장 표의 행). 어떤 행동이 있는지는 같고, 모양은 전부 다르다.
- **프레임 수의 기준값**과 **첫/끝 고정 방식**(PixelLab `animate_image`에 첫·끝 이미지를 고정).
- **시간표의 틀**: 준비(startup) → 유효(active) → 회수(recovery). 수치는 요원마다 다르다.
- **크기**: 정자세 원본 키 128px, 캔버스 160×160(팔을 뻗는 공격은 192×160), 표시 2배. 발 기준점은 캔버스 아래에서 16px.
- **광원**: 왼쪽 위 45도, 외곽선은 어두운 같은 계열색(검정 단일선 금지), 팔레트 요원당 12~16색.
- **복장 공통**: 관리국 요원은 전원 검은 넥타이(사용자 확정 2026-10-20). 그 밖의 복식은 요원마다 다르다.
- **시점**: 오른쪽을 보는, 옆에 가까운 3/4. 좌우 반전으로 왼쪽을 만든다(비대칭 소품은 반전을 허용한다).
- **효과·소품·UI**: 타격 불꽃·먼지·속도선·탄피·아이템·문은 공용. 능력 효과(폭발·가시·그림자·염동·불·실)는 요원 고유.
- **재생 규칙**: 역재생(가드 해제·수납·일어서기), 마지막 장 유지(다운·조준·앉은 대기), 반전(방향), 코드 효과(히트스톱·흔들림·번쩍임).

## 4. PixelLab 제작 순서 (실측 2026-10-20)

1. 원작 외모 서술(위키)과 사용자 제공 원화를 참고해 **신규 기준표 1장**(정자세, 게임 시점)을 만든다. 기존 생성물·도트·시트·컷인은 참조 입력으로 쓰지 않는다(AGENTS.md).
2. 기준표를 사용자가 승인한다.
3. 대표 자세 6종(대기·걷기·달리기·점프·근접·원거리)을 먼저 뽑아 통일성을 검수한다.
4. 반복 동작은 열어 생성 → 접촉 장 고정 재생성(2회). 단발 동작은 기준 자세 첫·끝 고정(1회).
5. 매 결과를 측정(폭 변화, 디딤발 바닥선, 8→1 이음, 디딤발 이동량)하고 플레이 가능한 시연판에 넣는다.
6. 모든 차감을 `spend.log`와 `game-src/action/<요원>/log.json`에 적는다.

대사표에는 차원 승강기 투입 대사와 승강기 호명 반응 3줄(결정 D3)이 들어간다. 슈퍼아머 구간·부상 시 동작 변화·임시 무기 2클립의 요원별 모양은 `../게임_기본기획서.md` 부록 E·F를 따른다. 각 제작서 4장 표에 38·39행을 추가할 때 F.3의 요원별 예를 출발점으로 쓴다.
