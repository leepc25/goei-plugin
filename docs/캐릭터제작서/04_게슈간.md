# 게슈간 · 제작 기획서

문서 버전: 1.0 / 2026-10-20 / Claude / 상태: 사용자 검토 전 / 제작 순서: 4번

## 1. 원작 근거 (위키 「게슈간」)

- 종합대응팀 요원(전 격리 사고 진압 담당). 20대 중반 여성. 좌표 지정형 염동력. 3인조의 둔기. 사과는 두 글자. 문을 마주 보는 자리.
- 외모: 짧게 자른 눈처럼 하얀 머리, 차가운 파란 눈, 무덤덤한 표정. 운동선수처럼 탄탄한 체격. 헐렁한 흰 셔츠에 관리국 슬랙스. 한 손에 늘 큐브. 짐 가볍게.
- 능력: 눈이 지정한 지점에 거대한 힘이 정확히 떨어짐. 한 번 내리치고 다음까지 **한 박자**. 사람을 던지고, 머리를 터뜨리고, 공간 왜곡을 주먹 쥐어 짓뭉갬. 한계: 눈으로 지정해야 함, 보지 못한 표적 불가, 한 박자 사이에 방향 트는 상대는 빠져나감. 관찰 재능(자기를 보는 것을 알아챔). 근접: 염동력으로 고정·던지고·짓누르기 + 진압 시절 맨손 격투, 몸으로 들이받는 게 먼저.
- 성격: 말이 적고 경계심 강함, 낯선 사람 먼저 시험, 마음 연 사람에게 무뚝뚝하게 다정. 기관을 안 믿음. 로제몬에게 끌려가 줌. 아군 무기를 눈짓으로 날려 줌.
- 어록: 「그래. 미안.」 「알았어. 미안.」 「…총 잘 쏘네?」 「…해냈어. …해냈어…」

## 2. 플레이 정체성

**한 문장**: 보고, 한 박자, 떨어진다. 그 사이에 움직이는 놈만 산다.

- 거리: 근~중. 지정은 화면 안 어디든(시야).
- 수단: 염동력(지정 낙하·고정·던지기·압살) + 진압 격투(들이받기·메치기).
- 리듬: 지연형. 지정 → 한 박자 → 발동. 격투로 적을 세워 두고 염동으로 끝낸다. 맞추면 압도적, 빗나가면 틈.
- 강점: 제어 최고(고정·띄우기·던지기), 단일 표적 큰 피해, 물건을 손 안 대고 던짐.
- 약점: 지연, 빠른 적·시야 밖 적, 혼자 있을 때(로제몬·NPC가 가리켜 주면 지연 반감).
- 중급자용. 타이밍 게임.

## 6. 자원과 능력치

- 체력 3, 힘 4, 사격 4(지정), 방어 3, 속도 3, 경직 저항 3, 필살 충전 3.
- 고유기 자원: **집중**(한 박자 게이지, 지정마다 소모·자동 회복). UI는 눈 옆 작은 원.

## 7. 강화와 숙련

계열 「지정」·「진압」·「경계」:
- 지정: 지연 -30% / 빗나간 지점 범위 피해 / 고정 2.5초
- 진압: 메치기 범위 / 태클 거리 / 던진 적 충돌 피해 +50%
- 경계: 뒤에서 오는 적 자동 감지(미니맵) / 첫 피격 무효 / 문 마주 보면(방 입구 쪽) 피해 +15%
- 계열 완성: 지정 → 지연 없음 / 진압 → 모든 다운 적 자동 띄움 / 경계 → 난입 예고

숙련: 2, 3 연속 지정, 5 필살 2단계, 6 공간 왜곡 압살, 8 전용 유물 「큐브」(고정 중 피격 무시), 10 셔츠 색 변형(회색).

## 8. 지원 요원 기술

「…저기.」 — 적 하나 공중 고정 + 아이템 하나 플레이어 손에 배달(원작 무기 배달).

## 10. 효과·소품

- 지정 커서: 파란 원 + 십자(코드), 한 박자 동안 수축.
- 낙하: 지정 지점에 흰 수직선 1프레임 → 바닥 충격파.
- 고정: 적 주위 파란 테두리 점멸.
- 큐브: 8×8 삼색, 공중 회전 4장(요원 고유 소품).

## 12. 검수 기준

- 지정 장에서 눈 크기와 색 변화가 128px에서 읽힘.
- 주먹 쥐는 장이 분명(손가락 윤곽 변화).
- 격투 동작의 골반 회전이 힘 방향과 일치.
- 큐브가 전투 대기에서 몸과 겹치지 않음.

## 13. 임의로 정한 것

1. 지정은 자동 조준(가장 가까운 적) + 방향키로 바꿈. 마우스 강제 없음.
2. 가드가 지속 방어가 아니라 0.5초 밀어내기(원작에 지속 방어막 없음).
3. 큐브가 전투 중 공중에 떠서 따라다님(원작 "공중에서 한 바퀴" 확장).
4. 로제몬 지원 시 지연 반감.
