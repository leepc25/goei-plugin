## 2. 그림 규격 (기존 170클립과 똑같이)

- 캔버스 **192×144**, 투명 PNG, 오른쪽(동쪽)을 봄.
- 발바닥 선 **y = 136**, 기준 x **57**. 모든 장이 같은 위치 기준이다. 코드는 장마다 발 위치를 재지 않는다.
- 기준 그림 `game-src/action/jyaldi-v5/full/A2.png`(96×96), 캔버스에 놓은 판 `A2-pad.png`(192×144, (25,42)에 배치).
- 키 약 138px, 팔레트·체형은 `docs/캐릭터제작서/01_쟈알디.md` 2장. 머리 허리까지, 붉은 눈.
- 가구(부스·욕조·변기·칸막이)는 생성기가 그림 안에 같이 그려도 된다. 다른 생활 동작도 생성기가 침대·책상·사다리를 직접 그렸다.

## 3. 만드는 방법 (Claude가 쓴 방식, 그대로 써도 됨)

- 도구: PixelLab `animate_with_skeleton_v3`. 기준 그림 A2-pad + 장마다 18관절(COCO) 뼈대. 장 수별 비용은 3장 2회, 8장 3회, 15장 4회.
- 뼈대: `game-src/action/jyaldi-v5/scripts/rig.py`.
  - `P(hip, lean, s, h, 앞발, 뒷발, 앞손, 뒷손, ...)`로 자세를 만들고 `clip(이름, 영어 동작 설명, [자세들], 소품 설명)`으로 등록한다.
  - 앉은 자세는 `SIT(...)`, 누운 자세는 `BL(...)`·`SO(...)`를 참고한다.
  - `python3 rig.py <이름>`을 돌리면 `full/plan-*.png`에 뼈대 미리보기가 나온다. 생성 전에 확인한다.
- 생성: `cd game-src/action/jyaldi-v5/scripts && python3 gen_all.py <이름...>`.
  - 결과는 `full/clips/<이름>/NN.png`에 저장되고 `spend.log`에 기록된다.
  - 서버 오류로 끊기면 같은 명령을 다시 실행한다. 이미 넣은 일감을 이어받는다.
- 알려진 버릇: 8장 클립은 끝 장이 기준 그림으로 되돌아가고, 6장 클립은 끝 장이 흩어지는 일이 있다. 빌더의 `auto_trim`이 생활 동작 묶음에서 자동으로 빼 준다.
- 실패 시: 같은 방식을 글만 고쳐 다시 뽑지 않는다(AGENTS.md). 원인을 적어 사용자에게 보고한다.

## 4. 시연판에 넣기

1. `tools/jyaldi_life_defs.py`의 `LIFE` 목록 끝에 `('showerin', '씻기·집안일·운동', '샤워 부스 들어가기', 8, False)`처럼 한 줄씩 넣는다. 형식은 (클립, 분류, 이름, fps, 반복)이다.
2. `python3 tools/build_jyaldi_full_demo.py`를 실행하면 `release/demo/jyaldi-full.html`이 만들어진다. 출력의 `missing`이 비어 있어야 한다.
3. 시연판 아래 「동작 목록」에서 눌러 재생해 확인한다.
4. `docs/캐릭터제작서/공통_생활동작목록.md` 표에 같은 행을 추가한다.
