## 2. 그림 규격 (기존 170클립과 똑같이)

- 캔버스 **192×144**, 투명 PNG, 오른쪽(동쪽)을 봄.
- 발바닥 선 **y = 136**, 기준 x **57**. 모든 장이 같은 위치 기준이다. 코드는 장마다 발 위치를 재지 않는다.
- 기준 그림 `game-src/action/jyaldi-v5/full/A2.png`(96×96), 캔버스에 놓은 판 `A2-pad.png`(192×144, (25,42)에 배치).
- 키 약 138px, 팔레트·체형은 `docs/캐릭터제작서/01_쟈알디.md` 2장. 머리 허리까지, 붉은 눈.
- 가구(부스·욕조·변기·칸막이)는 생성기가 그림 안에 같이 그려도 된다. 다른 생활 동작도 생성기가 침대·책상·사다리를 직접 그렸다.

## 3. 만드는 방법 (Claude가 쓴 방식, 그대로 써도 됨)

- 도구: PixelLab `animate_with_skeleton_v3`. 기준 그림 A2-pad + 장마다 18관절(COCO) 뼈대. 장 수별 비용은 3장 2회, 8장 3회, 15장 4회.
- 뼈대: `game-src/action/jyaldi-v5/scripts/rig.py`.
  - `P(hip, lean, s, h, 앞발, 뒷발, 앞손, 뒷손, ...)`로 자세를 만들고 `clip(이름, 영어 동작 설명, [자세들], 소품 설명)`으로 등록한다.
  - 앉은 자세는 `SIT(...)`, 누운 자세는 `BL(...)`·`SO(...)`를 참고한다.
  - `python3 rig.py <이름>`을 돌리면 `full/plan-*.png`에 뼈대 미리보기가 나온다. 생성 전에 확인한다.
- 생성: `cd game-src/action/jyaldi-v5/scripts && python3 gen_all.py <이름...>`.
  - 결과는 `full/clips/<이름>/NN.png`에 저장되고 `spend.log`에 기록된다.
  - 서버 오류로 끊기면 같은 명령을 다시 실행한다. 이미 넣은 일감을 이어받는다.
- 알려진 버릇: 8장 클립은 끝 장이 기준 그림으로 되돌아가고, 6장 클립은 끝 장이 흩어지는 일이 있다. 빌더의 `auto_trim`이 생활 동작 묶음에서 자동으로 빼 준다.
- 실패 시: 같은 방식을 글만 고쳐 다시 뽑지 않는다(AGENTS.md). 원인을 적어 사용자에게 보고한다.

## 4. 시연판에 넣기

1. `tools/jyaldi_life_defs.py`의 `LIFE` 목록 끝에 `('showerin', '씻기·집안일·운동', '샤워 부스 들어가기', 8, False)`처럼 한 줄씩 넣는다. 형식은 (클립, 분류, 이름, fps, 반복)이다.

3. 시연판 아래 「동작 목록」에서 눌러 재생해 확인한다.
4. `docs/캐릭터제작서/공통_생활동작목록.md` 표에 같은 행을 추가한다.

## 6. 수정 요청 (2026-10-21, 사용자 지적 + Claude 장 단위 확인)

화장실 3클립은 Claude 쪽에서 다시 뽑았다. 아래 샤워·목욕 6클립을 GPT가 다시 만든다. 규격은 2장 그대로(192×144, 발바닥 y=136, 기준 x=57, 오른쪽을 봄). 체형은 옷 입은 대기 장과 같음을 실측으로 확인했으니(머리 y37~발 y135) 그대로 둔다.

**가구는 그리지 않는다.** 캐릭터만 그리고 부스·욕조는 게임이 따로 그린다(사용자 지시: 캐릭터 그림에 사물을 같이 그리면 결함). 그래서 동작은 빈 공간에서, 가구가 있을 자리를 기준으로 한다.

1. `showerin` / `showerout` (사용자: "샤워부스 들어가고 나오는건 왜저래")
   - 지금: 문을 열지 않고 유리 벽을 통과해 들어가고, 안에 들어가면 몸이 회색 반투명 덩어리로 바뀜. `showerout`은 `showerin`을 거꾸로 돌린 것과 같음.
   - 고칠 것: 앞쪽 손으로 문 손잡이를 잡아 당겨 열기 → 한 발 들어 문턱 넘기 → 들어가서 돌아서 문 닫기. 몸은 끝까지 불투명. 나오기는 따로 그림(문 밀어 열기 → 나와서 문 닫기).
2. `shower` (사용자: "머리감을땐 팔이 꺼꾸로 꺾여지고")
   - 지금: 3~5장에서 팔꿈치가 등 뒤로 꺾임. 0~2장 머리색이 회청색(코드로 덮어 둠).
   - 고칠 것: 두 손을 머리 위로 올려 앞쪽에서 머리 감기, 팔꿈치는 얼굴 옆 앞쪽을 향함. 어깨·팔꿈치·손목 순서가 자연스럽게(뼈대 미리보기 plan-*.png로 먼저 확인). 머리색은 모든 장 검정.
3. `bathin` / `bath` / `bathout` (사용자: "목욕도 씨발 왜저러고")
   - 지금: 2장에서 욕조 가장자리에 걸터앉은 다리가 욕조 벽을 뚫고 나옴. 3장 이후 몸이 물 위에 떠서 욕조 앞 가장자리 위에 얹혀 보임(잠기지 않음). `bath`의 김이 만화풍 흰 구름이라 다른 그림과 안 맞음. `bathout`은 `bathin`을 거꾸로 돌린 것.
   - 사용자 추가 지적: "45도 각도 욕조가 있냐", "양발끝부터 붕 떠서 들어가냐". 지금 몸이 45도로 비스듬히 누워 있고, 들어갈 때 두 발이 같이 떠서 미끄러져 들어감.
   - 고칠 것: 들어가기는 한 손으로 가장자리를 짚고 → 앞발 하나를 들어 넘겨 물에 딛고 → 뒷발을 넘기고 → 무릎 굽혀 앉기(한 번에 한 발, 두 발이 동시에 뜨지 않음). 담근 자세는 등을 거의 세워 욕조 끝에 기대고(상체 기울기 20도 안쪽) 무릎은 물속에서 굽힘, 어깨·머리만 가장자리 위로 보임. 욕조 높이(바닥에서 약 30px)를 기준으로 몸은 가슴 아래가 욕조 앞 가장자리 높이(y≈106) 아래로 내려가게. 김은 그리지 않음(게임이 코드로). 나오기는 따로 그림.
4. 같은 방식을 글만 고쳐 반복하지 말 것(AGENTS.md). 바꾼 방법과 비용을 spend.log에 적기. 다 되면 `python3 tools/build_jyaldi_full_demo.py`로 빌드하고, 이 6클립의 `full/split/<이름>/` 폴더는 지운다(새 그림엔 가구가 없으므로).

### 6-추가. 캐릭터만 그리기 (2026-10-21 15시 사용자 지적: "부스까지 다 그려 놓으면 어떻게 배치하라고")

- 샤워부스·유리문·욕조·세면대·변기·김·물줄기를 **전부 빼고 캐릭터만** 그린다. 빈 공간에서 문을 여는 손, 욕조 가장자리를 넘는 다리, 앉는 자세만 있으면 된다.
- 대신 장마다 접촉 위치를 192×144 칸 px로 적어 넘긴다: `handle`(문손잡이를 쥔 손), `rim`(욕조 가장자리 높이·발이 넘는 x), `seat`(변기 좌판 높이). 게임이 그 좌표에 부스·욕조·변기를 따로 그린다.
- 기존 full/split/<클립> 폴더는 다시 생성 후 지운다(빌더가 split을 먼저 읽음).
