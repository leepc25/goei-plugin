## 2. 외형 기준 (기본 그림 확인)

참고 그림: `assets/agents/Deadpole_default.avif` (832×1216, 사용자 제공 2026-10-19). 권총 아이콘: `game-src/art/items/dot/sig_deadpole_pistol.png`.

기본 그림에서 읽은 것:
- **앞머리를 일자로 자른 히메컷**, 옆머리도 일자로 떨어짐, 허리 아래까지 오는 긴 검은 생머리. 쟈알디와 가장 큰 차이(쟈알디는 앞머리를 옆으로 넘김).
- 눈: 크고 동그란 갈색(쟈알디는 붉은 눈), 볼 홍조, 옅은 미소.
- 짙은 숯빛 정장(쟈알디보다 따뜻한 회갈색 기운), 흰 셔츠, 검은 넥타이, **검은 장갑**, 바지.
- 기본 자세: **두 손을 배 앞에서 맞잡고, 고개를 살짝 기울인 채 섬.** → 기본 대기 그대로.
- 몸: 가늘고 어깨가 좁음.

도트 규격: 쟈알디와 같은 192×144 캔버스, 발바닥 y=136, 기준 x=57, 오른쪽을 봄. 키는 쟈알디(대기 장 머리끝~발 약 99px)의 약 88% = **약 87px**. 뼈 길이(rig THIGH·SHIN·UARM·FARM·TORSO)를 0.88배.

구별 검사(생성 후 자동): 대기 장 머리끝 y가 쟈알디보다 10~14px 아래, 이마에 앞머리 일자선, 눈 색이 갈색 계열.

## 3. 동작 근거 (실제 동작 자료)

| 쓰는 곳 | 바탕 | 요점 |
| --- | --- | --- |
| 뽑기 | 경찰·사격 교본의 **4단계 뽑기**(잡기 → 뽑아 총구 앞으로 돌리기 → 가슴 앞에서 두 손 만남 → 뻗기) [교본] | 데드폴은 1·2단계를 한 장, 3·4단계를 한 장으로 압축(2장). 2단계 자세에서 바로 쏠 수 있음 = 리텐션 사격 |
| A 1타 | **리텐션(밀착 유지) 사격 자세**: 총을 가슴 옆에 붙이고 팔꿈치를 뒤로 당겨, 붙은 상대에게 총을 뺏기지 않고 쏨. 다른 손(장갑)은 얼굴 앞을 막음 [교본: 근접 사격 「Position 2/리텐션」] | 몸통 비틀기 작게, 발은 그대로 |
| A 2타 | **이소슬리스 자세**로 내디디며 두 손을 뻗음, 더블탭(2발 연속) [교본] | 앞발 짧게 내디딤, 두 팔 쭉, 어깨가 귀 쪽으로 움츠러들지 않게 |
| A 3타 | 밀착 3발 + **장갑 손바닥 밀어내기**(크라브마가 근접 거리 만들기: 손바닥으로 가슴 밀고 물러서며 쏨) [교본] | 3발 동안 고개 까딱(사과), 마지막 장에 뒷발로 물러섬 → 묵직한 마무리 |
| S | 이소슬리스 정조준. 정지 사격이 이동 사격보다 정확함 [교본] | 서 있으면 피해 ×1.3 |
| 재장전 | **긴급(스피드) 재장전**: 탄창 버림 → 새 탄창 → 슬라이드 [교본] | 빈 탄창은 떨어짐(효과는 코드) |
| 걸음(전투) | **뒤꿈치-발끝 굴려 걷기**(사격하며 걷기, 무릎 굽혀 상체 흔들림 흡수) [교본] | 쟈알디의 복싱 밀고 끌기와 다름 |
| 달리기(전투) | 총구를 아래로 향한 **낮은 준비 자세**로 뜀(가슴 앞 두 손) [교본] | 작은 보폭, 높은 회전 |
| 앞구르기 | 유도 **앞구르기 낙법(마에 마와리 우케미)**: 앞손·어깨 바깥쪽으로 비스듬히 구르고 무릎으로 일어남 [교본] | 끝 자세 = 한쪽 무릎 쏴 |
| 슬라이딩 | 야구 **슬라이딩**(앞다리 펴고 뒷다리 접고 엉덩이로 미끄러짐) + 누운 자세 사격(방어 사격 교본의 등 대고 쏘기) [교본] | 높은 공격 밑으로 지나감 |

## 7. 만드는 방법

1. 기준 그림: `create_image_pixen`(옆모습, 오른쪽, 기본 그림 외형 설명) 후보 4장 → 기본 그림·쟈알디와 나란히 비교해 Claude가 고름(히메컷 앞머리, 키 87px, 갈색 눈, 옆모습). 고른 그림을 이 스레드에 올림(멈추지 않고 계속 진행, 잘못됐으면 사용자가 바로 세울 수 있게).
2. 옆모습 고정: 고른 그림으로 기본 대기 뼈대 1회 → 옆모습으로 나온 장을 모든 클립의 기준 그림으로(쟈알디 guard/00 방식, 3/4 정면 돌아감 방지).
3. 뼈대: `game-src/action/deadpole/scripts/rig.py` — 쟈알디 rig.py의 P()·IK·anatomic()을 가져오되 뼈 길이 0.88배, 자세는 이 문서 5장대로 전부 새로 씀. 자동 검사: 팔꿈치 방향(audit_joints), 발바닥 y=136, 어깨 회전 s ≤ −0.25(옆모습), 쟈알디 같은 이름 클립과 관절 좌표 비교해 **거의 같으면 실패**(복사 금지 검사).

## 8. 엔진에 새로 필요한 기능 (「게임 마무리 한 곳에서」로 넘김)

지금 엔진(src/game/action/engine/player.ts·moves.ts)은 쟈알디 전용이다. 데드폴을 넣으려면:

1. **요원별 기술표**: Player가 MOVES·COMBO·수치(체력·탄창·속도·넉백 배율)를 요원 정의에서 받음. 입력 → 동작 연결도 요원별(A가 탄을 쓰는지, D가 공격인지).
2. **근접 사격 판정**: A 연타가 탄을 1/2/3발 소모, 판정은 짧은 사거리 히트스캔(총알 몸체 아님), 탄 0이면 딸깍 → 자동 긴급 재장전.
3. **빠른 뽑기 = 첫 발**: draw 2장째에 발사, 집어넣기는 전투 끝 뒤 자동.
4. **정지 사격 보너스**: S가 이동 안 했으면 피해 ×1.3.
5. **다운 추격**: 무릎 쏴가 쓰러진 적을 맞힘(지금은 다운 중 판정 없음).
6. **슬라이딩 낮은 몸**: 미끄러지는 동안 맞는 상자를 낮춤, 높은 공격 무시.
7. **앞구르기 통과**: 무적 + 적과 몸 충돌 끔, 끝나면 A가 무릎 쏴로 이어짐.
8. **칼날 잡기**: Q 짧게 6틱 창, 적 공격에 종류 꼬리표(날붙이·맨손·둔기·총알·능력) 필요, 성공 시 적 「붙잡힘」 반응(40틱) + 자동 반격.
9. **막아서기**: Q 길게 = 피해 100%·넉백 0·뒤쪽 아군/생존자 피해 0·필살 게이지 2배. 가드 게이지 없음.
10. **되감기**: 받은 피해 3초 기록, D로 그만큼 회복, 대가로 단서·지도 1개 잊기(이야기·지도 모듈 연결), 쓰기 전 표시.
11. **냄새 추적**: D 길게 = 눈 감음 상태, 반경 늘어남, 놓으면 숨은 문·회수물·숨은 적에 점선 화살(층 생성 데이터 필요). 앉아 D = 발자취 화살표.
12. **죽음과 부활**: 체력 0 → `die` → 누움 4초(맞으면 연속 사망) → `revive`, 체력 100%·상태이상 해제·2초 무적, 출동당 3회, HUD 하트. 4번째 = 후송. 부활 횟수 숙련·강화로 바뀜.
13. **필살 선두 노출**: 도발(모든 적 목표 = 데드폴) 3초, 받은 피해 합산 → 쓰러짐 → 합산 ×2 범위 피해 → `superrise`(횟수 안 씀). 필살 게이지가 받은 피해·죽음으로 참.
14. **배대뒤치기**: 던진 적이 데드폴 뒤쪽에 떨어지고, 데드폴은 누운 상태로 끝나 `getup` 18틱.
15. **넉백 배율**: 받는 넉백 ×1.3.
16. **기생체 퇴거(숙련 3)**: 오염·최면 등 상태이상이 걸리면 `purge` → 죽음 → 부활(횟수 안 씀).
17. **타인 되감기(숙련 6)**: 동행 NPC·생존자 회복, 대가로 그 NPC 대사 1개 지움(이야기 모듈).
18. **지원 기술**: 다른 요원이 C로 부르면 `support`로 등장, 2초간 플레이어 피해를 데드폴이 대신 받음.
19. **냄새 맡는 동안 동행 NPC 대사 끊김**(원작 「일제히 조용해진다」).
20. **눈 세 가지**: 표정 층(둥긂·가늚·감음)을 따로 그려 상태에 따라 얹을지, 클립 그림에 포함할지는 생성 결과를 보고 정함(128px 기준 눈 3px이라 그림 안에서 구별되는지 검수).
