## 생성과 내보내기

- 내장 ImageGen 사용. PixelLab 호출 0회. 기준 `game-src/action/kyuras/base/A.png`, 기존 idle, 쟈알디 채택본의 크기와 구도를 열람했다. 쟈알디 이미지를 생성 입력으로 사용하지 않았다.
- 첫 장은 큐라스 A.png를 참조하고, 이후는 이번에 생성한 큐라스 장을 참조하여 인물·색·비율을 연결했다.
- 최종 파일은 모두 192×144 RGBA PNG. 생성 원본은 nearest-neighbor 방식으로 축소하고 투명 캔버스에 배치했다. 서 있는 클립은 동일 변환, 앉은 클립은 동일한 별도 변환을 사용하며, 앉은 키를 서 있는 키로 확대하지 않았다.
- 투명 가장자리의 극저알파 잔색을 정리했다. 탈의 05의 지지발은 최종 내보내기에서 아래로 1px 보정했다.
- 욕실·욕조·물줄기·바닥·벗은 옷을 PNG에 포함하지 않았다. 샤워 거품은 머리 위에만 있다.

## 확인한 것과 적용 범위

- 20장 존재, 크기 192×144, 투명·불투명 픽셀 모두 존재, 각 클립 안 픽셀 내용 중복 없음 검사.
- 20장 접촉 시트를 직접 열어 인물·수건·자세·불필요한 물체 유무를 검토했다. 발바닥 최하단은 135~136px이며, 샤워의 머리/손 높이는 동작에 따라 달라진다.
- `release/demo/kyuras-bathing.html`은 이번 20장의 PNG를 내장한 단일 HTML. 동작 선택·일시정지·한 장 넘기기·배율·속도·키보드 위치 이동을 제공한다. 빌더: `python tools/build_kyuras_bathing_demo.py`.
- 본편 게임 엔진에 행동을 연결하거나 기존 큐라스 시연판을 교체하지 않았다. 이 납품은 요청된 그림과 별도 확인용 시연판이다.
- 브라우저 실행 파일이 환경에 없어 실제 브라우저 재생 검사는 수행하지 못했다. DOM/canvas 모형 실행에서 HTML 스크립트의 4개 동작 선택·프레임 전환·20장 내장을 확인했다. 사용자의 최종 시각 승인이나 Claude의 채택 판정과는 구분한다.
