## 이번에 만든 것

- 사용자 결정(03:17)대로 **전투·이동을 먼저** 만들었다: 본체 전투 54클립 + 지형 이동 3(돌아서기·낙하·착지) + 벽 기대기(수동 능력이라 앞당김) + 꼬마 인형 12 + 마네킹 12 = 82클립. 이미 받아 둔 기본 클립 14개(손 뻗기·당기기·의자 앉기 등)도 들어 있다.
- 시연판은 로제몬 규칙으로 따로 짰다(쟈알디 판을 고쳐 쓴 것이 아님). 본체 판정 0, 꼬마가 박자마다 날아가 대신 때림, 3박은 실로 적을 끌어와 엎음, 최면 동전 던지기(성공 = 등 돌려 떠남, 실패 = 눈 감싸고 그 적이 달려듦), 실 걸기(쓰러진 마네킹·쓰러진 적 → 아군 인형, 실 2가닥), 웅크리면 꼬마가 끌려와 대신 맞음, 끌려가기 회피, 멱살 → 노려보기 2번 → 「돌아가.」(그 적이 다른 적과 싸움), 앙상블 → 주저앉아 간식, 왼쪽 벽에 기대면 게이지가 빨리 참, 다운되면 실이 전부 끊김.
- 실은 장마다 앞손 좌표에서 인형 머리로 그린다(manifest `anchors`의 `hand`·`head`).
- PixelLab 사용: 이 스레드 약 330회(기준 그림 포함), 상한 712회 안.

## 그림 결함 (장 단위 검수)

코드로 고친 것
- down 07: 끝 장이 선 자세로 되돌아가고 회색 얼룩 → 뺌
- getup 00·01: 머리에 회색 노이즈 → down 06(누운 장)으로 바꿈
- wfire 01~04: 총구 앞에 떨어진 회색 연기 덩이 → 지움(00의 총구 불꽃은 둠)
- kid_ankle 04, man_sweep 02 등: 몸과 떨어진 작은 점 → 지움(모든 클립 공통)
- 발이 바닥선 아래로 1~8px 빠진 장(crouch·lowcue·jump 일부, man_limp·man_rise·man_break 누운 장) → 바닥선(y=136, 꼬마 88)으로 올림

남은 것(다시 뽑거나 손으로 고쳐야 함)
- down 03~06, man_throw 03~04: 뒤로 젖힌 머리카락·머리가 그림 왼쪽 끝에서 잘림
- downbeat 00: 머리 위로 든 두 주먹이 갈색 덩어리로 뭉개짐
- drink 01~05: 생성기가 갈색 병을 손에 같이 그림(물건은 따로 그린다는 규칙 위반). 시연판은 엔진 컵을 빼서 겹치지 않게만 함
- wswing: 쇠파이프 대신 손에 작은 검은 고리가 그려짐(파이프는 엔진이 손 좌표에 그림)
- wfire: 설계는 「고개 돌린 채 쏨」인데 과녁을 똑바로 봄
- turn: 3장 모두 거의 같은 옆모습(돌아서는 중간 자세 없음). 엔진은 좌우 뒤집기로 대신함
- man_limp·man_rise·man_break 누운 장: 바닥에 닿는 쪽 몇 px가 원래 캔버스 밖이라 잘려 있음
