## 2. 1차 독립 검수(04:10, 불합격) 뒤 고친 것

| 검수 지적 | 처리 |
|---|---|
| 칼날 잡기에 권총 두 자루, 옷깃 잡기가 잡기 장 복사 | 둘 다 다시 생성(빈손으로 움켜쥠). 잡으면 접사 그림으로 배에 대고 맞쏘기(`counter`)로 이어지게 조작 수정 |
| 접사: 총이 얼굴 높이, 다른 손이 배 | 다시 생성: 앞손 주먹은 가슴, 총은 배 높이 |
| 필살·막기·지원: 팔을 안 벌림 | 다시 생성: 두 팔을 어깨 높이로 앞뒤 쭉 폄 |
| 근접 사격 총구가 위, 슬라이딩이 하늘로 쏨, 공중 사격이 수평 | 다시 생성: 근접 사격 앞으로, 슬라이딩 앞 비스듬히 위, 공중 사격 비스듬히 아래 |
| 줍기에 회색 상자가 그려짐 | 다시 생성(빈손) |
| 얼굴이 청회색·유령처럼 보임 | 원인은 코드 보정(불꽃 지우개)이 팔레트 밖 밝은 살색을 지워 얼굴에 구멍을 낸 것. 얼굴 살색 덩어리는 지우지 않게 고침 |
| 누운 장이 뜨거나(쓰러짐) 가라앉음(기기·구토 쓰러짐) | 바닥에 붙는 클립은 장마다 바닥선(135줄)에 맞춤 |
| 머리 둘레 연기 같은 번짐(슬라이딩·일어나기 등) | 투명에 닿은 청회색·무채색 점을 바깥부터 벗겨 냄 |
| 산탄총·공중 사격·옷깃 총구 끝 주황 점 | 지움 |
| 부활 마지막 장 얼굴 앞 회색 네모, 무릎 걷기 마지막 장 튐 | 그 장을 뺌 |

다시 생성 10클립에 약 33회.

## 3. 남은 그림 결함

| 클립 | 결함 |
|---|---|
| roll | 구르는 2~3장이 팔다리 없는 덩어리로 보임 (16fps라 게임 속도에선 짧음) |
| pipe 1 | 파이프가 캔버스 왼쪽 끝(x=0)에서 잘림 (배대뒤치기·쓰러짐·필살 부활은 2차 검수 뒤 오른쪽으로 옮겨 다시 생성, origin으로 위치 보정) |
| super·cover·support | 셋 다 끝 자세가 「두 팔 앞뒤로 폄」으로 같아 구분이 약함. 뒷팔이 머리카락 사이로 짧게 튀어나옴. 필살은 게임에서 끝 장을 3초 붙잡아 읽히긴 함 |
| catch → counter | 잡기 끝 장에서 맞쏘기 첫 장으로 넘어갈 때 머리가 약 9px 튐 |
| tomoe 1~2, getup 0~2 | 머리 둘레 어두운 번짐이 조금 남음 |
| cq1·cq3 | 리텐션 총이 얼굴 높이, 3타 끝 손바닥 밀기가 안 보임 |
| reload | 탄창 갈아 끼우는 손이 안 보임(탄창은 게임이 그림) |
| mantle | 턱을 잡는 손 없이 위로 떠오름 |
| 산탄총 소품 | 대기·걷기·달리기·쏘기에서 산탄총 모양이 제각각 |
| pipe | 휘두르기 0·6장 잔상, 3장에서 파이프가 몸 뒤로 숨음, 길이가 장마다 다름 |
| sniffground 2~5 | 긴 머리가 엉덩이에서 짧게 끊김 |
| run | 총이 안 보임(빈손 달리기) |
| holster 0, draw 2 | 넣기 첫 장에 총 없음, 뽑기 끝이 한 손 조준 |
| talk | 입 벌린 장은 코드로 2점 찍은 것 |
| undress 00~04 (GPT) | 2차 기준으로 그려져 정장 색은 코드로 바꿈. 머리카락 흩날림, 4~5장 수건 위 흰 점 |
| GPT 씻기 4클립 | 외곽선이 두껍고 명암이 평평해 톤이 조금 다름 |
