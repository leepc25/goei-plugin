## 3. 게임 규칙 (엔진 구현 기준)

### 3.1 시간표 (30Hz 틱)

- 빠른 적(태그 fast)은 지정 후 한 박자 안에 0.5칸 이상 움직이면 빗나감. 빗나간 자리에 효과만 남음(흰 수직선 + 바닥 파문).
- 로제몬 지원·동행 NPC가 적을 가리키면 그 적에게는 지연 6틱(원작 "가리키면 훨씬 무섭다").
- 데드폴 동행 시 아군 오폭 판정 있음(원작 "주먹 쥘 때 움직이지 않기"). 데드폴만 맞음, 죽어도 되살아남.

### 3.2 능력치·자원

- 체력 3, 힘 4, 지정 4, 방어 2(유지 가드 없음), 속도 4, 경직 저항 3, 필살 충전 3.
- 집중 3칸(눈 옆 작은 원 3개). 큐브 회전 속도 = 남은 집중(엔진).

### 3.3 강화·숙련

04 문서 7장을 그대로 쓰되 "가드" 관련 항목만 쳐내기 판정 +3틱으로 바꿈. 숙련 3 = 연속 지정(chain2), 숙련 6 = 공간 왜곡 압살(grabcrush 공유).

## 4. 클립 표 (생성 대상 전체)

쟈알디 최종 136클립과 1:1로 맞추되, 쟈알디 전용(권총 뽑기·집어넣기·사격·장전, 쇠파이프·산탄총 들고 서기·걷기·달리기, 벽돌, 장갑)은 게슈간식으로 바꾸거나 엔진이 대신하므로 뺐다. 손전등 3클립은 "공중에 띄움"이라 생성 없음(평소 걷기 그대로). 「대응」 칸은 같은 자리에 쓰이는 쟈알디 클립이고, 그림·뼈대는 하나도 가져오지 않는다.

## 5. 만드는 법과 비용

1. **기준 그림**: 기본 이미지를 보고 옆모습(오른쪽) 도트 한 장. 쟈알디 A2와 같은 크기·화풍(192×144 캔버스, 발바닥 y=136)으로, 처음부터 **옆모습**(3/4로 뽑으면 클립마다 정면으로 돌아감, 쟈알디 교훈). 후보 몇 장 → Claude가 기본 이미지와 나란히 비교해 고름 → 사용자에게 한 장 보여 주고 멈추지 않고 진행. 약 30회 이내.
2. **뼈대**: `game-src/action/geshugan/scripts/rig.py`를 새로 씀(쟈알디 rig의 IK·팔꿈치 보정 함수만 가져오고 자세는 전부 새로). 몸 비율 = 어깨 넓게, 허벅지 굵게, 키 약 97%. 클립마다 실제 동작 자료(레슬링·유도·파쿠르)와 대조, `audit_joints.py`식 자동 검사(팔꿈치 방향, 발 접지, 옆모습) → 뼈대 미리보기(생성 0) 확인.
3. **생성**: animate_with_skeleton_v3, 기준 그림 한 장에서 122클립 전부. 프롬프트는 몸 자세만(물건·가구 이름 금지).
4. **검수·보정(Claude가 전부)**: 장 단위 전수 검사(팔꿈치·목·손가락 수·옆모습·의상 색 흔들림·가구 섞임), 코드 보정(장 빼기·덧그림), 그래도 안 되면 그 클립만 뼈대 고쳐 다시 생성. 손·소품 좌표(hands.json), 앉기·눕기 골반 점.
5. **납품**: `release/demo/geshugan-full.html`(쟈알디 시연판과 같은 형식, 휴대폰 링크 포함) + `docs/캐릭터제작서/게슈간_결함목록_<날짜>.md` + 사용 횟수.

## 6. 엔진에 새로 필요한 것 (「게임 마무리 한 곳에서」로 넘김)

지금 `src/game/action/engine/player.ts`·`moves.ts`는 쟈알디 전용(탄창 MAG=8, combo jab→cross→power, blast·grabblast 하드코딩). 게슈간을 넣으려면:

1. **요원별 동작표·조작기 분리**: MOVES와 입력→동작 연결을 요원 데이터로(쟈알디 하드코딩 제거).
2. **지정 커서**: 가장 가까운 보이는 적 자동, 방향키로 바꾸기, 수축하는 원 + 십자, 시야(벽·화면 밖) 판정.
3. **지연 발동 판정**: 입력 장과 판정 장이 다르고, 그 사이 대상이 0.5칸 이상 움직이면 빗나감(fast 태그). 빗나간 지점 효과.
4. **집중 자원** 3칸 + 회복 + 「집중 회복」 동작 중 2배. 탄약·재장전 UI를 요원별로 바꿈.
5. **적 상태 「고정」**: 공중에 뜬 채 멈춤, 피격 반응 없음, 유지 중 방향키로 끌기, 놓으면 투사체가 되어 다른 적과 충돌 피해.
6. **연계 분기 조건**: 3타는 대상이 공중일 때만, 쓰러진 적 위 A = 압살.
7. **쳐내기 가드**: 유지형이 아닌 짧은 판정 창, 투사체 반사, 실패 시 50% 피해 + 긴 회수.
8. **4방향 염동 도약**: 위·아래(깊이)도 같은 그림, 충돌 무시 무적.
9. **관찰 패시브**: 뒤쪽 공격 예고 「!」, 그 창 안의 Q·Shift 완벽 판정.
10. **낙법 기상**: 다운 중 Space로 즉시 기상.
11. **띄운 물건**: 무기·손전등·큰 물건을 손 좌표가 아닌 어깨 옆 공중 기준점에 붙여 흔들림과 함께 그림. 둔기 휘두름은 그 물건 자체를 코드로 회전. 줍기 사거리 2칸(물건이 날아옴).
12. **큐브 소품**: 대기 때 손, 전투 때 어깨 옆에 떠서 따라옴, 다운 때 떨어졌다 기상 때 날아옴, 회전 속도로 감정·집중 표시.
13. **필살기 전원 들어 올리기**: 화면 안 적 전부 고정 → 일괄 낙하.
14. **동행 연계**: 로제몬·NPC가 가리킨 적은 지연 6틱, 데드폴 오폭.

## 7. 임의로 정한 것 (사용자 확인 대상)

1. 넥타이: 기본 이미지엔 없지만 공통 규칙대로 맴(빼라고 하면 뺌).
2. 기본 공격에 주먹질 없음, 2·3타가 염동(원작 근접 교리 "격투 위에 염동을 겹친다"를 연계 안에서 구현).
3. 유지 가드 없음, 쳐내기만(원작에 방어막 없음).
4. 회피가 구르기가 아니라 염동 도약(데드폴 앞구르기와 안 겹치게, "도망칠 때 쓰는 발").
5. 무기·큰 물건·손전등을 손에 들지 않고 띄움.
6. 「소리 지르기」 자리에 「노려보기」, 「손 흔들기」는 두 손가락만, 「가리키기」는 턱짓.
