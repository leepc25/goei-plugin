## 0. 무엇으로 다른가 (게임 규칙 기준)

한 줄 리듬: **"쇼 → 시청률 → 판정"**. 브라우니는 싸우는 상대가 아니라 **진행자**다. 그의 방에 들어가면 방송이 시작되고, **쇼의 규칙이 곧 물리 법칙**이 된다. 체력을 깎는 게 목표가 아니라 **좋은 방송을 만드는 것**이 목표다. 망치면 「방송 사고」로 무대 전체가 적이 된다.

| 항목 | 브라우니 |
| --- | --- |
| 등급 | 괴이 존재(보스 이상). **체력 깎아 이기는 대상이 아님**(측정 불가). 적대해도 끝나는 조건은 쇼 안에 있다 |
| 크기 | **M급 키 약 176**(쟈알디 1.9배, 256×256). 「방송 사고」 2단계에서 **스튜디오를 채우는 거대화**(L, 다부위: 텔레비전 머리 상반신 + 장갑 손, 화면 높이 이상) |
| 기본 태도 | 중립. 출연자 = "친구". 환대·예의·쇼맨십이 한 미덕 |
| 자원 | **시청률 게이지**(0~100, 화면 위 방송국 간판 모양). 화면 표정이 곧 게이지: 웃음(70+) · 떨리는 웃음(40~69) · 우는 이모티콘(20~39) · **시계**(20 미만, 100초 카운트다운 시작) · 꺼진 화면(방송 사고) |
| 고유 규칙 1 | **코너 진행**: 방에 들어가면 코너가 차례로 열린다. 퀴즈(선택지 문제) · 장애물(무대 장치를 스타일 있게 피하기) · 방청객 질문 · 상품. 각 코너에 **포맷 규칙**이 하나씩 붙는다(예: 퀴즈 중 아이템 사용 금지, 장애물 중 무대 밖으로 나가기 금지). 규칙은 화면 큐 카드로 보임 |
| 고유 규칙 2 | **스타일 = 점수**: 정답보다 쇼가 중요. 회피 직전 회피, 연속 콤보, 무대 장치를 역이용해 처치, **박수 큐(cue)에 맞춰 도발·감정 표현 키**를 누르면 시청률이 오른다. 가만히 서 있기(지루함), 같은 행동 반복은 떨어진다 |
| 고유 규칙 3 | **방송 사고**: (a) 브라우니나 스태프를 먼저 침 (b) 포맷 규칙 위반 (c) 시청률 0. 화면이 꺼지고(검은 유리에 플레이어 얼굴이 비침) judge → 한 명을 **재로**(플레이어면 체력 60% 손실). 그 뒤 「PD 재량」 단계(보스전)로 넘어감 |
| 고유 규칙 4 | **PD 재량(보스전) 끝내는 법**: 브라우니를 때려서가 아니라 **방송을 살려서** 끝낸다. 100초 시계 동안 무대 공격(조명·소품·거대 손)을 버티며 **시청률을 70까지 다시 올리면**(스타일 행동, 큐 맞추기) 화면에 웃음이 돌아오고 "자, 다음 코너!" 쇼로 복귀. 0초가 되면 강제 퇴장(출동 실패 아님, 큰 피해 + 방 밖으로 내던져짐) |
| 고유 규칙 5 | **친구**: 쇼를 시청률 70 이상으로 끝내면 handshake → **친구**(출동 사이에도 영구). 친구가 되면 「착한 친구 키링」(토끼) 획득 = 다음 출동부터 동행 조언자(아래 9.6). **친구를 소홀히 하면 대가**: 키링 잔소리를 계속 무시하거나 키링을 버리면 다음 방송에서 시작 시청률 30 |
| 고유 규칙 6 | **정답!**: mindread로 플레이어가 고를 선택지를 **먼저 맞힌다**(커서가 있는 선택지를 읽어 "정답!"). 커서를 바꾸면 "어? 마음이 바뀌었어요?" 시청률 +5(재치) |
| 특별 출연 | 친구일 때 출동당 1번: **화려하기만 한 쇼형 괴이 보스**(극단·뮤지컬·유쾌 테마파크 계열 태그 `show`)를 만나면 텔레비전이 켜지며 burn("쇼의 본질은 화려한 게스트가 아니에요."): 그 보스 최대 체력 40% |
| 상인일 때 | 「상품 코너」: 방송에서 번 **출연료**(그 방송의 시청률 × 점수)로 상품 교환. 다른 화폐 안 받음 |
| 적일 때 | 방송 사고 뒤에만. 도망(무대 밖 문)도 되지만 **도망 = 시청률 0 + 친구 기회 그 출동 동안 없음** |

### 1.3 원작과 다르게 정한 곳 (Claude 결정)

1. **화요퀴즈쇼를 메트로배니아의 특별 방**(「방송국」 방)으로 옮김. 원작은 엽서로 정신만 끌려감 → 게임에선 층 안의 **낡은 텔레비전 물건을 E로 켜면** 그 방이 스튜디오로 바뀜(같은 화면, 몸 그대로). 엽서는 회수물로 두고, 엽서를 쓰면 다음 방이 확정 방송국.
2. **재가 되는 것**은 플레이어에겐 즉사 대신 체력 60%.
3. 「산제물의 합창가」(돼지 머리 지휘자 편성)는 이 설계에 넣지 않음. 지휘자는 브라우니가 아니라 다른 존재라서, 필요하면 보스 선정 쪽에서 따로.
4. 퀴즈 문제는 원작대로 흉흉한 주제(해부학·출혈량)지만 **답이 있는 문제**로, 게임 안 위키 내용(괴이·요원·세력)에서 낸다(플레이어가 위키를 읽을 동기).

### 1.4 기본 그림에서 본 외형

- 머리 = **낡은 브라운관 텔레비전**(어두운 갈색 나무 테두리, 뒤가 불룩한 상자, 오른쪽 위로 살짝 기운 각도). 화면은 둥근 모서리 직사각형.
- **갈색 쓰리피스 정장**(넓은 깃 재킷, 조끼, 바지), 흰 셔츠, 짙은 넥타이, 재킷 가슴 주머니에 흰 손수건. **검은 진행자 장갑**(손목까지), 검은 끈 구두.
- 어깨가 넓고 큰 체격. 기본 자세: 가슴 앞에서 장갑을 고쳐 낌.

## 2. 그림 톤 맞추기

- A2와 같은 방식(순검정 1px 외곽선, 약 78색 이하, 채도 0.2 안팎, 왼쪽 위 빛, 음영 2~3단). pixen, side, east, 투명 배경.
- 갈색 정장은 A2 범위로 채도를 눌러 탁한 갈색(밝기 3단), 장갑은 순검정이 아니라 어두운 청회색 + 하이라이트(외곽선과 구분).
- **화면은 비어 있어야 한다**: 생성 설명에 "blank dark grey-green glass screen, no image on screen". 화면에 뭔가 그려지면 edit_image_pixen으로 비움. 화면 안 표정·시계·얼굴은 전부 코드가 그림(아래 3).
- 비교판 `game-src/action/named/brownie/compare.png`.

## 5. 동작 근거

- 1970년대 미국 버라이어티 퀴즈쇼 진행자 몸짓: 두 팔 벌린 오프닝, 박수 유도(머리 위 손뼉), 상품 소개(옆으로 길게 팔 뻗기), 카메라 손가락 총, 사인오프 인사.
- drumroll: 입 드럼롤 + 허공 북 치기(진행자 관례).
- lift: 큰 손으로 작은 것을 집을 때 허리를 깊이 숙이고 손목만 씀(정중함 = 느림).
- 큰 체격의 무게감: 걸음마다 무릎을 거의 안 굽히고 발바닥 전체로 디딤, 정지 자세는 완전히 멈춤("poised stillness").
- 품질 절차는 팀 규칙과 같음.

## 9. 엔진 메모 (「게임 마무리 한 곳에서」에 넘길 것)

### 9.1 방송국 방

1. 층 생성 때 출동당 최대 1개 **방송국 방**(낡은 텔레비전 물건이 있는 방, 확률 0.15, 엽서 사용 시 다음 방 확정). 텔레비전을 E로 켜면 화면 깜빡임 → 방 배경이 스튜디오 덮개(코드)로 바뀌고 문이 잠김(쇼가 끝날 때까지). 켜지 않으면 그냥 지나감(괴이 존재는 무조건 적대하지 않음).
2. 상태: 쇼(neutral) → [방송 사고] → PD 재량(enemy, 무대 공격) → 쇼 복귀 또는 강제 퇴장 → 끝(친구 판정, 상품 코너).

### 9.2 시청률

3. 시작 50(친구면 65, 친구 소홀이면 30). 오르는 것: 회피 직전 회피 +4, 콤보 10타 +5, 무대 장치로 처치 +6, 큐 카드 1초 안에 도발·감정 표현 키 +8, 퀴즈 정답 +10, 오답이지만 3초 안에 감정 표현 +4("극적 긴장감!"), mindread 뒤 선택 바꾸기 +5. 내리는 것: 3초 넘게 가만히 -2/초, 같은 기술 4번 연속 -3, 피격 -2, 퀴즈 시간 초과 -10.
4. 화면 표정 = 구간(0.장 참조). 20 미만에서 **시계 100초**: 다시 20을 넘기면 시계가 사라짐, 0초면 방송 사고 (c).

### 9.3 코너 (방송 하나 = 코너 3개, 약 3분)

5. **퀴즈**: 단상(코드)에 서면 선택지 4개 문제. 문제 은행 = 게임 위키 문서에서 뽑은 사실. 포맷 규칙: 답할 때까지 아이템·공격 금지(위반 = 방송 사고). 브라우니 think·drumroll·mindread·"정답!".
6. **장애물**: 무대 장치(떨어지는 조명, 굴러오는 소품 상자, 스포트라이트 원 = 그 원에 들면 다음 장치 표적)가 60초 동안. 포맷 규칙: 무대 밖(양 끝 1칸) 금지. 스타일 행동이 점수.
7. **방청객 질문**: 보이지 않는 방청객이 질문(선택지). 재치 있는 답(유머 태그 선택지) +, 무례한 답 glitch(경고 1회) → 두 번째면 방송 사고.
8. **상품 코너**(끝): prize → 상점 창, 화폐 = 출연료(최종 시청률 × 10). 상품: 엽서(다음 방송국 확정), 반짝이 색종이(던지면 적 2초 혼란), 진행자 장갑 한 짝(막기 판정 +0.1초, 1층), MVP 트로피(그 출동 회수물 가치 +20%), 샌드위치(체력 회복 + 끼니).

### 9.4 방송 사고 → PD 재량

9. judge 1.2초(화면 꺼짐 + 비친 얼굴) → 대상 재(플레이어 체력 60%, 동행 NPC는 그 출동 이탈).
10. PD 재량 1단계(진행자 크기, 40초): spotlight(원 안이면 다음 공격 표적) · snap(소품 낙하) · sweep(깊이 한 칸 쓸기) · stomp(충격파, 점프로 피함) · conduct(밴드 음파, 막기로 받음) · lift(플레이어를 집어 소품 낙하 지점에 내려놓음, 피해 0).
11. 2단계(60초, 거대화): grow → 상반신 화면 위, 장갑 손 둘. 쓸기·집기·내려치기·가리키기(가리킨 칸에 재 기둥 0.8초 예고). 무대 공격 사이사이 큐 카드가 더 자주 뜸(회복 기회).
12. 시청률 70 도달 → 화면 웃음, throat 후 "…좋아요, 아주 좋아요! 자, 다음 코너!" → 쇼 복귀(남은 코너 계속). 100초 다 지나면 강제 퇴장(체력 1, 방 밖 다음 방으로 던져짐, 친구 기회 없음).
13. 브라우니에게 공격은 **피해 0**(히트 반응 hit·stagger만). 대신 공격으로 무대 장치를 부수면 스타일 점수.

### 9.5 친구

14. 쇼를 70 이상으로 끝냄 → handshake → `story.brownieFriend = true`(영구). 다음부터 시작 65, 방송국 방에서 첫 인사 "친구! 밥은 먹었어요?"(끼니 상태가 배고픔이면 scold → serve 샌드위치).
15. **토끼 키링**(친구 보상, 장신구 칸): 출동 중 (a) 숨은 함정·가짜 벽 앞 2칸에서 "저쪽은 가지 마요" 말풍선 (b) 사람 NPC 대화에서 거짓말 선택지에 "저 사람 거짓말하는데요?" 표시 (c) 배고픔 상태가 3분 넘으면 잔소리. (c)를 3번 연속 무시하면 `neglect +1`(3이면 다음 방송 시작 30). 키링을 버리면 `neglect = 3`.
16. **특별 출연**: 친구 + 키링 장착 + `show` 태그 보스 → 보스 체력 70%에서 텔레비전 화면이 화면 구석에 켜짐 → 브라우니 진행자 크기로 등장 burn(보스 최대 체력 40%) → bow → 사라짐. 출동당 1회.
