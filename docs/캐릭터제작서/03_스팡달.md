# 스팡달 · 제작 기획서

문서 버전: 1.0 / 2026-10-20 / Claude / 상태: 사용자 검토 전 / 제작 순서: 3번

## 1. 원작 근거 (위키 「스팡달」)

- 종합대응팀 선임 요원, 신입 교육 순번 담당. 20대 중반 여성. 능력: 가시, 그림자. 전문: 후방 암살. 관리국 에이스.
- 외모: 웨이브 진 보라색 단발, 창백한 피부, 빛이 없는 금색 눈(깜빡이지 않음), 반쯤 웃는 입. 가볍고 마른 체형, 가슴 풍만. 표준 검은 스커트 정장, 권총. 발소리 없이 움직이고 원치 않는 거리까지 다가옴. 좋은 냄새.
- 능력: 몸에서 검은 바늘 가시(관통 연사, 손끝 정밀 가시, 격자 구속). 그림자 속으로 녹아들어 다른 곳에서 나옴(공간을 가로지르지 않음). 대표: 표적 뒤 그림자에서 솟아 가시 하나로 뇌간. 한계: 두꺼운 장갑의 대형 개체와 상성 나쁨. 정체 불명(가면 벗겨지면 검게 변하고 눈이 여럿, 가시가 사방으로).
- 성격: 포식자형 유머, 귓가 속삭임, "후후후, 농담이야", 진짜 선배(무서운 수업, 진급 축하 집밥), 감정 표현 땐 손가락 꼼지락.
- 어록: 「자기소개 안 해? 어차피 곧 죽을 거니까…」 「있잖아, 있잖아. 너는 언제 죽을 것 같아?」 「우습네. 정말.」 「큐라스, 여보세요?」

## 2. 플레이 정체성

**한 문장**: 보이는 곳에 없다. 뒤에 있다.

- 거리: 근접(기습). 중거리는 가시 투사(보조).
- 수단: 가시(손끝·팔), 그림자 이동, 격자 구속.
- 리듬: 빠르고 조용하다. 구속 → 뒤로 이동 → 급소 → 이탈. 정면 싸움은 약하다.
- 강점: 최고 기동, 배후 공격 피해 2배, 구속으로 무리 통제, 권총 안 씀(권총은 본부 장식).
- 약점: 체력 최저급, 방패·대형 적에 피해 반감, 그림자 없는 밝은 방(4층 조명 켜진 집 등)에서 그림자 이동 불가.
- 숙련자용. 거리 관리와 뒤잡기를 알아야 한다.

## 7. 강화와 숙련

계열 「배후」·「구속」·「그림자」:
- 배후: 배후 피해 +50% / 배후 3타 시 쿨다운 초기화 / 적이 등을 보이면 느려짐
- 구속: 구속 3초 / 구속 중 피해 +30% / 바닥 꿰기 범위 확대
- 그림자: 스텝 쿨다운 반 / 밝은 방에서도 1회 가능 / 이동 후 무적 연장
- 계열 완성: 배후 → 모든 공격이 배후 판정 2초 / 구속 → 격자가 방 전체 / 그림자 → 필살기 2회

숙련: 2, 3 그림자 잔상, 5 필살 2단계, 6 이빨 뽑기, 8 전용 유물 「진급 축하 도시락」(휴식방 회복 2배), 10 정장 색 변형(짙은 보라).

## 10. 효과·소품

- 가시: 검은 바늘, 끝 하이라이트 1px. 투사체는 8px 길이.
- 그림자 웅덩이: 발밑 타원, 가라앉기·솟기 각 2장(요원 고유).
- 격자: 검은 선 격자 1프레임 점멸.
- 걷기·달리기에 먼지 효과 없음(발소리 없음).

## 12. 검수 기준

- 눈이 어떤 장에서도 감기지 않음.
- 걷기에서 머리가 거의 안 움직이고 몸이 위아래로 튀지 않음(2px 이내).
- 그림자 가라앉기·솟기에서 머리·발 순서가 맞음.
- 가시가 손끝·팔뚝에서 돋아 보이고, 무기를 "쥔" 것처럼 보이지 않음.

## 13. 임의로 정한 것

1. 권총은 장식(본부 모델링에만), 전투에서 쓰지 않음.
2. 밝은 방에서 그림자 능력 제한(규칙 태그로 구현).
3. 정체 연출(검게 변함·눈 여럿)은 쓰지 않음.
4. 던지기 = 바닥에 꿰어 고정.
