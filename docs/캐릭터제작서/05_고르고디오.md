# 고르고디오 · 제작 기획서

문서 버전: 1.0 / 2026-10-20 / Claude / 상태: 사용자 검토 전 / 제작 순서: 5번 (두 번째 몸 = 아머가 있어 비용 큼)

## 1. 원작 근거 (위키 「고르고디오」)

- 진압팀 선임 요원. 30대 초반 남성. 적합자(기계 장갑). 신장 약 2m. 오토바이 출동. 파트너 큐라스. 비밀 없음.
- 외모: 레슬러처럼 떡 벌어진 체격, 민머리, 깔끔한 수염, 자신감 있는 얼굴. 요원 복장 위 검은 재킷. 재킷 안에 식칼처럼 생긴 두툼한 칼. 아머는 소환하는 것(평소 흔적 없음), 소환 시 체격이 한 번 더 커짐. 근미래형 전신 판금, 등의 날개형 부스터에 푸른 불꽃, 목소리 기계 필터.
- 능력: 승인 구호 「적합자 고르고디오! 승인 요청!」으로 아머 소환. 비행 부스터, 초음속 돌격, 구조물급 내구, 건틀릿이 뼈와 가죽을 찢음, 거대 개체와 씨름. 계단통 투척, 사람 둘 안고 벽 뚫기. 한계: 정점급 상대에겐 아머 내구도가 먼저 무너짐. 맨몸도 덩치 큰 근접 전투원(식칼).
- 성격: 민간인 먼저, 호통과 배려 한 문장, 용기를 존중, 정면 돌파(하중 기둥 보면 손이 근질), 전투 후 수사관(진술 모순 지적), 사투리는 기분 좋을 때.
- 어록: 「이 건물 금방 확인하고 오겠습니다.」 「그냥 이거부터 다 부수는 게 낫지 않나?」 「요원 자질 있네. 마음에 들어! 알아서 따라와! 죽으면 네 책임이고!」 「그럼 나오는 건 다 죽이면 되겠네.」(아머)

## 2. 플레이 정체성

**한 문장**: 느리고, 크고, 잡으면 끝이다. 아머를 부르면 벽도 길이다.

- 거리: 근접. 돌진으로 접근.
- 수단: 맨몸(식칼·잡기) ↔ 아머(건틀릿·부스터·투척). 두 상태를 오간다.
- 리듬: 느리고 무겁다. 아머는 내구도가 닳고, 닳으면 맨몸으로 돌아온다.
- 강점: 체력·방어 최고, 잡기·던지기 최고(대형도 잡음), 벽 파괴, 아머 중 피격 경직 없음.
- 약점: 느림, 좁은 방에서 돌진 제한, 아머 내구도, 빠른 적에 헛손질.
- 초보도 잡을 수 있지만 아머 관리가 핵심.

## 6. 자원과 능력치

- 체력 5, 힘 5, 사격 1, 방어 5(아머 중 +), 속도 1(아머 활강 중 3), 경직 저항 5, 필살 충전 2.
- 고유기 자원: **아머 내구**(UI 하나). 맨몸일 때는 쿨다운 표시.

## 7. 강화와 숙련

계열 「장갑」·「돌격」·「정면」:
- 장갑: 내구 150 / 붕괴 시 주변 폭발 / 재소환 쿨다운 반
- 돌격: 돌격 거리 +1칸 / 벽 충돌 피해 2배 / 활강 중 접촉 피해
- 정면: 벽·문 파괴 시 보상 / 기둥 부수기 범위 / 가드 중 전진 가능
- 계열 완성: 장갑 → 내구 자동 회복 / 돌격 → 돌격 무적 / 정면 → 방 진입 시 벽 하나 자동 파괴

숙련: 2, 3 기둥 부수기, 5 필살 2단계(벽 두 장), 6 두 명 안기, 8 전용 유물 「특수 주문 헬멧」(아머 소환 즉시), 10 재킷 색(회색).

## 10. 효과·소품

- 부스터 불꽃: 푸른 화염 4장 반복(아머 고유).
- 소환 섬광: 흰 섬광 2장 + 판금 조립 선(코드 효과).
- 아머 붕괴: 판금 파편(고유 파편 그림 1장, 코드로 흩뿌림).
- 식칼: 던지면 바닥에 꽂힌 그림 1장.
- 컷인: 헬멧 얼굴 + 푸른 라인.

## 12. 검수 기준

- 맨몸과 아머의 발 기준점·시점·광원이 같음.
- 아머가 정장 색 교체가 아니라 판금 실루엣과 관절을 가짐.
- 걷기에서 어깨 흔들림과 무게감(발 디딤에 2px 침하).
- 부스터가 뒤에서 보이되 몸을 가리지 않음.

## 13. 임의로 정한 것

1. 아머 = D로 소환하는 두 번째 상태, 내구 0이면 붕괴.
2. 아머 중 아이템·상호작용 불가.
3. 식칼은 원거리 던지기 후 회수.
4. 필살기는 벽 뚫기(원작 붕괴 탈출 일화).
5. 제작 순서 5번(비용 때문).
