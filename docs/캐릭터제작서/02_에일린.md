# 에일린 · 제작 기획서

문서 버전: 1.0 / 2026-10-20 / Claude / 상태: 사용자 검토 전 / 제작 순서: **첫 완주판 2번**

## 1. 원작 근거 (위키 「에일린」)

- 종합대응팀 선임 요원, 부장 부재 시 현장 지휘 대행. 20대 초반 여성, 입사 10년 차(최연소 입사·최연소 지휘급). **초능력 없음.** 장비: 권총, 소총, 방탄조끼.
- 외모: 바랜 백금발 높은 포니테일, 빛이 빠진 탁한 눈(글자를 읽을 때 가늘어짐). 체격 작고 단단함(단련된 몸). 정장 위에 대충 걸친 방탄조끼, 권총집, 어깨에 멘 소총. 출동 전 착용 순서 「조끼, 권총, 장총, 점검」.
- 능력: 없음. 훈련·규율·위치 선정·절차. "싸움이 닿지 않는 자리를 찾는 데 능하다." 규칙 기반 괴이에서 남보다 먼저 규칙을 이해. 들어가면 벽의 안내문부터 읽음. 총 정비 집착.
- 성격: 말이 짧다(한 단어 명령), 직함 호칭 금지, 관리국을 쓰레기 회사라 부르며 야근, 자기 안전을 맨 먼저 지움, 다쳐도 기록하고 일함. 어린 시절 교회 괴이에 부모를 잃음.
- 어록: 「준비됐어?」 「좋아.」 「증명해.」 「가다가 죽지 마. 시신 회수 귀찮아.」 「에일린이라고 불러. 여기서 직함 부르는 건 현명하지 않아.」 「읽으면 돼.」

## 2. 플레이 정체성

**한 문장**: 능력이 없으니까, 먼저 읽고, 먼저 자리를 잡고, 먼저 쏜다.

- 거리: 중~원. 근접은 개머리판과 권총으로 버티기만.
- 수단: 소총(주), 권총(근접 전환), 방탄조끼(가드), 섬광·소금 같은 장비 활용에 보너스.
- 리듬: 준비형. 조준을 유지할수록 세고, 탄창이 비면 재장전 틈이 생긴다. 사선을 만드는 위치 싸움.
- 강점: 원거리 안전 처리, 규칙 힌트(규칙방에서 무전 없이도 힌트 1개), 아이템 효과 +50%.
- 약점: 기본 화력 낮음, 체력 낮음, 붙으면 약함, 탄창 관리.
- 숙련자용은 아니다. 쟈알디 다음으로 쉽되 "자리 잡기"를 배워야 한다.
