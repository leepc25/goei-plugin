## 0. 쟈알디·다른 요원과 다른 점

| 항목 | 쟈알디 | 다른 요원 (기획서 02~07) | **로제몬** |
| --- | --- | --- | --- |
| 누가 때리나 | 본인 주먹 | 본인(총·가시·염동·아머·불·권총) | **본인은 안 때린다.** 판정은 인형(꼬마·마네킹·쓰러진 적)과 실에서만 나옴. 본체 공격 판정 0 |
| 기본 공격(A 3타) | 잽 → 스트레이트 → 강한 스트레이트, 앞으로 나가며 밀어냄 | 개머리판, 가시 찌르기, 들이받기, 식칼 등 | **지휘 3박**: 「저기!」(검지 큐) → 「거기 말고!」(손등 쓸기) → 「…당겨.」(두 손으로 실 잡아당김). 1·2타는 꼬마가 **멀리서**(본체 앞 160px까지) 대신 때리고, 3타는 적을 **밀지 않고 로제몬 쪽으로 끌어와** 엎어뜨림 |
| 공격 거리 | 근접 | 요원마다 | 인형이 있는 곳. 본체는 뒤에서 벽을 등짐 |
| 공격 중 본체 | 동작 끝날 때까지 묶임 | 대체로 묶임 | 지시 손짓(4~6장)만 묶이고, **인형이 때리는 동안 본체는 자유롭게 걷고 물러날 수 있음** |
| 자원 | 권총 탄창 8발 + 예비 | 탄창·피로·아머 내구도·부활 횟수 등 | **실 가닥**(동시에 조종하는 그릇 수, 2칸) + 최면 대기 4초. 탄약 없음. **벽에 기대면** 실·필살 게이지가 빨리 참(수동 능력) |
| 원거리(S) | 권총 한 손 사격 | 소총·가시·발화 등 | **최면 「돌아가.」 동전 던지기**: 성공(50%) = 적이 4초간 등을 돌려 걸어감(전투 이탈). 실패 = **로제몬 쪽이** 0.5초 눈을 감싸고 무방비, 그 적이 로제몬을 1순위로 노림 |
| 고유기(D) | 폭파 | 그림자 이동, 지정 낙하 등 | **실 걸기**: 가장 가까운 그릇(쓰러진 적·마네킹·방 소품)에 실을 걸어 아군 인형으로 세움. 길게 = 모든 인형 일제 돌진(지휘 다운비트) |
| 가드(Q) | 두 팔뚝 전면 가드 | 조끼·화염 요격·아머 등 | **본인은 막지 못함**: 웅크려 머리를 감싸고, 인형이 앞으로 끌려와 대신 맞음. 인형이 없으면 피해 20%만 줄어듦 |
| 회피(Shift) | 짧은 방향 대시 | 그림자 이동·구르기 등 | **끌려가기**: 꼬마를 회피 방향으로 던지고 실을 감아 몸이 머리부터 그쪽으로 끌려감. 거리 1.6배, 시작 2틱 늦음. 무적은 끌려가는 중에만 |
| 잡기(E) | 멱살 → 무릎 → 잡기 폭파 | 메치기·식칼 등 | **멱살 → 노려보기 → 확정 최면**: 때리지 않고 얼굴을 들이밀어 노려봄(누적), 마지막에 「돌아가.」 = 이 적이 4초간 **다른 적과 싸움**. 붙어야 해서 위험한 대신 100% |
| 필살기(W) | 컷인 후 큰 폭발 | 요원마다 | **앙상블**: 화면의 쓰러진 적·그릇이 전부 일어나 덮침(실제 개체 최대 4, 나머지는 잔상). 끝나면 벽에 기대 주저앉아 간식을 꺼냄(1초 무방비, 체력 소량 회복) |
| 달리기·걸음 | 전투 질주, 넓은 보폭 | 요원마다 | 펜슬 스커트라 **보폭이 짧고 회전이 빠른 종종걸음**. 점프도 두 발 모아 깡총 |
| 아이템 | 보통 | 에일린: 장비 +50% 등 | 간식 효과 +30%, 붕대·약은 서툴러 효과 -10% |
| 임시 무기 | 쇠파이프 휘두르기, 산탄총 견착 | 요원마다 | 눈 감고 두 손으로 내려침(무게에 끌려감), 총은 팔 뻗고 고개 돌린 채 쏨(명중 낮음). 들고 다닐 땐 품에 안거나 손가락으로 집어 멀리 듦 |
| 겹치는 요원 | — | 게슈간(지정 → 지연 → 발동), 고르고디오(두 몸) | 게슈간은 **자기 염동이 직접** 지연 공격, 로제몬은 **현장 물건을 몸으로 세워** 싸움. 고르고디오 아머는 본인이 입는 몸, 로제몬 인형은 따로 서 있고 실로 연결되어 **끊길 수 있음**(본체가 다운되면 전부 쓰러짐) |

**모양만 다른 주먹질이 아닌 이유**: 판정 출처(인형·실), 거리(인형 위치), 연타 결과(3타가 끌어옴), 자원(실 가닥·벽), 실패가 있는 원거리, 본인이 못 막는 가드, 끌려가는 회피, 때리지 않는 잡기가 전부 게임 규칙으로 다르다.

## 3. 동작 근거 (실제 움직임 자료)

무술이 아니다. 로제몬은 싸우는 사람이 아니라 **지휘하고 조종하는 사람**이라, 근거도 그쪽에서 가져왔다.

| 동작 | 근거 | 그대로 쓴 점 |
| --- | --- | --- |
| 전투 대기·지휘 3박·충전·필살기 | 오케스트라 지휘법: 준비 박(손을 들고 멈춤), 3/4박 도형(아래 → 바깥 → 위), 큐(검지·손으로 연주자 지정), 다운비트 | 1타 = 큐(검지), 2타 = 2박 바깥 쓸기, 3타 = 3박 위로 걷어 올리며 당김. 충전 = 두 손 든 준비, 방출 = 다운비트 |
| 실과 인형 | 마리오네트 조종: 머리 줄 → 어깨 줄 → 무릎 줄 순으로 들어 올림, 줄에 들린 걸음은 무릎이 들렸다 떨어지고 발끝이 바닥을 스침, 줄이 끊기면 관절이 풀려 그 자리에 무너짐 | 인형 일어나기·걸음·쓰러짐 |
| 최면 | 무대 최면의 눈 고정 유도(시선을 한 점에 묶고 손바닥을 세움), 짧은 명령 | 원거리 준비 = 손바닥 세우고 정지, 발사 = 손목 꺾어 가리킴 |
| 3타 당기기 | 줄다리기 당기는 자세: 엉덩이를 뒤로 빼고 발뒤꿈치로 버팀, 팔이 아니라 체중으로 당김 | 몸이 작아서 뒤로 두 걸음 끌려감까지 넣음 |
| 가드·피격·놀람 | 깜짝 반사(Landis & Hunt 1939 「startle pattern」: 눈 감음, 어깨 올림, 고개 숙임, 팔 굽힘) | 가드가 맞서는 자세가 아니라 반사로 움츠림 |
| 걸음·달리기·점프·계단 | 펜슬 스커트 보행: 무릎 아래가 묶여 보폭이 짧고 회전이 빨라짐, 계단은 비스듬히, 넘을 때 걸터앉아 두 다리를 돌림 | 종종걸음, 두 발 깡총, 비스듬히 계단 |
| 던지기·임시 무기·임시 총 | 비숙련자 동작: 언더핸드 투척, 두 손으로 내려치며 몸이 끌려감, 팔을 잠그고 얼굴을 돌리는 사격 | 돌진공격·물건 던지기·38·39행 |

이번 근거는 일반 자료(지휘법·마리오네트·깜짝 반사 연구) 기준이며, 쟈알디처럼 영상 측정 수치를 따로 모으지는 않았다. 뼈대 만들 때 장마다 위 원칙(무엇이 먼저 움직이는가)을 그대로 지킨다.

## 5. 엔진에 새로 필요한 기능 (→ 「게임 마무리 한 곳에서」)

지금 엔진(`src/game/action/engine/player.ts`, `moves.ts`)은 쟈알디 전용(콤보 = 본인 판정, 권총 탄창)이다. 로제몬이 돌려면 아래가 필요하다.

1. **요원별 기술표**: `MOVES`·`COMBO`·탄창·회피 값을 요원 데이터로 분리(모든 요원 공통 필요).
2. **판정 출처 분리**: 기술의 판정이 플레이어 몸이 아니라 다른 개체(인형)나 선(실)에서 나오게. `MoveHit`에 `from: 'self' | 'puppet' | 'thread'`.
3. **아군 인형 개체**: 체력·피격·다운·파괴, 플레이어 지시 대기열(박마다 하나), 실 길이 제한(본체에서 6칸 넘으면 끊김), 본체 다운 시 전부 쓰러짐.
4. **그릇**: 방 소품(마네킹 등)·쓰러진 적을 "실을 걸 수 있는 것"으로 표시. 쓰러진 적을 아군으로 세울 때 적 그림 재사용 + 보라 테두리 + 덜렁 움직임.
5. **실 그리기**: 본체 머리점(매 장 좌표 = manifest `head`)에서 인형 머리까지 보라 베지어 선, 끊길 때 점선 1장.
6. **끌어오기 반응**: `react: 'pull'`(넉백 반대 방향, 지정 거리까지).
7. **확률 기술**: 최면 성공·실패 분기, 실패 시 본인 경직 + 어그로 표시.
8. **적 상태 「돌아감」·「아군화」**: 일정 시간 등을 돌려 걷기 / 다른 적을 공격.
9. **벽 감지 수동 능력**: 벽 옆 정지 → 벽 기대기 클립 + 실·필살 게이지 회복 가속.
10. **본체 이동과 공격 분리**: 지시 손짓이 끝나면 인형이 때리는 동안 본체 입력 받음.
11. **얼굴 색 바꾸기**: 칭찬 사건 때 얼굴 영역 색 빨강 → 보라(본부 전용, 팔레트 치환).
12. **끌려가기 회피**: 꼬마를 먼저 던지고 그 점으로 본체를 당기는 2단 이동, 8방향.

## 6. 만드는 방법

- 기준 그림: 기본 이미지를 보고 **쟈알디 A2를 그림체 참조로** Pro Flash로 옆모습 후보를 뽑아(96×96, 장당 5회) 고르고, 192×144로 옮긴 뒤 뼈대 클립 하나에서 옆모습 장을 골라 기준으로 씀(쟈알디 때 3/4 정면 문제 해법). 꼬마·마네킹 기준도 같은 식.
- 동작: 쟈알디와 같은 `animate_with_skeleton_v3`, 뼈대는 로제몬 전용 `rig_rojemon.py`(키 0.86배, 치마 보폭 제한, 위 근거). 프롬프트는 몸 자세만, 물건·가구 이름 금지. 그림엔 캐릭터만.
- 손 좌표·머리점(실 시작점)·골반점을 manifest에 남김.
- 검수: 자동 검사(팔꿈치·무릎 방향, 발바닥 y=136, 옆모습 폭, 치마 보폭) → 뼈대 미리보기 → 생성 → 장 단위 전수 검사(상반신 3배) → 결함 목록 → 고침 → 시연판 `release/demo/rojemon-full.html`.
- 샤워·목욕·용변 12클립: 기준 그림이 나오면 바로 GPT 의뢰서(쟈알디 의뢰서 형식), Claude는 생성 안 하고 검수만.
