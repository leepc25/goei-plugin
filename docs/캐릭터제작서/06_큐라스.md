# 큐라스 · 제작 기획서

문서 버전: 1.0 / 2026-10-20 / Claude / 상태: 사용자 검토 전 / 제작 순서: 6번

## 1. 원작 근거 (위키 「큐라스」)

- 진압팀 선임 요원. 30대 초반 남성. 발화(핑거 스냅). 원거리 화력 지원·요격. 파트너 고르고디오. 무기 없음(본인이 무기). 취미 남의 팀 신입 빼 오기. 천적 스팡달.
- 외모: 연두색 머리를 뒤로 넘김, 볼이 홀쭉하고 마름, 꺼지지 않는 미소. 출동 시 요원 정장 위 오토바이 장비와 헬멧. 손가락 굳은살. 몸놀림 가볍고 빠름, 붙잡힐 거리 안으로 안 들어감(거리 일정).
- 능력: 손가락을 튕기면 시야 안 지정 지점이 폭발. 소규모 폭발, 요격(투척물·총알), 지속 포격, 화염벽. 재생 촉수를 재생보다 빠르게. 한계: 출력이 체력에 묶임, 교전을 체력 기준으로 설계. 아군 오사 제로(팀원 위치 추적).
- 성격: 가장 성격 좋음, 쉬지 않고 떠듦(수다 = 전술 보고), 영입 중독, 스타크래프트 내기, 로이 머스탱 비교 해탈, 공포 반응 정직(스팡달), 두 손가락 경례.
- 어록: 「진압팀엔 너 같은 인재가 필요해! 빨리 전출 신청해!」 「왼쪽으로 돌 테니까 여기서 엄호해!」 「로이 머스탱 얘기 내 평생 백 번은 들었어!」

## 2. 플레이 정체성

**한 문장**: 거리를 지키고, 박자에 맞춰 튕긴다. 손가락이 닿는 곳이 전장이다.

- 거리: 중~원. 근접은 피한다.
- 수단: 발화(지점 폭발·요격·화염벽). 무기 없음.
- 리듬: 박자형. 연타하면 체력(발화 피로)이 닳고, 쉬면 찬다. 큰 폭발은 아껴서.
- 강점: 화면 어디든 공격, 투사체 요격(가드), 무리 통제(화염벽), 동행 NPC 피해 없음.
- 약점: 체력 낮고 근접 약함, 피로 관리 실패 시 아무것도 못 함, 시야 밖 불가.
- 중급자용. 거리 유지 + 자원 관리.

## 6. 자원과 능력치

- 체력 2, 힘 1, 사격 5, 방어 2, 속도 4, 경직 저항 2, 필살 충전 4.
- 고유기 자원: **발화 피로**(UI 하나, 손 옆 작은 막대).

## 7. 강화와 숙련

계열 「박자」·「요격」·「엄호」:
- 박자: 연타 4회째 피해 2배 / 피로 회복 +50% / 100 도달 시 무력 없음(대신 다음 폭발 반값)
- 요격: 요격 범위 / 요격 성공 시 피로 회복 / 근접 공격도 1회 요격
- 엄호: 동행 NPC 피해 +30% / 지원 호출 비용 반 / 생존자 주위 자동 요격
- 계열 완성: 박자 → 필살 게이지가 연타로 참 / 요격 → 가드가 전방향 / 엄호 → 지원 요원이 3초 더 머묾

숙련: 2, 3 화염벽, 5 필살 2단계, 6 촉수 솔로, 8 전용 유물 「굳은살」(피로 최대 150), 10 재킷 색.

## 8. 지원 요원 기술

「왼쪽 괜찮아? 오른쪽 괜찮아?」 — 플레이어 주변 3지점 동시 폭발 + 투사체 전부 소멸.

## 10. 효과·소품

- 지점 폭발: 주황 구형 3장(요원 고유). 큰 폭발은 같은 그림 2배.
- 요격: 투사체 위치에 작은 불꽃 1장.
- 화염벽: 세로 불기둥 4장 반복.
- 손가락 튕김 소리: 코드 합성 "딱".
- 컷인: 웃는 얼굴 + 손가락.

## 12. 검수 기준

- 손가락이 128px에서 보이고 튕기는 장에서 엄지·중지 변화가 읽힘.
- 기본 표정이 웃음, 다운에서만 사라짐.
- 어떤 클립에도 주먹·발차기 근접이 없음.
- 폭발 중심이 캐릭터를 가리지 않음.

## 13. 임의로 정한 것

1. 근접 연계가 "물러나며 폭발"(원작: 붙잡힐 거리 안으로 안 들어감).
2. 피로 100에서 1.5초 무력.
3. 동행 NPC·지원 요원 오사 없음(원작 아군 오사 제로).
4. 헬멧은 전투 중 쓰지 않음(얼굴·표정 식별).
