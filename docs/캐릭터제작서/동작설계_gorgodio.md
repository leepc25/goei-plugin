| 손바닥 밀기 | **스모 쓰파리(つっぱり)·오시** [경기] | 허리를 낮춘 채 **스리아시(발바닥 끌며 전진)**, 두 손바닥을 번갈아 상대 가슴·목에 내밈. 팔만이 아니라 뒷발이 밀고 허리가 같이 나감 |
| 하단 밟기 | **스모 시코(四股)** [경기] | 한 다리를 옆으로 높이 들었다 무릎을 굽히며 내리밟음. 반대 다리와 허리로 버팀 |
| 달리며 차기 | 프로레슬링 **빅 부트** [경기] | 달려오다 앞발 바닥으로 상대 얼굴 높이를 밀어 참. 뒷다리 한 발로 서고 상체는 뒤로 젖힘 |
| 래리어트(장갑) | 프로레슬링 **래리어트** [경기] | 팔을 옆으로 쭉 펴고 몸통을 돌려 팔뚝으로 목 높이를 휩쓺. 맞는 순간 앞발 디딤, 팔은 굽히지 않음 |
| 공중 공격 | 프로레슬링 **바디 프레스(스플래시)** [경기] | 공중에서 몸을 수평으로 펴고 배·가슴으로 덮침. 착지 = 엎드림 |
| 잡기 | 그레코로만 **베어 허그(허리 감기)** [경기] | 두 팔로 상대 허리를 감고 손을 맞잡음, 골반을 붙여 들어 올림 |
| 잡기 타격 | 박치기 [판단: 민머리 근거] | 목을 굳히고 다리·허리로 이마를 앞으로 보냄. 머리만 흔들지 않음 |
| 앞으로 던지기 | 프로레슬링 **고릴라 프레스** [경기] | 상대를 두 팔로 머리 위까지 밀어 올려(팔 쭉 폄) 잠깐 버틴 뒤 앞으로 내던짐 |
| 뒤로 던지기 | 레슬링 **벨리 투 벨리 수플렉스** [경기] | 앞에서 끌어안은 채 골반을 밀어 넣고 등을 활처럼 젖히며 머리 너머 뒤로 던짐 |
| 식칼 던지기 | **손도끼·칼 던지기(오버핸드)** [교본] | 두 발 고정, 칼을 머리 뒤로 들었다 눈높이에서 놓고 팔을 끝까지 따라 내림. 회전 수는 거리로 정함 |
| 가드 | 팔뚝 벽(레슬링·무에타이 하이 가드) [교본] | 두 팔뚝을 세워 얼굴·가슴을 덮고 턱을 당김, 어깨를 올림 |
| 가드 밀쳐내기 | 스모 **노도와(목 밀기)** [경기] | 가드에서 앞손 손바닥으로 상대 목·가슴을 밀어냄. 뒷발이 밀어줌 |
| 버티기 | 미식축구 라인맨 충돌 대비 자세 [판단] | 무릎을 굽혀 낮추고 발을 넓게, 어깨를 앞으로, 턱 당김. 충격을 몸무게로 받음 |
| 생존자 메기 | **소방관 운반법(파이어맨 캐리)** [교본] | 사람을 한쪽 어깨에 걸치고 한 팔로 다리·팔을 함께 감아 쥠 |
| 장갑 움직임 | CPS2 「아머드 워리어즈」(캡콤 1994)·「사이버봇」(1995)의 부스터 대시 [판단] | 무릎 굽히고 상체 숙인 채 발이 바닥에서 살짝 떠서 미끄러짐. 무게는 착지 때 무릎을 깊게 굽혀 2장 버티는 것으로 보여 줌 |

공통 타격 원칙(README 1장)은 그대로 지킨다: 디딤발 → 허리 → 어깨 → 팔(칼). 연타는 뒤로 갈수록 깊고 느리고 묵직하게. 칼 1타·2타는 칼 든 손이 오가므로 같은 손 연타가 아니라 **방향이 번갈아** 바뀐다(각도 1 → 2). 3타는 두 손.

## 3. 게임 규칙 (조작별, 맨몸 / 장갑)

입력은 게임 기본기획서 부록 A를 따른다.

### 3.1 맨몸

| 입력 | 동작 | 규칙 |
| --- | --- | --- |
| A, A, A | 칼 사선 내려베기 → 올려베기 → 두 손 내려찍기 | 커밋형(헛쳐도 다음 타가 나감). 1·2타 시작부터 슈퍼아머 1, 3타 2. 3타는 A 유지 시 모으기(최대 0.6초): 피해 1.5배·가드 깨기 |
| A(칼 없음) | 손바닥 밀기 3연속 | 한 번 누를 때마다 한 손. 피해 작고 밀어냄 큼. 3번째에 벽이면 벽 충돌 피해 |
| ↓A | 시코 밟기 | 하단. **다운된 적에게도 맞음**(누운 적 추가타) |

| 공중 A | 바디 프레스 | 아래 넓은 판정 + 착지 충격파. 착지 뒤 엎드렸다 일어남(빈틈 큼) |
| S | 식칼 던지기 | 탄 1. 맞으면 적에게 꽂힘(적이 죽거나 넘어지면 바닥에 떨어짐), 빗나가면 바닥·벽에 꽂힘. **E로 뽑기 전까지 칼 없음** |

| Q | 팔뚝 가드 | 가드 게이지는 쟈알디보다 느리게 닳음 |
| Q 중 A | 밀쳐내기(노도와) | 가드 반격. 앞 적 밀어냄 |
| Shift 짧게 | 버티기 | 0.4초. 무적 아님. 피해 70% 감소, 밀림·잡힘 없음 |
| Shift 길게 | 달리기 | 가속 0.5초(관성), 작은 적은 몸으로 밀고 지나감 |
| Space | 점프 | 낮음. 착지 충격파(붙은 작은 적 움찔) |

| 잡은 채 A | 박치기 | 2번까지, 3번째는 자동으로 앞 던지기 |

| 잡은 채 뒤+A | 수플렉스 | 뒤로 메침. 피해가 가장 큼, 끝나고 누웠다 일어나는 빈틈 |

| W | 필살기 | 맨몸이면 소환을 짧게 재생하고 장갑 필살기로 이어짐(장갑 내구 무관) |

| 1~4, 줍기, 사다리, 덕트 | 불가 | — |

### 3.3 장갑 내구와 상태 전환

- 내구 100. 장갑 중 받는 피해는 **전부 내구에서** 빠지고 체력은 그대로. 경직 없음(잡기·필살기 맞으면 내구 2배 소모).
- 내구 0 → **장갑 붕괴**: 판금이 깨지는 4장(장갑 그림) + 파편 효과 → 맨몸 강 피격·다운. 재소환 쿨다운 12초.
- 맨몸일 때 내구는 초당 5씩 회복. 소환은 내구 30 이상부터.
- 초안(05)의 「피해 50% 체력 통과」는 쓰지 않음: 장갑이 버티는 동안은 거의 막을 게 없다는 위키 문장에 맞춤.

## 4. 그림 규격

| | 맨몸 | 장갑 |
| --- | --- | --- |
| 캔버스 | **224×176** | **256×192** |
| 발바닥 y | 168 | 184 |
| 기준 x(골반) | 84 | 100 |
| 몸 키(도트) | 약 104 (쟈알디 92 × 144/128) | 약 116 + 헬멧 |
| 표시 배율 | 엔진 PIXEL 2.75 그대로 → 화면 약 286px | 약 320px |

- 그림에는 캐릭터만. 식칼·장갑 건틀릿은 몸·무기라 그림에 둠. 던진 칼·꽂힌 칼·바닥 조각·오토바이·생존자·가구·불꽃·충격파·섬광은 그림 밖(엔진). 장마다 손 좌표·각도를 manifest anchors(hand, hand2, angle, hip)로 남긴다.
- 옆모습(동쪽) 고정. 3/4로 돌아가지 않게 rig 어깨 회전 s는 -0.25 이하(쟈알디 교훈).
- 팔레트(원화에서 뽑음, 기준 그림 승인 때 확정): 피부 따뜻한 황갈 2~3단, 수염·눈썹 짙은 갈색, 눈 호박색, 재킷 검정 가죽(푸른 회색 하이라이트), 셔츠 흰색, 넥타이 검정, 바지 검정, 부츠 검정. 장갑: 짙은 회청 판금, 검정 관절, 청록 라인, 부스터 불꽃은 코드.

## 7. 만드는 순서 (승인 뒤 한 번에)

1. 맨몸 기준 그림: 원화(`Gorgodio_default.avif`)의 얼굴·라이더 재킷·체격을 옆모습 전신으로. 4안 중 원화와 가장 닮은 것을 골라 고침. 뼈대 3장 생성으로 옆모습 고정판을 얻음(쟈알디 guard/00 방식).

7. 시연판 `release/demo/gorgodio-full.html`(쟈알디 시연판 틀 재사용), 결함 목록 `docs/캐릭터제작서/고르고디오_결함목록_<날짜>.md`, 독립 검수 일꾼 1회 → 링크.

## 8. 엔진에 새로 필요한 것 (「게임 마무리 한 곳에서」로 넘김)

지금 `src/game/action/engine/player.ts`·`moves.ts`는 쟈알디 전용(MOVES·COMBO·탄창이 고정). 고르고디오를 넣으려면:

1. **요원별 기술표**: 요원마다 MOVES·연타 목록·입력 → 동작 대응을 따로 둠(`agents/<id>/moves.ts`). 연타 규칙 옵션: 히트 확인형(쟈알디) / 커밋형(고르고디오).
2. **두 번째 몸(폼)**: 맨몸/장갑 상태, 상태마다 다른 그림 묶음·캔버스·발 기준·몸통 판정·속도·쓸 수 있는 입력. 전환 동작(소환·해제·붕괴).
3. **장갑 내구 자원**: HUD 막대 하나(탄 표시 자리), 장갑 중 피해 → 내구, 0이면 붕괴, 맨몸 때 회복, 소환 조건(30 이상)·쿨다운.
4. **상시 슈퍼아머**: 맨몸은 세기 1 타격에 경직 없음. 장갑은 경직 없음.
5. **버티기**: 무적 대신 피해 감소·밀림 없음·잡기 면역 구간.
6. **회수형 투척 무기**: 식칼이 날아가 적·바닥·벽에 꽂히는 월드 물건이 됨, E로 회수, 칼 유무에 따라 A가 바뀜(칼 없으면 `tsuppari`). 그림은 `sig_gorgodio_knife*.png`.
7. **가드 반격**(가드 중 A) / **가드 전진**(장갑).
8. **잡기 확장**: 대형 적 잡기, 뒤로 던지기(수플렉스), 8방향 투척(깊이 줄 포함), 날아간 적이 벽·다른 적과 부딪히는 피해.
9. **다운된 적 추가타**(시코 밟기 판정이 누운 적에 맞음).
10. **관성 이동**: 달리기 가속·멈춤 미끄러짐, 장갑 활강(발이 뜬 이동), 걸으며 작은 적 밀기.
11. **착지 충격파**(점프·바디 프레스·장갑 착지).
12. **부술 수 있는 지형**: 금 간 벽·문·바닥·기둥(숙련 3: 무너져 적에게 피해), 장갑 E로 부숨, 부스터 도약으로 위층.
13. **화면 밖 필살기**: 한 줄 관통 → 벽 뚫음 → 반대편 화면 끝에서 등장.
14. **생존자 들기**: 어깨에 메기·내려놓기(생존자 그림은 손 좌표에 붙임), 메는 동안 공격 불가.
15. **오토바이 등장**: 오토바이 소품 그림 + 타기·내리기 클립 위치 맞춤.
16. **장갑 말하기**: 말풍선 글자에 기계 필터 효과.
17. 그림 크기: 요원마다 캔버스(224×176, 256×192)와 발 기준이 다름 → manifest의 frameW·frameH·foot·anchor를 요원·폼별로 읽게.

## 9. 지키는 규칙 (팀 기억에서)

- 그림엔 캐릭터만, 프롬프트엔 몸 자세만(물건·장면 이름 금지). 무기(식칼)·건틀릿은 그림에 둠.
- 팔꿈치·무릎 자동 검사(audit_joints), 옆모습 유지(어깨 회전 작게), 누운 다리 마름모 금지.
- 다시 뽑은 클립은 코드 보정을 다시 확인.
- 독립 검수 통과 전엔 링크 안 냄. 결함은 사용자가 찾게 하지 않음.
