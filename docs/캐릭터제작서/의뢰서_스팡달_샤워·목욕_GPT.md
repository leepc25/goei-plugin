- 작성: 2026-10-22, Claude(「스팡달 도트 제작」). 쟈알디 때와 같은 분담: 맨몸이 나오는 장면은 GPT가 그리고, 연출 수위와 승인은 사용자가 직접 정한다.
- 먼저 읽을 것: `docs/캐릭터제작서/03_스팡달.md`(외형), `docs/캐릭터제작서/동작설계_spangdal.md` 5.8절, 쟈알디 의뢰서 `docs/캐릭터제작서/의뢰서_쟈알디_샤워·목욕·용변_GPT.md` 7·8장(같은 규격으로 채택된 사례).
- 참고로 보면 좋은 그림: 쟈알디 납품분 `game-src/action/jyaldi-v5/full/clips/undress/`, `showerturn/`, `shower/`, `bath/`. **자세·몸짓은 따라 하지 말 것**(아래 동작이 다름), 규격과 그림체만 같게.

## 1. 기준 그림 (스팡달)

- 옷 입은 기준: `game-src/action/spangdal/base/S0-pad.png` (192×144), 대기 장 `game-src/action/spangdal/full/clips/idle/00.png`.
- 몸: 쟈알디보다 작고 가늘다. 대기 장에서 **머리끝 y≈45, 발바닥 y=136, 몸 중심 x≈69**. 키는 쟈알디의 약 0.89배.
- 머리: 턱선까지 오는 웨이브 단발, 거의 검정에 가까운 짙은 보라. 앞머리가 **먼 쪽 눈을 덮고**, 가까운 쪽 눈 하나만 탁한 금색으로 보인다.
- 얼굴: 창백한 피부, 입 다문 옅은 반미소. **눈을 감지 않는다**(잠잘 때만 감음).
- 옷: 검정 스커트 정장(엉덩이 길이 재킷, 흰 셔츠, 검정 넥타이, 무릎 길이 펜슬 스커트, 검정 스타킹, 낮은 검정 구두).

## 2. 규격 (빠짐없이 지킬 것, 기존 PixelLab 클립과 같음)

| 항목 | 값 |
| --- | --- |
| 파일 | 장마다 PNG 한 장, 이름 `00.png`부터 두 자리 번호 |
| 캔버스 | **192×144**, RGBA, 투명 배경. 반투명 픽셀·흐림·안티에일리어싱 없음(알파 0 또는 255만) |
| 방향 | 오른쪽(동쪽)을 봄. 돌아서기·샤워의 뒷모습만 예외 |
| 발 기준선 | 서 있는 장은 불투명 맨 아래 줄이 **y=135**(발바닥이 y=136 선에 닿음). 모든 장이 같은 선 |
| 몸 기준 x | 엉덩이 중심 **x=68** (대기 장 몸통 범위 x 57~81) |
| 키 | 서 있는 장 머리끝 **y≈45**, 몸 높이 약 91px. 장마다 키가 바뀌지 않게 |
| 테두리(외곽선) | **#000000, 1px**, 바깥 둘레 전부. 굵은 선·2px 선 금지 |
| 명암 | 부드러운 2~3단, 빛은 왼쪽 위 |
| 그림체 | `game-src/action/spangdal/full/clips/idle/00.png`과 같은 도트 크기(1px = 화면 1도트), 같은 채도 |

### 그리지 않는 것

캐릭터만 그린다. 바닥·벽·부스·욕조·물줄기·물웅덩이·김·큰 거품·옷걸이·바구니·벗은 옷 없음(옷은 장 사이에 그냥 없어지고 게임이 짧게 암전). 손은 빈손(수건 외).

## 3. 만들 클립 (장 수와 장마다 손동작)

### undress (탈의) 7장, 옆모습(오른쪽을 봄). 차분하고 정확하게, 서두르지 않음
저장: `game-src/action/spangdal/full/clips/undress/00.png`~`06.png`

| 장 | 옷 | 손 | 몸·얼굴 |
| --- | --- | --- | --- |
| 00 | 정장 전부 | 두 손을 배 앞에 포갬(기준 대기 장과 같음) | 반쯤 웃는 입, 눈 뜸 |
| 01 | 정장 전부 | 가까운 손 손끝으로 재킷 단추(배꼽 높이)를 집음, 먼 손은 배 앞 | 고개 살짝 숙여 눈만 단추로 |
| 02 | 재킷 없음, 흰 셔츠·넥타이·스커트 | 가까운 손 손끝이 넥타이 매듭(목 아래)을 아래로 당김 | 고개 바로 |
| 03 | 넥타이 없음, 셔츠·스커트 | 두 손 손끝이 셔츠 맨 위 단추(쇄골)에 | 고개 바로 |
| 04 | 셔츠 없음, 수건(가슴~무릎)·스커트 | 가까운 손이 가슴 위 수건 끝을 눌러 고정, 먼 손 내림 | 정면 응시 |
| 05 | 수건·스커트를 무릎까지 내림 | 두 손이 무릎 높이에서 스커트 허리를 잡음 | **허리는 곧게, 무릎만 굽혀 내려앉음**(쟈알디처럼 허리 숙이지 않음) |
| 06 | 수건만, 맨발 | 두 손을 다시 배 앞에 포갬 | 똑바로 섬, 반쯤 웃음 |
