## 0. 쟈알디·다른 요원과 다른 점 (한눈에)

| 항목 | 쟈알디 | **에일린** | 겹치지 않게 본 요원 |
| --- | --- | --- | --- |
| 정체성 | 한 번 움직이면 거기가 없어진다 (초능력 파괴) | **먼저 읽고, 먼저 자리를 잡고, 먼저 쏜다** (초능력 없음 [위키]) | 데드폴: 권총으로 빠르게 들어갔다 나옴 / 큐라스: 원거리 발화 |
| 거리 | 근접~중 | **중~원. 붙으면 떼어 내는 것이 목적** | |
| 주무기 | 장갑 주먹 + 폭파 | **소총(카빈)**. 권총은 비상용, 주먹 없음 | 데드폴 = 권총 주무기 |
| A (기본 공격) | 잽 → 스트레이트 → 강한 스트레이트 (손 번갈이, 점점 깊이 전진) | **소총 사격 리듬: 페어(2발) → 페어 → 조준 1발**. 사거리 화면 끝까지, 전진 0. **거리가 붙으면 A가 자동으로 「떼어내기 3단」**: 총구 찌르기 → 개머리판 → 밀어차기 + 한 걸음 후퇴(적이 사격 거리로 밀려남) | 쟈알디는 붙어야 강함, 에일린은 붙으면 약해서 떼어 냄 |
| A 길게 누름 | 없음 | **정밀 조준(숨 참기)**: 누르는 동안 견착·이동 느림, 떼면 관통 1발 | 쟈알디 D 충전과 다른 키·다른 판정(점 1발 vs 범위) |
| S | 권총 뽑기(한 손) | **권총 전환**: 소총을 멜빵으로 떨구고 권총을 두 손으로. 소총이 비었을 때 재장전보다 빠름 [근거: 경찰 rifle-to-pistol transition] | 데드폴의 빠른 뽑기는 주무기, 에일린은 비상 전환 |
| D (고유기) | 폭파 (범위, 벽 파괴) | **판독**: 0.5초 멈춰 읽음 → 화면 안 적에게 「표식」(약점 노출, 받는 피해 +50%, 정밀 1발은 확정 다운) + 규칙방이면 규칙 힌트 1줄 | 공격이 아니라 정보·디버프. 데미지 0 |
| W (필살기) | 구역 폭파 (앞 전체 범위) | **「증명해.」 순차 저격**: 무릎 쏴 자세로 탄창 교체 → 화면 안 적 최대 8을 **위협 순서대로 한 발씩** 쏨(표식된 적 2배). 범위 없음, 한 놈씩 | 범위형 필살기들과 정반대(점 사격 연속) |
| 자원 | 폭파 쿨다운 게이지 | **탄창 실물 관리**: 소총 30발 탄창 4개(반 남은 탄창도 따로 기억), 권총 15발 2개. 쿨다운 없음, 탄이 곧 자원 | 쟈알디 권총 8발과 달리 잔탄 계산이 플레이의 중심 |
| 재장전 | 1종 | **2종**: 전술 재장전(남은 탄창 회수, 빠름) / 빈 탄창 재장전(탄창 버리고 장전손잡이까지, 느림) [근거] | |
| 이동 | 걷기·달리기 | **전술 보행**(상체가 포탑처럼 고정, 걸으면서 사격 가능, 명중 −20%) [근거: 사격 보행] | 다른 요원은 이동 중 사격 불가 |
| 앉기 | 한쪽 무릎(가드용) | **무릎 쏴 자세**: 높은 공격이 머리 위로 지나감, 사격 반동·흔들림 절반 | |
| 가드 | 두 팔뚝 전면 가드 | **소총 막기**: 총을 가로로 두 손에 들어 막고 몸은 조끼 정면으로(피해 60%↓), 잡기·폭발은 못 막음 [근거: 총검술 high block] | |
| 회피 | 짧은 사이드스텝 | **뒤로만**: 이탈 백스텝 2보(총구 유지). 앞으로 피하려면 **슬라이딩**(달리며 A) | |
| 돌진 공격 | 어깨 박치기 | **슬라이딩**(발로 다리 걸기 → 무릎 쏴 자세로 끝남, 다음 사격 보너스) | |
| 공중 공격 | 점프 킥 | **공중 하향 사격 1발**(앞 아래 45°) | |
| 잡기(E) → 타격 → 던지기 | 멱살 → 무릎 → 잡은 채 폭파 | 옷깃 → **총구를 턱 밑에, 접사 1발** → **밀어차 넘어뜨리고 물러남**(힘이 없어 던지지 못함) | |
| 체력·속도 | 체력 4/5, 느림 | **체력 2/5, 보통**. 맞으면 아픔 → 위치 싸움이 강제됨 | |
| 패시브 | — | 규칙방 힌트 1개, 아이템 효과 +50%, 휴식방 위치 표시 [02_에일린.md] | |

**정리**: 쟈알디는 「다가가 때린다」, 에일린은 「거리를 지키며 쏘고, 붙으면 떼어 내고, 탄을 센다」. 같은 키를 눌러도 판정 모양(점·선 vs 범위), 거리 목표(붙기 vs 벌리기), 자원(쿨다운 vs 탄창)이 다르다.

## 1. 캐릭터 시트에서 뽑은 동작 원칙 (근거 문장)

| 원칙 | 위키 문장 [위키] | 동작에 미치는 영향 |
| --- | --- | --- |
| 군더더기 없음 | "움직임에 군더더기가 없어서, 처음 보는 무장 인원들도 … 계급이 높다는 걸 정확히 알아챈다" | 모든 동작이 쟈알디보다 **짧고 작다**. 예비동작 최소, 손이 쓸데없이 올라가지 않음. 큰 몸짓 금지 |
| 작고 단단함 | "체격은 작고 단단하다. 타고난 몸이 아니라 단련된 몸이다" | 쟈알디보다 키 약 8% 작게. 낮은 무게중심, 무릎을 늘 조금 굽힘 |

| 착용 순서 | "❗조끼, 권총, 장총, 점검.❗" | 출동 준비 클립 = 조끼 끈 당김 → 권총집 확인 → 소총 멜빵 → 약실 확인 |
| 짧은 말 | "명령이 한 단어인 날은 상황이 급한 날" | 말하기·손짓이 거의 없음. 가리킬 때도 손가락 하나(전술 수신호) |
| 자기 안전을 먼저 지움 | "그 셈에서 맨 먼저 지우는 건 자기 자신의 편안함과 안전", "다쳐도 … 기록하고, 그대로 일한다" | 부상 대기·절뚝 걷기에서도 **총구가 안 내려감**. 치료 직후 바로 총 점검 |

| 금지 | 02_에일린.md 3장 | 초능력 효과, 큰 점프, 화려한 몸짓, 웃는 표정(옅은 입꼬리까지만) |

## 2. 외형 기준 (기본 이미지 `assets/agents/Aileen_default.avif`)

기본 이미지에서 읽은 것: 바랜 백금발(크림빛 금발) **높은 포니테일 + 검은 머리끈**, 일자 앞머리와 귀 옆으로 내린 긴 옆머리, 회청색 눈, 무표정, **검은 정장 재킷(엉덩이 길이) + 검은 바지 + 흰 셔츠 + 검은 넥타이**, 맨손. 기본 이미지에는 **조끼·소총이 없다**.

위키는 "현장 복장 … 정장 위에 대충 걸친 방탄조끼, 권총집, 어깨에 멘 소총"이라고 한다. 그래서 기준 그림을 **장소별로 3장** 둔다(같은 클립을 옷마다 두 번 만드는 「옷 갈래」가 아니다. 클립마다 기준 그림은 하나).

| 기준 | 차림 | 쓰는 클립 |
| --- | --- | --- |
| **H (본부)** | 기본 이미지 그대로: 정장·흰 셔츠·넥타이·오른쪽 허리 권총집. 조끼·소총 없음 | 본부 업무·생활·사교·감정·씻기 (60개) |
| **F (현장, 멘 총)** | H + 짙은 올리브 방탄조끼(옆끈 느슨하게) + 소총을 등에 사선으로 멤 | 현장 비전투·임시 무기 (24개) |
| **R (현장, 든 총)** | F와 같은 옷, 소총을 두 손에 로우 레디로 듦 | 전투·지형 대부분 (54개) |

- 키: 쟈알디 기준표 93px → 에일린 **약 86px**(작고 단단). 캔버스·발 기준은 쟈알디와 같음(192×144, 발바닥 y=136, 기준 x=57) — 엔진·빌더 그대로 씀.
- 소총: 짧은 카빈(몸길이의 약 0.45), 검정·짙은 회색, 멜빵. 무기는 그림에 그린다(사용자 규칙: 무기·손전등 몸체는 그림에). 총구 불꽃·탄피·탄도선은 코드.
- **손전등 따로 없음** [판단]: 소총에 **무기 장착 라이트**(총열 아래 작은 원통). 빛은 코드가 총구 기준점에서 쏨. 그래서 쟈알디의 손전등 대기·걷기·달리기 3클립을 따로 만들지 않고 전투 대기·전술 보행·달리기를 그대로 씀(현장에선 늘 총을 들고 있으므로 자연스럽고, 3클립 절약).
- 기준 그림 만들기: create_image_pixen(쟈알디 기준표 A와 같은 방식, 옆모습) 후보를 뽑아 기본 이미지와 나란히 비교 → H 확정 → 같은 그림에 조끼·소총을 edit로 얹어 F·R. 기본 이미지를 생성기에 직접 넣지 않음(쟈알디 때 일러스트 입력은 색이 탁해짐, jyaldi-v5-cps2-redo 기록).

## 3. 실제 동작 근거 (교본·훈련 자료)

| 동작 | 실제 근거 | 요점 |
| --- | --- | --- |
| 전투 대기 = 로우 레디 | 미 육군 사격 교범 TC/FM 3-22.9, 경찰 소총 교육 자료(고·저 준비 자세) | 개머리판 어깨에 반쯤, 총구 45° 아래, 두 눈 뜨고 시선은 위. 몸은 **정면에 가깝게**(조끼 판이 적을 향함 — 현대 소총 사격의 정면 자세. 쟈알디 복싱 스탠스처럼 비틀지 않음) |
| 전술 보행 | 사격 보행(「Groucho walk」·combat glide): 무릎 굽혀 충격 흡수, 발뒤꿈치 → 발끝으로 굴림, 보폭 짧게, 상체는 포탑처럼 허리 위로 고정, 후퇴 땐 발끝 → 뒤꿈치 ([SOFREP](https://sofrep.com/news/how-to-simultaneously-walk-and-shoot-like-a-pro/), [Recoil](https://www.recoilweb.com/?p=126900), [USAMU 팁](https://archive.shootingusa.com/PRO_TIPS/USAMU1/usamu1.html), [Primary & Secondary](https://primaryandsecondary.com/forward-movement/)) | 걷기 8장에서 머리 높이 변화 1px 이내, 총 각도 고정 |
| 페어(2발) / 모잠비크 | 경찰·군 권총·소총 사격 훈련의 controlled pair, Mozambique drill(몸통 2 + 머리 1) | A 리듬 = 2 · 2 · 1. 세 번째는 조준을 다시 맞추느라 느리고 셈 |
| 무릎 쏴 | TC 3-22.9 kneeling(지지·무지지) | 뒷무릎 바닥, 앞무릎 세움, 앞팔꿈치를 앞무릎 위에 |
| 총구 찌르기·개머리판 치기 | 미 육군 FM 3-25.150 Combatives(총검·소총 격투), 미 해병 근접전 교범의 horizontal/vertical butt stroke, smash ([FM 3-25.150](https://archive.org/download/MManuals/Fm3-25.150Combatives.pdf), [USMC FMFM](https://ia800907.us.archive.org/1/items/strategic_intelligence_network/incomming/US-Marines-Close-Quarters-Combat-Manual-FMFM-07%20%281%29_text.pdf)) | 찌르기 = 두 손으로 총을 앞으로 짧게 밀어 총구로. 개머리판 = 뒷손이 개머리를 앞·위로 돌려 침, 허리 회전이 먼저 |
| 밀어차기 | 같은 교범의 front kick(거리 벌리기), 크라브마가 밀어차기 | 무릎 들어 뒤꿈치로 배를 밀어냄. 쟈알디의 하단 킥(앞발을 바닥 따라 뻗음)과 다른 높이·목적 |
| 권총 전환 | 경찰 rifle-to-pistol transition: 보조손이 소총을 몸 쪽으로 눌러 멜빵에 떨구고 주손이 권총을 뽑음 ([Shooting Illustrated](https://www.shootingillustrated.com/content/how-to-practice-transitioning-from-rifle-to-handgun/), [Police and Security News](https://policeandsecuritynews.com/2016/09/primary-to-secondary-an-easy-transition/), [Elk Grove PD 교육 자료](https://elkgrovecity.org/sites/default/files/city-files/Departments/police/policies-and-standards/education-and-training-materials/eco-firearms-psp-transition-training.pdf)) | 권총은 **두 손 아이소셀리스**(쟈알디는 한 손 사격) |
| 전술 재장전 / 빈 탄창 재장전 | 경찰·군 사격 교육의 tactical reload vs emergency(speed) reload | 전술: 새 탄창을 먼저 쥐고 교체, 헌 탄창은 조끼 주머니로. 빈: 탄창 떨굼 → 삽입 → 장전손잡이 당김 |
| 소총 막기 | 총검술 high block / port arms(총을 가로로 두 손) | 막는 동안 이동 불가, 무릎 굽혀 버팀 |
| 이탈 백스텝 | 사격 보행의 후퇴(발끝 → 뒤꿈치), 「break contact」 | 등을 보이지 않고 총구 유지한 채 2보 |
| 슬라이딩 | 야구·축구 슬라이딩 태클의 발 앞 미끄러짐 [판단: 게임 장르 관례] | 끝 자세가 무릎 쏴와 같아서 다음 사격으로 바로 이어짐 |
| 문 진입 | 경찰 실내 진입의 「slicing the pie」, 문 옆에 서서 노크 | 문 열기 전에 안내문을 읽는 1장 [위키] → 총구가 먼저 들어감 |

### 4-3. 자원·능력치

- 소총 탄창 30 × 4개(장착 1 + 예비 3). **탄창마다 남은 수를 따로 기억**(전술 재장전으로 반 남은 탄창이 생김, HUD에 탄창 칸 4개). 권총 15 × 2. 현장 습득·정비실 보충. 무제한 금지(사용자 2026-10-20).
- 체력 2, 힘 1, 사격 5, 방어 3(조끼), 속도 3, 경직 저항 2, 필살 충전 4.
- 강화·숙련은 02_에일린.md 7장 유지. 숙련 3 = 제압 사격(바닥 쓸기 연사, 줄 위 전원 경직), 숙련 6 = 엄폐 사격(물건 뒤에서 상체만 내밀어 쏨, 엄폐 중 피해 80%↓).

### 4-4. 엔진에 새로 필요한 것 (→ 「게임 마무리 한 곳에서」로 넘김)

지금 엔진(`engine/player.ts`·`moves.ts`)은 쟈알디 한 명용으로 박혀 있다(`MOVES`·`COMBO` 고정, A = 주먹 판정, S = 권총).

1. **요원 키트 분리**: 요원마다 MOVES·COMBO·입력 해석·자원을 갖는 정의 파일(`agents/eileen.ts`). 플레이어 클래스는 키트를 읽어 동작.
2. **히트스캔 사격**: 자기 z줄 폭 안 첫 적(관통이면 전부)에 즉시 명중, 탄도선·총구 불꽃·탄피는 코드 효과. 지금 `bullet` 몸체는 날아가는 탄.
3. **거리별 A 분기**: 가장 가까운 앞쪽 적이 40px 안이면 떼어내기 체인, 밖이면 사격 체인.
4. **누르고 있기(A 홀드) 조준 상태**: 이동 30%, 흔들림 감소, 떼면 발사. 조준선 UI.
5. **탄창 여러 개 + 무기 2종 상태(소총/권총)**: 탄창별 잔탄, 전술/빈 탄창 재장전 분기, S 전환. HUD 탄창 칸.
6. **이동 중 사격**: 걷기 하체 클립 + 사격 상체? → 그림은 전술 보행 클립 하나로(총 고정), 사격 효과만 총구 기준점에서. 엔진은 걷는 중 A를 막지 않으면 됨.
7. **무릎 쏴 자세의 높은 공격 회피**: 적 판정에 높이 구분(head/mid/low) 또는 앉은 상태에서 상단 판정 무시.
8. **표식 상태(디버프)**: 적에 marked 타이머, 피해 배율, 표식 아이콘. 규칙방 힌트 훅(stage 모듈).
9. **필살기 순차 표적**: 화면 적 정렬(위협도·거리) → 6틱마다 한 명씩 히트, 카메라 짧은 줌.
10. **총구 기준점**: 장마다 총구 좌표·각도(manifest anchors에 `muzzle: [x,y,deg]`) — 불꽃·라이트 빛·탄도선이 여기서 나감. 빌더가 뼈대에서 뽑음.
11. **엄폐 사격(숙련 6)**: 엄폐물 옆에 붙는 상태, 상체만 내미는 클립.
12. **슬라이딩 끝 → 무릎 쏴 연결, 다음 첫 발 2배**.

## 8. 확인할 것 (Claude 판단)

1. 기준 그림 3장(본부 정장 / 현장 조끼+멘 총 / 현장 든 총). 기본 이미지에는 조끼·소총이 없고 위키에는 현장 복장으로 있음.
