# 쟈알디 178클립 전수 검사 (2026-10-21 15시)

사용자 지적: 캐릭터 그림에 가구·배경·든 물건·무기·빛까지 같이 그려져 있어서 게임에서 배치·교체를 할 수 없음.
원칙(이번부터 모든 요원 공통):

1. **그림에는 캐릭터만.** 가구·벽·창·문·사다리·밧줄·기계·물건·무기·빛·연기·불꽃 전부 빼고 그린다.
2. **대신 좌표를 남긴다.** 장마다 손 위치(앞손·뒷손), 쥔 물건 각도, 앉은 좌판 높이, 등·벽 접촉점, 문손잡이 위치를 manifest에 적는다. 게임은 그 좌표에 가구·물건·무기를 따로 그린다. 그래서 어떤 물건을 집어도 같은 동작을 쓴다.
3. **자세는 사람이 할 수 있는 것만.** 팔꿈치·무릎 방향, 누웠을 때 다리 모양(마름모 금지), 옆모습, 디딘 발 고정.

검사 방법: 최종 스트립(full/final/) 178클립을 장 단위 접촉 시트로 전부 확인(Claude 눈 검사). 생활 29클립(14:57 재생성)은 빌드에 제대로 들어가 있음을 확인함(문·사다리·의자·송신기는 가구 없음).

## A. 가구·배경을 그린 것 → 가구 없이 다시 생성 (17)

bedlie(침대), board(게시판), brief(화이트보드), button(버튼판), coffee(커피머신), dishes(싱크대·찬장), handwash(세면대·디스펜서), locker(사물함), microwave(전자레인지·음식), push(나무 상자), stairs(계단), wash(세면대·거울), water(화분), window(창문), lever(레버 장치), rope(밧줄), backpack(바닥 가방)

샤워·목욕 6개(shower, showerin, showerout, bath, bathin, bathout)는 부스·욕조까지 그려져 있음 → 사용자 생성분이라 의뢰서 6장에 "캐릭터만" 추가.

## B. 손에 든 물건·무기를 같이 그린 것 → 빈 손(쥔 모양)으로 다시 생성 + 손 좌표

- 들고 이동 20: idle/walk/run × box·brick·cup·folder·light, idle/walk_pipe, idle/walk/run_shotgun
- 무기 동작 7: pipe(휘두르기), shotgun(사격), draw, holster, fire, reload, gearcheck(권총)
- 작은 소품 22: mop, giftbox, handover, notebook, papers, phone, phonelook, seatphone, seatread, seatdrink, seatnoodle, seatgame, toast, feast, smoke, towel, transmit, deskwork, drink, eat, bandage, brushteeth

walk_pipe·idle_pipe는 쇠파이프를 바주카처럼 어깨에 가로로 얹음 → 한 손으로 어깨에 비스듬히 걸치기로.

## C. 효과를 그림에 박은 것 → 코드에서 지우고 게임 효과로 (Claude 처리, 재생성 없음)

손전등 빛(idle/walk/run_light), fire 총구 불꽃·연기, shotgun 연기, grabblast 불꽃, super 광탄, support 잔상, smoke 담배 연기, bath 김

## D. 자세 결함 → 다시 생성

- 누운 다리 마름모: sofa, situp, bedlie, down(2~4장), bedwake(1~2장). 옆으로 누우면 다리는 곧게 펴거나 위쪽 무릎 하나만 세운다.
- sneak(살금 걷기): 두 무릎이 바깥으로 벌어진 O자 → 발끝으로 좁게 디디며 무릎은 앞을 향함.
- leadhand(손잡고 이끌기): 뒷팔이 등 뒤로 꺾임 → 몸 뒤로 비스듬히 아래로 뻗음.
- 이미 넘긴 팔꿈치 목록: annoyed cry embarrassed hairflip kneelcry music situp sofa stretch towel yawn / block blockhit down fall land toss pipe2, mop 각도, stretch.

## E. 찌꺼기 → 코드로 지움 (Claude 처리)

push 손 앞 상자 조각, hug 2장 회색 번짐, deskslam 2장 회색 번짐, inspect 4~5장 회색 점, tie 마지막 장 점, seatnoodle 떠 있는 컵(처리함)

## 규모

다시 생성 = A 17 + B 49 + D 신규 6 ≈ 72클립, 클립당 2~3회로 약 150~220회(잔액 약 9,000).

## manifest 좌표 형식 (엔진 스레드와 맞출 것)

```
clips.<key>.anchors = [   // 장마다
  { hand: [x, y], hand2: [x, y], angle: deg,   // 앞손·뒷손 손목(그림 칸 192×144 px), 앞손 쥔 방향(팔꿈치→손목, 0=앞, 시계 방향 +)
    seat?: [x, y], back?: [x, y], wall?: [x, y], handle?: [x, y] }   // 해당 동작만
]
```
좌표는 rig.py 뼈대(+DX, DY)에서 빌더가 최종 장 순서대로 뽑는다.

## 다른 스레드에 알림 (스레드 간 메시지 한도로 문서에 적음)

- 전투·생활 재생성 스레드: 무기·든 물건도 **빈손(쥔 모양)** 으로 뽑는다. 단 재생성 범위를 사용자 결정 카드로 묻는 중이라 **결정 전엔 B(물건·무기) 생성 시작 금지**. 결정이 나면 이 문서에 적는다.
- 필살기(super)·잡고 폭발(grabblast)·지원(support)·사격(fire, shotgun)의 효과는 빌더(jyaldi_fixes OUTSIDE_FX·DETACHED)가 이미 지움 → 효과 때문에 다시 뽑지 않아도 됨. hits는 그대로.
- 엔진 스레드: game-src/action/jyaldi-v5/full/final/hands.json을 빌더가 씀. 형식 {클립: [[x, y, 각도], ...]}, 192×144 장 px, 각도 0 = 위로 세움·시계 방향 +(rig 앞손 팔꿈치→손목). manifest.json의 clips.<클립>.anchors에는 뒷손(hand2)까지 있음. rig 뼈대가 없는 talk·getup만 빠짐.
