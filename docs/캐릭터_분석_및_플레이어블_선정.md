## 2. 첫 완주판 2명을 쟈알디·에일린으로 고른 이유

- **가장 멀리 떨어진 두 사람이다.** 능력자 대 무능력자, 근접 대 원거리, 묵직함 대 준비형, 부장 대 대행. 같은 방을 완전히 다르게 공략하므로 "요원마다 다른 손맛"을 두 명으로 바로 증명한다.
- **그림이 가장 싸다.** 둘 다 정장 인간 체형이고 추가 그림(아머·인형·분신)이 없다. 효과도 폭발과 총구 화염뿐이다.
- **주무대(차원 승강기, "규칙 괴담 종합 선물 세트")와 맞는다.** 에일린은 "들어가면 벽의 안내문부터 읽는" 규칙 괴담 전문가라 층마다 규칙이 다른 승강기에서 규칙 시스템의 튜토리얼 역할을 자연스럽게 맡는다. 쟈알디는 건물을 부수는 사람이라 정비 구역 입구(금 간 벽)를 여는 시범을 보인다.
- **원작 관계가 있다.** 부장과 부장 대행. 둘의 작전 회의는 몇 마디로 끝난다. 본부 대화 사건의 첫 조합으로 쓰기 좋다.

대안으로 검토한 조합: 쟈알디+고르고디오(둘 다 근접 파괴라 겹침, 아머 비용), 쟈알디+스팡달(블랙 커피 동지로 관계는 좋지만 둘 다 근접), 에일린+큐라스(둘 다 원거리). 모두 첫 두 명으로는 부적합.

## 4. 플레이어블 선정 외 결정 (게임 설계)

- **지원 요원**: 플레이어블 8명은 모두 지원 요원으로도 쓴다. 지원 기술은 각 제작서 8장에 있다. 콘쥬스는 원작대로 전투 지원에 쓰지 않는다. 대신 휴식방에서 보급품을 가져다 주는 연출(안전 지점 한정)만 한다.
- **본부 NPC 동작 묶음**: 잼트리(타이핑·커피·응대·하이힐 걸음), 고그니쟈(모니터·장치 조작·큰 목소리 몸짓), 데쥬레(스캔·홀로그램·놀람·커피), 콘쥬스(상자 운반·서류 전달·따라가기). 각 10~20장. 플레이어블보다 뒤에 만든다.
- **적의 체형 공유**: 가짜 관리국 요원은 같은 정장 체형 1종으로 총·방패·지휘관을 소품과 팔레트로 나눈다. 검사부대만 별도 1종. 백일몽 탐사조는 가면 정장 체형 2종(남·여).

## 5. 사용자 결정이 필요한 것 (한 번에)

1. 첫 완주판 2명을 쟈알디·에일린으로 (추천: 확정)
2. 제작 순서 3~8번 (스팡달 → 게슈간 → 고르고디오 → 큐라스 → 데드폴 → 로제몬)
3. 콘쥬스 본부 전용 유지 (원작 명시라 바꾸지 않는 것을 추천)
