01
주요 메뉴
 
상황판
시각·위치·목표, 진행 중인 괴이·사건, 요원 카드
임무
지도에서 출동지 고르기, 커스텀 임무
괴담톡
인물과 메신저 대화, 단톡방 만들기·초대
소지품
가계부·소지품·장착 칸, 쇼핑몰에서 사고팔기
기록
사건 일지와 종료 보고서, 이미지로 저장
설정
기능별 켜고 끄기, 모델·지침 고르기
02
인터넷
플러그인 안 브라우저, 탭으로 오가며 이용
괴이위키 괴담넷 괴담 갤러리 세정게 연어 마켓 우주 쇼핑몰 백일몽 포인트몰 망상홈쇼핑
03
설치
 
1아래 단추로 최신 zip 받기
2Risu 설정 → 플러그인 → 가져오기에서 goei-plugin.js 추가, 권한 창 모두 허용
3괴이_ANOMALY.charx를 캐릭터로 가져오기
4카드를 처음 열면 본체를 한 번 받음 (실패하면 zip 속 goei-body.js 넣기)
5채팅 화면 구석 유령 단추 → 세력·첫 장면·언어 고르고 출발
주의
캐릭터 이미지가 카드에 들어 있으니 예전 에셋 모듈은 끄기
04
업데이트
 
플러그인
Risu 설정 → 플러그인 탭에서 업데이트, 본체는 카드를 열 때 알아서 받음
카드
유령 단추 → 설정 → 점검 → 업데이트 → 「카드 업데이트 준비」 → 「카드에 적용」, 채팅은 그대로
