# 쟈알디 도트 작업 인계 (2026-10-21)

이전 스레드 「쟈알디 도트 제작 이어가기」가 너무 길어져 결정을 놓치는 실수가 나와 새 스레드로 넘김.
저장소 leepc25/goei-plugin, 작업 파일은 main의 `game-src/action/jyaldi-v5/`. PixelLab은 `scripts/mcp.py`(JSON-RPC, `python3 mcp.py schema <tool>`), 사용 기록 `spend.log`.

- `docs/캐릭터제작서/01_쟈알디.md`

## 확정된 것 (사용자 결정)
- **기준표 = A**: `game-src/action/jyaldi-v5/sheet7/jyaldi-base-pixen-a.png` (create_image_pixen, 96 캔버스, seed 711, 키 93px, 오른쪽 보는 전투 자세). 청회색 음영 정장, 흰 셔츠, 검은 넥타이, 검은 장갑, 오른쪽 허리 홀스터, 검은 긴 머리, 붉은 눈.
- A의 고칠 점: **재킷이 짧아 크롭티처럼 보임 → 엉덩이를 덮게.** A의 대기 자세(넓은 다리, 뒷손 허리)는 실제 스탠스와 다름.
- 모든 자세는 실제 무술 근거. 연타는 손이 번갈아: 잽(앞손, 예비동작 없음) → 스트레이트(뒷손) → 강한 스트레이트(앞손). 공중 = 점프 킥.
- 앞으로 나가는 동작에서 디딘 발이 미끄러지면 안 됨(문워크 금지). 걸음은 그림 안에서 내딛고 코드는 동작 끝에만 위치를 옮김.
- 최우선은 액션성(미스타라·던파처럼 크고 확실하게).

## 작업 규칙 (사용자가 여러 번 화낸 것)
- 생성은 사용자가 하라고 할 때만, 횟수를 먼저 말함. 결정 대기 중 생성 금지.
- 새 방법은 공식 문서·`search_help`(무료)·웹 검색으로 먼저 조사. 실패하면 글만 바꿔 재시도하지 말고 원인 보고.
- **생성 결과를 A와 나란히 놓고 비교한 뒤에 다음 단계로.** (이번 실수의 원인)
- 답은 한국어, 짧게, 변명 없이. 다음 할 일은 Claude가 제안.
- 폰 링크: `https://raw.githack.com/leepc25/goei-plugin/main/release/demo/<파일>.html`. 429가 뜨면 `https://rawcdn.githack.com/leepc25/goei-plugin/<커밋 전체 해시>/release/demo/<파일>.html`.

- animate_image 열린 생성: 첫 장에서 크게 못 벗어남(깊은 내딛기·질주 불가).
- animate_with_skeleton_v3: 관절 좌표대로 자세가 나옴(성공). `scripts/skel2.py`(IK), `skel3.py`(3연타 15장·걷기), `skel_run.py`.

- **그러나 등록한 캐릭터(c0968765-…)는 A가 아님**: 정면 그림을 설명만으로 새로 뽑아 새까만 정장·보라 머리·가는 몸이 됨. 쓰지 말 것. 비교: `/mnt/project-files/goei-plugin/review/jyaldi-A-vs-registered.png`.
