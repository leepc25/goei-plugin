# 게임 플러그인 탑재 (리스 플러그인 안에서 게임 돌리기)

작성 2026-10-21 · 스레드 「리스 플러그인 탑재」 · 브랜치 `claude/project-thread-6tyjal`

게임은 괴이 ː 이면세계 플러그인 창 안에서 돈다. 이 문서는 게임과 플러그인 사이의 다리, 게임 파일을 받아 두는 방식, 저장 칸, 본편 연동, 모바일 화면 처리, 측정값을 정리한다. 엔진 쪽 모듈 연결은 `docs/게임_모듈_연결.md`(게임 전투와 조작 스레드)가 맡는다.

## 1. 들어가는 곳

- 창 머리의 게임 버튼(예전 「관리국 순찰」 자리, `data-action="game-open"`)을 그대로 쓴다. 머리는 모든 탭에서 보이고, 모바일 하단 서랍은 즐겨찾기 자리라 건드리지 않았다.
- 누르면 **시작 화면**이 뜬다: 게임 파일 받기 → 저장 칸(이어하기·새로 시작·불러오기·보관·지우기) → 본편 연동 → 이전 시험판(관리국 순찰·1인 전투 검증판) → 측정.
- 게임 중에는 머리에 ‹(시작 화면으로) · 전체화면 · 닫기. 창을 다시 그려도 게임 덮개는 따로 들고 있다가 다시 붙인다(`reattachGame`).
- 다른 봇에서는 아무것도 하지 않는다. 게임 코드는 시작기(goei-plugin.js)에도 본체에도 없고, 괴이 카드에서 게임 버튼을 눌렀을 때만 꺼낸다.

## 2. 게임 코드 팩 (본체와 분리)

v0.16.29 시작기·본체 나누기와 같은 방식이다.

| | 시작기 | 본체 | 게임 코드 |
| --- | --- | --- | --- |
| 파일 | `goei-plugin.js` | `goei-body.N.txt` | `game/goei-game.N.txt` |
| 언제 읽나 | 모든 봇 | 괴이 카드를 열 때 | 게임 버튼을 누르고 받기·시작할 때 |
| 저장 | Risu 플러그인 | pluginStorage `goei:body` | pluginStorage `goei:game:code` |
| 판 확인 | | 첫 줄 `// goei-body 판` | 첫 줄 `// goei-game 판` (플러그인 판과 같아야 함) |
| 실행 | | nonce 붙인 script | nonce 붙인 script → `globalThis.__goeiGame` |

- 진입점 `src/game/entry.ts` → `{ version, mount(box, bridge), legacy }`. `mount`는 지금 `src/game/play.ts`(회색 상자를 다리에 맞춘 것)이고, 엔진이 들어오면 `play.ts` 한 파일만 `src/game/action/main.ts`의 `mountGame`으로 바꾼다.
- 이전 시험판(순찰·1인 전투)도 코드 팩으로 옮겼다. 저장 키(`goei:game`, `goei:game-action:v1`)와 그림 팩 받기는 예전 그대로다.
- 본체가 1,159KB → 1,093KB로 66KB 줄었다. 엔진·적·대사가 붙어 게임 코드가 커져도 본체(괴이 카드를 열 때마다 읽힘)는 그대로다.

## 3. 자산 팩

- 폴더 하나 = 팩 하나: `game-pack/<폴더>/pack.json` (`{"id": "jyaldi", "required": true}`)과 파일들. `atlas.json`은 머리의 atlas로 들어가고 나머지(png·webp·ogg·json…)는 확장자 붙은 이름 그대로 담긴다. `pack.json`이 없는 폴더(옛 `patrol`·`action`)는 예전 방식 그대로.
- 모양: `GOEIPACK` + 머리 길이(uint32 LE) + 머리 JSON `{id, version: 1, hash, atlas, files: [[이름, 시작, 길이]]}` + 바이트. `hash`는 내용 sha256 앞 16자.
- 빌드(`npm run build`)가 `dist/game/<id>.pack`과 512KB 조각 `<id>.N.bin`, 목록 `dist/game/index.json`을 만든다. 웹 Risu 프록시가 요청당 약 1MB까지라 조각으로 받는다.
- 받기: `required` 팩은 시작 화면 「받기」에서 코드와 함께 받는다. 지문이 바뀐 팩만 다시 받는다. 저장소를 닫아도 `.pack`·`goei-game.js`를 「파일로 넣기」로 넣을 수 있다.
- 저장: pluginStorage `goei:game:pack:<id>` = `{hash, atlas, bytes, files: {이름: [mime, base64]}}`.
- 꺼내기: `bridge.assets.url(pack, '파일.png')` → blob 주소(처음 부를 때 만듦), `bridge.assets.bytes(pack, 파일)` → 바이트(소리 `decodeAudioData`용), `bridge.assets.atlas(pack)`. 게임을 닫으면 만든 blob 주소를 모두 거둔다(`releaseAll`).

## 4. 다리 (`src/game/bridge.ts`)

게임이 받는 것: `slot`(시작 화면에서 고른 칸) · `saves` · `assets` · `card()` · `photo(asset)` · `report(result)` · `viewport` · `waiting()/onWaiting()` · `narrow()` · `close()`. 타입은 파일 주석 참고. 엔진·본부 스레드와 이 모양으로 맞췄다(바꿀 때는 이 스레드와 상의).

### 저장 칸

- 0 = 자동 저장, 1~3 = 수동. 본문 `goei:game:slot:N`, 목록 `goei:game:slots` = `{slots: [{slot, savedAt, title, summary, schema, size}], last}`.
- 본문 모양은 본부 스레드가 정한다(`schema` 예: `goei-hq/1`). 쓰기는 차례로 해서 자동·수동 저장이 겹쳐도 목록이 어긋나지 않는다.
- 이 기기의 Risu에 남는다(카드·채팅과 무관). 시작 화면에서 자동 저장을 빈 칸으로 「보관」할 수 있다.

### 본편 연동 (기본기획서 22장)

- 읽기(자동): 게임을 열 때 `card()`가 지금 채팅의 명부 요원(이름·소속·직급·상황판 상태·편성 가능 여부·대표/얼굴 사진 이름), 괴이·특수 목록, 지금 상황판에 뜬 괴이·사건·특수를 준다. 사진 주소는 `photo(asset)`.
- 쓰기(버튼만): 게임은 정산 때 `report({id, mission, outcome: return|evac|withdraw, depth, agents, rules, loot, summary})`를 넘긴다. 플러그인은 쌓아만 둔다(최근 5개, 같은 id는 한 번). 시작 화면의 결과마다:
  - 「보고서 붙이기」: 이 채팅에 유저 메시지로 놓고 「전송 대기」로 둔다(`%%GOEI_UNSENT%%`). 보낼지는 사용자가 전송 버튼이나 취소로 정한다. 응답 중이거나 마지막이 안 보낸 유저 메시지면 막는다.
  - 「기록 로어북에 남기기」: 이 채팅 로어북에 「관리국 훈련 기록」 한 칸(항상 켜짐, 최근 5줄). 토큰을 쓰므로 누를 때만, 시작 화면에서 지울 수 있다.
- 게임 결과로 본편 요원 상태(부상 등)를 바꾸지 않는다(22.3).
- 괴담넷 생환담·괴담톡 한마디(22.2)는 대사 스레드의 미리 쓴 글이 나오면 같은 버튼 자리에 붙인다(아직 없음).

## 5. 모바일 전체화면·가로

Risu 플러그인 창은 iframe이라 브라우저 전체화면이 막혀 있을 수 있다(`src/host/game/viewport.ts`).

1. 전체화면 버튼 → `requestFullscreen` + `screen.orientation.lock('landscape')`(안드로이드 크롬).
2. 막히면 창 안 전체화면(고정 덮개, z-index 9999).
3. 그래도 세로로 든 폰이면 게임을 90도 돌려 가로로 보인다(아이폰 사파리는 가로 고정이 없음). 폰을 가로로 돌리면 돌리기를 푼다. 돌리기는 안쪽 상자(`.gx-game-in`)에 건다(브라우저 전체화면은 그 요소의 transform을 지운다).
4. 돌려 보일 때 화면 좌표와 게임 좌표가 다르다. 게임은 터치 좌표를 `bridge.viewport.toLocal(clientX, clientY, 요소)`로 바꿔 쓴다(회색 상자 스틱은 이미 그렇게 함). 버튼(DOM)은 브라우저가 알아서 맞춘다. 캔버스 크기는 `clientWidth/Height`(돌리기 전 크기)로 잡는다.

## 7. 릴리스 때

- `npm run build` 뒤 `dist/game/`(index.json·goei-game.N.txt·<id>.N.bin)를 `release/game/`으로 복사해 함께 올린다. 플러그인 판이 바뀌면 게임 코드도 다시 받으므로 index.json의 version이 플러그인과 같아야 한다.
- 이 브랜치는 릴리스하지 않았다(사용자가 말할 때 모아서).

## 9. 통합 엔진으로 바꾼 뒤 (2026-10-21 저녁)

- `src/game/play.ts`는 통합 엔진 `src/game/action/main.ts`의 `mountGame`을 그대로 부른다. 회색 상자·따로 만든 시연판(goei-plugin-game.html)은 뺐다.
- 저장 칸 고르기·불러오기는 게임 안 본부(hq)가 맡는다. 시작 화면에는 「게임 시작/이어하기」 하나만 둔다. `bridge.slot`은 0(자동 저장).
- 게임 중에는 덮개가 창(iframe) 전체를 덮고, 머리는 오른쪽 위 작은 단추(‹ · 전체화면 · ×)로만 남는다. 세로로 든 폰은 자동으로 돌려 채운다.
- 캔버스 크기(가짜 Risu): 844×390 → 693×390, 390×844 → 돌려서 693×390, 1280×950 → 1280×720, 1100×900 → 1100×619.
- 게임 코드 771KB(조각 5개), 쟈알디 팩 753KB(조각 2개). 처음 받기 2.2초, 닫았다 열기 5번 힙 18.6 → 19.3MB(번마다 약 0.17MB 남음, 엔진 쪽 정리 확인 필요).
- 알려진 충돌: 플러그인 상태창 CSS가 `.gst`를 쓰고 대사 모듈 바탕도 `.gst`라, 같은 문서에 상태창 CSS가 있으면 대사 층이 420px 판으로 그려진다(상태창 「끄기」면 대사 층이 아예 숨는다). 대사 모듈 쪽 이름을 바꾸기로 요청함.
