## A. 퍽

- [ ] A2. 쌍 퍽 출현 빈도 (지금 임의값: 조건이 맞으면 후보에 50% 확률로 최대 1개)

- [ ] A4. 화면 HUD의 퍽 토큰·쌓임 숫자 (지금은 시험장 옆 칸에만)
