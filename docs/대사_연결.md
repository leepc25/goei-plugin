## 1. 자료가 가는 길
- 원본: `game-src/dialogue2/characters/<이름>.json`(52) · `game-src/dialogue2/npc/<원형>_<남|여>.json`(30). 칸 구조는 `game-src/dialogue2/칸_구조.md`.
- 팩: `python3 tools/build_dialogue2_pack.py` → `game-pack/dialogue/` (`c_<이름>.json.gz`, `n_<파일>.json.gz`, `index.json`, `pack.json {"id":"dialogue","required":true}`). 12.8MB → 3.2MB. **대사를 고치면 이 도구를 다시 돌리고 game-pack/dialogue 도 함께 커밋한다.**
- 빌드(`npm run build`)가 다른 자산 팩과 같이 `dist/game/dialogue.pack`(512KB 조각)으로 만든다. required 라 시작 화면 「받기」에서 코드와 함께 받는다.
- 게임: `src/game/world/dialogue2.ts` `Dialogue2` 가 `bridge.assets.bytes('dialogue', 파일)` 로 인물·NPC 파일 단위로 받아 `DecompressionStream('gzip')` 으로 푼다. 처음 세계를 만들 때 그 방에 있는 이름 인물과 NPC 30 파일을 미리 받는다(`prefetch`). 팩이 없으면(시연판·DecompressionStream 없는 옛 웹뷰) 모든 칸이 null 이라 대사 없이 돈다.
- 옛 `src/game/world/dialogue.json`(game-src/dialogue, `tools/build_dialogue.py`)은 **몹에게 말 걸 때 모델에 주는 말투 한 줄(voice)** 에만 남아 있다. 말풍선은 더 쓰지 않는다.

## 2. 칸 열쇠 (호출하는 쪽이 쓰는 것)
`Dialogue2.line(kind, name, cell, ctx)` 또는 `Chatter.cue(actor, cell, ctx, {fallback, icon})`. 칸 열쇠는 「묶음.칸」:

| 쓰는 열쇠 | 실제로 찾는 자리 |
|---|---|
| `facing.greet` · `react.warn` · `busy.eat` · `companion.move` · `injured.greet` · `combat.start` · `shower.intrude` · `expel.warn` | `<묶음>.<주인공 소속>.<평판>.<칸>` — 소속 A00·B00·C00·D00·E00, 그 밖(F00~ 명부 세력)은 `etc`. 평판 friend(우호·호의) / neutral / wary / hostile |
| 위 묶음인데 `ctx.target` 이 `{user}` 가 아닌 다른 사람 | `expel.*` → `expel_other.*`, `combat.*` → `combat.other.*`. 나머지 묶음은 null |
| `facing.greet/talk/hit1/hit2` 이고 `ctx.player`(플레이 중인 이름 인물)가 그 사람 자료의 `chars` 에 있음 | `chars.<인물>.<칸>` 먼저 |
| `time` | `time.<morning/day/evening/night>` (ctx.hour) |
| `social.mate` (+ ctx.partner) | `social.mate.<상대>` 없으면 `social.mate_greet` |
| `situation.alert` · `social.topics.<주제>.open` · `shower.mate` 등 | 그대로 |
| 풀어 쓴 경로 `facing.A00.wary.talk` | 그대로 |

`ctx`(CueCtx): `faction`(주인공 소속) · `stance`(그 사람 쪽에서 본 주인공 평판: 이름 인물 = 호감 구간 hostile→hostile, warm·close→friend, base→그 소속의 세력 평판; 몹 = 그 소속의 세력 평판; 싸우는 중이면 hostile) · `player` · `target` · `partner` · `hour` · `say`(자료 없을 때 임시 글). `modules.ts cueCtx()` 가 만든다.

일반 NPC(행인·학생·불량배·청소부·경찰·상인·의사·간호사)는 공통 칸이 1갈래라 `speech.ts MOB_CELL` 이 바꿔 준다(`facing.greet`→`glance`, `facing.hit1/2`→`hit`, `combat.faint`→`faint`, `situation.crowd`→`crowd`, `situation.see_body`→`see_body`, `react.armed`→`armed_angry`, 출근·퇴근은 그대로). 세력 소속 NPC(경비·안내 직원·행정 직원·관리국 요원과 다른 세력 파일)는 이름 인물과 같은 구조라 그대로.

### NPC 파일 고르기 (`npcFileOf(원형, 성별, 거점 소속)`)
성별은 그림 신상(`mobProfiles.json`). 의사는 남만, 간호사는 여만, 편의점 점원은 상인. 경비·안내·행정·관리국 요원은 거점 소속에 따라: A00(또는 모름) → `<원형>_<성별>`, B00 → 경비·요원은 `가짜 관리국 진압부대_남`, 직원은 `검사부대_남`(가짜 관리국은 남성만), C00 → `백일몽 직원_<성별>`, E00 → `프리랜서_<성별>`, F00~ → `협회 직원_<성별>`.

## 3. 사건 → 칸 (speech.ts `Chatter.step`, 보이는 장면만, 장면에 글 말풍선 3개까지)
| 시뮬 사건 | 누가 | 칸 |
|---|---|---|
| `cue` (코드가 콕 집음) | id/who | `e.cell`, `e.ctx`(target·say…). 자료 없으면 `ctx.say` |
| `notice` (주인공 알아봄) | 그 사람 | `facing.greet` (20초에 한 번) |
| `hurt` | 맞은 사람 | `down` → `combat.faint`(기절 순간 신음), 이미 맞서던 몸(hostile) → `facing.hit2`, 아니면 `facing.hit1` |
| `kill` | 가까운 목격자 1 | `situation.see_body` |
| `report` | 신고자 | `report` |
| `steal` | 피해자 / 도둑(60%) / 구경하던 사람 | `robbed` / `pick_run` / `situation.crowd` |
| `harass` | 시비 거는 쪽 / 당하는 쪽 | `harass` # / `harassed` ? — 대개 기호, 25%만 글(장면에 글이 없을 때) |
| `flee` | 도망자(50%) | `flee` |
| `police` | 경찰 | `halt` |
| `follow` | 그 인물 | follow→`react.follow_yes`, wait→`react.wait`, return→`react.return`, hit(맞아서 그만둠)→`facing.hit1` |
| `shift` (50%) | 출근·퇴근하는 사람 | `situation.shift_on` / `shift_off` |
| `alarm` on | 그 장면 둘까지 | `situation.alert` |
| `brawl` | 거점 쪽 사람 | `combat.start` (target = 방문자 → `combat.other.start`) |
| 혼잣말 | 주인공 700px 안 한 명, 25~50초마다 35% | 수다 중이면 `social.mate`(대개 「…」), 소란 구경 중이면 `situation.crowd`, 그 밖은 `time` |

같은 사람은 14초 쉬고(맞음은 1.5초, 혼잣말은 30초) 말한다.

## 4. 대화창 (talk.ts)
- 말을 거는 순간 그 사람이 하던 일이 있으면 첫 말풍선: `busy.<work|eat|rest|toilet|train|smoke>` (`modules.ts fieldLink.busyCell`: 욕구 활동 id 또는 doing 글로 고름). 자료 없으면 아무 말 없음.
- 모델이 없거나 실패(예외)하면 그 인물이 대신 하는 한 줄 `facing.talk` + 오류 글은 그대로.
- 몹도 같다(`mob:<id>` 열쇠).

## 5. 경비 막기 (필드 기능 스레드와 나눈 일)
칸은 `expel.<소속>.<평판>.{warn, attack, attack_weapon, attack_threat, pass_companion, pass_permit, alarm}` + 다른 방문자용 `expel_other.{같은 7칸}`. 대사 파일 10개(경비·관리국 요원 남녀, 가짜 관리국 검사·진압부대, 백일몽 직원 남녀, 협회 직원 남녀).
actors.ts 는 필드 기능 스레드가 고친다. 호출은 **`this.events.push({ kind: 'cue', scene, who: g.def.name, id: g.def.id, cell: 'expel.warn', ctx: { target: '{user}', say: '여긴 관계자 외 출입 금지입니다.' } })`** — `target` 이 `{user}` 면 24갈래, 다른 방문자 이름이면 `expel_other`. `say` 는 자료가 없을 때(팩 못 받음) 쓰는 임시 글. 평판·소속은 넘기지 않아도 된다(speech 가 cueCtx 로 채운다). 다른 자리(동행 거절·경고·무기 겨눔·동료 쓰러짐…)도 같은 모양으로 `react.follow_no`·`react.warn`·`react.armed`·`combat.mate_down` 등을 쓰면 된다.

## 6. 아직 안 이어진 칸
`busy.no_seat`, `companion.*`(동행 중 장면 옮김·싸움·주인공 다침), `injured.*`(의무실), `react.crime_seen/mate_hit/armed/talk_leave`, `combat.ult/low/death/wake/mate_down/mate_dead`, `shower.*`(샤워 기능 보류), `social.topics`, `situation.see_body` 이름 인물(kill 사건 목격자로만). 그 순간을 만드는 코드 쪽에서 `cue` 사건을 밀어 넣으면 바로 붙는다.
