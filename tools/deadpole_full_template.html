이동 ←→ 좌우, ↑↓ 앞뒤 · Shift 누른 채 = 달리기, 짧게 = 앞구르기(무적, 적을 뚫고 지나가 무릎 쏴로 끝남) · Space 점프 · ↓↓ 무릎 쏴(←→ 낮게 이동, A 아래로 쏘기 = 쓰러진 적도 맞음, D 바닥 냄새, ↑ 일어서기)
A 근접 사격 3연타(리텐션 1발 → 더블탭 2발 → 「죄송합니다」 3발 + 밀기, 탄 6발) · 달리며 A = 슬라이딩 사격 · 공중 A = 아래로 2발 · 적 앞에서 E 옷깃 잡기(A 밀착 사격, 방향+A 배대뒤치기, Space 놓기)
S 빠른 뽑기(뽑는 장에서 1발) → 두 손 조준 사격(서 있으면 더 셈) · 탄창 15발을 A와 같이 씀, 비면 딸깍 → 자동 긴급 재장전 · R 재장전
D 짧게 = 되감기(최근 3초 피해 회복, 대가로 단서·지도 하나를 잊음, 20초 대기) · 길게 = 냄새 맡기(놓으면 적·숨은 방으로 냄새 선) · Q 짧게 = 칼날 잡기(칼 든 적이 치는 순간에 맞추면 붙잡고 반격 사격, 둔기는 못 잡음) · 길게 = 막아서기(피해는 그대로, 밀리지 않음, 게이지 2배)
W 선두 노출(게이지 100, 맞아야 참): 걸어 들어가 3초 동안 모든 적의 공격을 받음 → 쓰러짐 → 받은 피해 ×2를 모든 적에게 되돌림 → 되감기로 일어섬
체력 0 = 죽음 → 4초 누움(그동안 맞으면 연속 사망) → 부활(체력 가득, 2초 무적), 출동당 3회 · X 죽음 시험 · H 약 피격 · K 다운
