# PixelLab 배경 시험

- API v2(프록시가 인증 주입). `gen_bg.py`: `generate-image-v2` + 화풍 그림(style_image).
- 크기 제한: 비율에 따라 최대(정사각 512×512, 16:9 688×384, 가로 최대 792). `inpaint-v3`·`edit-images-v2`는 512×512까지.

## 2026-10-24 시험 1: f2 복도
- 프롬프트 `f2_prompt.txt`(짧은 영어), 화풍 그림 = 쟈알디 방 원본을 1/2로 줄인 것(836×470), 688×384.
- 결과 `game-src/art/field/raw/f2_pixellab_test.png` 688×384, 182.7초, **27 generations** 사용(남은 7737 / 월 19355).
- 좋은 점: 진짜 도트(1px = 1도트), 소품 밀도 높음(소화전함, 분리수거함, 정수기, 게시판, 액자, 옷걸이, 대기 의자, 엘리베이터).
- 문제: 밤·창밖 야경, 벽 얼룩·바닥 얼룩(낡음), 소화전함·정수기에 한글 글자, 왼쪽 옆벽·안쪽 대기실로 공간이 꺾임, 바닥 반사. 세로 384px라 게임 세로 700에 쓰려면 약 1.8배(2배) 키워야 함.

## 2026-10-24 시험 2: 옆벽(/) 달린 막힌 벽 1장
- 프롬프트 `f2_wall_prompt.txt`(뒷벽 모서리 17%, 옆벽 바닥선이 왼쪽 아래 모서리로, 문·창·물건 없음, 얼룩 없음). 592×444, 화풍 그림 = 쟈알디 방 1/2.
- 결과 `game-src/art/field/raw/f2_pl_wall.png`, 225초, **2 generations**(시험 1의 27과 큰 차이, 원인 미확인).

- 시험 1(관리국 2F 복도라고 넣은 것)도 밤·얼룩·낡음으로 나와 관리국 톤(밝고 정돈된 최신 시설)과 맞지 않음. 화풍 그림(밤 사무실)의 분위기·소품이 그대로 따라옴.
