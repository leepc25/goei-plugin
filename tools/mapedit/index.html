바닥 막힘 가림 깊이선

배경·캐릭터

배 (1 = 규격 크기: 세로 890에서 앞 1.5배)

조작

보기: 기본 확대 1.00(배경은 자동 2배). 사람 크기 = 세로 890 화면에서 맨 앞 1.5배·맨 뒤 0.85배를 장면 세로에 맞춘 값(게임과 같음) · 1 = 확대 1.00 · 0 = 전체 보기.
가림(C): 그린 다각형 안의 배경 그림을 캐릭터 위에 다시 칠한다. 캐릭터 발이 주황 깊이선보다 위(안쪽)면 그 부분이 캐릭터를 덮어 「뒤로 지나가는」 모습이 된다. 카운터·진열장처럼 배경에 그려진 물건 둘레를 딴다.
자동 가림(A): 물건 둘레로 상자를 끌면, 상자 테두리 색(벽·바닥)과 다른 점만 골라 가림을 만든다. 허용치·붓으로 다듬는다.
선택(V): 클릭으로 고르기 · 끌어서 옮기기 · 빈 곳 끌기 = 화면 이동 · 휠 = 확대/축소.
다각형 고치기: 고른 다각형의 흰 점 끌기 · 변 가운데 ＋ 끌기 = 점 추가 · 점 오른쪽 클릭 = 점 삭제 · 안쪽 끌기 = 통째 이동.
다각형 그리기(F·B·C): 클릭으로 점 · 첫 점(노랑) 다시 클릭 또는 Enter·더블클릭·오른쪽 클릭 = 닫기 · Backspace = 점 빼기 · Esc = 취소. 닫으면 선택 모드로.
소품: 모서리 끌기 = 크기 · R 회전 · H 좌우 뒤집기 · 주황 손잡이 끌기 = 깊이선(캐릭터 발이 이 선보다 위면 소품에 가려짐).
의자: 선반의 테스트룸 의자를 놓으면 노란 점(바닥 가운데)이 앉는 자리로 자동으로 생깁니다. 남·남동·남서 = 정면, 동·서 = 옆, 북쪽 = 뒤로 앉기. 앉는 모습은 캐릭터마다 저장된 값이 맞춥니다. 의자는 놓은 깊이의 사람 배율로 자동 크기.
앉는 자리(S): 의자가 아닌 가구(소파·벤치·침대)에만. 앉았을 때 발이 놓일 바닥을 클릭.
캐릭터: 끌어서 놓거나, 고른 뒤 방향키로 걷기(바닥·막힘 적용, Shift = 빠르게).
자동 가림(A): 가릴 물건을 덮는 상자를 끌면 벽·바닥 색과 다른 픽셀만 가림이 됨. 오른쪽에서 붓으로 더하기·지우기.
