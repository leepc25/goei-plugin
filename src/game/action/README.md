# 1인 전투 검증판

기획서 0.2를 위한 첫 실행판. 기존 4인 관찰형 순찰은 그대로 유지하고, 게임 창 상단의 **1인 전투 검증판 / 기존 순찰**로 선택한다. 신규 판은 기본으로 열린다. 릴리스 번호·자동 업데이트 파일은 이번 개발 커밋에서 바꾸지 않는다.

## 들어 있는 것

- 1280×720 방 하나, 쟈알디 1명, 근접 모퉁이 귀신 2체와 사격 경비 2체.
- 방향키 바닥 이동, Z 권총 판정, X 점프와 공중 사격, C 범위 파괴, Shift 회피, A 정면 가드, A+↓ 낮은 방어, S 필살기와 짧은 컷인.
- Q 회복 / W 방어 회복 / E 능력 회복. 키를 누른 순간 한 번만 소모하고 효과가 없으면 소비하지 않는다.
- 준비 동작·사격 탄환·경직·밀려남·다운·기상 보호·회피 무적·고유기 슈퍼아머. 무적과 아머의 피해 처리는 다르다.
- F 수동/자동. 자동도 같은 행동·쿨다운·충돌을 사용한다. 응답 대기 중 자동만 1.25배속.
- 바닥 클릭 이동, 적 클릭 추적·사격, 우클릭 방향 회피, 화면 행동 버튼. 터치는 가상 조이스틱+멀티터치 버튼.
- Esc 일시정지, 초점·앱 전환 시 입력 해제. 수동에서 채팅으로 초점을 옮기면 정지한다.
- `goei:game-action:v1` 별도 저장. 약 5초 간격·메뉴·전환·닫기에서 스냅샷 저장. 쓰기를 직렬화하고 다시 열 때 완료를 기다린다. 기존 `goei:game` 순찰 기록은 건드리지 않는다.
- 승리/후송과 새 훈련. 앱을 닫은 동안 진행하거나 패배시키지 않는다.

## 임시 자산과 빠진 범위

기존 팩에서 쟈알디·적 두 종류·배경 한 장만 추가 디코딩한다. 새 그림 팩 다운로드는 필요 없다. 원래 쟈알디 도트는 약 100px 높이이므로 이번에는 약 1.57배 확대해 160px 기준의 화면 비중을 검증한다. 이는 160px 원본 신규 자산을 완성했다는 뜻이 아니다.

기존 도트에는 전용 권총·점프·가드·회피·시네마틱 포즈가 없으므로 가까운 기존 포즈를 재사용한다. 가드·아머는 테두리, 능력은 사각 파동, 컷인은 기존 스킬 포즈 확대+속도선으로 표현한다. UI 한글은 시스템 글꼴이며 최종 픽셀 폰트가 아니다. 인체 움직임·캐릭터 외형·컷인 품질의 완성판으로 평가하지 않는다.

본부, 절차적 맵, 다른 요원, 잡기·투척·공중 콤보 보정, 별도 인벤토리, 키 재매핑, 능력 충전·좌표 지정, 지원 참전, 소리, 완성 시네마틱은 후속 범위다. 자동은 현재 눈앞의 적 4체를 처리하는 전투 AI이며 미확인 규칙·사건·경로 탐사 AI는 아직 없다. 아이템 세 종류는 검증용 지급품이다.

저장 형식은 이 검증판의 스키마이며 최종 게임 스키마와는 다르다. 다른 구조나 손상된 데이터는 새 훈련으로 열고 안내한다. 브라우저 강제 종료 직전의 비동기 쓰기는 보장하지 않으므로 최대 최근 저장 이후 진행이 손실될 수 있다.

## 실행·검증

```sh
npm ci
npm run typecheck
npm run build
npm test
python3 -m http.server 8765
```

빌드 결과의 **`dist/goei-action-demo.html`은 필요한 그림을 포함한 단일 파일**이라 일반 브라우저에서 단독으로 열도록 구성했다. 관리형 브라우저의 파일 접근 정책에 따라 로컬 HTTP 서버가 필요할 수 있다. 개발 중에는 `http://localhost:8765/tests/game/action.html`을 연다. `?w=390&h=844`는 모바일 크기 확인용이며 실제 모바일 터치/가로 모드도 별도 확인한다. 독립 HTML과 서버 데모는 각 실행 위치의 localStorage의 `goei-action-demo:v1`을 사용한다. 기존 시험 페이지 `tests/game/demo.html`은 4인 순찰 그대로다.

실제 Chromium 입력 시험:

```sh
# Playwright가 전역에 설치되어 있다면
node tests/action-browser.mjs
# 별도 설치 경로인 경우
PLAYWRIGHT_MODULE=/path/to/playwright CHROMIUM_PATH=/path/to/chromium node tests/action-browser.mjs
```

브라우저 시험은 로컬 HTTP 서버를 직접 열고 종료한다. 키보드 이동·점프/사격, 키 반복 시 아이템 단발 소비, 채팅 초점, 닫기/재열기, 자동 완주, 해제, 터치 조이스틱+공격, 모바일 가로 넘침과 pageerror를 확인한다. 이 시험은 가짜 GameHost로 진행하며 실제 RisuAI 프로그램 내 설치·저장 API·응답 이벤트는 별도 실기 확인이 필요하다.

## 다음 작업 순서

1. 실제 외형 레퍼런스와 160px 원본 도트로 점프·가드·회피·권총·컷인을 교체한다.
2. 수동 타격감과 모바일 표시 크기, 자동 전투의 거리 유지·공격 중 회피를 조정한다.
3. 가까운 적과 캐릭터 몸 밀기·벽·고정 장애물 판정을 추가한다.
4. 최소 본부와 방 이동·지도·임무 루프로 확장한다.

## 첫 구현 검증 기록 (2026-10-19)

- `npm run typecheck`, `npm run build`, `npm test` 통과. 전체 16개 테스트 파일 중 신규 전투 시험 파일 1개에는 자동 완주·저장 재현·시간 제한·방어·무적/아머·점프·소모품·적 예고·후송·저장 검증 시나리오가 있다.
- Chromium 실제 입력 시험 통과: 키보드·Q 단발 소비·게임 밖 텍스트 입력·재열기·자동 완주·멀티터치 조이스틱/공격·390px 화면 넘침 없음·독립 HTML·실제 게임 UI의 모드 전환·저장 키 분리.
- 독립 HTML 약 247KB(원본, 그림 포함). 그림 팩은 기존 720,037바이트 그대로이며 새 이미지 파일을 추가하지 않았다.
- 브라우저의 `file://` 접근은 실행 환경의 관리자 정책으로 막혀 직접 파일 열기 자동 검증은 수행하지 못했다. 동일 HTML은 로컬 HTTP에서 검증했다.
- 실제 RisuAI 프로그램과 모바일 실기 검증, 장시간 메모리 프로파일은 후속 확인 항목이다. 이번 결과를 그 검증까지 완료한 것으로 취급하지 않는다.
