## 1. 엔진 연결 (docs/게임_모듈_연결.md 3장)

| 내보내는 것 | 하는 일 |
| --- | --- |
| `createEnemy(kind, x, y, rng, {elite?, affixes?})` | 엔진 `Body`를 돌려준다 (`team: 'enemy'`, `frame()`·`step()`·`applyHit()`·`draw()`·`drawBack()`) |
| `stepEnemies(world)` | 모든 적 한 틱. 엔진이 `body.step`을 직접 부르면 안 불러도 된다(같은 틱 두 번은 무시). `stop>0`인 적은 건너뜀 |
| `applyHit(enemy, hit, world)` | 피해·반응·넉백을 적이 스스로 적용 → `{kind:'hit'|'guard'|'armor'|'immune', killed?}` |
| `spawnWave(budget, floorType, depth, rng, area?, opts?)` | 위협 예산으로 산 파도 목록 (`SpawnSpec[][]`, 정예는 `elite`·`affixes`) |
| `planEncounter({...})` | 위와 같고 예산 사용량·정예 수·난입·조합 서명까지 |
| `guardianSpawn(floorType, area?)` | 수호자 방 편성 (`boss: true`). 재현의 층은 노부부 둘 |
| `budgetFor(depth, chunkIndex, danger, variant, growth)` | 방 예산 (회색 상자 시험판과 같은 식) |
| `signalEnemies(world, signal)` | 규칙 이행 신호. E 입력에서 부른다 (아래 4장) |
| `setDropHook(fn)` | 처치 드랍 굴린 결과 → 아이템 모듈 `dropFromKill`에 연결 |
| `isThreat(body)` | 싸움 구간을 막는 적인가 (평화로운 주민, 밥상 앞 노부부는 아님) |

적이 쏘는 발사체는 `world.add(Proj)`로 들어가는 `team: 'enemy'` 몸이다. 플레이어 피격 상자와 겹친 다음 틱에 사라진다.

### 엔진에 바라는 것 (모두 선택)

- `Hit`에 붙어 오는 `debuff?: {kind, ticks}`를 플레이어 `applyHit`가 읽어 디버프를 건다 (출혈·오염·두통=조작 반전·공포·둔화).
- 잡기: `grab: true`인 Hit가 `every`(10틱)마다 이어서 온다. 14틱 넘게 안 오면 풀린 것. 연타로 빠져나오면 `enemy.releaseGrab(world)`를 불러 준다.
- `custom` 이벤트: `debuff`(쳐다보기 두통·B-12 공포), `screen`(어둠 퍼뜨리기), `evac`(B-12 셋 이상 닿음), `hurtPlayer`(썩은 밥), `enemyDrop`, `ruleKept`·`ruleBroken`(규칙서), `guardianCleared`(`how: 'kill'|'rule'|'endure'`), `bossPhase`, `groggy`, `enemyGrab`·`enemyRelease`, `enemyRally`, `enemyEscape`.
- `world.noise`(0~1)는 침묵의 층 외에도 발소리·소리와 냄새가 듣는다. `world.light`(0~1)는 손전등, 빛은 플레이어가 보는 쪽 420px.
- 틈새(다리 많은 것)는 층의 `props`에 `kind: 'crevice'`(막히면 `label: 'plugged'`)가 있으면 그 위치를, 없으면 화면 네 곳을 쓴다.

## 4. 규칙 신호 (`signalEnemies`)

`greet {x,y}` 주민 인사 · `door {x,y}` 문틈 손 · `plug {x}` 틈새 막기 · `bowl {x,y}` 그릇 덮기 · `mealThanks` / `mealEat` / `turnAway` 405호 밥상.

## 5. 위협 예산 (`spawn.ts`)

- 층 유형별 살 수 있는 적만 산다. 난입(가짜 관리국·백일몽)은 따로 굴린다.
- 파도: 예산 30 미만 1, 75 미만 2, 그 위 3. 한 파도 머릿수는 `min(8, 3 + 깊이/2)`.
- 같은 종은 덜 뽑히게 무게를 낮춰 조합을 섞는다. 직전 3방과 서명이 같으면 다시 뽑는다(3회).
- 남는 예산 → 정예(가격 14, 접사 출혈·경 아머·빠름·재생 중 1~2, 체력 1.6배). B-5 아래는 예산 15%를 처음부터 정예 몫으로 둔다.

## 6. 판정

- 동작은 단계(예고 → 유효 → 마무리)로 적고 `bake`가 장마다 `hit[]`·`hurt[]`를 따로 만든다(`moveJson`으로 JSON). 팔·무기가 뻗는 동안 공격 상자가 장마다 자라고, 뻗은 팔도 피격 상자다.
- 피격 상자는 부위(머리·몸통·다리·팔·방패·등·입·모서리)로 나뉘어 약점 판정에 쓴다.
- 예고는 최소 8틱(대부분 12~30틱). 예고 장에는 공격 상자가 없다(시험으로 확인).
- 공격권: 한 번에 근접 공격하는 일반 적은 2체(B-6 아래 3체). 나머지는 둘러싸고 기다린다. 사격 역할은 예외.
