# 아이템과 무기 (`src/game/action/items/`)

> 2026-10-28: 옛 출동용 부분(현금·이상 파편·사채·회수물 가방·중림 상인 `shop.ts`·`shopPanel.ts`·시험판 `demo.ts`)은 차원 승강기와 같이 지웠다. 아래 표는 당시 기록이다.

기본 기획서 11~14장·부록 F를 코드로 옮긴 순수 모듈. DOM·엔진 코드를 부르지 않고(엔진 타입만 `engine.ts`에서 가져옴), 상태는 전부 JSON으로 저장된다. 난수는 필드 시드(`rand(field)`)만 쓴다.

| 파일 | 내용 |
| --- | --- |
| `data.ts` | 소모품 9종, 정비실 `SUPPLY_CATALOG`, 요원 고유 무기·탄(쟈알디 8+16, 에일린 24+72, 데드폴 15+45, 나머지는 탄 없음), 임시 무기 두 묶음(한 손 근접 4종 / 총 3종), 환경 물건 12종(던지기·부수기·둘 다), 회수물 7종, 드랍 표(적 7종 + 물건 7종), 중림 상인 4곳 |

| `field.ts` | 바닥 드랍·자동 흡수(현금·파편·회복 조각·탄)·E 줍기(무기·아이템·회수물·물건 들기), A 던지기·휘두르기·물건 부수기, S 사격, 1~4 사용, 섬광·연막·소금 구역, 폭발 연쇄. `stepField(...)` → `ItemEvent[]` |

## 규칙 요약

- 고유 무기는 바꾸지 않는다. 임시 무기는 손에 하나: 근접 묶음이면 A가 그 무기(요원 클립 `pipe`), 총 묶음이면 S가 그 총(클립 `shotgun`). 다른 무기를 주우면 들던 것은 바닥에 내려놓는다. 내구·탄 0이면 사라진다. 총 탄은 보충하지 않는다.
- 고유 원거리 탄은 제한. 탄창이 비면 자동 재장전, R 수동. 예비가 바닥나면 탄 드랍 확률 +25%(막힘 방지). 탄이 없는 요원에게는 탄 대신 현금이 떨어진다.
- 효과가 없을 때(체력 가득에 회복약 등) 소모품은 소비하지 않는다. 사용 간격 0.35초.
- 물건: E로 들고 A로 던진다(맞으면 넘어뜨림·터짐), 든 채 E는 내려놓기. 부수는 물건은 고유 근접·임시 무기·탄·투척물 무엇으로든 부서지고 드랍 표를 굴린다. 드럼통 폭발은 주변 적과 물건을 연쇄로 친다. 금 간 벽은 `tag: 'hiddenRoom'`(층 생성 쪽이 쓴다).
- 정산(현금 → 예산, 회수물 감정, 빚 상환)과 Esc 가방 화면은 「본부와 임무 흐름」 몫. 그쪽은 `run.cash/shards/bag/debt`를 읽는다.
