# 괴이: 이면세계

RisuAI용 괴담 시뮬레이션 「괴이: 이면세계」의 전용 플러그인과 카드입니다. 지금은 개발 중인 판입니다.

## 설치

1. [Releases](https://github.com/leepc25/goei-plugin/releases)에서 최신 zip을 받습니다.
2. Risu 설정 → 플러그인 → 가져오기에서 `goei-plugin.js`를 추가하고, 뜨는 확인 창 두 개를 허용합니다.
3. `괴이_이면세계.charx`를 캐릭터로 가져옵니다. 쓰던 에셋 모듈(캐릭터 이미지)은 그대로 켜 둡니다.
4. 채팅 화면 구석의 유령 버튼을 눌러 세력, 첫 장면, 언어를 고르고 **출발**을 누릅니다.

## 업데이트

- 플러그인: Risu 설정 → 플러그인 탭에서 업데이트합니다.
- 카드: 유령 버튼 → 설정 → 업데이트에서 「카드 업데이트 준비」 → 「카드에 적용」. 채팅과 사진은 그대로입니다.
