# 괴이: 이면세계

RisuAI용 「괴이: 이면세계」(괴이봇 2탄 기반) 전용 플러그인과 카드 업데이트 파일을 두는 곳입니다.

- `release/goei-plugin.js`: 플러그인. Risu 설정 → 플러그인 탭이 이 파일로 자동 업데이트합니다.
- `release/card-update.json`: 카드 데이터(사진·에셋 제외). 플러그인 창의 설정 → 업데이트에서 받아 카드에 적용합니다.
- `release/version.json`: 최신 버전 정보.

처음 설치할 때는 배포받은 zip의 플러그인과 카드(`괴이_이면세계.charx`)를 한 번 넣으면, 그다음부터는 Risu 안에서 업데이트됩니다.
