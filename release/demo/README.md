# 직접 실행하는 전투 시연판

`goei-action-demo.html` 파일을 다운로드한 뒤 브라우저에서 연다. 그림과 코드가 포함된 단일 파일이며 별도 서버나 설치가 필요 없다.

방향키 이동, Z 근접/사격, X 점프, C 능력, Shift 회피/달리기, A 방어, S 필살기, Q/W/E 아이템, F 자동 전투, Esc 메뉴. 터치 조이스틱과 버튼도 제공한다.

한 방 전투 기능을 확인하는 작업 중 빌드다. 현재 캐릭터 동작은 체형 검토에서 불합격한 임시 자료다. 고정 기준 체형을 반영한 완성 시연판으로 간주하지 않는다. 본부·절차 생성 던전·전체 캐릭터는 포함하지 않는다. 정식 플러그인 릴리스와 분리된 시연 파일이다.
