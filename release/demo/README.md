# 쟈알디 체형 개선 플레이 시연판

`goei-jyaldi-slender.html`을 다운로드한 뒤 브라우저에서 연다. 코드와 그림을 내장한 단일 HTML이며 설치·서버가 필요 없다. 기존 `goei-action-demo.html`도 같은 최신 빌드로 교체했다.

방향키 이동, Z 근접/사격, X 점프, C 능력, Shift 회피/달리기, A 방어, S 필살기, Q/W/E 아이템, F 자동 전투, Esc 메뉴. 모바일은 화면의 조이스틱과 버튼을 사용한다. 첫 화면에서 **계속**을 누른다.

이번 판은 늘씬한 성인 체형의 전용 도트로 걷기·달리기·장타→팔꿈치→앞차기 3연계·사격·점프·가드·피격·다운·기상을 연결한 한 방 전투 시연판이다. 이전 SD 시트는 포함하지 않는다. 본부와 절차 생성 던전까지 완성된 전체 게임을 뜻하지 않는다.

`goei-jyaldi-motions.html`은 같은 도트의 동작 선택, 일시정지, 이전/다음 프레임, 2배 확대를 제공한다. 게임과 별도로 열 수 있다.

검증: TypeScript, 빌드, 전체 단위 시험 16개 파일, Chromium 키보드·터치·자동전투 완주·저장 복귀·Risu 호스트 모의 통합. 게임 내 160px 프레임 및 배경 위 표시를 별도로 검토했다.
