# 일반 체형 · 실제 플레이 시연판

**현재 파일: `goei-jyaldi-normal.html`**. 다운로드해서 브라우저로 열고 **계속**을 누른다. 코드와 런타임 그림을 내장한 약 0.8MB 단일 HTML이며 설치·서버·별도 그림 다운로드가 필요 없다. `goei-action-demo.html`도 같은 최신 파일이다.

새 일반 체형, 보강한 상체·팔과 조금 큰 손, 원본 128px 기준의 정수 2배 표시를 **실제 이동·전투에 적용했다.** 이전 늘씬한 체형의 게임을 새 변경이라고 소개하는 파일이 아니다. 과거판 `goei-jyaldi-slender.html`은 기록으로만 남긴다.

방향키 이동 / Z 가까이서 근접·멀리서 사격 / X 점프 / C 파괴 능력 / Shift 회피·유지 달리기 / A 가드·A+아래 낮은 가드 / S 필살기 / QWE 아이템 / F 자동전투 / Esc 메뉴. 바닥 클릭 이동, 적 클릭 공격, 우클릭 회피, 터치 조이스틱·버튼도 지원한다.

## 이번 적용

- 전투 대기 8장, 걷기·달리기 각 12장.
- 장타→팔꿈치→근거리 파괴 충격: 10·12·16장. 앞차기를 파괴 능력으로 재사용하지 않는다.
- 권총 발사 6장, C 14장, S 본체 24장, 별도 상반신 컷인 12장.
- 전용 회피 16장. 준비·이동·제동·복귀를 나누고 이동 구간만 실제 전진한다.
- 가변 프레임 유지 시간으로 준비·타격·회수를 배분하고 접촉 시점에 피해를 낸다.
- 달리기 체공·점프에서 접힌 다리 길이를 이유로 몸통이 아래로 떨어지지 않도록 가상 지면 기준점을 둔다. 이미지의 인체를 늘여 맞추지 않는다.
- 문·소품이 커진 새 640×360 배경, 정수 2배의 적 도트, 새 바닥 이동 범위·총구·피격 높이·그림자·마우스 선택 영역.
- 이전 저장의 바닥 좌표를 새 범위로 이관한다. 구형 순찰 모드와 저장 키는 유지한다.

패킹은 본체 원본 150장·별도 컷인 12장·기준 포즈 1장으로 총 163프레임이다. 클립의 시작/끝 포즈 공유와 일부 제작 여분이 있으므로 전부 별도 플레이 상태를 뜻하지 않는다. 계획의 필수 45동작/326장을 모두 완성했다는 뜻도 아니다. 시작·정지·반전·뒤걸음, 상세 가드/피격/기상, 점프 단계의 추가 중간 그림과 별도 무장 전환은 추가 제작 범위다. 현재 가드·낙하·피격·기상 일부는 여전히 단일 포즈다. 본부·절차 던전까지 완성한 전체 게임으로 취급하지 않는다.

`goei-jyaldi-motions.html`은 **같은 최신 자산**을 사용해 동작 선택·일시정지·이전/다음 프레임·2배 확대를 제공한다. `samples/`는 최초 단일 포즈 비교 자료다.

검증: 빌드·TypeScript·전체 단위 시험, Chromium 키보드·터치·자동 완주·저장 복원·Risu 호스트 모의 통합, 실제 배포 HTML의 자산 지문 및 근접/필살기 실행. 배포 HTML이 최신 코드/일반 체형 자산을 포함하는지 회귀 시험에서 검사한다.

Risu 그림 팩은 `release/goei-game-action-normal.pack`(버전 3)으로 별도 배포한다. 기존 플러그인이 사용하는 `goei-game-action.pack`(버전 2)과 그 캐시 키는 보존한다. 이 작업은 독립 시연판과 게임 소스 변경이며 클로드의 플러그인 v0.16.32 자동 업데이트 배포 파일을 덮어쓰지 않는다.
