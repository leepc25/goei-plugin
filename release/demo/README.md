# 쟈알디 액션 v4 · 실제 플레이 시연판

현재 파일: **[goei-jyaldi-action-v4.html](goei-jyaldi-action-v4.html)**. 코드와 그림을 내장한 단일 HTML이다. `goei-jyaldi-normal.html`과 `goei-action-demo.html`도 같은 최신 파일이다. 열어서 **계속**을 누른다. **동작 훈련** 버튼은 가까운 수동 표적을 배치해 새 동작을 시험한다. **새 훈련**은 일반 4체 전투로 돌아간다.

## 이번 변경

- GDC Cartwright 강연의 핵심 자세·가변 유지·히트스톱과 SLYNYRD의 보행/공격 분석을 제작 근거로 사용했다. 무료 에셋을 다운로드해 게임에 삽입한 변경은 아니다.
- 새 걷기·달리기는 각각 4개 핵심 자세다. 걷기는 팔의 앞뒤 교대, 달리기는 교대하는 팔과 추진·체공 실루엣을 다시 생성했다. 12장을 채우는 것을 목표로 삼지 않았다. 원본 128px 기준, 게임 정수 2배 표시다.
- 걷기도 달리기 보폭을 선택하던 오류를 고쳤다. 걷기 160 / 달리기 192 화면px의 한 주기를 각각 실제 이동 거리와 연결한다. 시작·정지 전환이나 접지 오차의 정량 검증까지 완료한 것은 아니다.
- 새 근접 1·2·3타는 5·5·6장. 준비·접촉·회수의 시간을 다르게 주고, 약 267 / 300 / 467ms를 기본 동작 시간으로 사용한다. 무조건 균등 FPS로 넘기지 않는다.
- 약타 명중 50ms, 강타 명중 약 83ms의 정지를 준다. 접촉 자세를 유지하고 정지 뒤 적을 밀어낸다. 헛치면 멈추지 않는다. 정지 중에도 공격 입력과 섬광은 진행한다.
- 점프·착지·공중차기·공중 사격을 새 그림으로 연결했다. 공중 포즈를 서 있는 키로 확대하지 않고 시트별 단일 배율과 가상 바닥 앵커를 사용한다.
- 앉기·앉아 이동·하단차기·대시 어깨치기를 실제 입력에 연결했다. 피격·다운·기상·가드 붕괴 스턴·승리·탈진/후송 자세도 연결했다.
- 결과 상태에서도 본체 동작이 진행된다. 결과 안내를 지연하고 위쪽에 배치해 승리/패배 자세를 가리지 않는다.
- 참조되지 않는 제작 여분 그림을 런타임에서 제거했다. 총 패킹 프레임은 **163→120개**이며 행동 120종을 뜻하지 않는다.

## 조작

방향키 이동 / Z 가까이서 약약강·멀리서 권총 / X 점프 / C 능력 / S 필살기 / Shift 회피·유지 달리기 / A 가드 / QWE 소모품 / F 자동 / Esc 메뉴.

- **A+아래:** 앉기. A를 유지하고 좌우를 누르면 낮은 자세로 이동한다. A를 놓으면 해제한다.
- **앉은 상태 Z:** 하단차기.
- **달리기 또는 회피 초반 Z:** 대시공격.
- **공중에서 가까운 적을 향해 Z:** 공중차기. 먼 적 방향은 공중 사격이다.
- 마우스 바닥 클릭 이동·적 클릭 공격·우클릭 회피, 터치 조이스틱·버튼도 지원한다. 터치는 A 버튼을 잡은 채 조이스틱을 아래로 기울여 앉고 좌우로 이동한다.

## 동작 검수와 한계

[goei-jyaldi-motions.html](goei-jyaldi-motions.html)은 같은 최신 그림과 개별 유지 시간을 사용한다. 동작 선택·0.5배속·일시정지·가중 시간에 맞는 이전/다음 자세·바닥 격자·확대를 제공한다. 정량 시험 통과와 시각 품질 합격은 구분한다.

v4는 핵심 동작 재제작의 첫 플레이 후보다. 보행의 4개 자세 사이 변화, 시트 간 체형 일관성, 실제 표시에서의 접지와 연결은 계속 시각 검수할 대상이다. 기본/전투 대기는 현재 각각 정지 자세 1개이며 호흡 완성본이 아니다. 시작·정지·방향 반전·뒤걸음·횡이동, 상세 방어 진입/해제, 전용 부위별 피격 등 모든 계획 동작이 완성된 것은 아니다. C 14장·S 본체 24장·컷인 12장은 기존 자료를 사용한다. 본부·절차 던전까지 완성한 전체 게임으로 부르지 않는다.

구현 데이터: `game-src/action/normal-v4/layout.json`. 재생 규칙: `src/game/action/motion.ts`. 재현: `python3 tools/action_normal_assets.py` 후 `npm run build`.

Risu용 새 팩: `release/goei-game-action-normal-v4.pack`, 버전 4, 전용 캐시 키. 기존 v2/v3 팩과 자동 업데이트 배포 파일은 보존한다. 게임 소스·독립 시연판을 공유한 것이며 이미 설치된 플러그인의 자동 업데이트를 발행한 것은 아니다.
